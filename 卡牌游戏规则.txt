1.基础规则



游戏所需

 阵营（Faction）：选择一个阵营（各阵营有独特机制与打法，另有阵营指南）

 卡组（Deck）：每名玩家 1 套完整卡组，含 1 张督军（传奇将领）。注意：一个完整的卡组需要督军卡牌再加上其他30张单位卡牌和计策卡（这些卡牌需要时同一个阵营的卡牌）。





战场（The Battlefield）

由双方玩家的棋盘（Board）、卡组（Deck）、弃牌堆（Discard Pile）及其他游戏区域组成。



 玩家棋盘：9 个空格。督军永远占据中央格，两侧各 4 格共可部署 8 张部队卡或者建筑卡。

 弃牌堆：被摧毁的部队或使用过的战术进入弃牌堆。

 持续效果（Persistent Effects）：标注"本场战斗持续生效（For the rest of this battle）"的效果在卡牌被弃置后依然生效——将此类卡放于弃牌堆旁的独立牌堆。

 能量（Energy）：用计数指示物放在卡组旁表示。

 骷髅头（Skulls）：将敌方督军生命削减至 20 / 10 / 0 时（首次）各获得 1 个骷髅头。

 特殊区域：部分阵营机制需要额外资源或卡牌状态记录，预留空间。



游戏模式（Game Modes）



**经典模式（Classic）**

| 项目 | 规则 |



| 目标 | 将敌方督军生命降至 0（同时 0 = 平局） |

| 卡组 | 1 督军 +  30 张阵营卡 + 防御卡 |

| 手牌 | 起手 3 张；上限 10；每回合抽 1 张 |

| 后手 | 后手玩家开局多 1 张牌，并持有防御卡 |

| 换牌（Mulligan） | 游戏开始时双方皆可选择任意手卡，将其返回卡组，之后从卡组抽出相应数量的卡牌加入手卡|

| 能量 | 每回合开始最大能量 +1 |

| 加时（Overtime） | 后手玩家最大能量达 10 时进入加时，双方每回合改为抽 2 张卡（从抽一张到抽两张） |

| 组卡限制 | 每张卡牌根据其稀有度（相同的普通/稀有/史诗卡最多2张；相同的传说卡最多1张且不同的传说卡最多7张）允许加入卡组的相同卡牌的张数；所有卡必须与督军同阵营 |





**2. 卡牌类型（Types of Cards）**



**卡牌分类**

 卡牌（Cards）：游戏中所有卡牌

 单位（Units）：督军卡、部队卡、建筑卡

 部队（Troops）：仅部队卡，不含督军

 建筑（Troops）：仅建筑卡

 计策（Stratagems）：战术卡、事件卡、科技卡、任务卡

 法术（Wildcards）：仅法术卡



注意：作用于"部队"的效果不能影响督军和建筑；作用于"单位"的效果可以影响督军和建筑。



**卡面布局**

所有单位卡有：近战攻击、远程攻击、生命、类型。战术卡无攻击/生命。所有可打出卡费用 ≥ 0。



**稀有度（Rarity）：**



| 灰 | 普通 |

| 蓝 | 稀有 |

| 紫 | 史诗 |

| 金 | 传说 |

| 橙 | 防御/特殊（无常规稀有度） 



**单位卡：**



**督军（Warlords）**

卡组核心，定义阵营、初始生命与关键机制。督军总是拥有天赋（Talent）——每回合开始加入手牌、回合结束移除的临时计策卡。



**部队（Troops）**

参与战斗，对敌方单位（部队、督军与建筑）造成伤害。

部署：可选择督军左侧或右侧的空置的棋盘卡槽（督军左右侧各有三个卡槽）；8 格全满则无法再部署。

使用：部署当回合不能行动（除非注明，如迅捷/侧翼等词条）；每回合每个单位 1 次行动（特例：一些效果允许单位做出多次行动）。

摧毁：单位卡的生命 ≤ 0 即被摧毁；部分卡因为效果（词条、计策或者单位效果等情况）可不造成伤害直接摧毁。被摧毁时的触发效果（如反噬）立即结算，然后进入弃牌堆。

建筑：可以视为特殊的部队卡，一般不能主动攻击，在场上持续发挥作用：增强我方，削弱敌方


**计策（Stratagems）：**

类型：战术卡、事件卡、科技卡、任务卡

战术卡：一般是增强我方单位或者削弱敌人单位，以获取战斗优势

事件卡：根据其效果可能影响双方。看其卡牌的具体效果。

科技卡：一般是付出一定资源（能量或者阵营特有的类似能量的资源），以获取持续性效果。

任务卡：一般是完成一些任务后获取持续性增益。比如消灭敌方15个单位后，直到游戏结束时我方手卡费用全部减1。

**防御卡**

后手（防守方）可打出的特殊战术，弥补后手劣势。每个阵营有 3 张独特防御卡。（注意这个防御卡我还没有设计）



**卡牌效果**



即时生效的卡：打出 → 结算效果 → 进入弃牌堆。影响多个单位时，按单位部署顺序逐一结算。


指向性/非指向性：根据卡牌的效果是否指定对象，部分卡牌的效果作用于全体单位或者随机单位。


持续/非持续：部分卡牌的效果可能是即时生效，也可能持续整个回合、数个回合，甚至持续整个游戏



**3. 游戏流程**

战前准备（顺序执行）

1. 替换手卡（换牌）

2. 部署督军

3. 能量设为 1（注意先手方进入回合后按照流程增加1点能量，此时先手方的第一回合有两点能量）

4. 确定阵营规则与货币（额外卡/指示物）

5. 掷骰/抛硬币决定先手

6. 后手取得防御卡（抽牌后置入起手牌）

7. 卡组洗牌并放置

8. 先手方正式进入回合



**回合结构**

敌我双方共用一个回合，但是只有轮到自己时才能根据回合阶段顺序进行能量增加、抽卡等操作，每个我方回合按以下顺序：

比如：第一回合是我方回合与敌方回合组成的，敌我回合交替进行（各自完成自己的回合）直至完成一个完成的回合。

1.回合开始阶段： 结算"回合开始"效果

2.判定阶段：结算阵营能力

3.补充能量阶段：增加1点能量值上限，且恢复所有能量（恢复到能量值上限）

4.抽卡阶段：抽 1 张牌

5.行动阶段：以任意顺序打出单位/计策/法术，或者让可用单位执行行动（攻击、发动自身效果等操作）

6.结算阶段：结算"回合结束"能力

7.正式结束阶段：回合结束，回合交给对手



**能量**

通用资源，用于打出/激活卡牌。起始 1，每回合 +1，双方均达 10 能量后进入加时。



**效果目标选择**

有效目标 = 场上无防止被选中的生效效果的单位。部分卡指定敌方单位/敌方部队/友方部队。部分关键词使单位对特定攻击方式/战术无效。



**攻击目标选择**

若敌方棋盘上任何单位有【护卫】词条或者有特殊效果（要求只能选择该目标攻击），则只能选中这些【护卫】单位或者有特殊效果的单位。



**行动**

每单位每回合 1 次行动（除非另有说明），行动：发动效果、进行攻击等操作。部分单位有替代行动可取代攻击，比如发动自身效果获得收益或者削弱敌人。


攻击：选择单位 → 声明攻击类型（近战/远程）→ 选择有效目标 → 声明攻击。伤害按声明的攻击类型同时结算，以近战/远程攻击敌方单位，对其造成近战/远程伤害的同时，自己也会受到相应的近战/远程伤害


> 示例：玩家 A 用【兽人小子】攻击玩家 B 的【初生者】（声明近战）。兽人小子造成 3 点近战伤害，同时受到 1 点近战反击伤害。初生者（0 生命）进入弃牌堆；兽人小子生命 3→2。

> 近战或者远程为攻击力 ≤ 0 的单位，也可以发动攻击，只是自己不会对敌人造成近战/远程伤害



替代行动：职责、狂暴、祈祷等关键词是部分单位可执行的替代攻击行动，受与攻击相同的限制条件约束（进行替代行动就不能进行攻击）。



**抽空疲劳**

牌库抽空后，每次尝试抽牌，督军承受疲劳伤害 = 自首次抽空以来的尝试抽牌次数。向牌库加回卡牌不重置疲劳计数。指定抽取某类卡的"检索"效果不触发疲劳（先检索再抽取）。




4. 其他规则

**词条（关键词）**

1.集结：某个单位从手卡打出时发动效果

2.护卫：保护左右两侧的单位，使其不会成为攻击或者（计策、法术、单位效果）效果的目标。攻击或者（计策、法术、单位效果）效果选择的目标只能先选择这些带有护卫词条单位，前线单位除外。

3.前线：场上存在前线词条单位的时候，攻击选择的目标只能先选择这些带有前线词条单位，同时不受我方【护卫】效果的影响（不会被护卫单位保护）

4.侧袭：不受敌方【前线】【护卫】效果影响

5.护甲（x）：主动攻击或者反击，受到普通伤害的时候可以抵消X点伤害，至少受到一点伤害。例如：用10点近战攻击力的单位攻击护甲（10）的单位，护甲（10）的单位本应该受到“10-10”的伤害，但是根据“至少受到一点伤害”的规则，其护甲（10）的单位受到1点伤害。

6.破甲（y）：主动攻击或者反击的时候抵消护甲（x）的y点护甲效果，例如：攻击力3带有破甲（3）的单位攻击护甲（3）的单位，可以对其完整造成3点伤害。

7.反大（x）：对大型单位额外造成x点伤害（主动攻击或者反击）

8.反步（x）：对步兵单位额外造成x点伤害（主动攻击或者反击）

9.淬毒（x）：对某个单位造成伤害后（主动攻击或者反击），给予其【中毒（x）】效果

10.中毒（x）：持续一回合，回合结束时受到x点伤害

11.附魔：造成的伤害改为魔法伤害。比如：某个单位获得【附魔】效果后，其造成的伤害从普通伤害改为魔法伤害，可以无视护甲效果

12.再生（x）：回合结束时，恢复x点生命值

13.痊愈（x）：持续一回合，回合结束时，恢复x点生命值

14.燃烧（x）：持续一回合，回合结束时受到x点伤害。

15.易伤（x）：受到伤害时，额外受到x点【易伤】伤害。注意：受到【易伤】伤害不会再次触发【易伤】伤害，防止不断循环

16.隐蔽：不会成为法术、计策的选择目标，但是可以成为攻击、单位效果的选择目标

17.隐身：直到下个我方回合的“回合开始”，该单位无法成为法术/计策/单位效果的选择目标以及不会成为敌方单位的攻击目标

18.伏击：登场回合不展示卡面（插图、数值等信息），受到攻击后展示其卡面或者我方回合的“回合开始”阶段

19.闪击：该单位登场的回合就可以攻击或者执行其他行动（发动自身效果、进行其他特殊行动）

20.冲锋（x）：该单位第一次攻击时额外造成x点伤害

21.斩杀：消灭敌方部队的时候获得一定的效果

22.狂怒（x）：单位生命值第一次低于x时且没有被消灭的时候，该单位获得一定的效果

23.狂暴（x）：单位生命值低于x时且没有被消灭的时候，该单位获得一定的效果

24.恐惧（x）：回合结束时进行一次骰子投掷，当点数小于x时，该单位返回手卡且清空所有受到的施加效果（所有的buff和debuff效果），但是当前的生命值不变（返回手卡时该单位的生命值剩下1点，回到手卡后其生命值还是1点）。

25.士气（y）：立刻自动消耗y点【士气】去抵消x点【恐惧】。该单位不存在【恐惧（x）】且存在【士气（y）】的时候，攻击值增加y点。

26.践踏：攻击时，发动攻击的单位对受到攻击的单位造成的溢出伤害（指的是造成的伤害值大于受攻击单位的剩余生命值的时候，其多出的数值为溢出伤害），对受到攻击的单位的左右的某一个相邻单位（随机选择）造成溢出伤害。比如：攻击10的单位a攻击生命值5的单位c，最后造成了5点溢出伤害，该5点溢出伤害又对单位c的相邻单位b造成5点伤害。

27.爆炸（x）：攻击时对攻击对象的相邻单位造成 X 伤害

28.护盾：防止本单位下一次将受的伤害，然后失去护盾

29.残骸：本部队死亡时用“残骸卡牌”表示残骸；残骸受伤害或控制者回合结束时被摧毁；残骸单位可以被某些效果【复生】 ，重新回到场上。

30.混乱：回合开始阶段时触发效果：该回合随机选择攻击、待机、受到伤害三种行动。攻击：随机攻击场上的一个任意单位（敌我双方）；待机：本回合不行动；受到伤害：受到1-2点伤害。

31.困惑：本回合（除了法师）部队无法攻击；法师则是无法发动法术

32.亡计：该单位死亡（被消灭）时，触发一定的效果

33.无敌：不会受到任何伤害且无法被消灭

34.眩晕：无法执行任何行动（攻击或者其他行动）

35.哨戒（x）：受到攻击前，先对发动攻击的单位造成x点伤害

36.暴怒：该单位无法被你操作（主动选择攻击对象或者发动其自身效果，但是该单位仍可以成为效果的选中对象），回合开始阶段时触发效果：自动攻击一名单位。

37.失明：本单位失明期间远程攻击设为 0

38.嗜血：一回合可进行至多 2 次攻击

39.震荡：被本单位攻击的单位获得眩晕

40.残忍：你的回合时，敌方单位受伤害未死亡时激活效果 

41.飞行：只能被【飞行】单位近战攻击或者受到远程攻击

42.兽潮（x）：从手牌打出时该单位卡时，在手卡中复制一张相同的【临时】单位卡，最多x次；每一张复制的【临时】单位卡，其费用与首张相同

43.团结：该单位卡从手卡打出时，场上每有 1 个友方的【团结】单位 ，该单位获得1点近战和远程攻击力

44.狙击：若远程攻击会摧毁目标：不承受反击伤害

45.兽群：场上每有 1 个友方的【兽群】单位 ，该单位攻击时额外增加1点近战和远程攻击力；若回合结束时，该单位没有进行过攻击则受到1点伤害。

46.压制：该单位无法发动攻击

47.誓言：完成【誓言】所要求的任务后，获得一定的增益

48.毁灭者：该单位摧毁一个单位后获得一点【毁灭点数】

49.猎杀标记：可叠加。带猎杀标记的敌方部队被摧毁时，对敌方督军造成伤害并治疗我方督军，数值 = 其标记数

50.守护者：通过“反击”（受到攻击时进行的反击）消灭敌人时，获得一定的效果

**其他词条**

天赋：回合开始时在手卡生成的【临时】战术卡

临时：回合结束时从手卡消失

登场：包括布置、增援

布置：从手卡打出单位卡牌到场上

增援（放置）：从除了手卡之外的地方将单位卡牌放置到场上

复活：不属于【登场】的特殊情况，一些单位通过效果重新出现在场上

复生：【复活】的一种情况，一般是【残骸】单位重新复活

普通伤害：大部分伤害都是“普通伤害”，没有特别说明的伤害一般都视为“普通伤害”

魔法伤害：一般是法术或者【附魔】造成的伤害

消灭：也可以被称为“摧毁”，指的是我方单位被敌方攻击或者效果影响导致生命值降为0

死亡：被消灭

待机：该单位本回合不执行任何行动

溢出伤害：指的是造成的伤害值大于受攻击单位的剩余生命值的时候，其多出的数值为溢出伤害

反击：单位受到近战、远程攻击的时候，也对发动攻击的单位造成相应的近战、远程伤害（数值为自己的近战、远程攻击力数值）

毁灭点数：根据毁灭点数的进度获得不同的收益：0-3无效果；4立刻获得一张【黑暗契约】卡牌；6立刻从卡组抽两张卡；9能量条上限加1；12我方场上单位的近战/远程攻击力加1，直到游戏结束；18手卡费用减2，直到游戏结束；25直接获得游戏胜利。
