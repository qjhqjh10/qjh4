## 二、我们怎么实现（三件，都在 `Shell/`）

| 件 | 文件 | 干什么 |
|---|---|---|
| **滚动区** | `MenuScroll.cs` | 视口 + 内容两端 + 偏移；`Shift/Intersects/FocusOn/Wheel`。**全壳唯一一份滚动实现** |
| **裁切** | `MenuWindowBase.Clip`（`PxRect?`） | 画内容前设一次、画完清掉；`Rect()` 把越界部分**截掉并把 uv 一起截**（否则图会被压扁）。**= 原版 `RectMask2D` 的等效物** |
| **指针层** | `PointerLayer.cs` | 新输入系统轮询 + 自己算命中：**滚轮**派给滚动区、**左键**派给 `WindowButton`。**.NET 唯一一条「真鼠标 → 界面」的路** |

**范围怎么定**（`MenuScroll` 自己算，调用方不用管）：
- **左对齐内容**：`[0, 内容右端 − 视口右端]`（只能往左滚）。
- **居中内容**：**两侧都有** `[内容左端 − 视口左端, 内容右端 − 视口右端]`
  ⇒ 往右滚能看到被左柱盖住的那几个、往左滚能看到越出右边的那几个。

**滚轮手感**：照**卡组编辑那条已经验过的路**（`DeckRuntime.HandleScroll` 用 `dy * 0.4f`，
`Deck/DeckRuntime.cs:1106-1113`）⇒ 新输入系统一格 ±120 ⇒ 一格滚 48px。**别两处各写一套。**

**命中顺序**（`PointerLayer.HitButton`）：**渲染队列大的先**（画在上面的先吃），
同队列再比 `z`（越小越靠前 —— 照 `CardInteraction.HitTest`）。
扫描时机 = **真有滚轮/按下/抬起时**才 `FindObjectsByType<WindowButton>()`（**不做每帧扫描、也不建静态登记表**）。

## 三、🔴 实现到什么程度（**2026-10-03 更新**）

### 3·1 ✅ **已做**（2026-10-03 这一轮补上的）

> 🔴 **判据 = Unity 自带的 `ScrollRect` 源码本体** —— 原版游戏的滚动就是它跑的，
> 「照抄 UGUI 的算式」= 逐位复刻、**不是我们挑的**。本地就能读：
> `Unity/MyGame/Library/PackageCache/com.unity.ugui@27635d171b1a/Runtime/UGUI/UI/Core/ScrollRect.cs`
> （另 `EventSystem/EventSystem.cs:68` 的 `m_DragThreshold = 10`）。

| 件 | 算式 / 值（照 UGUI） | 落在哪 |
|---|---|---|
| **惯性** | `v *= Mathf.Pow(m_DecelerationRate, deltaTime)`；`\|v\| < 1` ⇒ 0；`pos += v * dt`（:863-866） | `MenuScroll.Tick` |
| **速度来源** | 拖动中每帧 `newV = (pos − prevPos)/dt`；`v = Lerp(v, newV, deltaTime * 10)`（:884-888） | 同上 |
| **回弹** | `Elastic` 且越界 ⇒ `SmoothDamp(pos, 边界, ref speed, smoothTime)`，`smoothTime = m_Elasticity`（滚轮那一帧 **×3**），`\|speed\| < 1` ⇒ 0（:849-858） | 同上 |
| **橡皮筋** | `(1 − 1/((\|over\|·0.55/viewSize) + 1)) · viewSize · sign(over)`（:1084-1087） | `MenuScroll.RubberDelta` |
| **拖拽** | `pos = 按下时的位 + (当前指针 − 按下指针)`；Clamped ⇒ 夹回；Elastic ⇒ 再减 `RubberDelta`（`OnDrag` :779-810） | `MenuScroll.BeginDrag/DragTo/EndDrag` |
| **拖拽阈值** | **10px**（`EventSystem.m_DragThreshold`）—— 越过 ⇒ 这一套「按下→抬起」判成拖、**抬起时不再点按钮** | `PointerLayer.DragThreshold` |
| **悬停** | 指针下那一颗进 `Highlighted` 态；离开还原 | `PointerLayer.HoverAt` + `WindowButton.Enter/Exit` |
| **按下态** | `Pressed`；按下与抬起不在同一件 ⇒ 不派发 `onClick`（UGUI 语义，本来就有） | `WindowButton.Press/Release` |
| **纵向裁剪** | `MenuDraw.Rect` 现在**横纵两轴都截 uv**（原来只截 x ⇒ 纵向滚动区裁不住）；`MenuWindowBase.Text/TextBox` 的「整块在框外就不建」也补了 y | `MenuDraw.Rect` / `MenuWindowBase` |
| **接上滚动的界面** | 锻造轨道 · 锻造阵营条 · 战役阵营条 · 收藏窗 · 商店栅格（🆕）· **战役轨道 `Campaign Track`（🆕）** | 各自的 `Build*` |
