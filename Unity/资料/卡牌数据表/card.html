How to Use Card Forge

Create print-ready card sheets at standard 63×88mm card size (9 cards per A4 page).

  • Click a slot to upload one or more images. Multiple images fill consecutive slots.
  • Drag & drop images from your file manager onto any slot.
  • Right-click a slot for options: copy, paste, duplicate, fill row/page, rotate, remove.
  • Drag between slots to reorder cards (hold and drag a filled card to swap).
  • Use Contain / Cover / Fill toggle to change how images fit card slots.
  • Front + Back sheets are paired — when printing double-sided, backs are mirrored so cards align when cut.
  • Save Layout exports all card data as JSON (including images). Load Layout restores it.
  • Use Ctrl+P or the Print button. Set "Save as PDF", enable "Background Graphics", and set scale to 100%.
