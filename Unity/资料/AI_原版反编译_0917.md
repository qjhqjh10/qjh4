## 二、🔴 已经解出来的：**AI 的换牌规则**（原来记的是「规则没解开」）

`AI.GetAiMulliganCards(PlayerHand hand)` → `decomp_out_ai/AI__GetAiMulliganCards.c`：

```
遍历手牌：
  · 若 card.mulliganOption == MulliganOptions.whispersOfChaos (=30)  → 保留
  · 否则若 card.rawCardData.manaCost > 4                              → 换掉
  · 其余保留
```

**逐字对照**（偏移用 `dump.cs` 翻的，不是猜的）：

| 反编译里 | 字段 | 怎么翻出来的 |
|---|---|---|
| `*(int*)(item + 0x260) == 0x1e` | `CardScript.mulliganOption == 30` | `dump.cs`：`CardScript // 0x260 private MulliganOptions <mulliganOption>k__BackingField`；枚举 `MulliganOptions { normal=0, secondTurn=10, extraWarlord=20, whispersOfChaos=30 }` |
| `4 < *(int*)(*(longlong*)(item + 0x28) + 0x78)` | `item.rawCardData.manaCost > 4` | `EntityScript // 0x28 RawCardScript <rawCardData>` + `RawCardScript // 0x78 public int manaCost` |

⇒ **我们工程现在的「AI 一张都不换」是可以改掉的**（`BattleDriver.OpenMulligan`，那儿还留着「有据的偏离」的注释）——
**照这条规则实现即可**，那条注释要一并更新。
