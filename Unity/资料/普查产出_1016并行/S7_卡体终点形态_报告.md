## 一 · 原版手牌卡：**是 uGUI 件**，但**不是「画布布局件」**；卡体自带一颗 `WorldSpace` 根 Canvas

### A. 手牌锚点链（逐节点类型，battlearena2）—— 父链没错，但**类型全反了**

```
BattlePrefab[T] ← BattleHud[T] ← Canvas[R, Canvas_2765] ← BackCanvas[R, Canvas_2768]
   ← Safe area BackCanvas[R] ← BottomAnchor[R] ← PlayerArea[**T**] ← HandArea[**T**, +PlayerHand]
   ← HandAnchor[**T**, +CardsHorizontalLayout]
```
- `GameObject/PlayerArea.json` = `Transform 1345` + MB 4548（`Transform/Transform_1345.json`，⛔ **无 `RectTransform_1345`**）
- `GameObject/HandArea.json` = `Transform 1344` + MB 4547 → `m_Script -1233043523015714209` = **`PlayerHand`**
- `GameObject/HandAnchor.json` = `Transform 1284` + MB 4248 → `7953367724191579424` = **`CardsHorizontalLayout`** ⇒ **`HandAnchor` 是纯 `Transform`**
- 上游才有 RT：`BottomAnchor`(`RectTransform_2811`) ← `Safe area BackCanvas` ← `BackCanvas`(`RectTransform_2877` · `Canvas_2768` · `m_RenderMode=2` · `m_OverrideSorting=0`)
- 根 `Canvas` = `RectTransform_2952`(scale 0，运行时由 Canvas 驱动) + `Canvas_2765`(**`m_RenderMode=1` ScreenSpaceCamera** · `m_Camera=1559`) + **唯一一颗 `CanvasScaler` `MB_4940`**（`ScaleWithScreenSize` · **1920×1080** · **`Expand`** · ppu 100）
- `1559` = `GameObject/UI Camera.json` 的 Camera（`Camera_1559`：**`orthographic:false` fov 40** · `m_CullingMask=32`=层5 · depth 0）
  ⇒ **原版 HUD 是「透视相机 + `ScreenSpaceCamera` 画布」**（⚠️ 我们用的是**正交**相机 —— **如实记，本报告不判它算不算偏离**）

⇒ **结论：手牌区在画布树里，但 `PlayerArea`/`HandArea`/`HandAnchor` 三节是【纯 `Transform`】**（uGUI 布局/锚点**不管**它们，`DOMove` 世界位移才管）。**⇒ 两说各对一半。**

### B. 卡 prefab（决定性）—— `bundle_battleprefabs_vfxandmisc_assets_all/`

- `GameObject/CardPrefab.json` `[T, 层0]` = `CardScript`（字段 `cardCollider2D`）+ **`BattleCardUI`** + `CardHighlight` + 5×`CardTextCountersController`
  - `GameObject/2DCard.json` **`[R, 层5]`** = `RectTransform_3376`（`sizeDelta` **2.0927×3.3313** · anchor .5/.5）
    + **`Canvas`**（`Canvas_351872722556656576.json`：**`m_RenderMode=2` WorldSpace** · `m_Camera=0` · **`m_OverrideSorting=1`**）
    + `CanvasRenderer` + `CanvasGroup`
    + **`BoxCollider2D` × 2**（`1.97×3.02 @0` ＋ `1.25×2.53 @ y−2.62`，prefab 里**两颗都 enabled**）
    + MB：**`CardCollider2D`**（字段 `boxCollider2D` / `colliderHeightMultiplierInHand` / `colliderShowInBig`）· `Card2DController` · `AutoCardRotation`(10/10/10) · `CardTextsController` · `UIGroupTint`…
    - `2DCard/UI Collider` `[R]` = `CanvasRenderer` + **`NonDrawingGraphic`**（`m_ClassName = NonDrawingGraphic` · ns `UnityEngine.UI.Extensions`；
      **`m_RaycastTarget=1` · `m_RaycastPadding=(0,0,0,0)` · `m_Maskable=1`** ← **现读核过 `T03` 引的值，一致**）+ `UIGenericEventCatcher`(`OnClick`/`OnEnter`/`OnExit`)

  - `Board Elements/3DBody` **`[T, 层10]`** = `SortingGroup` + 网格/粒子（`Card 3D` · `TraitIcons` · `HealthText` …）

⇒ 🔴 **原版卡 = 「自己一颗 `WorldSpace` 根 Canvas 的 uGUI 面(`2DCard`) ＋ 一个 3D 体(`3DBody`)」合体**。
`2DCard` 是 `RectTransform`，`UI Collider` 是它的子件（**stretch `(0,0)-(1,1)` + `sizeDelta (−0.2,−0.44)`**）。

### C. 落位是【世界位移】（decomp）

- `PlayerHand__SetParentOfCard.c` = `card.transform.SetParent(HandAnchorLayout.transform, true)`
- `PlayerHand__SetupCardInHand.c` = `BattleCardUI.ShowBoardObjects(false)`（藏 3D 体）+ `SetSortingLayer/Order` + `set_parent(HandArea…, false)` + 存 `card+0x148 = HandAnchorLayout`

## 二 · 原版场上卡：**同一颗 prefab 的两种表示并存**（画布面 + 3D 体）

- 场上卡就是 `CardPrefab`（`CardScript` + `BattleCardUI`）；
  `BattleCardUI__SetSortingOrder.c` = **`Canvas.set_sortingOrder(n)` + `transform.SetSiblingIndex(n)`** ·
  `BattleCardUI__SetSortingLayer.c` = **`Canvas.set_sortingLayerID(...)`**
  ⇒ **场上卡的层序靠它【自己那颗嵌套 Canvas】管**（`m_OverrideSorting=1` 正是为此）。
- `CardScript__SetUnitInPlayLayer.c` → `CardCollider2D.SetColliderNotInHand` + `BattleCardUI.SetSortingOrder/Layer`

- 3D 体由**透视** `BoardCamera` 画（`Camera_1560` **ortho=false fov 46.4** · `m_CullingMask=1137` · `m_Depth=−1`；`UI Camera` depth 0）⇒ **3D 体(层10) 与 卡面(层5) 分别由两台相机画**。
- `MinionManager__FillMinionPositions.c` / `__AdjustMinionBoardPos.c`：场上槽位是 **`Vector2` 数组**（x,y 世界量），**非画布坐标**。

## 三 · `EverguildPhysics2DRaycaster` ＋ `GetTargetInPos` ＋ `CardCollider2D` 怎么串 ⇒ **两条命中面【并存】，第三条链是「瞄准」**

1. **两条并存（同一 `EventSystem`）**：`EverguildGraphicRaycaster`（hash `3762903421402112529`）**8 个** = 根 `Canvas`(go1006) · `BackCanvas`(go1242) · go618 · go158 · go463 · go818 · go937 · go1091；
   `EverguildPhysics2DRaycaster`（hash `-1470708798798514034`）**1 个**，挂在 **`UI Camera`** —— 而**它正是根 `Canvas` 的那台相机**（`m_Camera=1559`）。
2. **不是二选一，是「两条都喂 EventSystem」**：反编译体互相印证 ——
   `EverguildGraphicRaycaster__.ctor.c` 体 = `CustomRaycaster : GraphicRaycaster`；`CustomRaycaster__Raycast.c` = `GraphicRaycaster.Raycast(...)` → **`RaycastFilter.FilterRaycastResults(results)`**；
   `EverguildPhysics2DRaycaster__.ctor.c` 体 = `CustomRaycaster2D : Physics2DRaycaster`；`CustomRaycaster2D__Raycast.c` = **`Physics2DRaycaster.Raycast(...)`** → **同一个** `RaycastFilter.FilterRaycastResults`。
   而 `RaycastFilter__FilterRaycastResults.c` **只做 `List<RaycastResult>.RemoveAll(pred)`（只剔不选）** ⇒ **没有「谁取代谁」**。
3. 🔴 **`BattleManager__GetTargetInPos.c:104` = `Physics2D.GetRayIntersectionNonAlloc(buf, …)`**，取 **buf 第 0 项**（`RaycastHit2D.get_transform` → `GetComponent<A>/<B>/<C>`）；另有一条 **3D 兜底**（`Camera.ScreenPointToRay` + `Physics.RaycastNonAlloc` + `GetComponentInParent`）。
   🔴 **调用者只有 `BattleManager.Update`**（全仓 grep：`GetTargetInPos` 仅出现在 `BattleManager__GetTargetInPos.c` / `BattleManager__Update.c`）
   ⇒ **它是「指针下是谁」的瞄准/悬停射线，⛔ 不是卡片点击路。**
4. `CardCollider2D`（hash `-1521720365599783612`）挂在 **`2DCard`**（本场景 **8 个实例**）：
   `Initialize` 读 `BoxCollider2D.size/offset` 存为 Original；`SetColliderInHand` **乘 `colliderHeightMultiplierInHand`** 改 size/offset；
   `SetColliderNotInHand(state)` 在 `state∉{11,6}` 时 `set_enabled(false)` 并复位；`Toggle` 管第二颗(0x58)；`SetCollidersShowBig` 管「大卡窗」。
   调用者：`CardScript.SetUnitInPlayLayer / SetAsHero / SetAsDeck / SetupInDeck / SetStateAsMulligan / RemoveFromGameCard / SetAsCemetery` ＋ `PlayerHand._MoveCardsInHandToPosition`。

⇒ 🔴 **两条命中面（uGUI `NonDrawingGraphic` ＋ `Physics2D BoxCollider2D`）都在 `2DCard` 上【并存】。**
⚠️ 但 **`GetTargetInPos` 是【瞄准链】，⛔ 不能拿来证明「卡点击走物理」**。
