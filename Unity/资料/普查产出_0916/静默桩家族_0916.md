## 一、病根：两把尺子都没量到「这个种类会不会判」

| 层 | 原来的判据 | 漏掉的东西 |
|---|---|---|
| `EffectText.OpHasMechanism` | 只查「**条件种类是不是空**」 | 种类**认得出来**、但结算层是 `return false`（= 判不了）—— **报表放行** |
| `BattleDriver` 打 `*` | `if (c.Type == "tactic")` | **单位卡 / 防御卡永不打 `*`** ⇒ 卡面一侧也看不见 |
| `EffectText.Coverage` | 默认 `type="tactic"` | **单位卡的账根本不在表上** |

三条叠起来 ⇒ 「这张卡的这半句永远不会发生」这件事**只有一个地方说**：运行时一行日志。

## 五、坑（这块是知识，别删）

- **`When <事件>, <正文>` 的卡，别拿 `EffectText.Parse(整条 desc)` 的结果下结论。** 那切分在
  `CardDef.AddWhenTrigger` 里；裸解析会把事件从句漏进**目标短语**（实测 `Accursed Helbrute`：
  `raw「when a friendly troop receives a dark pact, this troop」`）。
- **`EffectResolver.cs` 里的类叫 `RuleCore`**（`public static partial class`）—— 文件名不等于类名，引用要写 `RuleCore.`。
- **`PayloadOp` 的引用字段**：`op.Payload` 是**字符串**，解析成项要走 `GivePayload.Parse(op.Payload)`。
- **`ConditionHolds` 的契约**：`return false` = **「判不了」**（调用点会报「整条效果没有生效」并记进 `unresolved`），
  跟「条件不成立」是两件事。**别把判不了改成静默的 false。**
- 🔴 **改 `switch` / `if` 分支密集的那种函数时，Edit 的 `old_string` 一定要带上「那一段的收尾」**
  （`r.Kind = …; return true; }`）。2026-09-16 吃了三次：因为收尾那三行在**同一个文件里长得一模一样**，
  拿它当锚点会把**上一支的收尾顶掉**、让两支黏在一起 —— 而**花括号总数仍然平衡**
  （后面那一支的 `}` 正好补上），所以**自己写脚本数括号查不出来**，只有编译器会说
  （症状是「`ErrorText.cs(4124): The modifier 'static' is not valid for this item」这种莫名其妙的 CS0106）。
  ⇒ **改完立刻读一眼那一段**，别只看 `git diff --numstat`。
- **`RuleEngineTest` 里有几条老断言钉的是「某张卡是终态、不许猜」**（`Mekaniak` 的池子表计数、
  「事件流里明说不认识」）。**把那张卡真做出来之后，这些断言会红** —— 那不是回归，是**该改判**。
  2026-09-16 改了 3 条（`RuleEngineTest.cs` 的 `ChooseEffectPools` 计数、`Mekaniak` 那两条、
  以及 `Extermination Protocol` 那条「只报不替」）。
- 🔴 **两张报表对同一张卡给出不同结论 = 判据写了两份**（2026-09-16 收尾时又抓到一起）：
  自检的**逐阵营覆盖率表**自己又判了一遍（`un.Count == 0 && pa.Count == 0`），
  **漏了 `EffectText.Coverage` 的两条豁免** —— ① 手牌陷阱（`IsHandTrap`）直接算全过 ·
  ② `HandledByOtherLayer` 把「别的层已经接手的句子」从「不认识」里剔掉。
  ⇒ 实测 `Genestealers` 那栏「战术卡 34 · 完全解析 **33**」，而全局表头写 **445/445** ——
  差的就是 `Poisoned Supplies` / `Cult Propaganda` 那几张**手牌陷阱战术卡**。
  **这是本工程记过的「报表虚低」**（下一个人照着做会去重做已经做完的事）⇒
  已改成**单卡跑一遍 `Coverage`**，两张表**同源**。
  ⚠️ **判据**：只要有两个地方都在「判同一件事」，就一定会漂 —— 改的时候**先 grep 有没有第二份**。
- 判据只此一处的地方（改的时候别另写一份）：`EffectCondition.ClauseKeyword(s)` · `CreatePool.MatchesKind` ·
  `RuleCore.CanJudgeCondition` · `EffectText.IsKnownWord`。
