1. 🔴 **`blacklegion` 的均值 +3.19 不是「全图均匀罩纱」，是「下半屏暗部被抬高」**。

   ⇒ **随 y 单调增**，不是常数罩纱。而且落在**极暗区**时**相对差极大**：
   `--rect 200,590,280,660` 我们 **12.8** / 原版 **3.0**（**4.28×**）·
   `--rect 0,560,280,720` 我们 **18.2** / 原版 **11.2**（**1.62×**）。
   ⛔ 别去追「全局罩纱」；要做的是**下半屏的暗部/黑电平**（见 **C4 / C5 / C6 / C7**）。
2. 🔴 **三场都没有「按物体的位置偏移」** —— 全图最优平移三场一致 = **dx 0 / dy +2**（1280×720 空间）。
   （判法：整图 + 上/下半屏分别搜 ±12px，**都只在 dy=+2 变好**；若不是全局的，差的那块会要求另一个位移。）
   ⚠️ 与本批 `A3` 报告交叉一致：这是正本已记的**取景平移（干净对位）**，**不是缺陷**，后面每条都是「亮度 / 内容」差。
3. ✅ **`astramilitarum` 是三场里最整齐的一场**（|逐块差| ≤ 5 占 **86.5%**），但**不是没问题** ——

   ⇒ 印证正本那条：**数字看不出「这里本该有个物件」，要并排看。**
