## 〇、三个总判决（先回答简报里点名要查的）

1. 🔴 **`darkangels` 的均值 +2.75 不是「全图均匀罩纱」** —— 大平面逐块几乎一致：
   `--rect 400,400,700,500` 我们 **116.2** / 原版 **114.5**（+1.7）·
   `800,400,1100,500` **114.2 / 114.9**（−0.7）· `200,500,400,650` **93.4 / 94.2**（−0.8）。
   均值是被**两三块局部亮点**拉起来的（罐子光晕 + 天空岩体那块），**别去追全局量**。
2. 🔴 **三场都没有「按物体的位置偏移」** —— 全图最优平移三场一致 = **dx 0 / dy +2**（1280×720），
   即 1920×1080 下的 **(0, −4)px**，与正本记的「干净的 (0,−4)px 平移」同源 ⇒ **取景平移，不是缺陷**。
   （判法：拿任意区域搜 ±12px 最佳平移，**每个区域都只在 dy=+2 变好、且变好幅度一样**；若不是全局的，
   差的那一块会要求另一个位移。）**⇒ 后面每条都是「亮度/内容」差，不是对位差。**
3. ⚠️ **正本 `战场13场_逐场对账_0920.md:415-419` 那张「带形签名」表已过期**（铁律 5，**没改正本，只在此标出**）：
   表里 `darkangels` = `+12.0 / +10.5`、`emperorschildren` = `+10.4 / +7.2`（y0-120 / y120-240）。
   **现读**（`工具/arena_bands.py`）：`darkangels` **+2.9 / +9.0**（其余带 ≤±1.6）·
   `emperorschildren` **−2.3 / +1.2** ⇒ **EC 那条「只有顶部亮」已经不存在了**，DA 只剩 y120-240 那一条。

## 四、方法与可复算命令（照抄即可）

```bash
cd /d/4/Unity
# ① 分带（先判「是不是全图均匀」）
PYTHONIOENCODING=utf-8 python -I -X utf8 工具/arena_bands.py  <场>
# ② 逐块有符号差（找极端块；--bs 20 更细）
PYTHONIOENCODING=utf-8 python -I -X utf8 工具/arena_blocks.py <场> --bs 20 --top 14
# ③ 量某一块的**两个均值**（本报告每条结论的背书工具）
PYTHONIOENCODING=utf-8 python -I -X utf8 工具/arena_regions.py <场> --rect x0,y0,x1,y1 [--rect …]
# ④ 放大看（每场只有一个输出，跑完立刻读）
PYTHONIOENCODING=utf-8 python -I -X utf8 工具/arena_sbs.py <场> --rect 比例,比例,比例,比例 --gain 6
```

**另有一件临时只读探针**（本次为定位"物体形状差"写的，**不在白名单工具里，可删**）：
`d:/4/Unity/_tmp_view/_probe_a3.py`，三种用法：
- `--rect x0,y0,x1,y1`（可重复）→ 打 **RGB 三分量 + lum + std**（`std` 用来分「平区/有结构」）
- `--mode dark|bright --bs 20 --top 12` → 列「原版有、我们黑」/「我们亮、原版暗」的块
- `--shift x0,y0,x1,y1 --r 12` → 搜**最佳平移**（判「是位置偏移还是亮度差」，§〇·2 就是这么定的）
- `--map x0,y0,x1,y1 --bs 20` → 该区的 ASCII 差图
