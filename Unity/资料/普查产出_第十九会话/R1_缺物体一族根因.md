## 〇、方法（可复算）

**判据链**：`<场>_manifest.json`（= 原版实读的 pos）→ 按该场 `camera` 投影到 1280×720
→ 与 `资料/原版实拍/arena_0920/shot_*.png` 的像素位置比。

投影公式（Unity 物理相机，逐字照 `ArenaBuilder.ConfigureBoardCamera` 的口径）：

```
tanH = (sensorSizeX/2)/focal(28)          # gateFit = Horizontal
tanV = tanH / (1280/720)                  # 竖直视角由宽高比推出来
view = qinv(camRot) · (world − camPos)    # Unity 视空间：+X 右 / +Y 上 / +Z 前
px   = ((viewX/viewZ)/tanH * 0.5 + 0.5) * 1280
py↑  = ((viewY/viewZ)/tanV − 2·lensShiftY) * 0.5 + 0.5) * 720    # y 从**底**起
```
`lensShiftY` 用清单里那份原版值 **−0.205**（`ArenaBuilder` 实际喂的是
`BattleScene.BoardLensShiftY()` ≈ **−0.2105**，差 0.0055 ≈ **4px**，不影响本报告任何结论）。

🔴 **投影方向（`−2·lensShiftY` 还是 `+2·lensShiftY`）是现核的，不是抄的** —— 两个独立锚点：
1. **aeldari 传送门**：`Vortex portal` / `Portal High quality` world **(108.4, 7.6, 22.9)**
   → 投影 **(840, ytop 84)**；A2 报的亮盘 rect 正是 `800,0,880,140`（中心 840）✅
2. **darkangels 星空**：`Star twinkle` 一族（world z ≈ 1458、y ≈ 250~530）→ 全部落在
   **ytop 21~70**（画面顶部星空）；反过来那个符号会把它们扔到 ytop 316~365（画面中部）❌

**噪声**：单点位置的可信度约 **±30px**（粒子有扩散、OBJ bbox 不可全信）。所以下面凡
「是不是**清单里没有**」这类结论**不靠投影**（靠 `名字+世界 pos` 直接对），投影只用来**定名**。

## 二、两族根因

### 🔴 族 A · 搬运/生成 —— `GameObject` 解析规则把对象整件丢掉（**只命中 astra 2 件**）

**根因（一处）**：`load_go_dir` 只把「**文件名 stem == `m_Name`**」的 dump 认作 pathID 命名的资产：

```python
# 工具/scripts快照/unity_scene_to_godot.py:99-110（d:/2/Warpforge_tools/scripts/ 下同一份、同 99-110 行）
#   🔴 2026-09-20 修：文件名尾的 `_<n>` **只有当 stem == m_Name 时才算 pathID**。
if m and m.group(1) == nm:
    known[int(m.group(2))] = data          # ← 进 a.GO，能被 m_PathID 查到
else:
    plain.setdefault(nm, []).append(data)  # ← 进 plain，**返回时被丢弃**（Assembler 只取第一个返回值）
```

`Generator ` 的 `m_Name` **末尾带一个空格**（`Generator_570.json` 的 `m_Name` 实测是 `"Generator "`），
而 dump 写出来的文件名把空格吃掉了 ⇒ stem `"Generator"` ≠ `"Generator "` ⇒ **进 `plain` 被丢**。
后果链（全程静默）：

1. `a.GO[570]` 不存在 ⇒ `go_comps[570]` 为空
2. ⇒ `mesh_of()` / `mats_of()` 什么都返回不了
3. ⇒ `gen_unity_arena_manifest.py:1392` 那句 `if not mesh_name: continue` **整件丢掉**（`warn` 也不打）
4. ⇒ 清单、`Models/`、场景、prefab **四处都没有它**（已逐处核过）

**实据（astra）**：
- `d:/2/解包整理/07_场景/battlearenaastramilitarum/GameObject/Generator_570.json`：
  `m_Name = "Generator "` · 组件 `[1424, 1669, 1616, 1768, 5039]`
  = Transform · **MeshFilter**（`m_Mesh = {fileID:2, pathID:39}` → **网格名 `Generator 1`**）· **MeshRenderer**（mat `{fileID:2,pathID:14}`）
- 世界变换：pos `(102.58, 0.68, −9.89)`、**scale 174.863**（= 战场通用缩放，是常规摆件）
- 我们的 `battlearenaastramilitarum_manifest.json` 里 **`Generator` 出现 0 次**；
  `arenas/battlearenaastramilitarum/Models/` 里**没有** `Generator*` 的 OBJ
- 同族第二件（**同场、同一根因、此前没人报过**）：**`Bunker Gun `**（pid **500**）
  world `(70.45, 21.99, 69.85)` → 投影 **(x334, ytop8)**，清单里也没有
  （它被 `gen_arena_groups.py` 当成**容器节点**收进了 `nodes[]`：
  `Battle Arena Astra Militarum Baked/Bunker Gun .001/Bunker Gun `）

**全 13 场普查（判据 = 逐场扫 GameObject dump：「stem≠m_Name」+ **确实带 MR/PS/SMR/PSR** +
名字在清单里找不到）**：命中 **只有这 2 件，都在 astra**。
⚠️ 原始扫描会多报 25 条**假阳性** —— 那是**纯名**文件（`Scrap_5.json` / `Thorn_5.json` /
`BG_Building_1.json` / `Capillary_1.json` …：名字自己以 `_<数字>` 结尾），它们的对象**都在清单里**
（走真实 pid 那条路进来了）。**别把这 25 条当账。**

**修法（要做；判据已齐）**：
1. **改 loader**：`工具/scripts快照/unity_scene_to_godot.py:99-110` —— 不认「stem==m_Name」这一条死规矩；
   改判据为「**stem == `m_Name` 去掉首尾空白/非法字符后的形状**」（即 `win_safe(m_Name).strip()` 那一侧），
   或干脆**同时读 bundle 侧**（`BundleResolver` 已能按 pid 直读 GameObject）。
   ⚠️ 那条注释自己写的**要防的坑是真的**（`Scrap_5.json` 会冒充 `GO 5`，而 GO 5 是 arena2/leviathan 的
   `Directional Light`）⇒ 新判据必须**两边都判**：`stem == nm 或 stem == nm.strip()`，
   并且**「多条候选抢同一个 pid」时报错出声**，不许静默取第一条。
2. **补一条出声**：`gen_unity_arena_manifest.py:1392` 那句 `if not mesh_name: continue` 现在**一声不响**。
   加一条 `warn['go_unresolved']`（带 GO pid），**照铁律「不许静默失败」**。
   同族已在文件里被点过名（`buildin_mesh` 那一大段注释就是同一个坑），**网格这一支漏了**。
3. **重跑链**：`gen_unity_arena_manifest.py --arena battlearenaastramilitarum` → `ArenaBuilder.BuildAll`
   →（按 `CLAUDE.md` §二）`BattleScene.BuildAndSaveScene`。OBJ 会自动补进 `Models/`。

   ⇒ **已被就地订正过**（铁律 5 已履行），**不需要再改**。
   ✅ 我独立复算过一遍（读 13 份 `<场>_groups.json`）：`nodes[]` 合计 **263**（最多 tauviorla 96、
   最少 emperorschildren 6）、`targets[]` 合计 **1164**、`adds[]` 合计 **0** —— **与那条注释逐数吻合**。

   「`nodes[]` 是「原版有、我们没建」的那批（含容器层）」——
