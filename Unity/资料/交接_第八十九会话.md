| 坑 | 一句话 |
|---|---|
| **「追加到类尾」= 那个类的尾部，不是文件尾部** | 多类型文件（`DeckEditorState.cs` 3 个类型 · `BattleContext.cs` 两段 `partial` 夹 `static class MatchTypes`）按文件尾追加 ⇒ 落进静态类 `CS0708` |
| **类闭合行号 ≠ 类尾可追加位置** | `BattleDriver` 闭合在 `:36699`，`:36700` 是 namespace（我这一轮给错过一次，已更正） |
| **`--only` 是前缀匹配** | 一律给完整文件名 |
| **合并工具「一行不合规 ⇒ 整份不写」，且看起来像什么都没发生** | `B89_RXb` 因此被静默挡掉一次 |
| **`check_ledger_points.py --root DIR` 不改「读哪份账」** | 账本路径硬编码 ⇒ 对副本跑闸做不到 |
| **无访问修饰符的私有字段 / `const` 常量行永远不能当 A 档落点** | `_MEMBER_MOD` 只认 public/private/protected/internal |
