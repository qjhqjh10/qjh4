### 1.3 ✅ 已实现的两个东西（第五轮做完，这里是**实际**的接口）

**(a) `WarpforgeEffectPlayer`** —— `Assets/WarpforgeVFX/Runtime/WarpforgeEffectPlayer.cs`

```csharp
namespace WarpforgeVFX
{
    public class WarpforgeEffectPlayer : MonoBehaviour
    {
        // 播一个特效。parent 传 null 就挂在场景根上。
        public static WarpforgeEffectPlayer Play(string effectName, Transform parent = null,
            Vector3 localPosition = default(Vector3), float scale = 1f,
            float autoDestroySeconds = -1f);          // <0 = 用效果库里记的原版时长
        public static WarpforgeEffectPlayer Play(WFEffectEntry entry, ...);   // 已经有 entry 时用这个
        public static WarpforgeEffectPlayer PlayFuzzy(string keyword, ...);   // 记不清全名时用

        public static int  ActiveCount { get; }       // 当前活着的实例数（测试靠它证「播→消失」）
        public static void KillAll();                 // 切场景/退牌局时兜底
        public event Action OnFinished;               // 播完时触发（销毁之前）

        public void Exit();                           // 停发射、进入收尾（对应原版 AnimFXController.Exit）
        public void Kill();                           // 立刻销毁
        public void Tick(float dt);                   // 外部驱动（批处理/白板）；autoTick=false 时用
        public bool autoTick = true;                  // 自己跟 Update 走；外部驱动时关掉
        public float ExpectedLifetime { get; }
    }
}
```

**位置/缩放语义（这里踩过坑，别改回去）**：`Play` 会把实例**归位到 parent 的原点**，
但**绝不碰根节点的旋转和缩放**。原因：原版有一批 prefab 把根节点停在**场外 x≈100** 的「后台位」
（`Atk_GrotGrenade` 在 99.59、`Attack_Stomp` 在 100），不归位就会播到场景外面；
而旋转/缩放是效果作者定的（`Antimatter Explosion` 根节点是 X=-90°，`Atk_GrotGrenade` 是 scale 0.5），
归零会把一批效果整体转 90°。`scale` 参数是**乘数**，乘在作者设定的缩放之上。

**生命周期规则**（从原版签名桩 + 2346 个组件的参数值反推，**未经反编译核实**，实拍一比就能验）：

| 参数 | 来源 | 行为 |
|---|---|---|
| `destroyTime` | 原版 `AnimFXController.destroyTime`（912 个效果有，中位 3.0s） | 到点自动走 `Exit()` |
| `exitDestroyTime` | 同名字段（956/990 是默认值 3.0） | `Exit()` 之后再活这么久才销毁 |
| `preventDestroy` | 同名字段（97 个实例是 1） | **不自动销毁**，由玩法代码在合适时机 `Exit()`/`Kill()` |
| 粒子自然时长 | 导出时算的（`duration + 最大寿命 + 延迟`） | `destroyTime` 缺失时（63 个效果）用它 |
| `SAFE_DESTROY_TIME = 3f` | 原版常量 | 上面两个都没有时的兜底 —— **保证没有永远不死的对象** |

> 想覆盖一切时用 `Play(..., autoDestroySeconds: 2f)` —— 连 `preventDestroy` 的也照收，
> 这是玩法代码防泄漏的抓手。

**(b) `WarpforgeEffectLibrary`** —— `Assets/WarpforgeVFX/Runtime/WarpforgeEffectLibrary.cs`

```csharp
WarpforgeEffectLibrary lib = WarpforgeEffectLibrary.Instance;   // 自动从 Resources 取
WFEffectEntry e;
if (lib.TryGet("Antimatter Explosion", out e)) { ... }
List<WFEffectEntry> hit = lib.Find("Explosion");                // 模糊找，按名字长度排序
```

- 资产在 `Assets/Resources/WarpforgeVFX/WarpforgeEffectLibrary.asset`（958 条）
- 每条带：`prefab` / `destroyTime` / `exitDestroyTime` / `preventDestroy` / `natural` / `loops`
  / `verdict`（台账判定）/ `confidence`（置信度）/ `ratio`（亮度比）
- **为什么用 ScriptableObject 而不是 `Resources.LoadAll`**：后者会把整个目录无条件全打进包
  （958 prefab + 1.8 GB 贴图）；SO 的引用列表是「被引用才进包」，而且编辑器与打包后行为一致
- 数据源：`数据/游戏数据/effect_index.json`（由 `工具/gen_effect_index.py` 从
  prefab 目录 + `animfx_components.json` + 还原台账 join 出来），再用
  `EffectLibraryBuilder` 补上 Unity 侧才算得出的 `natural`/`loops` 并生成资产

## 二、卡牌表现基座设计

> 原版只作**参考蓝本**：学它的结构、抄它的手感数值、照搬它的设计思路，
> 但最终的布局/交互/动效要自己设计。这一节给的是**建议方案**，不是原版复刻。

### 2.1 原版有哪些现成的、可以直接拿来当参考的

| 资产 | 在哪 | 能拿来干什么 |
|---|---|---|
| `Card Hand To Board` clip（0.92s） | 原版动画数据 | 「手牌落到战场」的**完整时序蓝图**，17 条曲线把时间点拍清了 |
| **74 个 `UnitTweenSO`** | ✅ 已同步：`d:/4/Unity/数据/游戏数据/tween/`（74 个 JSON） | ease / duration / delay / loops / punch 数值**整套可搬**，含具体类型名（`PunchTween` 等） |
| `DrawCard` / `TurnCardAround` | `d:/2/Warpforge_code/`（签名桩）+ Ghidra 反编译 | 原版是 DOTween 代码驱动，`DOScale` + `SetEase` 直接写在里面 |
| `CardHighlight` 5 色态 | 原版预制体 | 可打出/不可打出/选中/目标/悬停 的状态色 |
| `card_anim_map.json` / `atk_vfx_map.json` | `Unity/数据/游戏数据/` | 卡牌 → 特效映射（591 条定义 → 400 个预制品） |
| 34 个卡牌类 / 2024 个方法名 | `d:/2/Warpforge_tools/data/decomp_il2cpp_0827/` | 当**需求规格说明书**用 —— 它告诉你「原版考虑了哪些情况」 |

**取用原则**：数值照搬（手感是调出来的，重调浪费时间），结构和交互自己定（要避版权、也要贴合自己的玩法）。

### 2.4 数值从哪来

| 要调的 | 参考来源 |
|---|---|
| 发牌手感（缩放/位移/缓动） | `DrawCard` 的 `DOScale` + `SetEase`；74 个 `UnitTweenSO` 里的 `PunchTween`（`ease` 是 DOTween 的 Ease 枚举，`6` = InOutQuad 一类） |
| 手牌到战场（0.92s 的完整时序） | `Card Hand To Board` clip 的 17 条曲线 |
| 高亮过渡时长 | `CardHighlight` 的色态切换 |
| 落位吸附 | 原版没有独立数值，自己定（建议 0.15–0.2s，`Ease.OutBack`） |

> ⚠️ **不要照搬原版的整体布局坐标** —— 那是给 1920×1080 手机横屏调的。自己的游戏先定分辨率与安全区，
> 再按自己的比例重算扇形半径和间距，只把**缓动曲线和时长**搬过来。

### 2.5 和特效怎么接（✅ 已实现）

`atk_vfx_map.json` / `card_anim_map.json` 是**原版**现成的映射表，我们自研的卡查不到；
落地时改成 **事件 + 阵营 + 卡** 三级的 `VfxMap`，中间隔一层 `CardEffects` 钩子：

```csharp
// 卡牌只说「我登场了 / 我挨打了」，播哪个特效由 VfxMap 决定；钩子由游戏启动时接到 WarpforgeEffectPlayer.Play
CardEffects.FireEvent(evt, worldPos, faction, cardId);
```

这样特效和卡牌表现是**解耦**的 —— 换特效不用改卡牌代码，换卡牌布局不用碰特效。
