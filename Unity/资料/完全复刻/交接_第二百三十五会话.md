## 四、关键结论 / 判据（下会话直接用）

1. **catalog 不是「全是远端」**：84 本地 + 3 CCD；只改那 3 条（坑 595）。
2. **BinaryStorageBuffer 的数组长度前缀是字节数**；keys `/8`、location set `/4`（坑 596）。
3. **catalog 改本地后必须 crc 归零**：jar + 非零 CRC 是从未跑过的组合（坑 599）；`verify_catalog()` 会兜住。
4. **B1 后也不能从 JS 删 xform**：热更换整份 JS、不换 catalog，≤g 老包仍依赖（坑 600）。
   无硬依赖由**对照包**（`--without xform.js` 的 env5）证明。
5. **重装/换账号首次同步默认云端**：本地先备份（幂等）→ 静默应用 + 伪重启，不弹窗（坑 597）。
6. **gadget 版本不是冻结主因**：同负载 17.23.3 9/9 · 17.27.4 9/9；主导因素是启动期注入负载（坑 598）。
   选 17.27.4 是工程判断（Frida release notes），不是本轮 A/B 优胜。
7. 出包两个新判据：构建日志 `catalog.bin: ccd 3 -> 0 … crc 归零 3 条` 与断言 `catalog 本地化 = OK`。
8. **B2/B3 不要再去改资产**：`PlayFabSharedSettings.asset` 没有 URL 字段（属性不序列化；TitleId 是代码常量）；
   `PhotonServerSettings.asset` 的 HostType/ServerAddress 只在 `ConnectUsingSettings` 分支生效，游戏走
   `ConnectToRegion → ConnectToRegionMaster`（region 名字服务器）⇒ 改资产无效。长期方案 = 阶段 C 原生钩子。
9. **F1 判据**：`wf_bridge.log` 出现 `[SAVE-J]` 且时间早于 `wf.log` 的 `[MAIN] 阶段A`；
   哈希必须与 JS `filesHash` 逐字节一致（Java/Node 同为 `9ed70e54e8d669ce` 的自测样例）。
10. **安装**：Honor 安装器会拦 `pm install`（签名/安全/荣耀账号），先
   `settings put global package_verifier_enable 0` + `verifier_verify_adb_installs 0`（坑 602）。
