### OFF-181 细节（本会话最大一块）

- **根因**：别人电脑弹 `INTERNAL FAILURE! Failed to Download UnityDependencies!` —— MelonLoader 缺「生成好的
  Il2Cpp 程序集 / Unity 运行库」就会去 GitHub 下载，国内直连失败。上游 `LavaGang/MelonLoader.UnityDependencies`
  **有** `6000.2.6` release（不是 404）；包本身完整（`Config.cfg` 哈希与 `GameAssembly.dll` SHA-512 一致）。
- **自检为什么没拦住**：旧版只查 9 个文件，**没查** `Il2CppAssemblies`（157 / 116 MB）与 `UnityDependencies`（72 / 7 MB）。
- **做法**：
  1. 包根新增 `游戏运行依赖\`（**213 MB / 296 个文件**，镜像包根，可手动整目录覆盖）；
  2. 启动器 `TryInstallRuntimeDeps` + 自检「一键修复/安装依赖」：从依赖包**只补缺失/0 字节**；
  3. 自检/启动器新增「Il2Cpp 程序集 / Unity 运行库 / Config.cfg / 生成配置哈希」四行，**逐文件对账**（少一个 dll 也 FAIL）；
  4. 新增 **`诊断面板.bat` + `tools\diag_panel.ps1`**（WinForms）：版本/文件/依赖/进程/端口/日志摘要 + **导出问题文件**（桌面 zip）；
  5. 出包⛔ 不再用 `tar -a -c -f *.zip`（实测产出 TAR），改 **7-Zip / Compress-Archive**，出包后抽查首字节 `PK`；
  6. `prepack_check` S1 新增：依赖包两目录 + `Config.cfg` + `版本.txt` + 诊断面板。
- **验证**：包内 `WarpforgeSelfCheck --check` PASS（新 4 行全 OK）；模拟杀软删 1 程序集 dll + 1 Unity dll + `Config.cfg`
  → `--repair` 全部补回；`prepack_check --no-run` **PASS 32 / WARN 4 / FAIL 0**；诊断面板实机出图并导出 578 KB zip。
