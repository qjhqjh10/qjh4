## 三、关键实现（接手必看）

| 主题 | 落点 | 要点 |
|---|---|---|
| 回合闸 | `Pre_ResolveEndTurn` + `RetryResolveEndTurnCo` | **只用四个动作队列**判忙；`resolvingActionFlag` 本 build 恒 true，只打日志；补发前 `_gateForceUntil = now + 1 s` |
| 换手牌动画 | `HandSwapCo` | 等队列清空 → 旧手牌左飞 0.55 s → **1 s** → `SetupCardInHand`（引擎入手动画）→ **1 s** → `BeginSeatDeal`（抽卡）→ **1 s** → 天赋窗 |
| 动作节奏 | `AiSeatPlayCo` / `ExecuteAiAction` | `_animSeqUntil`：每个动作后 +3 s；动作前等门闸 |
| 天赋选择 | `TalentChoiceCo` | 全座位调度；电脑 `aiPick`（1 或 2 张，不弹窗）+ `_talentGateSeat` 门闸；本机弹窗标题写 `titleTextField` 的 TMP |
| 手牌显隐 | `EnforceLoadedHandsTick` | 每侧只显示 `_loadedSeat[side]` 的手牌；**当前座位自己被关掉的卡要补开**；隐藏前 `IsOnBoard` |
| 场上卡牌 | 同上（forceShow 段） | `unitsInPlay` 里 `activeSelf=false` 且不在播动画/特效 ⇒ 补开 |
| 告警 | `AlertTick` / `Alert` | 规则：`hand.dup / hand.gap / wing.dup / deploy.repeat / play.double / talent.timeout / turn.stall / units.hidden` → `alerts.tsv` |
| 换牌窗布局 | `FixMulliganFrames` | ① 帧按前两帧等差摆正 ② 按钮按第 0 帧偏移 + lossyScale 比例补偿 ③ 尝试 `ForceRebuildLayoutImmediate`（取 RectTransform 仍失败，已不依赖） |
| UI 导航 | `UiNavProbe` | 命令文件 `phase0/ui_cmd.txt`；`click 继续` 在战斗窗里要用 `clickoff 继续`（按钮初始 disabled） |
