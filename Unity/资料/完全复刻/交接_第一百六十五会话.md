## 四、本会话新增的坑（`已知的坑.md` 167–176）

- **167** `PhotonNetwork.CloseConnection`（op 254）在自建 Photon 上**不摘房间成员** ⇒ 房间一直「已满」；改「`kickTarget` 属性 → 客机 LeaveRoom」。
- **168** 刚进房 `PhotonNetwork.room` 可能瞬时 null ⇒ 「被移出」判定要**连续缺失 >2.5 s**。
- **169** IL2CPP `Type.GetProperty("Instance", Public|Static)` **取不到继承来的静态属性**（`SingletonBehaviour<T>`）；走基类链 + `TryCast`。
- **170** 克隆名片自带 Button（点它开练习窗）；屏 C 名片要先把 Selectable 关掉（只关 `enabled`）再盖点击区。
- **171** 克隆名片的 `GetWorldCorners` 恒 0、`rect/lossyScale` 互相打架 ⇒ 屏 C 头像点击区用**行高线性式**覆盖整张名片。
- **172** 同机双开两个客户端连同一个假服务端会共用玩家身份（IP 映射）⇒ A 内置 8765 + B 外部 `config_b` 8766。
- **173** `Button.interactable=false` 会把目标 Graphic 压成 Disabled 灰（头像变灰的真因）。
- **174** `cardSprite`（`SM_*` 1024²）在新建 Image 里**不渲染**；`fullHeroSprite`（`UI_Deck_Warlord_*` 2048²）可以 ⇒ 卡组图用大立绘。
- **175** 进房路径 `_roomDeck = null` 必须写在 `ResolveDeckForMatch` **之前**（否则客机卡组图/文字为空）。
- **176** `DeckInfoControls.Initialize` 是全局 postfix；「房间一次性的复用」要加窗口作用域标记 + `Close()` 清理。
