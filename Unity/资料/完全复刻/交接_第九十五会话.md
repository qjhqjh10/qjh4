## 六、用什么方式检查（**不要轻易全量自检**）

| 层 | 什么时候 | 命令 |
|---|---|---|
| **L0 秒级** | **每次改完 `.cs`** | `TMPDIR=/tmp/wf_<代号> bash d:/4/Unity/工具/typecheck.sh`（必须 **0/0**） |
| **L1 探针** | 改引擎行为 | `bash 工具/ruleprobe.sh check` / `play check`（⚠️ 重钉只在「无 `.cs` 写手」时由调度台串行做） |
| **L1·b** | **同步点必跑** | `bash 工具/ruleprobe.sh play all dump <tmp.tsv>` —— **`play check` 不跑那两条自检**（⑦ 付费前缀 / ⑧ 事件电池） |
| **L2 闸** | **同步点，且写手全停** | `check_ledger_points.py --all-A`（`--fix` **第一遍是修前快照**）· `check_patch_conflicts.py` |
| **L3 单宿主** | 只动一个宿主 | 只跑那一条 |
| **L4 全量** | 跨面 / 动共用件 / 准备提交 | `bash d:/4/Unity/工具/_run_8_checks.sh`（20 条 · 串行 · 约 9 分钟） |

⚠️ **判绿红看【断言合计】、不看退出码**；⛔ **别用 `grep -c '✗'` 数失败**（`✗` 会出现在 ✓ 的文案里）—— 按行首标记数。
⚠️ **`typecheck` 的编辑器程序集在运行时失败时根本不跑**（`CS0006`）⇒ 必须两段都绿才算 0/0。

## 八、🔴 本会话新发现的知识（**都是坑，别重踩**）

1. **「container 0 命中」≠「资产不存在」** —— `Gacha Crate Opening.mp4` 的 PathID **不在** `AssetBundle_1.json` 的 297 条 container 里，它是被 **prefab 的 `VideoPlayer.m_VideoClip` 直接 PPtr** 引用的。
2. **「数量吻合」≠「同一批」** —— 4 个 OverIcon GUID 与「图集外正好 4 张」数量 4=4 是**巧合**；四个 pathID 全在图集**内**，是阵营图。**必须逐 pathID 落位**。
3. **`m_Container → pathID` 判法不是万能的**（配合 §八·1）；**`--dry` 报「更新 N」≠「没合过」**（配合 §三·1）。
4. **基线可能比代码旧** —— 遇「指纹与基线不符」，**第一步查基线什么时候钉的**。本会话的基线钉在闸落地前 44 分钟。
5. **`[NonSerialized]` 字段落不了列** —— 判「某格该不该进卡表」前，先看 `Assembly-CSharp/` 的签名桩有没有 `[NonSerialized]`，再看 SO 的**内嵌 type tree** 到哪一格为止。
6. **同一个字段名可能指两个不同对象** —— `+0x90`：附魔卡的 `spellType` vs `CardEffect.secretBuff`。代码里要写死这条区分。
7. **虚槽定名的通用钥匙**：`FUN_1800021f0(idx,…)` 的 `idx` = `dump.cs` 的 `Slot:`；换算式 `(0x1xx − 0x138)/0x10`；**独立交叉验证法** = 找一个已知 Slot 的同签名方法比对（本会话用 `EqualityComparer<T>.Equals`(Slot 8) 验了 `LiveOpsEventData.get_Army`）。
8. **ILSpy/反编译的假象**：`.c` 首行名 ≠ 文件名 = 内容错位 **或** ICF 折叠；ILSpy **丢实参常量**（一整排 `default`）、**丢 `= true` 的写点**、**丢异步状态机体**。
9. **同一方法在两份 tsv 各记一遍** —— 本会话查出 322 组跨文件重复键（`泛型与启动链_补读.tsv` 是重灾区）；**合并器按「域 == 文件名」消歧 ⇒ 补读表那半边永远被消歧到主题表，用补丁改不动，只能人工对齐**。
10. **`Quaternion.Angle` / `==` / `!=` 在本机有 0.16206° 盲区**（`IsEqualUsingDot(dot) => dot > 0.999999f`）；全仓唯一量角器 = `CardPresentation/Core/AngleMath.cs`。
