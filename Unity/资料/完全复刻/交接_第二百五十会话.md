## 三、关键结论 / 判据

1. **坑 680**：PC 没有可用 `TMP_InputField` 模板 ⇒ 运行时自建（顺序：字段赋完再激活）。
2. **坑 681**：`Localize` / `EverguildTextController` 会把克隆字改回 ⇒ `Destroy`（`enabled=false` 走不通）。
3. **坑 682**：`UnityAction` 是 Il2Cpp 委托 ⇒ `Delegate.CreateDelegate` 静默失败，必须 `DelegateSupport.ConvertDelegate`。
4. **坑 683**：克隆 TMP 的 `RectTransform` 比摆放尺寸大 + `raycastTarget` 默认 true ⇒ 压住按钮吃掉点击。
   判据 = `EventSystem.RaycastAll`（本探针 `ray <x> <y>`）；修法 = 标签 `raycastTarget=false` + 命中面放父层。
5. **坑 684**：`SendInput` 四种模式都不出字符（ESC 能收到、原版输入框同样打不进）⇒ 用 `WM_CHAR`。
6. **坑 685**：窗口会把隐藏过的原版内容重新点亮 ⇒ `CanvasGroup.alpha=0` + 重隐 + LateUpdate。
7. PC「已登录」= `PlayerDataManager.playFabEmail` 非空（邮箱登录）；本地默认账号（青剑湖）视为游客、允许 LAN。
