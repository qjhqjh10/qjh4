## 三、关键结论 / 判据（新会话直接用）

1. **安卓 JS 别直接调 `Addressables.LoadAssetAsync`**（必 `abort was called`，坑 637）；
   用 `Everguild.Addressables.ComponentReference<T>(guid).Load()`，且 `.ctor` 必须先 `class.alloc()` 再在实例上调。
2. **frida 桥返回的字符串带双引号**（坑 638）：`get_name`/`targetId` 比较前先 `cleanStr()`。
3. **`RankingDisplay.Initialize` 的 Nullable 参数**（坑 639）：PC 必须传**有值**的 Nullable
   （`Activator.CreateInstance(Nullable<T>)` 装箱是 null；传 null 会 `Il2CppObjectBaseToPtrNotNull` NRE）；
   安卓用 `Il2Cpp.nullable(value, klass)`（`Il2Cpp.nullable(null)` 会抛「A class must be specified」）。
4. **关 LayoutGroup 后要显式给子件尺寸**（坑 640）：`Ranked Division Info` 的 `DivisionImage` 序列化高度是 0。
5. **事件级弹窗靠 `drawData.EventComponents[Popup=12]`**（坑 641）：缺了永远不弹；补完要同步 dist/data.js/WfOfflineData。
6. **升段弹窗只在「胜利越段」触发**；输局通常被保护成 `delta=0`，不要拿输局验弹窗。
7. `OFF-214` 两边默认关：PC `WF_OFFLINE_SKIRMISH_DIV=1`（默认只读）；安卓 `skirmishrank.js` 的 `S.off=true`。
