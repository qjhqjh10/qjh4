## 六、怎么复跑

```bash
# 单开 2v2（含 AI 座位）
taskkill //IM Warpforge.exe //F
cd E:/warpforge/game
export WF_OFFLINE_CLIENT_PROFILE=a WF_PROBE_OUT=E:/warpforge/07_产物/<名>/a
export WF_GAME_VERSION=1.1 WF_4V2=1
export WF_OFFLINE_PHOTON_REDIRECT=1 WF_OFFLINE_PHOTON_REDIRECT_ALL=1
cmd //c start "" Warpforge.exe -screen-fullscreen 0 -screen-width 1250 -screen-height 700
# 在线对战 → 创建房间 → 下一页 → 2v2 → 入座 → 增加电脑 ×3 → 开始游戏
# 要 AI 弃牌：按 F11 扫卡组 → 点电脑头像 →「选择卡组」→ 挑 over4 大的
```

- ⚠️ 双开布局：`game` + `game_b`；B 用 `WF_OFFLINE_CLIENT_PROFILE=b` + `WF_OFFLINE_NO_REMOTE=1` + 8766 外部服务端（坑 172/187）。

- ⚠️ 投降：`key esc` → 点「放弃」。门动画约 8.8 s，之后**点一下屏幕**才回主菜单。
