1. **卡点**：`OnUnityAuth` 返回的 token 过不了 `Unity.Services.Authentication` 校验：
   - 已对上字段表（`Unity.Services.Authentication.AccessToken`，安卓 dump TypeDefIndex **19337**）：
     `aud`/`scp` 是 `string[]`、`ext` 是对象（`AccessTokenExtraClaims`）、`exp`/`iat`/`nbf` 是整数；
   - 报错演进：`Empty or null access token` → `Error converting value "offline"`（aud 应为数组）
     → `Value cannot be null`（claim 缺）→ **`The configured environment(production) and the access token one(null) don't match`**（当前）；
   - 已试 claim 名：`env` / `ext.env` / `environmentName` / `environment_id` / `environmentId` / `environment_name`（都返回 null）；
   - **新会话建议**：① 用 Frida hook `Unity.Services.Authentication` 里做校验的方法（dump 搜 `AccessToken`/`JwtDecoder`），
     直接把「token 解析结果」看下来；② 或 hook `AuthenticationService` 的失败点让它沿用本地身份；
     ③ 元数据里出现过的字面量：`environmentName` / `environmentId` / `UnityEnvironment` / `com.unity.services.core.environment-name`。
2. 若主菜单仍被挡：备选 = 不跳过教程（教程路线已验证可玩），或走「盖世游戏跑 PC 版」（已验可玩）。

   ⚠️ 想快速迭代就装 `out/*.listen.apk`（config.listen）走 `run_on_phone.py` 热加载。
