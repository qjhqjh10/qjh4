## 二 「一次替换」的两个前置问题 —— **两个都是否**

### Q1 · `LiveOpsLocalCatalog` 有没有覆盖 `blockedEvents` / `shared`？—— ❌ **两个都没有**

先纠正一处口径：**`LiveOpsLocalCatalog` 是我们自己的类**（`Shell/LiveOpsLocalCatalog.cs`，1083 行），原版**没有**这个类（全量 ilspy `find -iname "*LocalCatalog*"` = **0 命中**）。所以问题应读成「我们这个离线目录能不能顶替原版 handler 的那两件事」。

原版那两件事的判据（🥇 ilspy）：
- **`blockedEvents`**：`ILiveOpsHandler.cs:37-39,71` `GetBaseEvents(bool includeBlockedEvents=false)` / `GetBlockedEvents()` /
  `Task SetupEvents(List<ILiveOps> events, **List<ILiveOps> blockedEvents**, JObject sharedData)`；
  实现里是**两个字段**（`LiveOpsHandler.cs:933` / `:1325` 各一份 `blockedEvents`）。
  ⇒ 语义 = **服务端把某些事件「屏蔽」了**：它们**仍在列表里**（可被列出/调试），但**不可开**、`GetEvents()` 默认不返回。
  消费点：`DebugEventTogglerWindow.cs:291,294,318`（调试窗列出全部含 blocked）· `IRankedEvent.cs:197` / `ShopOfferAssetProvider.cs:43`（`includeBlockedEvents: true` 取全量）。
- **`shared`**：同一个 `SetupEvents` 的第三个参数 `JObject sharedData` —— **跨事件共享的一份 JSON**，每个事件从它里面读公共配置（不是各自 SO 里带）。
- **我们这边**：`LiveOpsLocalCatalog` 只做三件事（文件头逐条写着）：① `eventId → Event_Description 键` ② `eventId → 日期` ③ `eventId → 图片`；
  选「当前活动」的判据 = `now ∈ [startDate,endDate)` ∧ `enabled` ∧ `uploadToLive`，**多个在期取 `startDate` 最晚的那个**。
  ⛔ **没有「屏蔽」这个概念**（只有 `enabled=0` 的 SO 被排除，那不等于 blocked）· ⛔ **没有「共享数据块」**（13 份 SO 各带一份，没有公共层）。
- ⇒ **结论：两个都没覆盖。** 真要换真 LiveOps 层，`blockedEvents` 与 `shared` 是**必须新补的两件**（不是配置问题，是**语义缺一层**）。
  ⚠️ 而且注意：**`blocked` 与「过期」不是一回事** —— 过期是时间维、blocked 是运营维；我们现在只有前者。
