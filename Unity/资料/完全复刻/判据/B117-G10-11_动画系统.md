## 一、重点 1：`CardAnimOrder` —— 同一拍里多个动画的先后，原版靠什么定

**答：靠一个【FIFO 的自动动作队列】，不是 tween 序、也不是「同时插入」。**

判据链（逐句读过）：

| 跳 | 出处 | 读到的内容 |
|---|---|---|
| ① 一拍一条 | `decomp_full/AbilityLogic__PlayAnim.c:51-58,180-200` | 外层 `foreach` 走 `this + 0x18`（= `AbilityLogic.cardAnimations`），**按列表序**逐条处理；每个目标调一次 `BattleManager.AddCardAnim(...)` |
| ② 队列 | `decomp_full/BattleManager__AddCardAnim.c:20-27,88-96` | 造一个 `BattleAction`（`BattleAction..ctor(…, 0xb, …)` ⇒ **kind = 0xb = cardAnim**），末尾 `AddAutoActionToQueue(mgr, action, delay)` ⇒ **入队** |
| ③ 一条一条播 | `decomp_full/BattleManager._ResolveAnim_d__466__MoveNext.c` state 0→1→5 | 出队后：起 `DelayedVFXPlay` → 震屏 / `UnitShake` / `UnitTweenSO` → **`WaitForSeconds(GetAnimDuration())`** → `FinishResolvingAction`（才走下一拍） |
| ④ 「要不要等」 | 同上 `:196-207`（`local_res8[0] = AnimInfo.GetAnimDuration(...)` 那一段，闸是 `param_1 + 0xc0`） | 只有 `waitAnimToApplyEffect` 为真才等；为假 ⇒ **当场 Finish**，下一拍在同一时刻起 |
| ⑤ 多目标 | `AbilityLogic__PlayAnim.c:214-222` | `i == targets.Count-1 ? waitAnimToApplyEffect : false` ⇒ **同一拍的 N 个目标同时起，只有最后一个带 wait** |

⇒ **我们这一侧（`BattleDriver.ExpandAbilityBeats`）已经是这个形状**：`acc` 只在这一拍 `Waits` 时累加；
多目标拍全部落在同一 `at`；`beatTail` 保证事件级副作用只响一次。**✅ 无差异。**

⚠️ 一个**已如实标注**的近似（不重复立账）：原版「0 个目标 ⇒ `LogError` + **整段 return**」，
我们 `break`（后面的拍也不排，但因为我们的目标粒度更粗，见 `ExpandAbilityBeats` 的 doc）——
那一支 2026-10-28 已按「整段 return」改过（`B90_B2`）。

## 二、重点 2：`FlyingCardController` —— 抽牌 / 弃牌 / 回手的飞行曲线

### 2·a 先纠正一件事：`FlyingCardController` **不是**抽牌/弃牌/回手那条链

它管的是 **`flying` 关键词单位的「抬到空中 + 上下浮动」**（`DefinedTrait.flying` 徽标驱动），
判据 = `BattleCardDisplayStatusAnim` 的 `ToggleFlying`。抽牌/弃牌/回手是另外三条：

| 链 | 原版方法 | 位移缓动 | 时长 | 我们 |
|---|---|---|---|---|
| 抽牌 | `CardScript__DrawCard.c:63-80` | `DOScale` 与 `DOMove` 都是 `SetEase(0xc)` = **OutQuart**；`DORotate(zero)` **无 SetEase** ⇒ 默认 OutQuad（**只有敌方走**）；我方走 `TurnCardAround`（Linear×2 段） | `VarsGlobal.TimeToDrawCard(isPlayer)`：我方 **0.3** / 敌方 **0.15** | `CardFeel.DealInPose / DealIn / DealInQuad`，**缓动写的是 `OutCubic`** ⇒ 🔴 **差一档**（见 §四 A2） |
| 弃牌 | `CardScript__MoveToDeck.c:83-85` | `DOMove` `SetEase(6)` = **OutQuad** | 调用方给的时长 | `CardFeel.ShowCardBeingDrawn` 一族 |
| 回手 | `CardScript__MoveBackToHand.c`（37 行） / `__ReturnToDeckAnim.c`（22 行，只是协程 kickoff） | **没有 tween** —— 走 `UpdateMinionInHandPosition` 那一套（`DOMove` 世界 / `DOLocalRotate` 局部 / `DOScale`，全 OutQuad） | `VarsGlobal.timeToPositionCard` = **0.2** | `HandLayout.Place` → `CardView.TweenPose(…, CardTween.RelayoutDuration=0.2, OutQuad)` ✅ |

## 四、重点 3：`PopNumber` —— 飘字的位移与淡出

### 4·a 位移：**原版没有位移**

判据 = `AnimationClip_-3234148433819516763.json`（`InBattleDamageCounter Variation 1`）：
`m_PositionCurves` = **0 条**、`m_RotationCurves` = 0 条。它只动两个量：
`m_ScaleCurves`（根 `0.6641 @0 → 1.0 @0.2`；`DamageIcon` `0.5763 @0.1167 → 0.7 @0.2`）与
`m_FloatCurves`（`DamageText.m_fontColor.a` `0 @0 → 1 @0.1167`，保持到 `1.6667`，`→ 0 @1.8333`；
`DamageIcon` 的 α `0 → 0.8235 @0.1167`；另几条 `m_IsActive`/`m_Enabled` 开关）。

⇒ **不位移、不上浮**（原版 `DamageCounter` 是 `3DBody` 的子件，位置固定在 `(0, 1.708, 0)`）。
我们 `PopNumber.Pop` 也只有 α + 缩放 —— **✅ 这一半是对的**。

### 4·b 缓动：**原版是「零切线 Hermite」= 平滑阶跃，不是线性/OutQuad**（🔴 已修）

| 段 | clip 关键帧的切线（现读） | 原版曲线形状 | 我们改前 | 改后 |
|---|---|---|---|---|
| `DamageText` α 入 `0 → 1 @[0, 0.1167]` | 两端 **0.0 / 0.0** | `3t²−2t³`（t=0.25 处 **0.15625**） | `Ease.Linear`（0.25） | `CardFeel.ClipSmoothStep`（零切线 Hermite） |
| `DamageText` α 出 `1 → 0 @[1.6667, 1.8333]` | 两端 **0.0 / 0.0** | 同上 | `Ease.Linear` | `CardFeel.ClipSmoothStep` |
| 根 `ScaleCurves` `0.6641 → 1 @[0, 0.2]` | 两端 **0.0 / 0.0** | 同上 | `Ease.OutQuad` | `CardFeel.ClipSmoothStep` |
| `DamageIcon` α `0 → 0.8235 @[0, 0.1167]` | 两端 **0.0 / 0.0** | 同上 | `Ease.Linear` | `CardFeel.ClipSmoothStep` |
| `DamageIcon` `ScaleCurves` `0.5763 → 0.7 @[0.1167, 0.2]` | 首端 **0.0628**、末端 **0.0** | 近平滑阶跃（首端略带头速） | `Ease.OutQuad` | `IconScaleRamp`（首端归一化切线 0.0423） |

修法（`Battle/PopNumber.cs`）：两条归一化 `AnimationCurve` 喂给 `SetEase` ——
求值语义（Unity Hermite）与原版**同一套**，⛔ 没自己手写一份「差不多的」缓动函数。
序列自己的 ease 仍是 `Linear`（否则会覆盖子补间的 ease）。

> 时间轴**没动**：`0.1167 进 / 0.2 缩完 / 停到 1.6667 / 1.8333 消失`，整条 **1.8333 s**（`BattleScene.cs:23241` 那条断言仍绿）。

### 4·c 治疗飘字（对照，不改）

`CardScript._Heal_d__468__MoveNext.c:155-205`：先 `localScale = one × 0.05`（`0x1834b2f94` 实读 0.05），
再 `DOScale(one, 0.7)`（`0x1834b3188`）`SetEase(6 = OutQuad)` `SetLoops(2, Yoyo)` ⇒ 1.4 s，
之后 `WaitForSeconds(1.5)`（`0x1834b3090`）才关。我们 `CardView.ShowHeal` 四个值全对 ✅。
