## 四、顺手发现

1. 🔴🔴 **`B111_T2B` §④·2 的「26 条连 shader 都没有 ⇒ 必须新写 shader + Unity 编译验证」只在「我们没有重建 shader」这层成立。**

   ⇒ 这 25 条**不该按「要 Unity 编译 shader」判卡点**；真正卡的是「哪张材质挂哪个窗」的 UI 线排期。
   （复算命令：`python -I -X utf8` + UnityPy 遍历 `*.bundle`，读 `Shader.m_ParsedForm.m_Name`。）
2. 🔴 **`MENU_UI_EQUIV` 的等价判据是「原版材质名 → 我们材质名」1:1 表，会漏掉「同一 shader 的第二个原版材质」。**
   实证 = `Shader Graphs_Division Change`：它和 `Rank Change` **同一个 shader、同一个消费节点**（`Division Image`），`B110_M1`（2026-10-31）已经把等价材质做完、接完线、写完断言（`Editor/B110_M1_MenuMat_Assert.cs:150-160`）—— **但 `res_audit` 今天仍把它算成「真缺」**。
