## §1 `EnemyHeroDamageScorer` 的「创新低才算」

### 1·1 原版判据（实读）

| 项 | 原文 | 出处 |
|---|---|---|
| 计数公式 | `num = initialized ? (lowestHealth − evt.CurrentHealth) : evt.DeltaHealth;` → `if (num > 0) { lowestHealth = evt.CurrentHealth; initialized = true; OnScore.Invoke(num); }` | `decomp_full/EnemyHeroDamageScorer__OnHealthChange.c:11-23` · ILSpy `EnemyHeroDamageScorer.cs:18-27` |
| 字段偏移 | `+0x28 = lowestHealth` · `+0x2c = initialized` · 信号 `+0x10 = CurrentHealth` / `+0x14 = DeltaHealth` | 同上 `.c:12/13/16/19` |
| 信号源 | `DeltaHealth = lastEnemyHealth − CurrentHealth`（**只在值变了才发**）；`lastEnemyHealth` 初值 = 0（Obscured 默认） ⇒ **开局第一个信号 delta 恒负、被忽略** | `BattleEventsController.cs:48-70`（`CheckHealth`，`Update():43` 每帧） |

**结论 ①：是「只在创新低时计数」，不是每次伤害都计。**
**结论 ②（类别注记，重要）：它是【评分器】不是【挑战消费者】。**
`EnemyHeroDamageScorer : BattleScorer`（`BattleScorer.cs:4-6`：`public readonly UnityEvent<int> OnScore`）⇒ 这一格喂的是**战后评分**。
原版挑战变量 `ChallengeVariable.damageDealtToEnemyWarlord = 40`（`ChallengeVariable.cs:7`）走**服务端** `ChallengeVarResult`
（`ChallengeVarResult.cs:68-90`：`ChallengeValueUsed` = `Cumulative(0)` / `HighestValue(10)` / `LowestValue(20)`，**由挑战配置决定取哪一格**），
`SetChallengeResults/UpdateChallengeResults` 本地 0 调用者（`B88_R5` §二·2·1 已三源核）。
⇒ **挑战那一格本地没有原版判据**；拿评分器口径当挑战口径 = 唯一可对齐的本地物，但**必须在账里写明这是借来的口径**。

### 1·4 可粘贴改法（唯一插入点 = `BattleDriver.UpdateHud`）

```csharp

else if (foeHpNow != _foeSkullHpSeen)
```
