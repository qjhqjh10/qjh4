## §一 方法（可复现）

### 1.1 扫的是什么

对 `判据/*.md` 的**每一行**做三类提取：

| 类 | 正则（简写） | 说明 |
|---|---|---|
| **命名 `.c`** | `([A-Za-z0-9_.<>]*)__([A-Za-z0-9_]+)\.c` | `.c` 的命名是 `类名__方法名.c`，类名部分可含 `.`（嵌套类）与 `<>`（泛型） |
| **裸 `.c`** | `[A-Za-z0-9_./-]+\.c`（不含 `__`） | 如 `AddEffect.c`、`get_CurrentCost.c` —— 判据里大量用**方法名简写** |
| **其它路径** | `…\.(cs\|json\|prefab\|assets\|asset\|tsv\|txt\|py\|md\|bundle)` | 含缩写前缀 `DEC/` `ILSPY/` `ASSETS/` `BUNDLE/` `OUR/`（各文件头有定义） |

### 1.2 怎么判「存在」

- **命名 `.c`** → 直接查 `D:/2/tools/decomp_full/<名字>`（**精确**）。
- **裸 `.c`** → 在 `decomp_full` 的全部 `.c` 里找 **后缀匹配**（`EntityScript__get_CurrentCost.c`.endswith(`CurrentCost.c`) = 真）⇒ 只有这样才不会把合法的「方法名简写」全判成断链。
- **其它路径** → 先按缩写前缀拼出绝对路径查 `os.path.exists`，再用**全盘 basename 索引**（`decomp_full` 25,096 + `out_cpp2il_dev_ilspy` **递归** 2,398 + `assets_full` 247k + 真束 + `Warpforge_code` 桩 + `D:/4/Unity`）兜底。
  ⚠️ **`out_cpp2il_dev_ilspy` 必须递归**（它按**程序集/命名空间**分目录，如 `Everguild.LiveOps/`）；第一版我用了 `listdir` ⇒ 把 `Everguild.LiveOps/DraftEventBase.cs` 这类**全判成缺失（假阳性 96 条）**。
- **运行期路径**（`persistentDataPath/WarpforgeDecks.json` 等）单列，**不计入缺陷**（本地本就不该有）：共 **37 条**（`存档体系` 28 · `日常与活动` 6 · `Tap` 3）。

### 1.3 复现（下个会话可直接跑）

```bash
cd D:/4/Unity/资料/完全复刻/判据
# 命名 .c 的存在性（最快的一条）
python -I -X utf8 - <<'PY'
import os,re,glob
DEC="D:/2/tools/decomp_full"; dec=set(os.listdir(DEC))
pat=re.compile(r"([A-Za-z0-9_.<>]*)__([A-Za-z0-9_]+)\.c\b")
for f in sorted(glob.glob("*.md")):
    for i,l in enumerate(open(f,encoding="utf-8",errors="replace"),1):
        for c,m in pat.findall(l):
            n=c+"__"+m+".c"
            if n not in dec: print(f,i,n)
PY
```
