## 0. 一句话结论

攻击链的核心状态位**只有 3 个**，全在 `BattleManager.<ResolveAttack>d__438` 一个协程里：
`+0x138 defenderReturnsDamage` / `+0x139 defenderKilledByShuriken` / `+0x13A attackerKilledBySentry`。
原版把 `+0x138/+0x139` **两条 bool 合写成一个 u16**（`.c:616` 写 `1`、`.c:632` 写 `0x100`）；
我们**已经拆成两个独立 bool**（`B145-E25`），另外两例（`HIT0 +0x35`、`SENTRY +0x13A`）也已落地/反向拆。
**本轮新发现 2 条「未做成可轮询位」的近似**（`+0x351` · `+0x30`，见 §4 B/C，**待证可观测行为**）
**+ 1 条休眠位**（`+0x34 doItFast`，§4-D 已核「6/6 调用点传 false ⇒ 当前不可达 ⇒ 行为等价」）。

## 4. 本轮复核结论：2 条已核等价 + 2 条待证近似

**A. `defenderReturnsDamage(+0x138)` 是等价重构，未发现行为偏差（本轮已核清，非新缺口）。**
原版在 `.c:616` 先置 1，随后在 `:921/935/949/968` 的四条**特殊打法**分支持清 0：
`:968` = `HasCurrentTrait(0x14 = sneakAttack)` · `:949` = `ActivatesTerror` ·
`:935` = `ActivatesNoReturnSniperAttack` · `:921` = `ActivatesNoReturnLongRangeAttack`
（名字取自 `out_il2csharp/BattleManager.cs:33101-33147`）。这四条 = `CounterAttack.NoCounter` 的四通道。
**次序核**：`.c:866` 先跑主伤害 `ResolveAttackDamage(攻方→守方)`，`:871-968` 才判这四支，`:1114` 才读 `+0x138` 决定反击 ——
我们在 `RuleCore.cs:7333` 求值 `NoCounter` 也正好在**主伤害（`:7196`）之后、反击之前**，**时机一致**。
⇒ 差异只在于「原版落成一个持久位、我们现算」，**未找到可观测行为差异**。
（⚠️ 本轮初稿曾误写「原版在主伤害之前算」，现据 `.c:866-968` 现读订正。）

**B. `wholeDamageAnimFlag(+0x351)` 我们没有可轮询位。**
原版是**真位**：`R:312` 置 1 → 受击方协程 `R:340-346` 等 1.0 s → `R:366` 清 0；而
`M:1155` 以 0.2 s 一拍**轮询**它，清 0 才放行下一步。我们折成「`DurationOf(EvtKind.Hit)` 固定 1.0 s」。

- 可观测差异：**今天为零** —— 6/6 调用点都传 `doItFast=false`（§4-D）。若将来出现 fast 档，原版会**提前放行**、我们会多等 1.0 s（**未来风险，当前不可达**）。

**C. `shouldShowOffensive(+0x30)` 只有表现层等价物。**
原版在 `_ApplyOffensiveAndDefensiveEffects` 的协程里把「本阵营空进攻卡 state ≠ 当前环境 state」存成位，
后续两处读它决定是否 `DisplayRevealedCard`。我们的判断在 `BattleDriver` 的进攻卡链路里现算。

- 可观测差异：**待证**（若两处读取之间环境 state 变化，原版用**旧值**，我们用**新值**）。

**D. `doItFast(+0x34)` 我们没有建模，但当前不可达 ⇒ 行为等价。**
原版 `R:296/:340` 两处读它决定「要不要等那 1.0 s」。**本轮把 6 个调用点逐个现读**
（`grep -rn "CardScript__ReceiveDamage(" d:/2/tools/decomp_full`）：6/6 传 `doItFast=0`
（签名只有 3 参 `ReceiveDamage(UnitDeathType, DamageInfo, bool doItFast = false)`，`dump.cs:36415`；
`.c` 里的尾两位 `,0,0` 是 Ghidra 给无原型函数补的 artifact，真第 3 参 = 0）
⇒ **生产路径上 `doItFast` 恒 false**，我们的固定 1.0 s 今天**行为等价**，该位只是原版留下的休眠开关。
