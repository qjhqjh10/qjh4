## 3. 顺手发现（不在两条的施工单内，但都要记账）

### 3·1 🔴 glitch 材质的 `_Noise` 原版绑的是 **`ScanLines`**，不是 `Noise Combined`

**判据**（原版材质 `Card Frame Glitch` = `assets_full/bundle_duplicateassetisolation_assets_all/Material/Material_-2877403367212247079.json`）：

```json
["_Noise", {"m_Texture": {"m_FileID": 0, "m_PathID": 1565928461195782613}, "m_Scale": {"x":1,"y":1}, "m_Offset": {"x":0,"y":0}}]
```
- `m_FileID = 0`（**同包内**引用）· `m_PathID = 1565928461195782613`
- 该 pid 在 `bundle_duplicateassetisolation_assets_all` 里 = **`ScanLines`**（UnityPy 直读：
  **128×128** · `m_TextureFormat 25` · `m_ColorSpace 1`(sRGB) · `m_MipCount 8` · **`m_WrapU/V/W = 0/0/0`**）；
  资源账同一条 → `资料/完全复刻/资源/R0_资源覆盖账.tsv:83260`
  （`bundle_duplicateassetisolation_assets_all.bundle  1565928461195782613  Texture2D  ScanLines`）。
- 全库**只有一份**叫 `Card Frame Glitch` 的材质（`grep` 所有 `bundle_*/Material/*.json`），不存在「另一份绑 Noise Combined」。
- 我们工程里那张 `WarpforgeVFX/Textures/ScanLines.png` 与导出件**逐像素相同**（PIL 逐通道 maxdiff = 0），
  但它在 `WarpforgeVFX/Textures/`，**不在任何 `Resources/` 下 ⇒ 运行期取不到**。

**我们现在的做法**：`CardView.cs:14365` 绑的是 `CardArt.CardbackSdfNoise()`（= `Noise Combined`），
`CardArt.cs:933`、`CardView.cs:14251-14253` 的注释也写「`_Noise` = `Noise Combined`」，
`WarpforgeVFX/Editor/CardGlitchProbe.cs:81` / `:122` 还把这条错口径**钉成了断言**
（`Check(now.GetTexture("_Noise") == noise, …)`）—— **自检绿 ≠ 口径对**。

**处置建议**（不在本条白名单内，交调度台派活）：
1. 把 `ScanLines.png` 复制进 `Resources/Art/`（或 `CardArt` 加一条专用读口），**`.meta` 照原版：Repeat / sRGB / 开 mip**（现有那份正好是 `wrapU/V/W 0/0/0 · sRGBTexture 1 · enableMipMap 1`，直接搬 meta 即可）；
2. `CardView.cs:14365` 换成它；`CardArt.cs:933` / `CardView.cs:14251-14253` 就地订正文本（**零行数变化**）；
3. `CardGlitchProbe.cs:81` / `:122` 两条断言改成断 `ScanLines`（否则会把错口径继续钉死）。

### 3·2 `ui_menu/Noise_Combined.png` 除 wrap 外还有两处与原版不符

原版 `Noise Combined`：**线性（`m_ColorSpace = 0`）+ RGBA32 未压缩（fmt 4，64 KB）**；
我们这张：**sRGB（`sRGBTexture: 1`）+ CompressedHQ（BC7）**。
- 本工程是 **Linear**（`ProjectSettings/ProjectSettings.asset:50 m_ActiveColorSpace: 1`），
  原版是 **Gamma**（导出工程的 `ProjectSettings.asset:56 m_ActiveColorSpace: 0`；与
  `工具/import_original_card_sdf.py` 开头那节「原版 Gamma 按原始字节采样」同一口径）。
- 在线性工程里 `sRGBTexture: 1` 会**多一次 sRGB→linear 解码**，而原版这张本身就是「按原始值采样」⇒ **值会偏**。
  这正是 `VoiceWaveMaterial.cs:30` 早就写下的那句警告（「⛔ 别挂 `ui_menu/Noise_Combined.png`：那张是 sRGB」）——
  但 `RewardWindow`（#7）与 `WFUI_DivisionChange`（#8）**正在用它**。
- 压缩档：原版 RGBA32 未压缩；BC7 会改动噪声值（`_Noise` 在 #7/#8 里直接参与颜色/位移计算）。

⇒ 改法见施工单「改动 3」（同一个 `.meta` 一次改完：wrap + sRGB + 压缩档），三处一并解决。
