## 一 · 扫描器说明

### 1·1 关键事实：本仓是 **Allman 花括号**

实测 `if (cond) { … }` 同行多行块 **0 处**（`DeckScene.cs` 66 处同行 `if` 全部单行闭合）。
⇒ 「3A-b 块级 guard」与「3A-brace」是**同一种形状**（`if (cond)` + 下一行的 `{` + 块），
**唯一区别 = 块内 `Check` 条数**：`≥2` ⇒ 3A-b；`==1` ⇒ 3A-brace。

### 1·2 判定规则

1. 读法复用 `b105r3/scan.py`：`io.open(p,'rb')` 二进制读 → 按 `\n` 切 → 剥尾部 `\r`；
   再走它那套 `CODE/LINE/BLOCK/STR/VSTR/CHR` 六态状态机（注释与字符串抹成空格、列号不变）。
2. **条件提取**：`if (...)` 用**配平括号**取内部条件（⛔ 不用非贪婪正则，否则 `QuadRectPx(… out a …)` 会被截断）。
3. **块定位**：`{` 与 `if` 同行 ⇒ 块从该行起；`{` 在下一非空行 ⇒ 块从 `{` 那行起；
   块尾 = 花括号平衡回到 `if` 之前那一级的行。**单行闭合块不计**（没有跨行）。
4. **断言计数**：块内 `[if 行 .. 块尾]` 区间里 `Check` 族（`Check`/`CheckTrue`/`CheckNear`/`MenuCheck`/`NodeCheck`/`AssertTrue` … 共 30+ 名）调用次数。
5. **三类「已覆盖」（任一条命中就不计入余量）**：
   - **pre-tag**：前 1–8 行出现字面量 `（前提`；
   - **semantic**：前 1–8 行出现**同一变量**的 `X != null` 断言（如 `CheckTrue(hq != null, "…")` 没打 `（前提` 字样，但语义已覆盖）；
   - **else-guard**：`if` 语句之后（16 行内）有 `else` 分支且其中 `Check(false,…)` / `CheckTrue(false,…)` / 文案含 `（前提` ⇒ 条件假时**报红而非静默**。
6. **单语句 3A**（余量表）额外要求：`)` 之后本行无其它语句，或本行就是 `if (cond) Check(...)`；
   若 `)` 后同一行跟着一条**非 Check** 语句（如 `if (extra != null) over.CardIds.Add(...)`）⇒ **不算守卫断言**（这是本轮修掉的一个假阳性）。
