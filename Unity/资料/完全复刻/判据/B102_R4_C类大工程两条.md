4. 🔴 **原版比分条是整数除法（原版自己的 bug）**：`int num7 = num6 / num2; float num8 = 1f - (float)num7;`（`TwoSidesEvent_OnGoingTab.cs:213-216`）⇒ `scores[1]=1, total=2` 得 **0.5**，不是 0.5（浮点也是 0.5）—— 但 `scores[1]=1, total=3` 得 `1-0=1.0`（浮点应是 0.667）。**照抄，⛔ 别“修正”成浮点**（铁律 18·0）。
5. **`b__0` 的 state 公式在 ILSpy 里被打散成位运算**（`:37-55`），`decomp_full` 的 C 版是干净的 `(param_3 < *(int*)(param_1+0x14)) + 1`（`:24-32`）⇒ **判据取 C 版**，与 `ParentEventWindow.MilestoneState:2070` 已落地的一致。
6. **`OnOpen` 开头那条 `Method not found @1804B33B0`（= 全局空桩）** 说明 `base.OnOpen()`（`WindowTabBase.OnOpen`）本身是空的 ⇒ 我们**不需要**补一个基类调用。
7. **`RewardProgressBarPanel.Initialize` 的 `resourceIcon` / `resourceName` 两个实参原版都传 `null`**（`InitializeMilestones.c:45` 末两个 `0`）—— 我们 `:2047` 已照传 `null, null`，这条**不是缺口**。
