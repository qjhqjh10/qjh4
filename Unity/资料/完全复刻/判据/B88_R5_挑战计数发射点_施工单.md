### 裁定 2 🔴 「数」不在 `ChallengeLogMgr` 里 —— 在 **24 个 `MissionChallenge` 子类**里

`TroopKilled` / `Damage` / `Attack` / `BattleEnd` / `AddCardEffect`），喂 **10 个消费者**。

### 4·1 引擎侧：补两格 + 一格（**这是唯一需要新加的计数**）

#### ① 击杀部队数 —— `AchievementTally.AddTroopKilled(int killerSeat)`

- **写点**：`d:/4/Unity/MyGame/Assets/RuleEngine/Core/RuleCore.cs:6239`
  （`TryCreditKillCore` 的 `return true;` **之前**一行）。那里手上正好有 `killer` / `kOwner` / `victimP` / `victim`。
- **插入一句**（概念）：
  ```csharp

  ```
- **新成员**（追加在 `AchievementTally` **类尾**，`:274` 之后）：
  ```csharp
  public readonly int[] TroopsKilled = new int[2];
  public void AddTroopKilled(int killerSeat) { if (SeatOk(killerSeat)) TroopsKilled[killerSeat]++; }
  public int TroopsKilledOf(int seat) { return SeatOk(seat) ? TroopsKilled[seat] : 0; }
  ```
- 🔴 **为什么不是 `MinionDeathBookkeepingDeferred`**（`RuleCore.cs:10287` 起）：那里**没有凶手**（形参 `killer:int` 已被降级成「只作 `PendingDeath.Killer` 诊断留痕」，见 `RuleCore.cs:9732` 与 `:8977-8980`）。
