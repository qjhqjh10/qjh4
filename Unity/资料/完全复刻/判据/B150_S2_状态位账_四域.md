## 一 · 口径

| 项 | 值 |
|---|---|
| 什么叫「合并位」 | 编译器把**两个相邻 bool 字段**合成一次 `*(undefined2 *)(p + 0xNN) = 0x…` 存（例：`= 0x100` ⇒ 低字节清 0、高字节置 1）。只映射成**一个** C# `bool` ⇒ 另一半语义**静默丢失** |
| 怎么找 | ① 全库 grep `*(undefined2 *)(… + 0x…)`（276 命中）→ ② 剔掉第三方库（I2.Loc / TextMeshPro / Photon / PlayFab / UnityEngine.UI）→ **游戏逻辑 14 处** |
| 怎么定名 | `d:/2/tools/il2cpp_out/dump.cs` 按类体 + `// 0xNN` 偏移反查（脚本见 §五） |
| 怎么判我们这边 | 现读 `RuleEngine/Core` + `CardPresentation/Battle`，逐组给「独立字段 / 等价式 / 无」 |

**覆盖边界**（⛔ 别把「这张表」当「全部状态位」）：
- 只覆盖**相邻 bool 被合并成一次宽存**这一类；**单字节单字段**的写法（`*(undefined1*)(p+0xNN) = 1`）不在本表内（那是普通字段，不会丢语义）。
- 只扫 `decomp_full`。**无方法体的 724 条 / 泛型具体化**不在覆盖内（见 `CLAUDE.md` §17 四类未覆盖面）。
- 判定用的是 `.c` 伪码；`.c` 会吞实参常量、丢返回值 ⇒ 凡结论依赖「实参是不是全 default」的，本表**不采信 `.c`**（本表没有这种依赖）。
