### GB-1 · UM64 `Angels of Death` **不该点目标** —— 是解析把 Codex 那一句做成了「必需选一个」

- **判据结论：** 原版出牌**不**要目标，两处独立判据。
  1. **出牌闸**：`d:/2/tools/decomp_full/BattleManager__CanPlayCard.c` 在费用判完之后那一段 ——
     `SupportMethods__IsSpellType(cardType)` 为假 **或** `EntityScript__get_targeted(card)` 为假 ⇒ **直接 `return 1`**，
     **根本不进**「遍历棋盘找合法法术目标」那个循环。

  2. **结算目标集**：`AbilityLogic__GetTargets.c:972-987` 的 `targetsAffected == 10`（`0xa`）那一支 = 调

     · UM64 的 Codex 那条 logic：`abilityTargetCriteria[2]` = `ab 2 · trigger 410`，

     · ⇒ 卡面 `Give +1 [Ranged] to your Primaris Intercessor` 在原版 = 给**你场上全部**的原铸仲裁者 +1 远程，**不是挑一个**。

  - **「具名卡目标 = 全体」有 2/2 实证**：全池只有两张卡的己方目标被解析成**卡名筛**（基线 `工具/ruleprobe/基线/out_baseline.txt` 全扫）——
    `SAU52 Self-Destruction`（`all friendly canoptek scarabs`，已是 `Count=0`）与 `UM64`；
    两张在原版 SO 里都是 `targetsAffected = 10 (allFiltered)` + `filterSpecificCards` 单卡。

### GB-2 · `ASH15` 的「部署语音」是**按名猜的兜底行**，原版对这张卡**没有任何可用语音** ⇒ 应当**不播**

- **判据结论：orphan（无 SO 归属）· 原版这一刻不播 · 原版连语音钮都不建。**
  1. **卡 SO 的音频字段全空**（`资料/普查产出_1018/allcards_1350/cards_raw.json` 的 `ASH15 / full_raw` 亲读）：

     返回 0 ⇒ `UnityEngine_Object__op_Equality` 为真 ⇒ **直接跳出口，什么都不播**（气泡也不发）。
     我们**已经**是对的：`BattleDriver.cs:7566` 那句 `if (e.Kind == EvtKind.Deploy && clip == null) return;`。
  3. **语音钮**（原版 `voiceOverButton`）：`CardDisplayWindow__SetCardVoiceOver.c` 取
     `RawCardScript__GetAvailableSounds()`，其实现（`RawCardScript__GetAvailableSounds.c`）把 **`+0x188`(defaultChatSound) ·

  4. **我们唯一的偏差就在这一步**：`VoiceLines.Has()` 判的是「这张卡在 `voice_lines.json` 里有没有行」，
     而 `TryPick` 的 `soOnly`（`VoiceLines.cs:733`）在**没有任何 SO 归属行**时**放行所有行**
     ⇒ ASH15 那条 `src` 为空的行会被取到。
  5. **全表规模（关键）**：`voice_lines.json` 现读 **642 张卡 / 1,897 行**，其中**只有 `ASH15` 一张**

     那条行本身：`{ ev: deploy, file: "VO_CW_SaimHann_Howling Banshee - Shriek.ogg", text: "Shriek" }`，**无 `src`、无 `so`**
     （= 二级来源 `card_index.json`），全表**仅此一处**引用这个 clip。
  6. **「原版别处会不会播」= 没有**：这条 clip 的真身在 `aeldarisaimhanncardassets_assets_all.bundle` 的
     `AudioClip/`（`Unity/数据/索引/anim_address_map.json` 有地址），但**没有任何卡 SO 引用它**；
     原版五个语音出口（`GetSummonSound` / `GetAttackSound` / `GetDeathSound` / `GetChatSound` / `GetAvailableSounds`）
     对 ASH15 全部返回空。⇒ **不是「找错归属」，是「这条 clip 原版没用在这张卡上」**。

- **我们要改：`Unity/MyGame/Assets/CardPresentation/Core/VoiceLines.cs:147` 的 `Has()`** ——
  从「表里有这张卡」改成「**这张卡至少有一条 SO 归属行**」：
  ```csharp
  public static bool Has(string cardId)
  {
      EnsureLoaded();
      if (cardId == null || _byId == null) return false;
      Card c; if (!_byId.TryGetValue(cardId, out c) || c.lines == null) return false;
      for (int i = 0; i < c.lines.Count; i++) if (IsSoAttributed(c.lines[i])) return true;
  ```

  （`IsSoAttributed` 已在 `VoiceLines.cs:760`，判据 = `so` 非空 或 `src == "cardSO"`，与 `TryPick` 的 `soOnly`（`:733`）同一份。）
  覆盖到的调用点（都不用另改，它们都经由 `Has`）：
  `CardButtons.HasVoice`（`Core/CardButtons.cs:32-33`，注释里本就写着「原版判据 = `GetAvailableSounds().Count > 0`」）·
  `CardDisplayWindow.cs:1205`（试听前那句）· `CardDetailPopup.cs:2701`。
  **⛔ 不要改 `voice_lines.json`**：那条行 `src` 留空是生成器 `工具/import_original_audio.py` 的**正确标法**
  （空 = 二级来源 `card_index.json`，「orphan」= 按名猜）；把它改标 `orphan` **不改变任何行为**
  （`IsSoAttributed` 对两者都返 false），只会让来源记录失真。

- **今天的行为**：战斗里 ASH15 登场**不响**（已符合原版）；但**卡片详情窗 / 放大窗的语音钮会显示**，

- **还差什么**：无阻塞项。⚠️ 唯一提醒：改 `Has` 之后 `Editor/BattleScene.cs:15383 / 21931 / 22317` 三条断言里用 `Has`

### GB-3 · 拖拽跟手的两档硬吸附阈值 = **dist² < 0.01 / > 1000**，速度 = **10.8**，平滑**不 clamp**

- **判据结论（全部是二进制读过 + 指令流核对，不是推的）**：
  - 方法：`CardScript.SetCardMovement`，`d:/2/tools/il2cpp_out/dump.cs:36159-36160` `RVA 0x5FC4E0 / VA 0x1805FC4E0`。
  - **目标**：`targetPoint.z := BattleManager.get_CanvasZPosition() − 10`
    （`DAT_1834b2da8` = **10.0**，4B float；`CardScript__SetCardMovement.c` 那一句 `*(float *)(param_2 + 1) = fVar5 - DAT_1834b2da8`）。
  - **距离**：`d2 = (target.x−cur.x)² + (target.y−cur.y)² + (target.z−cur.z)²`（三个 `subss`+`mulss`+`addss` 连加）。
  - **两档硬吸附**（**比的是距离平方**）：
    ```
    if (0.01f > d2)  ||  (d2 > 1000f)   ⇒ transform.position = target;   // 硬吸附
    ```
    · `DAT_1834b2dbc` = **0.01**（`read_literal.py` 4B float）· `DAT_1834b3124` = **1000**（4B float）。
    · 指令流复核：`1805FC5C2 movss xmm0,[0x1834B2DBC]` → `1805FC5CA comiss xmm0,xmm3` → `1805FC5CD ja <snap>`；
      `1805FC5D3 comiss xmm3,[0x1834B3124]` → `1805FC5DA ja <snap>`。
    · 换成直线距离：**< 0.1 世界单位**（≈10.8 px）或 **> 31.62 世界单位**（≈3,415 px）⇒ 瞬移吸附。
  - **硬吸附那一支还做一件配套事**：把 `rotationTarget`（`+0x2FC/0x300/0x304`）整块拷成一个**静态 Vector3**
    （`1805FC7A6..1805FC7BC`）。那个静态量的身份**没有落地核**（它在 il2cpp 的运行时静态区、文件里读不到），
    ctor 里 `targetPosDuringAnim` 用的是**同一个**静态量 ⇒ **按「它与 ctor 同源」推断为 `Vector3.zero`**（= **倾斜归零**，
    只剩 `forcedExtraRotation`）。⚠️ 若后续要 100% 钉死，需要运行时探针读那个静态度；本批不改这条的结论强度。
  - **平滑那一支**：`pos += (target − pos) × (cardMovementSpeed × deltaTime)`，
    **没有 `Clamp01`**（`1805FC619 movss xmm6,[rbx+0x2E8]` → `1805FC628 mulss xmm0,xmm6`(=dt) → 三个分量各自 `mulss`+`addss`）。
    **`cardMovementSpeed`（`+0x2E8`）= 10.8** —— 两个独立来源一致：
    · ctor 默认值 `CardScript__.ctor.c`：`*(float*)(param_1 + 0x2e8) = 0x412ccccd` = **10.8**；
    · 预制体 `d:/2/tools/assetripper_out/ExportedProject/Assets/CardPrefab.prefab:2855` = `cardMovementSpeed: 10.8`。
  - **倾斜那一支的常量**（我们已对齐，此处仅存档）：`movingRotationReduction(+0x308)` = 10（ctor `0x41200000`）·
    `maxCardRotation(+0x2EC/0x2F0)` = 20 · `minCardRotation(+0x2F4/0x2F8)` = −20 · clamp 的 `+0.5` = `0.5` · clamp 上界 = `1.0` ·
    清符号位用 `xorps [0x1834B2C80]`（= `0x80000000` 掩码）· 最后 `×0.0174533`（= π/180）再 `Internal_FromEulerRad`。
  - 60fps（dt=1/60）下的跟手系数：**原版 0.18**；我们今天的 `1−exp(−20·dt)` = **0.2834**（更快、而且曲线形态不同）。

- **我们要改：`Unity/MyGame/Assets/CardPresentation/Hand/CardInteraction.cs:987-988`**（`UpdateDrag` 里那两行；紧邻的倾斜那一段是 `:1005-1009`）——
  ```csharp
  var prevPos = t.position;
  var d2 = (target - prevPos).sqrMagnitude;
  if (d2 < 0.01f || d2 > 1000f)                 // 判据 CardScript__SetCardMovement.c + VA 0x1805FC5C2/0x1805FC5D3
      t.position = target;                       // 硬吸附（原版同时把 rotationTarget 归零 ⇒ 下面的倾斜写 0）
  else
      t.position = prevPos + (target - prevPos) * (10.8f * dt);   // ⚠️ 原版【不 clamp】；Vector3.Lerp 会 clamp，别用它
  ```
  并把紧跟着的倾斜那一段（`:1005-1009`）在**硬吸附那一档**写成 `rx = ry = 0`（原版 `rotationTarget = Vector3.zero`），
  `z` 仍保留 `localEulerAngles.z`（这是我们 2D 卡的既有等价处理，🔶 已在原注释里标过）。
  **单位不用换算**：我们的手牌世界单位同样是 **108 px / 单位**（`Hand/HandLayout.cs:96 / :457`）⇒ 原版阈值直接可用。

- **今天的行为**：拖牌时跟手**偏快**（60fps 0.283 vs 原版 0.18），而且**速度曲线形状不同**（我们是 `1−e^(−20·dt)`、
  原版是 `10.8·dt` 的线性档 ⇒ 30fps 下 0.36 vs 我们 0.487，两档帧率之间的差异幅度对不上）；
  远处重排/瞬移（例如换位、大跳）会**平滑飞过去**，原版会**直接瞬移**（`d2 > 1000`）；近距离收尾（`d2 < 0.01`）
  原版直接贴住，我们会残留一点点指数尾。

- **还差什么**：**没有**（三个数都取到了）。两条附注：
  1. 原版目标 z 是 `CanvasZPosition − 10`，我们用的是 `dragLiftZ = 0.6`（`CardInteraction.cs:40`）—— 两者**基准不同**
     （原版那个 10 是相对它自己的 Canvas z），**未查清是否该改**，本批 ⛔ 不动。
  2. 反汇编里 `movingRotationReduction`（`+0x308`）是 `divss`，值为 10；若哪天把它当 0 用会除零 —— 只是提醒，
     我们现有常量 `DragTiltReduction = 10f`（`CardInteraction.cs:2175`）已经对。
