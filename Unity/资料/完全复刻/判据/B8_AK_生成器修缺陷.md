## 一 4 处各改了什么（判据注释都写在代码里）

### 1. 轮抽被硬编码成「暂停」→ 改成按账真实状态（`gen_feature_index.py:154-161`）

```python
('轮抽模式', '主链', '轮抽', r'.*'),     # 原：('轮抽模式', '暂停', '轮抽', r'.*')
```

- **判据①（用户口径 2026-10-25 原话）**：「卡池拖拽 · 轮抽模式。**可以做**，轮抽模式都已经做了一些了」。
- **判据②（仍然有效的窄口径 2026-10-24）**：「轮抽**不做奖励**」—— 管的是【奖励】，⛔ 不是【模式】。
- **改前后果（实测）**：轮抽域 A102 · B28 · **C11** · D58，整域被标 `暂停` ⇒ **11 条 C 从工作队列里消失**。
- **kind 为什么取 `主链`**：该域 C 行里有 1 条 `P0`（`DraftModeSelectPacksStateDemo.UpdateDeckInfoPanelAnimSync`）
  ⇒ 账推 = 主链，取 `主链` 才不会在 §4.1 里造出一条假的「我判边角 / 账推主链」冲突。
- 原 `RESUME['轮抽模式']`（状态机 Pay → SelectPacks → WarlordSelection → Ongoing → Reward）**没删** ——
  它不是暂停线了，但那条推进顺序仍然有用，改成行尾备注 `⏭ 推进顺序：…`（`main()` 里那一段）。

### 2. 功能点名带 markdown `**`（`:317-320` 改字面量 + `:383/:419/:500` 加通用清洗）

- 字面量：`排位赛与遭遇战模式（**未暂停**）` → `排位赛与遭遇战模式（未暂停）`。
- **根因不是那一个名字，是没人管名字**：新增 `_NAME_BAD_CHARS = ('**', '`', '|', '\n', '\r')` + `_clean_name()`，
  并且**在 `main()` 建分组 key 时就清洗**（`:500`），不只是打印时清洗 —— 否则「按功能点名 join」仍会用脏名。
- `--dry` 断言：**含这些字符的功能点名 = 0**（原来那条 `**未暂停**` 会让整行表格从该单元起被截断）。

### 3. 6 行同名「编译器生成类型」→ 同行业名 + 域后缀 + ⏭ 不进验收（`:373-381` / `:427-429` / `:553-556` / `:535`）

- `SKIP_NODES = {'编译器生成类型（无玩家语义）'}`；`display_name(fn, dom)` 给它们补 `· <域>` ⇒ **6 行不再同名**。
- §1 备注写明 `⏭ **不参与验收**（编译器生成的闭包 / lambda / 匿名类型…）`；
  并且**不进 §4 的两版对照表**（`:551-553`，它们不是功能点，进去只是噪声）。
- 名字口径选的是「同名 + 域后缀」而不是「并成 1 行」：并成 1 行会让 324 条账行跨 6 个域挤在一个功能点里，
  「方法数 / 状态分布」就没有意义了；留 6 行 + 明确「不计验收」既保账完整又能被程序跳过。

### 4. 36 个玩家可见窗口没有独立功能点 → 补 `CLASS_RULES`（`:241-310` 新增块 + 7 行「并进」改动）

**规模（我自己数的，别抄死）**：兜底桶里「类名以 `Window|Popup|PopUp|Panel|Tab|Menu` 结尾」的 = **44 类 / 156 行**
