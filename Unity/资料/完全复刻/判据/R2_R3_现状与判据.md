### 1.7 判据：怎么判「一个网格坏没坏」（复述 + 本会话确认）

1. **不能只看 `Object.Instantiate` 的结果** —— 流式网格拷出来是**未初始化内存**（`资料/已知的坑.md:2737`，实测 `±1.3e38 / inf`）。
2. **判据只能三选一**：① 从 `GraphicsBuffer` **读回顶点**再比极值（`|值| > 100` 或 NaN/Inf = 还是垃圾）；② **单独渲一张**看；③ 拿 OBJ 的 `v ` 行数**对数量**（本会话用的就是 ③）。
3. 🔴 **包围盒不算判据** —— `m_LocalAABB` 是元数据，顶点坏了它照样对得上。
4. 读流式网格本身的三条坑（`资料/已知的坑.md:3613`）：
   `ChannelInfo.dimension` **只有低 4 位是维度**（法线通道存的是 `0x34`）；bundle 内层文件的 `read()` **是消耗式**的（必须 `Position = off` 重读）；`m_StreamData.offset` **相对 `.resS` 起点**（别再加 `BaseOffset`）。

## 五、顺手发现（本会话新查到的）

1. 🔴 **`Recorded` 不是孤儿 —— 它是 Leviathan 地堡门的 Timeline 轨道**。
   `bundle_battlesharedresources_assets_all` 里有 `GameObject/Bunker Door Parent.json`（`m_IsActive: true`），组件 `[Transform, PlayableDirector 7845524703085758649]`；
   该 director 指向 `MonoBehaviour/546939151656983859`（`Leviathan Bunker Door Animation`，5 条 track），bindings 里 track `983775116529081651` 绑到 GO `-4873928100598937415`，而 `Recorded` 正是这条 track 上的 clip。
   director 参数：`m_Enabled: 1` · `m_InitialState: 1`（= Playing）· `m_WrapMode: 1`（Loop）· `m_InitialTime: 15.0` · `m_DirectorUpdateMode: 1`。
   ⇒ **原版这扇门是会动的**。`工具/extract_missing_shaders.py:587` 那段注释写「**原版 0 消费者**（13 场里没有任何 `Animation.m_Animation` 指着它）」—— **只查了 Animation 组件、没查 Timeline 组件**，所以结论对「Animation 路」成立、对「整体」不成立。
   我们的 `battlearena2`/`leviathan` 清单里 `Bunker Door Parent/Bunker_door/Cube` 是**静态网格**，没有 PlayableDirector（`battlearenaleviathan_manifest.json` 的 key 只有 `scene/camera/light/ambient/defaultEnv/postFx/meshes/particles/tapHits`）。

2. **`R2_重建网格/` 的 26 个 OBJ 是「尺子」，不是「出货」** —— 全仓 `.cs/.py/.json` **0 引用**。真正出货走的是 `EffectExporter.DeepCopyMesh`（→ `WarpforgeVFX/Meshes/`）与 `ArenaBuilder` 的 OBJ 导入（→ `arenas/<场>/Models/`）。

3. **没有任何运行时网格读回** —— `GetVertexBuffer` 只在两个 `Editor` 文件里。

4. **`WarpforgeVFX/Animations/` 里有 3 条与 `CardPresentation/Resources/Animations/` 重复**（`Division Up` / `Rank Up` / `Level Up Card`），真正被 `Resources.Load` 取的是后者；前者是无人引用的重复导出件。

5. **`R3` 表里有重名**：`Battle Arena Emperors Children Camera Intro` 两条（EC pid 19 / spacewolves pid 14）—— 印证 `CameraIntro.cs` 头注「⛔ 绝不按 `m_Name` 找 clip」。
