### 3·4 🔴 接线前必须知道的一个副作用（**不是可选项**）

## §4 服务端边界（铁律 18·0）

- **J2 `0x372` / J11 `0x45e` 是 CloudScript（服务端）**：奖励**清单由服务端给**（`CollectedCampaignRewardsResult.rewards`），客户端只负责「把回包里的每一条塞进背包」。
- ⇒ 🔶 **唯一的自设计点** = 「服务端返回哪几条」这一格，本地等价物 = `CampaignData.RewardsOf(i, tier)`（生成器从 `Campaign Node Data*.json` 的 `Rewards[]` 按 `rewardTier` 过滤，= 原版 `CampaignRewardsWindow.Open` 那个谓词）。**发奖本身（J5-J8）是纯客户端代码，必须照原版做——本次施工单就是补它。**
- 其余服务端件（`GetOwnedCount` 的服务器存档、`CardTierConfig`）不重造：拥有数在本工程 = 本地背包 + `CardProgress`。

## §5 还差什么（本件没做 / 没查清）

1. **`RewardService.Collect` 编排层仍没建**：本施工单只在调用点补了「发奖循环」。账 `日常_奖励:676` 把 `Collect` 收敛成 `DailyData.ShowCollectedWindow` 并判 A —— 那一条描述的是**开窗**那一半，**发奖那一半不在里面** ⇒ 该账行要么补锚、要么改判（`CollectRewardsSignal` 广播 / `grantedXp` 求和 / 开窗用 `onClose` 而非 `onCollect`，三样都还缺）。
2. **货币奖励（`C2`）仍不会发放**：生产里**没有登记 `Inventory<ICurrency>`**，货币正本是 `Shell/DailyData.cs:3087 Wallet`（用户口径「资源固定 2000」）。接线后这些 id 只会 `Note("rs-item:unresolved")`（**出声、不静默**，但也不发）。要不要把货币接到 `Wallet`，按 §18·0 属「非服务器」⇒ 应复刻原版 `CollectCurrencyReward`，但要先决定「`Wallet` 是否就是 `Inventory<Currency>` 的落地」——**本件不判**。
3. **其余奖励类型同样不发放**（同一批，不归本件）：`UM_SK_Starter` = `PrebuiltDeck`（账 `日常_奖励:678` 判 D，理由「全解锁 + 预组全可用」）；`Booster Pack …` = `ShopContainer`（开包链在 `BoosterPackOpenWindow`）；`WildcardUltramarines1..3` 的数量正本是 `CardProgress.Wildcards`；3 条 32 位 hex = **avatar / title 类 cosmetic**（`643ee10a…` 在 `Ultramarines_Deck7_Letharius2.json` 里是 `deckTitle.targetId`；另两条在 `Resources/profile_cosmetics.json` 命中）。⇒ **发奖链完整复刻需要逐类型各立一条**。
4. **新卡角标（J10）口径今天会翻转**：`NewCardBadgeOn` 读 `CardProgress.Owned`，而 `Owned` 在「给足」兜底与「背包播种」两态下分别给 `≥10` 与 `0`；播种又是**懒的**（只有 `CollectionWindow.CardsState` 首次访问时播）⇒ **同一次会话里「先开收藏窗 / 先开领奖窗」会得到相反结果**。这是播种口径（全解锁）与「首张卡」语义的冲突，**不是本件能定的**。
5. **收藏窗不会自己刷新**：`CardInventory.CollectionUpdated`（`Shell/Inventory.cs:1344`）全仓**零订阅者** ⇒ 已打开着的收藏窗在领奖后不会更新（重开会重读）。原版靠 `CardCollectionUpdatedSignal` 驱动 `CardCollectionDisplay.OnCollectionUpdate`。
6. **`CollectSingleReward` ③ 的 Currency 判型我们用的是「id 在 `Inventory<ICurrency>` 里查得到」**（`Shell/Inventory.cs:2079`）—— 原版是 `reward.Item is Currency`（**类型**）。因为 1 里没有货币背包，这一支今天恒不命中；接线货币时同一条要重核。
7. **未查清**：`CollectDeckReward`（`RewardService__CollectDeckReward.c`）我们没读透（账 678 判 D）——若口径改成「复刻原版」，它也要一并核（`UM_SK_Starter` 正是这条路）。
