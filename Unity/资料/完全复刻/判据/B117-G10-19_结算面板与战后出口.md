## 三、当场修了什么（判据明确）

### 1. `AllRewardsHolder` 的 `CanvasGroup` + 1.0 s 淡入（0.15 s 后开始）

* 判据：P2 `CanvasGroup &3578`（`m_GameObject: 583` = `AllRewardsHolder`，`m_Alpha 1`）；P4 `ShowRewards.c:192-195`
  `DOFade(allRewardsGroup, 0, v, 0).From().SetDelay(w, …)`；P6 实读 `v = 0x1834b2bb8 = **1.0f**`、
  `w = 0x1834b2bbc = **0.15f**`（**与 `SetupDoor` 加在片长上的是同一个常量**）。
* `DOFade(…, 0, …).From()` 的语义 = **从 0 补到当前值** ⇒ 原版就是「淡入」。
* 落点：`EndPanel` 类尾新增 `EnsureRewardsGroup` / `BeginRewardsFade` / `TickRewardsFade` / `ResetRewardsFade`
  + 常量 `RewardsFadeSeconds = 1f`（延时直接用 `BattleDoors.CommonAnimationScaleTime`，**⛔ 不另立一个 0.15**）。
* 泵：`EndPanel.Advance(dt)`（真机由 `BattleDriver.AdvanceTimeline` 推、批处理由 `BattleScene.Step` 推 —— 与
  `TickLoadingFade` 同一条泵）。**批处理没有帧循环** ⇒ 照 `BattleDriver` 的同级做法**直接落最终值**（α=1），
  这样 `EndPanelProbe` 的四张骷髅图与既有断言**一个字节都不变**。

### 2. `AllRewardsHolder` 自身的显隐

* 判据：P4 `ShowRewards.c:30-52`（`skulls==0 && 奖励空 && EarnedRating==0` ⇒ 整块藏）。
* 落点：`Show` 末尾 `ApplyPanelVisibility()`（新方法在类尾）—— 条件是
  `ShownSkulls > 0 || 奖励条数 > 0 || 评分 != 0`。

### 3. 补齐 `HolderRating` 那一棵（4 颗：`HolderRating` / `Trophy` / `ArmyIcon` / `RatingText`）

* 几何/贴图/字号全部照 P2 的 RT 与组件字段逐值抄（`RatingW/H`、`TrophyW/H`、`ArmyIconW/H`、`RatingTextW/H`、
  `TrophyX`、`RatingTextX`、`ArmyIconX`、`RatingFsMin/Max/Base` 这一串常量就是那张表）。
* 两颗子件的 x 不是拍的：`HolderRating` 的 `HorizontalLayoutGroup`（`MB 4922`：spacing 0 · MiddleCenter ·
  ChildControl 0 · ForceExpandHeight 1）+ uGUI「**只有 surplusSpace > 0 才按 alignment 挪起点**」
  ⇒ `pos = (186.9742 − (60.0588 + 65.302)) / 2 = 30.8067`
  ⇒ `Trophy = 30.8067 + 30.0294 − 93.4871 = **−32.651**`、`RatingText = 30.8067 + 60.0588 + 32.651 − 93.4871 = **+30.029**`。
  `ArmyIcon` 的序列化 `ap.x = 92.478745` 换算到中心锚 = `60.0588 + 64.8399/2 − 93.4871 = **−1.0084**`
  —— 那正是「三颗全开、内容溢出（`pos = 0`）」那一档，**它也是 `HolderRating` 溢出态的现场证据**。
