### 3·3 灭自证（若写/改断言，给「两边一起改回去就变红」的反例）

1. **`IsInPlay` 不含待死**：`Check(u.IsInPlayStateOf(waitingToDie) == false)` **且** `Check(slot 命中 && IsPendingDeath ⇒ !IsUnitInPlay)`。反例：如果有人把 `IsInPlayStateOf` 改成含 5、**同时**把 `IsUnitInPlay` 的 `IsInPlayState` 调用删掉，两条断言会**一起绿**——所以必须**同时**断「槽位命中但待死 ⇒ false」和「槽位未命中但 IsInPlayState 为真（手牌单位）⇒ false」两条，改任一侧都会红一条。
2. **`CanAttackNow` 的 `pindown` 收窄**（`B145-E2`）：断 `FieldAttack(...) <= 0 ⇒ ErrNoMeleeAttack` 之外，再加一条 `pindown 但远程 > 0 ⇒ 近战 ErrNoMeleeAttack、绿光 CanActNow 仍真`。反例：把 `pindown` 加回本函数会让第二条红。
3. **`ActivateBloodThirst` 四闸**：四条各写一条反例（trait 缺 / 计数≠1 / 不是本方回合 / 待死），任何一条被删掉对应断言必红；再加一条「计数=2（嗜血第二刀之后）⇒ 不再亮」挡「只要带嗜血就亮」的退化写法。
