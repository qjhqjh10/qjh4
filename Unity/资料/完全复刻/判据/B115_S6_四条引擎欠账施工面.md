## 二 `ENG-18` · `chooseone` / `X or Y` 的"分支层"

### 1 判据（原版怎么做的，两套机制，别混）

#### ① `Choose one: A; B or C`（卡面明写 `choose`）—— 是**选卡**，不是选文本

- 数据位（本笔现读 `cards_engine.json`）：`choicesTargetsAffected = 180` · `choicesMaxTargets = N` · `choicesSpecificCardIds = [...]`。
- 原版消费：`decomp_full/BattleManager__GetChoiceFullPool.c:28-49` —— `targetsAffected == 180` 且 `filterSpecificCards` 非空 ⇒ **候选池 = 这些卡 SO**（不走 `manager+0x308` 那套）；
  `BattleManager__GetChoiceOptions.c:40-101` 从池里抽 `min(池, maxTargets)` 张、玩家挑一张、`SortByCostAndName`。
- **选项卡本身带结构化 ability**（本笔核 `cards_truth.json`，例 `Craftworld Convergence` 的 3 张选项卡）：
  ```json
  {"chosenAbility": 60, "playersAffected": 10,
   "targetCriteria": {"targetsAffected": 10, "friendlyUnits": 1, "includeHero": 1, "includeMinions": 1},
   "manaBuff": {"manaAmount": 2, "friendlyPlayer": 1, "createMana": 1, "spiritStoneMana": 1}}
  ```
- **主卡自己的 ability 行**（`cards_truth.json`，`cards_engine.json` 里 `abilities: null`）：
  `chosenAbility = 360`（= 选牌结果）+ `targetCriteria {targetsAffected 180, selectFromChooseResolution 1}`。

⇒ 原版的"分支层" = **选项卡 SO 上的 `chosenAbility` 行**，玩家选的是**卡**，结算的是**那张卡的 ability 行**。

**6 张 `Choose one:` 战术卡全是这个形状**（本笔现扫，`cards_engine.json`）：`ASH71 Craftworld Convergence`(3) · `DA46 The Rock`(3) · `Duelist's Hubris 6ed51d…`(2) · `Inscrutable Cunning d01a5b…`(3) · `Hymn of Battle 4d348c…`(3) · `SW48 The Fang`(3)。

#### ② `X or Y`（卡面**没有** `choose`）—— 是**同一 ability 的多条 logic 行 + 随机挑一行**

- 判据：`decomp_full/RawCardScript__ResolveAbilities.c` 全文 47 行：
  ```
  :16-30  if (param_6 != 0 /* randomAbilityResolved */ && list.Count > 1) {
              uVar1 = GetRandomInt(mgr, 0, list.Count);
              PlayAbility(list[uVar1], ...);   // 只跑那一条
              return; }
  :31-43  // 否则逐条全跑
  ```
  （ILSpy 同体 `out_cpp2il_dev_ilspy/RawCardScript.cs:2029-2050`，但把 `param_6` 渲染成了 `if (obj != null)` —— **又一处 ILSpy 丢实参**，以 `.c` 为准。）
- 数据实证（本笔扫 `cards_truth.json`）：`ASH39 Deadly Ambush` = **一条 ability、两条 logic 行**：
  `lg0 {chosenAbility:30 buffOthers, targetCriteria:{ta:90, friendlyUnits:1}, buff:{buffType:3, trait:460}}`（给 Flank）·
  `lg1 {chosenAbility:130 stun, targetCriteria:{ta:90, enemyUnits:1}}`。
- ⚠️ **随机消耗 = 1 次 `GetRandomInt(0, n)`** —— 与我们今天 `DoChooseOne` 的 `RandomPick` 分支**消耗次数相同**（`EffectResolver.cs:4666`），这对"改完指纹别乱"很重要。
- ⚠️ **`ResolveAbilities` 的调用点三源都查不到**（`decomp_full` / `out_cpp2il_dev_ilspy` / `out_il2csharp` 都只有定义）⇒ 见 §八「查不到」。
