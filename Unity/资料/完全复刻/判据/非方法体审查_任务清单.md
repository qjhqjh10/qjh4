## AUD01 · 序列化视觉参数

- **目标**：找出「prefab 里有非默认缩放/旋转/透明度/出厂关闭、而我们没照做」的件。
- **数据源**：`D:/2/新解包资源/assets_full/bundle_menus_assets_all/`（`RectTransform/` · `Image/` · `Text/` …，**组件目录名先 `ls` 现读**）。
- **四类参数**：`m_LocalScale ≠ (1,1,1)` · `m_LocalRotation ≠ identity` · `m_Color.a ≠ 1`（含 RGB ≠ 白）· `m_IsActive = 0`。
- **方法**：递归解 GameObject→`m_Children`；只收非默认；**同名多实例逐个算**（`Avatar Item Small` 有 7 个）。
- **落点判断（关键）**：到 `MyGame/Assets/CardPresentation/**` 找我们对应的代码，判 ✅已对上 / ❌缺失 / ？判不准，给 `文件:行`。
- **范围**：先做我们**有对应窗口**的 prefab（Avatar 一族 / 联盟格 / 排行榜行 / 聊天头像 / 模式卡 / 卡组编辑卡池格 / 战斗卡体）。
- **已知实例**：`Avatar Item Small` 的 `Highlight 1.9 / Border 1.25 / Image 2.0` ⇒ 我们 `Shell/AllianceMemberTab.cs:1904-1912`、`AlliancePanelWindow.cs:666` 没乘（判据已齐，等写手）。
- **状态**：✅ **普查完成（2026-10-30 `B101_P1`）**：机扫 `bundle_menus_assets_all` **313 棵根 / 16,768 GameObject / 6,114 行非默认值**，产出 46 条；脚本在 `_tmp_view/b101/`（`scan.py` 单树 · `sweep.py` 全量，7 秒可重跑）。
  - ❌ **3 条真缺口**（修在 `B101_W3`）：① `AllianceMemberTab.cs:1907-1912` 成员行头像三层倍率全丢（1.9/1.25/2.0，实算立绘应 197.75×131.39、我们 98.9×65.7）② `AlliancePanelWindow.cs:284/:1114` 战斗侧联盟立绘缺 ×2（应 340.05×238.43；旧注释的「运行时缩放」归因不成立）③ `DeckRuntime.cs:697` Done 外发光丢 **90° 旋转**（应 223.2×81.4 横条，键 `:946` 注释也错）。
  - ✅ **20 余条已对上**（费用曲线四套值 · 排行榜两色 · Chat 四色 · 卡面底板 · 模式卡三色 · Missions ×1.15 · `Skull ×0.869565` 等）⇒ 下一波 ⛔ 别重查。
  - 📌 **738 行 `scale=(0.01,0.01,0.01)`** 是原版「缩到 1% 当隐藏」的手法，我们用 `Show()/alpha` ⇒ **视觉等价，⛔ 别按 0.01 复刻**。
  - ⚠️ **方法论**：所有 ❌ 都是**实算**（按锚点+pivot 推布局框 → 乘 `m_LocalScale` → 与我们常量逐数比），⛔ 不能靠 grep 数值（本工程大量「把倍率乘进矩形」，烘进去后 `1.25` 在代码里一个字符都不出现）。
