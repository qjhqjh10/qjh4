### 2·2 打桩 vs 不打桩

## Q3 需要喂的数据形状

现状（`ExecuteCloudScript.InitializeLiveOps.json:39-175`）：`GameModes.RawEvents` 有 3 条（OfflineClassic / OfflineSkirmish / OfflineDraft），**三条的 `Persistence` 都是 `null`**。

### 3·1 两个「静默丢弃」的闸（按可能性排序）
1. **`Persistence == null` ⇒ 事件进 blockedEvents（最高嫌疑）**：`"Persistence": null` 经 `SerializationHelper.cs:1059-1075` 被跳过 ⇒ 属性保持 null ⇒ `ValidateEventData`（`LiveOpsEvent.cs:727-875`）`save == null` ⇒ 新建 TSave。新存档构造只置 `IsNew=true`，**`IsActive` 默认 false** ⇒ `IsActive()` false ⇒ `blockedEvents.Add` ⇒ 0 张卡。
   反证「IsActive 必须由服务端给」：客户端自造活动事件时显式 `persistence.IsActive = true` 再 `new RawEvent(...)`（`decomp_full/Everguild.LiveOps/DlcMessageProvider.cs:126-129`）；全仓 `IsActive = true` 的写点只有这类 provider，常规路径只有 `ToggleEventActivation`（`LiveOpsEvent.cs:268-276`）。
2. **`$type` 解析不出具体事件类 ⇒ CreateEvent 返回 null**：`TypedSerializer.cs:97-110` 读 `$type` → `ReflectionHelper.GetTypeFromString`（`GetType(name,false,true)`）；失败则回落 `objectType`（`:162-171`）。`LiveOpsEventData` 非 abstract ⇒ 会建成**基类**对象 ⇒ `TryGetEventFromData` 无映射 ⇒ 静默丢。
   现状写法：`"RankedV2Data, Assembly-CSharp"`、`"RankedFastModeData, Assembly-CSharp"`、`"Everguild.LiveOps.DraftEventData, Assembly-CSharp"` —— 类名与命名空间均正确。
3. 容器 prefab 加载失败 ⇒ `MakeContainer` 返回 null ⇒ 静默 0 张。

### 3·2 每条 `RawEvent` 需要的字段
`RawEvent` = `Data`(需 `$type`) + `Persistence`(需 `$type` + `IsActive:true`)。
`Data`（`LiveOpsEventData.cs:14-28`，字段名大小写敏感）：

| 字段 | 类型 | 必填/取值 |
|---|---|---|
| `$type` | string | 事件 Data 子类：`RankedV2Data` / `RankedFastModeData`(全局)、`Everguild.LiveOps.DraftEventData` / `PracticeEventData` |
| `eventId` | string | 唯一；`PracticeEvent` 必须**恰好**是 `"PracticeEvent"` |
| `enabled` | bool | true |
| `activationType` | enum | **0 = Permanent**（`LiveOpsEventData.cs:92`，`GetState` 恒 2） |
| `priority` | int | 任意 |
| `showInMainMenu` | bool | true |
| `drawData` | EventElements | 见下 |
| `dates` / `filter` / `location` / `mainMenuOptions` | — | Permanent 下可为 null |

`drawData`（`EventElements.cs:14-24`）——**是 `List<…>`，不是字典**：

| 列表 | 项类型 | 必填项 |
|---|---|---|
| `EventComponents` | `List<EventComponent>`（`key`: enum, `value`: AssetReference{`m_AssetGUID`}） | **`key:35`(MainMenuContainer) 必须有**；`key:10`(MainWindow) 可选 |
| `EventLabels` | `List<EventLabel>`（`key`/`useLargeSizeOnMobile`/`value:{mTerm}`/**`Args` 必须 `[]`**） | `key:0`(Title) |
| `EventAssets` | `List<EventAsset>` | 可选，`key:10` 卡背景 |

`Persistence`（子类 = 事件的 `SaveType`）：`RankedV2Event : RankedEventBase<RankedV2Save, RankedV2Data>`；`PracticeEvent : PlayEvent<PracticeEventSaveGame, PracticeEventData>`。
最小：`{ "$type": "<SaveType 全名>, Assembly-CSharp", "eventId": "<同上>", "IsNew": true, "IsActive": true }`。
⚠️ `$type` 必须给对：`ValidateEventData` 若 `save is TSave` 不成立会新建存档、**丢掉你的 IsActive**（`LiveOpsEvent.cs:779-800`）。
