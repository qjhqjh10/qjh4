## 〇 一句话

S3 表现维 = 逐卡三问：**这张卡的这一拍，真的播了哪一件？** 今天能机器判的只有四块 ——
① 特效「件名 vs 声明表」的解析（S2，静态）· ② 特效的**离体数值**（台账 `|ln|`）· ③ 动画的**调度 trace**（管道已建、**真实样本 0**）· ④ 语音的**取件与调用口**（只有 fixture 级）。
**「像不像 / 好不好听」只有用户能判**（用户 2026-10-26 口径）—— 本清单只判通路。

## 一、S3 要验什么（逐维）

| 维 | 「该播什么」的判据源（期望值） | 「真的播了」的证据必须长什么样 | 机器能判到哪 | 只能人判 |
|---|---|---|---|---|
| **② 特效** | `Resources/card_vfx_by_card.json` 的 `cards[].events[].es[].n`（原版 SO GUID 链 → prefab 名）；现读 **1,100 卡 / 2,675 件 / 647 个不同 prefab** | `CardEffects.Play(name,pos,parent)` 被调到（`Core/CardEffects.cs:21/37`）→ `WarpforgeEffectPlayer.Play` **建出实例**（`WarpforgeEffectPlayer.cs:225/267`）→ 还要**推进时间**才谈「播完」（`Tick(dt)`，`:483`） | 件名集合 / 顺序 / 时刻 / 世界落点 / 父层，可与声明表**逐字比**；**同一 prefab 的亮度比**可与原版比（离体 sweep） | 像不像 |
| **③ 动画** | `cards_engine.json` 的 `animTimes`（**1,469 行 / 874 卡**）＋ `数据/游戏数据/card_anim_order.json`（928 卡 / 1,527 refs）＋ `animinfo_lookup.json`（418 条） | `BattleDriver` 时间线**排期**这一刻被记进 `AnimTrace`（`Core/EventTiming.cs:1310`；收口 = `Battle/BattleDriver.cs:39192/39227`）⇒ 件名 / `startOffset` / `holdSeconds` / `cueKind` / `firstOfEvent` | 件名序列 / 相对起始偏移 / 阻塞时长（`工具/compare_anim_trace.py`） | 手感、节奏顺不顺 |
| **④ 语音** | `Resources/voice_lines.json`（642 卡 / 1,897 条）＋ `card_vfx_by_card.json` 的 `cards[].audio`（精确绑定，现读 **641 卡 / 698 条**） | `VoiceLines.TryPickExact`（`Core/VoiceLines.cs:300`）取到卡片 → `BattleDriver.PlayUnitVoiceClipOnly` 真的 `PlayOneShot`（`BattleDriver.cs:7656-7670`）／deploy 走气泡 `UnitChatPanel.Speak`（`UnitChatPanel.cs:325 ShownSide`、`CardDisplayWindow.cs:404 LastVoiceFile`） | 卡×事件 → 取到哪条 cue/clip + 是否可加载（`Clip()`）+ 播放口被调到（计数） | 听感 |

⚠️ **两条硬口径**（W25 §三 已写死，照抄不另立）：

1. **「工程里有这个文件」≠「这张卡会播它」** —— 必须给**触发**证据（哪个钩子、哪一行、什么时候调）；**②③④ 的「对」在 S2 里是静态通路**，不是「已经播了」（`B107_W25.md` §五·5·1 原文）。
2. **「特效像不像」只有用户能判**（§五·5·2）；本文件不做截图并排比的判定。

### S3-V1 全池**逐卡特效数值**（不跑 Unity，join 现成台账）
```bash
cd /d/4/Unity && python -I -X utf8 - > _tmp_view/s3_vfx_per_card.tsv <<'PY'
import io, json, collections
U='d:/4/Unity'
d=json.load(io.open(U+'/MyGame/Assets/CardPresentation/Resources/card_vfx_by_card.json',encoding='utf-8'))
led={}
for r in io.open(U+'/资料/特效还原台账.tsv',encoding='utf-8-sig').read().splitlines()[1:]:
    f=r.split('\t')
    if len(f)>=5 and f[0]: led[f[0]]=(f[2],f[4])          # 判定, |ln|
print('cardId\tname\tfaction\tpieces\tworstAbsLn\tverdicts')
cnt=collections.Counter(); miss=0
for c in d['cards']:
    ns=[x.get('n') for e in c.get('events',[]) for x in e.get('es',[]) if x.get('n')]
    vs=[]; worst=0.0
    for n in ns:
        v=led.get(n)
        if v is None: miss+=1; vs.append('MISSING'); continue
        vs.append(v[0]); cnt[v[0]]+=1
        try: worst=max(worst,abs(float(v[1])))
        except Exception: pass
    print('%s\t%s\t%s\t%d\t%.3f\t%s'%(c['id'],c.get('nm',''),c.get('fa',''),len(ns),worst,'|'.join(sorted(set(vs)))))
print('#cards=%d missing=%d %s'%(len(d['cards']),miss,cnt.most_common()),file=__import__('sys').stderr)
PY
```
- **期望（现读）**：`#cards=1100 missing=0`；件级分布 `对得上 2,154 · 两边全程空 517 · **只有原版有内容（导出整个丢了）4**`；逐卡 **686 张全可测** / **405 张至少一件「全程空」** / 9 张无件；最大 `|ln| = 0.185`。
  🔴 **2026-11-02 就地订正（铁律 5 · `B118-J11` 现核）**：原来这里写的「**次阈值小样本 4**」**定性错** —— 脚本打的是 `判定` **原文**，那 4 件是 **C 组「只有原版有内容 —— 导出整个丢了」**（`资料/比对基线/台账_before_1031fix.tsv`：`只有原版有内容 3 + 只有导出有内容 1`），**不是「样本太小」。按本文件自己的红档定义，C 组要进缺陷清单** ⇒ 这 4 件另立账核（活状态表 `D118-74`）。
