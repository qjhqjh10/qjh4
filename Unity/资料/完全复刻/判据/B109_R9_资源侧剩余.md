## §5 R4-05 Gargoyle 两个 Texture3D —— **别用 PNG，原始体数据就在 bundle JSON 里**

**原版判据（本轮现读并实解）**
| 资产 | json | 尺寸 | `m_Format` | `m_DataSize` | 每体素 | wrap/filter |
|---|---|---|---|---|---|---|
| `vectorfield` | `bundle_battleprefabs_vfxandmisc_assets_all/Texture3D/Texture3D_-5601361985474094491.json` | 64×64×64 | 8 | **1,048,576** | **4 B** ⇒ R8G8B8A8_UNorm | Repeat / Bilinear |
| `SDF_Test` | `…/Texture3D_-6523327969514304178.json` | 31×31×64 | 45 | **123,008** | **2 B** ⇒ R16_SFloat（半精度） | Clamp / Bilinear |

- 两份 `m_MipCount = 1`、`m_ColorSpace = 0`（linear）、`m_IsReadable = true`、**`m_StreamData.size = 0` ⇒ 数据内联**。
- 数据字段 = `image data.$bytes`（base64）：我实解出 **1,048,576 B / 123,008 B**，头部值合理（vectorfield RGBA 首像素 124,131,136,255；SDF 首四个 half = 0.105/0.095/0.085/0.076）。
- ⚠️ **`判据/B106_资源侧R0R4_施工单.md:135` 写的「`RFloat`/`RGBA32`」里 RFloat 是错的** —— 123,008 / 61,504 体素 = **2 B/体素 = RHalf**（4 B 的 RFloat 会是 246,016 B）。

**切片方向（实测，不是推测）**：AssetRipper 导出 = **逐 z 切片竖排 + 每切片内部上下翻转**。判据：`vectorfield.png` 64×4096，按 `png_row = z*64 + (63 − y)` 与原始字节比对 **mean|Δ| = 0**（另外三种排布 4.4~4.5）；`SDF_Test.png` 31×1984 同构。⚠️ SDF 的 PNG 是 8 bit 可视化（首像素 26,0,0,255 ≠ 原始半精度），**拿它当数据会掉精度**。

**可执行改法（推荐路径，绕开方向问题）**：新建编辑器脚本 `WarpforgeArena1/Editor/GargoyleTexture3DBuild.cs`：
```csharp
byte[] b = Convert.FromBase64String(<json 的 image data.$bytes>);   // 两条各自的字节
var v = new Texture3D(64,64,64, TextureFormat.RGBA32, false);
v.SetPixelData(b, 0); v.wrapMode = TextureWrapMode.Repeat; v.filterMode = FilterMode.Bilinear; v.Apply(false,false);
var s = new Texture3D(31,31,64, TextureFormat.RHalf, false);
s.SetPixelData(b, 0); s.wrapMode = TextureWrapMode.Clamp;  s.filterMode = FilterMode.Bilinear; s.Apply(false,false);
```
`SetPixelData` 吃的就是 Unity Texture3D 的原生内存序（x 最快 → y → z），与 `image data` 字节序一致 ⇒ **不需要任何翻转**。**若坚持用 PNG**：必须按 `(z,y) → row = z*H + (H−1−y)` 还原，且 SDF 只能得 8 bit 近似（不满足原版 R16_SFloat）⇒ 不要走这条。
**断言要点**：`.asset` 的 `width/height/depth/format/mipCount` = 上表；`GetPixelData(0)` 与源字节逐字节相同；两件的 `.meta` guid 写回 `_shared` 的材质/VFX 引用（别名规则见 R4-02）。
**还差什么**：Unity 批处理（只有主对话能跑）· `_shared` 目标路径。
