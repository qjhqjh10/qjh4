# B117 · 卡牌展示场景 × 表现矩阵（`G11` · 2026-11-03）

> 用户问题：「不同地方的卡牌可能的表现不一样，查一下有什么地方分别展示什么样的卡牌：场上、手卡、大图详情、卡组等。」
> ⚠️ 本文件是**判据**，状态看 `活状态表`。

---

## 零、一句话结论

**原版卡面状态有 18 档**（`CardStateOptions`）+ 9 档文字类型 + 2 档立绘尺寸 + …；
**我们只有 3 个 `CardFace`**（`Full` / `Board` / `Hand`），其中 `Full` 一档**独自承担了 11 个场景**（战斗大图 / 菜单详情 / 卡池 / 卡组编辑池 / 记录悬停 / 轮抽 / 开包 / 商店抽屉 / 多卡展示 / 选牌 / 换牌预览）。
另有一条**正交轴 `CardUse`**（`Standard` / `ZoomWindow` / `Booster`），才是真正按宿主分档的那条。

## 四、不该"统一"的三处（⛔ 别为了统一而套 `CardView`）

- **卡组格**是卡背（`Shell/CollectionWindow.cs:5275`）· **结算**是奖励抽屉（`Battle/EndPanel.cs:12`）· **效果列表**是文字行（`CardDisplayWindow.cs:709-760`）——它们本就不是卡面。
- **手牌与换牌是同一批对象**（`MulliganPanel.cs:965/1011` 直接搬手牌里的 `CardView`），看起来一样是**对的**，原版也是同批卡换状态 13/14。
- **收藏卡池 vs 卡组编辑池**同为 `Full` 但尺寸不同（1.0417 vs 0.9609），是两套原版宿主各自的公式，**不是漏档**。
