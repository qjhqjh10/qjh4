### 2. `AiScripted` 怎么按脚本出牌（时序、目标选择）

- **时序**：外层是协程 `_ExecuteScriptedTurn`（`decomp_full/BattleManager._ExecuteScriptedTurn_d__597__MoveNext.c`）：
  `IsNextActionScriptedPlayerAction` 为真 ⇒ **原地停住等玩家**；否则 `PlayScriptedTurn` → 指针 `+0x10` ++ →
  `SkippableActionWait(GetDelay(…))` → 等动作队列清空 → 下一条。
- **延迟** = `GetDelay(manager, turnData, before)`：`before` ⇒ 元素 `waitBefore @0x20`、`after` ⇒ `waitAfter @0x24`
  （下标在 after 时用 `counter-1`）。`ScriptedAction` 字段表 → `dump.cs:42111-42124`。
  ⚠️ **不含音效时长**（那是**战役**的 `GetCurrentWaitTime` 才加的）。
- **目标选择**：`GetActingCard` 按 `actingUnitType` 取列表（`30/31/32` 同一条 `GetPlayerMinionsAndRemnantInPlay`，**不区分左右**）；
  再从列表里按**卡的 `name` 字符串**逐条 `String.Equals` 挑（`AiScripted__GetChosenCard.c`）；
  🔴 **一条都不匹配时退回 `list[0]`（不是 null）** —— 我们**故意不照抄**（我们的 `TutorialRules.Resolve` 认不出就 null + 出声）。
- **落点**：`PlayCard` 取的是**当时的鼠标位置**再 `GetClosestAvailableSlot`（`ExecuteAction.c:856-869`）——
  即 `playerAction=false` 那些脚本自己出的牌，**落点本质上是任意的**。

### 4. 战役脚本与教程脚本：**同一个类、两套重载、两个指针**

- 都是 `AiScripted`：`PlayScriptedTurn(BattleManager, TurnScriptedData)`（教程）与
  `PlayScriptedTurn(BattleManager, List<ScriptedActionCampaignData>)`（战役）**同名两套**；
  `ExecuteAction` 同样是两套重载（`dump.cs:24571-24574` + ILSpy `AiScripted.cs:1915` / `:2062`）。
- 指针两个：`actionCounter @0x10`（教程）· `actionCampaignCounter @0x14`（战役）。
  `ResetActionCounter()` **一次写 8 字节**（两个一起清）；`UpdateTurn()` **只清 `+0x10`**。
- 唯一共享的是实例本身与 `voiceLinesController @0x20` / `currentTurn @0x18` / `skipNextAction @0x29` / `stoppedTutorial @0x28`。
- **我们是对半分**：教程那一半在 `RuleEngine/Core/TutorialScript.cs`，战役那一半在 `Battle/CampaignScriptRunner.cs`（本件）——
  这是**结构性差异**（不是行为差异）：两个 `int` 被拆进两个类，靠 `CampaignScriptTurnDriver(tutorial)` 那一跳把归零口挂上。
- 🔴 **战役数据本地不存在**：`ScriptedActionCampaignData` 的四张表挂在 `WarlordPathData`，只存在于
  `TimedCampaignObject`（服务端 LiveOps 资产）⇒ 见 `CampaignScriptRunner.cs` 文件头那三条取证（`assets_full` / `d:/2/关服前存档` 全空）。

2. `TutorialTipScript` 的 `fadeDuration = 0.2` / `minTimeBeforeSkip = 1.0` 已在 prefab 实例上**实测确认**
   （`bundle_scenes_scenes_battlearena1/MonoBehaviour/MonoBehaviour_5246.json`）⇒ 我们那两个常量是判据值，不是挑的。
