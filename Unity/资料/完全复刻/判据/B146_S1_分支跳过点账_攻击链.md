### 1·2 扫描口径（「被跳过的一步」怎么抓）

只算这五种形状，且**必须落到一个具体调用名 + 行号**，⛔ 不写「少做一件事」：

1. `if (cond) { … }` 的**否定路径** —— 条件假时整段（含其中调用）被跳过；
2. `if (!cond) return …` / `if (!cond) goto LAB_x` —— 之后到函数尾/标签之间的调用被跳过；
3. `goto LAB_x` —— **标签行到 goto 之间的调用**被跳过（这是本试点最值钱的一类）；
4. `break` / `continue` —— 中断当前 case / 循环，后面的调用被跳过；
5. `switch` 的 `default` 缺失 / 恒不命中（`switch` 值域外的状态码）。

工具：`python -I -X utf8 d:/4/Unity/工具/scan_skipped_calls.py <file.c> [--top N] [--write OUT.tsv]`
逐条输出 `file / line / cond / then_calls / terminator / target / skipped_calls / else_calls`。
实测：`CanAttackNow` 19 条 `if`、`MoveNext` **230 条** `if`，其中带 `goto` 的会自动解出「被跳过区间」的调用表。
