using System;

namespace RuleEngine

    public static partial class SimpleAI
    {
        /// <summary>按 <see cref="AiAction.Score"/> **降序、稳定**排序（原版 `AI.TweakAvailableActions` 的
        /// `Enumerable.OrderByDescending(currentActions, a => a.actionScore)` —— LINQ 稳定排序；
        /// `List<T>.Sort` 是 introsort，**不保证稳定** ⇒ 等键（同分）的相对次序会被打乱，
        /// 而下游「从表尾删最低分」+「`SelectBestAction` 平手留先枚举的」都吃这个次序。
        /// 判据 = `decomp_full/AI__TweakAvailableActions.c:85-87` + `cpp2il/out_cpp2il_dev_ilspy/AI.cs:270-276`
        /// + `out_il2csharp/Assembly-CSharp/AI.cs:102`（原版 lambda 键 = `actionScore`，`:2964`）。
        /// ⚠️ 写法与 `RuleCore.StableSortByPlayOrder` 同一条纪律（原始下标做第二排序键）；
        /// ⛔ 别改成 `list.Sort(...)`（不稳定）、⛔ 别用 `OrderByDescending`（本文件没有、也不加 `using System.Linq`）。</summary>
        static void StableSortByScoreDesc(List<AiAction> list)
        {
            int n = list != null ? list.Count : 0;
            if (n < 2) return;
            var items = new AiAction[n];
            var idx = new int[n];
            for (int i = 0; i < n; i++) { items[i] = list[i]; idx[i] = i; }
            Array.Sort(idx, (a, b) =>
            {
                int c = items[b].Score.CompareTo(items[a].Score);   // 降序
                return c != 0 ? c : a.CompareTo(b);                 // 同分 ⇒ 原始下标序（稳定）
            });
            for (int i = 0; i < n; i++) list[i] = items[idx[i]];
        }
    }
}

- `play all dump` **不变**（同上：AI 不在结算层）。

### 2·5 验收断言

1. **helper 级（最强判别式）**：构造 3 条**同分** `AiAction`（`Kind` 各不相同以便辨认），调 `StableSortByScoreDesc` ⇒ 断言**相对次序未变**；再给第 2 条加 0.5 分 ⇒ 它排第一、另两条仍保持原相对序。🧨 把实现换成 `list.Sort(...)` ⇒ 同分那条断言红（用 3 条可能不够触发 introsort 重排，**用 ≥ 17 条同分 + 交错分数**更稳）。
