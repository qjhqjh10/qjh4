**关键结论（本轮最值钱的一条）**：原版 `LeaveRoom` 的对端语义是
`OnPhotonPlayerDisconnected → _ForfeitDisconnectedEnemy`（**先 15 s 重连窗口、到期才判**）；
而我们只要发了 `bye`，对端走的是 `HandlePeerClosed` ⇒ **当场判弃权**。
所以「不判结果直接离场」的等价物 = **`Close(say: false)` 硬断 + 本机不记账**，
**不是**「新增一个判负/判胜的支」。

/// ⛔ 别改成 <c>Close(true)</c>：那会让对端走 <see cref="HandlePeerClosed"/> ⇒ 立刻判我们弃权。</summary>
void LeaveWithoutResult(string why)
{

    _aborted = true;
    Debug.LogError("[Net] 不判结果、直接离开这一局：" + why

    _s.Close(say: false);          // ← 硬断：不发 bye
}
