### §1·1 #1 Division Change（fragment 全算式，抄自 Ruri）

源：`d:/2/tools/ruri_out_1020_allshaders/ExportedProject/Assets/Shader/Everguild_UI_Division Change.shader:112-195`（fragment 内联在 `.shader` 里）
```
n  = noise(uv*_Noise_ST.xy+_Noise_ST.zw)*2-1
w  = 0.6 + _Blend*0.4            // 半径随 _Blend 扩张
p  = uv + _DistortAmount*n - _DistortCenter
r  = length(p);  k = 1 - clamp((r - w)*11.111115, 0, 1)
use2 = (_DissolveAmount >= k)    // 已溶解区 → 取 _SecondaryTex
a    = lerp(_MainTex.a, _SecondaryTex.a, use2); if (a==0) discard;
border = (int)(_BorderWidth + _DissolveAmount >= k) - (int)use2
bc   = lerp(_DissolveColor, _DissolveColorSecondary, 1 - clamp((r-(w-_ColorBorderWidth))*11.111115,0,1))
rgb  = lerp(_MainTex.rgb, _SecondaryTex.rgb, use2) + border*bc.rgb
```
参数（`Material_-7300284622968135969.json`）：`_Blend 1` · `_BorderWidth 0.36` · `_ColorBorderWidth -0.01` · `_DissolveAmount 0.084` · `_DistortAmount 0.02` · `_DissolveColor(1.5157,0.2327,0,1)` · `_DissolveColorSecondary(0.9245,0,0,1)` · `_DistortCenter(0.5,0.59,0.5,0.5)` · `_Noise` 贴图 `m_FileID 3 / pid -8214795764591836323`，`_Noise_ST.scale=(3,3)`。

## §3 需要 Unity / 真机的部分

1. **材质资产怎么建**：两条路 —— ① 编辑器里建 `.mat` 放 `Resources/`（照 `Resources/Shaders/CardSprite.shader` 的先例：`Shader.Find` 只能找到进包的 shader，放 `Resources/` 免改 GraphicsSettings）；② 运行时 `new Material(Shader.Find("WarpforgeVFX/UI/..."))`（照 `Shell/ForgeTab.cs:1056` 的 `ForgeGlowMaterial()`）。**必须在 Unity 里跑一次**确认 shader 编译通过（`typecheck` 管不到 shader）。
