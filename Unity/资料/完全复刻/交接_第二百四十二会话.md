## 三、关键结论 / 判据（新会话直接用）

1. **战役节点奖励是服务端下发的**：`CampaignEventData.Nodes`（`CampaignEventData.cs:12-18`）才是运行时数据；
   `Graph` 是 `[JsonIgnore]` 编辑器字段；打包 `Ultramarines Campaign.json` **没有 `Nodes`**。
   本地 `Campaign Node Data` 47 个是编辑器图占位值 —— **不是线上真值**；线上值（红水晶/黄金等）随关服丢失。
2. **13 阵营真值**：`Ultramarines 10 / Goff 20 / SaimHann 30 / Sautekh 40 / BlackLegion 50 / Leviathan 60 /
   TauEmpire 70 / Sororitas 80 / Genestealers 90 / AstraMilitarum 100 / DarkAngels 110 / EmperorsChildren 120 / SpaceWolves 130`。
3. **战役/锻造厂满级都用静态模板**：战役 `NodesCollected=47` + `Used=Total=33100`；锻造厂 `currentPoints=25490` +
   `rewardsCollected=50`；⛔ 不要为它们加 state/880/882/1118 的领取状态机。
4. **锻造厂轨道 = 50 档**（不是 45）：用户实拍「等级 2/50」+「50/110」；阈值 `t(i)=10*(i*i+i-1)`，第 4 档起 🔶。
5. **空节点根因**：Currency SO 无 `uniqueId` ⇒ `LoadableReference` 解析不到 ⇒ `Item=null` ⇒ `ItemDrawer` 不调用。
   修复必须补解析（PC `ItemInfo<ObtainableItem>.get_Item`；安卓 `src/currencyref.js`），⛔ 不要再手动补画。
6. **安卓 frida 桥的字符串带引号**：`targetId` 日志是 `tid="C2"`，查表前必须 `cleanStr()` 去引号。
7. **`python -I` 不会把脚本目录加进 sys.path**（3.11+ `-P`）⇒ 兄弟模块 import 前显式 `sys.path.insert`。
8. **JSON 模板保持原风格**：用 `tools/_json_style.py` 的 `dumps_like_existing`，写回前做逐字节 round-trip 断言；
   `Rewards` / `NodesCollected` 在源文件里是单行，⛔ 别用 `json.dumps(indent=1)` 整份重排。
