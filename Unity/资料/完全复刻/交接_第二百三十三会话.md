## 三、关键结论 / 判据（给下会话）

- **联网时机**：⛔ 加载/登录阶段零联网；**主菜单就绪**判据 = `GeneralMenuController.Instance` 有效（⛔ 不是 `WindowsManager`）。
- **伪重启**：安卓直接 `SessionManager.RestartSession(true)`；PC 用「手动序列 + `LoadScene(0)`」；⛔ 不要绕过 `EverguildSceneManager`。
- **重启期间停自家轮询**（`restarting` 守卫），否则会卡死主线程。
- **推送更新**：Java 先校验 sha256（fetch/commit/启动三次），wrapper 才加载；客户端弹窗流程 = 同意 → 进度 → 完成。
- **JS 代码更新必须下次进程启动生效**（Unity 无可靠进程内自重启）。
- 云存档冲突语义：`localDirty`（本地 hash ≠ 上次同步 hash）与 `cloudNewer`（云端 rev ≠ 上次同步 rev）；两边都变才弹窗。
