## 四、本波新增的坑（下个会话直接躲）

1. 🔴 **启动客户端后别用「heartbeat 最后一行含 MainMenu」判断新客户端就绪** —— `heartbeat.tsv` 是 Append，旧客户端的最后一行会假命中。判据 = **时间戳晚于本次启动 + `t<60`**。
2. 🔴 **ESC 设置窗的「放弃」按钮位置会受上一帧状态影响**；点之前先 `shot` 确认设置窗真的开了，否则会点到手牌/大图。`放弃` 有时无二次确认、有时弹空白框。
3. 🔴 **`pkill -f run_server.py` 会把执行它的 ssh shell 一起杀掉**（命令行含同串）⇒ 用 `systemctl stop wf-photon` 或 `pgrep -f "^/opt/wf-photon/venv/bin/python /opt/wf-photon/run_server.py$"`。
4. 🔴 **pyPhotonRealtime 的 AppId 必须 32 字节**；短串会被判 `garbage` 断开。`ConnectToMaster` 传 GUID 形式（`597d8559-e190-…`），SDK 自己转字节。
5. ⚠️ **`NetworkCustomManager.PhotonServerSettings.AppSettings` 反射为 null**（游戏用的是旧 `ServerSettings` 资产）⇒ 探针里 AppID/版本走**硬编码兜底**（`PhotonRedirectProbe.FallbackAppId`），不要指望反射读到。
6. ⚠️ **OFF-119 的协程只跑两次就停**：`CORO-OUT` 间隔 1.47s（正好 1.5s 等待），之后没有第三次 ⇒ 先验证 `Time.timeScale`（v5 探针已加日志）。
7. ⚠️ **客户端启动偶发卡在 `Simple Transition`**（本次一次，4 分钟没进主菜单）⇒ 杀进程重开即可，别当登录链坏了。
8. ⚠️ 战斗类 TSV 每次起客户端被 `ProbeLog.Reset` 清零的坑仍在（交接 146 §四·1）；关客户端前先 `cp`。
