## 一、本会话做了什么

### 1.1 默认卡组「经典」无效 —— ✅ 修好并实测

- **现场数据**（用户 16:26 双机点击）：A/B 的 `eventPrefs` 都只写了 `OfflineSkirmish`，且写的是**经典卡组**；
  随后的挑战 `PUNReceiveDeckData` 1085/1087 B = 30 张（经典），换牌仍是旧卡组。
- **根因**：默认卡组按**事件**存（`PlayEventSaveGame.defaultDeckId`），`GetEventDeck()` 还校验
  `deck.GameMode == 事件 EventPlayMode`。经典好友挑战读 `GetActiveEvent<RankedV3Event>()`（合成 OfflineClassicV3）、
  经典主菜单读 `GetActiveEvent<IClassicEvent>()`（OfflineClassic）；而原版入口 `IRankedEvent.GetActiveEvent()`
  在离线数据里恒返回 **OfflineSkirmish**（priority 50 最高）⇒ 经典拿不到。
- **修法**（`src/deckdefault.js` / `src/rankedv3.js`）：
  - `setDefault` 按 `deck.GameMode` 分流：13 → `IFastModeEvent`；0 → `RankedV3Event` + `IClassicEvent`；
  - 合成事件不进 RawEvents ⇒ `defaultDeckId` 由 `rankedv3.js::saveJson` 拼进 Save（重启回灌）；
  - **合成事件 `ev.ref(true)` 钉住 + 复用前探活重建**（闲置数分钟后被 GC，句柄失效 ⇒ 偶发写不进，坑 512）；
  - 按钮只在「收藏 → 卡组」的详情弹窗出现（判据 `context.SelectButton == null`）；点完**自动关窗**。
- **实测**：`mode=0 OfflineClassicV3=ok · OfflineClassic=ok` → 两条 `[DEFDECK]` → **自动关窗** →
  重启 `[RANKEDV3] 默认卡组=…` 回灌；**用户复测确认「默认卡组正常了」**。

### 1.4 赛后「未认证」弹窗 —— ✅ 修好并实测

- **定性**：判负/VICTORY 本来就对；弹窗来自赛后上报 `RecordRankedResult` 的 PlayFab **本地** `NotAuthenticated(1074)`：
  没有 `[SRV]`/`[REDIR]`；同一时刻 `IsClientLoggedIn=1`（ticket 22 / entity 20）；该调用点被 IL2CPP **内联**，
  三处钩子都看不到 ⇒ **与假服务端无关**（历史 53 次成功）。
- **修法**（`src/popup.js`）：接管 `CloudscriptHandler.HandlePlayfabError`；`err.Error==1074` 且 `data.js` 有
  `ExecuteCloudScript.<FunctionName>` 模板时，用 `JsonWrapper.DeserializeObject` 构造 `ExecuteCloudScriptResult`
  并**直接调 onSuccess**（等价本地服务端成功包），跳过上报与弹窗；没模板才走原版。
  兜底：`PlayfabErrors/NotAuthenticated` 窗口仍「隐藏 + 15 s 自动点重试（最多 4 次）」。
- **实测（A 机两轮）**：`RecordRankedResult 本地补成功` → `OnFastModeMatchFinished` → `[BLOG] 战斗记录（26 条）`
  → `saveMatchRecording` → `OnRankedMatchRecorded ×2`；屏幕 **VICTORY、无弹窗**（`s375_1122_unauth/A23.png`）。
