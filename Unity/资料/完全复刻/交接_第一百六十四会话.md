## 四、本会话新增的坑（`已知的坑.md` 163–166）

- **163** C# `File.GetLastWriteTimeUtc(不存在的文件)` 不抛异常（返回 1601）⇒「缺模板」被当成「坏模板」回 500；
  必须显式 `File.Exists`。
- **164** `EMBED_SERVER=1` 但 8765 上有健康的外部服务端 ⇒ 内置按设计让位（`reuse-external`），看起来像没生效。
- **165** `JToken` 的毫秒时间戳是 **Int64**，`(int)` 会 `OverflowException`；它在注入链中间抛出会被外层
  catch 吞掉，表现为「某字段恒 0 / 后面注入全没生效」。一律先 `(long)`。
- **166** 对拍工具的 state 种子必须用**绝对** `state_file`（否则 Python 会拿开发机真实存档当种子）；
  邮件箱两边必须指同一份 `邮件箱/`。
