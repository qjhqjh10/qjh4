## §2 怎么读这张表（验收三法怎么挂）

| 列 | 用途 |
|---|---|
| 功能点 | 「玩家能做的一件事」。**验收按行跑**，不按类跑 |
| 主链/边角 | **主链** = 玩家一定会走到（开局·出牌·攻击·目标·结算·收藏/卡组主链·卡面数值）；边角 = 次要/低频/纯观感 |
| 挂哪些类.方法 | 回到 `账/<域>.tsv` 的原行（按 `原版类` + `方法` 搜），那里有 `判据出处` / `判据要点` / `我们的落点` |
| 状态分布 | **改成 A 之前先看这一列** —— 有 C 就说明这条功能点还有「该做没做」的洞 |

**三步走**：① **判据签收** = 该功能点下每一条 C/E 都要有 `判据出处`；② **oracle 对照** = 原版离线可跑，拿这条功能点的行为去比；③ **成品并排比** = 截图/录屏与 PvP 卡面/界面并排。
