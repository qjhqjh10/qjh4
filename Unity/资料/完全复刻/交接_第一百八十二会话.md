## 三、关键实现（接手必看）

| 主题 | 落点 | 要点 |
|---|---|---|
| 回合闸 | `BattleManager.ResolveEndTurn` prefix + `RetryResolveEndTurnCo` | 忙就跳过并记 action，空闲补发；**⛔ 别再用 `_NextTurn.MoveNext` prefix 返回 false**（Unity 视为迭代器结束 ⇒ 回合永久卡死，坑 248） |
| 换手牌动画 | `SwapSeat` → `HandSwapCo` → `BeginSeatDeal` | `currentHand` 同步换（引擎不等动画）；表现层「旧飞左 0.28 s → 新飞右 0.28 s」；首发/换牌/抽牌记进 `_pendingDeal`，动画结束才发 |
| 战斗探针 | `ControlTick` / `DumpBattleState` | 命令文件每 0.3 s 读一次并清空；dump 追加到 `b4_state.tsv` |
| 结束回合按钮 | `ClockManager.SetEndTurnText` postfix + `ApplyClockUi`（Tick 0.25 s） | 队友回合：`clockText.text="我方回合"` + `clockButton.set_interactable(false)`（字段是**属性**，坑 250） |
| 横幅 | 拦 `TMP_Text.set_text` | 「你的回合」在队友回合改成「队友回合」 |
| 战将天赋选择 | `TalentChoiceCo` + 3 个补丁 | 抽卡动画结束后摘掉自动天赋 → `ChooseCardMenu.Setup(list,"",3,0)` 弹窗 → 多选 → 「继续」生成；**部队天赋未改**；坑 251/252 |
| 换牌大卡隐藏 | `AiCloneMulliganCo` | 非本机座位 `mulliganManager.gameObject` 关 → `CompleteMulliganPhase` 后恢复 |
