## 三、关键实现落点（接手必看）

| 主题 | 文件 / 函数 | 要点 |
|---|---|---|
| 手牌指针与显示解耦 | `Battle4Probe.SwapSeat` / `RestoreHandDisplay` / `RestoreHandDisplayCo` / `RestoreTrueHandPointer` | `_loadedSeat` = 战将/牌堆真正装载的座位；`_shownHandSeat` = 手牌 UI 显示谁；`RestoreHandDisplay` 只动 UI，**不改 `_loadedSeat`**，所以 `SwapSeat` 早退必须再比手牌列表 |
| 加牌入手的三个入口 | `BattleProbe.Pre_HandPtrDraw/New`（挂在 `BattleManager.AddDrawCard` / `AddNewCardToHand` / `AddDrawSpecificCard`） | 进函数前把该侧 `currentHand` 还回 `_loadedSeat[side]`，否则别人的抽牌落进本机手牌 |
| 幽灵手牌 | `Battle4Probe.DedupeHandLists` | 清 `inCemetery/inDeck/removedFromGame` 条目并重排（告警 `hand.ghost`） |
| 后手卡 | `Battle4Probe.AddGoesSecondCard` | 必须 `SeatRawFor(seat, side)`，⛔ 不能用 `RawForSide(side)` |
| 2v2 外壳复位 | `Battle4Probe.ResetLocal2v2` + `MenuRootTick` | 判据 = `SceneManager.GetActiveScene().name` 不再含 `Arena`，且**这一局进过 Arena**；另 120 s 兜底 |
| FTUE 低血无敌 | `BattleProbe.Pre_NoFtueInvul`（挂 `MatchData.GetBotConfigFTUEShouldUseFirstGameLogic`） | 离线一律 false；⛔ 别再去动 `BotListFTUE` 数据 |
| 压暗层兜底 | `Battle4Probe.ShadeGuardTick` + `UiNavProbe.OpenWindows()`（已升 `internal`） | 所有战斗都跑；`GameWindow.IsOpen` 有窗口 ⇒ 合法压暗，不动；无窗口 + 亮 >3 s ⇒ `SwitchShade(false,…)` |
| 只读诊断钩子（本会话新增） | `BattleProbe`：`battle:CounterText` / `UpdateHealthText` / `Adjusted` / `AddEffect` / `AddTraitSilently` | 全写 `phase0/battle.tsv`；⚠️ `ProbeUtil.FindMethod` 是 **DeclaredOnly**，查基类方法要用 `FindMethodInHierarchy`（坑 **300**） |
