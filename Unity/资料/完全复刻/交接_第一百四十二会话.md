## 四、本波新增的坑（下个会话直接躲）

1. 🔴 **`$type` 必须带命名空间**（`Everguild.LiveOps.ExpansionPassData` / `CampaignEventData`）：短名 + **concrete 声明类型**会反序列化成功但事件被**静默丢弃**（零日志）。同名类在全局命名空间才可用短名（`MainMenuMissionData` 等）。
2. 🔴 **`server.py` 不热重载**：改它之后必须 **kill 旧 python 再起**，否则客户端拿到的还是旧默认值/旧分支（本波战斗记录空白就是这个）。
3. 🔴 **`VictoryCounters` / `BattleLogData` 读口是 `UserReadOnlyData`**（`checkPublicData=false`），不是 `UserData`。
4. 🔴 **通配符 id 的稀有度是数字**：`Wildcard<SaimHann>1`，写成 `Common` 会被静默丢弃。
5. 🔴 **玩家攻击只有「拖出单位→在目标上松手」**；本回合刚上场的单位 `CanAttackNow=False`，必须等下一回合。点选→点目标不存在。
6. 🔴 **加 liveops 事件会改变 `GetActiveEvent<T>` 集合**，可能触发教程分支；mod 已给 `IsTutorialIndexCompleted` 加兜底桩（`WF_OFFLINE_TUTORIAL_STUB=0` 可关）。
7. 🔴 **设置窗**：只有「全屏/窗口化」、**无分辨率列表**，窗口模式**不持久**；**「删除账户」会删本地存档（别点）**。启动参数 `-screen-fullscreen 0 -screen-width 1600 -screen-height 900` 最可靠。
8. 🔴 **`Latest.log` 不含 Unity `Debug.Log/LogError`**；真日志 = `%LocalLow%/Everguild/Warpforge/Player.log`，每次启动重写。
9. ⚠️ 旧坑沿用：`AddComponent/DestroyImmediate` 不触发生命周期；`Player.log` 被下次启动覆盖；`_tmp_view` 证据先拷再关。
