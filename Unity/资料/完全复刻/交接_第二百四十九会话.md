## 三、关键结论 / 判据

1. **坑 676**：`UnityWebRequest` 连「明文 + 非回环」会卡死在 `SendWebRequest`（https/127.0.0.1 正常；
   补 networkSecurityConfig 与 usesCleartextTraffic 均无效）⇒ LAN HTTP 走 **Java 桥**；
   Java 侧只放行私有/回环 IP。`lan.js` 按 URL 自动分流；mmqueue/reconnect 已接。
2. **坑 677**：游戏在**登录期**就自己连 Photon，阶段 B 装 hook 太晚 ⇒ 两端各自 create 同名房。
   修：photon 挪阶段 A（找不到类 1.5 s 重试）· 游客+已配置 LAN ⇒ 先连房主 · 装好后读 `ServerAddress` 复查重连。
3. **坑 679**（经典才暴露）：① `/__mm` 在 LAN 模式所有操作都要 `room=`；② 经典连调两次入队，
   第二拍 `fresh=1` 清掉刚配到的 matched ⇒ 同模式 1.5 s 去重；③ LAN 可达性不能带 TTL 重算（改粘性），
   否则进房瞬间 `backend lan→none` 把队列 stop 掉。
4. 房间键 = 两次 FNV-1a 32（UTF-8）拼接；`testpass123 → d30ea1b8e15cdbee`。
5. 安卓 `photonHost`：游客 + 有 LAN 配置 ⇒ 一定走房主（早期未知也先连房主），主菜单重算后「已登录+云可达」再切回云。
6. PC 端 `WF_LAN_ROOM` 非空 = LAN：不记排位/统计；`SetHost`/`SetLanBase` 可在界面保存后即时生效（下次连接/入队）。
7. PC 支持页原版内容隐藏必须放在**模板检查之后**（否则模板缺 ⇒ 空白页）。
