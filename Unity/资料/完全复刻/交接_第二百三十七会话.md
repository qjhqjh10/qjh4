## 四、关键结论 / 判据（新会话直接用）

1. **换账号三件套**（坑 608）：身份（`playFabId` + `WFIdentity.adopt`）· 存档（`adoptAccountSave`）·
   游戏内存（`playFabId` + `playFabEmail` + `SetLoginData`/`SavePlayerData`）；顺序 **先 `LoadPlayerData` 再保存**。
2. **账户页已登录判据 = `PlayerDataManager.playFabEmail`(0x348)**（坑 609）。
3. **设了登录数据后原版会走 `LoginWithEmailAddress`**（坑 610）⇒ 假服务端必须有该模板。
4. **桥的 `implementation` 只有 setter**（坑 611）⇒ 后置用 `Interceptor.attach`；`FindObjectOfType<AccountTab>` 取不到，
   在 `Refresh/OnOpen` 后置钩子里记实例。
5. **`adb input text` 进不了 TMP 输入框**（坑 612）⇒ 文件命令通道填字段，按钮真实点击。
6. **媒体备份恢复会带回旧身份**（坑 613）⇒ 恢复时删三个身份键。
7. **服务端管理接口要 `admin=1`**（查询参数），令牌在 URL 前缀里。
