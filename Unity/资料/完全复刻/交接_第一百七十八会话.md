## 三、`OFF-189` 做了什么

### 3.1 用户口径（2026-11-14 原话）

### 3.2 实现（新探针 `Probes/DraftBotButtonProbe.cs`，`WF_OFFLINE_DRAFT_BOT_BTN=0` 关）

| 步骤 | 做法 |
|---|---|
| 挂点 | **`SearchingMatchWindowDemo.OnEnable`**（+ `SearchingOpponentWindow.Open` 兜底）—— 实测真正弹的是 **Demo 那扇**（坑 239） |
| 闸 | 只在选秀（`matchType==110` / `playMode==7`）显示；`OnEnable` 时 `matchData` 还是 null ⇒ 挂起、`Tick` 最多重试 40 秒 |
| 按钮 | 克隆原「取消」→ 写「人机」→ `RemoveClickListeners()` + `onClick.AddListener` 绑自己 |
| 点击 | 原版 bot 出口 `ChangeToBotBattle(matchData)` → `SetBotOpponent()`（110 → **120 ClosedDeckBot**）→ `MoveToBattleRoom`（`playingOfflinePvp`，不碰 Photon）；再照原版 `if (!CanMatchWithHumans) FinishedLeavingBattleSearchRoom()` |
| 🔶 自设计 | 按钮文案/位置/只在选秀显示；**并且吞掉选秀的 `MatchMakingError`**（否则弹窗 43 ms 就关掉搜索窗、按钮点不到，坑 240） |
| 布局 | 父容器 `VerticalLayoutGroup` **只能 Destroy**（坑 241）；两颗按钮 `localScale` 等比缩到 0.797 + 按「锚点是容器左下角」补居中偏移（坑 242） |
