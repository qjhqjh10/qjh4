### 2·4 附加：卡组编辑里「怎么正确加卡 / 删卡」

**判据 1 —— 满 30 一定加不进去（原版行为）：**
`CardDeck.CanAddCard` 末尾（`cpp2il/…/CardDeck.cs:882-888`）：
```
int num5 = EmptySlotsCount();
if (num5 > 0) return true;
term = "MenuDeck/Tip/DeckFull";
```
`EmptySlotsCount` = `30 - cardLibrary.Count`（`CardDeck__EmptySlotsCount.c`）⇒ 30/30 时恒为 0 ⇒ 拒绝并 `UIMessageController.ShowError("MenuDeck/Tip/DeckFull")`（`DeckEditingWindow.CheckCardDrag`，`:1403-1436`）。**先删一张主牌再加。**

**判据 2 —— 拖拽方向决定「拖卡」还是「滚列表」（这条最容易踩）：**
`SupportMethods.IsScrollDragThreshold(Vector2 delta)` 的真身（`decomp_full/SupportMethods__IsScrollDragThreshold.c` + 常量：
`0x1834b30c0 = 60` · `0x1834b3268 = 120` · `0x1834b2e98 = 57.2958`(=180/π)）：

```
参考向量 = Vector2.right (1,0)                     // cpp2il 里明确是 Vector2.rightVector
角度 = acos(clamp(dot(delta,right)/|delta|, -1, 1)) * 180/π
return 60 < 角度 < 120;                            // =「偏竖直的拖拽」算滚动
```
- **竖直方向拖（60°~120°）= 滚动列表**，`CheckCardDrag` / `CheckCardSlotDrag` 会直接把 target 设成 ScrollRect；
- **水平方向拖（<60° 或 >120°）= 拖卡**，才走真正的加/删。

实测吻合：10:52:18 那次「从左栏拖出去」是水平拖 ⇒ `sfx.tsv` 有 `CardStartDrag`、`menulayout.tsv` 没有 ScrollRect 记录；10:52:42 那次「从卡池往左栏拖」是竖直拖 ⇒ `menulayout.tsv` 记 `DRAG-BEGIN Scroll View` + `DRAG #1..#6`，而 `sfx.tsv` **没有** `CardStartDrag`。

⇒ **正确手势**：按住卡 → **横向**（往左/往右）拖出至少几十像素再松手；不要上下拖。
