- 「备注里有状态断言」= `保持X / 维持X / 维[护持]X / 仍判X / 仍是X / 还是X / 暂定X / 暂判X / 先按X / 建议等级=X` 这类**肯定式**措辞，且 **X ≠ 状态列**（正则见 §附录 A）。

- **A / B 之分** = 备注里**最后一条**状态断言落在哪一档：等于状态列 ⇒ A；不等 ⇒ B。另外两种情形也归 A：**状态断言之后**出现 `推翻/已过期/作废/覆盖/撤回`；或「差异」列里出现**比冲突句更晚**的日期（说明这一行后来被重写过、只是备注没清）。
