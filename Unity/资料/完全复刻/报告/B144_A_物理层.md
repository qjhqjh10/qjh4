## 二 · 本轮改了什么（改前 / 改后 / 判据）

### 2·1 `ArenaBuilder.BuildSceneTail` —— 独立战场场景的 `BoardCamera` 七格

| 格 | 改前（Unity `Camera` 构造默认值） | 改后（原版 `Camera &1461`） |
|---|---|---|
| `m_ClearFlags` | `1`（Skybox） | `2`（SolidColor） |
| `m_BackGroundColor` | `(0,0,0,1)` | `(0.028763004, 0.028794324, 0.029411793, 0.019607844)` |
| `m_Depth` | `0` | `−1` |
| `m_CullingMask` | `4294967295`（全层） | `1137` = 位 `{0,4,5,6,10}` |
| `m_HDR` | `1` | `1`（不变，显式写出） |
| `m_AllowMSAA` | `1` | `0` |
| `m_OcclusionCulling` | `1` | `0` |

**判据**：`Battle Arena 1.unity` 的 `Camera &1461`（逐格现读）。
**⚠️ 为什么掩码这里是「照抄 1137」而战斗场景是 `1<<8 | 1<<10`**：独立场景这条路**不做整树刷层**，
内容留在**层 0**（现读 `battlearena1.unity`：121 个对象层 0、1 个 `CardLowBoardLimit` 层 11）——
与原版同层，所以 1137 逐位有效。⛔ 换成 `1<<8|1<<10` 会让 121 个层 0 对象**一张都不画**（预览图全黑）。
（这条「两个载体两套层号」本身是 #13 的副产物，已记在 §五-3。）

### 2·2 `ArenaBuilder.BuildOneArenaPrefab` —— 刷层段保留原版非零层

* 新增 `OriginalNonZeroHostLayers(mf)`：从清单 `tapHits[].layer` 取**非 0** 的宿主名（每场恰 1 条 `CardLowBoardLimit` = 11）。
* 刷层循环改为：名字命中 ⇒ 用**原版层号**，否则照旧 → `ArenaLayer(8)`。
* 为什么层 0 的宿主**不能**跟着回 0：它们**有** `MeshRenderer`，回 0 会被透视相机整颗丢掉。
* `VerifyTapHostLayers` 同步放宽「条件②」：允许 `layer == 清单原版层`（**只按清单给例外，⛔ 不设名字白名单**）。
  兜底：自检被单独调、`_origHostLayersByScene` 没填时，从 `LoadManifest(scene)` 现读（⛔ 不退化成「一律按层 8」）。

### 2·3 `ArenaBuilder.RestoreInactiveCardBodies` —— `Cache Stealth` 的 3D 卡体
