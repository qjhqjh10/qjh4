## 五、顺手发现（⛔ 不许静默）

1. **`--booster-shaders` 与 `--prefabs` 用的是同一个源包**（`boosterpacks_assets_all.bundle`，27 MB）——
   两者**互不覆盖**（一个写 `wf_boosters_extra`、一个写 `wf_booster_shaders`），但**都依赖源包**：
   哪天源包被换版，**两个产物都得重跑**。`--check` 两支都能单独体检（本模式那支打印「含 Booster Pack 的 shader 个数」）。
2. **产物的内层 CAB 名 = `CAB-68791fd68434784bd588e5ce344e6773`（与源包同名）** —— 工具本来就会印那段警告。
   本工程运行时**从不加载源包**（`WarpforgeShaderLoader` 只加载 `StreamingAssets/WarpforgeVFX/` 下 6 个产物），
   ⇒ 安全；⚠️ 但 `B97W23Assert` / `B97W29Assert` 这类**编辑器探针**若将来为了「A/B 对比」把源包也 `LoadFromFile`，
   **会整包被拒收**（症状 = `LoadFromFile` 返回 null + `another AssetBundle with the same files is already loaded`）。
3. `WarpforgeShaderLoader.LoadShadersFrom` 对同名 shader **只保留第一个**（`:220` 的 `if (!_byName.ContainsKey(...))`）——
   所以「第六条 `LoadOne` 会不会被前面的包顶掉」取决于**名字唯一性**。本 shader 名全库唯一（源包内 1 个），已核。
4. `BoosterPackAssets.PrefabNames` 与导出器原来那 17 条**逐条相同、顺序也相同**（逐条比过）——
   所以这次转调**零行为变化**，只是把表收到一处。
