## 6 顺手发现（铁律 13·4⑧ + 14；已在 `.md` §六 落盘）

1. 🔴 **`CardScript.OnTurnStart` 的真实体比账里大得多**（→ 移交 **B4**）：**5 个 `OnTrigger`**（30/31/**230**/**46**/**440**）+ `ActivateMinion` **两次** + 清 `+0x58/+0x67/+0x48` + 隐身(trait 70) 清理并 `BroadcastUnitLoseStealth` + `trait 100/975` 置位 + `trait 455 ⇒ DestroyUnit`。旧账只写「30 再 31 两次」。判据 `decomp_full/CardScript__OnTurnStart.c:1-280`。
2. **`CardScript.OnTurnSetup` 会把`手牌卡` `cardState` 置 1**（`:19-21`；手牌两跳传 1、棋盘跳传 0）—— 「inHand 语义」**有实体副作用**，不只是个 flag（R5 施工时要一起做）。
3. **`MinionManager.BroadcastActivateMinion` 与 `ActivateMinions` 是同一份体差一句**（`RefreshOccupationSlots`）—— 做 R13/R17 时别写成两个独立算法。
4. **`CardScript.OnTurnStart` 里 `ActivateMinion` 调两次**（`:104`/`:120`）—— 只看 `MinionManager.BroadcastActivateMinion` 会漏掉「每张卡自己那次」。
5. 🔴 **同一条判据只落地了三分之一**：`BoardJumpIncludesPendingDeath` 名单里**只有 `GetsDarkPact`（= ObtainedMark）**，而 `ObtainedMark` / `ObtainedMarkerlight` / `ObtainedHuntMark` 三族在原版**逐行同形**（都无 `IsInPlay`）⇒ 后两条属漏登（R10）。
6. **`.c` 丢栈变量时可用「相对已知结构体拷贝的偏移」反推**（`BroadcastDeadUnit` 那两条）；**`out_il2csharp` 会泄漏相邻方法的局部变量名** ⇒ 两者都不能靠符号，要靠偏移。建议记进「判据源坑表」。
7. **`AreMinionsWithAmbush` 的消费者是「法力显示」**：有伏击单位时法力数字印 `?/{total}`（`ManaTypeHolder.ToggleCurrentMana`）—— 这条把「伏击」和「HUD 能量文字」连起来了，属 HUD 那条线也要知道的一条事实（我们已实现，见 `BattleDriver.AmbushHidesEnergy`）。
8. **`MinionManager.AddMinionOccupation` 的侧别选择有三层闸**（右表含卡 ∧ 右有位 → 左表含卡 ∧ 左有位 → 按 `GetNextSlotWithoutDisplacing` 的符号），不是简单的「哪边少去哪边」—— 补文档时别简化。
