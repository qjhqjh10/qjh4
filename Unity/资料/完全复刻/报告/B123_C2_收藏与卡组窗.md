## 一 `B121-COLL-24` · `Clear filters` 不看 `_cosmoFilter`

### 1·1 改前（三处各写一份，且都只读 `State.Filter`）

```
4806  bool clearFiltersOn = !State.Filter.IsEmpty;     // 显隐
8471  return !State.Filter.IsEmpty;                    // 命中闸（KeyLive）
7334-7337  ClearFilters()：只清 State.Filter          // 动作
```

而**页头 chip 的来源是另一份数据**：`RefreshHeaderChips` 在 `_tab == 2` 时用 `_cosmoFilter`（`:10320`）。
⇒ `B121-COLL16` 把 chip 建出来之后，卡背页出现「**有 chip、却没有 `Clear filters`**」——玩家可见的缺口，
不是当年注释写的「判据不足」。

### 1·2 改后（一个谓词，三处共用 —— 类尾 `:10394`）

```csharp
bool HdrClearOn { get { return _tab == 2 ? !_cosmoFilter.IsEmpty : !State.Filter.IsEmpty; } }
```

| 处 | 改法 | 位置 |
|---|---|---|
| 显隐 | `bool clearFiltersOn = HdrClearOn;` | `:4806`（连同 `:4801-4804` 那段「判据不足」的旧注释**同物理行**改写） |
| 命中闸 | `case "hdr_clear": return HdrClearOn;` | `:8471`（`:8458` 的 doc 同步） |
| 动作 | `_fltScroll = 0f; ClearCosmoFilterKeepOwned();` | `:7338` → 方法本体在 `:10400` |

`ClearCosmoFilterKeepOwned()`（`:10400`）：

* `_tab != 2` ⇒ 直接 return（卡牌页不碰卡背那份）；
* 否则 `_cosmoFilter = DeckFilter.None` 再**把 `Owned` 抄回来** —— `Owned` 是**开关**、不是 `filters[]` 一项
  （与 `ClearFilters` 里那两个开关同口径，原版 `showOnlyOwnedCards` 只有一个写点）；
* 连**刷新**一起收口（`RefreshCosmoFilters()` + `RefreshCosmetics()`），`RefreshHeader` 由调用点补。

### 1·3 🔴 顺手补的一处（本条的必然配套，`ApplyCosmoFilter` 尾）

`ApplyCosmoFilter` 原来只刷抽屉与卡背格（`:7951-7959`）、**不刷页头** ⇒ 点完一个阵营，页头 chip 与这颗钮
要等**下一次别的刷新**才出现（=「点下去没反应」类静默）。已在 `:7960` 同物理行补 `RefreshHeader()`。

> ⚠️ 这一处**不是**本条派生出来的猜测：它与本条是**同一条链**（chip/钮都读 `_cosmoFilter`，都只在 `RefreshHeader` 里重算），
> 不补的话 A6 那条断言会红 —— 报告里如实记「属于本条」。

### 1·4 另一处同源的口径（`ClearFilters` 里 `:7337`）

```csharp
if (_tab != 2) State.SetFilter(f);
```

原版那颗钮清的是**当前那个 controller** 的 `filters[]` ⇒ 在卡背页点清空，**不该**顺手把卡牌那份也清掉
（否则「卡背页点清空 → 回卡牌页发现筛选也没了」= 原版没有的副作用）。断言 `A16` 钉住这一条。

### 1·5 与收藏窗那份对照

收藏窗**本来就自洽**：每页读自己 drawer 的 `State`（显隐 `CollectionWindow.cs:3740`、chip `:7187-7189`）
⇒ 本轮**没动** `CollectionWindow` 的那两处。卡组编辑窗是唯一不自洽的那一处（判据结论一致）。

1. **Ban 不能往下**：它必须高于**本格全部内容层**（`MenuDraw.cs:3820-3821` 的 `qBan` doc），本格内容顶 = `qOverlay` = `QDsHit` = **3129** ⇒ 只能 ≥3130。

   ⇒ 把 Ban 放那儿 = 「弹窗开着时 Ban 图标压在所有弹窗上」，语义错。
