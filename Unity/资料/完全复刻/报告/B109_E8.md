### 1·2 四维判定规则（逐条）

**① 引擎效果（动态）** —— 用 S3 的 `判定` 列按卡聚合：
1. 该卡 S3 **无行** ⇒ `未验到`（证据写「关键词卡：<keywords 用 / 拼>」）；
2. 有行但**任一行 `判定 ≠ 对`** ⇒ `未验到`（证据写「对 A/未验到 B；未验到族=族(trigger)」）；
3. 全对但 `all_dump.tsv` 的 `played ≠ 1` ⇒ `未验到`；
4. 全对且 `played=1` ⇒ `对`（证据写「通道=…」，通道取该卡各行 `备注` 里 `通道=` 之后那段；空备注跳过；一条都没有则记 `主档`）。

**② 特效（静态 S2）**：
1. `byCard[卡id]` 除 `_assetRefs` 外**没有任何桶** ⇒ `N/A`（证据回填 S1 的 `共用链VFX(非逐卡)` 列）；
2. 桶里有 `trigger_unmapped`（= 引擎没有发射口）⇒ **`错`**；
3. `ability` 桶且 `hasActiveAbility ≠ 1` ⇒ **原版不消费**（例外①）：只有该桶 ⇒ `N/A`，还有别的桶 ⇒ 其余照判、证据加「另 ability 桶 N 条 hasActiveAbility≠1」；
4. 其余：**全部有 `prefab` 的条目**都在工程 prefab 名索引里 ⇒ `对`；缺一个 ⇒ `错`。

**③ 动画（静态 S2）**：
1. `animTimes` 为空 ⇒ `N/A`（回源过：原版 `cardAnimations` 也没非空 GUID）；
2. `tg` 落在「无发射口」名单 ⇒ **`错`**（旧脚本：硬编码 `{81,700,695,647,291,701}`）；
3. `tg > 0` ⇒ 取**同一 `(卡id, tg)` 的 S3 行**：最后一行 `判定 == 对` ⇒ 过；否则 `未验到`；
4. `tg == 0` ⇒ 看 `all_dump.played`；
5. `tg == -1`（activeAbility 动画）且 `hasActiveAbility ≠ 1` ⇒ 原版不消费（例外①）；**全部**是 `tg=-1` 时判 `N/A`；
6. 以上都过 ⇒ `对`。

**④ 语音（静态 S2）**：
1. `voice_lines` 无该卡条目 ⇒ `N/A`；
2. 该卡有 `summonAudio/attackAudio/deathAudio/...` 的 **unresolved** 行 ⇒ `未验到`；
3. 至少一条 `src == cardSO` ⇒ `对`；只有 `none/orphan` ⇒ `未验到`。

**`数据来源` 列** = `S1全卡核验总表（1,128 卡骨架）` + `/S3:pool_diff4(w41s3b)`（有 S3 行）+ `/cards_engine` + `/card_vfx_by_card`（有桶）+ `/cards_engine.animTimes`（有动画）+ `/voice_lines`（有语音）。
**`备注` 列** = ②的备注 + ③的备注（`；` 连接）；另有 **3 条人工备注**逐字保留（`BL47` / `BL50` / `GOF2`，见脚本 `MANUAL_REMARK`）。
