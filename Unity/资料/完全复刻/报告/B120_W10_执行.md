## §Q7 `Card3DAnimationController.targetFrameRate`（`B120-Q07`）

### 判据（动手前现读）

- `decomp_full/Card3DAnimationController__Update.c:22-23`：`fps = Application.get_targetFrameRate()`；
  `if (1.0f / (float)fps + time < 0)`（`DAT_1834b2bb8` 实读 = **1.0**）。
- **原版没有静态值**，`fps` 由设置链写入：`GameStaticData.FPSLimit`（出厂 **2**，`GameStaticData__.cctor.c:212` 静态区 `+0x128 = 2`；
  `LoginManager.cs:217` 也写 2）→ `ApplySettingsOptions` / `ApplyGraphicsQuality`
  （il2csharp `PlayerDataManager.cs:10408-10459`，逐句 = **0→30 · 1→60 · 2→−1**）→ `SetTargetFramerate`（`PlayerDataManager__SetTargetFramerate.c` 末句）。
- 我们**自己已经照抄了这一映射**：`Shell/LocalPlayerData.TargetFramerateFor`（出厂 2 ⇒ −1），并且启动时会真的写进 `Application.targetFrameRate`。

⇒ **原版那一格的注释理由是错的**：「真包里恒为正所以取不到那个值」**不成立** —— 真包默认档**就是 −1**。

### 改前 → 改后

| | 改前 | 改后 |
|---|---|---|
| 式子 | `OneFrameSlack / fps + _currentAnimationTime >= 0f` 内联在 `Update` 里 | **抽成 `public static bool FrameSlackExpired(int targetFrameRate, float remaining)`**，逐字照抄、**不加钳制** |
| 调用点 | `int fps = Application.targetFrameRate; if (fps <= 0) fps = 60;`（🔶 且注释理由错） | **同左**（行为不变），🔶 标记改写成本轮的真实理由 + 指向本报告 |
| 注释 | 「真包里恒为正」 | 🔴 已就地订正（铁律 5），带出处 |

### 🔴 为什么「照抄」这一格要停手（反证）

`fps = -1` ⇒ `1.0/(-1) + remaining < 0 ⇔ remaining < 1`：
**剩不到 1 秒就当帧收尾** —— 时长 < 1 s 的动画会在**第一次 `Update` 就 `AnimFinished()`**。

现读我们自己的卡体动画时长表（`Resources/cardanim_clips.json`，`vd+ts+tm+te`，1067 条）：

| 区间 | 条数 | 占比 | 照抄 −1 档的后果 |
|---|---|---|---|
| ≤ 1.0 s | **881** | **82.6%** | **第一次 `Update` 就当帧收尾**（等于整层卡体动画不播） |
| > 1.0 s | 186 | 17.4% | 一律被砍掉**整整 1 秒**（中位数 0.75 → 最长 7.0） |

⇒ 这不是「尾巴差一点」的量级，而是 **卡体动画层整体失效**（而 `BattleScene` 里那一族「回调 / 收尾次数」断言也会跟着翻）。
**按派活包写的停手条件：「如果发现照抄会让我们动画全当帧收尾 ⇒ 停手写反证」** ⇒ **本轮不改行为，只把式子抽出来 + 订正注释**。

### 两个候选方案（请调度台择一）

1. **照抄**（铁律 18·0 默认）：删掉 `if (fps <= 0) fps = 60;`，`Update` 直接用 `Application.targetFrameRate`（含 −1 / 0 两档）。
   代价 = 上面那张表；且**真机也受影响**（我们启动就把 `targetFrameRate` 写成 −1）。
2. **保留 60 的钳制**（现状）：式子与判据同形，只有「一帧裕量」这一格是我们挑的。
   此时应收口成一句可机检的话：**「`fps <= 0` 时按 60 算」是 🔶 自己设计，理由 = 照抄会让 82.6% 的卡体动画当帧收尾**（已写进注释与账）。

> 我对两条都**不替调度台下结论**。若选 1，改动只有一行（删钳制），断言 B4 会自动仍然绿、B7 需按新行为重写（0.2 s 的拍在批处理里会**立刻**收尾而不是推 0.25 s 后收尾）。

### 影响

- **行为零变化**（本轮）——只把式子抽成公开静态方法 + 改注释；`Update` 走 `FrameSlackExpired(fps, _currentAnimationTime)`，`fps` 仍钳 60 ⇒ 逐位等价。
- 收益：**判据式子现在可被自检直接盯**（B4 会把「原版 −1 档的怪语义」断出来），下个会话不必再靠读注释。

### 断言

B1–B8；**B4 是灭自证**（给 `FrameSlackExpired` 加钳制 ⇒ 红）；**B8 是数据反证**（`cardanim_clips.json` 里 ≤1.0 s 的占比必须 > 50%，掉下去就说明「不该照抄」的前提变了、必须重裁）。
