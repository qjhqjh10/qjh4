## ③ 张数条 vs 卡体：真实前后序 —— **查到了**

**判据（新）**：`Card2DController` 的字段**全是 `UnityEngine.UI.Image`**
（`frame` / `frameHighlightAndShadow` / `cardBackImage` / `cardBackShadow` —— `d:/2/tools/cpp2il/out_cpp2il_dev_ilspy/Card2DController.cs:7-25`）
⇒ **原版卡体是 uGUI Image，不是 SpriteRenderer** ⇒ 与 `Counter`（也是 Image）在**同一张 canvas** 上
⇒ 先后由 **兄弟序 + 材质队列** 决定；prefab 兄弟序 = **`Counter`(0) → `CardUI`(1)**（`menu_dump … "Collection Card"`）
⇒ **原版是「卡体盖在张数条上」**。

**那为什么条还是看得见？** 因为 `2DCard` 的**框**（499.70 高）不等于它的**不透明区** ——
卡框/立绘在 `y > 461`（512 帧）那一段**是透明的**，条从那片透明区露出来。**这一条还没验**（见 ⑤）。

**我们怎么办（如实标 = 主动偏离）**：我们的 `CardView` 卡体是**实心块**（铺满 `2DCard` 那个框），
若照原版把条放到卡下面 ⇒ **`xN` 整条看不见**（比偏移更糟）。
⇒ **保留「条在上」**（`QPageRow` 3032 > 卡 3000），并把断言 ④ 的文案从「判据不可及 + 实拍佐证」换成
**上面这条真判据 + 「为什么我们仍取条在上」**（已改，`Editor/CollectionScene.cs`）。
