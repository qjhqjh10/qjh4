## 一、`B139-E3` — 治疗飘字底下那颗 `HealIcon`

**改前** `Core/CardView.cs:9162`（`BuildHealText` 内）只有 `_healText.gameObject.SetActive(false);` ⇒ 飘字只有 TMP，

`sprite Card Heal` · `localScale 0.56046` · `sortingOrder 100` · `m_Color.a 0.853`（恒定、无曲线）· 自身 `(0,0,0)`，
z 那一跳烘在**父件** `HealText` 的 `−0.05`。`Battle/PopNumber.cs:657` 那个 API 就按这四个数摆，且是「挂在**已存在的**
`HealText` 下、不乘飘字桥」那一档（与 `Pop()` 里「飘字根顶替 `HealText`」不同，见它的 doc）。
本次**只调 API**，没改 `PopNumber.cs`，没在本处重写位姿。

CreateAnim`）**只给一张卡**。

**为什么不是「Play 前后临时换一下」（这一条会把改动变成回归）**：`StealthEffect` 实读 `fade=1` +
`toggleMaterialOffOnExit=1` ⇒ `Exit()` → `ToggleMaterial(false)` → 补间播完把恢复交给 `ModuleTick` 的 `_restoreAt`

「材质换上去、永远换不回来」（比不换更糟）。同理**不能**就地写 `Resolver = _ => 我的卡`（会顶掉 `BattleDriver`
常驻那份、别的效果全读错卡）⇒ 所以是「按实例查表 + 转发外层」。

**`actingIsPlayer`**：原版读 `CardScript+0x40`，我们 `CardView` 无阵营字段 ⇒ 用项目既有兜底
`CardFeel.IsPlayerRow(世界 z)`（与 `ApplyDepthScale` / `PlayTweenDepthScale` / `UnitTweenTable` 同一条，⛔ 非新造判据）。
