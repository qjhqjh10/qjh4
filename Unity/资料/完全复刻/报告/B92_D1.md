## §1 一句话结论

**`_lastPose` 为 null**（不是 `cards`、不是 `hand`）。它是被 **`HandLayout` 的实例字段初始化器在 `HandLayout.cs:265` 抛异常中断** 弄成 null 的：
本会话 `B92_N5` 把 `hoverLift` 的初值改成 `HoverLiftPxForDevice / 108f`，而这个新的静态属性读 `Screen.dpi` ⇒ Unity 抛
`UnityException: get_dpi is not allowed to be called from a MonoBehaviour constructor (or instance field initializer)`
⇒ **构造器在 265 行中断**，声明顺序在其后的 `_lastSeen`(328) / `_nowSet`(329) / `_lastPose`(371) 的初始化器**一次都没跑**（保持 default = null）⇒
首趟 `Refresh` 第一句 `_lastPose.Clear()`（`:710`）→ NRE → `BattleScene.Run` 抛异常退出（return code 1）。

对象的**其余部分照样被建出来了**（Unity 只记日志、不中止场景构建）—— 证据：NRE 抛在 `Refresh` **内部**（栈顶是 `HandLayout.Refresh [0x00000]`），
而 `Refresh` 是从 `CardInteraction.cs:1600` 的 `hand.Refresh(...)` 进来的 ⇒ `hand` 非 null、`this` 非 null，纯粹是字段没初始化。
