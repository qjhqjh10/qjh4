   - 共同底层已经存在：`ImageQuad.SetUvRect(Rect)`（`Battle/ImageQuad.cs:534`，改 `_uv` + `RebuildMesh()`）。**缺的是「按 fillAmount 算 uv」这一层**，所以每个窗各写一遍 `new Rect(0,0,amount,1)`。
   - **建议的共享口**（一行签名，不实现）：
     ```csharp
     // ImageQuad.cs
     public enum FillAxis { Horizontal, Vertical, HorizontalReverse, VerticalReverse }
     public void SetFill(float amount, FillAxis axis = FillAxis.Horizontal);  // = SetUvRect(按 axis 裁剪)
     ```
