**命令① `.meta` 的 `isReadable` 按类别统计**
```bash
python -I -X utf8 -c "import io,os,re,collections
R=r'd:/4/Unity/MyGame/Assets/CardPresentation/Resources'
c=collections.defaultdict(lambda:[0,0,0])
for dp,_,fs in os.walk(R):

    c[k][0 if (m and m.group(1)==b'0') else 1]+=1
for k in sorted(c): print(k,c[k])"
```

**命令④ `.meta` 缺失 / 孤儿 / GUID 重复**
```bash
python -I -X utf8 -c "import io,os,re,collections
R=r'd:/4/Unity/MyGame/Assets/CardPresentation/Resources'
g=collections.defaultdict(list); miss=[]; orph=0
for dp,_,fs in os.walk(R):
  for f in fs:
    p=os.path.join(dp,f)
    if f.endswith('.meta'):
      if not os.path.exists(p[:-5]): orph+=1
      m=re.search(rb'^guid:\s*([0-9a-fA-F]+)',io.open(p,'rb').read(),re.M)
      if m: g[m.group(1)].append(os.path.relpath(p,R))
    elif not os.path.exists(p+'.meta'): miss.append(os.path.relpath(p,R))
print('缺 meta',len(miss),'孤儿 meta',orph,'GUID 重复',sum(1 for v in g.values() if len(v)>1))"
```
