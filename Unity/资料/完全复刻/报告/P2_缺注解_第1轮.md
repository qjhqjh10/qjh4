## 甲 · UIGradientUtils 两条

**a) 调用面审计（先做，结论：没有任何一处做过「手上补偿」）**
`CardArt.Gradient(...)` 全仓 8 个调用点，全部传 **188**（= 90 − 82 + 180）：

**b) `RotationDir` 到底返回什么（一手证据）**
`decomp_full/UIGradientUtils__RotationDir.c`：`uVar1 = FUN_180488130(θ)`、`uVar2 = FUN_1804886e0(θ)`，返回 `CONCAT44(uVar2, uVar1)` ⇒ **x = FUN_180488130、y = FUN_1804886e0**。
身份判定：`AnimFXModuleChangeVelocity.ParticleSystemVelocity__CalculateMaxHeight.c:50-58` 把 `FUN_1804886e0(angle)` 平方后代入 **v²·sin²θ/2g** ⇒ **FUN_1804886e0 = sin**、FUN_180488130 = cos ⇒ **RotationDir = (cosθ, sinθ)**。
我们 `CardArt.cs:775-776` = `rad = angleDeg·Deg2Rad; dx = cos(rad); dy = sin(rad)` ⇒ **同一约定**。
⇒ 有效渐变轴之所以是 (sinθ, cosθ)，来自 `CompensateAspectRatio` 里那次换位（下面 c），**与 RotationDir 无关**。原注解与工程记忆里那句「(sin,cos) / 差 90°」是错的（D 2026-10-25 已在 `DailyRewardPopup.cs:262-270` 订正过同一句，我没回头核它，这次补上）。

**c) `CompensateAspectRatio` 是真缺口（降 C / P1）**
`decomp_full/UIGradientUtils__CompensateAspectRatio.c` 现读：`local = (rect.h/rect.w) × dir.x`，再 `(dir.y, local)/‖·‖` ⇒ 返回 **normalize(dir.y, dir.x·h/w)**（把方向按矩形宽高比拉回来）。
我们的 `CardArt.Gradient` 在**正方 128×128** 上按 `|dx|+|dy|` 归一化生成贴图，再由 quad 拉伸到矩形 ⇒ **没有这一档**。

**补它 = 改 `Gradient` 的签名与 8 个调用点**（其中 `Deck/DeckRuntime.cs` 不在白名单）⇒ 记 C/P1。
