## 四、判据证据（本批**新查**的部分）

### 4.1 `SetQuestPointsWithDelay` —— 为什么是「值即时 / 演出延后」两层

- `decomp_full/PlayerManager__AddQuestPoints.c`（全文现读）：先把 `qp + n` 写回引擎（`+0xc4..+0xd4` 五个 int 的 `ObscuredInt`），紧接着
  **`ManaManager__SetQuestPoints(manager, qp, 阈值, animate: 0)`** —— 参数 4 = `0` ⇒ 这一跳**不弹**。
  之后才 `StartCoroutine(PlayerManager__SetQuestPointsWithDelay(delay, finishCallback))`。
- `decomp_full/PlayerManager._SetQuestPointsWithDelay_d__43__MoveNext.c`：
  `state 0` = `UnityEngine_WaitForSeconds___ctor(delay)`；`state 1` = 按
  `matchData+0xa8`（GameplayVariablesData）的 `+0x4b`（`alternativeTraitLogic`）二选一取阈值
  （`scenarioVariables+0x30` / `+0x2c`）→ **`ManaManager__SetQuestPoints(…, animate: 1)`** → 调 `finishCallback`。
  ⇒ **只有这一次带 `animate: 1`**，它才是「弹跳 + 降向特效」那一跳。
- 两档 delay 的实参（`AddQuestPoints.c` 两个 `LAB_18063d3fc` 上游）：
  **非结算支**（`qp < 阈值`）`uVar6 = DAT_1834b2bb4` = **0.5**；**结算支**（`qp >= 阈值` ⇒ 先 `qp -= 阈值`、
  再 `RawCardScript.OnQuestResolved`）`uVar6 = DAT_1834b2bb8` = **1.0**
  （字面量值由 `B92_B8` 用 `工具/read_literal.py` 实读：`0x1834b2bb4` = 0.5 · `0x1834b2bb8` = 1.0）。
- 我们这边的「结算支」可观测判据 = **余数变小**：结算支必然把整整一个阈值从余数里扣掉，
  而一次加的 `n` 远小于阈值 ⇒ 存回去的值**必然比原来小**；非结算支则**必然变大**。两条互斥。

### 4.2 `StopAnimsInPlay` —— 三步语义

`decomp_full/CardScript__StopAnimsInPlay.c:5-6` ＋ `BattleCardUI__StopAnimsInPlay.c:1-60`：
① `CleanStatusAnims(true)` ② 倒序销毁 `activeAnimsInPlay` 逐件 + `Destroy(summonSicknessFrame)` ③ 清表。
语义 = **销毁那批场上过渡对象**，不是复位位姿。我们的等价物 = `CardView.StopInPlayAnims()`：
① `CleanStatusAnimsClearAll()` ② 「那批过渡对象」在我们这边**就是 DOTween 补间本身**（无临时件）⇒ `DOKill` 遍历
③ `summonSicknessFrame` 是**空 AssetReference** ⇒ 无对应物。

### 4.3 `RemoveSelfBuffsFromQueues` —— 只撤 `playAnim`

`decomp_full/BattleManager__RemoveSelfBuffsFromQueues.c:5` = 一句转调
`CancelEffectsFromDisappearingUnit(this, card, card, shouldIgnoreDestroy: 1)`；

## 五、没查清

1. **586 的「中间值」那一格**（如实记，⛔ 不当已复刻）：
   原版结算支里，`qp` 会**先按「满阈值」的值显示**（`SetQuestPoints(qp, 阈值, animate:0)`，此时 `qp >= 阈值`），
   一秒之后才落到余数。我们引擎在 `RuleCore.QuestPointStepFor` 那侧**已经把阈值扣掉**，
   HUD 读到的只有余数 ⇒ `n >= 阈值`（一次加满）这种情形我们**不弹**（原版会先弹到满再落）。
   要补得让引擎把「扣阈值前的值」一起带出来 —— `RuleEngine/**` 不在本件所有权。
