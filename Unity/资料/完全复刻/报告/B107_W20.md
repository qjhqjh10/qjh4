## ⑤ `RewardsWindow` 为什么保持「全不绑」（不是漏做）

- 判据陷阱（`B106_AUD03` §2·0）：`OnLanguageChanged(){ if (Label.RelocalizeUnder(transform) == 0) Open(); }` ⇒ **一个窗只要绑了 ≥1 颗，就再也不会走整窗重建**；未绑的标签会**永久停在旧语言**。
- 本窗**正文由 `MissionsTab` / `CampaignTab` / `ForgeTab` 三页各自建**（`RewardsWindow.BuildTabContents`），那三份**都没有 `BindText`**，而且**不在本笔白名单**。⇒ 只绑左栏 3 颗页签 = 页签变、正文停旧语言 = **半绑比不绑更糟**。
- 0 绑定这一路是**通的**：换语言只发生在 `SettingsWindow.ChooseLanguage`（`Shell/SettingsWindow.cs:3775`）—— 它 `SetLanguage` 之后会**遍历 `Manager.openWindows` 逐个调 `OnLanguageChanged()`**（`:3783-3792`）⇒ 开着的奖励窗走 `RelocalizeUnder==0 ⇒ Open()` 整窗重建；换语言时没开着的窗，下次 `Open()` 本来就按新语档建。
- ⛔ 要「只重取不重建」，必须**连同三页正文一起绑**（那是一个跨 3 个文件的活，`判据/B106_AUD03.md` §2·3 #6 已记）—— 交调度台另派。
