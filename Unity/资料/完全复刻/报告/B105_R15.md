## 三、关键发现（本轮新查，按铁律 5·b）

1. 🔴 **5 个 VFX 输出材质的 shader 悬空，现有重绑器管不到**：
   `_shared/Hidden_VFX_Aeldari Dust_System_Output Particle Unlit Quad.mat` 的 `m_Shader` guid = `f2642f61…`，
   工程 `*.meta` **0 命中**（Portal 四条同理）；而 `ArenaOriginalShaderRebind` 只遍历 `GetComponentsInChildren<Renderer>`（`:135/:179`），
   `ArenaOriginalShaderIndex.cs:66-68` 自承「这 5 个由 VFX Graph 资产引用，树里碰不到」⇒ **验有、重绑没有**。
   **后果：装了 VFX 包，Aeldari 也渲不对。** 两条修法：材质资产级重绑 / 按 `B101_R3` §B-3 手写 6 个 shader（二选一）。
2. ⚠️ **订正 `B101_R3` §B-3 的适用范围**：「6 个输出 shader 全缺」只在【工程 `.shader` 资产】口径成立；
   **运行时按名取原件这条链 6/6 都已随包**（5 在 `wf_arena_shaders`、Gargoyle 那个在 `wf_shaders_extra`）。
3. ⚠️ **R4 清单的「我们有没有用」列不可当「我们在用」**：75 条 `无独立名字（经引用者）`、72 条 `已用（数据表）（经引用者）`
   都是**沿引用者继承**的（生成器 `_tmp_view/wfres/r4_shaders.py`），验的是原版侧引用者，不是本 shader。
4. ⚠️ **自建 shader 目前全是兜底**：`WarpforgeShaderMap.UseOriginal` 65/65、`Replacements` 32/32 的键**都已随包**
   ⇒ 正常态下一个自建件都不会被解析到。⛔ 别拿自建件当「在用件」验收。
5. ⚠️ **ComputeShader 没有 Ruri 退路**（Ruri 只反编译 `Shader`）：要重建内核逻辑只能反汇编 `uniqueVariants[].code`（DXBC/DXIL），
   本机**没有 CS 反汇编入口**。好消息：VFX 内核是编译产物，**直接拷 `.asset` 即可，不用重写**。
6. ⚠️ **20 个第三方 shader（UI Extensions 19 + MeshBaker 3 + UI/Particles/Hidden）只在 `globalgamemanagers#5/#13`（Always Included）里**，
   **0 个 Material/prefab/场景引用** ⇒ 可以明确判「内容没用」。
7. ⚠️ **`B101_R3` §B-4 的三个行号已漂**：现读 Leviathan `34305 / 44178 / 83372`、Saim Hann `168211`（原文 `44011/80002/80129`）。
8. ⚠️ `Saim Hann Infinity Circuit Overload.prefab:168211` 的 `m_Asset` 指向的是 **Aeldari Portal**（pid `-6218776015286680102`），**不是 Gargoyle**
   —— 那 1 处是「Aeldari Portal 也没接上」，修起来比 Gargoyle 简单（资产在工程里，只缺 guid）。

## 五、没查清（如实记）

1. **装包后 Aeldari 是否真恢复**：需要 A0 判定 + 起 Unity；本件只读、没跑。
2. **VFX Graph 是否接受运行时换过 `shader` 的材质**（走「材质级重绑」那条修法的前提）：要实测。
3. **`40k_battle_fx_gargoyle.png` 是不是 flipbook**（512×512 · alphaIsTransparency=1，帧布局没核）⇒ 影响手写 shader 的 UV 动画；
   原版那份输出 shader 是 **Dummy（772 B）**，静态判不出。
4. **两个 Texture3D 的切片方向**（z 递增自上而下还是自下而上）—— 要摆一次图看 SDF 有没有翻（B101_R3 已记，本轮未动）。
5. **`GenSdfRayMap` 到底属 URP 还是 VFX 包**：本机两个 PackageCache 都没搜到（只有 `VrsTexture` / `ProbeVolumeSamplingDebugPositionNormal` 命中 URP/Core），
   结论按「随包版本提供、不属游戏内容」写，**没有更强的证据**。

## 七、覆盖边界

- 覆盖：`R4_Shader_VFX_清单.tsv` 全部 **261 对象** × 三族；我们侧证据 = 随包 bundle / `WarpforgeShaderMap` / `WarpforgeShaderLoader` /
  `ArenaOriginalShaderIndex` / 效果 prefab `shader:` 字段 / `.cs` 字面量与 API 调用 / 工程 `.meta` guid 反查。
- **不覆盖**：Shader 的视觉正确性（要真机）；清单外的 Shader/ComputeShader（若有漏，需重跑 `r4_shaders.py`）；
  VFX Graph 运行时行为；`d:/2` 以外的原版来源。
- 「账的覆盖边界」（项目口径）：本件是**资源清单定性**，不是复刻账；
  代码账 / 资源账的数字与本件无关，⛔ 别把本件的 261 当成「已经复刻完的资源数」。
