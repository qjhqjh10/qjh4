## 一 真缺口（C · 21 条，一句话一条）

### 菜单/外壳（6）
1. **`EverguildButton.SetUpButtonColors`**（P1）— 原版灰化有 per-instance 闸（`colorTintGreyOnDisable && m_Transition==ColorTint`），我们无条件灰。**普查 880 颗里 34 颗 `grey=0`、570 颗不是 ColorTint**（含 555 SpriteSwap）⇒ 这些原版不灰我们会灰。落点 `Shell/WindowButton.cs:933`。
2. **`EverguildToggle.SetUpButtonColors`**（P2）— 同族，且 Toggle 族 over-apply 面更大：**153 颗里 95 颗 `grey=0`**。
3. **`EverguildLayoutGroup.CalculateSpacing`**（P2）— 原版 `spacing = (容器 − n×子件)/(n−1)`，只在 **3 个 prefab 的 `steps`**（`Missions Tab` / `Weekly Mission Container` / `Rewards Base Submenu Variant`，均 `evenlySpaceinBetween=1`）；我们把里程碑 `spacing` 写死 20 ⇒ 子件数一变（4↔5 档）就不对。
4. **`EverguildTextMeshPro.UpdateTextSizeSmallScreen`**（P2）— 原版小屏档**只改字号**（683 个 TMP 里 **86 个** `smallScreenMaxFontSize>0` 是活的），我们**整窗缩放** ⇒ 行高/换行点不同。
5. **`ParentConstraint.Sync`**（P2）— 主菜单那颗 `Front`（`inheritScale=0`、Update 档、target = `Level Up Effect`）在我们这棵卡面树里**没有同名跟随**；`CardPrefab/EffectAnchor` 那档挂父级已等价。
6. **`UIGradientUtils.LocalPositionMatrix`**（P2）— 原版投影后**直接 clamp01**；我们多了一次满量程重映射（`/ (|dx|+|dy|)`）⇒ 45° 那类非轴向渐变**色带宽度/端部饱和**不同（已核 `CompensateAspectRatio` 那档是对的）。
