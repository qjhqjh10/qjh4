### 4·1 方法

1. `t5` 与 `t12` 是**同一机位、两个不同时刻**（文件名标签差 7，按拍摄脚本口径 = 相隔约 7 秒）的两张原版实拍；
   两者互比 ⇒ **只可能差在「会动的东西」上**（= 粒子）。⚠️ 标签到秒数这一步**没有独立判据**，本报告只用「相隔若干秒」这个定性事实。
2. `align()` 求平移：**13/13 场全部 `(0,0)`** ⇒ 相机没动，两帧可直接逐像素比。
3. 平滑（σ=6 @640×360）+ 阈值 8 ⇒ **动区掩码**。静区的平均差 = **原版自己的噪声地板（0.2–1.1）**。
4. 我们 vs `_t5`（对齐 + `rank_match` + 同款平滑）⇒ 逐像素差，**按动区/静区拆成两块**。

### 4·4 判词（**这是尺子，不是缺陷**）

1. **任何逐像素结论，落在动区里的那部分一律不可信。** 按上表：`leviathan` 有 **49.3%** 的差、
   `blacklegion` 29.9%、`tauviorla` 28.9%、`aeldari` 24.2%、`arena1` 21.0% 都**落在 7 秒内会动的区域里**。
   `astramilitarum` 只有 3.3%（动区仅 0.8% 面积）⇒ **它的差几乎全是真差异**，是 13 场里最"干净"的一把尺子。
2. **`A1615` 的「没有正确秒数」得到独立佐证**：`t5↔t12` 之间，**原版自己**在动区的平均差 = **11.7–20.7**，
   而静区只有 **0.2–1.1**。我们只推进 `WF_PSSEC = 2.0` 秒，**不可能同时命中任意一个原版相位**。
3. **我们的差不是「停在某一个相位上」**：`我们vs t5` 与 `我们vs t12` 两列逐场只差 0.0–0.6
   （对照：「两原版帧互差」1.0–3.5）⇒ **换一个原版相位解释不了我们的差**，剩下的就是真差异。
4. **`T05` 那团火整块 100% 在动区**（`t5↔t12` 该块平均差 **21.9**）⇒ **对它做单帧 max 比较天然带 ±7 级以上的噪声**
   （原版四个相位 190.0 / 195.3 / 197.7 / 204.2 就是实测噪声带）。
5. **建议固化成工具前置**：以后任何「我们 vs 原版」的逐像素候选，**先扣掉动区掩码**再排名。
   现在的 `arena_diff.py` 用的是「多相位取中位」，而**相位图只剩 3 场且是 10-12 的**（§〇）⇒ **它现在等于没有防护**。
   本报告这套 `t5/t12` 互比**只用原版自己的两帧，不依赖我们的相位图**，可以立刻替代。
