## ① 判定口径（这是本步最重要的一件事）

协调人给的判据：**「这条断言能不能抓住被测对象改坏」** —— 不是「写法像不像自证」。据此把候选分成五档：

| 档 | 含义 | 要不要动 |
|---|---|---|
| **恒真自证** | 「`实际`」与「期望」在结构上**永远是同一个值**（同一个函数、同一条派生）⇒ 改什么都绿 | 🔴 必改 |
| **要改** | 期望值来自一个**判断性函数**（规则/映射/格式），而**这个函数自己没有被任何字面量钉死** ⇒ 这条证明不了它对 | 🟠 补一条字面量 |
| **假阳·源已有字面量** | 同源，但那个函数**在别处**已经用字面量钉死 ⇒ 这条只是冗余复核 | 不动 |
| **委派** | 「A 必须等于 B，因为 B 是唯一实现」——**正确写法**，⛔ 不算自证 | 不动 |
| **假阳·外部数据 / 前后·复现·结构** | 期望读的是资产/表/存档，或比的是「变没变 / 同种子是否一致 / 父链结构」 | 不动 |

## ④ 改了什么（只改了普查脚本，⛔ 没碰任何断言文件）

`工具/assert_selfproof_census.py` 加了**一条**规则：**三元表达式不拆**。

```python
# 形状 C 里：含 `?` 的子句直接跳过（含 3 参形态 want 里的 `?`）
for cl in clauses:
    if "?" in cl:
        continue
```

**为什么必须改**：`Check(kept == null ? -1 : kept.Count, 1, "…")` 这种写法，在深度 0 上第一个 `==`
落在 `?` 前面 ⇒ 拆出来的「期望值」是 `null ? -1 : kept.Count`，被当成「来自工程调用」的变量报出来。
本工程里这类有一批（`C8_Assert.cs:150` · `RuleEngineTest_N1.cs:515` · `RuleEngineTest.cs:34743` ·
`:9309` · `:21567` · `:24654` · `RuleEngineTest_S23_Parse.cs:119` 等）。

| 读数 | 改前（509 文件） | 改后（511 文件） |
|---|---:|---:|

| 其中「实现本体」 | 298 | **280** |
