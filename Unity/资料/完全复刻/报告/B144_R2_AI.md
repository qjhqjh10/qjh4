## 二、改动（3 处代码 + 4 处注释；零净行数变化）

### 2·1 `SimpleAI.cs:958` — `ScorePoisoning` 改读 `StunnedAtStartOfTurn`

```diff
- float f = target.IsStunned ? 0.8f
+ float f = target.StunnedAtStartOfTurn ? 0.8f   // 原版读 `+0x55 = stunnedAtStartOfTurn`，⛔ 不是 IsStunned
```
**判据**：`decomp_full/AI__ScoreFromPoisoning.c`（全文）——
`fVar7 = DAT_1834b2fa0`（0.8）；`if (*(char *)(param_2 + 0x55) == '\0') { … cantAttack ⇒ 0.5；否则 health < 3 ⇒ 0.2，≥3 ⇒ 0.5 }`。
`+0x55` = `stunnedAtStartOfTurn`（B134 §二 #33 已按指令流 0.8/0.2/0.5 三个常数复核）；`IsStunned`（`Has(stun 100)`）是**另一个量**——本回合中途被眩晕时 `IsStunned=真 / StunnedAtStartOfTurn=假`，原版给 0.5/0.2，我们原来给 0.8。
**可观测性**：池内 `poisonous` 0 张 ⇒ 今天零行为变化（B134 已记）；改的是「以后有卡时不再错」。

### 2·2 `SimpleAI.cs:1001-1002` — `TraitScore` 的 `camouflage` / `longrange` 1.5 → 1.0

**判据**：`判据/AI打分与动作选择_第2轮.md` §6·6 的 `ScoreFromBuff` trait→分表（`AI.cs:1807-1965` 实读）：
`camouflage` / `longrange` 属 **1.0** 组（`ward camouflage longrange unstoppable flying …`）；**1.5 组**只有 `stealth / sneakAttack / sacrifice / pack`。
**可达性**：`TraitScore` 只被 `PayloadScore`（`ScoreOps` 的 `give/gain` 载荷）与零调用点的 `KeywordValue` 使用；现池 `give` 载荷里**没有** camouflage/longrange（现扫 `desc/descZh` 的 `give|gain` 短语）⇒ 今天零行为变化，但表值必须与原版一致。

### 2·3 `SimpleAI.cs:2196-2197` — `MightAttackBuffedCard` 补第三闸 `cardState == 2`

```diff
- if (u.Attack + meleeDelta >= 1) return true;
- return u.RangedAttack + rangedDelta >= 1;
+ if ((u.Attack + meleeDelta >= 1 || u.RangedAttack + rangedDelta >= 1) && u.CardStateOf(ctx) == CardStateOptions.inPlay) return true;
```

**判据**：`decomp_full/BattleManager__MightAttackBuffedCard.c:10-27` —— 三闸 = `mightAct` ∧（`CurrentMeleeAttack + buff+0x48 ≥ 1` **或** `CurrentRangeAttack + buff+0x50 ≥ 1`）∧ **`*(int*)(card+0x228) == 2`**（严格等于 `inPlay`）。
