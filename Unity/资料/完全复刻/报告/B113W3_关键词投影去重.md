## 一、根因（复述一句，判据不在这里抄第二份）

生产端 `EffectResolver.ApplyOneGain` 的限时档（`EffectResolver.cs:12454-12472`）**同时**做两件事：
① `ApplyTraitEffect(...)` 往 `_traitEffects` 里落/并一条 `TraitEffectRecord`；
② 把**同一条记录**挂到 `TempBuff{TraitRec = appliedTrait}` 上。
投影 `EffectsToShow.Of` 的 ② 支（`TempBuffs` / `IsKeyword`）与 ③ 支（`TraitEffects`）**各出一行** Trait ⇒ 印两遍。
③ 才是原版 `activeEffects(+0x108)` 的正本；① 支对 `StatMod` 早有同形状去重（`timedMods`，`:215-227`），关键词这半一直没补。

**身份链已现核**：`UnitState.ApplyTraitEffect:2943-2997` —— 新建时 `_traitEffects.Add(rec); return rec`（`:2994/:2996`），
命中既有记录时返回的也是**同一个实例** ⇒ `TempBuff.TraitRec` 与 `u.TraitEffects` 里某一项**引用相等**。

```csharp
        static bool TraitRecAlreadyShown(UnitState u, UnitState.TraitEffectRecord rec)
        {
            if (u == null || rec == null) return false;
            var recs = u.TraitEffects;
            for (int i = 0; i < recs.Count; i++)
                if (ReferenceEquals(recs[i], rec)) return true;
            return false;
        }
```
