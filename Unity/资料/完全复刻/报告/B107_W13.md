## 二、逐条：判据 + 改了什么

### N88 · 聊天新消息滑入

**原版有没有这一拍：有。** 逐句现读（不是按文档转述）：

- `d:/2/tools/cpp2il/out_cpp2il_dev_ilspy/ChatContentView.cs:96-107`：
  `if (newMessageReceived) { var vh = GetItemViewsHolderIfVisible(GetItemsCount()-1); if (vh != null) {
  newMessageReceived = false; DOMoveY(vh.MessageUI.transform, transform.position.y, 0.3f);
  From(t, transform.position.y - 10f); } }`
- 同一方法的第二跳（`:71-89`）= 15s 计时（N89）。
- `ChatContentView.AddMessage`（ILSpy `:409-454`）：**只有**「未缓存 + 不是 cached 消息」才干 `newMessageReceived = true`；且上一条 tween 还活着时先 `TweenExtensions.Kill(tween, complete: true)`（`:437`）。
- decomp 交叉核对：`ChatContentView__Update.c:38-57`（`DOMoveY` / `From(… − DAT_1834b2da8)`）· `ChatContentView__AddMessage.c:52-61`（`Kill` 标志位）。

**落地**：`ChatTab` 类尾新增 `SlideDuration = 0.3f`、`SlideOffsetPx = 10f`、`StartSlide / BeginSlideForTest / TickSlide / FinishSlide`；
`Rebuild` 末尾在「本频道末条消息对象变了」时对**末条已建行**播滑入。三条等价边界：

1. **滚动/切页触发的 `Rebuild` 不播**（末条没变）；
2. **末条滚出视口没建 ⇒ 不播**（= 原版 `GetItemViewsHolderIfVisible` 返回 null 时整跳跳过）；
3. **批处理没有帧循环** ⇒ 生产路 `Application.isPlaying` 才起（同 `AlliancePanelWindow.StartAppear` 的先例），自检走 `BeginSlideForTest` + 手动 `TickSlide`。

> 🔶 **已按铁律 18 打标记**：原版用 DOTween `DOMoveY(...).From(...)`，本仓用同算式按 `Time.deltaTime` 推进（批处理无帧、DOTween 不会走）—— 0.3s / 10px / `Ease.OutQuad`（DOTween 默认缓动）逐项一致。

### N89 · 15 秒计时刷新

**原版周期：15 秒。** `ChatContentView__.ctor.c:17` 是 `*(undefined4 *)(param_1 + 0x148) = 0xf;`（15）；ILSpy `ChatContentView.cs:518` `updateDelay = 15;`。
`ChatContentView.Update` 的第一跳：`if ((Now − lastUpdate).TotalSeconds > updateDelay) { lastUpdate = Now; UpdateTimers(); }`；
`UpdateTimers`（`decomp_full/ChatContentView__UpdateTimers.c`）遍历可见项、逐个 `ChatMessageUI.UpdateTimer()`；
`ChatMessageUI__UpdateTimer.c` 用 `TimestampMs(+0x60)` → `DateTimeOffset.FromUnixTimeMilliseconds` → 与 `UtcNow` 求差 → `GetTimeStringWithSingleDigit(ts, eventTimer:true)` 写 `Time`。

**落地**：`ChatTab.Rebuild` 建行时把「消息 + `Time` 标签」记进 `_rowMsgs` / `_timeLabels`（标签按 `Player Header/Time` 或 `Friend Header/Time` 找）；
`RefreshTimeTexts()` 逐颗 `Label.SetText(SocialData.TimeText(m))`（时间串实现唯一一份 = `SocialData.TimeText`）；
`TickTimers()` 按 `DateTime.Now` 判 15s（与原版同一条 wall-clock 口径，⛔ 不用累加 `deltaTime`，否则暂停时与原版不一致）。
`Update()` 每帧同时泵滑入与计时；批处理没有 `Update` ⇒ 自检直接调 `RefreshTimeTexts()`（断言 D 段就是这么做的）。
