## 三 · 顺手发现的 5 条（比 17 条本身更重要，⛔ 不要漏）

### 1. `GetCampaignScriptedData` **不是死代码** —— 调用点在异步状态机体内，ILSpy 丢了名字
`out_il2csharp/Assembly-CSharp/BattleManager.cs:40240` 与 `:40660`：
```
ExecuteCampaignScriptedTurn(GetCampaignScriptedData(CampatinScriptedActionType.PostMulligan), 0)   // :40240
ExecuteCampaignScriptedTurn(GetCampaignScriptedData(CampatinScriptedActionType.PreMulligan),  0)   // :40660
```
⇒ 本方法**恒返 null**，所以「战役脚本动作」整块在本 build 是空转。判 D 的理由是**恒 null ⇒ 无行为**，**不是**「没人调」。

### 2. `IsCampaignScriptAvailable` **也不是死代码**，它是**战役脚本两条支的闸**
`out_il2csharp` 里它被渲染成 **3 个实参** `(this.__4__this, 10, 0)` / `(this.__4__this, 0, 0)`（= 1 参方法 + MethodInfo），对应 `PostMulligan=10` / `PreMulligan=0`（`CampatinScriptedActionType` 枚举：PreMulligan=0 / PostMulligan=10 / Victory=20）。恒 false ⇒ 两条支永不执行。

### 3. 🔴 `ShouldUseEnviromentalEffects()` = 环境效果阶段的闸，**恒 false ⇒ 原版根本不弹「选进攻卡/防御卡」面板**
- 调用点（`out_il2csharp` 渲染成 **2 个实参** `(this.__4__this, 0)` = 0 参方法 = 本方法）：
  `BattleManager._SetupEnviromentalEffectPhase_d__352.MoveNext`，VA **0x1809C2D90**。
- 机器码（`_tmp_view/D1_judge/dis_window.py 0x1809c2d7b 96`）：
  ```
  1809c2d80  xor edx,edx        ; 无参
  1809c2d85  cmp eax,0xa0       ; matchType == Replay(160)
  1809c2d8a  je  0x1809c300b

### 4. `armedTrap` 的真相 —— 账里 `PlayerHand.AddActiveTrapToHand` 那条旧理由**是错的**
旧备注写「`CardScript.SetAsActiveTrap` 全树 0 调用方 ⇒ `armedTrap` 恒 false」。**不成立**：

```

    … CreateCard(createdCard, playerHand.transform, isPlayer, army, flag2);          // il2csharp :18346
