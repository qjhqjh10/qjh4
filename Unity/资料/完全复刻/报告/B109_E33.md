## 六·b、续办补刀（`B109_D2` §3 · 2026-10-31）

**病**：`MenuFxMaterials.Apply` / `ApplyAll` 把 `Resources.Load` 拿到的**那一份共享材质**直接挂成
`sharedMaterial`；而 `ImageQuad.SetTint` / `SetRenderQueue` 写的正是
**`_mr.sharedMaterial.color` / `.renderQueue`**（`Battle/ImageQuad.cs:400` / `:425`）—— 也就是说
**「染色」和「渲染队列」这两个 per-quad 状态是存在材质实例上的**。共用一份 ⇒ 最后写的那颗盖掉全部
（联盟 10 颗奖杯描边全部落到队列 3263、染色被抹成白；时钟那 4 处同病）。

**改法（只动 `Shell/MenuFxMaterials.cs` 一个文件，⛔ 没碰任何窗口文件）**：

```csharp
public static void Apply(ImageQuad q, string resPath)
{
    if (q == null) return;
    var proto = Load(resPath);
    if (proto == null) return;
    Color tint = q.Tint;                       // 换之前那一份（SetTint 写的就是 sharedMaterial.color）
    var inst = new Material(proto);            // ⛔ 别把 proto 本体挂上去 —— 每颗一份
    if (inst.HasProperty("_Color")) inst.color = tint;
    q.SetMaterial(inst);
}

public static void ApplyAll(GameObject go, string resPath)
{
    if (go == null) return;
    if (Load(resPath) == null) return;
    var quads = go.GetComponentsInChildren<ImageQuad>(true);
    for (int i = 0; i < quads.Length; i++) Apply(quads[i], resPath);   // 逐颗转调（每块各自克隆）
}
```

- **渲染队列**由 `ImageQuad.SetMaterial` 自己从**旧材质**读出并带过去（`ImageQuad.cs:299-303`），所以不用我们管；
  我们只补 `_Color`（染色）。
- **Clock 那 4 处（`ExpansionPassEventWindow:1013/1267` · `MainMenuRuntime:3112` · `OfferContainer:1545`）不用改调用点** ——
  它们原来染的是**自己的旧材质**，`Apply` 现在会把那份 `_Color` 带进克隆体，所以自动治好了。
  ⚠️ 那 4 个文件都在本批白名单内，但**这次一行都没动**。
