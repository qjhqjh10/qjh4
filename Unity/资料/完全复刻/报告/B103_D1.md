## 二 · `B102AUD03R` 四条红（③ `TabButtons` 死 handler）

### 2.2 根因（一句话）：`target != null && target == null` 是**恒假**式

`Shell/TabButtons.cs:286-287`（`DropDeadHandlers`）与 `:309-310`（`DeadHandlerCountForTest`）两处写的是同一个谓词：

```csharp
var target = d.Target as UnityEngine.Object;
if (target != null && target == null) continue;   // ← 想表达「Unity 假 null」
```

- `target` 的静态类型是 `UnityEngine.Object` ⇒ `target != null` 绑定到 **`UnityEngine.Object.op_Inequality`**，
  它本身就是「`!(op_Equality(target, null))`」；`op_Equality` 对**已销毁**对象返回 `true`。
- ⇒ 整个表达式 = `!X && X` = **恒 false** ⇒ **一条 handler 都不会被摘**、**一条死 handler 都不会被数出来**。
- 正确写法（判「Unity 假 null」必须**先把引用本身和 null 分开**）：
  `if (!ReferenceEquals(target, null) && target == null) continue;`

### 2.3 四条实得值逐条推演（全部由同一个根因推出，无第二条）

设 `tb1` 被 `DestroyImmediate` 后它那条订阅仍是死 handler（`Target` = 已销毁的 `TabButtons`）：

| 步骤 | 事件上应有的 | 因恒假谓词实际 |
|---|---|---|
| 销毁 `tb1` 后数死 handler（A0-前提⑥） | 1 | **0**（谓词恒假 ⇒ 数不出）✔ 对上 |
| `NewTabButtons` 之后再 `Initialize`（A1） | 摘掉 tb1 ⇒ 1 | **2**（没摘）✔ 对上 |
| 再 `Initialize` tb3（A2） | tb2 + tb3 = 2 | **3** ✔ 对上 |
| `tb3.Initialize` 重复（A2c） | 先摘后挂仍 2 | **3**（`_subscribed` 为 null ⇒ 那句 `-=` 空转；`HasUpdateTab` 认得 tb3 ⇒ 不加 ⇒ 停在 3）✔ 对上 |

⇒ **四条全绿只需要改那一处谓词**（A2/A2c 没有独立的第二因）。**判 β（实现缺陷），断言侧期望值是对的。**

### 2.4 严重性（必须记账的那半句）

`TabButtons.cs` 的文件头（`:75-80`）自己写着：`AUD03` 普查判它「幂等 ✅」**不成立**，
真正的病是「整窗重建 ⇒ 每次 +1 条死 handler，无界增长」。
现在 **③ 的修法从未生效** ⇒ 收藏 / 奖励 / 设置三族**生产路径上的死 handler 还在累积**
（只在 `OnTabChanged` 触发时对已销毁对象调 `UpdateTab`，**不报错、结果无意义** = 静默）。
⇒ 这条不只是自检红，**是玩家侧真缺陷**。（好在不崩：`UpdateTab` 只读托管字段。）

### 2.5 修法建议

- `Shell/TabButtons.cs` —— **两处共用一个谓词**（铁律「两处写同一条规则 = 迟早不一致」）：
  ```csharp
  static bool IsDeadHandler(System.Delegate d)
  {
      var uo = d != null ? d.Target as UnityEngine.Object : null;
      return !ReferenceEquals(uo, null) && uo == null;   // 🔴 假 null 必须 ReferenceEquals 先分档
  }
  ```
  `DropDeadHandlers`（`:287`）与 `DeadHandlerCountForTest`（`:310`）都调它。
- ⚠️ 别图省事写成 `if (target != null) keep += d;` —— 那会**连静态方法 / 非 Unity 的 Target 一起摘掉**（`as` 出来是字面 null）。
- 断言侧**一个字都不用改**。

### 2.6 一票否决实验

- 改完谓词复跑 `ShellScene.Run`：**四条同时转绿**（且 `B102AUD03R 合计` 从 `25/4` → `29/0`）。
  若只转绿 A0-前提⑥ 而 A1 仍 2 ⇒ 那说明还有第二因（比如 `HasUpdateTab` 的 `Target == this` 用的是 `object` 引用比较），**需要再看一轮**。
