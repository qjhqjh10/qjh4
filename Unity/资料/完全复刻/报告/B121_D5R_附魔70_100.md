## §三 空 ids / 空 PPtr 的处理（出声、不崩）

`SummonCriteria.unitsToSummon` 是**三态**（`CardDef.AbilitySummonSpec.UnitsToSummon`）：
`null` = **没导出/未知** ⇒ **出声 + 不结算**（`:1723` 起；⛔ 绝不折成空表 —— 折了会掉进支④去扫池，行为全变）；
`[]` = 明确没有引用 ⇒ 走支③/④；非空 ⇒ 支①/②。另四条同族闸也都**出声不崩**：
`spec == null`（这一行没有 `summonCriteria` / 旧表 / 手写夹具）· `isForEnemy` 未知 · `summonAllTargets` 未知 ·
`chooseCardInPlay` 未知 · `RawCardPool` 没登记（支①② 的 id 查表 **和** 支④ 的候选域，两处都出声、都不拿 `ctx.CardPool` 顶替）·
`matchesRawCard` 判不了（**保留候选** + 出声）。
空 PPtr（`m_PathID == 0`）由 `B121-D4` 在生成器侧跳过 ⇒ 数据里不会出现空 id；执行体再多一道：查不到的 id 只计数、不建空引用。
