```csharp
// ✅ 已复刻（2026-11-04 · B141 · W83 · 判据 = CardTraitCollection__GetTraitInPlayListForIcons.c:112-192 第二支
//   ＋ CardTraitCollection__GetAbilityToTraitDict.c:1-53 的 25 对表）
// 原版「由 ability trigger 派生的 trait」也进场上 7 位图标：把 `ExtraAbilityTraits` 里
// **step ①（TriggerName != null）** 的那些并进 `u.Keywords`；⛔ step ②（`hasActiveAbility` 补的那一条，
// TriggerName == null）**不进**这条路 —— 原版图标路径只查 25 对表。
// 去重口径照原版：**已在本表里的（= 卡自己的 trait，第一支循环已收）不再加**。
// 角标：`outDerivedKeys` 收「由本方法加进来的键」，调用方必须把它们传给 `For(..., zeroCounterKeys:)`
// —— 原版这一枚的 counter 走 `GetCurrentTraitValueWithModifiers(card, traitId)`，而派生 trait
// **不在 CurrentTraits 里**（`UpdateTraitIcons.c:83-88` 的 `List.Find` 命中不了）⇒ counter 恒 0 ⇒
// `BoardTraitIcon` 走 `Without counter` 那一支。⚠️ 不压制的话 `ecstasy` 会多印一个「1」
// （它在 `CarriesValue` 的 ③ 表里）。
public static System.Collections.Generic.List<System.Collections.Generic.KeyValuePair<string, int>>
    MergeDerivedTraits(System.Collections.Generic.IEnumerable<System.Collections.Generic.KeyValuePair<string, int>> own,
                       RuleEngine.CardDef card,
                       System.Collections.Generic.List<string> outDerivedKeys)
{
    var acc = new System.Collections.Generic.List<System.Collections.Generic.KeyValuePair<string, int>>();
    if (own != null) foreach (var kv in own) acc.Add(kv);
    if (card == null) return acc;
    var all = card.ExtraAbilityTraits;
    for (int i = 0; i < all.Count; i++)
    {
        var e = all[i];
        if (e.TriggerName == null || string.IsNullOrEmpty(e.Keyword)) continue;   // ⛔ step② 不进图标路径
        bool has = false;
        for (int j = 0; j < acc.Count; j++)
            if (string.Equals(acc[j].Key, e.Keyword, System.StringComparison.Ordinal)) { has = true; break; }
        if (has) continue;
        acc.Add(new System.Collections.Generic.KeyValuePair<string, int>(e.Keyword, 0));
        if (outDerivedKeys != null) outDerivedKeys.Add(e.Keyword);
    }
    return acc;
}
```

### 2.4 灭自证：⛔ 不许「把派生 trait 写进引擎关键词」

最省事的"修法"是往 `UnitState._keywords` 或 `CardDef.Keywords` 里塞派生 trait —— **那是错的**：

* 原版 `HasCurrentTrait` 读 `CurrentTraits(+0x128)`；派生 trait 只由 `CheckCurrentTraits` 追加，
  而 `RawCardScript__CheckCurrentTraits.c` **全树 0 调用点**（三源确认:`.c` 无调用方 / ILSpy 只有定义 / `out_il2csharp` 同）
  ⇒ **原版出货的 `Has()` 看不见派生 trait**。
* 若塞进 `_keywords`：`rally` 一档就有 **587 张卡带 trigger 0** ⇒ `Has("rally")` 对它们一起变真，
  会串进效果结算 / AI / 光环一堆读点，**这是原版没有的行为**（且 `play check` 指纹会大面积动）。
* ⇒ 本件在断言里**钉死了这一条**：`C2` 断言「派生 trait 不进引擎关键词（`Has("ecstasy") == false`）」。
