## §3 补丁（交回给 `Shell/DraftModeWindow.cs` 的所有者 / 调度台）

三点说明：① 目标必须是 `IEventImageTarget`，本仓的图件是 `ImageQuad`（`Shell/EventImageSelector.cs` 只有 uGUI 适配器
`UnityImageTarget`）⇒ 补丁自带一个 `ImageQuad` 适配器（**放在 `DraftModeWindow.cs` 里当私有嵌套类**，不新增文件）。
② 数据源 `EventAssets` 在本地 `LiveOpsLocalEvent.Assets`（`LiveOpsLocalCatalog.cs:180`）。③ 本机 Timed 事件 0 份 ⇒ 空表 ⇒ 两格按原版关掉。

```csharp
// ── ① 私有适配器（放进 DraftModeWindow 类里；不是 MonoBehaviour，随便放）────────────────────
sealed class QuadEventImageTarget : IEventImageTarget
{
    ImageQuad _q;
    public QuadEventImageTarget(ImageQuad q) { _q = q; }
    public Texture2D Sprite
    {
        get { return _q != null ? _q.Texture : null; }
        set { if (_q != null) { if (value != null) { _q.SetTexture(value, true); _q.gameObject.SetActive(true); }
                                else _q.gameObject.SetActive(false); } }
    }
    public bool Enabled
    {
        get { return _q != null && _q.gameObject.activeSelf; }
        set { if (_q != null) _q.gameObject.SetActive(value); }
    }
}

// ── ② Demo 页表头那颗 `Game Mode Icon`（原版实例 ① ② 都挂在这儿，一格 GameModeIcon）──────
//     位置 = `BuildOnGoingPage` 同族那颗 `Game Mode Icon` 建出来之后（DraftModeWindow 里对应节点名相同）
_eventAssetSprites = new List<LiveopUIDrawer_EventAssetSprites.EventAssetImages>
{
    new LiveopUIDrawer_EventAssetSprites.EventAssetImages
    { EventAssetType = (int)LiveOpsAssetRef.GameModeIcon, Image = new QuadEventImageTarget(gmIconQuad) },
};
LiveopUIDrawer_EventAssetSprites.Initialize(_eventAssetSprites, LocalLiveOpsEvent /* DraftMode 的事件实例；无则 null */);

// ── ③ Timed Pay 页（原版 `DraftModeMenuPayStateTimed.OnOpen` 末句）────────────────────────
//     两格 = RankingIcon(6) / HeaderImage(3)（prefab 实例实读）
if (_eventImages == null) _eventImages = new List<EventImageSelectorController.ImageEventDrawData>
{
    new EventImageSelectorController.ImageEventDrawData { Image = new QuadEventImageTarget(rankIconQuad), EventAssetType = (int)LiveOpsAssetRef.RankingIcon },
    new EventImageSelectorController.ImageEventDrawData { Image = new QuadEventImageTarget(headerImageQuad), EventAssetType = (int)LiveOpsAssetRef.HeaderImage },
};
var eventAssets = new List<EventImageSelectorController.EventAsset>();
if (LocalLiveOpsEvent != null && LocalLiveOpsEvent.Assets != null)
    foreach (var a in LocalLiveOpsEvent.Assets)
        eventAssets.Add(new EventImageSelectorController.EventAsset { Type = a.Key, AssetName = a.SubObjectName });
EventImageSelectorController.Initialize(_eventImages, eventAssets);
```

## §6 顺手发现（都要记账）

1. 🔴 **R16 判据 C27 的「`PurchaseMilestone(0)`」是错的** —— 那是 **ILSpy 丢常量**：`out_cpp2il_dev_ilspy/TwoSidesEvent.cs`
   把 `TryColllect` 的实参渲成 `0`，`out_il2csharp` 才是真身 `Save.collectedRewards(+0x34)`。
   （同族已记：`CLAUDE.md` §三「ILSpy 会把实参常量反编译成 `default`」。）
2. 🔴 **本仓既有注释把 `+0x34` 的容器记错了**：多处写 `Data.currentMilestone(+0x34)`。实际 `TwoSidesEvent+0x18 = Data`、
   `+0x20 = Save`；`+0x34` 在 **`TwoSidesEventSave.collectedRewards`** 上（反证：`SelectTeam` 把 `Save+0x38` 当 string 读 = `playerTeam`）。
   本批已就地订正 `ParentEventWindow.cs:1991` 与 `:2006` 那两行（铁律 5）。⚠️ 其它文件里若也这么写，要一起改（本批未扫）。
3. 🔴 **原版 `PurchaseMilestone` 的 `milestoneIndex` 形参整段没用到**（`.c` 里 `param_2` 零次读）。
   ⇒ 谁想「顺手把它用上」就会偏离原版。
4. 🔴 **领取标记不是本地那一半**：原版靠云返回的 `updatedPersistence` → `UpdateSaveGame` 才写；
   所以 R16 判据里「置领取标记 + 重刷」只有「重刷」是本地可做的（= `_CollectClicked_b__13_0` 回调里那句
   `this.InitializeMilestones()`，il2csharp `:147-150`）。本批按原版做：**不置标记**。
5. ⚠️ **`EventImageSelectorController` 的 `ImageEventDrawData` 原版是 `EventImageSelectorController` 的 private 嵌套类**
   （`image / eventAssetType / cacheAssetReference` 三格）；我们的等价里 `LastAssetName` 是**自检读口**，不是原版字段
   （原版那份 `cacheAssetReference` 是 Addressables 句柄，用来 `Release`；我们没有那层）。
