## 一 三个洞各怎么修的

### 1. 洞① · `判据出处` 只验前缀 ⇒ **打错路径照样绿**（K1：一块写错 5 条，机检一条没拦）

**改法（`check_judge_token`）**：每个 `;` 分隔的 token 走四步，任一步不过即**失败**：

1. **必须带原版前缀**（`decomp_full/` `cpp2il/` `assets_full/` `bundle_` `判据/` `D:/2/`）——
   裸名（账里那种 `ShopData.cs:349` 风格）判失败，并提示它其实在哪；
2. **自证闸**：含 `CardPresentation/` `RuleEngine/Core` `RuleEngine/Data` `MyGame/Assets` ⇒ 失败；
3. **文件逐字存在**（`JudgeMap.resolve`）；
4. **行号在界**：`路径:83-170` / `:251` / `:119/144/155` 都取数字，首尾必须落在文件行数内。
   **只有文本类扩展名**（`.c .cs .md .txt .tsv .json .py .h …`）才按行读；资产/二进制/目录**只验存在**
   （⛔ 不对二进制数行 —— 那会得到垃圾行数）。

**公共映射 `JudgeMap`（这就是「别让每个写手自己猜」的那件东西）**：
前缀 → 真实根：`decomp_full/`→`D:/2/tools/decomp_full` · `cpp2il/`→`D:/2/tools/cpp2il` ·
`assets_full/`、`bundle_*`→`D:/2/新解包资源/assets_full` · `判据/ 账/ 报告/`→`D:/4/Unity/资料/完全复刻/…` ·
`资料/`→`D:/4/Unity/` · 盘符路径原样。

路径写错时**不是靠猜**，而是在真目录里反查（懒建索引、结果记忆化）：

* `.cs` 少了/多了命名空间子目录 ⇒ 按 basename 在 `cpp2il/out_cpp2il_dev_ilspy/`（递归）里找；
* `.c` 少了命名空间前缀 ⇒ 在 `decomp_full/`（25,096 个文件）里按「每个 `.` 之后的后缀」建索引，
  所以 `ContainerOfferEvent__OpenOfferContainer.c` 能命中 `Everguild.LiveOps.ContainerOfferEvent__OpenOfferContainer.c`；
* 唯一命中 ⇒ 失败并打印 **`应写成 \`完整路径\``**（写手直接抄）；多处同名 ⇒ 失败（歧义无从复核）；查不到 ⇒ 失败。

另外给写手加了 **`--resolve-judge`**：动手写之前跑一次，把裸名解析成完整路径（见 §四）。

### 2. 洞② · `多认领` 只告警、`rc` 仍 0 ⇒ **脏分母也是「过」**

**改法**：`--strict` 下 `多认领 ≥1` **直接判失败**（每条一行，带「一行只能有一个 primary owner」）。
`--strict` 同时把「`我们的落点` / `验收口` 写成空串」也判失败（那是**忘填**，不是「确认没有」）。
**合并脚本一律带 `--strict`**；单块过 part 时可以不带（保持 K1 那份基线不抖）。

### 3. 洞③ · 没有按域口径 ⇒ 每个 part 都打「未认领 9,26x」

**改法**：`--domain <域>`

* 未认领/多认领只按该域统计，另印一行「全库（仅信息，part 阶段不看它）」；
* 域内未认领 = 0 时印 **`✓ 域内未认领 = 0（part 级通过条件满足）`**；
* 🆕 **越域认领闸**：本块认领了**别的域**的账行 ⇒ **判失败**（K1 §五③ 第 6 条那条纪律的机检版：
  「共用件可以写落点，认领不行」——`ItemDrawer.Draw` 这类会被 K3/K4 来抢）；
* 域名非法 ⇒ 印出现读的 20 个域名、rc=2。

### 4. 顺带两条（都做了）

| 顺带项 | 做法 | 实测 |
|---|---|---|
| `我们的落点` 没有合法的「无落点」值 | 哨兵 **`—`**（`NOPOINT` 还认 `-` `无` `N/A`）**合法放行并计数**；**空串改成告警**（`--strict` 下失败）。统计行印「无落点(`—`) N 个功能点」—— 这本身是有用指标（K1：商店域 1/13） | 空串→`—`：告警 1→**0**，统计「无落点 1」 |
| `等级` 分不出「复刻」与 `🔶 自己设计` | 允许**后缀**：`A` `A?` `C🔶` `C🔶?` 都合法；**按基档比对与计数**（`A🔶` 算 A），比率照设计 §四 算，另印一行 **`🔶 自己设计：含标记的功能点 N 条（等级 A 的 M 条 …）`** | `A`→`A🔶` 仍 0 失败并单列；写成 `C🔶`（重算 A）**照样判红** ⇒ 标记不能用来放宽等级 |

### 5. 另外两处顺手加固

* **读取一律二进制**（`read_lines`）：按 `\n` 切、去 `\r`、末尾空行不算行 —— 与 CLAUDE.md
  「按行号报位置的工具必须二进制读」那条一致（文本模式遇裸 CR 会让行号整体偏）。
* **`跑法` 的类索引只建一次**：原型是每行 `os.walk` 整个 `Assets/`，13 行就够呛，356 条会卡死。
* **`--self-test`**：把「闸会不会红」变成一条命令（7 类故障注入，见 §二.7）。

```bash
python -I -X utf8 d:/4/Unity/工具/feature_index_check.py <索引.tsv> [选项]
python -I -X utf8 d:/4/Unity/工具/feature_index_check.py --manifest [--ledger DIR]
python -I -X utf8 d:/4/Unity/工具/feature_index_check.py --resolve-judge <名字或路径> [...]
python -I -X utf8 d:/4/Unity/工具/feature_index_check.py <索引.tsv> --self-test
```

| 参数 | 作用 |
|---|---|
| `--ledger DIR` | 账目录（默认 `D:/4/Unity/资料/完全复刻/账`）。**做对照实验时指向快照目录**（见 §二） |
| `--src DIR` | 我们源码根（默认 `D:/4/Unity/MyGame/Assets`） |
| `--domain NAME` | **按域口径**：未认领/多认领只统计该域；并检查**越域认领**。**part 阶段必须带** |
| `--strict` | 多认领 ≥1 判失败；`我们的落点`/`验收口` 空串判失败。**合并脚本一律带** |
| `--no-judge-exists` | 跳过判据文件存在性（应急；默认开检查） |
| `--quiet` | 只印失败，不印告警明细 |
| `--self-test` | 对一份**已知全绿**的表做 7 类故障注入，逐条断言抓到 |
| `--manifest` | 打印「域 → 账行数 → 在哪些文件」（派活用，⛔ 别再手打行数） |
| `--resolve-judge` | 把裸名/相对名解析成真实完整路径（`✓` 已对 / `✗` 需拆 / `?` 歧义） |
| `-h` / `--help` | 完整说明（含公共映射表与 `等级` 后缀语义） |

**退出码**：`0` 全过 · `1` 有失败 · `2` 用法错。
**不带任何动作参数 ⇒ 只打印用法并 rc=2，什么都不做。**

### 给 12 块写手的三条（请直接抄进简报）

1. **`判据出处` 只写带前缀的完整路径**：`decomp_full/…` `cpp2il/out_cpp2il_dev_ilspy/…` `assets_full/…` `判据/…`。
   不确定就先跑 **`--resolve-judge <名字>`**，把输出的 `应写成 \`…\`` 原样抄进表（⛔ 别自己拼命名空间）。
2. **没有落点写 `—`**（不要留空串，也不要写别的）。
3. **本块只认领本域的账行**；共用件（`ItemDrawer.Draw` 这类）可以写进 `我们的落点`，⛔ 不许写进 `原版构成`。
