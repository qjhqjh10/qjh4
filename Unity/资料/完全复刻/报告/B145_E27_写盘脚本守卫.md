## 实测方法（怎么判「真的没写」）

1. **裸跑前**：把该脚本**全部产物**（由审计包装器给出）复制到 `_tmp_view/e27_bak/<脚本>/` 并记 `sha256 + size`。
2. **裸跑**：在**临时 cwd**（`_tmp_view/e27_run`）执行 `python -I -X utf8 <脚本>`，记 `rc`。
3. **判零写盘**：逐份重算 `sha256` 与第 1 步比 —— **不看 mtime**（脚本本身不动产物）。
4. **判「带显式动作不变」**：取 `git show HEAD:<脚本>` 当改前基准，用**它自己的写盘档**跑一遍 → 记产物哈希 → 再用改后版 `--write` 跑 → 逐字节比。
5. **写盘审计包装器**（本轮新建，只读、零落盘）：`_tmp_view/e27_run/waudit.py`
   —— 把 `open/io.open/os.replace/os.rename/os.remove/os.makedirs/shutil.copy*` 换成「记录 + 空实现」，
   再 `runpy` 跑目标脚本，输出 `WAUDIT_WRITE <kind> <path>`。**它只回答「会不会写」，⛔ 不回答「产物对不对」**。
   用法：`python -I -X utf8 waudit.py <脚本.py> [args...]`（结果在 stderr）。
6. **产物归位**：所有产物跑完都**已还原**到会话开始时的字节（本轮验证 BAD=0）；`git status` 里商品目录无改动。

## 顺手发现（本轮未修，属下一轮）

1. **静态扫描的 A/B 分组有明显误判**（实测 17 个候选：13 个真写、4 个不写）。
   - `gen_mainmenu_effects.py` 裸跑**本来就不写**（预览档，只是 rc=0）——被误归 A 组；
   - `gen_tutorial_variants.py` 早已有必填动词（裸跑 rc=2）；
   - `gen_battlehud_clips.py` / `gen_arena_scene_clips.py` / `gen_arena_timeline.py` / `gen_pid_index.py` / `gen_card_dossier.py` / `gen_prebuilt_decks.py` 都已有守卫；
   - `gen_icon_plan.py` 裸跑不写（`WRITE=False`），但 rc=0；
   - `gen_anim_clips.py` / `gen_defensive_cards.py` 裸跑不写（只打印）。
2. **`gen_ability_enum_dict.py` 的盘上 TSV 已过期**：现算 **84,159 B**，盘上 **84,726 B**；新加的 `--check` 当场报 `rc=1`。
3. **`gen_tmp_font_assets.py` 目前是坏的（改前就坏）**：`_selftest()` 报
   `⛔ 模板字段集 != (头 10 ∪ 原版 JSON 键集)`，模板侧多出 **39 个材质/贴图字段**（`m_SavedProperties` / `m_Shader` / `m_TextureFormat` …）
   ⇒ `_template_order()` 读到的**不是 TMP_FontAsset 那份 `!u!114` 块**（或模板资产被人改过）。
   该脚本的 `--write` / `--verify` **现在都 rc=1 且一个字节不写**；我**没动它的逻辑**，只加了守卫。
4. **`gen_cards_truth.py` 盘上两份产物已过期**：用 `git HEAD` 版重跑，产物会变（我 A/B 时确认，随后已还原）。
   ⚠️ 台账里 `cards_truth.json` 是「唯一正确源」——过期会影响统计口径，建议排一条「重跑 + 核销」。
5. **`gen_unit_tweens.py --write` 自检口径不符**：打印「非空 curve 关键帧：**6**（应为 0）」。
6. **两个已守卫脚本的裸跑 rc=0**（`gen_arena_scene_clips.py` / `gen_battlehud_clips.py`）：打印用法但**退出码 0**，
   与纪律「非零退出」不一致；建议下一轮统一改 2（它们不发车，只是 rc 不对）。
7. **`gen_feature_index.py` 的重跑命令语义变了**：原来无参就覆盖写 `功能点索引.md`，现在裸跑 rc=2。
   ⇒ 任何写死「无参重跑」的调度单要改成 `--write`；文件头那段「默认仍然是覆盖写」的旧注释**已就地更正**。
8. **`gen_cards_engine.py` 裸跑是「干跑」但 rc=0**（不写盘，但未按纪律返回非零）；本轮未动它。
9. **A/B 验证方法学坑（对后续同类活有用）**：把 `git HEAD` 版拷到**别的目录**跑，凡依赖 `__file__` 的脚本会改变输出或直接失败 ——
   本轮遇到三例：`gen_card_vfx_by_card` 缺兄弟件 `parse_catalog.py` ⇒ 诊断字符串变了；`gen_feature_index` 缺 `feature_index_check.py` ⇒ 直接崩；
   `gen_environment_conditions` 的 `ROOT = dirname(__file__)/..` ⇒ 找不到数据。
   ⇒ 基准跑要**补齐兄弟文件 / 把根路径常量改成绝对路径**，否则会得到「假差异」。
