## 二、显示入口（为什么每次进都弹）

| 环节 | 出处（现读） |
|---|---|
| 闸门 | `CardCollectionTab.OnOpen()`：`FeatureConfig.Check("WildcardTutorial")` + `!tipsData.sawWildcardTutorial` ⇒ 调 `StartWildcardTutorial(filterToggle, ownedToggle)`；离线存档这个 flag 恒 false ⇒ **每次进都弹** |
| 方法 | `E:/warpforge/03_反编译/cpp2il/out_cpp2il_dev_ilspy/CardCollectionTab.cs:163-181` |
| 引导机 | `WildcardTutorialManager.StartWildcardTutorial` → `AddPointer(FilterToggle)`；`ToggleFilters(bool)` 里读 `LocalizationManager.GetTermTranslation("Tips/WildcardTutorial1")` 再 `AddPointer(OwnedToggle, 文案)` |
| 方法 | `.../WildcardTutorialManager.cs:289-333`（`ToggleFilters` 在 :333 起） |
| 气泡对象 | `TutorialPointer`（`SetTutorialText / StartPointer / ShowStartingPointer`） |

⇒ 根因不是某个界面的本地 bug：**原版靠 `TipsData.sawWildcardTutorial` 存盘位在「看完一次」后自行关闭**，离线存档里它永远是 false。

## 三、挂了几处（全部「显示入口 prefix → return false」）

`Probes/TipSkipProbe.cs` · 共 **7 个**（`phase0/hooks_installed.tsv` 有逐条结果）：

| # | 目标 | 覆盖 |
|---|---|---|
| 1 | `WildcardTutorialManager.StartWildcardTutorial` (2 参) | **用户报的那一处**（整套过滤器引导不启动、监听不注册、指针不例化） |
| 2 | `WildcardTutorialManager.AddPointer` (3 参) | 同一套系统的兜底入口 |
| 3 | `TutorialManager.AddPointer(TutorialPointerData)` | 通用教程指针（战役/任务/升级卡/排位/教程结束页） |
| 4 | `TutorialManager.AddPointer(GameObject, Vector2, bool)` | 同上（直接目标重载） |
| 5 | `TutorialManager.AddPointerHideInCampaign` (0 参) | 战役教程指针 |
| 6 | `MainTutorialManager.AddPointer(MainTutorialButtons)` | 主菜单教程手指（FTUE 已由 `Stubs.InstallFtueSkip` 关掉，这里再兜一层） |
| 7 | `BattleManager.ShowTutorialTip(SmallTipData)` | 战斗内教程提示（教程战才走） |

⛔ **故意没挂**：
- `MainTutorialManager.AddPointerWithDelay` / `TutorialTipScript.ShowTip` 等**返回 `IEnumerator`** 的方法 —— prefix 跳过会返回 null，`StartCoroutine(null)` 直接抛。
- `TutorialManager.ShowTutorialMessageWindow` —— 返回 `GameWindow`，跳过会返回 null 让调用方 NRE；它只被 `TutorialStage*` 调用，而 FTUE 已被关掉。
- **查询型 tooltip 不算「引导」**：`EverguildTooltipManager` / `TextTooltipController` / `HoverManager(MiniTipHover)` / `Battle/Tips/*`（「法力不够」这类操作反馈）/ `RadioMessageScript` 电台对白 —— 全部保留。
