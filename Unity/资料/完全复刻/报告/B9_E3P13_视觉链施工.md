### ① 730 `CardScript.DissolveMinionCard(bool dissolveY)` → 账状态 **B**

- **判据（🥇 全文亲读）**：`decomp_full/CardScript__DissolveMinionCard.c:15-49`。

  （`cpp2il/out_cpp2il_dev_ilspy/BasicCardUI.cs:761-771`）：`DOTween.To(() => fadeGroup.alpha, x => fadeGroup.alpha = x, newAlpha, timeToFade)`
  ⇒ **CanvasGroup α**。时长 = `globalVars + 0xb0` = `timeToDissolveCard` = **0.2**。

- **两条订正**：
  ① 原账/施工单把它写成「材质溶解 / `_DissolveAmount` 那一向」——**错**，这条路是 α。
  ② **`dissolveY = true` 那一支全 build 零调用**：`grep -rn DissolveMinionCard decomp_full` 只有
  `CardScript__MoveBackToHand.c:19` 与 `CardScript__OutFromPlayingAreaAnim.c:15`，**两处都传 `0`**
  ⇒ 「溶回来（1→0）」那一支是**死分支**，原版从不走它。

  时长取原版字段 `DissolveCardTime` = 0.2）。**未接线**（用户侧入口 = `HideHeroAtStart` / `UndissolveToDeck`，
  在 `BattleDriver`）。
- **验收口读数**：`CardView.DissolveAmount`（`CardView.cs:6973`，自检口已存在）。
  跑完应 **== 0**（本方法**故意不调** `EndDissolve()` —— 那一句会把 `_dissolveAmount` 置 **−1**，读数口就证明不了「回到 0」；
