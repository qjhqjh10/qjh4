## 五、判据订正与补完（铁律 5 / 铁律 17）

### 5·1 `summonAllTargets` 的「目标数」——**已定死**（补 `B91_P3` §六·2 记的「未定」）

回源逐段读 `decomp_full/AbilityLogic__GetCardToSummon.c`（全文 282 行）：

```
:47-102   unitsToSummon 空 ∧ chooseCardInPlay(+0x29) == 0  ⇒ 扫 get_fullCardCollection() 过 CheckIfRawCardMeetsCriteria
:103-149  unitsToSummon 空 ∧ chooseCardInPlay != 0        ⇒ GetTargets(...) 的目标集，**逐目标全塞进结果表**
:150-157  结果表非空 ∧ summonAllTargets(+0x28) != 0        ⇒ **返回整表**
:158-186  否则                                            ⇒ GetRandomInt(0, Count) ⇒ **返回一张**
:191-209  unitsToSummon 非空 ∧ +0x28 == 0                 ⇒ 随机取一张
:210-238  unitsToSummon 非空 ∧ +0x28 != 0                 ⇒ 逐项全给
```

⇒ **「目标数」= 候选表的长度**，候选表 = `unitsToSummon`（非空时就是它；空时按 `chooseCardInPlay` 取 `GetTargets`
或扫全收藏）。**与 `furtherMultiplier(+0x30)` 无关** —— 后者是 `PlayAbility` 的 `do{}while` **重复次数**，另一件事。

### 5·2 `chooseCardInPlay` 的**极性**（`B91_P3` §二·8 只写了「改从场上选」，容易做反）

`:47` 那个 `if (*(char *)(param_2 + 0x29) == '\0')` ⇒ **`chooseCardInPlay == 0`（假）= 扫整个收藏**；
`:103` 的 `else if (param_3 != 0)` ⇒ **`!= 0`（真）= 走 `GetTargets` 的目标集**。
即「**真** = 从场上/目标集里挑」，与字段名同向。⛔ 接线时别把两支写反。

### 5·3 `B91_P3` §二·8 那张表的**口径**（数字对不上，原因已查明）

⇒ **`P3` 那张表用的是「召唤族」口径**（不是 bug）。本列的落法**与 `abilityDamage` 一致 = 全列都落**，
