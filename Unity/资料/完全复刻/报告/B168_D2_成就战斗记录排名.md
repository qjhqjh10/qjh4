## 一、裁定（排名段数 + legendaryElo）

### 1·1 `rankedRanks`：选 **7 段**（不是 13 段）

- 本地真值：`d:/2/tools/assetripper_out/ExportedProject/Assets/MonoBehaviour/RankedDivisionsSO.asset`
  —— `divisions` **只有 `divisionNumber 1..7`**（01-Rook / 02-Veteran / 03-Commander / 04-Admiral /
  05-Conqueror / 06-Galactic Threat / 07-Legend），`ranks` 只有 1..6（Roman I..VI）；
  图标 bundle `bundle_rankeddivisionicons_assets_all/Sprite/` 也正好这 7 + 6 张。
- 保留 13 段会 NRE：`DivisionImageDisplay.Initialize`（ILSpy `DivisionImageDisplay.cs:23-31`）拿
  `PlayerDataManager.rankedDivisions.GetDivisionData(division.DivisionNumber)` 的返回值**直接解引用 `.image`**；
  `division ≥ 8` 时 `GetDivisionData` 返回 null。
- 收成 7 段后任何分数都落在 1..7，且 `GetDivisionByPoints` 的 `FindLastIndex(correspondingMMR <= points)`
  仍单调。**MMR 间隔 100（0..600）、每段 3 印章** 是我们自定的（🔶 服务端数据，判据在远端）。

### 1·2 `legendaryElo`：必须给 **0**，否则排名页签会被删掉

- `RankedTab.Setup`（ILSpy `RankedTab.cs:118-130`）：`rankedMode == null || !rankedMode.IsLegendaryElo` ⇒ `DestroyTab(this)`。
- `IsLegendaryElo` 真值 = `LegendaryElo <= CurrentScore`
  （`decomp_full/RankedFastMode__get_IsLegendaryElo.c`：`return iVar2 <= iVar1`，iVar2 = 配置值、iVar1 = 当前分）。
- 🔴 **P2 报告原写「未填=0 ⇒ 0>=0 为真」是错的**：`RankedBaseData.cs:13` 是
  `private int legendaryElo = 2500;`（ctor 场初始化，反序列化时先跑；JSON 缺键不会变 0）。
  离线 `CurrentScore = 0`（空榜 currentEntry.value=0）⇒ `0 >= 2500` 为假 ⇒ **页签消失**。
  （已按铁律 5 就地订正在 `B168_判据_账户页_战绩成就排名.md` §4·2 与 §4·3。）
- ⚠️ **已知副作用（照实记）**：`GetDivisionByPoints`（ILSpy `RankedV2Event.cs:489-492`）在
  `points >= legendaryElo` 时**直接取最后一段** ⇒ `legendaryElo=0` 时 0 分显示 **`07-Legend`**，不是 `01-Rook`。
  「页签可见」与「0 分显示 Rook」原版语义上**不可兼得**（页签只给 legendary 段位开），选了前者。
- `seasonNumber=1`：给 `IRankedEvent.GetRankedEventBySeason(season)` 反查用（战斗记录条目的段位图标），
  与注入的 `BattleLogMatch.season = 1` 对齐。

落点：`server/tools/add_all_configs.py` §4 / §4·b + `main()` 里的 `RANKED_EVENT_PATCH` 应用段。
**只改 `OfflineClassic.Data` 的三个键，⛔ 不整条覆盖该事件**（drawData/gameplayVariables/Persistence 归别人）。

## 八、顺手发现（供调度台分流）

1. **`LegendaryElo` ctor 初值 2500** —— P2 报告原判「未填=0」会让排名页签被 `DestroyTab`。已订正并落数据。
2. **`GetDivisionByPoints` 在 `points >= legendaryElo` 时直接取最后一段**（`RankedV2Event.cs:489-492`）
   ⇒ 「0 分 → Rook」与「排名页签可见」不可兼得。这条原版语义建议写进任何「排名页」验收基线。
3. **`ProcessBattleLog` 会把整张战斗记录列表按回包重写** —— 任何「成功回调不读 FunctionResult」的直觉在这两个
   handle（pin / removeNotSaved）上**不成立**；模板给 `{}` 会静默清空页面。
4. **`UpdateAchievement` 的回包被用来整条替换本地存档** —— 回空对象 = 把该成就进度清 0（会静默）。
5. **兑换码 payload 键名是 `coupon`**（不是 `code`），handle 名是 `redeemCoupon`（不是 `redeemCode`）。
