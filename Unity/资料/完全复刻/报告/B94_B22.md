## 三、A-5（账 346）的实际做法 —— 与施工单不完全一样，理由写在这里

施工单写「在易伤第二发那次 `Hurt` 上补 `kind: DamageKind.VulnerableCombat` 且 `deathType = IsPlayerTurn() ? …`」。
**现读代码：我们的引擎没有「易伤第二发那次 `Hurt`」** —— 两条合并在**同一个** `ApplyDamageCore` 里结算
（`actual = 主伤 + vulnSecondPart`，只拆成两条 `EvtKind.Hit` 事件）。所以按字面照做**无法落点**。

改法（判据 = `BattleManager__GetDeathType.c` 全文 457 行现读）：

1. **`RuleCore.DeathTypeOfSource` 改成原版整张表**（`DeathTypeOfSource(ctx)` = `DeathTypeOfSource(ctx, 3)` 保持原调用点语义）：
   - `:133-146` 来源卡 `IsSpellType`（`tactic` / `defence` / `whispers`）⇒ **30 Tactic**（先判，压过下面三档）；
   - `:366-373` `damageType == 8 (VulnerableCombat)` ⇒ `来源卡.isPlayer == IsPlayerTurn()` ? **10** : **15**
     —— `.c` 原文是 `cVar14 = *(char*)(lStack_110 + 0x40); cVar15 = IsPlayerTurn(bm); if (cVar14 == cVar15) return 10;`，
     `+0x40` 经 `EntityScript__get_isPlayer.c` 现核 = `isPlayer`（**不是** R-W 简写的「只看 `IsPlayerTurn`」）；
   - `:373` 位掩码 `0x1088`（damageType ∈ `{3 Ability, 7 Vulnerable, 12 RandomAbility}`）⇒ **20 Ability**；
   - `:415` 其余 ⇒ **0 Unknown**（原版 `uVar16 = 0`）—— 顺带把施工单「建议把兜底 20 改成 0」做掉了（今天是 no-op：4 个调用点都传 3）。
2. **「谁打死的那一下」**：`ApplyDamageCore` 新增 `out bool killedByVulnerable`（`vulnSecondPart > 0 && u.Health - actual <= 0`，
   位置在 `u.Health -= actual` 之前，行内追加）⇒ `HurtCore` 末尾那句 `RemoveIfDead(...)` 改为
   `(vulnKilled && DamageTypeOfKind(kind) == 4) ? VulnerableCombatDeathType(ctx, actingCard) : deathType`。
   **只改战斗档**（`DamageTypeOfKind(kind) == 4` ⟺ `kind ∈ {Melee, Ranged}` ⟺ 原版 `damageType == 4 Attack`，也就是第二条 DamageInfo 变 8 的唯一条件），
   **其余路径逐字不动**（反击 / 爆裂 / 践踏 / 哨戒 / 标记光 / 疲劳的 `kind` 都不是 4 ⇒ 不命中）。
3. **`isPlayer` / `IsPlayerTurn` 的等价物**（本仓「这一方是不是电脑」的唯一判据 = `ctx.IsBotSeat`）：
   `isPlayer ⟺ !ctx.IsBotSeat(卡主座位)`、`IsPlayerTurn ⟺ !ctx.IsBotSeat(ctx.Active)`。
   ⇒ **单机对电脑**：攻击方只在自己回合出手 ⇒ 两布尔恒同值 ⇒ **恒 10**；P2P（`BotSeat < 0`）⇒ 两布尔恒真 ⇒ **恒 10**。
   只有「在**对方**回合出手的攻击」才会落到 15（白名单外、静默）—— 与 `.c` 的实际落点一致。
4. ⚠️ **卡主座位取不到**（`SeatOf` 返 `-1`，如来源卡已离场）⇒ 按 `isPlayer = false` 并**出声**。如实记：
   原版 `isPlayer` 是**卡上的一个布尔**、离场后仍可读；B24 的 `OwnerSeat` 只在**棋盘写点**铺开，离场前的值能留住，
   但**从未上过场**的来源卡仍是 `-1` ⇒ 差这一档（不猜）。

**今天可观测性 = 0**：现池 `cards_engine.json` 1,127 张的 `abilityTriggers` 含 **175 = 0 张** ⇒ 这条新路径不会让任何卡多响一次。
