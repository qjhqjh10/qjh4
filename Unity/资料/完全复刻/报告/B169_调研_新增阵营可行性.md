# B169 调研：新增阵营 / 新卡 / 新机制 —— 「只新增文件」可行性

> 只读调研 · 2026-11-07 · **未跑游戏 / 未跑 Unity**。运行时才成立的结论在 §八 标注。
> A = 离线版原版客户端 + MelonLoader mod（IL2CPP，无法重编译）；B = 复刻工程 `d:/4/Unity/MyGame`。

## §一 结论速览

**A · 离线版**
- **新卡（复用现有插画/音效/动画）+ 现有 trigger/effect/buff 能表达的机制 ⇒ 可行**，**一个原版文件都不用改**：mod 里 `ScriptableObject.CreateInstance` 造 `RawCardScript` → 写字段 → `CollectionManager.AddCard`。
- **新阵营（第 14 个）⇒ 部分可行**：`CardArmy` 是编译期枚举、加不了名字；但**卡上的阵营是普通 int 字段**（`ObtainableItem.cardArmy // 0x2C`），塞未占用值（如 140）后数据/卡组/战斗都通。**唯二硬阻塞** = 两处「按 army 查表、缺键抛异常」：`CardFramesSO.GetClanFrame` · `ArmyBackgroundsSO.GetMediumBackground` ⇒ 必须 Harmony 兜住或运行时注入 SO 条目。
- **全新效果种类**（新 buffType / 新 AbilityEffect / 新 trigger 语义）⇒ 部分可行，**必须 Harmony 拦截**（改的是运行时方法，仍不动原版文件）。
- ⚠️ **新插画/音效要走新 bundle**（自建包 + `AssetBundle.LoadFromFile` + Harmony 改 getter），catalog 加不了条目。~~bundle 必须用 Unity 6000.2.6f2 打~~ 🔴 **2026-11-07 实测推翻**：用 **6000.3.23f1** 打的最小包（Sprite+Texture，2,509 B）在 **6000.2.6f2** 客户端 `AssetBundle.LoadFromFile` **加载成功**（`bundlecompat.tsv`：`LOAD result=OK` · `ASSETS count=2` · `SPRITE … -> OK rect=32x32 tex=32x32`）⇒ **跨版本可用，不必装 6000.2.6f2**。⚠️ 未验：Shader / AnimatorController / MonoBehaviour 脚本类资产（这三类仍可能不兼容）。

**B · 复刻工程** — **完全可行**：卡是 JSON（faction 是字符串），美术是 `Resources/Art/cards/art_<id>.png`，加卡 = 加数据 + 加图。新阵营只补几张 13 条表 + 写新机制 handler，无不可逾越阻塞。

**回答用户顾虑**：**B 里「只新增文件」100% 成立；A 里「不碰原版代码」不可能（本来就要 mod 拦截），但「不碰原版数据资产」基本可以做到**（详见 §六）。

### 2.1 枚举本身 — `dump.cs:45634-45652`
`Neutral=0, Ultramarines=10, Goff=20, SaimHann=30, Sautekh=40, BlackLegion=50, Leviathan=60, TauEmpire=70, Sororitas=80, Genestealers=90, AstraMilitarum=100, DarkAngels=110, EmperorsChildren=120, SpaceWolves=130`
- **14 个成员**（Neutral + 13 阵营），值域 0 与 10…130，步长 10。**空位**：5/15/…/135 全空；140 及以后也空。
- 另有 `CardArmyOrdered`（`dump.cs:45655-45673`）同样 14 个，但 **`SaimHann = 55`**（不是 30）—— 两套编号别混。

### 2.2 关键：卡上的阵营**不是枚举字段**
- `ObtainableItem.cardArmy // 0x2C`（`dump.cs:18774`），类型写 `CardArmy`，**实际 4 字节 int**。

- ⇒ 运行时用 140 这种「枚举里没定义的值」**数据层合法**；没有字段校验、没有 `Enum.IsDefined`。

### 2.3 玩法主链没有穷举 CardArmy
`typeof(CardArmy)` / `Enum.GetValues` 落点：`DebugCardPickerGrid.cs:238/316/326`（调试选择器）、`ArmyUtilities.cs:115`（只取类型）、`RankedScoreBoostData.cs:36`、`FeatureConfig.cs:694`、`MainTutorialManager.cs:509`（按阵营建表，未定义值只是「不出现」）。

### 2.5 能不能「只靠 mod 加枚举成员」
- **不能加名字**（编译期元数据）；**能加值**（`cardArmy` 是 int，用 140）。
- `.ToString()` 对未定义值在 .NET 返回数字串（⇒ `CardArmyToString` = `"Armies/140"`）—— **⚠️ 游戏内未实测**（§八-1）。
- **保守替代**：复用现有 army 值、用另一维度区分（`expansionPack` / `refNameId` 前缀）；代价是与那个阵营混在一起。

## §三 新卡怎么进游戏（A）

### 3.1 加载链
```
AddressableCardLibrary(AssetLabel) → BaseAddressableLibrary.LoadLibrary(canUpdate)
  → Addressables.LoadResourceLocationsAsync(label)        // 每个地址 = 一张卡
  → 逐条 GetLocalHandle → LoadAssetAsync<RawCardScript>() // AddressableCardLibrary__GetLocalHandle.c
  → AssetCompletedLoading → CollectionManager.AddCard(card)
```
- `CollectionManager`（`dump.cs:71591`）三桶：`FullHeroCollection +0x20`（`cardType==10`）/ `FullCardCollection +0x28`（其余）/ `AllCardCollection +0x30`（全部）。
- `AddCard(RawCardScript)` 是 **public**（`dump.cs:71606`），谁都能调。
- `GetRawCardFromId(id)`（`dump.cs:71618` / `CollectionManager__GetRawCardFromId.c`）**只查 FullCardCollection + FullHeroCollection**，不查 AllCardCollection。

### 3.2 三条路
| 路线 | 可行性 | 说明 |
|---|---|---|
| **① 运行时注入**（推荐） | ✅ 可行 | `CreateInstance("RawCardScript")` → 按 `dump.cs:23244-23310` 偏移写字段 → `CollectionManager.Instance.AddCard(card)`。**mod 已有先例**：`Probes/CurrencyFixProbe.cs:180-192`（`CreateInstance("Currency")`）、`:304-330`（`AssetReferenceTyped<Sprite>(guid)` + 原生指针直写）。时机：`AllCardCollection.Count>0` 后幂等补一次（仿 `ProfileFixProbe.Tick`） |

## §七 推荐路线与风险

### 7.1 A（离线版）
1. **新卡**：mod 里建 `NewFactionContent`，等收藏载完后 `CreateInstance<RawCardScript>` + 写字段 + `CollectionManager.AddCard`；**技能树 `DeepCopy` 克隆现有卡再改**。
2. **新阵营值**取 **140**（延续步长 10），并同时：拦 `CardFramesSO.GetClanFrame`（缺 key 借现有阵营的框或返回 null）· 拦 `ArmyBackgroundsSO.GetMediumBackground` · 往 `ArmyIconsSO` list append（可选，纯观感）· 拦 `LocalizationManager.GetTranslation` 返回 `Armies/140` 等文案。
3. **假服务器**加 `WildcardConfig`（+4 条）与 `AlliancesConfig`（+奖杯）。
4. **新机制**：能拼现有 effect 就纯数据；不能就 Harmony 拦 `CardScript.AddEffect` / `AbilityLogic.PlayAbility`。
