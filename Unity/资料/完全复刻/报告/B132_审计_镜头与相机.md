## 〇 · 结论三句

1. **战斗相机（BoardCamera）的光学部分逐值对齐**：投影模式 2、焦距 28、fov 46.397182、lensShift、near 0.3、逐场 far、逐场 sensor（41.5 或 37.2）、13/13 一致。差的是**清屏色 / cullingMask / 标签与 AudioListener 归属 / GSC 那台相机的 0.006° 旋转**。
2. **HUD 相机整台是另一套模型**：原版 `UI Camera` = **透视 fov 40 / 近 0.3 远 300 / mask 32（仅 UI 层） / clearFlags 4（不清屏） / 专用 UI renderer（rendererIndex 1）**；我们 `Main Camera` = **正交 size 5 / fov 60 / 近 0.01 远 200 / mask 4294966015 / clearFlags 2 / 主 renderer（−1）**。这是已有账 `D118-85` / `D-1` 指向的同一件事，本轮把**另外 14 个字段**也取到了值（见 §B）。
3. **震屏与运镜的数值已全部对齐**（包络 `t²` + 三次 Hermite、近战 gain 2/4/8、方向 = 归一化攻击方向、13 场开场 clip 逐字节一致）；**唯一还差的是「震屏 × 开场运镜」写同一台相机 transform 的时序冲突**，以及**进战斗黑场的缓动是线性（原版 OutQuad）**。
