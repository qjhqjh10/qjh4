## 二 `GetState` 六档（本批独立项 · 全表）

### 2·1 六档：状态值 | 条件（逐条） | 出处 | 我们 `IsInPeriod` 差在哪

原版 `LiveOpState` 枚举值（`out_cpp2il_dev_ilspy/LiveOpState.cs`）：
`NotAvailable = -1, Planned = 0, OnPreview = 1, Active = 2, Finished = 3, Expired = 4`。

### 2·2 `IsActive(now, includePlanned)`（同样是判据，且**有个坑**）

`decomp_full/Everguild.LiveOps.LiveOpsEventData__IsActive.c` 全文可直译：
`!enabled ⇒ return includePlanned`；否则 `state = GetState(now)`，
`(includePlanned && state == Planned) ⇒ true`；`state ∈ {Active(2), Finished(3)} ⇒ true`；`state == OnPreview(1) ⇒ true`；其余 false。
⇒ **`Finished` 也算 active**（连 `Expired` ≠ active）——这就是账里那句「原版 `IsActive` 连 `Finished` 都算 true」的准确形状。
消费者实例：`ShopStore.cs:372` 用 `IsActive(now, false)`；`FixedStoreData.cs:72,139` 用 `IsActive(now, true)`（含 Planned）。

### 3·1 结构（`decomp_full/TMProWarpText__*.c` + `out_cpp2il_dev_ilspy/TMProWarpText.cs`）

| 方法 | 判据（可直接照写） |

### 3·2 `WarpText()` 逐句

1. `if (!text) return; isForceUpdatingMesh = true; text.havePropertiesChanged = true; text.ForceMeshUpdate();`
2. `ti = text.textInfo`；`ti == null || ti.characterInfo.Length == 0 || ti.characterCount == 0 ⇒ return`
3. `minX = bounds.center.x − bounds.extents.x`；`maxX = bounds.center.x + bounds.extents.x`
4. 逐字符（只处理 `characterInfo[i].isVisible`）：
   - `midX = (verts[v].x + verts[v+2].x) * 0.5`（`0.5` = `0x1834b2bb4`）；`baseY = characterInfo[i] +0x144`（`baseLine`，见「还差」）
   - 四个顶点先 `-= (midX, baseY, 0)`
   - `nx = (midX − minX) / (maxX − minX) + 0.0001f`（`0x1834b2f48 = 0.0001`）
   - `y0 = curve.Evaluate(nx) * yCurveScaling`；`y1 = curve.Evaluate(nx + 0.0001f) * yCurveScaling`
   - `dy = y1 − y0`；`dx = ((maxX − minX) * nx + minX) − midX`
   - `angle = Atan2(dy, dx) * Rad2Deg`（`0x1834b2e98 = 57.2958`）；**`if (!(dy > 0)) angle = 360 − angle`**（`0x1834b2bc4 = **360**`，不是 180）
   - 旋转/位移（`.c` 直译）：`Axis.Y` ⇒ `pos=(0, y0, 0)`、`euler=(0,0,angle)`；`Axis.Z` ⇒ `pos=(0,0,y0)`、`euler=(0,−angle,0)`；`scale = Vector3.one`（`Deg2Rad = 0x1834b2dc0 = 0.0174533`）
   - `M = Matrix4x4.TRS(pos, Quaternion.Euler(euler), Vector3.one)`；四顶点 `M.MultiplyPoint3x4(...)`
   - 再 `+= (midX, baseY, 0)` 还原
   - 每个字符处理完调一次 `text.UpdateVertexData(TMP_VertexDataUpdateFlags.All)`（vtable `+0x808`）
5. 循环结束 `isForceUpdatingMesh = false`

### 3·3 🔴 出货值 ≠ `Reset()` 的默认值（状态 → 参数，铁律 5·c）

`assets_full` 里带 `yCurveScaling` 的 **MonoBehaviour 实例 = 34 个，全在 `bundle_boosterpacks_assets_all`**（= 开包界面）：

| 参数 | 34 个实例的实测值 | 说明 |
|---|---|---|
| `axis` | **1 (= Axis.Z) ×34** | ⛔ `Reset()` 默认的 `Axis.Y` 分支**没有实例** |
| `yCurveScaling` | **−0.09 ×34** | 不是 `Reset()` 的 `100f` |
| `vertexCurve` | **两种曲线，各 17 个**：A = 3 键 `(0, 0.0284, slope 5.888, outW 0.0254) → (0.5, 1.0) → (1, 0, slope −9.2866)`；B = 5 键 `(0, −0.3843) → (0.0635, 0.1453) → (0.1238, 0.5256) → (0.5, 1.0) → (1, 0, slope −5.9425)` | 每个实例自带曲线 |
| wrap | `m_PreInfinity = m_PostInfinity = 2 (Loop)` ×34 | `Reset()` 给的是 `Once` |

⇒ 复刻时**三样都要**：`Reset()` 的编辑器默认（编辑器里新建组件才出现）+ 实例上的真实曲线（开包界面用）。
