### 2.2 分辨率变了怎么触发（壳侧发射源）

`ShellRuntime.Update` 每帧 → `TickAspectClamp()`：比 `Screen.width/height` 与上一帧，变了就调
**自己那件**的 `AdjustCameraViewport()`。

- 第一次只立基线、不抬（守卫照抄 `BattleCameraSreenSize.Tick`）。
- ⛔ **不抬那条静态事件** `BattleCameraSreenSize.ScreenResolutionChanged` —— 战斗里的 `BattleCameraSreenSize`
  也订着它，两边同时抬会把 `ResolutionHasChanged`（起 DOTween 补间）跑两遍。

  `ScreenResolutionChangeSignal`，**谁抬的在全反编译里查不到**；壳侧又没有战斗那个 `BattleCameraSreenSize`
  ⇒ 只能自己比屏宽高（与 `BattleCameraSreenSize.Tick` 同一手法）。

## 3 🔴「两族读像素」复核（简报点名；⛔ 一个都没改 `Core/LayoutSpace.cs`）

| 族 | 位置 | 结论 |
|---|---|---|
| ① 直读 `Screen.width/height` | `Core/LayoutSpace.cs:167-181 IsInsideScreen` | **不需要改**。它的调用面只有战斗侧 `BattleDriver.WorldPointer`，而原版 `BattleManager.GetMousePerspectivePos` 的判据**就是整屏**（`0 <= x && x < Screen.width …`）⇒ 跟着相机 `rect` 缩反而**偏离原版**。已用断言 E1 把「仍是整屏」钉死（改坏法：改读 `pixelRect` ⇒ E1 红） |
| ① 直读 `Screen.width/height` | `Shell/MainMenuRuntime.cs:2777` | **这行是注释，不是代码**（模式卡视差那一段的说明：「`屏幕x / Screen.width` 恒等于 `设计x / 1920`」）。⚠️ 夹取之后**这个等式不成立了**（画布只铺在 viewport 里）⇒ 真正的代码路径 `ModeCardParallaxDu` 已改走 `ScreenNormalizedXForDesignPx`（见 §3.1），`Screen.width` 那一半本来就**没在跑** |
| ② `ToPixel` | `Core/LayoutSpace.cs:234`（x 斜率写死 108） | **不需要改**。「只在 16:9 等于真值」这条性质**不因夹取而改变**：夹取改的是 `Camera.aspect` ⇒ `VisibleWidth`，而 `ToPixel` 的 x 斜率本来就与 `VisibleWidth` 无关（这是它已知的缺陷，账 `A990②`）。正确的逆 `ToDesignPixel`（`:299`）走 `PxPerWorldX = 1920 / VisibleWidth`，是**viewport 相对**的 —— 夹取后 `VisibleWidth = 10 × 夹取后 aspect`，设计 px 仍然「0..1920 = 画布那一条」，**定义不变、仍自洽**。已用断言 E3 把这条耦合钉死（`VisibleWidth = 10 × 夹取后 aspect`） |

### 3.1 顺手发现**已修**（同一族，属白名单内）

主菜单模式卡视差（原版 `UIParallaxImage.UpdateParallax`）写进材质的 `_ScreenPosition.x = sp.x / Screen.width`
（**整屏**分母）。我们原来是 `设计x / 1920` 的**烘死近似** —— 只在「画布铺满整屏」时成立；夹取后
画布只占 `cam.rect` 那一条 ⇒ 差 `rect.x + (设计x/1920)×rect.width` 与 `设计x/1920` 的那一截
（32:9 每张卡最多差 **0.031 UV × `_Parallax.x`**）。

- 新口：`MainMenuRuntime.ScreenNormalizedXForDesignPx(float)`（`float` 折算，`rect` 取 `LayoutSpace.Cam.rect`）。
- `rect = 整幅 (0,0,1,1)`（所有 4:3~22:9 的屏，含批处理 640×480）⇒ 与旧式**逐位相同** ⇒ **既有读数一条都不动**。
- 断言 E2 四条（0 / 1920 / 960 / 整幅档）。
