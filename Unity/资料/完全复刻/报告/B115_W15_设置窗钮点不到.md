- `Describe(node, x1,y1,x2,y2)` —— **一行说完**七格：① 节点在不在 ② **最近视口**（`ViewportClip.FindAbove` + `ClipPx`）

- `Report(...)` —— **两档分开说**：钮不在激活链上 ⇒ `Debug.Log`「这一刻判不了」；否则 ⇒ `Debug.LogError`「**点不到**」。

**为什么旧探针永远不会响（这次一并写进了代码注释）**：
`MenuDraw.Hit` 返回 `null` 只有一条路 —— `ClipRect(r, PaddedClip(clip, maskPad), out hr)` 判「整块在框外」
（`Shell/MenuDraw.cs:2235`），而它前面两句是 `if (IsNoClip(clip)) return true;` / `if (!clip.HasValue) return true;`
⇒ **`clip` 非空才可能返回 null** ⇒ 只有**父链上真的挂着 `ViewportClip`** 时才可能。
设置窗 4 处 `ViewportClip.Hang` 全建在**子件或兄弟**上（`:1874` 页签遮罩 · `:3657` 语言列表 · `:3901` 音频页 · `:4516` 图像页），
`General` / `Online` 两页的父链上**一个视口都没有** ⇒ 旧探针恒不触发（连「判不了」都不会说）。
另外旧文案「⇒ 点它只会落到吸收层 `AbsorbHit`」**归因是错的**：吸收层档 = `qContentMin − 1` = **3134**（`MenuDraw.cs:2507`），
钮 = `QOverlay` **3135** ⇒ 吸收层**严格更低**，就算钮在也**永远赢不了**它。已就地改掉（铁律 5）。
