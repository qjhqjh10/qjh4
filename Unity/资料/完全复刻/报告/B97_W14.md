### 与施工单的**一处有意的差异**（附理由，请调度台知悉）

施工单 ③ 只写了 `_angle = Step(...); localRotation = ...`，**没提 active 闸**。我加了一道：

```csharp
if (!_lwCog.gameObject.activeInHierarchy) return;
```

**理由（照抄原版，不是我们自己设计）**：原版 `SimpleRotation.Update` 挂在 `Cog` 上，而 Unity 对
`m_IsActive = 0` 的物体**根本不调 `Update`** ⇒ `ErrorMensajeContainer` 关着时那颗齿轮是**冻住**的
（`BuildLoginWindow` 末尾那句 `setActive(false)` 是它唯一的写点）。不加闸 = 会在看不见的时候继续累计角度，
虽然肉眼无差（重新显示时角度两边都是任意的），但那是**与原版不同的运行状态**。
⇒ 按铁律 18·0「默认照抄原版」加闸；同族先例 = `B97_HUDROT` 对 39 个竞技场 `Highlight` 也是「只推进 activeSelf 为真的那一颗」。
