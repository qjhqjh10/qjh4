1. **`CardsSpecialConfig` 的 `expansionData.Length`** —— 决定 `Where get cards` 钮在原版到底显不显示。本机**无该 SO 实例**（只有类桩）⇒ 真值拿不到。我们默认 `true` 并打 🔶。**这使 GachaEventTab.Initialize 维持 B 而非 A**（若原版该 config 为空则会隐藏，我们默认会显示 ⇒ 潜在可见差）。
2. **`ExpansionPassPurchasePremiumPanel` 的 `+0x60` 委托是什么**（`b__12_1` 调它）—— 方法体是间接跳转（`jumptable 未恢复`），只知道两个实参 `(0x40, 0x28)`。但整条链卡在服务器 premium 数据 ⇒ 不影响本地落地。
3. **VIP 到期时刻** —— `InventoryManager.GetExpirationDate(RequiredItem)` 机制在本地，但 `RequiredItem` 来自 `DailyStoreData`（远端 store SO 未导出）⇒ 计时器恒 `--`（账 `商店:325` 已记）。
4. **本代理无法验证 Editor 程序集编译** —— `typecheck.sh` 的**运行时程序集被别的代理的半成品挡住**（本轮先后撞到 `ProfileTab.cs` / `ItemDrawer.cs` / `TimerDisplay.cs` 的 `CS0103/CS0246`，均非我的文件），导致 `WFCheck.dll` 没产出、编辑器程序集报 `CS0006` 级联。
   ⇒ **`GachaEventWindow.cs`（运行时程序集）本轮无任何报错 ⇒ 已编过**；`Editor/ShopFamilyAssertB94S1.cs` + `ShopScene.cs`（编辑器程序集）**本轮没能被 csc 实测**，只做了括弧配平 + 逐符号核对（对 `GachaEventWindow` 的三个新 public 成员、`ShopTabPage.PageShowsTimer/VipPage/SetHost`、`CheckSink/MenuCheck/MenuNearStyle` 用法均与已编译的 `B93S1` 同形）。**请在同步点补跑一次 `ShopScene.Run` 或等 ProfileTab/ItemDrawer/TimerDisplay 编过后重跑 typecheck。**
