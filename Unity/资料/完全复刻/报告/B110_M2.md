## §`Shell/ParentEventWindow.cs` 的 #11 补丁

> ✅ **已落盘，本代理已核**：`B110_D4` 把它做成了类尾的 `ApplyEventUiMaterial(ImageQuad q, bool scanLines)`
> （`Shell/ParentEventWindow.cs:2566`）+ 调用点 `:1086`：
> ```csharp
> ApplyEventUiMaterial(
>     MenuDraw.Rect(page, Tex(ArtGlow, "选择阵营页的扫描线"), Scr(P1ScanLinesR), "Scan Lines", QPageArt, Color.white),
>     true);
> ```
> 它 `Resources.Load<Material>("Art/vfx/WFUI_ScanLines")` → 退路 `Shader.Find("WarpforgeVFX/UI/Scan Lines")` → 告警退回静态图。
> **本代理的两份产出与它逐字对齐**（`.mat` 落盘名 `Resources/Art/vfx/WFUI_ScanLines.mat` ·
> shader 名 `WarpforgeVFX/UI/Scan Lines`）⇒ **D4 那条路会走 ①，不会走告警分支**。
> 断言里也断了这条契约（`CheckWiring()` 的两条）。
>
> 若将来那一跳被回退，**等价补丁**（插在 `Shell/ParentEventWindow.cs` 现有 `ApplyEventUiMaterial` 之前即可，一步到位）：

```csharp
// 原版节点：`Two Sides Event Window` → `Scan Lines`（sprite = `Glow UI W40K`）
// 材质 = `Material_-8529927314253658951.json` → `Resources/Art/vfx/WFUI_ScanLines.mat`
// shader = `WarpforgeVFX/UI/Scan Lines`（逐指令复刻，见 `Resources/Shaders/WFUIScanLines.shader` 文件头）
static void ApplyScanLines(ImageQuad q)
{
    if (q == null) return;
    var proto = Resources.Load<Material>("Art/vfx/WFUI_ScanLines");
    if (proto == null)
    {
        var sh = Shader.Find("WarpforgeVFX/UI/Scan Lines");
        if (sh != null) proto = new Material(sh);
    }
    if (proto == null) { Debug.LogWarning("[Event] 取不到 `WFUI_ScanLines` ⇒ `Scan Lines` 退回静态图"); return; }
    Color tint = q.Tint;
    var inst = new Material(proto);            // ⛔ 别挂共享本体（队列/染色会被后盖掉）
    if (inst.HasProperty("_Color")) inst.color = tint;
    q.SetMaterial(inst);
}
```

调用点（把 `:1086` 那一行换成「先取回 quad、再换材质」）：

```csharp
var scanLinesQ = MenuDraw.Rect(page, Tex(ArtGlow, "选择阵营页的扫描线"), Scr(P1ScanLinesR), "Scan Lines", QPageArt, Color.white);
ApplyScanLines(scanLinesQ);
```
