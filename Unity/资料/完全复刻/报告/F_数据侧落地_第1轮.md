## ⑥ 顺手发现

1. 🔴 **`gen_cards_engine.py` 有两条互不相干的建行路径**（主循环 + 隐藏附魔模板），
   任何新增的「每张卡都该有」的列**必须在两处都加** —— 否则那张附魔模板会成为池里唯一的 `null`，
   而这是**已经踩过一次**的坑（`:3979` 那段注释就是上次的复盘）。本轮 diff 当场抓到了这一次（1,127/1,128）。
2. 🔴 **`export_trait_collection.py` 的 GUID 解析面比它以为的窄**：只扫 `*cardanim*` 包。
   `customObject` 允许指向任意资产（Sprite / GameObject / CardAnim），这类解析**天生会漏**。
   ⇒ 建议所有「按 GUID 反查资产」的脚本统一走**全 bundle 的 container 索引**（`guid_map_bundles.tsv` 那套）。
3. **改数据前先备份是必须的**：本轮三个 BEFORE 备份都在 `_tmp_view/wfres/`，任何一条 diff 不对都能立刻回滚。
4. **`cards_engine.json` 的列集合本来就有 22 种形状**（不是这次引入的）—— 这张表**不是严格 schema 的**，
   所以「只加一列」这种改动的风险主要在**读取侧**（`CardDatabase` 是否按列存在性分支），不在写在侧。
