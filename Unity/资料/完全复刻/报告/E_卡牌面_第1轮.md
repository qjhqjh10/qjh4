## ⑥ 顺手发现

1. **「Top30 缺口」里的 `TraitDescriptionUI` 是幻影**：不只是它，整族 `TraitDefinitionDisplay` + `TraitDescItem` + `TraitDescriptionUI`
   （19 类里的 3 个、**27 个方法**）在本 build **不可达**（证据见 §2.1）。现存的 trait 提示由 `EverguildTooltipItem` 族承载
   （我们 `Core/Tooltip.cs` 已经复刻）。⇒ 这 27 条以后不要再当「缺口」排活（除非证据更新）。
2. **`CardTextCountersController.SetText(int)` 的真实默认参数**：`decomp_full/CardTextCountersController__SetText.c` 是 2 参转调
   `SetText(x, -1, -1, 0, 0, 0, 1)` —— 即 `currentValue=baseValue=-1`（**不涂色**）、`removeContainerIfBelowZero=1`。
   这解释了「初始 `SetText` 不涂色」那条既有结论，可以放心。
3. **`colliderHeightMultiplierInHand` 的类默认值 1.2 是个陷阱**（§2.1）—— 谁照 C# 常量改，卡的可点区会高 19%。
