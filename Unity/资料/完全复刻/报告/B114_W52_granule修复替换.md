> 用 Python `subprocess.run(["cmp","-s",pathA,pathB])`（`shell=False`）调 `cmp` 时，**`VO_Tau_Empire_Aun'va_*.ogg` 这 13 份返回 rc=2（无法打开）**，其余 437 份返回 0。

> ⇒ **这是 Python `list2cmdline` 与 MSYS2 `cmp.exe` 的 argv 解析在 `Aun'va`（小写 `'va`）上的引号重排伪失败**，**不是文件不同**。
> 判据：同目录下 `Aun'Va`（大写 V，`VO_Sautekh_Ramatekh the Cruel_vsAun'Va.ogg`）与 `Aun'Shi` 走同一条 subprocess 路径**都返回 0** ⇒ 与内容无关。
> ⇒ **以后用 Python 批量调 MSYS 的 `cmp`/`diff` 要警惕**；要么 `shell=True`，要么直接用 Python 全文比较。
