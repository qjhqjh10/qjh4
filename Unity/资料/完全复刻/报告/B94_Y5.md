### 2.3 `ShowStartingPointer` / `ShowClickedPointer` / `GetAdjustedPos`（逐句）

**`ShowStartingPointer.c`**
- 位置 = `GetAdjustedPos(clickPos, orientation)`；`useLocalPositions(+0x50)` 决定 `position` 还是 `localPosition`（本 prefab = 0 ⇒ world）。
- `localScale`：`param_3==0(right)` ⇒ 静态常量 `Vector3.one`；`left` ⇒ `(DAT_1834b2bc8=-1, DAT_1834b2bb8=1, 1.0)`。
- `rotation`：`Euler(0, left? DAT_1834b3358*π/180 : 0, DAT_1834b3350*π/180)` = **`(0, left?-180°:0°, 40°)`**。
- `bgLight` 的 sprite alpha 置 **0**。
- 末句 `SetActive(pointer.gameObject, showPointer(+0x71))`。

**`ShowClickedPointer.c`**
- 位置 = `GetAdjustedPos(clickPos, orientation)`。
- `localScale`：`right` ⇒ `(0.7, 0.7, 0.7)`；`left` ⇒ `(0.7×-1, 0.7, 0.7)`。
- `bgLight` sprite alpha 置 **1**；`clickAnim != null` 才 `Instantiate(clickAnim, clickPos)`（本 prefab **null** ⇒ 不实例化）。
- ⚠️ **这一支不设 rotation**（只有 scale）—— 旋转只在 `ShowStartingPointer` 里设、每轮 cycle 起点重设。

**`GetAdjustedPos.c`**
```
offX = xOffset(+0x5c);  if (orientation != 0) offX ^= 0x80000000（取负）
y    = yOffset(+0x60)
return ( clickPos.x + offX , clickPos.y + y , <指针当前 z> )
```

## 5. 没查清 / 未做（如实记）

1. **`left` 朝向的视觉是否符合原版** —— `localScale=(-1,1,1)` **与** `Euler(0,-180,40)` 同时存在。在**平 quad** 上，「绕 Y 转 180°」在屏幕投影等效于水平翻转 ⇒ 与 `scale.x=-1` **可能叠加成双翻**。我**逐值照抄**（这是 `.c` 的硬判据，不是猜），但**未在真机看**。⚠️ 今天**生产链路全部走 right**（`BattleDriver` 两处都传默认）⇒ 该分支只被断言走到、**零可见风险**；等真要用 left 时先真机看一次。
2. **`bgLight` 第二张图**未建（见 §3.1）—— 点击态「高光 alpha 0→1」这一半**视觉上没有**，断言也没断它。
3. **canvas 档的 DOMove 语义** —— 原版 `DOMove` 是改 `transform.position`；我们统一按**世界点插值 + `CvPlace`** 落位（沿用本件现有两档口径，16:9 下逐位相同）。真机在非 16:9 下未验。
4. **`SetPointer` 现在会加 (2,−2) 世界偏移并来回缩放** —— 这是原版语义（此前我们既没偏移、也没动画）。⚠️ 对现有调用点（`BattleDriver:17997` 教程指针、`:35667` 狂暴指针）是**可见变化**：指针相对锚点会朝右上方错开约 2×108 px 并开始 0.7↔1 的呼吸。**建议真机验收时看一眼**（无断言钉位置，不会红）。
