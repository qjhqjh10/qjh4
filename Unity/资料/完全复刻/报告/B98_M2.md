## 一、现状（改前 → 改后）

**改前**：`CardPresentation/Shell/DraftEventBase.cs` 的 `CurrentDraftState` 是**反推**（我们没持久化原版 `DraftEventBase + 0x28` 那一格），

活动到期时永远不会 `FinishRun()` 收尾「正在跑的一局」，只会打那句 `Trying to finish an unstarted run`。

**改后**：反推按 `DraftModeWindow.UpdateState` 的 ①②③ **逐句**补齐了 `SelectPack(10)` 与 `OngoingRun(15)` 两档

**映射表（改后；左 = 本局存档 `DraftRunSave`，右 = 反推出的 `DraftModeState`）**

| 状态 | 判据（`DraftModeWindow.UpdateState` 的 ①②③） | 产出 |

| 没有一局 | `RunForTest == null` | `Intro(0)` |
| 已收尾（①） | `joinState == Finished(2)` **或** `matchesLost >= MaxTries(3)` **或** `matchesWon+matchesLost >= MatchesToFinish(4)` | `Finished(20)` |

| **正在跑一局（③后半）** | `pickedKeys.Length >= RoundsPerDraft` | **`OngoingRun(15)`** ← 本轮补的那一档 |
