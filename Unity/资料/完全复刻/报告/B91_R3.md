## §四 · 本批新取到的判据（供后续批直接用）

1. **`ParentConstraint.Sync()`（菜单 525）prefab 实读**（`assets_full/bundle_battleprefabs_vfxandmisc_assets_all/MonoBehaviour/MonoBehaviour_-4995210038592889920.json`）：
   `targetParent` = 某 Transform（= `3DBody`）· **`inheritPosition=1` / `inheritRotation=1` / `inheritScale=1`** · `updateMethod=1`（LateUpdate）· `alignAxis=0` · `autoInit=1`。
   `.c`（`ParentConstraint__Sync.c`）三档：`+0x28`⇒`position = target.TransformPoint(childLocalPos)`；`+0x29`⇒`rotation = target.rotation * childRotOffset`；`+0x2a`⇒`localScale = Vector3.Scale(target.localScale, scaleOffset)`。
   🔴 **三个 offset 字段（`childLocalPos`/`childRotOffset`/`scaleOffset`）不在序列化 JSON 里** —— 由 `Init(target)` 在 `Awake` 时从「当前自身相对 target 的位姿」自捕获（ILSpy `ParentConstraint.cs:34-38,97-120`）。⇒ 复刻时**不要**从 prefab 抄 offset，要在建锚点那一刻相对 `_body3D` 捕获。
   ⇒ 结论：**必须新增一个 MonoBehaviour（类名==文件名才能被 `AddComponent`）**，白名单外 ⇒ 本批不能落；且 `_body3D` 相对卡根若不动，跟随是 no-op ⇒ 须运行时验证是否真有独立动画再定 A/等价。

2. **`AlliancesController.GetCachedGroupById`（社交 114）**：原版 = `groupListCache.Find(g => g.groupId == id)`（ILSpy `AlliancesController.cs:1349-1374`），返回 `Group`（消费者 `GetGroupById` 读 `.members`/`.memberCount`）。我方 `AllianceListing` 无 `groupId`、且只有 `Members(count)` 无 members 列表 ⇒ **不是等价物**，须先给行模型补 `Id`。

3. **`AlliancesManager.BuildCurrentMember`（社交 131）**：主体 = `EntityObjectsManager.GetObject<JObject>("groupPlayer")`（服务端实体缓存），再用 `PlayerDataManager.playFabId` / `entityKey.Id` / `PlayerAvatarDataManager.PlayerAvatarID/PlayerAvatarBorderID` 覆盖（ILSpy `AlliancesManager.cs:548-590`）⇒ **服务端依赖，离线 null**，不是本地可闭。
