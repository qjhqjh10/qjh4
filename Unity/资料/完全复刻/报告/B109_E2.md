### 1·2 `t = 2.0` 是 **AnimationEvent 自己的时间**，不是 clip 长度

`MyGame/Assets/CardPresentation/Resources/misc_clips.json`（生成器 `工具/gen_misc_clips.py`；源件 = `bundle_boosterpacks_assets_all/AnimationClip/*.json`）：

```
Booster Open Standard   length = 2.366666555404663   events = [{t: 2.0, function: "StartCardAnimationEvent"}]   curves 13
Booster Open Sororitas  length = 2.0                 events = [{t: 2.0, function: "StartCardAnimationEvent"}]   curves 12
```

🔴 **Standard 的末帧是 2.3667，事件却在 2.0** ⇒ 2.0 不可能由「clip 长度」推出来，它是事件表里写死的时刻。
（现成核对口 = `Editor/B98A5_Assert.cs:263-264`「★ 它在 **t = 2.0 s**」，那段本来就对。）

### 1·3 所以原版的整条时间线是

```
Initialize ──Instantiate──▶ 包实物 Animation（m_PlayAutomatically=1）自己播 Booster Open <阵营>
                            │
                     t = 2.0 │ AnimationEvent StartCardAnimationEvent
                            ▼
                  windowAnimation.Play()  ← 这才是「开包 clip」的起点（我们原来把它放在 Build 后第一拍）
                            │ 0.6166667 s
                            ▼
               AnimationEndEvent ⇒ 5 张卡 ChangeState(2)（可以点）

⇒「5 张卡可点」的原版时刻 ≈ Initialize + 2.6167 s。修前我们是 +0.6167 s，**早整整 2 s**。
```

```csharp
bool OpenTimelineGate()
{
```
