## 旧档第一次读会发生什么（逐句推演）

前提：`ShellRuntime.Awake` 的顺序是「先 `ImportAll()`、后 `RegisterMirrors()`」（判据 → `LegacySaveReader.cs:44-45` 那条注释）。

1. **真 Play 启动 → `ProfileData.EnsureSave()` → `LoadFromDisk()`**（`ProfileData.cs:1046-1076`）
   - `ReadThroughLegacy` 先中央 `CosmeticData`、再旧档 `profile.json`（`:1060`）。
   - 拿到 payload → `JsonUtility.FromJson<SaveDto>`（`:1068`）。旧 payload 缺 `achHighest` ⇒ `d.achHighest == null`
     ⇒ `:1076` 走兜底 **`_achHighest[id] = achValues[i]`**。
   - **结论：成就进度一条不丢；只丢「历史最高」这一格，而它本来就从未被存过**（11-04 之前没有这个键）。
     从这一刻起内存里的 `highest == current`，之后 `SetAchievementValue` 照常抬 highest（`HighestOnlyRises` 那一路）。
2. **`ImportAll()`（同一帧、`RegisterMirrors()` 之前）** —— 只有当中央档**已存在且缺 `achHighest`** 时才有动作：
   - `ImportProfile`：`centralPayload = GetRaw(CosmeticData)`；`MissingProfileFields(centralPayload)` **现在**返回 `` `achHighest` ``（改前返回 `null` ⇒ 直接 Skip）。
   - ⇒ 进 `TryFillMissingProfileFields(centralPayload, 旧档原文)`：
     - 其它 7 个键已在 ⇒ 一个都不动；
     - `!HasTopField(flat,"achHighest")` ⇒ `HighestForLegacyFill(旧档 DTO, 中央 DTO)`：
       旧档有这一列 ⇒ 逐 id 搬（并夹到 ≥ current）；旧档也没有 ⇒ 每条 id 写 `max(current,0)`（⛔ 不是 0）。
     - `merged = ToJson(c)` ⇒ `MissingProfileFields(merged) == null` ⇒ **这次真的补成功**（改前：重建出来的 payload 仍缺这一列 ⇒
       `TryFillMissingProfileFields` 返回 `false` ⇒ 报「补完还是缺」并**拒绝覆盖**）。
   - `SaveCenter.SetRaw(CosmeticData, merged)`：**只写法有差异的那一份中央档**；此刻双写表还没注册
     （`RegisterMirrors` 在后面）⇒ **旧档 `profile.json` 这一趟不会被写**。
   - 中央档已经有 `achHighest`（11-04 之后写过盘的）⇒ `incomplete == null` ⇒ **Skip，一个字节不动**。
3. **下一次 `SaveNow`（任何会落盘的改动/退出）**
   - `ToJson(_save)` 永远含 `achHighest`（空数组序列化成 `"achHighest":[]`，`HasTopField` 的空数组分支认它 ⇒ **闸不会误杀新档**，断言 A6 钉住）
   - ⇒ 中央档 + 旧档 `profile.json` **两份同时补上该键**，自此自愈。
4. **旧档 `profile.json` 本身缺这一列**（更老的档）：`ImportProfile` 整份转存那一支照旧（逐字转存，不改写）；
   补缺路径按上一条兜底 `max(current,0)`；`LoadFromDisk` 读它时走 `:1076` 兜底。**任何一条路都不写 0 覆盖真值。**

**可回滚性**：新增的只有一个顶层键，`JsonUtility` 对未知字段是忽略的 ⇒ 回滚到旧客户端读我们的 `profile.json`/中央档**不受影响**。
**这次唯一的行为变化**：缺 `achHighest` 的老中央档，在第一次跑 `ImportAll` 时会**被补一次**（改前是「Skip」）。
这是字段闸应有的行为（调度台已裁定「做」），而且只补该键、其余键原样保留。
