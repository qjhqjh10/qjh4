### 1·1 为什么是这三条

1. **`HandCardViewOf(player, null, instanceId)`**（`:39284`，T21-a 已存在且已接线）：`instanceId > 0` 时它**只按 `CardView.Inst.Id` 认**，同名两张不会猜；`owner != _me` 直接返 `null` —— 对手手牌没有 `CardView`，与原版 `AbilityLogic__PlayAnim.c:185-222`「对手手牌那一支 `LogWarning` 后跳过」同形。
2. **落在 `if (instanceId != 0)` 块内、`return ViewAt(slot)` 之前** ⇒ 顺序 = **棋盘 → 手牌 → 格号**：
   - 棋盘命中 ⇒ 棋盘视图（`CardScript` 的场上视图比手牌视图更「真」）；
   - 手牌命中 ⇒ 手牌视图（`InstanceId` 优先于 `Slot`，即 S1 §5·2 F2 的灭自证那条）；
   - 都没命中 ⇒ **原样退回格号**（行为与改前逐字一致，不产生新回归）。
3. `instanceId > 0` 的闸：`CardInstance.Detached` 那类是**负 id**，手牌 id 恒正 ⇒ 负号/`0` 一律不进手牌查询。

### 1·2 行数守恒怎么做到的（重要）

`BattleDriver.cs` 是 CRLF、**40,288 行**、`账/*.tsv` 里共有 **792 处** `BattleDriver.cs:<行号>` 字样（含判据列引用；其中 **49 处在 `>= 36186`**，最远 `:40001`）⇒ 插一行就是那 49 处漂移。
做法：**把两处 `foreach (…)` + 其 `if` 合并成同一行**（语义逐字不变，`foreach (var kv in X) if (…) return kv.Value;` 是合法 C#），空出来的那一行用来放「注释 + 手牌回落」。
**验证（二进制现读）**：`bytes 3,333,030 → 3,333,492`（+462，正好是一行注释 + 一行代码）· `CRLF = 40,288 · LF = 40,288 · 裸 CR = 0`（**行尾没被翻**）· `split(b'\r\n')` 仍是 40,289 段（= 40,288 行 + 末尾空段）· `:36196` 仍是方法收尾的 `}`。
⇒ **旧→新行号映射 = 恒等**（没有任何行号变化），账不用改。
