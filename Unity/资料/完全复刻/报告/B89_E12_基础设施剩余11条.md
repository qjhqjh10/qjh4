### §1·a 三处「判据与施工单不符 / 施工单说查不到其实查得到」（⛔ 都以现读为准）

1. 🔴 **`IsBattleLogCreated` 的白名单施工单写错了**（简报里也照抄了那句）：
   施工单 §4.2 与简报都写「⚠️ **`110 ClosedDeck` 不在白名单**（容易看错）」。**反了。**
   - 机器码（`python 工具/disasm_va.py … 0x18075DF70`）：
     ```
     18075DFCC  8d 43 a6            lea eax,[rbx-0x5a]      ; matchType-90
     18075DFCF  83 f8 1e            cmp eax,0x1e            ; <=30
     18075DFD4  b9 01 00 10 40      mov ecx,0x40100001
     18075DFD9  0f a3 c1            bt  ecx,eax             ; bit(matchType-90)
     ```
     `0x40100001` 的置位 = **{bit0, bit20, bit30}** ⇒ 90 / **110** / 120 ⇒ **110 在**。
   - 施工单/简报那次解码把 `0x40100001` 读成了 {0,30}，漏了 bit20。
   - **真正的白名单 12 档** = `{10, 20, 50, 90, 110, 120, 150, 170, 180, 200, 210, 211}`
     （不在的是 `80 EventAI / 100 Tutorial / 130 Campaign / 140 TutorialReplay / 160 Replay / 190 Scene`）。
   - ✅ 已在 `Core/PlayerDataMath.cs:220` 的 doc 里就地订正（B2 批做的），本批补了两条**钉死它的断言**。
2. **`GetDefaultQualitySetting` 不是「方法体缺失」**：施工单 §4.3 写「`Method not found @18087E560` = 这一跳」。
   实际上 `decomp_full/GameStaticData__get_DefaultQualitySetting.c` **全文可读，只有一句 `return 4;`**（= `Ultra`），
   与 ILSpy `:484 public static EverguildQualitySetting DefaultQualitySetting => EverguildQualitySetting.Ultra` 互证。
