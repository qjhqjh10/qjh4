### 2.2 `default=` 字段

| 值 | 含义 |
|---|---|
| `ABSENT` | 集合里**任何类型**都没有 `uniqueId == d151b095…` |
| `TYPE-MISMATCH type=…` | id 对，但对象的**运行时类型不是 `PlayerAvatar`** ⇒ `OfType<PlayerAvatar>()` 会把它滤掉（这是「集合有、`GetAllItems` 取不到」的典型形状） |
| `type=PlayerAvatar id=d151b095… inInventory=False` | 类型对、但在库里被标成「不在库存」⇒ `Where(x.inInventory)` 会滤掉 |
| `showInCollectionOptions=OnlyIfOwned` + `IsUnlocked=False` | 会被第二层过滤（`x.showInCollectionOptions == OnlyIfOwned && !x.IsUnlocked`）剔掉，除非它就是当前 `PlayerAvatarID` |
| `IsHidden=True` | 会被 `Where(!x.IsHidden())` 滤掉 —— 这一项若为 `ERR:`，说明 `IsHidden` 自己抛了（`PlayerItem.IsHidden` 依赖 `FeatureConfig`） |

## 三、判据订正（写手 M5 现读发现，按铁律 5 记在这里）

1. **`CollectionManager.get_FullCosmeticCollection` 不存在。**
   `dump.cs:71597` 是 **`public List<CosmeticItem> FullCosmeticCollection; // 0x38`** —— 公开**字段**，不是属性。
   ⇒ 本探针**不挂**这个 getter（挂了只会 `SKIP`），改为在 `Census()` 里直接读字段。
   任务书里写的 `CollectionManager.get_FullCosmeticCollection` / `PlayerDataManager.fullCosmeticCollection(+0x38)` 应理解为「集合怎么取」；`+0x38` 是 `CollectionManager` 上那个字段的偏移。
2. **`AvatarTab.OnOpen` 与 `AvatarTab.Initialize` 在二进制里是同一个函数**（`decomp_full/AvatarTab__OnOpen.c` 与 `AvatarTab__Initialize.c` 逐字相同：
   `InitializeGameObjects(); RefreshDisplays();`）⇒ **只挂 `OnOpen` 一个**，两个都挂会在同一条 native 函数上装两个钩子（所有行都会双记）。
3. **`GetAllItems<T>()` 是泛型**（dump 里 RVA = -1，闭实例在 `GenericInstMethod` 块：
   `PlayerAvatarDataManager.GetAllItems<object>` RVA `0xD60CD0`）⇒ 必须 `MakeGenericMethod(PlayerAvatar)` 后再 patch；挂不上会在 `hooks_installed.tsv` 记 `FAIL`，同时 CENSUS 那几行仍然能回答同一个问题。
4. **不能用 `ProbeUtil.IterateIl2Cpp` 数这个大集合**：它内部有 **400 项硬上限**（`ProbeUtil.cs:351-352` `while (guard++ < 400)`），而这里要数 1180～1261 项。
   ⇒ 本探针自带 `ToList()`（非泛型 `IList` → `Count/Length + Item[int]` 反射 → 最后才退回 `IterateIl2Cpp`），上限 4000。
5. **`IntPtr` 不实现 `IConvertible`** ⇒ `Convert.ToInt64(Pointer)` 会抛 `InvalidCastException`；`PtrOf()` 已按 `IntPtr / long / int` 分支。

## 五、边界（⛔ 别拿这些当结论）

- 探针**只读**：所有 hook 都是 prefix/postfix/finalizer，不改 `__result`、不拦执行、不伪造数据。
- 只在**头像页打开**（`OnOpen`，最多 3 次）或**集合首次非空**时做全量 CENSUS；`IS-HIDDEN` 只对默认头像那一颗落行 ⟹ 不会每帧刷屏。
- 每类异常只落**一次**（`_errOnce`），异常**绝不抛回游戏**。
- 本探针**不能**回答「为什么 Page 切不过去」（那是 `ProfileFixProbe` 的 R0/OFF-51 范围）—— 它只回答「集合里有没有 / 过滤会不会吃掉 / 哪一步抛」。
