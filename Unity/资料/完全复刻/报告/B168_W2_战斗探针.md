### 3.1 关键实现说明

- **`GetItemCount` 在泛型基类上** ⇒ 从 **`CardCollectionDisplay.BaseType`（= `CollectionDisplay<RawCardScript>` 的构造类型）**取 `GetItemCount(0)`（`:141-141` 起）。解析不到 / patch 失败都会写 `hooks_installed.tsv`（`collectionfill:CollectionDisplay<T>.GetItemCount` + `:baseType` 两行），**不猜**。

### 5.2 OFF-39：一次完整拖拽的**预期行序**

```
attack:OnTouchDrag            （多条，直到指纹不再变）
attack:TryDraggingFromBoard   IN  ≠  OUT            ← 只有 OUT 里 cardState=inPlayAminingAttack(17) 才说明"走到底了"

  ...（松手那一下）
attack:IsValidAttackTarget    valid=True/False
  ├─ True  → attack:AddAttackAction → attack:StopTracking
  └─ False → attack:CancelAttack    → attack:StopTracking
```

**逐格判读**（直接对 B168-C §2.4 的未知数）：

| 看到的形态 | 结论 |
|---|---|
| `GetTargetInPos` 只有 `target=null`（或压根没它） | **落点/碰撞体问题**，不是规则闸 —— 大概率是坐标口径（C 报告 §2.3 C 节：2560×1440 实拍 vs 2000×1125 显示，差 ×1.28） |
| `GetTargetInPos` 返回**自己 / 友军** | 拖动距离或落点偏了（射线打到自己半场） |
| 返回**正确敌军** 但 `IsValidAttackTarget valid=False` | **规则闸**。看同一行的 `stealth70 / precog640 / stun100`：<br>· target `stealth70=True` → 目标潜行（规则 #5）<br>· target `precog640=True` → 不可指定（#6）<br>· attacker `stun100=True` → 攻击者被眩晕（#10）<br>· 三项全 False 但 valid=False ⇒ 去查 #7（defender）/ #8（flying/vanguard/coward/frenzied）/ #11（pindown+近战）——那几条**不在本探针字段里**，需回 `BattleManager__IsValidAttackTarget.c` 按值逐条对 |
| `IsValidAttackTarget` **压根没出现**（松手后直接 `CancelAttack`） | 说明 `Update` 的 case 6 **没走到规则判定**：看 `StopTracking` 那行的 `playerTurnFlag` / `allowPlayerActionsFlag` / `conn` —— 任一为 False/非 `Connected` 就是上游闸（`Update` 前置的两条 return / `case 6` 的第一条 `playerTurnFlag`） |
| `StopTracking` 里 `target=null` 而前一帧 `GetTargetInPos` 有值 | **松手那一帧鼠标已经离开碰撞体**（非常典型的「拖到目标上停一下再松手 / 松手前移开」症状） |
| 有 `AddAttackAction` 但 `battle.tsv` 仍无 `ResolveAttack` | 问题在**更下游**（动作入队/结算），不在手势层 |

### 5.3 OFF-42：`collectionfill.tsv` 的判读（照 B168-C §4.3）

按**时间列**排一次，找 `CardInventory.UpdateItemCollection`（信号生产者）与 `CardCollectionDisplay.OnEnable`（页签激活）的先后：

| 形态 | 结论 |
|---|---|
| **②（UpdateItemCollection）晚于 ③（OnEnable）** | 现象应是「**一直空**」而不是「10 秒后自己好」 |
| **② 早于 ③ 且之后没有第二次 ②** | **第一次进页签必然空白** —— 真 bug，需要「进页签时主动 refresh」 |
| **③ 之后 `OnCollectionUpdate` 有跑，但 `itemCount=0`** | 卡在 `GetCollection()` / `CollectionManager.AllCardCollection` 未载完 —— 看 `OnCollectionUpdate` 那行的 `ms`：**ms 很大** ⇒ 慢在填充本身；**ms 很小但 itemCount=0** ⇒ 数据侧没给东西 |
| `ms` 曲线 | `UpdateItemCollection` 的 `ms` 才是「一次性重活」的候选；`OnCollectionUpdate` 的 `ms` 是大头就说明慢在 UI 侧 `SetCell` |
