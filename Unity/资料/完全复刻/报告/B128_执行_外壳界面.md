## 二 `界面-P-07` 详细（为什么是「按可见行分段」而不是「每格一个绝对档」）

**改前**（`AvatarTab.BuildRows`）：`Highlight/ Border/ Image/ Name` 四层分别恒 `Q+1 / Q+2 / Q+3 / Q+4`，
469 格**共用**这三档 ⇒ 同一层里谁压谁由**到相机的距离**决定。

**原版**（`d:/2/tools/assetripper_out/ExportedProject/Assets/Avatar Item Small.prefab`，2026-11-03 现读）：
- 子件序 = `Raycast Target → Image Container{ Highlight → Border → Image → Avatar Name }`；
- `grep m_SortingOrder / m_OverrideSorting / Canvas:` ⇒ **0 命中**（只有 `CanvasRenderer` / `CanvasGroup`）；
- ⇒ 同一 Canvas 里按**兄弟序**画；`AvatarTab__InitializeGameObjects.c:152` 逐格 `Instantiate` ⇒ **建序 = 列表序 = 行优先**
  ⇒ **后建的那一格压先建的**。

**重叠是几何事实**（自己量的，不是看图猜的）：
- 立绘实绘 = 布局框 ×2.0 ⇒ **360 × 285.26**，格距 **205 × 230** ⇒ 四邻在透明四边上必相交；
- 宽立绘更狠：实测 `Avatar_All_Servo Skull` 的 alpha bbox = 381/512 ⇒ 实绘**可见**宽 **267.9 > 行距 205**（真重叠 63px）；
- `Border`（×1.25 = **225** 宽）与左右邻相交 **20px**。

**为什么不能「每格一个绝对档」**：
- 469 格 × 3 层 = **1407 个号**；页带之上能用的空段只有 `3220–3999`（**780** 个）；
- `4000` 起是 **Overlay pass**：`ToastNotifications`(4072+) / `LoadingMenu`(4090) / `TutorialPointerUi`(4110+) 必须永远在最上面；
- 往下：本页页带只有 10 个号（`3160 + PageIndex*10` = 3170–3179），再往下是窗框/压暗层（`QShade` 3150）。

**所以**：`BuildRows` 本来就挂在 `MenuScroll.OnChanged` 上（`:293`，一滚就整页重建），
每次重建用 `_scroll.Offset` 算**第一可见行**，把可见的行映射成 0..7 号档：

```
firstRow = max(0, floor((VpT + _scroll.Offset - (GridT + PadT)) / (CellH + GapY)))     // :409
slot     = clamp(row - firstRow, 0, 7)                                                 // :415
qCell    = 3180 + (slot * cols + col) * 3 - Q                                          // :416（Q = 3170）
```

- 档位落点 **3180–3299**（8 行 × 5 列 × 3 层 = 120 号）：
  - `3180–3219` = 本窗**其它五页**的页带（`TitleTab` 3180 / `BattleLogTab` 3190 / `AchievementsMenu` 3200 / `RankedTab` 3210）——
    `PlayerProfileWindow` **一次只激活一页** ⇒ 本页可见时那几段全空（与 `AllianceMemberTab` 直接占用 `3210–3299` 同一条前提）；
  - `3220–3299` = 空闲；
  - **上界卡在 3299**：3300 起是弹窗带（`GenericOptionsPanel` 3330 / `BlockingOverlay` 3338 / `AllianceMemberOptionsPopup` 3340 / `PurchasePremiumWindow` 3521 / `PopUpGameWindow` 3560）——
    弹窗开在档案窗之上时**必须压住格子**（`WindowsManager.OpenWindow` 弹窗支只给底窗 `ToBackground()`，**基类不关物体** ⇒ 档案窗仍在画）；
  - 8 行容量：视口 644.77 / 行距 230 ⇒ 同屏最多 3 行整 + 上下各溢 1 行（立绘上下各溢 71 / 28.6）⇒ 同屏最多 5 行，留到 8 行有余量。
- `Avatar Name` 挂 `qCell + 2`（原版它在 `Image` 之后，但**这一件原版就不上屏**：`m_IsActive = F`、运行期无 `SetActive`）；
  `Hit`（透明命中 quad）**保持原来的 5 不动** —— `PointerLayer` 只在**命中 quad 之间**比队列，而格与格的命中框互不重叠。

**账漂移**：`AvatarTab.cs` 在 `BuildRows` 里 **+4 行**（`:408-409`、`:415-416`）⇒ 该文件里 `行号 > 407` 的 A 行要 `--fix`；
类尾那 49 行加在**最后一个账落点（`:817`）之后**，不引起漂移。
