## 二 A 的 3 条 —— 逐条对拍证据（都是我亲手读的）

### ① `PlayerDataManager.CurrentMillis()` → `Shell/LiveOpsEvent.cs:81`（`ToMs`）

* 原版体：`decomp_full/PlayerDataManager__CurrentMillis.c`（31 行 / 8 条有效语句）= `(DateTime.UtcNow − SupportMethods.GetUtcOriginDate()).TotalMilliseconds`。
* **关键在下一跳**：`decomp_full/SupportMethods__GetUtcOriginDate.c` 的构造实参是
  `System_DateTime___ctor(local_res10, 0x7b2, 1, 1, 0, 0, 0, 1, 0)` ⇒ **`0x7b2` = 1970**、月日 = 1/1、`Kind = 1(Utc)`
  ⇒ 原版 `CurrentMillis` 的值域就是 **Unix 毫秒**（ILSpy 那边同样能看到 `new DateTime(1970, 1, 1, …)`）。
* 我们这边：`ToMs(DateTime) = new DateTimeOffset(utc.ToUniversalTime()).ToUnixTimeMilliseconds()`（同一行声明），
  消费点 `Shell/LiveOpsHandler.cs:550` = `ToMs(LiveOpsClock.NowUtc)` ⇒ 同值域、同单位。
* 机制差只有形状：原版**无参**读系统时钟，我们是**纯函数** + 宿主传时刻（便于自检注入固定时刻）。
* 观测量：`ToMs(1970-01-01T00:00:00Z)` = **0** · `ToMs(2026-10-26T00:00:00Z)` = **1792972800000**。

### ② `PlayerDataManager.GetOnlineData<T>(PlayerDataKey, bool)` → `Shell/SaveCenter.cs:156`（`Get<T>`）

* 原版：`PlayerDataManager.cs:11877-11881` 一转调 → `OnlineData.GetPlayerOnlineData<object>(userInfo, key, checkPublicData)`；
  后者体在 `cpp2il/out_cpp2il_dev_ilspy/OnlineData.cs:145-192`（48 行，**逐句读过**）：
  ① `userInfo == null` ⇒ `return null`；② key 不在 `UserReadOnlyData`、且（`!checkPublicData` 或不带在 `UserData`）⇒
  `CustomDebug.Log("No player data found for key " + key)` + `return null`；③ 命中 ⇒ `JsonWrapper.DeserializeObject<T>(record.Value)`。
* 我们：`Get<T>` → `GetRaw`（缺 key ⇒ `SpeakOnce("missing|…")` 出声 + null）→ `JsonUtility.FromJson<T>`；
  坏 JSON / 未来版本都出声 + null（**不静默当默认值**）。
* 机制差三处（已写进账）：`checkPublicData` 的两级回落是 PlayFab 的服务器形状（我们单层本地库，该形参无对应物）·
  反序列化器不同 · 原版泛型无约束而我们是 `where T : class`（54 个槽的 payload 全是对象）。

### ③ `PlayerDataManager.SetMusicAndFxVolumes()` → `Core/WarpforgeAudio.cs:66`（`ApplyAll`）

* 原版：`cpp2il/out_cpp2il_dev_ilspy/PlayerDataManager.cs:10432-10441`（**逐句**）=
  `SetMixerVolume(Music, MusicVolume × MusicManager.musicVolumeMultiplier)` ·
  `(Voices, VoiceOversVolume)` · `(FX, SoundFxVolume)` · `(Jingles, SoundFxVolume)` ·
  `PlayerPrefs.SetFloat(MUSIC_PLAYER_PREFS_VOLUME, MusicVolume)`。
* 参数名与 dB 换算在下一跳 `SoundManager.SetMixerVolume`（`decomp_full/SoundManager__SetMixerVolume.c` + ILSpy `:569-595`）：
  参数名 = `"Volume" + MixerType`；`volume == 0 ⇒ -80f`，否则 `Mathf.Log10(volume) × 20f`。
  两个常量我**从 PE 现读**（`工具/read_literal.py`）：`0x1834b327c` = 4B float **−80** ✅ · `0x1834b301c` = 4B float **20** ✅
  （ILSpy 把 `Log10` 那一跳标成 `Method not found @18048A970`，但 `× 20f` 与 `−80f` 都在体外且已核）。
* 我们：`ApplyAll()` 一次写 4 个同名参数（`VolumeMusic/VolumeVoices/VolumeFX/VolumeJingles`，Jingles = FX）、
  `Write()` 内联同一条 dB 公式（`v<=0 ? -80 : log10(v)*20`）、`SetMusic` 落 `PlayerPrefs["MusicVolume"]`。
* 机制差：原版一处方法一次写 4 个 mixer，我们 `ApplyAll()` 同样一次写 4 个、但公开面按滑块拆成 3 个入口；
  `MusicManager.musicVolumeMultiplier` 在预制体里查不到默认值 ⇒ 我们取常量 1f（代码里已注明）。
* 观测量：`WarpforgeAudio.ParamsOk`（4 个参数名都能 `GetFloat`）。
