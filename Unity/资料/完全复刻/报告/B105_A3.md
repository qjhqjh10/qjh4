## 顺手发现

1. `ShellScene` 没有 `Check(bool,string)`（只有 `Check<T>(T,T,string)` / `CheckTrue` / `CheckNear` / `CheckA1212`）⇒ 前提断言要用 `CheckTrue`，照抄 `Check(bool,…)` 会 CS7036。
2. `QuadPxRect(..., out …)` 放进 `bool ok = x != null && QuadPxRect(x, out a, …)` 时，外层 `float a,b,c,d;` 必须显式给初值，否则短路时 `out` 不执行 ⇒ CS0165。
3. 三个断言助手本身 null 安全（`CheckDeckFixtureSurvives` / `CheckA1212` / `CheckScaleTwo`）⇒ 外层 `if` 可删（缺件时它们自己会红），但不构成静默。
4. 两处诊断文案已过期并就地订正：`BattleScene` 11294 的 else 原写「这一条不判 3D 体」、30938/30947/30954 的 else 原写「那两条不判 / 那一条不判」。
5. 并发代理痕迹：`Editor/` 下多个宿主同时 `M` ⇒ `check_ledger_points --fix` 要等所有人交回。
6. `BattleScene.cs` 46000+ 注释里的「R13 因套 `if (driver != null)` 而从未执行」是同类事故的现成先例。
