## 二 🔴 召唤语音闸的**行为变化**（单列，建议进一次真机听感验收）

**改了什么**：`SpeakFor(BattleEvent)`（`:7500`）的 `case EvtKind.Deploy:` 现在**先过 `ShouldTriggerSummonAnim(e, out _)`**，与 `PlaySummonDelayedVfx` **共用同一道闸**（`BattleDriver.SummonAnimGate`，`:38584`）—— ⛔ 没有第二份闸。

**这是真的可观测变化**（不是零变化件）：

| 部署档 | 改前 | 改后（原版） |
|---|---|---|
| 从手牌打出、无 `ephemeral`/`ambush` | 播 | **播**（不变） |
| 从手牌打出、带 `ephemeral` | **播**（错） | **不播** |
| 从手牌打出、带 `ambush` | **播**（错） | **不播** |
| 效果召唤 `Summon` / `Reanimate` / `AutoPlayFromHand` | **播**（错，会从 `deploy` 精确档捞一条念） | **不播** |

**判据链**：`state 3` = `if (doTransformAnim) LandOnGround()` 之后那**两道闸**（`shouldTriggerSummon == 0 ∨ HasCurrentTrait(5 ephemeral) ∨ HasCurrentTrait(0x4b0 ambush) ⇒ 只等待`）；只有过了闸才 `invoke card+0x138`（`m_OnDisplaySummonMessage`）→ 再 `Instantiate(summonAnimDelayed)`。委托订阅只有一处（`BattleCardManager__CreateCard.c:86-89`）⇒ 闸 = 同一道。

**建议验收方式**：真机打一张带 `ephemeral`/`ambush` 的单位卡、再触发一次效果召唤 —— 应当**一点登场语音都没有**；同时打一张普通手牌单位 —— **照旧有**。声音是「删掉一类」，最容易「删多了没人发现」。

⚠️ **一个前提风险（如实记）**：闸要**盘上取到那个单位**（`ShouldTriggerSummonAnim` 里 `ps.Board[e.Slot]`）。若某条 `Deploy` 事件派发时单位还没落格，或 `e.DeployFrom` 是 `Unknown(0)`（不是 `HandPlayed`），这条判 `false` ⇒ **语音被误吞**。简报要求覆盖两条 Deploy 路径（玩家 `DoPlay:0.75s` / AI `LandAiDeployFlight` 落地拍）—— 这两条**只能在真机上听**，本件没有跑 Unity（⛔ 子代理不许），**如实记在这里**。

## 三 🔴 账 254 / 255：为什么**落地了却仍记 B**（时序，不是没做）

施工单写的判据是「面板改读**引擎已算好的** `Ctx.ChoiceOptions`」。本件照 `B97_W35` §三·A 的补丁落地了：

- `ShowAsk` 先问 `SharedChoiceOptionsFor(PendingCard, cands)`：
  `ReferenceEquals(ctx.ChoiceOptionsSource, PendingCard)` **并且**那一份全在候选域里（按 `CardDef.Id` 比）⇒ **照用引擎那一份**；
  否则返回 `null` ⇒ 落回旧的 `DrawForDisplay`（`ctx.ShowRng`）。

**但我们的调用序和原版不一样**：

```
原版：  ChoiceOfCardPlayer → GetChoiceOptions(抽 N) → ChooseCardMenu.Setup(options) → 玩家选 → 结算
我们：  BeginPlay → 面板（ShowAsk）→ 玩家选 → DoPlay → RuleCore.PlayCard → DoPlay→DoChooseCard→TakePickCard→BuildChoiceOptions(抽 N)
                        ↑ 此时 ctx.ChoiceOptions 还是**上一次**那一份
```

⇒ **大多数 ask 时 `ChoiceOptionsSource` 还没指向这一问** ⇒ 走旧兜底。唯一会命中的是「同一张卡**连续第二次**问」那种 stale 情形（那一份确实是引擎算过的 options，值本身合法）。

**要真正消掉这条时序差**，得让 options 在**开面板之前**就算好 —— 落点在 `EffectResolver`（`TakePickCard` 之前、或给 `ShowAsk` 一个「提前算」的引擎口），**不在本代理白名单**（`B98_G1/G2/G3/G5` 在改 `RuleEngine/**`）。

⇒ 所以：**面板侧已按施工单落地、断言在**（254d/g/h/j/l），但**如实记 B**（方案 §4.1：`A` = 行为一致；今天大多数 ask 仍是「面板自己抽」）。调度台若认为「面板侧落地即算 A」，改一行即可，我不在这里替它决定。
