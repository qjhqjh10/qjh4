### 2·2 `_selected` 到底是什么语义（本件最关键的一条）

**结论：`_selected` = UGUI `Selectable` 的 EventSystem 选中态（`hasSelection`），⛔ 不是 `Toggle.isOn`。**

| 判据 | 现读 | 出处 |
|---|---|---|
| 状态优先级 | `Disabled > isPointerDown(Pressed) > hasSelection(Selected) > isPointerInside(Highlighted) > Normal` | `Library/PackageCache/com.unity.ugui@27635d171b1a/Runtime/UGUI/UI/Core/Selectable.cs:611-623` |
| `selectedSprite` 只在哪一档取 | 只在 `case SelectionState.Selected` | 同文件 `:682-685` |
| `Toggle` 有没有覆写 `DoStateTransition` | **没有**（`grep -n "override" Toggle.cs` 只剩 `OnValidate/OnDestroy/OnEnable/OnDisable/OnDidApplyAnimationProperties/Start`） | 同包 `Runtime/UGUI/UI/Core/Toggle.cs` |
| 那当前语言那行为什么是 Selected | `Show()`：`item.toggle.isOn = value == i;` → **`if (item.toggle.isOn) item.toggle.Select();`** | `Runtime/TMP/TMP_Dropdown.cs:898 / :903` |
| 按下会不会把选中挪走 | `Selectable.OnPointerDown` 在 `IsInteractable() && navigation.mode != None` 时 `EventSystem.SetSelectedGameObject(gameObject)`；`Item` 的 `m_Navigation.m_Mode = 3`(Automatic) | `Selectable.cs` 的 `OnPointerDown`；`MonoBehaviour_4939.json` 的 `m_Navigation` |
| 拖出去算不算还按着 | `isPointerDown` 由 `OnPointerDown` 置、`OnPointerUp` 才清；`OnPointerExit` 只清 `isPointerInside` ⇒ **按住拖出去仍是 Pressed** | `Selectable.cs` 的 `OnPointerExit / OnPointerUp / currentSelectionState` |

> ⚠️ 我核对过「原版 build 会不会是旧的 UGUI（`Toggle` 覆写过 `DoStateTransition`、`isOn` 直接压过 hover）」这一支 —— **两种版本给出的可观察表完全相同**：当前语言那行无论走 `isOn` 还是走 `Select()`，都是 `_selected`；按下都是 `_press`。所以本件的行为表不依赖这条不确定性。

## ⑥ 顺手发现（本代理已改的标「已修」，其余交调度台分流）
