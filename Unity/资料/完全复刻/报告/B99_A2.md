## 二、生成器设计（`工具/gen_card_anim_order.py`）

### 取数口径（判据详见 `判据/B99_A2_动画时长_判据.md`）
- **顺序** = `AbilityLogic.cardAnimations` 数组序。
  - 基底：2022 快照 `cards_1195_2022时代.json`（activeAbility + cardAbilities）。
  - 增量：当前 build `cards_raw.json` **顶层** `activeAbility`（⛔ 不读 `full_raw`），只补基底没有的卡。
- **时长** = `AnimInfo.GetAnimDuration()` = `TimeMoving + TimeAtStartPos + TimeAtEndPos + Delay`
  （`StartDelay` 不计），四个分量逐字来自 `assets_full` 的 CardAnim MonoBehaviour `animInfo`。
- **vfx** = `animInfo.animAdressable.m_AssetGUID` → `anim_address_map.guid_to_asset` 名。
- 解析来源：A（`guid_to_asset`）/ B（`guid_map.tsv` 非 GUID 容器键；多名则放弃不猜）。

### 排序键（字节稳定）
- `cardAnims[]`：`ref_guids = sorted({...})` 全局按 GUID 升序。
- `cards[]`：基底按 2022 快照首现序（与 A6 同）；增量卡按卡 id 升序追加。
- 所有 set 迭代前 `sorted`；`stepsHistogram` 键按 `sorted`；无时间戳/无随机。
- 序列化 `json.dumps(ensure_ascii=False, indent=1)`，`io.open(...,'wb')` 写 LF。

### 幂等性验证（实测）
- `--probe-base`：基底 cards 复现 = True；cardAnims 内容复现 = True；`resolvedBy` 漂移 = 27。
- `--write` → sha1 `b41201e2…` → `--check` 幂等 = True → 再 `--write` → sha1 **仍 `b41201e2…`**。
