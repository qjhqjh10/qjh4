## 三、本波改动（4 件 · 逐件给判据）

### 1. `WarpforgeVFX/Shaders/WFMatcap.shader` —— 补 `_USEEMISSION` 加法分支（B131 D18 / 5-05）

**判据（一手，本波新做的反汇编）**：`工具/disasm_dxbc.py "Matcap Full Options" --stage ps` → `_tmp_view/dxbc/matcap_full_ps.txt`，
取 **3 张贴图的那个变体（`:73-112`）** 逐条读：

```
r0 = LinearToSrgb(cb1[2])            ; _Color
r0 = r0 * sample(t1, v1.xy)          ; × _MainTex
r1 = sample(t0, (v3.w, v4.w))        ; _MatCap
r1 = r1 * cb1[5].x                   ; × _Intensity
r0 = r0 * r1
r1 = LinearToSrgb(cb1[8])            ; ← _EmissionColor（**也做 sRGB 编码**）
r2 = sample(t2, v1.xy)               ; ← _EmissionTex，UV = 主贴图那一路
o0.xyz = r1 * r2 + r0                ; ← **加法**
o0.w   = 1.0
```

**改法**（3 处，全部加法式、没动结构）：
- pragma：`#pragma multi_compile_local_fragment _ _USEEMISSION`
  ⚠️ **为什么不是 `shader_feature`**：4 颗材质的 `.mat` 里 `m_ValidKeywords: []`（关键字由 `WarpforgeEffectBinder` **运行时** `EnableKeyword` 补，见 `Runtime/WarpforgeEffectBinder.cs:500-501`）⇒ `shader_feature` 的变体在 build 里会被剥掉。
- 贴图：`TEXTURE2D(_EmissionTex); SAMPLER(sampler_EmissionTex);`
- 片元：`#ifdef _USEEMISSION { emiCol = LinearToSrgb(_EmissionColor.rgb); col += emiCol * SAMPLE(_EmissionTex, IN.uv).rgb; }`

**已核的正常项**：4 颗带 emission 的材质（`ChemVial_1` / `GSC Dagger` / `RockSpike` / `RockSpike mild`）的 `_MainTex` 的 `m_Scale` 全是 1、`m_Offset` 全是 0 ⇒ `IN.uv`（带 `_MainTex_ST`）与**原版的未变换 uv** 相同。
⚠️ **已知细微差**：若将来某颗带 emission 的材质 `_MainTex_ST ≠ identity`，UV 会与本原版不同（已在 shader 注释里写死，⛔ 别据此推广）。

## 七、顺手发现（⚠️ 都不是本波改的，交给调度台分流）

1. **`_USENOISE` 的完整算式本波已经解出来了**（同一个 DXBC 文件的 4 贴图变体 `_tmp_view/dxbc/matcap_full_ps.txt:1080-1175`）。下一手可直接照做，别再重解：
   ```
   border  = lerp( sRGB(_BorderColor2), sRGB(_BorderColor1), smoothstep(lo, hi, noise) )
   hi      = _BorderWidth*(1 + 2*_DissolveAmount) - _DissolveAmount
   lo      = saturate( hi - _DissolveAmount*(1 - _BorderWidth^4) )        // 注意 `-_DissolveAmount*(1-bw^4)` 这一项是加在 hi 上的
   t       = saturate( (noise - lo) / (hi - lo) )
   smooth  = t*t*(3-2t)
   o0.rgb  = border*smooth + base ;  o0.w = base.a * ((hi >= noise) ? 0 : 1)
   ```
   （`noise` = `sample(_Noise, uv * _Noise_ST.xy + _Noise_ST.zw)`；池内只有 `OrkSkin` 一颗带 `_USENOISE`。）
2. **`BattleDriver` 的 `dim` 常量被 5 处共用**（见 §五·B）—— 以后任何「把 `dim` 改成白」的施工单都会**顺带改掉手牌标签与牌库计数**，判据没覆盖。已在本报告钉住。
3. **`Report/B131` 的「已修 2 条」严重低估**：🟠13 里 9 条早就做完了（B139-E / B140_WO / B141-W33 / W33b / W34 / W35 / W52）。建议调度台按本文件的四档表核销，别再按旧状态派活。
4. **`WarpforgeVFX/Materials/Embers Circle.mat` 的 `_BaseColor = 2.828427`** —— 审计 D14 完全没提这一格（它只写了 Smoke02 的色），但**它也是对的**（原版 2.828427076）。⇒ D14 的「色」那一半整体应当核销。
