   但**框一旦不是 0.66**，数量格会按 `Contain` 缩、抽屉按 ARF 溢出 ⇒ 数字**跑到抽屉外**。
   落点 = `Shell/ItemDisplayWindow.cs:408`（⛔ 不在本波白名单）⇒ 建议随 `B-260` 一起收口（改法 = 同一行加 `fit: ItemDrawer.RootFit.HeightControlsWidth`，

2. **「Icon 变体」不是一个统一的根比例。** 我按 prefab 现读复核了 13 份 `Icon … Variant`：

   建议后续把「Icon 变体 = 1080²」这句话就地订正（铁律 5）。
3. **`Editor/B114_W27_Assert.cs:234` 的 65×69.73 框是一条活的反证**：它证明「按族迁移」会立刻踩坏 mode 3 那一档

4. 🔴 **`Base Drawer` / `Deck Drawer` / `Wildcard Drawer` 三份 `m_AspectMode 2` 的 prefab，我们【根本没有按 prefab 画】**：
