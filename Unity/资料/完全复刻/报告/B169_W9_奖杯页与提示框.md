# B169_W9 · 联盟奖杯页（OFF-33）与加入提示框（OFF-90）

> 2026-11-07。**两件事同一根因**：`AlliancesConfig.trophies` 有两条必填字段是空的（`challenge` / `reward`），客户端在「加入联盟」完成回调里抛 NRE ⇒ 奖杯列表建不出来（OFF-33）＋ 回调后半段的关弹窗没执行（OFF-90）。
> ⚠️ `server.py` 本波有活跃写手（mtime 实时增长、`文件所有权_当前.md` §七 也写明本波禁触）⇒ 只交可粘贴补丁（§四）。

## 一、OFF-33 读口与根因

固定四级：`AllianceTrophiesView.Initialize` → `GetCurrentGroup(Draw)`（`cpp2il/AllianceTrophiesView.cs:25-30`）；`Draw(Group)` 遍历的是 **`trophyController.trophies`** 而非直接读 Group（`:70-87`；真值 `decomp_full/AllianceTrophiesView__Draw.c:60-203`）；`trophies` ← `AlliancesTrophyController.Initialize(group.trophies, member.trophies)`（`cpp2il/AlliancesManager.cs:187-195` Join 回调 / `:700-720`）；原料 = `AssetLocator.GetAssets<AllianceTrophyData>()`（`decomp_full/AlliancesTrophyController__Initialize.c:44`）→ `AllianceTrophyAssetProvider.GetAssets()` → **`ConfigManager.GetConfig<AlliancesConfig>().trophies`**（`cpp2il/AllianceTrophyAssetProvider.cs:9-16`）。⇒ 页签**不靠 `featuredTrophy` 找列表**，后者只决定「哪条算展示中」。

0 条 = 两处 NRE，都发生在 `trophies.Add` 之前（`AlliancesTrophyController__Initialize.c:109-116`）：

- `AllianceTrophy.Initialize` 首句 `Data.challenge.OnProgressUpdate -= …`（`cpp2il/AllianceTrophy.cs:284-300`）⇒ `challenge` 空就炸；第一条就是我们写成 `"challenge": null` 的 `Default_Trophy`。
- 即便修好，每条 entry 仍走 `badgeDrawer.Draw` → `item.reward.Reference.badgeImage.Load()`（`cpp2il/AllianceBadgeDrawer.cs:47-56`，调用点 `AllianceTrophyEntry.cs:174-175`）⇒ `reward` 空同样 NRE；我们 14 条全是 `"reward": null`。

**「Featured: Trophy Name」是 prefab 默认文本，不是缺 I2**：`Assets/Social Submenu Variant.prefab` 的 `selectedBadgeText` 是 `m_text: Featured: Trophy Name`（同 prefab 计数文本默认值 `45 Trophies Achieved!`）；只有存在 featured 条目才被 `string.Format(GetTranslation("SocialMenu/Alliances/Trophies/CurrentFeatured"), data.LocalizedName)` 覆盖（`Draw.c:114-127`），列表空 ⇒ `allianceTrophy == null` ⇒ 整段跳过。反证：截图「你已经获得了0个奖杯！」是 Draw 写的（默认应为 `45 …`）⇒ Draw 跑了、只是 0 条。**白块** = `selectedBadgeDisplay` 的 Image 没被 Draw 覆盖、保留空 sprite（与 OFF-88 同族）；补数据后画 `GetCurrentStatus()` 指向的 `AllianceBadge.badgeImage`（`cpp2il/AllianceTrophy.cs:270-283`）。

**数据侧修法**：① `Default_Trophy.challenge` 照原版 SO 逐字抄 `ConstantChallenge`（`ExportedProject/Assets/MonoBehaviour/Default_Trophy.asset`：`id:"Granted to All"` · `rewards:[{difficulty:0,targetValue:0,rewards:[]}]` · `reachMilestoneWhen:10` · `challengeType:2` · `cummulative:1` · `allowOnTutorials:1`）。② 14 条 `reward` 写**裸字符串 id**：`LoadableReference.OnBeforeRead` 对 `JTokenType.String` 直接当 `targetId`（`cpp2il/LoadableReference.cs`），`Reference` 再走 `AssetLocator.GetAsset<T>(id)`（`cpp2il/AssetLocator.cs:774-840`）⇒ 第一版统一 `"Default_Badge"`（在客户端 `sharedassets0.assets`；`AllianceBadgeAssetProvider` 挂 `Intro`，由 `AddressableAllianceItemsLibrary.cs:94` 灌集合）。③ 🔴 Group 的 `badge` 要么不写、要么必须带 `featuredTrophy`：`AllianceTrophy.IsFeatured` 读 `group.badge` **字段**（`cpp2il/AllianceTrophy.cs:35-95`），非 null 而 `featuredTrophy==null` ⇒ 直接抛 NRE（ILSpy `:91-94` 的 `IL_0164`）；字段 null 才回落 `trophyController.DefaultTrophy`。⚠️ 另一写手刚给「创建的联盟」加了 `"badge": {"tierLevel": 1}`（`create_alliance` 里那行；20:27 读时在 `server.py:1016`，该文件正在被改、行号会漂）⇒ 会让奖杯页又变 0 条，须改成 `{"tierLevel":1,"featuredTrophy":"Default_Trophy"}` 或删键。

## 二、OFF-90 组件与原版行为

组件 = **`WindowsManager.ShowPopUp("MainMenu/GenericWait", …)`（「请稍候」），不是消息框**：`AllianceListEntry.TryJoin()`（`cpp2il/AllianceListEntry.cs:290-310`）两个按钮参数都是 `default`（`GameWindowButton` 是 class ⇒ null）+ `closeOnEsc:false`；两按钮为 null ⇒ `LoadPopUpAndShow(text, localize, **null**, closeOnESC)`（`cpp2il/WindowsManager.cs:1996-2070`）⇒ **一个按钮都不建**，全仓无自动超时隐藏。**原版 = 不自动消失、也不用玩家点**，靠成功回调关：`{ HidePopUp(forceHide:true); m_OnAllianceJoin?.Invoke(); }`（`AllianceListEntry.cs:298-309`）。

**为什么不关（同 OFF-33）**：`AlliancesManager.JoinGroup`（`cpp2il/AlliancesManager.cs:1258-1293`，回调体 = `DisplayClass40_0._003CJoinGroup_003Eb__0` `:180-206`）顺序是 `trophyController.Initialize(...)` → `UiBadgeNotificationManager.Refresh` → **最后** `callback(group)`；`Initialize` 抛 NRE ⇒ `HidePopUp` 永不执行。另：文案「你可以在设置中关闭"禁用机器人"…」确是 `MainMenu/GenericWait` 的**简中列**（安卓 1.35 `I2Languages`：英文 `Please Wait...`，简中那格串成了 `noPlayers` 第二句）⇒ **原版官方串行**，不是我们漏翻。**修法：只改数据，不需 mod 补丁**；⛔ 不要给该弹窗加按钮/改成 Esc 可关。

## 四、可粘贴补丁（给 `server.py` 写手 / 调度台）

插到 `if method == "ExecuteCloudScript" and branch == "InitializeLiveOps":` 分支里、`payload = copy.deepcopy(payload)` 之后调 `self._patch_alliances_trophies(payload)`。只改内存副本，⛔ 不动 `responses/ExecuteCloudScript.InitializeLiveOps.json`、⛔ 不动别的 config。

```python
    _TROPHY_FALLBACK_REWARD_ID = "Default_Badge"   # 本地 sharedassets0 有；按阵营换图 = 后续
    _TROPHY_CONSTANT_CHALLENGE = {
        "$type": "ConstantChallenge, Assembly-CSharp", "id": "Granted to All",
        "rewards": [{"difficulty": 0, "targetValue": 0, "rewards": []}],
        "expansion": 0, "reachMilestoneWhen": 10, "challengeType": 2,
        "cummulative": True, "loopable": False, "loopIndex": 0,
        "allowOnTutorials": True, "allowOnDuels": False,
        "playModeBlocklist": [], "playModeAllowlist": [],
    }

    def _patch_alliances_trophies(self, payload):
        """AlliancesConfig.trophies 补 challenge / reward（空 ⇒ 客户端 NRE ⇒ OFF-33 + OFF-90）。"""
        try:
            fr = payload.get("FunctionResult") if isinstance(payload, dict) else None
            td = fr.get("TitleData") if isinstance(fr, dict) else None
            raw = td.get("AlliancesConfig") if isinstance(td, dict) else None
            if not isinstance(raw, str) or not raw.strip():
                return
            cfg = json.loads(raw); ts = cfg.get("trophies") if isinstance(cfg, dict) else None
            if not isinstance(ts, list) or not ts:
                return
            fc = frw = 0
            for t in ts:
                if not isinstance(t, dict): continue
                if not isinstance(t.get("challenge"), dict):
                    t["challenge"] = copy.deepcopy(self._TROPHY_CONSTANT_CHALLENGE); fc += 1
                if not t.get("reward"):
                    t["reward"] = self._TROPHY_FALLBACK_REWARD_ID; frw += 1
            td["AlliancesConfig"] = json.dumps(cfg, ensure_ascii=False, separators=(",", ":"))
            self.state.log.note("奖杯兜底：%d 条 · challenge %d · reward %d" % (len(ts), fc, frw))
        except Exception as e:
            self.state.log.note("奖杯兜底失败: %s" % e)
```

同批须改 `create_alliance` 那行：`"badge": {"tierLevel": 1}` → `{"tierLevel": 1, "featuredTrophy": "Default_Trophy"}`（或删 badge 键）。
