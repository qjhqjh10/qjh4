## 一、`B120-Q04c` · 拖牌落格链（`MinionManager.GetClosestAvailableSlot`）

### 1.1 结论（原版行为，逐句）

**可读源**：`d:/2/tools/cpp2il/out_il2csharp/Assembly-CSharp/MinionManager.cs:321-390`（这一段 il2csharp **比 .c 干净得多**，.c = `decomp_full/MinionManager__GetClosestAvailableSlot.c:35-145`）。两份互验一致。

```
GetClosestAvailableSlot(Vector2 pos):
  slots  = ToArray( Concat(GetSlots(-1), GetSlots(1)) )      // 8 个地面槽（每侧 4），左半在前
  start  = (leftOccupation.Count  < 4) ? 4 - leftOccupation.Count  - 1 : 4
  end    = (rightOccupation.Count < 4) ? 4 + 1 + rightOccupation.Count : 4      // 开区间上界
  if (start >= end) return 0
  best = +inf; bestIdx = -1
  for (i = start; i < end; i++):
      sp   = BattleManager.instance.boardCamera.WorldToScreenPoint(slots[i])
      d    = sqrt((sp.x-pos.x)² + (sp.y-pos.y)²)               // 2D 欧氏，屏幕像素
      if (best > d) { best = d; bestIdx = i }                  // 严格 < ⇒ 平手留【更早的下标】
  if (bestIdx < 0) return 0
  n = bestIdx - 4
  return bestIdx < 4 ? n : n + 1                               // 左 -(idx-3)，右 +(idx-4)；0 = 无
```

- **候选集不是 9 格**：`leftOccupation.Count = k`（= 左侧**已占**格数，不是空格数 —— `AvailableLeftSlot()` 判的 `count < 4`，见 `MinionManager.cs:614-619`）⇒ 区间首 = `4-1-k` = 扁平成组里**左侧最内那个空格**的数组下标；区间尾 = `4+m` = **右侧最内那个空格**。中间夹着的全是"已占格"。
  ⇒ 等价于：**「每侧合法插入区间的内圈 + 该侧最内空格」**，而且**满的那一侧整条被剔除**（`k == 4` ⇒ `start = 4` ⇒ 左半不在候选里）。与 `RuleEngine/Core/BoardSlots.cs:1-40` 文件头那句「合法插入区间 左 `-(k+1)..-1`、右 `+1..+(m+1)`」**逐字对上**。
- **没有容差**：`bestIdx` 只可能因"一个候选都没有"（两侧都满）而为 -1 ⇒ **只要棋盘上还有空格，任何指针位置都会返回一个格**（返回 `0` 仅 = 两侧全满）。
- **坐标基准**：`GetSlots`（`MinionManager.cs:149-176`）算的是 `transform.TransformPoint(new Vector3(x, 0, 0))` = **地面槽点（y = 0）**，再 `boardCamera.WorldToScreenPoint`。`pos` 是**屏幕像素**（调用点传 `TouchInputManager.TouchPosition`）。
- **不含督军位**：候选里根本没有督军格；返回值 `0` 是"无"，不是督军格。
- **返回值编码**：左 = `-(侧内下标+1)`、右 = `侧内下标+1`（`GetIndexFromSlot` 的逆，`MinionManager.cs:631-637`）。
