## §3 顺手发现（⛔ 没自己改）

1. **`cardTraits` 第一版落成了 Python repr 字符串** —— 真值 `CardTraits` 的元素是**字典**，`norm_list` 会 `str()` 掉。
   改用 `truth_traits_of`（主表同一个 helper）后是 `["Ephemeral"]`。⚠️ 同族风险：以后往这张表加任何"列表"字段，
   先看主表**同名/同族列**是怎么出的（⛔ 别直接 `norm_list`）。
2. **2 张模板没有 ability 行**（`abilities = []`）—— 它们靠 `buffEffect`/`handBuff` 之外的路径起作用？没查（不在本批范围）。
   E 组断言只钉 `count`/`id`/`whileInPlayAnim`，**没钉**「每张都得有 ability 行」（会误伤）。
3. **`nameZh` 目前全是空串**：模板 `uid` 是 32 位 GUID，官方中文表按 `Card_Name/<卡 id>` 建键 ⇒ 一个都查不到。
   ⚠️ 这张表**不用于显示**，所以暂时无影响；若将来要显示模板名，得走「英文名桥」（`by_en`）。
4. **`E14` 那条 `BattleContext.cs` CS0708 已经不在**：本轮 `typecheck` 现在 **运行时 0 / 编辑器 0**（连跑多次都是 0/0）。
   我上一次报的是 `Assets\RuleEngine\Core\BattleContext.cs(2350,21): error CS0708: 'MatchTypes.ResolvingExtrinsic':
   不能在静态类中实现实例成员`；现在该位置是 `IsReplayMatch` 的结尾，**错误已消失** ⇒ 无需转 E14（如他还在查，可告知已清）。

## §4 没查清

1. **注入与消费都没接**（不归我）：`BattleContext.EnchantmentTemplates`（E14）· `Enchantment.cs` 的两处 fallback 与
   `Attach` 缺省（R1c）⇒ **今天这张表仍然是「数据在、没人读」**（与 v37 的 `whileInPlayAnim` / `permanentBuffs` 同状态）。
2. **`LoadEnchantmentTemplates()` 没跑过**（红线）：两条断言（E2/E7）里它会真读一次；静态看没问题
   （`Resources.Load<TextAsset>` + `JsonUtility`，字段名与 JSON 键逐字一致），但**没有运行时证据**。
3. **`abilities` 只带四格标量**（`ca/pa/ta/fm`）—— buff/damage/summon 正文没进表。附魔效果解释层要真正跑起来时还得扩；
   ⚠️ 扩的时候**照主表的 helper 走**，⛔ 别在消费端另写一份解析。
4. `owners[].inPool` 是按**当前卡池**算的快照值 —— 卡池一变它就是旧值（表要重生成）。这一点已写进 `note`，但**没有机检**。
