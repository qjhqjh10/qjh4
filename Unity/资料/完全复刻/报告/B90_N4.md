#### §2.4 `UIGradientUtils.LocalPositionMatrix` —— 本轮补做
**判据两源现读**：`UIGradientUtils__LocalPositionMatrix.c` 全文 + `out_il2csharp/UIGradientUtils.cs:20-36`
- `m00 = dir.x/w · m01 = dir.y/h · m10 = dir.y/w · m11 = dir.x/h`；`m02/m12` = 由 `xMin/yMin` 平移项构成、末尾 `^ -0.0`（= **取负**；常量 `0x1834b2c80` 用 `read_literal.py` 现读 = `-0.0f`）。
- **消费端** `UIGradient__ModifyMesh.c:107-158`：先把 `dir` **除成单位长**（`if (1e-5 < |dir|) dir /= |dir|`），再 `t = pos · (dir/w, dir/h) + 平移`，随后**直接 `clamp01`**。

**修前**：我方 `t = (u·dx + v·dy) / (|dx|+|dy|) + 0.5` —— 那一除是**我们自加的「满量程拉伸」**（原注释写着「免得整幅只用到一小段色域」），原版**没有** ⇒ 斜向色带宽度差 **1～1.41 倍**（45° 时最大）。
**改后**：方向先单位化，再 `t = clamp01(u·dx + v·dy + 0.5)`，与消费端逐字对齐。`Gradient` 与 `GradientKeys` 两处同改（同一规则只留一份）。
**等价性说明**：矩形 `xMin/yMin` 那两项在「贴图铺满 quad」口径下与我们的 `u,v ∈ [-0.5,0.5]` 恒等；矩阵**第二行**（`m10/m11/m12`）原版**没有消费者**（`ModifyMesh` 只读第 0 分量）⇒ 不物化。
⚠️ **视觉面**：改了所有非轴对齐渐变的色带宽度（`Gradient(…, 188f)` 那族：主菜单底图 `MainMenuRuntime.cs:773` / 战役·活动底图 / 每日奖励 / 卡组编辑底 `DeckRuntime.cs:1472` 等）⇒ **需在同步点并排图复核**。
