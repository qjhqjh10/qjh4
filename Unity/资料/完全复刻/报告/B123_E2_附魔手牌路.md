## §5 `Wurrboy` 的 `mult = 10` —— **零改动 + 反证**（⛔ 没按猜测改）

### 5·1 回源结果：`local_178`（重复次数）的语义**确认了**

`AbilityLogic__PlayAbility.c:180-236`（逐句现读）+ ILSpy 干净版 `AbilityLogic.cs:520-560`（交叉复核，形参名对得上）：

```text
targets  = GetTargets(manager, **abilityLogic.multiplier(+0x30)**, thisCard, 1, 0)   // :180
if (multiplier.targetsAffected(+0x10) == 0 /* any */)      local_178 = 1;            // :202-206
else if (ta == 0xd2(210) || ta == 0xdc(220)) {                                       // :209-236
    if (multiplier.traitsFilter(+0x34) != 0) {
        local_178 = 0;
        foreach (t in targets) local_178 += t.GetCurrentTraitValueWithModifiers(traitsFilter);
    } else local_178 = targets.Count;                                                // 落到 IL_0300
}
else                                                      local_178 = targets.Count;  // :238
if (abilityLogic.furtherMultiplier(+0x38) > 0)            local_178 *= furtherMultiplier;
```

⇒ **重复次数 = 「乘数目标表」的长度**（`ta any` ⇒ 1；`ta 210/220` 且带 `traitsFilter` ⇒ Σ 该 trait 值）× `furtherMultiplier`。

### 5·2 为什么**做不了**（零改动的依据）

- `Wurrboy` 那一行现读：`ca 13 / ta 10 / damage{1,2,opt 90,type 5} / mult **10** / fm **0**`。
  `mult = 10` ⇒ `multiplier.targetsAffected = 10 (allFiltered)` ⇒ 次数 = **`GetTargets(乘数 criteria)` 的表长**。
- 🔴 **乘数 criteria 的 36 格没有导出**：`enchantment_templates.json` 的 `logic[]` 只有 `mult`（= `targetsAffected` 一个整数），
  没有 `friendlyUnits` / `includeMinions` / `keywordFilter` / `traitsFilter` … ⇒ **表长算不出来**。
