## 五 断言片段（灭自证三方锚 · 交 W10 落 `Editor/BattleScene.cs`）

🔑 必须造一块 transform **不是单位矩阵**的探针棋盘 —— 单位矩阵下 `local == world`，任何写法都「看着对」，那正是这个 bug 活到今天的原因。

```csharp
// ★ B124-W9：`DropTargetWorld`(3D 卡心投影) ↔ `SlotPosition`(2D 行心) ↔ 屏幕点
var probeRoot = new GameObject("B124W9_SpaceProbe");
probeRoot.transform.SetPositionAndRotation(new Vector3(3f, 2f, 4f), Quaternion.Euler(0f, 0f, 17f));
probeRoot.transform.localScale = new Vector3(1.7f, 0.6f, 1f);
var probe = new GameObject("ProbeBoard").AddComponent<BoardLayout>();
probe.transform.SetParent(probeRoot.transform, false);
probe.lineY = pBoard.lineY; probe.spacing = pBoard.spacing; probe.mirror = pBoard.mirror;
probe.use3D = pBoard.use3D; probe.boardCam = pBoard.boardCam;
int ps = BoardLayout.WarlordSlot + 1;
Check(Mathf.Abs(probe.transform.lossyScale.x - 1f) > 0.1f || Quaternion.Angle(probe.transform.rotation, Quaternion.identity) > 1f,
      "（前提）探针棋盘的 transform **不是**单位矩阵（local/world 混用才抓得住）");
Vector3 pDrop = probe.DropTargetWorld(ps), hDrop = pBoard.DropTargetWorld(ps);
Check((pDrop - hDrop).magnitude < 1e-4f && Mathf.Abs(pDrop.z) < 1e-4f,   // ② 空间锚：与棋盘自身 transform 无关、且在 HUD 平面 z=0
      $"★ 落点与棋盘自身 transform 无关（差 {(pDrop - hDrop).magnitude:F6}）· 在 HUD 平面（z={pDrop.z:F6}）"
    + "｜🧨 改回 `transform.InverseTransformPoint(...)` ⇒ 差 3+ 单位 ⇒ 红");
if (probe.use3D && probe.boardCam != null && LayoutSpace.Cam != null)   // ③ 屏幕锚（第三方）
{
    Vector2 spCard = probe.boardCam.WorldToScreenPoint(ArenaSlots.CardCenter(ps, probe.mirror, probe.ProjectionScale(ps)));
    Vector2 spBack = LayoutSpace.Cam.WorldToScreenPoint(pDrop);
    Check(Vector2.Distance(spCard, spBack) < 1.0f,
          $"★ 三方锚：落点回投 = 卡心屏幕点（差 {Vector2.Distance(spCard, spBack):F3} px）｜🧨 任一侧换相机/换空间 ⇒ 差成百 px ⇒ 红");
}
else Check((pDrop - probe.SlotPosition(ps)).magnitude < 1e-6f, "★ 2D 档 `DropTargetWorld` 逐位等于 `SlotPosition`");
Object.DestroyImmediate(probeRoot);
```
⚠️ 本仓已知坑：这里**不量命中矩形**（不涉及「量命中要量 quad」），也**没有用 z 分层**（分层一律看渲染队列）。
