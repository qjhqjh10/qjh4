## ④ 为什么选这个出声口

`UnityEngine.Debug.LogWarning("[Battle] 誓约二选一：…")`，两条理由：

1. 🔴 **不进指纹**：`NetProtocol.Fingerprint` 把 **`ctx.Events.Count`** 算进指纹（`NetProtocol.cs:564`），
   而这一处只在**本地玩家的出牌 UI**（`BeginPlay → PlayAsks`）上跑 —— 另一端手上不是同一张牌
   ⇒ 写 `ctx.Events` 就是「只在一端发生的日志」，P2P 两端指纹会分叉（本仓实测过 4×31² = 3844 的差，
   见 `BattleDriver.DiscardEventsAddedSince` 那段注释）。
2. **同文件既有先例**：`SharedChoiceOptionsFor`（`BattleDriver.cs:38866-38871`）就是
   `Debug.LogWarning("[Battle] …")` + 一行注释「⛔ 不用 `Ctx.Log`：这一句是表现层的」。
   `[Battle]` 前缀与它一致。
3. 已确认**没有全局日志钩子**会把 `Debug.Log` 再灌回 `ctx.Events`
   （`Application.logMessageReceived` 全仓 5 处，都是 `Label.cs:329` / `WarpforgeVatDriver.cs:518/579` /
   `CardFeel.cs:3004` 那种**订阅后立刻退订**的局部捕获）。

**另加了一个只给自检读的口**（否则断言只能去挂钩日志）：

```csharp
public string LastOathGateNoticeForTest { get; }   // 与那句 LogWarning 是同一段文本，⛔ 别在断言里另写一份
```
