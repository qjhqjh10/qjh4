**判据**（🥇 `decomp_full/CardScript__RemoveExtrinsicEffectsFrom.c` 全文）：
倒序扫 `.c:17/22`；三合取 `.c:32`（`extrinsic != 0`）· `.c:37/47`（`enchantingCard != null`）· `.c:51`（`== 参`）后 `.c:56` 摘 → `RemoveEffect` 逐 case 到 `case 3`（`CardScript__RemoveEffect.c:63-72`：`HasDefaultTrait ? 留着 : RemoveTraitSilently`，再 `!HasCurrentTraitActiveEffect` 第二道闸）。
我们的 `RemoveTraitEffect(rec)` = 那两道闸的唯一实现（⛔ 没另抄一份 `RemoveAll`）。

**如实标的口径差**（与既有 `RevertGrantsFrom` / `RevertGrantsCastBy` 同一条，不是新设计）：
① 原版比**对象引用**，我们按**卡名**（同名两张会多撤 —— 另三本账本来同限制）；
② `TraitEffectRecord` **没有 `Caster` 列** ⇒ 只能用 `Source`（生产点 = `EffectResolver.ApplyOneGain` 的 `source: by`，`by` = 施放卡名 `source.Name`）≈ 原版 `enchantingCard(+0x18)`；
③ `TraitEffectRecord` **没有 `Permanent` 列** ⇒ 原版 `permanentBuff != 0 ⇒ return`（`.c:35-38`）这条摘不到（每一条都来自 `ApplyTraitEffect`，它没有 permanent 形参 ⇒ 那一格原版侧今天也恒假）。

**行为影响**：`extrinsic` 生产点 = `ctx.ResolvingExtrinsic`，而 `HandEffect.Extrinsic` 全池**没有生产者**（`RuleCore.ResolveHandBuffOps` 的 doc）⇒ 全 `false` ⇒ **本批净零行为**（休眠，铁律 11 照建）。
⚠️ 若哪天 `HandEffect.Extrinsic` 接线，本改动会让「on-board 单位上由某张卡给的 addTrait」在来源离场时被撤 —— 那正是原版语义。

## 三 交回：`RuleCore` 两行换口补丁（账 `:853` · 归 W34）

**两个入队口**（`RuleCore.cs` 现读）—— 两处 `() => unit.RemoveTempBuff(buff)`：

- `:16521` —— 回合末到期（lane = `ActionPriority.DelayedInstant`）
- `:17230` —— 回合开始到期（lane = `ActionPriority.Instant`）

**改法（两处同形，⛔ lane 各保留原档、别统一）**：在 `var unit = u; var buff = b;` 之后加一行构造 `EffectRecord`，把 lambda 换成 `RemoveEffectRecord`：

```csharp
var unit = u; var buff = b;
// 账 853：换口 —— 走 RemoveEffectRecord（原版 RemoveEffect 的 permanentBuff 早退在 .c:35-38 最前；
// 今天 TempBuff.Permanent 恒 false ⇒ 净零行为）。lane 不动。
var rec = new UnitState.EffectRecord { Permanent = buff.Permanent, TempBuffRecord = buff };
if (EnqueueAbility(ctx, <原 lane>, "removeEffect:" + buff.Name,
                   () => unit.RemoveEffectRecord(rec), actionType: 16))
    queued++;
```

**为什么净零**：`RemoveEffectRecord` 里 `rec.TempBuffRecord != null` 那一支直接 `RemoveTempBuff(rec.TempBuffRecord)`（= 原来那句），且 `rec.Permanent` 今天恒 false（`TempBuff.Permanent` 生产点未接线）。
**为什么该换**：原版 `RemoveEffect` 的第一句是 `permanentBuff != 0 ⇒ return`（`.c:35-38`）；直接 `RemoveTempBuff` 现在**没有**这道闸 ⇒ 一旦 `Permanent` 接线，jam/到期会越过原版闸。
