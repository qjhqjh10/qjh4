## §九 教训（建议进坑表；我不动 `资料/已知的坑.md`，由你合并）

> 必须**读类声明**（`DynamicList.cs:7 public class DynamicList<T> : DynamicList` / `:642 public abstract class DynamicList`），
> ⛔ 不能看引用点里的短名（`grep DynamicList` 会把 `DynamicList<EventTrigger>` 一并命中）。
> 同族坑（本项目已有）：**「按类名搜资产永远 0 命中」**（序列化数据不含字段/类名，要按 `m_Script` 反查）。
> 判法：**判「有没有消费者」要连泛型实参一起看**；判「这个方法属于哪个类」要回到类声明/行号。

**本案的实证链**：调度台依据「这些类引用了 `DynamicList`」裁定「非泛型有消费方」→ 我读 647 行原文 →
