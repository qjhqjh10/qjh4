## 一、V-1 `工具/vfx_param_audit.py`

### 1. 移植了什么

来源 = 2026-10-26 V1 临时链（`d:/4/_tmp_view/v1tmp/`，**只读**）：

### 1.2 修掉的 bug（会静默算错，值得单独记）

`vfx_diff2._fields_of` 用 **`id(node)` 当缓存键**，而节点对象在逐 prefab 循环里会被 GC —— **id 复用**
⇒ 把别的 prefab 的字段喂给当前节点 ⇒ 同名兄弟配对错乱，表现为**成对镜像的假差异**。

实测证据（同一个 prefab，同一份代码）：

```
python vfx_diff2.py --pilot "Environmental Condition Necrons Immortal Beams"  → 真差异 0 行
python vfx_diff2.py --all                                                    → 该 prefab 46 行成对镜像的假差异
```
（它的 3 个同名 `Glow` 节点两侧字段集合完全相同、只是次序不同；配对距离矩阵对角线 = 1，
正确配对是 0→0 / 1→2 / 2→1。缓存串味后贪心配对选错。）

⇒ 本移植把结果**挂在节点自己身上**（`node["_fields"]`），不再依赖 `id`。
**推论**：旧 `alldiffs7.tsv` 那轮的逐 prefab 结果**不可复现**（0 差异这个**结论**没错，但那是跑出来的运气）；
本工具现在**确定性**，且独立复算 978 个 prefab 仍是 0 真差异。

### 1.3 行为纪律（照任务的硬要求）

| 调用 | 行为 |
|---|---|
| 不带参数 / `-h` / 未知参数 | **只打印用法、退出 0、什么都不写** |
| `--check` | 真跑、**不写任何文件**，只报差异 + 退出码（0 = 干净） |
| `--write [-o 路径]` | 重生成 TSV（默认 `判据/B9_特效参数对账.tsv`；本次**只写到 `_tmp_view` 验证，没动判据文件**） |
| `--self-test` | 内存里篡改一个字段再比；**检出 ⇒ 退出 1**（设计如此）；没检出 ⇒ 退出 3 |

`--check` 的判定口径（与 B9 表一致）：
* 只比**参数**（ParticleSystem 全部模块 / 各 Renderer / MeshFilter / SpriteMask + Transform 的 localPosition·localScale）；
* 已知等价噪声各自计数、不算失败：`m_MaskInteraction`、`m_StitchLightmapSeams`、`m_SelectedEditorRenderState`；
* 结构差里只有「**去掉尾随空格后路径相同**」的缺/多节点判命名等价（`Orbital 5 repeat ` 那条），**其余结构差算失败**；
* 材质：比的是「**运行时生效队列**」而不是静态 `.mat` —— 依据 `WarpforgeEffectBinder.cs:573`
  运行时用 `WFMatDef.renderQueue` 覆盖，数据 = `数据/游戏数据/mat_renderqueue.json`（我们）
  vs `renderqueue_truth.json`（原版：材质队列 >=0 用它，否则用原版 shader 默认队列）。

### 2. 检查规则

* 「已接」逐条解析 `我们的入口(文件:行)`：`·` 分条、`:N` / `:N-M` 取行、`（…）` 里取符号；
  `文件:1 起` 按**文件级**处理（⛔ 不当成第 1 行）；`同 X` / `同上` 按方法名 / 上一「已接」行**重定向**再核。
* 文件解析顺序：`Assets/<相对路径>` → `Assets/CardPresentation/<相对路径>` → 全仓按文件名唯一匹配。
* **硬失败（断链）**只有三种：① 文件不存在 ② 括号点名的符号**代码里找不到**
  ③ 符号只在注释行出现（那说明它是个**注释里的原版方法名**，不是可调用点）。
* 软告警（不算断链，但要人看）：行号越界 / 符号在文件里但不在所标行附近（漂移）/
  落点在注释块 / 只写文件没行号。
* 「未接 / 判不了 / 原版无」**原样列出**，既不算通过也不算失败。
* 有任何断链 ⇒ 退出码 1。

## 四、没做 / 没查清的

1. **V-1 不是「秒级」**：978 个 prefab × 两侧 YAML（我们那份是 Unity 写全默认值的，普遍几万行）⇒
   16 进程 **73～84 s**。没做磁盘缓存：缓存会让闸有「陈旧了就悄悄绿」的风险，宁可慢。
2. **只移植了「参数层」这条主链**，没有移植 `raw_tree.py` 的**完整对差**：
   那一档（AR 缺件的 14 个）当年只被 `gen_b9.py` 用来取**粒子系统计数**，它自己的结构差里混着
   「嵌套 prefab 实例被摊平」等已知噪声（实测 105 行），**从未进入 0 差异的结论**。
   本工具只在 AR 缺件时用它取计数，**不拿它判差异**（避免把噪声当缺陷）。
3. **`判不了` 的 1 个 prefab 没有解**：`Vanguard Frame Animated VAT` 原件不是独立 prefab（是本包
   `VanguardIdleEffect` 下的子节点），AR 里没有同名文件 ⇒ 参数层**这一格没被闸覆盖**（B9 表里也标着同样的说明）。
4. **触发链只核「已接」**；「未接 1」「判不了 3」本工具**不判**（也不该判）。
5. 材质队列闸比的是**数值**（原版生效队列 vs 我们运行时覆盖表），**不证明画面一致**（shader 行为另说）。

## 五、覆盖边界（这份闸能证明什么 / 不能证明什么）

* **能证明**：977/978 个特效 prefab 的**参数**（含变换）与原版逐字段一致；101 个静态队列不同的材质在**运行时**队列一致；
  45 行触发链里 29 条「已接」的落点**在这个仓库当前的代码上**要么命中、要么至少**不再假装命中**（漂移/断链都被点名）。
* **不能证明**：画面像不像（那要人眼看，见用户口径「特效由用户亲自看画面」）；shader 编译/渲染结果；
  触发链的**语义正确**（只核「落点存在」，不核「播的是不是那个 prefab」）；
  未接的 1 条 / 判不了的 3 条 / 原版无的 12 条。
* **数字会变**：`--check` 的每一项都是现读现算；报告里引用的 978 / 15,229 / 101 / 29 / 13 等均是 2026-10-31 那次运行的读数，⛔ 别当常量抄。
* 本次**没有改动**：任何 `.cs`、任何 Unity 资产、`判据/B9_*.tsv`、`账/**`、`CLAUDE.md` / `项目任务.md`、`d:/2` 任何文件。
  新增文件只有 3 个（上表）+ 本报告；`__pycache__` 由 Python 自动生成且已被 `.gitignore` 覆盖。
  ⚠ `git status` 里 `判据/B9_特效触发链.tsv` 显示 `M` —— 那是**本会话开始时调度台订正的 3 行**（见 §二·1），不是我改的；
  `判据/B9_特效参数对账.tsv` 的 `git diff` 为**空**（`--write` 只写到了 `_tmp_view/v1check/`）。
