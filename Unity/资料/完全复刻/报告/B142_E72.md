## 三、`B141-W29-ASSERT-SKIP` —— A4/A6 改反射直调私有静态，去掉 SKIP

判据现读：`Deck/DeckRuntime.cs:3976` `static bool IsScrollDragThreshold(Vector2 dragInput)`

旧的公开口 `UiIsScrollDragThreshold`（`:6749`）只是**实例包装**（`=> IsScrollDragThreshold(new Vector2(dx,dy))`）。
⇒ 原写法「拿不到 `DeckRuntime` 实例 ⇒ `SkipLine` 整段跳过」是**方法选错了**，不是前提真的不成立。

- `ScrollGate`：`typeof(DeckRuntime).GetMethod("IsScrollDragThreshold", Static|NonPublic|Public)`（懒取 + 缓存）。

- `GroupA_Thresholds`：`A4a` **硬断前提**「反射找得到那个私有静态」（找不到 ⇒ 红，⛔ 不再静默 SKIP）⇒ A4 / A5 / A6 用 `== true / == false` 判（`bool?` 抬升，`null` 时判红而不是判绿）。

- `GroupA_Thresholds(DeckRuntime rt)` 的形参**保留未用**（宿主调用点 `DeckScene.cs` 不动；参数未用不产生警告）。

计数变化：有实例时 A 段由 3 条变 4 条（+`A4a`）；无实例时由「A4/A5/A6 全 SKIP」变成 **4 条真跑**。

## 五、顺手发现（⛔ 没改，交调度台分流）

1. 🔴 **`Editor/RewardsScene.cs:10446`** 的限时条期望串是**二选一**：
   `string ephExpect = Loc.Current == AvailableLanguages.Chinese ? "2天 0小时" : "2d";`

   ⚠️ 触发条件与**机器系统语言**有关：`Core/Loc.cs:185` `Default = MapSystemLanguage(Application.systemLanguage)`（不是恒中文）；
   本机是中文 Windows ⇒ 当前不触发。**建议**改成从 `TimerDisplay.FormatTimeString(TimeSpan.FromDays(2), eventTimer:true).Replace("0h","").Replace("0m","")` 现算（⛔ 别再按语档二选一）。
2. 🟠 **`Editor/ShopScene.cs:6655-6670` `ParseTimerText`** 的单位正则只认 `天|小时|分钟|秒|d|h|m|s`；第三语言（`д/ч/м/日/時間/분`…）解析会失败 ⇒ 退回「逐字相等」那条更弱的比较（鉴别力下降，且秒数一动就红）。同属「假定只有 en/zh」的库存假设。
