## 二、逐条：不一致的 7 张，该改成什么

> 共性根因（一句话）：`Dispatch` **已经把 `DrawerOverride ov` 传进来了**（`Shell/ItemDrawer.cs:1916-1917`），
> 但 26 个抽屉实现里**只有 `GenericArmy` 用 `ov`**（`:1925` 末尾 `GenericArmy(..., ov, ...)`）。
> ⇒ 剩下这些「**一个类同时服务基础档与 Icon 档**」的抽屉，**永远按基础档 prefab 的几何画**。
> 对应关系（映射表 `资料/普查产出_1004/ItemDrawerConfig_映射表.md` §②）：`AvatarDrawer` / `ContainerDrawer` / `CurrencyDrawer` /
> `ExpansionPassPointDrawer` / `RandomCardDrawer` / `WildcardIconDrawer` / `AllianceBadgeDrawer` 都是**同一类、两套 prefab**。

### #2 Avatar — `Icon Avatar Drawer Variant`
- **原版**：根 1080²（ARF 高控宽 1）；`Content`(0,0)-(1,1) 满 → `avatarBG`(0,0)-(1,1) 满 → **`avatar` = (-307.8,-210.6)-(1387.8,1490.4)**（anchors `-0.285..1.285 × -0.195..1.38`）；`image` 槽 = `avatar`；`armyText` **有**（`114313026266067498`）；`label/quantity` = null。
- **我们**：`AvatarImageFrame` = (-65.0,65.6)-(795.2,796.1)，帧 712.8×1080（= 基础档 `Avatar Drawer` 那一份）。
- **差**：宽 **1.207× → 1.570× 根**（少 0.363 根宽）、高 **0.676× → 1.575×**、上沿 **0.061 → −0.195**（头像要往上溢出一大截）。
- **该改**：`Avatar(...)` 加 `ov == DrawerOverride.Icon` 分支 —— `fr = FrameOf(box, DrIconRoot, DrIconRoot)`，主图 rect = `fr.Map(-307.8f, -210.6f, 1387.8f, 1490.4f)`；`armyText` 保留（Icon 档也有）；`label` 槽是 null ⇒ `DrawerNameQuantity(hasName:false, hasQuantity:false)`（现在传的是 `hasName:true`）。
- **灭自证**：把 Icon 分支删掉 ⇒ 头像又回到 860×730 那一格 ⇒ 断言红。

### #4 Container — `Icon Container Drawer Variant`
- **原版**：根 1080²；`Content` 满；`image` 满帧、`m_LocalScale = 1.1` ⇒ 视觉 (-54,-54)-(1134,1134)；`armyIcon` 槽 **null**；`label/quantity` **null**；`background` **null**。
- **我们**：帧 712.8×1080；`image` = `(0.4,0)-(712.4,1080) × 1.2`（`ContainerImgScale = 1.2f`）；并且 `item.CardArmy != 0` 就画阵营徽记（`(0.4,939.6)-(712.4,1134)`）、还画名字/数量。
- **差**：比例 **1.2 → 1.1**；帧宽 0.66 → 1.0；**多画 3 层**（阵营徽记、名、数量）。
- **该改**：Icon 分支 ⇒ `FrameOf(box, DrIconRoot, DrIconRoot)`；`imgR = DrawerFrame.Scale(fr.Map(0,0,1080,1080), 1.1f)`；**不建** `armyIcon`；`DrawerNameQuantity(hasName:false, hasQuantity:false)`。

### #5 Currency — `Icon Currency Drawer Variant`
- **原版**：根 1080²；`Content` 满；`image` **满帧、scale 1.0**；`background` = null、**`icon`（小图标）= null**、`label` = null、`quantity` = null ⇒ **整格只有一张主图**。
- **我们**：`DrawCurrency` 按**基础档 `Currency Drawer`** 画：root 712.8×1080（`CurRootX1=603.6`）、主图 `(604,0)-(1316,864) ×0.9`，外加 **底板 + 名条行 + 小图标 + 数量**。
- **差**：主图 0.593×0.72 根（偏小、偏上）vs 满帧；**多画 4 层**（其中小图标/名条在 Icon prefab 上是空槽 ⇒ 原版根本不画）。
- **该改**：`DrawCurrency` 加 Icon 分支 ⇒ `fr = FrameOf(box, DrIconRoot, DrIconRoot)`，主图 = `fr.Map(0,0,1080,1080)`（scale 1.0）、`NodeCurrencyImage` 名保持；**跳过** ①背景 / ③名条行 / ④小图标 / ⑤数量 四段。
- ⚠️ 这条改完要顺带看 `LastCurrency`（自检读口，`ItemDrawerCurrency.cs:60-72`）——Icon 档那五个 bool 会变成 `MainImage=true` 其余 false。

### #6 Expansion Pass Points — `Icon Expansion Pass Points Drawer Variant`
- **原版**：根 1080²（**FitInParent** 1）；`Content` 1080²；`image` 满帧；`armyText` **null**；`label/quantity` **null**。
- **我们**：`ExpansionPassPoint → PointsForArmy`，帧 712.8×1080，图 = `(0.4,216)-(712.4,648)`；还画阵营名（`DrawerArmyName`）+ 名 + 数量。
- **差**：满框 vs 中间横带；**多画 3 层**。
- **该改**：`ExpansionPassPoint(...)` 加 Icon 分支 ⇒ `FrameOf(box, DrIconRoot, DrIconRoot)` + `fr.Map(0,0,1080,1080)`；不画阵营名/名/数量。
- ⚠️ 这一档**没有独立的 Icon 类**（映射表：`Icon`(10) → `ExpansionPassPointDrawer`），所以分支只能加在这个类上。

### #10 Random Card — `Icon Random Card Drawer Variant`
- **原版**（根 712.8×1080，**和我们的帧同形**，不用换帧）：`Base Background` (0,0)-(712.8,1080)；`Background` (0,-54)-(712.8,1080)（即 top-down 0..1134）；**`image` = 满帧 (0,0)-(712.8,1080)**；**`Random Image` = (71.3,108)-(641.5,972)**（570×864）；`armyText` **null**；`label/quantity` **null**。
- **我们**：`image` 与 `Random Image` **同一格** `(0.4,108)-(712.4,648)`（`slotR`）；还画阵营名/名/数量。
- **差**：`image` 下沿 **0.60 → 1.00**；`Random Image` 应当 **收窄到 0.10..0.90 宽、0.10..0.90 高**（570×864），不是 712×540；多 3 层。

  （`Base Background` / `Background` 两层现有 rect 已与原版一致，不改。）

### #13 Wildcard — `Icon Wildcard Drawer Variant`
- **原版**：根 1080²；`image` 满帧、`m_LocalScale = 0.94` ⇒ 视觉 (−32.4,−32.4)-(1112.4,1112.4)（**归一化 −0.03..1.03**，即「略小于满框」）。
- **我们**：`WildcardIcon` 走 `IconRect(box, st)` ⇒ `Square(box, IconFill)`：**默认 0.7**（归一化 0.15..0.85）；调用点另设 `0.95`（`ForgeTab.cs:1203`）/ `1`（`BaseOfferPopup.cs:1117`、`ShopTabPage.cs:199`）。
- **差**：0.70 vs **0.94**（且 0.95/1.0 也不等于 0.94）；另 `Square` 是「取短边的正方形」，而原版是「满框 × 0.94」（非方框时两者不同）。
- **该改**：Icon 档固定「**满框 ×0.94**」——即 `DrawerFrame.Scale(box, 0.94f)`，不要复用 `IconFill`（那个量是给「居中方块」档的，语义不同）。⛔ 别把 `IconFill` 直接改成 0.94（基础档 `Wildcard` 也用它）。

### #14 Alliance Badge — `Alliance Badge Drawer Icon`
- **原版**：**根上没有 `AspectRatioFitter`**（prefab 根 `m_SizeDelta = 165.9539 × 155.7357`，随调用框走）；`Frame` 与 `Badge`（= `image` 槽）都 **满根**；`armyText` **null**；`label/quantity` **null**。
- **我们**：帧 712.8×1080；`frameR = (0.4,216)-(712.4,648)`，`DrawTierFrame` 与 `Badge` 都画在这一格里；还画阵营名/名/数量。
- **差**：徽章应占**整个框**，我们只占「中间一条 712×432 的横带」且整格还被按 0.66 的竖版帧缩进方框的 66% 宽里；多 3 层。
- **该改**：Icon 分支 ⇒ **不换算帧**（`frameR = box` 原样），`Frame` 与 `Badge` 都 = `box`；关阵营名/名/数量。

## 四、跨条发现（比单张几何更重要）

### 4·1 🔴 **15/15 的 `label` / `quantity` 槽都是 null，12/15 的 `background` 也是 null**
逐份实读（本文脚本）：**`label` 与 `quantity` 15 份全是 `{fileID: 0}`**；`background` 只有 3 份非空
（`Icon Random Card` = `Background` · `Icon Premium Campaign` / `Icon VIP Premium Campaign` = `Campaign Glow`）。
⇒ 原版这些 Icon 档**只画主图**（+ 极少静态层）。我们现在有 6 个抽屉在 Icon 档**仍然画名字/数量/阵营名**（`Container`/`Currency`/`Expansion Pass Points`/`Random Card`/`Alliance`/`Avatar` 的 label）。
⇒ 这不是「几何差」，是「**层数差**」——`label == null ⇒ 原版基类 `ItemDrawer<T>.Draw` 走 `if (label)` 那一跳直接跳过」。修 Icon 档时**要一起关**。

### 4·2 🔴 **`drawerOverride` 只在 `GenericArmy` 一处被消费**
`Dispatch(string drawer, ..., DrawerOverride ov = Default)`（`Shell/ItemDrawer.cs:1916-1917`）已经把 `ov` 收进来了，
但 26 个 `case` 里**只有最后一个**把它往下传（`:1925` 末尾 `GenericArmy(node, box, item, quantity, style, ov, ref res)`）。
⇒ 上面 7 条「该改」全部是**给各自的 `Draw` 加一个 `ov` 形参 + Icon 分支**，路由（`PickDrawer`）不用动 —— 它本来就选对了类（`Editor/B109_E11_Drawer_Assert.cs` A1/B1 把 39 格钉死了）。

### 4·3 ⚠️ **`ArmyFill` / `IconFill` 的默认值是 0.34 / 0.70，不是「满框」**
- `ItemDrawerStyle.Default` = `IconFill 0.7 / ArmyFill 0.34`（`Shell/ItemDrawer.cs:228`）。
- 现读调用点：`IconFill` 被设成 **1** 的有 `BaseOfferPopup.cs:1117`、`ShopTabPage.cs:199`；**0.95** 的 `ForgeTab.cs:1203`；**0.7** 的 `OfferContainer.cs:1581`、`CampaignRewardWindow.cs:936`、`RewardWindow.cs:1412`。
- ⇒ 同一档 Icon 抽屉在不同窗里会画成不同大小（0.7 / 0.95 / 1）。**Icon 档的「满框」是 prefab 事实，不该由调用点各挑一个数**。
  + `CampaignPoint`（#3）唯一一个「对的」调用点是 `CampaignTab.cs:1899` 的 `CampaignPointStyle()`（`ArmyFill=1`）；
  + 同一格若从 `ItemDrawerStyle.Default(...)` 过去（`CampaignTab.cs:696`、`EventBadge.cs:321` 都是 Default）⇒ **0.34**，与原版差 0.66 边长。

### 4·4 ⚠️ 根形（ARF）这件事：我们只有 3 档换了 1080² 的帧
`FrameOf(box, DrIconRoot, DrIconRoot)` 只出现在 `ItemDrawerTitle.cs:97` · `ItemDrawerPoints.cs:51` · `ItemDrawerPremium.cs:102`。
其余一律 `FrameOf(box)`（712.8×1080）。而 15 张里 **9 张的根是正方形 1080²**（#2/#3/#4/#5/#6/#8/#11/#12/#13）——
我们按 0.66 竖版帧算 ⇒ 在正方形调用框里只占 **66% 宽**（`k=min(H/1080, W/712.8)`）⇒ 这是 #4/#5/#6/#2 的主要误差来源。
