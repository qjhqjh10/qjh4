# B99_P6 报告 · P06「旧机器 id / 静态盐」结案

> 会话第九十九（B99_P6）· 2026-10-30 · 判据全文 → `判据/B99_P6_旧profile静态解析.md`

## 1 一句话结论
**真不可解**（针对「旧 profile 的 `deviceId` 明文」这个字面目标）：那份档里唯一的密文就是 `deviceId`，其明文 = 旧机器（Windows 用户 `shen0`）的硬件标识 `SystemInfo.deviceUniqueIdentifier`，而加密盐**也是**该 DUID（自指）——常量盐已实测排除、旧机器痕迹本地全无 ⇒ 不可回收。**但对复刻不构成实际阻塞**：账号字段（`loginName`/`loginPassword`/`playFabId`）全为空串，密文背后只是一台已消失机器的硬件哈希，我们的复刻本来就会自生成 `deviceId`。

## 2 静态解析结果（自校验通过）
- **自校验**：字节消耗 **1211 / 1211**（读到 `MessageEnd` 恰好用尽）；`lastBuildSaved = "1.35.0"`（已知值反证）✅。
- 结构：`SerializedStreamHeader` → `BinaryLibrary("Assembly-CSharp…")` → `ClassWithMembersAndTypes{name=LocalPlayerData, 40 成员}` → `MessageEnd`。全程**未调用任何反序列化 API**（自写 MS-NRBF 逐字节记录解析器）。
- **关键三格**：
  - `loginPassword` = **空串**（BF `MemberReference` 指向空串对象，**不是密文**）
  - `deviceId` = **`dAkd61g/es6uhbbLFKmcC6VchJPlidujbxnShdBU9onSM0shYJRy3oAnodGQKspd`**（64 字符 base64 = 48B AES-CBC 密文）
  - `dataVersion` = **39**（≠ 0）
  - 附带：`loginName`=空串 · `playFabId`=空串 · `lastBuildSaved`="1.35.0" · 其余 35 字段（音量/画质/开关等）逐格已读（见判据文档 §1·2）。
- 对照：本机 qjh36 的原版存档（1,203 B）同 schema，`dataVersion=39`、另一段 64 字符密文、账号字段同样为空/Null。

## 3 三档判定与依据
- **`无阻塞`档？否** —— 要求 loginPassword 与 deviceId 都空；本档 deviceId 非空（有密文）。
- **`可解`档（dataVersion==0 常量盐）？否** —— dataVersion=39。
- **进 E1**：常量盐 `"toQmbArBDRPNkMbm"` 实解 → **非法 PKCS7 填充（pad=0x42）+ 非可打印** ⇒ 常量盐**判死**。
- **进 E2（要旧机器 DUID）→ 拿不到**：本机 MachineGuid 的 24 种变形当盐对两份密文全不命中；`Windows.old/Windows/System32/config` 不存在；`Windows.old/Users` 只有 `qjh`（无 `shen0`）；`d:/2` 无任何注册表/机器备份；归档 `Player.log` 无 DUID 痕迹（32-hex 仅全零）；本机自产物未持久化 DUID。且**跑原版游戏「当场解」也解不了**（`GetPWD(39)` 用运行机 DUID，非 shen0 的）。
- **⇒ 落定 `真不可解`**，R4b 三条活路全关。

## 4 「若可解」的可复现步骤（只写不执行，当前不成立）
需要 `shen0` 机器的 `SystemInfo.deviceUniqueIdentifier`：`kdf=PBKDF2-HMAC-SHA1(Inputkey, ASCII(duid), 1000, 48)` → key32/iv16 → AES-256-CBC 解 base64 → 去 PKCS7；**判定式**：解出必须全可打印 ASCII **且 == 所用盐**（自指，错盐命中率 < 1e-7）。详见判据文档 §四。

## 5 已排除的路（实测）
空串不加密 ❌ · 常量盐 ❌（实测乱码）· 本机 MachineGuid 变形 ❌（24 种不命中）· Windows.old 旧 hive ❌（config 已不在、Users 无 shen0）· `d:/2` 机器备份 ❌（0 命中）· Player.log 漏 DUID ❌（0 命中 + 仅全零 32-hex）· 换机跑原版 ❌（结构性不行）· 从密文反推 ❌（128-bit 未知盐，PBKDF2 不可暴力）。
