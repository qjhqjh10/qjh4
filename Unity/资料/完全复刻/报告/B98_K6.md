## 二 为什么 423 是「零行为」而不是「放宽了判据」

- 撤掉的那一格是 **`tut.CurrentTurn == null`**（`Ctx.Tutorial.CurrentTurn` 为 null ⇒ 早退）。
- 它在原版**没有对应物**（`IsScriptedStageAvailable` 两道闸），在**我们这边**的**唯一作用**是给下一句 `TutorialRules.IsWaitingUseAbility(tut.CurrentTurn, …)` 做取数前置 —— 而那一句**自己就有** `if (turn == null || turn.actions == null || ctx == null) return false;`（`TutorialScript.cs:1984`）。
