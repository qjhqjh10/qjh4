## 3 三级回退怎么落的

原版 `SelectStartupLanguage` → 我们这一段（`Core/Loc.cs`）：

```
Default（属性）    = MapSystemLanguage(Application.systemLanguage)      // 第 ②③ 级
Load()             : ① PlayerPrefs["Language"] 合法 ⇒ 直接用它
                     : ② 否则 ResolveStartup(null, Application.systemLanguage) ⇒ 系统语言映射
                     : ③ 映射不中（不在 13 种）⇒ Fallback = English（= Languages[0]）
ResolveStartup(int? saved, SystemLanguage device)                      // 纯函数，Load 与断言共用
                     : saved 合法 ⇒ (AvailableLanguages)saved
                     : 否则       ⇒ MapSystemLanguage(device)          // 内部 default ⇒ Fallback
```

- **第 ① 级**：`PlayerPrefs.HasKey(PrefKey)` 有键才读（原来用 `GetInt(key, (int)Default)` 的默认参，现在 `Default` 是运行期值，改成显式 `HasKey` 更贴「本地记住的设置」这一级的语义）。非法值 ⇒ `Debug.LogWarning` + 当没存过（⛔ 不静默）。
- **第 ② 级**：`MapSystemLanguage` 逐条 `switch`（只写 13 种 + `Chinese/ChineseSimplified/ChineseTraditional`），**`default ⇒ Fallback`**——原版没有「猜一个近似的」那一步，所以这里也不猜。
- **第 ③ 级**：原版取「I2 源语言表里第一个 `IsEnabled` 的语言」；本工程语言表没有禁用项 ⇒ 等价于 `Languages[0]` = **English** = `Fallback`（断言 A2 钉住这个前提）。
- **登录期那道兜底**（`SetInitialLanguage`：不在 13 名内 ⇒ English）在第②③级里已被覆盖：`MapSystemLanguage` 的返回值**恒在 13 种内**。
