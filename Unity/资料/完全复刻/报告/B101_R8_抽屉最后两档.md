### A-4 缩放：`×0.4839` 到底是不是判据？—— **不是；真判据是一条算式，不用真机**

**`UIScaleToFit.Fit()` 的完整语义**（`decomp_full/UIScaleToFit__Fit.c`；ILSpy 版丢了控制流，以 `.c` 为准）：

```
targetRect = 序列化字段 targetRect（非空时用它；`fitInParent=1` 且没显式给才用父件）
if (paddingType == 0 /*Flat*/)      targetW = targetRect.rect.w + padding.x ; targetH = .h + padding.y
else                  /*Multiplier*/ targetW = targetRect.rect.w * padding.x ; targetH = .h * padding.y
ratio = min(targetW / this.rect.w, targetH / this.rect.h)        // ← 等比"内接"
transform.localScale = (ratio, ratio, ratio)
```

**两份 prefab 的序列化字段（YAML 现读，逐字相同）**

```
fitInParent: 1
targetRect : {fileID: 224370222726513266}   → 反查 = Content      ← 不是父件，是显式的 Content
padding    : {x: 1.35, y: 1.35}
paddingType: 1                              → Multiplier（乘法）
```

**代入（Content = 712 × 1080，卡抽屉根按 ARF 0.66 撑满格）**

```
ratio = min(1.35 × 712 / 2.5437 , 1.35 × 1080 / 3.3686) = min(377.87 , 432.80) = 377.87   // 每 1 个"卡单位"画多少设计 px
```

🔑 **反验证**：`menu_dump` 自己算出来的 `×0.483895` = `min(0.91×1.35/2.5437, 1.38×1.35/3.3686)`
（0.91×1.38 是 `menu_dump` 在**那个宿主实例**上量到的根框）—— **两个数互相对上**（0.483 vs 0.4839，差的是 0.91 的取整）。
⇒ `menu_dump` 算的就是这条公式；`×0.4839` 只是**某个宿主格子里**的值，**换个格子就变**，⛔ 不能当常量抄。

**落到我们的实现（可直接用）**

```
卡体（2DCard）设计尺寸   = 2.0927 × 3.3313  卡单位
每卡单位设计 px (K_unit) = 1.35 × 712 / 2.5437 = 377.87
⇒ 卡的**设计 px** = 790.76 × 1258.85，中心 = Content 中心 = (356.4 , 540)
⇒ 相对 Content 宽的比例：卡宽 = 1.1106 × Content 宽（高 = 1.1106 × 1.592 × Content 宽）
```

`CardView` 在 108 ppu 下 scale=1 时是 **226.0 × 359.8 设计 px**（`CardView.Width 2.0927 × 108`，`BattleDriver.cs:9953` 同一口径）
⇒ **`localScale = 790.76 / 226.01 = 3.4988`**（若抽屉按 `fr.K` 缩过，则 `3.4988 × fr.K`）。

矩形（设计 px，root 左上原点，y 向下）：
`x1 = 356.4 − 395.38 = −38.98` · `y1 = 540 − 629.43 = −89.43` · `x2 = 751.78` · `y2 = 1169.43`
（**会横向溢出 Content 每边 ~39 px、上下溢出 ~89 px** —— 这是原版行为，§C-4 里说为什么不是我们算错。）

**⇒ 「需真机验缩放」这一条可以划掉。** 真机要看的是「溢出后压住邻格」是不是原版的样子（判据已定，视觉待验）。

### A-5 两个字符串字面量（`GetIdForClonedCard` 的 `Replace` 到底替换什么）

`AlternateArtCard__GetIdForClonedCard.c` = `return id.Replace(DAT_1842507f8, DAT_1842b80e0);`
用 `工具/read_il2cpp_string.py` 解出（两档都是 StringLiteral）：

| 槽 | 解码 | 值 |
|---|---|---|
| `0x1842507f8` | `type=5 idx=2077 entry=1038` | **`"#"`** |
| `0x1842b80e0` | `type=5 idx=1 entry=0` | **`""`**（空串；同一槽被 `CardDrawer.GetItemName` 返回 ⇒ 卡抽屉没名字，与 §A-1 自洽） |

⇒ **`GetIdForClonedCard()` = `id.Replace("#", "")`**（去掉 id 里所有 `#`）。

⚠️ **没查清的那一半**：`#` 挂在**异画物品 id**上还是**克隆卡 id**上，静态读不出来（要看异画那一批 `RawCardScript` SO 或奖励数据里 id 的写法）。
我们 `Resources/profile_cosmetics.json` 里 **0 个 `#`**（只装了 avatars / titles / achievements / borders，**没有异画物品**）⇒ **异画物品的 id 我们手上还没有**。
施工前必须先确认这条（否则「去了 `#` 的那张卡」取错）。
