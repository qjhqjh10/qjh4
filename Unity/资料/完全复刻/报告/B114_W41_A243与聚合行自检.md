## 二、`B-283` · 聚合行静态自检 `工具/check_aggregate_lines.py`

### 2.1 判据

1. **聚合行** = 一行里 `\w+_Assert\.Run\(\)` 出现 **≥ `--min-runs`（默认 20）** 次。
2. **「真正的 `//`」** 用逐字符扫描求，跳过：
   - 普通字符串 `"…"`（`\\` 转义）· 逐字字符串 `@"…"`（`""` 转义）· 插值字符串 `$"…"`
   - 字符字面量 `'…'`
   - 块注释 `/* … */`（**可跨行**；块注释里的 `//` 不算）
3. **违规** = 第 k 个 `Run()` 的**起始字符位 ≥** 该行第一个真 `//` 的字符位（字符位 = Python 解码后的 Unicode 码点，行内相对行首；行尾 `\r` 不计入行宽）。
4. 退出码：`0` = 全过 · `1` = 有违规 · `2` = 用法/读文件错（**不带参只打用法，不默认扫整棵工程**）。
5. `--json` 出机器可读；`--any-assert-call` 可放宽到 `\w+_Assert\.\w+\(`（含 `RunEngine()` / `CheckXxx()`）。

> 口径说明：**默认只精确匹配 `.Run()`**，是为了避开「注释里的散文提及」——见 §五-2 的实测假阳性。
