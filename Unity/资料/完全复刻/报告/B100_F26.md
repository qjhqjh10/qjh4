**改后**（同一行；`count` 在收窄后**重算**，重算不了时**如实 gap**）：


三句各自的理由：

| 句 | 作用 |
|---|---|
| `int candFaithful = cands.Count;` | 收窄前的候选数 = 「候选有没有被**真收集成 `UnitState`**」的判据（棋盘族收集 ⇒ `count == cands.Count`；墓地/手牌池只 `count += 1`、不收集 ⇒ `cands.Count == 0`） |
| `if (cands.Count != candFaithful) count = cands.Count;` | **本笔的修复本体**：收窄真生效 ⇒ 计数跟着走（原来永远是收窄前的数） |
| `else if (narrowingRequested && candFaithful != count) { gap = …; return null; }` | **不许静默失败**：这一档要求收窄但候选不是 `UnitState`、重算不了 ⇒ 出声判不了，⛔ 不拿收窄前的数顶（现池 0 行命中，休眠件，铁律 11 照样建） |

**⛔ 没有动的**：`ApplyMaxTargets` 的 `if (max < 1 || count <= max) return count;`（`:938`）—— 那是原版 `AbilityLogic__GetTargets.c:1164` / `:1169` 那道早退的形状，X9 明确要求别改它。
