#### B. `:847` —— **照施工单字面接会静默做错（停手反证）**
施工单写「生产点 = `EffectResolver.AttachHandEffect:5607`：写 `inst.HandEffects[...].Permanent = CardDef.HasPermanentHandCostBuff`」。四条反证：

1. **`AttachHandEffect` 手上没有「能力属主那张卡」**。实参只有 `source`（卡面分句字符串）· `ctx.ActingUnit`（＝**载体**；`Living Icon` 那条链上就是督军）· `inst`（**接收**这条效果的手牌）。全池 `HasPermanentHandCostBuff == true` 的只有 `GSC51 Living Icon`（`permanentBuffs` 两行 `at=enchantment` · `buffType=2` · `token=0474b163…`）与其**附魔模板** `0474b16360827b6408fb02b6820e7e63`（`enchantment_templates.json` 现读：`permanentBuffs[{at:buffEffect, buffType:2}]`，`abilities[{trigger:580 → logic[{ca:30, ta:50}]}]`）—— **两者在该调用点都拿不到**。
2. **照字面写 `inst.Card.HasPermanentHandCostBuff` 恒 `false`**：`inst.Card` 是**接收方那张普通手牌**，它自己的 `permanentBuffs` 是空的 ⇒ 写进去等于什么都没写，却会让账看起来「已接」= **静默做错**。
3. **`Living Icon` 的降费在我们模型里根本不经 `AttachHandEffect`**：卡面 `Lower the cost of a random troop in hand by 1` 解析成 `lowercost` ⇒ 走 `DoLowerCost`（`EffectResolver.cs:15309`）→ 落 `ctx.CostMods`（`:15485` 一带），**不产生 `HandEffect` 记录**。而它写的 `ExpireTurn = op.Duration == "turn" ? ctx.Turn : -1`，卡面没有 `this turn` ⇒ **`-1` = 永不过期 = 在我们模型里本来就已「永久」**。⇒ L847 的消费点（`RuleCore.ExpireHandBuffs` 的手牌效果清扫）**结构上碰不到它**。
4. **合法输入 = 0**：`cards_engine.json` 1,129 张现扫，`permanentBuffs` 里 `buffType == 2` 的行**只来自 `GSC51`**（且是聚合行、`at: "enchantment"`）。

⇒ **建议的口径（给下一位）**：`HandEffect.Permanent` 该由「**产生这条效果的 ability 行**」决定，而我们的 `HandEffect` **不带 ability 属主**。要真接，前置二选一：① 给 `HandEffect` 记住属主卡（`CardInstance.cs`）；② 承认「手牌费用永久性」我们走的是 `CostMod.ExpireTurn`，把它当**已等价**并改这一行的判据口径（**要调度台裁**，不是写手能定的）。
