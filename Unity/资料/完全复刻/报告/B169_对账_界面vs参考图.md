## 三、可修清单

### 3.1 🔴 白块缺陷（本会话单列 · 两类，根因同一个）

**A. 个人资料页**（`71_profile2.png`）：纯白矩形 **(1168,112)–(1532,476) px**（≈440×440 设计单位）+ 2 个 **(1000,500)–(1100,584)**、**(1000,652)–(1100,732)** 小白方形。
- 对应参考图：大块 = 面板右上那幅**战将大立绘**（骑摩托的星际战士，原版 `Warlord Mastery` 卡上的 `Badge`，440×440）；两个小块 = 三张信息卡左侧的**阵营圆形徽记**（参考是金/黄圆徽）。
- 代码落点：`Shell/ProfileTab.cs:1276` 与 `:1906` 的 `Badge` 矩形（warlord 版 440×440 = `1397.12, top-233.32 → 1837.12, top+206.68`；普通版 123.07×104.28 = `:1766`/`:1979`），`RefreshWarlordMastery` 一带的光照分支 `:1920`。
- 根因：贴图取不到时走 `Rect(..., null, ...)` ⇒ `CardArt.Solid()` 的**不透明白图**。同文件 `:291-293` 已经写明这是「`RankedTab` 那两处白块的病」，但这两条路径没堵。
- 修法：与 `TitleTab.cs:480` / `ProfileTab.cs:1645` 的做法对齐 —— **取到 tex 才 `SetActive(true)`，否则 `SetActive(false)` + `LogWarning`**。
- 附带：白块把面板右上角的 **X 关闭钮**盖住/挤没了（其它五页 X 正常可见，参考个人资料页也有 X）。

**B. 头衔页**（`73_title.png`）：纯白矩形 **(288,280)–(472,460) px**（≈221×221 设计单位）。
- 对应参考图：`选择你的头衔` 左侧那枚**称号所属阵营的大盾徽**（带翅膀的盾+剑）。
- 代码落点：`Shell/TitleTab.cs:61`（`IconL/T/R/B = 344.32,295.19 → 565.54,516.41`）+ `:274` / `:477`。
- 根因同上：`PreviewArmyIcon()` 返回了名字但贴图缺失 ⇒ quad 在、贴图空 ⇒ 白图。`:480` 那条分支有 tex 判空，`:474-477` 这条没有。
