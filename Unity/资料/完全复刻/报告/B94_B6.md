## 四、判据证据（全部本轮现读；全文 → `判据/B94_B6_判据补全.md`）

1. **`Countdown` 乘式（§1）** —— VA 反汇编 `Countdown$$Update`（`0x180623EA0`）：
   `movss xmm6,[rdi+0x44]` → **`cvttss2si rcx,xmm6`** → **`imul rcx,rbx`** → `call 0x180A89E90`
   （callee 全文 `mov rax,rcx; ret` = `TimeSpan.FromTicks`）。
   两个常量：`0x1834B2F60` = **8 字节 double 1.0**（4 字节读 = 0.0 是**错档**）· `0x1834B2DF4` = 4 字节 float **5.0**。
2. **深拷家族（§2）** —— `DeepCopy` 全族 22 处，`decomp_full` / `out_cpp2il_dev_ilspy` / `out_il2csharp` **三源同结论：家族外 0 调用点**；
   我们侧生产写点 = `CardDatabase.cs:2426-2446` + `EffectText.cs:10162`，`.minValue=/.maxValue=` 等全仓 7 处命中与本族无关。
3. **`Enchantments.TryGetCard`（§3）** —— `decomp_full/Enchantments.CardEffectToCard_Int32Enum___TryGetCard.c` 全文可读：
   `Enum.Equals(kind, key)` → `GetRandomInt(0, cards.Count)` → `cards[idx].Reference`。
4. **`ListExtensions`（§4）** —— `SpliceWhere` 体 = `Where → (count>0 ? Take) → ToList → 逐条 Remove`；
   `GetMax`/`GetMin` **同址同体**（ICF，`FUN_180d10f70`，`Append + Aggregate`），方向由 ILSpy `_003CGetMin_003Eb__0`（`:459`）定：
   `c >= 0 ? i2 : i1` ⇒ **同分取后者**。
5. **记分条/进度条宿主（§5）** —— 按 `monoscripts.json` 的 pathID 反查 `m_Script` 再走 `m_Father` 链现跑：
   `AllianceScoreBar` 6 / `MilestoneScoreBar` 3 / `ProgressBar` 7 / `GenericScoreBarLine` 15，**宿主 GO 两两无交集**；
   宿主路径与序列化字段（`MilestoneScoreBar{progressBar,scoringLines}` · `ProgressBar{slider,text}`）已逐条列在 §5。
6. **唯一 id（§6/§7）** —— 17 实例（menus 13 + 主菜单场景 4）/ 10 个 id；唯一消费者 = `TutorialPointerData.Target`。
7. **`FactionScore`（§8）** —— 三序列化字段；**无阵营名节点**；`Small`（6 实例，AllFactions 行 + Ranked Division Info footer）与
   `Big`（6 实例，`Player Profile Window/…/Top4` 的 #1–#4，第二行节点名 = `MaxRating`）两套几何逐值不同。
