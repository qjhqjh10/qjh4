| 🥉 解包资源 | 三个用它的 uGUI `Image`（`m_Material.m_PathID = 1349812993706917952`）：`Avatar Menu Item/Image Container/Image` · `Player Profile Window ▸ Avatar Tab ▸ … ▸ Avatar Menu Item ▸ … ▸ Image` · `Player Profile Window ▸ Profile Cosmetic Tab ▸ … ▸ Image` —— **都是 `m_Sprite = 0`**（运行期由 `AvatarDisplay.ChangeAvatar` 灌图） |

**四步（`AvatarDisplay.DoShine(float time)`）**：
1. 缓存字段 `+0x90` 为空时：`new Material(image.material)` 存进缓存并 `image.SetMaterial(...)`（**每颗头像一份材质实例**）。
2. `DOTween.Kill(material)`。
3. `material.SetVector("_Shine_Movement", (0, 0.2, 0, 0))` → `DOVector(材质, (0, 1, 0, 0), "_Shine_Movement", **4.0 秒**)`。
4. `transform.DOPunchScale(punch = <静态向量> × 0.1, 0.3s, vibrato 0, elasticity 1.0)`。

⇒ **那道光是「选中头像后 4 秒扫过一遍」的一次性补间**，不是 `_Time` 自走、也不是 `_Color` 脉冲。
镜头侧由 shader 自己算：`_USESCREENSPACE` 档用 **屏幕坐标**（`gl_FragCoord / _ScaledScreenParams`）做 uv，
旋转 `1.04 rad` 后加 `_Shine_Movement`；`_MainTex`（头像图）的亮度梯度造法线做偏移。
