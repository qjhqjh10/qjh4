⇒ 同 `Decorator` / `ContainerBuilder` 那个毛病（**同一原版方法两处记、判据不同步**）。本批**两表都改成 A**，并在主题表那三行的差异列写「与泛型表 642–644 同一件事」。

### 6·2 `ToggleCollectionFilter` 也有两份，已对齐

`收藏.tsv:312`（`ToggleCollectionFilter`）与泛型表 `143`（`ToggleCollectionFilter<T,`）是同一件事；312 早已 A、143 原本 C ⇒ 本批把 143 改 A（差异写清「与 312 / 泛型表 65 同判」）。

### 6·3 `ImageQuad` 没有 `fillAmount` —— 以后凡是 `Image.fillAmount` 的复刻都会撞这一条

本批用 **uv 左→右显影**当等价物（`SetUvRect(0,0,f,1)`）。这不是第一次（`Core/CostCurveDrawer.cs` 里也有一整套「等价于 `Slider.fillAmount`」的几何补间）。
建议界面线**收口一个共享口**（例如 `ImageQuad.SetFillHoriz(float)`），⛔ 别每个窗各写一套。

### 6·4 `EventBadge` prefab 不在离线包里（这条会影响以后所有活动组件）

`assets_full` 全量按 `notificationHolder` / `notificationText` 字段名搜 = **0 命中**；而 13 份活动 SO 的 `EventComponents[25]` 也**一份都没有**带值。
⇒ 结论（如实）：**本 build 的离线资源里没有 EventBadge prefab**，它是远端 Addressables 的引用。若将来要真做角标视觉，得去
`D:/2/关服前存档/安卓版本warpforge，包含远端资料/` 的 `UnityDataAssetPack.apk`（远端 Addressables 包）里找 —— 这是**新的挖包目标**，记在这里免得下一个人再「按字段名搜 0 命中就写本地没有」。

### 6·5 自检钩子统一了口径（供后续批次照抄）

四个新类都提供 `public static List<string> SelfCheck()`（在 `#if UNITY_EDITOR` 里，**不依赖场景/资产**），返回「问题清单」，空 = 通过。
