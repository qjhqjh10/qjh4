## 五、判据冲突 / 顺手发现

1. 🔴 **`JoinGroup` 的 `FunctionResult: null` 不安全**（与简报/A2 §4·4「回调对 null 安全」的说法冲突）：
   - `AlliancesController._003CJoinGroup_003Eb__1`（`out_cpp2il_dev_ilspy/AlliancesController.cs:960-966`）第一句是 `SetCurrentGroupCached(newGroup)`（这个 null 安全），**第二句 `PlayerDataManager.singletonManager.gameAnalytics.SendJoinAlliance(newGroup.groupId)` 无条件解引用**；
   - `AlliancesManager._003CJoinGroup_003Eb__0`（`AlliancesManager.cs:187-200`）同样无条件读 `group.groupId`；
   - `decomp_full/AlliancesManager.__c__DisplayClass40_0___JoinGroup_b__0.c` 里那个 `FUN_1803f47a0()`（NRE 抛）**在 `if (param_2 != 0)` 之外** ⇒ null 直接落到抛。
   - **为什么还是先落 null**：该分支现在**不可达**（`FetchGroups` 返回 `[]`，搜索列表空，没有可加入的目标），null 只是「不再落 `NotImplemented`」的占位；`CreateGroup` 那条**确实**有 `if (group != null)` 守卫，null 安全。
   - **升级条件已写进模板 `_todo`**：`FetchGroups` 一旦返回 ≥1 个 Group，「加入」按钮出现，`JoinGroup` 必须同时改成真 Group（否则点必 NRE）。OFF-34 的验收要拆成「创建」与「加入」两条。
2. **`Points<T>.get_Id` 用的是【泛型实参】的类型名，不是 `Points` 子类名**：`CampaignPoints : Points<CampaignHandler>` ⇒ `typeof(T).Name` = `"CampaignHandler"` ⇒ `"Campaign Points Neutral"`（`out_cpp2il_dev_ilspy/Points.cs:5,9-29`）。照子类名 `"CampaignPoints"` 去 `Replace("Handler","")` 会得到 `"CampaignPoints Points Neutral"` —— 我的 `--check` 第一版就是这么错的，已按 `.cs` 修正。`add_all_configs.py:187-188` 的注释写的是同一套推导（`ForgePoints` 那条对，是因为 `ForgeHandler` 恰好等于 `Forge`+`Handler`），后来人别按子类名推。
3. **`MissionsConfig.challenges` 的最终形态是 S1 的 6 条**（`Daily_5/9/10` + 周挑战 + 骷髅 + 登录），不是本文件草稿 §4 的「3 条 `Daily_Generic_*`」。该草稿已标 ⛔「不要再粘」—— 粘上去会把已实测通过的 6 条打回 3 条、且奖励物 id 会从 `campaignPoints` 变回不存在的 `Campaign Points Neutral`。
4. **改名不回显玩家输入**：模板是静态 JSON，`server.py` 没有「读请求参数回填」的能力 ⇒ `newName` 固定串。要真回显得改 `server.py`（读 `FunctionParameter.Data` 里的新名字），属**代码改动**，建议单开一条账（A2 §3·4-A1 已提）。
5. **`MISSION_DAILY_EVENT.Data.maxActiveCount` 保留 4 未动**：真正的日常上限是 prefab 的 `dailyMissionsHolder.maxAmount = 3`（`Missions Tab.prefab:21158`），第 4 条会被 `TryAdd` 丢弃；`maxActiveCount` 的消费者没全验，所以不动它（A2 §2·6-2 的建议）。
6. **`GetLeaderboard.total` 是 `Nullable<int>`**，给 `0` 而不是 `null`：`GetTotalByArmy` 之类的读法对 null 会走 `?? 0` 吗本机没验，给 0 最稳。
7. **`ItemsConfig` 两张表已从 `[]` 变成真值**（本次落地）：`itemsOrActionPrices` = `ChangeName` ×1、`unlockOriginalArtPrices` = rarity 1..4。**若将来删掉两个价格模板，必须把这两张表退回 `[]`**（否则点下去弹 `NotImplemented`）。
8. **`responses/` 现 46 个 JSON**（本次 +5）。服务端 `TemplateStore` 热重载 + `strict=True` 自测都已验，新模板无需重启即可生效。
