## 7 补查（调度台追加授权后）：`warlordStartSizeFactor` 的消费者 —— **已坐实**

> §5·1 原来的「判不了」已作废。手段 = **不用 Ghidra 的自制真 xref**：直接扫 `GameAssembly.dll` 的 **`il2cpp` 段**（⚠️ 代码**不在** `.text` —— `.text` 只有 4.9 MB 是引擎侧，48 MB 的 il2cpp 段才是游戏代码；第一版只扫 `.text` 得 0 命中，差点误判「没有人调用」）。

**步骤与结果**
1. `BattleManager.DeviceVariables()` 的 VA = `0x180508E50`（`dump.cs` RVA `0x508E50`）。
2. 扫 `il2cpp` 段里所有 `E8 rel32`（`call`）且目标 == 该 VA ⇒ **17 个调用点**。
3. 逐点向后反汇编 0x140 字节，找 `[... + 0x30]` 的**浮点**读 ⇒ **只有 1 个**：
   - `0x180611B6F  movss xmm2, dword ptr [rax + 0x30]`
   - 另 2 个是误报：`0x1805FE953 mov rcx,[rcx+0x30]`（指针，属 `CardScript.ShowCardInHand`）· `0x1824D9161 mov [rsp+0x30], r15`（栈写）。
4. 该指令所在方法（按 `dump.cs` 的 RVA 区间反查）= **`CardScript.<HeroLandIntoField>d__318.MoveNext`**（方法 RVA `0x6117C0`）。

**语义（指令 + `.c` 双向对上）**
```
mov  rcx, [r13 + 0x258]      ; CardScript+0x258 = battleManager
call BattleManager.DeviceVariables()      ; 0x180508E50
test rax, rax ; je ...
movss xmm2, [rax + 0x30]     ; VarsDevice.warlordStartSizeFactor（桌面 1.3 / 移动 1.5）
movss xmm0/1/…, [rbp-0x19 / -0x15 / -0x11]   ; card.defaultScale（CardScript+0x324，dump.cs:35508）三分量
mulss 三对                    ; 三分量各 × factor
call  UnityEngine.Transform.set_localScale  ; 0x183024AE0
```
`.c` 同段（`CardScript._HeroLandIntoField_d__318__MoveNext.c:36-56`）：
`BattleManager.GetUnitSizeInPlay(cardType, isPlayer)` → `CardScript.set_DefaultScale(那个尺寸)` → 取 `+0x324/+0x32C` 的三分量 → `× factor` → `Transform.set_localScale`；紧接着
`if (*(float *)(param_1 + 0x28) != 1.0f)`（= `waitMult != 1`）时还有 `localPosition.y -= 0.2`（`DAT_1834b2bb0`）。

**⇒ 判据（可直接施工）**：`warlordStartSizeFactor` = **督军「入场落位」那一刻的缩放倍率**：
`transform.localScale = card.defaultScale × DeviceVariables().warlordStartSizeFactor`。

**我方落点**：`CardPresentation/Battle/BattleDriver.cs:34703 HeroLandInto` —— 它的 doc **自己就写着「🔶 缩放/alpha 两半按我们的形状不写（见 HeroLandInto 的 doc）」** ⇒ 缺的正是这一半。
接的次序照原版：① `GetUnitSizeInPlay` 的等价物 → `DefaultScale`；② `localScale = defaultScale × factor`；③ 再判 `waitMult != 1.0` 的 `localPosition.y -= 0.2`。
值件 = 新建 `CardPresentation/Core/VarsDevice.cs`（桌面 **1.3** / 移动 1.5）。

**顺带**：`CardsHorizontalLayout.GetPosition/GetRotation` 那两处读 VarsDevice 的是 `+0x28`（`extraSpaceOnSelectedCard` 曲线）/`+0x18`/`+0x1c`，与 `warlordStartSizeFactor` 无关 —— B3 记的「`HandLayout` 6 处引用」指的是那条曲线，别混。
