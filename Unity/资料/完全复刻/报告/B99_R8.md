## §2 `真缺` 逐条（只有 1 条）

### 2·1 `Gargoyle Swarm Near`（6 行：`Gargoyle Swarm` VFX Graph + 3 个 ComputeShader + `SDF_Test` / `vectorfield` 两个 Texture3D）

- **原版哪个功能在用**：`Gargoyle Swarm Near/Mid/Far` 是 **`EnvironmentalCondition Leviathan Sweeping Infestation`** 的三个子件
  （R0 引用链：`Gargoyle Swarm Near ← Transform#8821932928566009538 ← Transform#-6760940038237151550 ← EnvironmentalCondition Leviathan Sweeping Infestation`）。
  这条 SO 就是 Leviathan 那张**进攻卡「Sweeping Infestation」**换上去的整场环境
  （我们的数据入口 `Resources/OffensiveCards.json:348-352`：`name=Sweeping Infestation` / `envSO` / `prefab` 三项都指向它）。
- **我们对应的实现类/构造点**：环境切换链是齐的 —— `Core/EnvironmentConditions.cs:10`（`EnableEnvironment` 三步）·
  `Battle/EnvironmentApplier.cs:12`（③ `Instantiate(scenarioObjects)`）· 环境 prefab 本体也重建过：
  `MyGame/Assets/WarpforgeVFX/Prefabs/EnvironmentalCondition Leviathan Sweeping Infestation.prefab`
  （`Gargoyle Swarm Near` 在 `:43982`、`Far` `:79973`、`Mid` `:80100`）。
- **缺的是资产本身还是接线**：**资产本身**（接线不用改）。实测那三颗节点上：
  ```
  VisualEffect:
    m_Asset: {fileID: -2190925272322067318, guid: 00000000000000000000000000000000, type: 0}
  ```
  `guid` 全零 = 悬空引用；工程内 `find -iname "*.vfx"` = **0**、`VisualEffectAsset` 资产 = **0**
  ⇒ 这三颗 VFX Graph **运行时什么都不播，而且不报错**（违反「不许静默失败」）。
- **不是孤例**：全工程 **4 件** prefab 带 `^VisualEffect:` 组件、`.vfx` 一个都没有 ——
  本件 + `WarpforgeVFX/ArenaOriginalPrefabs/battlearenaaeldari/battlearenaaeldari__Scenario.prefab` +
  `…/battlearenaleviathan/battlearenaleviathan__Scenario.prefab` +
  `WarpforgeVFX/Prefabs/EnvironmentalCondition Saim Hann Infinity Circuit Overload.prefab`。
- **要做的事（可照做粒度）**：
  1. 导出 `assets_full/bundle_battleprefabs_vfxandmisc_assets_all/` 的 `VisualEffectAsset_-2190925272322067318`（`Gargoyle Swarm`）
     + 三个 `ComputeShader`（`[Gargoyle Swarm] [System] {Initialize,Update,OutputUpdate} …`）+ `Texture3D/` 的 `SDF_Test` / `vectorfield`；
     判据源都在本地，路径已在上表。
  2. 把 `VisualEffect.m_Asset` 的三处悬空 PPtr 指回新资产（4 件 prefab 各查一遍）。
  3. **前置可行性**：VFX Graph 资产要 Unity 装了 `com.unity.visualeffectgraph` 才能反序列化；若不可行，
     最小动作 = 让这三颗节点**出声**（`Debug.LogWarning` 一次），⛔ 不许继续静默。
  4. 另三件 prefab（两个战场 Scenario + Saim Hann 那件）同批一起核，别只修本件。
