## 二、L179 / L231：禁用态 `disabledColor`（RGB + α）—— 证据链

1. **判据（原版）**
   - `d:/2/tools/decomp_full/EverguildButton__SetUpButtonColors.c`（54 行）：体只做一件 ——
     `if (colorTintGreyOnDisable(+0x17A) && m_Transition(+0x50) == 1) { colors.disabledColor.a = colorTintGreyOnDisableAlpha(+0x17C); set_colors }`。
   - 而**RGB 本身不是这个方法写的**：它是 prefab 里 `m_Colors.m_DisabledColor` 的既有值，由 UGUI
     `Selectable.DoStateTransition`（`case SelectionState.Disabled ⇒ tintColor = colors.disabledColor`，
     再 `StartColorTween(tintColor * colors.colorMultiplier)`）**乘**在目标图形上。
   - 逐颗实读分布（`B141-W34` 已落）：`(0.7843 ×3)` **1208** 颗（a=1.0 696 / a=0.502 504 / a=0.0 8）·
     `(0.8019 ×3)` **19** 颗 · 纯白 **49** 颗；ColorTint 且 `grey=1` 的 = **270 Button + 24 Toggle**。

2. **我们的落点（现读 `Shell/WindowButton.cs`）**
   - `KeyOf(BtnState)`：`if (!_interactable) return DisabledKeyNow;`
   - `DisabledKeyNow`：`DisabledKey`（出厂 0.7843137 ×3, a 0.5019608）+ **α 判据**
     `if (ColorTintGreyOnDisable) c.a = GrayOnDisableAlpha;`（出厂 1.0）。
   - `ApplyTint()` → `ComposeVertexColor(b, _k, ColorMultiplier)` = `Clamp01(底座 × 色键 × 乘数)`，**r/g/b/a 四通道**。

     （= UGUI 那两档本来就不走色偏）。
   ⇒ **「偏亮 ≈27%」的残差（1 / 0.7843137 = 1.275）在现读代码里不存在**。

3. **本波改的**：只改注释（`WindowButton.cs:979-981`，3 行 → 3 行，**行号零漂移**）——
   把「我们**没有对应物**」改成「RGB 与 α 两半都在」，并写清唯一真正的残差

## 三、L229：`PlayButtonSound` 的 `HasAudios()` 那一跳

### 3·1 判据（`d:/2/tools/decomp_full/EverguildToggle__PlayButtonSound.c`，69 行逐句现读）

```
cue = m_onClickSound(+0x130)
if (cue == null || !cue.HasAudios()) {
    if (useDefaultSound(+0x138)) cue = SoundManager.defaultButtonSound;   // → 直接播
}
if (cue != null && cue.HasAudios()) SoundManager.Play2D(cue, MixerType.FX);
else return;                                                              // 静音
```

⇒ **三档决议**：① 自身 cue **有声音** ⇒ 播它；② 否则 `useDefaultSound` 为真 ⇒ 默认按钮音；
③ 否则 ⇒ **一条都不播**（连 `PlayFx` 都不请求）。

> 🔴 **与简报口径的差异（按判据修正，铁律 3/10）**：简报括注「cue 为空/无 audio 时不播」若照字面做，
> 会把 **564 + 18 颗「自身 cue 为空、靠默认音」的按钮**一起掐哑（`EverguildButton` **1022/1022** ·
> `EverguildToggle` **151/151** 的 `useDefaultAudioClipIfNull = 1`）。判据原文那一档是「**且** `useDefaultSound` 为假」才静音。
> ⇒ 本波按判据的三档实现，并在断言里**双向**钉住（B1 断「空 cue 仍走默认音」、B2 断「不给默认音才静音」）。
