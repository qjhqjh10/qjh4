## ① B-234 · `GOF97` 是全池唯一 `ta = []` 的卡

### 结论

**合法空集，不是坏数据。** 而且活状态表那条的**归因是错的**：`ta=[]` 这一格**永远不会**触发
`ta-length-mismatch`（0 条 op ⇔ 0 个值，长度相等）。这张卡确实会记一条 gap，但记在 **Rally 那一块**
（1 条 op ⇔ `ta=[30,110]` 两个值），属**已知族**，与那个空数组无关。

### gap 到底记在哪（逐跳推演，每跳都有判据）

1. `Split` 按 `.` / 换行切 ⇒ **3 段**：`Stomp` / `Rally: Stun an enemy and adjacent units` / `Mob: Deal 1 damage to all enemies`
   （`EffectText.cs:1307-1322`）⇒ `BuildAbilityBlocks` 得 **3 块**（`EffectText.cs:2362-2384`）⇒ G1 `3 == 3` **过**。
2. **第 0 块 op 数 = 0**：`Stomp` 整句是纯关键词 ⇒ `IsKeywordOnly`（`EffectText.cs:2923-2939`）在 `:3649` 直接
   `return`，0 条 op ⇒ `ta.Length(0) == blk.Count(0)` ⇒ 走 `if` 分支、循环 0 次 ⇒ **不记 gap**。
3. **第 1 块（Rally）= 1 条 op**：`Stun an enemy and adjacent units` 是**单 op**（`EffectResolver.cs:16579` 原文：
   「`GOF97 Gargantuan Squiggoth`：`Rally: Stun an enemy and adjacent units` 是**单 op**」；同族见 `EffectText.cs:4595-4596`
   「`an enemy and its adjacent units` 那种「相邻」是**一条**目标」）⇒ 而 `ta = [30,110]` 长度 2
   ⇒ **`ta-length-mismatch` 记在这条 op 上**（`EffectText.cs:2124-2131`，新支 `else if` 在 `:2124`、赋值在 `:2130`）。
4. 第 2 块（Mob）= 1 op（"Deal 1 damage to all enemies"，全池对拍表里也是这一行）vs `ta=[10]` ⇒ 长度相等、过
   （`判据/B9_全池对拍_差异.tsv:317`）。
5. 这一档是**已知结构性族**，不是这张卡的数据坏：`报告/B113W2_引擎criteria.md:26` 记「`ta` 长度 ≥ 2（结构上挂不上）=
   **290 条 / 272 张卡**」；`判据/B113W2_criteria普查.tsv:788-790` 已把 GOF97 的 `ab=1` 判成 `logic-gate(块内多 op)`。

## ② B-235 · `AttackSelector.cs:1997` 那句「无视觉作用故不建」

### 先纠正一处指代

那句话**不是**说 3 颗圈不该建 —— 它说的是每颗圈上**第 5 个组件 `EverguildButtonMaterialModifier`** 不建。
**圈本身我们早就建了**：`_rings[3]`（`AttackSelector.cs:624`）· 图 `Attack_type_button_highlight`（`:895` / `:980`）·
rect `RingW/RingH = 176.23 × 176.875`（`:143`）· 选中态 `SetActive` 按 `IsPickedSlot`（`:1528`）。

### 那 3 颗圈是谁（arena1 现读，13 场同构）

| 圈（GO） | `m_IsActive` | 组件（5 个，顺序即 `m_Component`） | 父（`m_Father`） | 宿主按钮的 `highlightImage` |
|---|---|---|---|---|
| `Highlight`（GO 112） | **true** | RectTransform 3028 · CanvasRenderer 2170 · Image 5267 · SimpleRotation 4481 · **Modifier 4395** | `Select Melee Button`（RT 3368） | 112，`attackType = 1` |
| `Highlight_396`（GO 396） | **true** | RT 2776 · CR 2130 · Image 4108 · SimpleRotation 4305 · **Modifier 4693** | `Select Active Skill Button`（RT 2626） | 396，`attackType = 4` |
| `Highlight_180`（GO 180） | **true** | RT 3512 · CR 2249 · Image 4478 · SimpleRotation 4736 · **Modifier 5155** | `Select Range Button`（RT 2804） | 180，`attackType = 2` |

- `Image`（5267/4108/4478）：`m_Sprite` = `Attack type button highlight` · `m_Color (1,1,1,1)` · `m_Type 0` ·

- **Modifier 的序列化内容**：JSON 里**只有** `m_GameObject / m_Enabled / m_Script / m_Name`
  （`m_Enabled = 1`、`m_Name = ""`），**一个字段都没有** —— `ToogleGreyScale` 是自动属性的私有 backing field，
  Unity 不序列化它 ⇒ **默认 false**。
- 父链（8 层，逐层解 `m_Component` 的 `m_Script`）：`Highlight` → `Select * Button`（挂 `EverguildButton` +
  `CardDisplayAttackTypeButton` + 自己的 modifier）→ `Drag Attack Selector`（`AttackTypesButtonsController` +
  `HorizontalLayoutGroup`）→ `Safe area FrontCanvas` → `FrontCanvas` → `Canvas`（`CanvasScaler` +
  `UISafeAreaManager` + `EverguildGraphicRaycaster`）→ `BattleHud` → `BattlePrefab`。
  **这 8 层里没有任何 `Mask` / `RectMask2D`** ⇒ `GetStencilDepth()` 会是 0。

### 该不该建 —— 三样证据

**（a）唯一可能的视觉作用要 `ToogleGreyScale` 为真**
`EverguildButtonMaterialModifier__GetModifiedMaterial.c:37` —— `if (*(char *)(param_1 + 0x20) != '\0')` 才把材质换成
`Everguild/UI/Greyscale`（`:51-53`）；另一支是 stencil（`m_Maskable && stencilDepth > 0`，`:63-74`），本链无 Mask ⇒ 不进。
⇒ 位为假时**原样返回 base 材质**。

**（b）这个位只有一个写手，且它被宿主的一道闸关死**
- 写点**唯一**：`EverguildButtonHelper.DoMaterialRefresh`（`cpp2il/out_cpp2il_dev_ilspy/EverguildButtonHelper.cs:100-133`
  —— 里面算出 `(interactable ? 1 : 0) ^ 1` 并写回去；Cpp2IL 把那一句赋值吞了，只剩局部量，形状同「丢字段赋值」）。
- 调用点**只有 4 个类**（全树 `grep -l DoMaterialRefresh`：`EverguildButton` / `EverguildToggle` / `AllianceBadgeDrawer` /
  `EverguildButtonHelper` 自己）：
  - `EverguildButton.SetSoftDisabled`：`else if (colorTintGreyOnDisable)` 之后才调（`:1528` → `:1540`）；
  - `EverguildButton.SwitchMaterial`：`if (colorTintGreyOnDisable)` 里面才调（`:1548` → `:1567`）；
  - `EverguildToggle` / `AllianceBadgeDrawer`：宿主不是 toggle / 不是徽章，与本件无关。
- **宿主按钮的实测值（13 场 × 3 个按钮，逐个现读，全同）**：

| 场 | `colorTintGreyOnDisable` | `m_Interactable` | `softDisabled` | `graphicsToAvoidSetMaterials` |
|---|---|---|---|---|
| battlearena1 / 2 / 3 / aeldari / astramilitarum / blacklegion / darkangels / emperorschildren / genestealers / leviathan / sororitas / spacewolves / tauviorla | **0** | 1 | 0 | `[]` |

  ⇒ `colorTintGreyOnDisable = false` ⇒ `SwitchMaterial` / `SetSoftDisabled` **两条都直接跳过** ⇒ **`ToogleGreyScale` 没有任何路径变成 true**。
  ⚠️ 注意代码里的默认值是 `true`（`EverguildButton.cs:63`），**是序列化值 0 把它关掉的** —— 这一格是真正的闸，
  与「序列化里没字段」是两件事。

**（c）结论**：这 3 颗圈上的 `EverguildButtonMaterialModifier` **确实无视觉作用**（今天、以及原版任何一帧）。
`AttackSelector.cs:1997` 的**判词成立**，不需要建这个组件。
