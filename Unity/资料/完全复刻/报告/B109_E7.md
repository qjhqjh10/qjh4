### 1.2 🔴 施工单（`B108_A16` §六·2）那两处**不成立**（本笔的核心订正）

**① 桶已经搬走了 —— `VfxMap.Hit` 那一路恒空。**
`Core/VfxMap.cs:1263-1271`（2026-10-23 `T1`）载表时把所有逐卡 `hit` 行【改归】`unit_damaged_anim`：
`else if (ev.ev == Hit) { m[UnitDamaged] = picks; … movedToUnitAnim = true; }` ⇒ **`m[Hit]` 从不赋值**，
而 `ResolveAllTimed(..., perCardOnly:true)` 在逐卡查不到时**直接回空数组**（`VfxMap.cs:1582`）。
⇒ 施工单那句「`VfxMap.Hit` … `perCardOnly: true`」是**结构上的空转**。
`Pray_Exit` 今天在 `VfxMap.UnitDamaged`（= `"unit_damaged_anim"`）里 —— 断言 `B2` 钉住。

**② 播放时刻 `ActiveEnchantments` 已经空了。**
`RuleCore.ApplyDamageCore` 那一格是**排队摘**（`Enchantments.EnqueueRemovePray`，`Enchantment.cs:1060` 的 doc 自述
「泵点 = 外层 `ApplyDamage` 的 `ActionScope` 退出」；`RuleCore.cs:8623` = `using (BeginAction(ctx)) return ApplyDamageCore(…)`）
⇒ **引擎调用返回时附魔已经摘掉**；而 `PlaySignals` 是引擎返回**之后**才 drain（`RefreshAll()` 第一句，`BattleDriver.cs:19423`）。
⇒ 施工单那句「`Ctx.Players[p].Board[slot].Instance.ActiveEnchantments` 直接遍历」**恒读到空表** —— 断言 `D5` 钉住。

### 1.3 本笔的锚点 = 派发侧那条 `EvtKind.Trigger`

`B109_E6` 的 `FireEnchantmentAbilitiesByNumber`（`RuleEngine/Core/EffectResolverPartial_B109E6.cs:69`）在**摘除之前**、
按 trigger 数值那条路上发 `EvtKind.Trigger`，字段形状（`EmitCardTrigger`，`EffectResolver.cs:8416-8446`）：

| 字段 | 值 | 为什么够用 |
|---|---|---|
| `Kind` | `Trigger` | 只有派发侧带「附魔卡 + trigger 名」 |
| `CardId` | **附魔卡名**（`"Pray Enchantment"`） | `PlayUnitSkillAnim` 按它取**附魔卡自己**的动画行 |
| `Keyword` | `UnitDamaged`（可能带 `#i` 后缀） | 区分 `Pray_Success`（`TurnStartPlayer(31)`） |
| `Player` / `Slot` | **载体**（`FindSlot(unit)`） | 视图锚点 = 载体（原版 `AbilityData+0x10`） |

⚠️ 如实记（**原版形状，不是缺陷**）：`BroadcastUnitDamaged` 对**棋盘上每一张卡**各调一次 `ResolveDamageDealt`
（`.c:160` 在**该卡自己**身上 `OnTrigger(60)`）⇒ 这一拍会为「每一个带 `UnitDamaged` 附魔的单位」各来一次。
⛔ 别按「只演被打者」加闸（那是改原版）。

**b. 🔴 「0 伤也发 `EvtKind.Hit`」⇒ 本笔会在「盾挡下 / 0 伤」时也播 `Pray_Exit`（修法在引擎侧，不归本笔）**

`BroadcastWhen(WhenEventKind.Damaged, …)`（`RuleCore.cs:9559`）→ `FireBoardDamagedByNumber`（`EffectResolver.cs:10138`）
→ `B109_E6` 的附魔趟 → **本笔照播**。
⇒ **缺口在引擎侧**：`EmitHit` / `FireBoardDamagedByNumber` 需要一条「`amount == 0` 不派 60」的闸（原版那两行）。
本笔不动 `RuleEngine/**`（白名单外），如实上报。

**c. `Core/VfxMap.cs:3457` 有一条**还没删的「跳过附魔卡」闸**（同族 `SelfCheckUnitSkillAnims` 那半边已在 `B101_F1` 删掉）**
