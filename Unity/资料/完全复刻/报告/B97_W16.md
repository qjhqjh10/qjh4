## 四 与原施工单/既有文档的**三处冲突**（全部以 `.c` 为准，⛔ 不照抄错的）

### 4·1 关键词行的 `traitValue` **是 `> 0` 就追加**，不是 `> 1`
- `GameStaticData__GetEffectDesc.c:331-347`（`case 3`，本轮亲读）：
  `if (0 < *(int *)(param_1 + 0x40)) { uVar7 = Int32.ToString(param_1+0x40); Concat(traitName, " ", uVar7); }`
  ⇒ **值 ≥ 1 就拼 `" N"`**。
- 而 mark 行（`CardEffectItem__LoadEffect.c:96-99`）是 `if (1 < *(int *)(param_2 + 0x40))` ⇒ **`> 1` 才拼 ` (xN)`**。两处**不是同一个条件**（施工细则 §六·3 已记这一点）。
- ⇒ 施工细则 §三 S6 #7 写的 `"Get Vanguard one turn"` **少了那个数**。本件按 `.c` 断言
  **`"Get Vanguard 1 one turn"` / `"获得 先锋 1 一回合"`**，并另设判别式「⛔ 不许是裸关键词名」。
  ⚠️ **未经实拍核对**（本地没有原版 UI 实拍可对）—— 如实记在这里。

### 4·2 oath 三档在池内**不可达**（不是「没做」）
- 原版排除的是 `trait ∈ {1276,1277,1278}`（`DefinedTrait` 数值）。
- 我们的记录账 `TraitEffectRecord.Trait` 是**关键词名（string）**，而那三条 `DefinedTrait` **在池内没有任何关键词名对应**：
  它们被建模成 `CardDef.OathDouble` / `OathTripleActivation` / `OathInAllTurns`（`CardDef.cs:4310-4348`）三个 **bool**，
  「授给友军」那一层落在 `UnitState.OathTripleGranted` 布尔上（`Aura.cs:690-740`）—— **都不进 `_traitEffects`**。
- ⇒ 本件按「`DefinedTrait` 名的小写拼法」建了一**防御性名表**（`EffectsToShow.IsExcludedOathTrait`，doc 里写清「今天不可达」），
  A10a-d 断**规则核**（`IsExcludedNormal` 的数值判定）、A10e 断**注入记录**（`ApplyTraitEffect("oathdouble",1)` ⇒ 投影 0 条）。
  ⛔ 没有假装「池内能跑到」。

### 4·3 施工细则 §1.6 的 mark 行右列写错了
- 施工细则写 mark 行右列 = `Battle/Effect/{Khorne|Nurgle|Slaanesh|Tzeentch}`。
- **那一格错**：`Battle/Effect/Khorne` = 「赋予+2近战攻击和[[先锋]]」，是**契约的效果正文**，不是 mark 行。
- 真判据（`CardEffectItem__LoadEffect.c:53-99` 走的是 `enchanterText(+0x20)` 且 **`goto` 跳过 effectText**；
  `GetEffectDesc.c:396-412` 的 `case 8/0x11` 拼的是 `CardTraitDescription/<MarkOfChaosType>` = `…/Khorne`，
  官方 10,862 键表里**只有** `…/markOfKhorne`）⇒ 右列画**空白**。与类尾 `B95_FX` 那段五链文档一致。本件按**空串**实现。
