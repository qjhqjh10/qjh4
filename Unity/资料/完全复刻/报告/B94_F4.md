## 六、顺手发现（执行现场看见的，⛔ 都不在本批白名单内 ⇒ 只报不改）

1. **`EnemyReturnsAttack` 的外闸是 `isAttacker`（param_3）不是 `ranged`**（`.c:39` `if (param_3 != '\0')` 才进 sniper/longRange/shuriken 整块）；sniper/longRange 块内再加 `param_4==2`（远程）。我们 `NoCounter` 用 `ranged` 当外闸 → **在「attacker 视角 + 远程」这一档与 .c 等价**（attacker 恒真），但**若将来有非 attacker 视角调用**（`isAttacker=false`）会分叉。我们 `EnemyReturnsAttack` 目前没有 `isAttacker` 形参（假定 attacker 视角）⇒ 今天等价，**记一笔**：将来接 `RecordAttackPendingDamage` / `ToggleCombatPreviewHighlight` 那两个非施法者视角调用点时要补 `isAttacker` 闸。
2. **`terror` 原版要求 `cardType==0`（Minion）**（`.c:14` `get_cardType(param_2)==0`），我们写成 `!target.IsWarlord`。棋盘上非督军恒 Minion ⇒ 静息态等价；但「Hero 非督军」这种卡若上棋盘（池内无）会分叉 —— 记录，非缺陷。
3. **`RemoveExtrinsicBySource`（`Aura.cs:1046`）不判 `IsInPlay`**：原版棋盘那一趟是 `IsInPlay(card)` 才摘；我们遍历非空格。因为我们的「死亡」是搬出棋盘进 `DeadUnits`，非空格即「在场」⇒ 静息态等价；**残骸（`IsRemnant`）留在棋盘上时原版 `IsInPlay` 可能为假** ⇒ 边界记一笔（未实测）。
4. 🔴 **`HasDiedSinceLastTurn` 的 `.c` 与判据列口径冲突**（值得单派 VA 级）：
   `CardScript__HasDiedSinceLastTurn.c` 是 `iVar1 == iVar4 || iVar1 + 1 == iVar4`（`iVar1` = 卡 `+0x250` 回合数，`iVar4` = 死亡回合 `+0x3f8`），即 **`diedTurn == cur || diedTurn == cur + 1`**；
