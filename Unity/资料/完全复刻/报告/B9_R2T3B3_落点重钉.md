## ④ 顺手发现

1. **「落点失效」的主因是账没跟上实现，不是没做**：旧落点集中指向 `LiveOpsLocalCatalog`（旧本地表），而 `LiveOpsHandler.cs`（10-26 00:15）/`LiveOpsEvent.cs`/`LiveOpsFilter.cs`（10-26 22:31）已经把真身建好。同类「先建实现、后补账」的欠账在其他域可能也存在 —— 建议下一次按「同名方法搜索」批量筛，而不是逐条看旧落点。
2. **判据表的结论会过期**：本轮至少 6 条结论（GetID/GetState/IsActive/Initialize/SetupEvents/DeserializeSharedData）写着「缺/读不出」，而真身已经补上并坐实。⇒ 这些行**可以再核升 A**（建议与 `判据/B行逐条核_日常.tsv` 的维护者同步）。
3. **行号漂移确认**：`MainMenuRuntime` 2348→2356 · `AllianceMemberTab` 273→281 · `ProfileTab` 661→662（+1）等。
4. **自动化小坑**：一行式方法（`int FirstDeckInMode(int prefer) { return … }`）不会被「声明行以 `(` 结尾」的正则收进索引 —— 这类方法要按方法名再 grep 一次。
5. **7 条 `GetLabel/GetAssetReference` 类**只能指到 **primitive + 组合**（`TryGetLabel(:200)` + `FillArgs(:1014)` / `FindAsset(:235)`），因为原版的「一次按键取词条并格式化」在我们这边被拆成两件；落点写了主件并注明组合关系。
