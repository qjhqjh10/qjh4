## §1 判据（先定「接到哪、怎么对」，再动手）

**原版这一路到底做了什么**（`decomp_full/GraphicsTab__CardsTextInHandDropdownChange.c:1-45` **全文现读**）：


🔴 **它本体不重刷卡面**。真正的消费者是 `BasicCardUI__SetCardTextInHand.c`：**每次卡进手牌**时
`ToggleSimplifiedView(on = 1, option = GameStaticData.cardsTextInHandFormat)` ⇒ 玩家在设置页改完，
**下一次**那张卡进手牌就按新档画。

**我们这边的三个等价物**（判据都在代码里写死了）：

| 原版 | 我们 | 位置 |
|---|---|---|
| `cardsTextInHandFormat`(+0x140) 的**存档那一半** | `SettingsWindow.TextInHand.Value`（`PlayerPrefs["CardsTextInHand"]`，0..2） | `Shell/SettingsWindow.cs:3999` |
| `cardsTextInHandFormat` 的**被消费那一半** | `CardView.HandTextFormat`（`SetHandTextFormat` 是唯一写口，内部 `RefreshAllHandTextStates`） | `Core/CardView.cs:5105` / `:5118` |
| `…ChosenManually`(+0x144) | **我们没有这一位** | — |

**值域对照**（决定「要不要映射」）：`CardTextsInHandOptions` = `Default 0 / OnlyDescription 1 / OnlyName 2`
（`d:/2/Warpforge_code/.../CardTextsInHandOptions.cs`）；`CardView.HandTextFormat` 的 doc 与
`SetHandTextFormat` 的越界闸写的**就是同一组 0/1/2**（`Core/CardView.cs:5105-5127`）⇒ **一一对应、⛔ 不需要也不许做映射**。
⇒ **值域对得上，任务可以做**（没触发「对不上就停手」那条）。
