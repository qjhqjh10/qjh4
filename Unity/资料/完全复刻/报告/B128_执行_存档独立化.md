## 三、自检怎么注入

```csharp
string tmp = Path.Combine(Path.GetTempPath(), "wf_b128_" + Guid.NewGuid().ToString("N"));
string keep = SaveRoot.Override;
try { SaveRoot.Override = tmp; /* …各存档的 OverrideDir/OverridePath 照旧由各断言自己设… */ }
finally { SaveRoot.Override = keep; /* 或 null */ }
```
- `SaveRoot.Override` 只影响 **没有自己 Override 字段**的调用方；各存档类的 `OverrideDir` / `OverridePath` **仍然优先**。
- ⚠️ `SaveRoot.Override` 是**进程级静态**：自检用完必须还原成 `null`，否则同宿主里后面的断言会一起写到临时目录。
- ⚠️ 想验「C 盘不可写 ⇒ 回落」**必须让 `Override` 保持 `null`**（注入了 `Override` 就不会回落，只报「注入的目录不可写」）。
