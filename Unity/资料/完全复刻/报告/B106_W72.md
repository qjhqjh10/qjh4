## ① 结论

**根因确认**：`B106_W14` 把「已拥有」实现成 `OwnedOf > 0` 且对**所有商品**生效；原版那个布尔**只在 catalog 族的 `item is CosmeticItem` 时才算**。卡包（消耗品）因此被误判成「已拥有」⇒ 8 条失败（D1/D2 + E1~E6）一条根因。

**改法**：`IsOwnedCell` 按**两族**分别判（下面 §②-1 有判据）：
- **catalog 族**（第 0~3 页，`CatalogItemContainer`）= `Owned > 0 && Type == "Cosmetic"`；
- **offer 族**（第 4 页 Crates/Boosters，`ShopOfferContainer` → `PriceDisplayButton.Setup(IShopOffer)`）= `Owned > 0`，**不分类型**。

⚠️ **与施工单的一处有意偏离**：施工单写的是「`:1517` 改成 `o[idx].Type == "Cosmetic" && OwnedOf > 0`」（= 不分族、一律只认外观件）。若照字面做，**第 4 页的 `Open ({n})` 那一档会整条死掉**（`OpenOwnedOffer` 变零调用、`Editor/ShopScene.cs:2016-2039` 的 §② 会红），而 `B106_D2` §二 明写「② 不用改（`IsOfferFamily` 未动）」。判据（现读反编译）站在「分族」这边：

- `d:/2/tools/cpp2il/out_cpp2il_dev_ilspy/CatalogItemContainer.cs:206-257`
  `if (item is CosmeticItem) { … } else obj8 = 0;` → `if (… && obj8 == null) interactable = …; else interactable = false;` → `obj8 == null ? Setup(offer) : Setup(Loc("MenuShop/Owned"))`。
- `d:/2/tools/cpp2il/out_cpp2il_dev_ilspy/PriceDisplayButton.cs:52-101`（这是 **`ShopOfferContainer`** 即 Crates 页那一族用的价签钮）
  `if (ownedCount > 0) { Interactable = true; priceDisplay.Setup(Format(Loc("MenuShop/ShopContainer/OpenButton"), owned)); return; }` —— **没有任何类型判断**。
- `ShopOfferContainer.Refresh`（同文件 `:150-210`）对每一件都 `priceDisplayButton.Setup((IShopOffer)…)`，即整页走上面那一条。

⇒ **照字面改会造出原版没有的行为**（`Open ({n})` 消失），按「判据与施工单冲突以 `.c`/IL 为准」处理（CLAUDE.md §三 2026-10-27 那条）。
