## 五·b 重复计数修复（调度台 `E14` 现读抓到 · 2026-11-04 当天修）

**问题**：`B141_W53_Assert` 的 `_sink` 是 **`static readonly`**，**三个 `Run` 重载都不重置**（文件内 `Run()` / `Run(DeckRuntime)` / `Run(CollectionWindow)` 三段只往同一个 sink 累加）。
原写法「两次调用后各读一次 `Pass`/`Fail`」⇒ 第二次读到的是 **A–D+G+E 的累计值** ⇒ **A–D+G 被计两遍**，宿主通过数虚高。

**改前（`DeckScene.cs:5557` 同一物理行）**：
```
B141_W53_Assert.Run(); _sink.Pass += B141_W53_Assert.Pass; _sink.Fail += B141_W53_Assert.Fail;
B141_W53_Assert.Run(_rt); _sink.Pass += B141_W53_Assert.Pass; _sink.Fail += B141_W53_Assert.Fail;
```

**改后（同一物理行、行数零变化）**：
```
B141_W53_Assert.Run(); _sink.Pass += B141_W53_Assert.Pass; _sink.Fail += B141_W53_Assert.Fail;
int w53p0 = B141_W53_Assert.Pass, w53f0 = B141_W53_Assert.Fail;
B141_W53_Assert.Run(_rt);
_sink.Pass += B141_W53_Assert.Pass - w53p0; _sink.Fail += B141_W53_Assert.Fail - w53f0;
```

**为什么这样改**：Δ 法只把「第二次调用新增的量（= E 组）」加进宿主；第一段仍是绝对量（首次调用前 sink 恒 0）。
⛔ 不动断言文件本体（断言作者的分段设计是对的），也不改 `DeckScene.cs` 行数（仍 **10,585** 行）。
