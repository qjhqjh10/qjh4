## §五 ⚠️ 挂载未落地 —— 可粘贴代码（`WarpforgeArena1/Editor/ArenaBuilder.cs`，X1 名下）

**① 在 `ArenaBuilder` 类里加这个方法**（建议放在 `AttachOriginalMaterial` 附近）：

```csharp
    /// <summary>🆕 2026-10-29（第九十四会话 · 代理 W2）：给地块挂原版 `MaterialChangerByQuality`
    /// （判据 = `资料/完全复刻/判据/B94_R-G_画质档位映射.md` §4.1；报告 = `资料/完全复刻/报告/B94_W2.md`）。
    /// 只对表里点名的 (场景名, 原版 GO 名) 生效；表外一律不动。</summary>
    static void AttachMaterialChangerByQuality(Renderer r, string sceneName)
    {
        if (r == null) return;
        var mr = r as MeshRenderer;
        if (mr == null) return;                      // 原版 5 个实例都挂 MeshRenderer（Initialize 里 GetComponent<MeshRenderer> 只取自身）
        if (!CardPresentation.MaterialChangerByQuality.ArenaPresetTable.AttachForArena(mr, sceneName, r.name)) return;
        // 原版序列化 `priority = 2 (InitializationPriority.UI)`；基类那格是 private 的 [SerializeField]、本仓没有 setter
        var c = mr.GetComponent<CardPresentation.MaterialChangerByQuality>();
        var so = new UnityEditor.SerializedObject(c);
        var p = so.FindProperty("priority");
        if (p != null) { p.intValue = (int)CardPresentation.InitializationPriority.UI; so.ApplyModifiedPropertiesWithoutUndo(); }
        Debug.Log($"[Arena/MCQ] `{r.name}`（{sceneName}）挂上了 `MaterialChangerByQuality`（原版 5 个实例之一）");
    }
```

**② 调用点**：插在 `ArenaBuilder.AttachOriginalMaterial(...)` 的**第一段之后**（不受 `props == null` 那条早退影响）：

```csharp
        if (r == null || string.IsNullOrEmpty(shaderName)) return;
```
