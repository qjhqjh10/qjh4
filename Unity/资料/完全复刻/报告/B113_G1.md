## 二、项目级 colorSpace：**切不切**（这条转给用户定）

### 结论：**切（Gamma），但分两阶段执行；本批只做阶段一。**

**为什么该切（4 条硬理由）**
1. 原版就是 **Gamma**，本项目的目标是彻底复刻原版（`CLAUDE.md` §四；铁律 18·0「需要拍板的地方默认复刻原版」）。
2. 切换能**一次性消掉两整类欠账**：B-110（项目级）与 **B-115（38 条 sRGB 在 Gamma 下全部变 no-op、自动归零）**。
3. `WarpforgeShaderMap.UseOriginal` 的 **66 条 shader 走的是原版编译字节码** —— 那是在 Gamma 工程里编译的。今天它们跑在 Linear 管线里是「原版算式 + 非原版空间」，**这一块留在 Linear 怎么补都补不出来**。
4. 留在 Linear，原版那些 gamma 空间的混合公式（overlay / 阈值 / `2x-1`）只能逐个 shader 手工桥接；**每加一个原版 shader 就多一处要桥**，是长期负债（现在已经 13 份 / 32 处）。

**风险分级**

| 级别 | 面 | 具体 |
|---|---|---|
| 🔴 高 | 自建 shader 的「桥」 | 13 份 shader / 32 处 `LinearToSrgb()` 会变**二次编码** ⇒ 必须全删；另有 `WFUIGlowSdfNoise.shader:147` 的 `LinToGamma()` 手写常量要一起查 |
| 🔴 高 | 后处理 | `DefaultVolumeProfile` 29 个 overrides + 13 套逐场 `*_PostFx`（原版那套 = Bloom `threshold 1.15/intensity 5` + Vignette `0.297` + ColorLookup `contribution 1`）。**方向是变对**，但等于 13×3 个参数要重校 |
| 🔴 高 | 观感基线 | 卡面 / UI / 战场全部要重看；`资料/真Play待验清单.md` 与所有「并排比原版」的结论**作废** |
| 🟠 中 | 光照 | 方向光 + `unity_AmbientSky`；无烘焙光照（两边都没有 `LightingSettings`）⇒ 省掉最大的一块 |
| 🟠 中 | C# 手挑色号 | `new Color(...)` 的值是在 Linear 下挑的，机器找不出来 |
| 🟢 低 | 贴图 | 151 张 `sRGB=0` 不受影响；4,474 张颜色图「变对」 |
| 🟢 低 | 原版字节码 shader | 变对 |

**阶段划分**

| 阶段 | 内容 | 前置 | 验收 |
|---|---|---|---|
| **一（本批）** | 资产级：§一 的 13 条 `sRGBTexture → 0` + 压缩档提到 BC7/未压缩。**不动项目开关** | 无 | 跑受影响宿主；⚠️ 门槛在「`.meta` 不持久」—— 得先改 `EffectExporter` |
| **二（独立批次）** | ① `m_ActiveColorSpace: 1 → 0`；② 清 13 份 shader / 32 处 + 3 份手写 gamma 函数；③ 重跑 `EffectCompare` 全量 sweep；④ 重校 13 套 `*_PostFx` + `DefaultVolumeProfile`；⑤ 卡面/UI 整体重看 | 一次完整会话 + 能反复跑 Unity 的时间窗 | ① 全量 sweep `>0.30` 归零；② 四宿主截图差异逐条可解释；③ 真 Play 一轮 |
| **回滚** | `m_ActiveColorSpace` 一行可回，但 **shader 那 32 处必须一起回**（否则双重编码） | git 分支 | —— |
