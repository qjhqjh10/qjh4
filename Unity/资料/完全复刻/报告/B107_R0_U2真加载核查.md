## §2 判法（本探针的静态规则）

- **代码语料**：`MyGame/Assets/**/*.cs`，排除目录名 `Editor`（大小写不敏感）与 `#if UNITY_EDITOR` 段（去注释后按预处理器栈剔行）。
- **L1**：在代码里搜「该名字（或路径 basename）作为字符串字面量」，并要求该字面量所在行是加载调用（`Resources.Load/LoadAll` · `.LoadAsset/LoadAllAsset(s)` · `Addressables.LoadAsset*` · `.url =`），或该字面量是**包装口**的实参（包装口 = 以形参直调上述 API 的方法，如 `CardArt.Get`；自动识别 + 一层传递）。

- **U**：代码里没有同名字面量、也没有整值表命中，但仓里有动态加载口 ⇒ 静态无法判定（账的 U2 是**子串**命中，可能就是这样来的）。
- ⚠️ **已知局限**（也是「没查清」的部分）：① 只做**单行**实参解析（跨行调用记为无法解析 → U）；② 常量折叠只认同文件 `const/static string`；③ L2 是**字段名级**证据（`Load(x.clip)` 里的 `clip`），没有逐条做完整数据流；④ `#if` 处理是**简化栈**（`#elif` 只按文本含 `UNITY_EDITOR` 判）；⑤ **经 SO 注册表按名字取资产**（`WarpforgeEffectLibrary.TryGet(name)`）**不算加载 API** ⇒ 这类名字落 L3（资产其实被直接引用使用，只是没走 `Resources.Load`）；⑥ 子串/文本行命中按**大小写不敏感**（与账的 U2 同口径）。
