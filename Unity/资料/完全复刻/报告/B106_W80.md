## ③ 落点顺序与理由（照调度台裁定）

`:45243` 内的实际顺序：

```
… RunR13();
  B104_T21_Assert.RunEngine(driver.Ctx);
  B104_T21_Assert.RunPresentation(driver);
  pass += B104_T21_Assert.Pass; fail += B104_T21_Assert.Fail;
  B105_W2_Assert.RunPresentation(driver);
  pass += B105_W2_Assert.Pass; fail += B105_W2_Assert.Fail;
  CheckManaBuffHud(driver, Check, ...);
  driver.DetachStaticHooks();

```

- **`CheckManaBuffHud` 必须最后一个**：它自己 `driver.Begin(...)` 重开一局，会把前面的现场冲掉。
- **必须全部在 `DetachStaticHooks()` 之前**：`Begin` 会重挂静态钩子，排在 Detach 之后会让紧随的 `StaticHookCount == 0` 连带红。
- **`B105_W2_Assert.RunPresentation` 排在 `CheckManaBuffHud` 之前安全**：它确实会从引擎手牌真摘一张（`driver.Ctx.Players[me].Hand.RemoveAt`），但在 `finally` 里 `RefreshAll()` 复原（实测 `B105_W2_Assert.cs:228-260`），且随后 `CheckManaBuffHud` 就 `Begin` 新局。
- **`B104_T21_Assert.RunPresentation/RunEngine` 与 `B105_W2_Assert.RunEngine()` 互不依赖**：前者只读 `driver` 的手牌视图 / `CardView.EffectAnchor`，后者用自建 `NewCtx()`；三者的 `pass/fail` 各自累加。
- **`B105_W2_Assert.RunEngine()`（无 driver 参数）留在 `:46873`** 不变——它不碰 driver，静默跳过问题与它无关。
