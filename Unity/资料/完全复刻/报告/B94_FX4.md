### 2.2 为什么用 `CardDef.OathOps` 就是 DG1 说的那条判据

DG1 的原话是「`inst.Card.Desc` 解析后若存在 `op.Cost > 0 && EffectText.CostKindOf(op.CostKind) == "oath"`」。
`CardDef.OathOps` 正是这句话的**预解析版**（`CardDef.cs:4611` 的 `CollectOathOps`）：

```csharp
if (op.Cost <= 0) continue;
if (EffectText.CostKindOf(op.CostKind) != "oath") continue;
_oathOps.Add(op);
```

- 它在**每张 `CardDef` 构造时**跑（`CardDef.cs:3782`，卡牌构建流水线里，不分单位/战术）⇒ 现读就是权威集合。
- 省掉每次出牌再 `Parse` 一遍（DG1 也点了这个优化）。
- 平版那一支是把**运行期 ops** 摘组（`EffectResolver.WithoutOathPaidGroup`，`:17824`，判据同样是 `op.Cost > 0 && CostKindOf == "oath"`），
  而 `OathOps` 是**静态**的 ⇒ **平版 / 誓约版都会命中这道闸**（这正是要的：平版本来就不该再多扣）。
