## 二、方法（可复跑）

1. **资产参数**：`工具/vfx_param_audit.py --check`（只算不写；978 prefab / 14,007 PS / 全模块逐字段；默认值归一、
   同名兄弟按内容配对）。本会话实跑 = **rc 0 / 0 真差异**。
2. **数值抽样复核**（独立于闸，防「闸坏了还绿」）：自写两个只读提取器，分别读
   - 我们：`Assets/WarpforgeVFX/Prefabs/<名>.prefab` 的 `!u!198` / `!u!199` YAML；
   - 原版：`assets_full/.../ParticleSystem_<pathID>.json` 的 `InitialModule` / `EmissionModule` / `ShapeModule` /
     `ColorModule` / `SizeModule` / `SubModule` / `TrailModule` + `ParticleSystemRenderer_*.json`；
   对 **AttackHitSmall / Card 3D Death Explosion / Necrons death explosion / ArmourEffect / Healing_Circles /
   Aura_WhileInPlay_1 / DutyEffect / FlyingEffect / StunEffect / BulletImpact_2shot_trail / Invoke Minion Card Fade Default**
   逐字段比，**全部逐值相等**（下表给数）。
3. **结构/引用**（本轮新增，闸不覆盖）：
   - **子件次序**：967 个 prefab 的每一层「有序子件名列表」原版 vs 我们 **0 处不同**
     （`0` 处同名乱序、`0` 处名字集合不同）⇒ `@node:…/Name#N` 的下标语义与原版同源。
   - **模块节点引用**：`animfx_modules.json` 共 **3,123 条** `@node:`；**3,099 条**解析到带正确组件的节点；
     余 **24 条**是 `AnimFXController.modules[i]` / `collisionEvent.m_Target`（指向**运行时才存在**的模块组件，
     同效的模块条目本身都在数据里且解析成功）⇒ 不是丢件。
   - **extras 节点**：164 个挂载节点 **0 个解析失败**。
4. **程序化粒子**：`CardView.BuildCanAct` 手写的 `CanActParticles` / `RotatingRing` 与
   `assets_full/.../GameObject/CanActParticles.json` + `RotatingRing.json` 逐字段比（见 §三·11/12）。

## 六、顺手发现（⛔ 我没改，交调度台分流）

1. **`ParticleEmitOnEnable` 有两份实现**：`CardPresentation/Core/ParticleEmitOnEnable.cs`（被 `CardView.cs:6881` 手挂）
   与 `WarpforgeVFX/Runtime/WFExtraParticleEmitOnEnable.cs`（被 `WFEffectExtras.AttachAll` 按数据挂）。
   两者语义相同（`if (!ps.isPlaying) ps.Play()`），但同一节点会挂两个组件。建议收口到一份（铁律「两处写同一条规则 = 迟早不一致」）。
2. **`effect_extras.json` 的生成器缺 `m_Enabled` 字段**（F4 的根因），且**不记录 `particlesSystems`/`subEmitterIndexes` 数组**
   （F2/F3 的根因）。补这三个字段即可整批按原版还原，不必逐个手改。
3. **战场环境件不走 `WarpforgeEffectPlayer`**（`Battle/EnvironmentApplier.cs:170` 直接 `Instantiate`）⇒ `effect_extras`
   里的 `SyncParticleSeeds`(环境件)、`ShakeAndSoundObject`(35)、`MaterialFlickerEffect`(环境件) **一个都不会被挂**。
   这属战场环境审计的盘子，但与本轮的 extras 机制是同一处断口，先记账。
4. **`WFModuleCollisions` 仍未还原 `m_CallState`**（原版 563 条全是 2，我们一律当「会响」）—— 文件头已自认，本轮复核仍成立。
