## 三、关键机制（用户重点）

### 3.1 窗口模式与分辨率

**结论：设置窗里【没有分辨率列表】**（既不是 `Screen.resolutions`，也不是固定表）。

判据：
- 全量反编译里 `Screen.resolutions` / `Screen__get_resolutions` **0 命中**（`d:/2/tools/decomp_full/` 与 `d:/2/tools/cpp2il/out_cpp2il_dev_ilspy/` 均搜过）。
- `GraphicsTab` 的 9 个序列化字段里**没有**分辨率控件（`GraphicsTab.cs:13-29`）；`MediaTab` 只有 `windowModeDropdown`（2 项：全屏 / 窗口化，`MediaTab.cs:70-129`）。
- `Screen.SetResolution` 全工程唯一调用点是 `ResolutionManager.SetFullScreen`（`ResolutionManager.cs:25-39`）。

**窗口模式的实际行为**：

| 选择 | 调用 | 结果 |
|---|---|---|
| Fullscreen（option 0） | `Screen.SetResolution(Screen.currentResolution.width, Screen.currentResolution.height, true)` | 按**当前显示器分辨率**全屏（不是某个固定列表项） |
| Windowed（option 1） | `Screen.fullScreen = false` | 退出全屏、保留当前宽高；之后可被 OS 拖拽改大小（`ResolutionManager.Update` 每秒检测 `Screen.width/height` 变化并发 `ScreenResolutionChangeSignal`，`ResolutionManager.cs:41-69`） |

- `ResolutionManager` 是 `Intro.unity` 里的常驻 `SingletonBehaviour`（脚本 guid `418e420d…`，场景内 1 份）⇒ **不依赖 Steam / 服务端，离线可用**。
- ❗ `MediaTab.OnWindowModeChanged` **只调 `SetFullScreen`，不写 `GameStaticData.noFullScreen`**；而下拉框显示值读的正是 `GameStaticData.noFullScreen`（`MediaTab.cs:126-128`）。全仓写到 `GameStaticData+0xED`（`noFullScreen`）的地方只有 **cctor 默认 false 与 `LoadPlayerData`**（grep `+ 0xed) =` ⇒ `GameStaticData__.cctor.c:194`、`PlayerDataManager__LoadPlayerData.c:71`）。
- ⇒ **具体缺陷见 §四 D1/D2**。

### 3.2 画质档如何生效

`QualitySettingsManager.ApplyGraphicsQuality`（`QualitySettingsManager.cs:267-330`）逐项：
`GraphicsSettings.defaultRenderPipeline = 该档 URP Asset` → `QualitySettings.SetQualityLevel(qualityNumber)` → `ChangeResolution()`（只改 `renderScale`）→ `Shader.Enable/DisableKeyword("SUPERSAMPLING_ON")` → 若该档不允许超采样则 `useSuperSampling=false` → `QualitySettings.vSyncCount` → `PlayerDataManager.ApplyGraphicsQuality()`（= 重新设 `Application.targetFrameRate`）。
只在 **设置窗关闭时**跑（由 `ApplyGraphicsChangesOnClose` 闸住，`SettingsMenu.cs:177-182`）。

### 3.3 帧率与垂直同步

- `FPSLimit` 三档 0/1/2 = 30 / 60 / 不限；应用点在 `PlayerDataManager.SavePlayerData` 末尾与 `ApplyGraphicsQuality`，均写 `Application.targetFrameRate`。
- `vSyncCount = vsync ? 1 : 0`（`QualitySettingsManager.cs:308-310`）。
- 注意：`vsync=1` 时 Unity 以刷新率为准，`targetFrameRate` 可能被压制；两者同时开时以 vSync 为主。

### 3.4 音量

音乐/音效/语音都写 `AudioMixer.SetFloat("Volume" + MixerType 名, dB)`（`SoundManager.cs:569-590`）：`VolumeMusic` / `VolumeFX` / `VolumeJingles` / `VolumeVoices`；`volume == 0` → -80dB，否则 `log10(volume) * 20`。
音乐额外写 `PlayerPrefs["MusicVolume"]`，并由 `MusicVolumePlayerPrefsSetting.Start` 读回乘到某个 AudioSource 上（`MusicVolumePlayerPrefsSetting.cs:5-14`）。

### 3.5 语言

- 可选语言 = `GameStaticData.languagesDefinition`（13 个：English / Spanish / Russian / French / German / Portuguese (Brazil) / Italian / Korean / Simplified Chinese / Japanese / Turkish / Polish / Czech，`GameStaticData.cs:2443-2474`）。
- 下拉显示名 = I2 词条 `MainMenu/Settings/LanguageName/<语言名>`（`LanguageSelector.cs:85-93`），本地化表 13/13 都有。
- 切换 = `LocalizationManager.CurrentLanguage`，I2 记住在 PlayerPrefs「I2 Language」；启动时 `SelectStartupLanguage` 读它（`LocalizationManager.cs:733`）⇒ **持久化正常**。

## 五、对离线使用 / 自动化测试最有用的项（3 项 + 备选）

1. **窗口模式（媒体 → Window Mode）** —— 立即切窗口化（`Screen.fullScreen=false`），便于截图/录屏/多窗口对照。
   ⚠️ 不持久（D1/D2）。**更稳的做法 = 启动参数**（Unity Standalone 原生支持，游戏启动时不覆盖）：
   ```
   start "" "E:\warpforge\game\Warpforge.exe" -screen-fullscreen 0 -screen-width 1600 -screen-height 900
   ```
   现有 `start_offline.bat` 最后一行是 `start "" "E:\warpforge\game\Warpforge.exe"`（无参数），
   `WarpforgeOffline.exe` 的 `Launcher.cs` 也没有透传参数（`_build/Launcher.cs:45-57`）⇒ **要固定窗口尺寸：复制一份 bat，在启动行后面加参数**（环境变量那几行保留）。
   加 `-popupwindow` 可去边框；`-monitor N` 可指定屏。
2. **FPS Limit（图形 → FPS Limit）** —— 30 / 60 / 不限三档，关窗后落盘（`LocalPlayerData.fpsLimit`），重启仍生效；自动化测试固定 30 可降低渲染波动、稳定截图。映射：0→30、1→60、2→不限。
3. **画质档（图形 → Quality）** —— VeryLow/Low 直接换 URP Asset 并关卡牌 AA，明显降低 GPU 负担；关窗后落盘。PC 上**不会改窗口分辨率**（clamp 只对 mobile 生效）。

备选：语言切换（验证本地化/截图多语言）、音乐音量拉到 0（静音，避免录音干扰）、禁用机器人（如果想避免自动匹配出 bot）。
