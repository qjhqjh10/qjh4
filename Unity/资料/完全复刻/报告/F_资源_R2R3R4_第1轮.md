## ② 判据

### R3
1. 对 99 个 `AnimationClip` **逐个读导出后的 typetree**（不是读我们搬进工程的资产）。
2. 「有数据」= 下列任一非零：legacy/generic 曲线关键帧数、`m_StreamedClip.curveCount`、`m_DenseClip.m_SampleArray`、
   `m_ConstantClip.data`。
3. 「空壳风险」= 非 legacy + `m_MuscleClipSize > 0` + 上面四项全 0 —— **实测 0 条**。
4. 每条 clip 附**引用者**（R0 图，CAB 感知）。

### R2
1. 对 834 个 `Mesh` **读 typetree 原文**：`m_VertexData.m_VertexCount` / `m_DataSize` 长度 / `m_StreamData.size` /
   `m_CompressedMesh.m_Vertices.m_NumItems`。
2. 与 `assets_full/.../Mesh/<name>.obj` 的 `v ` 行数**逐个比**；`m_StreamData.size>0 且 m_DataSize==0` 记为流式。
3. 坏件**按 PathID 重新导出**（`R2_重建网格/<name>__<PathID>.obj`），并复核顶点数：
   `Spirt Stone` 748/748 · `Floor` 3577/1874/4749 · `CandleFlame_*` 10/74/19。

### R4
1. Shader 的**真名**在 `m_ParsedForm.m_Name`（`peek_name()` 对 Shader 恒为空 —— 所以 R0 台账里 Shader 是「无独立名字」）。
2. 「用上」= 引用者（Material / 场景 / GraphicsSettings）在 R0 台账里是「已用/已搬运」（继承，标注「经引用者」）。
3. Ruri 文件匹配 = 在 `ruri_out_*/ExportedProject/Assets/**/*.shader` 里找 `Shader "<真名>"` 声明；
   677 个文件 / 174 个唯一名；**0 个 Dummy**。
4. ComputeShader 的载荷不在 `m_CompiledShaders`（这个字段在本 build 不存在），而在 **`variants[] → kernels[] /
   constantBuffers[]`**；参数表就是从这儿读的。

## ⑥ 顺手发现

1. 🔴 **`sharedassets0.assets`（= `Assets/Resources/`）是卡牌数据的第二个入口**：8 个 `RawCardScript` +
   1 个 `AlternateArtCard` **只在这里**，任何卡牌 bundle 里都没有同名对象。我们之前「卡牌 bundle + allcards」
   那条路**结构上就搜不到它们**。
2. 🔴 **`AlternateArtCard #HB_GOF28`（`AA_HB_Goff_war_Ghazghkull Thraka`）在全工程零命中** ——
   异画线要核这一张是不是漏了。
3. **`UM_Forge_Badge`（AllianceBadge）全工程零命中**，另一个 `Default_Badge` 有（`AllianceTrophyModel.cs`）。
4. **`Ultramarines_war_Uriel Ventris_tutorial1`（`ec0d25fa…`）的 id 不在 `cards_engine.json`** ——
   其余 7 个 RawCardScript 的 id 都在。它只在 lore/ai 表里出现过 ⇒ 教学战专用卡，值得单列。
5. **24 个 ComputeShader = 16 个 VFX Graph 内核 + 8 个引擎件**，这个分母核清了（之前「23/24 没用上」的说法
   在**名字匹配**口径下成立，但它们其实是 3 个 VFX 资产的**运行时内核**，不是「没人用的死资源」）。
6. **Ruri 已经把 422 个 shader 反编译好了**（`d:/2/tools/ruri_out_1020_rootshaders`，0 Dummy），
   本轮把 **211/234 个 Shader 对象逐条对上号**；剩下 23 个的「为什么没有」也逐条写清了（7 空 blob + 16 内置）。
7. **23 个 Mesh 被同名覆盖**（`Cone.001~004` / `Cylinder` / `Spirt Stone` / `RockDebris_Low` / `Background Sky` /
   `Sphere`×2 / `Floor`×3）—— 这是 `fix_exports.py` 的「同包同名后写覆盖先写」口径，**不是新的数据丢失**，
   按 PathID 重导即可（已做）。
8. **`CandleFlame_*` 是「只有顶点、没有三角形」的粒子 billboard** —— 原版就是这样，UnityPy 的 `MeshExporter`
   对它抛 `AssertionError`。以后遇到「OBJ 没导出」先看 `indexCount` 是不是 0。
