### 1.2 `MapTriggerOpsByNumber` 的五步（口径 → 文件头 §二/§三，⛔ 此处不重复长注释）

1. **列未知**（`TriggerAbilityIndices == null`，旧表 < v42 / 夹具直建）⇒ 返 `null` = **不挂** ⇒ 保留退回档。
2. **列明确为空**（`[]`，原版**没有** ability 行）⇒ 返**空表** = 挂上（「这张卡的触发数值没有正文」是已知事实）。
3. **op 全集**：遍历 `CardDef.RoutableTriggers` 逐个 `def.TriggerOps(kw)`（`_triggerOps` 是私有的、没有整表公开口
   —— 这条走法与 `RuleCore.ActiveAbilityBodyOps`（`RuleCore.cs:15579`）**同一份**，⛔ 没有在 `Core/` 另开口子）。
   拿到的是**同一批 op 对象**（⛔ 不克隆；克隆会让表与正文两处不同源）。
4. **逐行归位**：`(ab, lg, trigger)` 行 →
   · `trigger < 0` / `ab < 0` ⇒ 跳过（出声计数）；
   · `lg == -1`（该 ability **没有任何 logic 行**，原版 `TriggerAbilities` 拿到它是空循环）⇒ 跳过；
   · 否则取 `op.AbilityIndex == ab` 的那些 op，按 `trigger` 分桶；同一 `(ab, trigger)` 的多条 logic 行
     **只算一次**（`HashSet<EffectOp>` 按对象引用去重 —— 原版 `trigger` 是 **ability 级**字段）。
5. **挂不挂**：桶全空 ⇒ 返 `null`（**不挂**，保留退回档，计进「归位失败」）；否则清掉空桶后挂上。

## 二 跳过统计（口径 + 静态估算 + 权威读数口）

### 2.1 🔴 覆盖为什么天然低（**这是本条唯一的真风险，R6 §三 Step 0 已点名**）

我们的正文是**文本 parse**，`AbilityIndex` 由 `EffectText.AssignAbilityIndices`（`EffectText.cs:1723`）
**带闸门推断**出来：`_triggerOps` 里的 op 绝大多数来自**片段解析**（`AddTriggerOp` / `CollectBareKeywordBody`
逐段 `EffectText.Parse(body, card: this)`；只有「整条 `desc` 就是那一段」时 `IsWholeDesc` 才走整条分支，
而那时块数必为 1 ⇒ 同样只出 `AbilityIndex = 0`），片段那条路要归位必须**同时**满足
`maxAb == 0`（该卡所有 `ab>=0` 的条件行都在 ability 0）**且** `CountAbilityBlocks(card.Desc) == 1`
（`EffectText.cs:1793-1800`）⇒ 否则 `AbilityIndex` 一律留 `-1`。

⇒ **`AbilityIndex` 只会是 0 或 -1**（片段路径 `AssignBlockIndicesOnly` 里只写 `= 0`）。
这直接决定了：**任何 `ab > 0` 的行永远归不了位**。现池实测：

| 测什么 | 张数 / 行数 |
|---|---:|
| 池内卡数（`cards_engine.json` v43 `count`） | **1129** |
| `triggerAbilityIndices` 列未知 | **0** |
| `triggerAbilityIndices == []` | **119** |
| 有行、但**一条 `ab>=0` 的条件行都没有**（`unitConditions` 里全是 `ab<0` 或整列为空 ⇒ `AssignAbilityIndices` 第一句就 `return`） | **787** |
| 有行、条件行 `maxAb > 0` / `maxAbOther > 0`（片段路径必 gap） | **83** |
| ✅ 满足 `maxAb == 0`（可归位） | **140**（上界） |
| ↳ 其中再被 `CountAbilityBlocks(Desc) == 1` 卡掉（多能力块） | **≈18** |
| ✅ **估算最终能挂上非空表** | **≈122 / 1129（10.8%）** |

⚠️ **后两行是静态估算**：`CountAbilityBlocks` 用的是 `EffectText.SegmentStartsAnotherAbility` 的正则不精确复刻
（正则近似 + 我自己那份 `IsRoutableTrigger` 词集），**最终数以运行期读数为准**。
