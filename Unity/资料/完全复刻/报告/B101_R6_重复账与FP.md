## 一、规范化算法（任务①）

### 1.1 做了什么

对 21 份账主表逐行取 `原版类` + `方法` 两列，按下列步骤算「规范化签名」，同签名的行归一组：

| 步 | 处理 | 例 |
|---|---|---|
| 1 | 类名：**反复剥掉成对的 `<…>`**（含嵌套） | `CollectionDisplay<T>` → `CollectionDisplay`；`<>f__AnonymousType75<<DeckId>j__TPar, <GameMode>j__TPar>` → `f__AnonymousType75` |
| 2 | 方法列若带 `类.` 前缀且前缀基名 == 类名 ⇒ 剥掉前缀 | `ItemDrawer<T>.Awake()` + 类 `ItemDrawer` → `Awake()` |
| 3 | 方法列尾部 `→ 返回类型` 单独取出并**保留进键** | `op_Implicit(…) → T` 与 `→ string` 分属两键 |
| 4 | 参数：按**顶层逗号**切（尊重 `<> () [] {}`） | `Dictionary<RawCardScript, int> deckLibrary` 不拆 |
| 5 | 每个参数：剥 `[特性]` / `params out ref in this` → 去掉顶层 `= 默认值` → 顶层空白切词，**丢最后一个词（参数名）留类型** | `bool option = false` → `bool`；`out T returnItem` → `out T` |
| 6 | 类型去全部空白 | `Dictionary<A, B>` → `Dictionary<A,B>` |
| 7 | 键 = `类.方法(参数类型序列)` | `ChallengeLogMgr.LogHeal(BattleAction)` |

### 1.2 边界 / 判断口径

- **规范化键相同 ≠ 一定重复**。脚本对每一组再做一次**回原版核对**：用 `d:/2/Warpforge_code/Scripts/Assembly-CSharp/` 的 2,294 份签名桩建索引
  （`(类型名, 泛型元数) → (方法名, 泛型元数) → 参数类型序列集合`），把每一行**反查回唯一的原版方法**；
  两行反查到**同一个原版方法**才算「真重复」，反查到**两个不同方法**就是「重载/两个类（非重复）」。
- **同一类型同时存在非泛型与泛型两版时**（如 `ItemDrawer` 与 `ItemDrawer<T>`、`Draggable` 与 `Draggable<T>`、`DynamicList` 与 `DynamicList<T>`），
  两边**各有一份实现** ⇒ 分别记账**不算重复**；`收藏.tsv:263/264` 那种「同一类列里写两种类名」的 3 行组判成 **部分重复**。
- **方法本身是泛型方法**时（`MarkUpload<T>()` vs `MarkUpload()`；`GetOnlineData<T>` vs `GetOnlineData`；`New<T>` vs `New`；`Refresh<T>` vs `Refresh`），
  原版**两个重载都存在** ⇒ 判 **非重复**；原版只有一个时判 **真重复（泛型标记写错）**。
- **返回类型**保留在键里：两个 `op_Implicit` 是 C# 语义上的两组运算符，**不参与去重**。
- **非签名行**（`（数据模型 record：9 个编译器样板方法）` 等 15 行）不参与分组。

### 1.3 已知的算法局限（⛔ 别当成「这里没问题」）

- 账里 / FP 里若把**类名写成了完全不同的名字**（不是泛型元数差异），不会归到一组，也就不会被本普查发现。
- 原版**签名桩只到「参数类型」层**，不区分 `int` 与 `Int32` 之别以外的命名空间差异（我做了 `A.B.C → C` 的简写归一）；两侧写法若一边全限定一边简写，会被判成「参数类型拼写不完全一致（按方法名+参数个数匹配）」，这一类在 TSV 的 `依据` 列会写出来。
- 签名桩**不含编译器生成的 lambda/display class 方法体声明**（`_003C…_003Eb__NN_M()`）⇒ 这类只能用「逐字相同」判重复，无法用原版核对（本批 5 组都属这一类，逐字一致）。

### 6.1 改了什么（三处）

**① 无括号 `类.方法` 展开**（`expand_no_paren()`）

```python

    if k.startswith(prefix): ...

#             → ③ 仍不行才退到「同名类全族」（`ContainerBuilder<TCont>.*` 就是这一档）

if not got:
```
