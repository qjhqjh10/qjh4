- 所有相机的 `m_RendererIndex` 全是 **-1**（`= 用 RPAsset 的默认 index 0`）：`Battle.unity:1509/1758` 与 13 个 arena 场景各一处。

**⇒ 结论：同源。缺的第二个 renderer 就是 `D-1` 里那台 UI renderer 的资产槽位，不是另一个独立缺陷。**

3. **需要真机 A/B**：去掉抓屏 feature 后 HUD 相机的抓屏/tone 行为会变，得进游戏比。
