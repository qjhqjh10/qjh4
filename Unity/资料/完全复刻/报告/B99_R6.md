## 2. 判法（怎么判「体里算出返回值」）

### 2·1 「首行是 void」≠「值丢了」

Ghidra 在推断返回类型为 `void` 之后，把 `return <表达式>` 渲染成两种**等价**形态，值都还在：

| 形态 | `.c` 的样子 | 值在哪 |
|---|---|---|
| **A 尾调用转发**（占 95%+） | 由 `Foo(a,b,0);` 收尾，然后 `return;` | **值就在 `Foo` 的 RAX 里**，尾调用原样带回 |
| **B 出参 / 写内存** | `*(undefined4 *)(lVar3 + 0x20) = 0xf0;` · `local_res10[0] = 4 < ...` | 写进结构体字段 / 局部数组 |

实证（`AI__GetAiMulliganCards.c`，账 `战斗逻辑驱动:9` 声称「`manaCost(+0x78) > 4` ⇒ 换掉」）：

```c
if (*(int *)(lVar2 + 0x260) == 0x1e) { local_res10[0] = false; }               /* +0x260 == 30 ⇒ 保留 */
else { local_res10[0] = 4 < *(int *)(*(longlong *)(lVar2 + 0x28) + 0x78); }     /* 比较与常量 4 都在 */
```

⇒ 该账判据**完全可复核**。

### 2·2 什么才叫「真丢」—— 本轮硬标准

死代码消除只删**只服务于返回值的纯算术 / 浮点常量**；**带副作用的调用与分支控制流留下**。所以：

> **`.c` 里还剩下调用与控制流、却一点也不剩「算出来的数」（`*` `+` 浮点字面量），而 ILSpy 的 `return` 是个累加/乘出来的局部变量 ⇒ 需换源。**

同族三方法对照（最能说明）：

| 方法 | `.c` 有算式吗 | ILSpy `return` | 结论 |
|---|---|---|---|
| `AI.ScoreFromBuffedAttack` | **有**（`.c` 首行 `undefined4`，闸没降级） | `return num7;` | （不在本批） |
| `AI.ScoreFromAttack` | **无**：只剩 4 条调用，4 处 `+=` 全没 | `return num2;` | **真丢** |
| `AI.ScoreFromBuff` | **无**：只剩 if 链，**零浮点常量** | 16 个 `return <常量>` | **真丢** |

### 2·3 副产物：**常量当「实参」时不会丢**

浮点字面量只要**当实参传出去**就以 `DAT_xxxxxxxx` 留在 `.c` 里，可用 `工具/read_literal.py` 4B float 读回。
实证 `PrebuiltPackUI__CloseAnim.c`（账 `卡组编辑:293` 的 `DOFade(...,0.4)` / `DOScale(...,0.6,0.4)`）：
`DOFade(...,0,DAT_1834b3158,0)` · `DOScale(...,DAT_1834b3180,DAT_1834b3158,0)`。
⇒ **只看「首行 void」会误判一大批**。

### 2·4 每行做了三件事

① 逐份读 `.c` 体；② 在 ILSpy 按**方法名 + 形参个数**定位同名体；③ 比对「`.c` 剩下那条语句」与「ILSpy 的 `return` 表达式」是否同一东西。
⚠️ **ILSpy 目录含子目录**（`Everguild.LiveOps/` 等），第一版平铺扫漏了 6 个文件，已改递归。
