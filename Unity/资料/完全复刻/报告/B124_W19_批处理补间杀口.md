## 一、新增测试侧辅助 `Editor/B124_TweenTestUtil.cs`（+1 文件 / 159 行）

批处理里 `TweenExtensions.Kill` 的**第一句**就早退（`if (!DOTween.initialized || t == null || !t.active) return;`），而 `DOTween.Init` 只在 Play 模式跑 ⇒ `Kill`/`Complete` 全家静默空操作，但 `TweenManager.Update` 照推。
真杀 = `TweenManager.Despawn(t)`（派 `onKill` → `RemoveActiveTween` → 回收池 → `active=false; Reset()`），也正是 `Kill(false)` 在非 update-loop 时的末句 ⇒ 本辅助 = 「`Kill(false)` 去掉 `!initialized` 早退」，逐句对齐。

| API | 说明 |
|---|---|
| `KillInBatch(Tween, where)` | 反射调 `Despawn(t,true)`；返回 true = 真杀了。`!active` / 不在活表（已死或 Sequence 子补间）⇒ 返回 false（与 `Kill` 早退同义，**幂等**） |
| `SnapshotActive()` | 只读 `TweenManager._activeTweens` 活表快照 |
| `KillNewSince(snap, where)` / `KillNewSince(snap, dur, where)` | 只杀快照之后新起、且（可选）时长匹配的补间 |
| `Available` | 反射是否可用 |

**失败一律出声**：拿不到 `TweenManager` / `Despawn` / 调用抛异常 / 杀完仍 `active` ⇒ `Debug.LogError` 并返回 false，
⛔ 不静默返回 true。⛔ 不用 `KillAll`/`DespawnAll`（宿主里还有别人家的补间）。
装了 `.meta`（guid `adfc6d7e…`）；请在 `文件所有权_当前.md` 登记，后续写手可复用。
