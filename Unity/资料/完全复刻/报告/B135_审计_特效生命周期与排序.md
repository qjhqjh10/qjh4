## 五、最该先修的五条（按影响力排序）

1. **B5 父旋转被我们吃进去了**（🟠）
   原版：`Instantiate(prefab, anchor.position, **prefab.localRotation 当世界旋转**, anchor)` ⇒ 特效世界旋转 = prefab 自身旋转。
   我们：`Instantiate(prefab, parent)` ⇒ 世界旋转 = **父旋转 ×** prefab.localRotation。
   命中面：任何锚点/卡本体带旋转的播放 —— 手牌扇形（`EffectAnchorHand = 2DCard`）、攻击倾摆、AI 落位飞行中的斜置。
   修法口径：`Play` 里对需要这一档的调用传 `worldRotationStays: true`（实例化后写 `t.rotation = prefab.rotation`），
   **不要**全局改（`ObjAnimEffects.ResolveAnimPrefab` 那条旧路是另一种语义）。

2. **B8 `doParentRelation` 用父子替代了约束**（🟠 · 193/314 实例）
   原版锚点是 `targetCard.GetEffectAnchor()`（相对卡根 (0, 1.34, −0.128) = **10.5% 卡高**的偏移），机制是 `ParentConstraint`（层级不变、目标卡销毁后特效仍留在世界），缩放不继承。
   我们是 `SetParent(targetCard, true)`（初始位置相同，但**层级变、卡走跟着没**、卡旋转时绕的是卡根不是锚点）。
   修法：补一个 `ParentConstraint` 等价组件（或至少改用 `EffectAnchorBoard` 当父 + `worldPositionStays`），
   并把 `doParentRelation` 那 193 个实例的层级/生命周期一并复核。

3. **A7 `unParentAtStart` 与 `_ownerWatch` 冲突**（🟠 · 2 个效果）
   `Teleport Trait Summon` / `Teleport Trigger Effect Quick`：原版 `preventDestroy=1` + `unParentAtStart=1` ⇒ **永不销毁**（原版泄漏）。
   我们模块脱了父，`_ownerWatch` 还指着原父 ⇒ 卡离场就把它们收掉 ⇒ 与原版不一致。
   修法：模块 `SetParent(null)` 时同步把控制器的 ownerWatch 摘掉（`ClearOwner()`），并在两种效果上写断言。

4. **C5 `vfxDelayTime` 没消费**（🟠 · 当前零命中，但是机制缺口）
   原版 `DelayedVFXPlay` 先 `WaitForSeconds(vfxDelayTime)` 再建特效；我们 `at = t0 + acc` 不含 `vd`。
   现读我们消费的 158 拍 `vd` 全 0、源表 1102 条里只有 2 条 `0.4` ⇒ **今天不影响画面**，
   但一旦表里出现非 0，特效会**早出场**、位移泵也早 `vd` 秒。修法：`at = t0 + acc + vd`，
   同时把位移泵的 `m.t` 初值置 `-vd`（或 `ts` 加 `vd`）。

5. **A7/C7 两处「边角顺序」合并收口**（🟠 · 当前零命中）
   · `Tick` 里寿命判定先于 `TickSounds` ⇒ 寿命那一帧该响的音被吞（原版帧末销毁、音照响）；
   · 同族：`_ownerWatch` 收掉实例时也直接销毁，`exitSounds` 一律不响（与原版「父件消失」一致，无需改）。
   修法：把 `TickSounds()` 提到两条 `DestroyAtLifetime()` 判定**之前**；现读 0/937 命中 ⇒ 改动零风险。
