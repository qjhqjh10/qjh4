## 二、S3-G6 `WFCMP_ONLY`（`MyGame/Assets/WarpforgeArena1/Editor/EffectCompare.cs`）

### 语义

- 环境变量 `WFCMP_ONLY` = **逗号分隔的卡 id / 件名白名单**；对导出 `.prefab` **文件名做子串匹配、大小写不敏感**；
  命中**任一** token 才渲（照 `NameFilter` 同款 `.IndexOf(...OrdinalIgnoreCase) >= 0`）。
- 与 `WFCMP_SIMT` / `WFCMP_ISO` 同风格：运行期读环境变量、默认关。
- 代码注释写死：「**不设 = 全量，⛔ 别改成默认只渲一部分**」。

### 「不设时逐字节不变」的证明（结构论证 + 实读）

1. 未设时 `OnlyFilter = new string[0]`；
2. `if (OnlyFilter.Length > 0) { ... }` **整段不执行** ⇒ `exports` 列表与今天**同一集合、同一顺序**；
3. 日志那行只追加 `""`（三元表达式 false 分支）⇒ 日志文本不变；
4. 其余渲染路径（`FrameCamera` / `RenderOne` / 两趟遍历）**一行未动**。
   ⇒ 输出 PNG 文件名、像素、顺序、日志全部与今天一致。
- 落在 `NameFilter` 块之后（第 62 行后），**文档里引用的 `EffectCompare.cs:26-27 / :36 / :39 / :43` 全部不受影响**。
