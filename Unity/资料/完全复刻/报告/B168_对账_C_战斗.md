## 二 · OFF-39（最优先）· 输入链全景 + 施工单

### 2.1 结论先行

1. **「点选自己单位 → 点敌方」这套手势在原版不存在。** 点击场上单位 = 开卡牌大图（`DisplayCard`），这是**原版行为**，不是我们坏了。⇒ 任务表里「单点单位只开卡牌详情」这半句应当**判据订正**（⛔ 判据本身错），不是缺陷。
2. **唯一的玩家攻击手势 = 从自己场上单位「拖出去、在目标上松手」。**
3. **我们的两次拖拽都成功进入了攻击瞄准态**（有音效铁证），**失败点在「松手 → 提交」**。所以下一步不是「修输入」，是「量松手那一刻的落点与判定」。

## 四 · OFF-42 · 收藏「张牌」页首次填充延迟

### 4.1 结论

**「探针没触发」的原因查清了，而且它不是缺陷，是判据写错了。**

- 探针**挂对了**：`hooks_installed.tsv` 里 `collectionfill:CardCollectionTab.ToFocus  OK  Il2Cpp.CardCollectionTab.ToFocus() : Void`；`List<T>` 泛型、`Nullable<T>` 都不是问题（`ToFocus` 是 0 参实例方法）。
- **`ToFocus` 在这条路径上根本不会被调**：
  - 切页签 = `GameWindowWithTabs.ChangeTab(tab)` → `ChangeTabCO(from, to)` → `to.TryOpenTab()`（`GameWindowWithTabs.cs:363-390`）
  - `WindowTabBase.TryOpenTab()` = `gameObject.SetActive(true)` + `OnOpen()`（`WindowTabBase.cs:74-84`）
  - **`ToFocus()` 只由** `GameWindow.TryOpen(path: TryOpen)` 的收尾、`WindowsManager.RefreshCurrentWindow/RefreshWindow<T>`、`SelectDecksTab` 调；打开窗口时它作用在**起始页签**（卡组页）上，不是张牌页。
- **张牌页的真填充口**：
  ```
  CardInventory.UpdateItemCollection()            // CardInventory.cs:11-16
      → Signal.Raise<CardCollectionUpdatedSignal>()
      → CardCollectionDisplay.OnEnable 里注册的 OnCollectionUpdate(...)   // CardCollectionDisplay.cs:84-96
  ```
  `CardCollectionDisplay.OnEnable` **只做 `Signal.Register`**（装事件，不填数据）；`RefreshCollection()` 只是 `CollectionDisplay<T>.RefreshCollection(...)` + 一个 `DOVirtual.DelayedCall`。

⇒ **`collectionfill.tsv` 只有表头 = 「ToFocus 没被调」，不是「填充链没跑」。** 这条不能当「10 秒空白」的证据。

### 4.2 关于「10 秒」和「一次性重活」

- 现场复现结论（11-07 冷启动）是 **t0 空白、t1（1 秒）已出卡**（`01_cards_t0.png` 778 KB 明显小于 `02_cards_t1.png` 2.9 MB / `03_cards_t3.png` 3.5 MB）⇒ 当前 **🟠 不可复现**。

## 七 · 顺手发现（未定性，供调度台分流）

1. **`windows.tsv` 里 `OpenWindow` 的 `wmNull=True`**（12:41:07 / 12:50:21 等）：`WindowProbe` 读到的 `WindowsManager` 实例是 null。可能是探针读法问题（静态 `Instance`），也可能是这条重载真的是 `WindowsManager` 静态调用。**没查清**，但它不影响窗口打开（`open-ret GameWindow` 正常）。
