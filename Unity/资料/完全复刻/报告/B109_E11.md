## 二、🔴 判据订正：施工单表 A3 / §六-2 的「`gameModeIcon` 恒 null」**不成立**（本会话现核）

施工单说「`Deck Drawer` 的 `gameModeIcon` 与 `cardBackDrawer` 都是 `{0,0}` ⇒ 原版从不画模式图标 ⇒ 我们多画一层」。

**现核（三源）**：

1. 映射表 §②：`PrebuiltDeck` 的 `drawerReference` GUID = **`7ea5632eb059b5b4493c5047a53e1706`**。
2. `bundle_menus_assets_all/AssetBundle/AssetBundle_1.json` 的 `m_Container` 里该 GUID → `m_PathID = -3438027711880944002`。
3. `GameObject/Deck Drawer_-3438027711880944002.json` 的组件 = `…, -4236236316202293634`；
   `MonoBehaviour_-4236236316202293634.json` 的 `m_Script` = **`DeckDrawer`**，其字段：
   `gameModeIcon = {m_FileID:0, m_PathID:4586698872319452798}` —— **非 null**。

另外两个 `Deck Drawer`（`GO -4925099082606703973` / `-2553787718627850794`）挂的是 **`DeckAndCardbackDrawer`**，它们的 `gameModeIcon` **确实**是 `{0,0}` —— 施工单多半是**只看了这两个实例**就推广到整个类。

⇒ **结论**：`ItemDrawerConfig` 为 `PrebuiltDeck` 指的那份 prefab 上 `gameModeIcon` **有槽**，原版 `DeckDrawer.Draw` 的 `gameModeIcon.enabled = (sprite != null)` 会真的生效；我们 `Shell/ItemDrawer.cs:1808-1813`（`Deck()` 的 ③④）**照原版画是对的**，**不需要改**（按用户 2026-10-28 口径「需要拍板一律复刻原版」——这里原版就是画）。
⚠️ 同时订正施工单 §六-1 的措辞：「`Deck Drawer` 根上挂的是 `DeckAndCardbackDrawer`」只对**那两个实例**成立；**配置表指向的那一份 root 上是 `DeckDrawer`**。
📌 两条都没改施工单本体（不在本代理白名单）—— 请调度台按铁律 5 就地改 `判据/B100_D1_抽屉18档_施工单.md` 的表 A3 行与 §六-1/§六-2。

### 3-1 `GenericArmyItemDrawer` 的判据与两处如实记

- 方法体（第一权威）：`cpp2il/out_cpp2il_dev_ilspy/GenericArmyItemDrawer.cs:12-37`（`decomp_full/…__Draw.c` 同形）。
- prefab 实读：`MonoBehaviour_1212849660543184768.json` —— `showItemInfoOnClick = 1`；`holder` = `{PathID 5357205478649376640}`
  = **`GameObject/Content_-1449735925700546688.json`**；`ItemDrawerComponents` 除 `ephemeralDisplay/ephemeralText` 外**全 null** ⇒ 外层自己不画任何图/字。
- 两条如实记（已写进文件头）：
  ① 原版那条**复用支**（`ReflectionHelper.Is(item, drawer.ObtainableItemTypeToDraw)`）在真实数据上**恒不命中**（内层抽屉的类型是内层物品类型，而传的是外层 `GenericArmyItem`）⇒ 原版实际每票 destroy+重建，我们照此实现、**不造实例缓存**；
  ② 内层 `drawerOverride` 原版传外层 `+0x20` ⇒ 给 `Dispatch` 加了**可选**形参由 `Draw` 传真值；⚠️ `ItemDrawerView.Refresh()` 没存 override ⇒ 重画时内层按 `Default`（差异只可能出现在「外层非 Default 档 + 内层是 GenericArmyItem」，今天零消费点，已出声）。
  ③ 🔶 唯一自加 = 递归深度上限 4（原版无此闸；防夹具自引用把 Unity 批处理打崩；超限出声 + 占位板）。

### 3-2 A2 形状修正

原版两句：`if (i >= Count) image.sprite = FirstOrDefault(iconsByRarity);` 然后**恒** `image.sprite = iconsByRarity[i]`（越界会 `List.get_Item` 抛）。我们原来对域外 rarity 是「取不到 ⇒ 不画」。
现改：域外 ⇒ `WildcardIconFirstRarity()`（= `FirstOrDefault`）画第一条可用图 + 出声 + `FallbackArt`；**域内行为不变**（主图 → `_small` → 数据层）；⛔ **不复制那个崩溃**。
