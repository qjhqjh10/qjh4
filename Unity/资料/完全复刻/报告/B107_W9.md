## 二、判据（两条腿，缺一不算）

**腿①：`AbilityTrigger` 枚举里没有任何成员能 name-parse 到它。**
`d:/2/tools/decomp_full/CardTraitCollection__GetTraitFromAbilityTrigger.c`：

- `:19-21` `trigger == 0 → return 10`（rally）
- `:22-24` `trigger == 0x50(80) → return 0x78(120)`（backlash）
- `:25-31` `trigger == 0x51(81) → return 0x3f2(1010)`（unstable）
- `:32-60` 其余：`AbilityTrigger` 名 → lowerCamel（首字符 `ToLowerInvariant` + 余下 `Substring`）→ `Enum.TryParse<DefinedTrait>`；失败返回 0。
  回到调用方：`CardScript__ActivateTriggerTraitAnim.c:7-10` → `if ((int)uVar1 == 0) return;` ⇒ 框不播。

**腿②：`DisplayTriggerAnim` 的全部 18 处调用点没有一处会传这个常量。**

## 五、建议的宿主接线（由调度台接，我没有改）

落点建议 = `WarpforgeArena1/Editor/AnimFXCheck.cs` 新开一节 `CheckTraitUnreachable()`（或并入 `CheckTraitStartEffects` 尾部）。
三条断言（第 3 条是**灭自证**，删表/清空条目会当场红）：

1. **表自身形态**：`TraitUnreachable.Count > 0`；逐条 `Evidence` / `Why` / `Scope` 非空；`All` 按 `DefinedTrait` 严格升序且无重复 trait。
2. **每条都必须「有行但无动画/无触发」**：对每个条目，用 `trait_effect_bindings.json` 现读该 trait 的行 ⇒
   断言 `TriggerType ∈ {3,6}` 存在（证明「字段在」），并断言它**不在** `TraitFrames` 的 `_triggerBook` 可播集合里
   （或断言其 `prefab`/`cardAnim` 为空或原版调用点缺失 —— 二选一按现接口取）。
3. **灭自证（结构上不可能同时满足）**：
   `TraitUnreachable.IsUnreachable("regeneration") == true` **且** `TraitUnreachable.IsUnreachable("stomp") == false`
   **且** `…("huntMark") == false` **且** `…("bloodThirst") == false`。
   理由：把表清空 ⇒ 第 1 条红；为「让它们都可播」把表改成空壳 ⇒ 第 3 条红；把可达的也塞进表 ⇒ 第 3 条红。
