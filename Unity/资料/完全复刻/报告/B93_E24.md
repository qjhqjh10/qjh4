{

// 类尾（:1730 起注释 + :1735 方法体）
static void ClearInputState()
{
    var pl = _inst != null ? _inst : Object.FindFirstObjectByType<PointerLayer>();   // ⛔ 只找、绝不新建
    if (pl == null) { Debug.Log("[Key] 输入层停用时**没有 PointerLayer 实例** ⇒ …无从清理…"); return; }
    if (pl._hover != null) { pl._hover.Exit(); pl._hover = null; }   // ① = HandlePointerExitAndEnter(pointer, null)
    pl._pressed = false; pl._down = null;                            // ② = m_PointerData.Clear()
    pl._dragScroll = null; pl._dragItem = default(DragSource);
    pl._itemDragging = false; pl._dragging = false;

}

## 没查清 / 顺手发现

1. 🔴 **`_editing` / `_typed` / `_buf`（文本框那条链）停用时没有清 —— 这是本批**明知没做**的一处。**
   原版那一步是 `ClearSelection` 顺带把 `InputField` 反选（`OnDeselect` → `DeactivateInputField`），
