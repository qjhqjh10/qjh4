## 二、为什么给 null 是安全的（同一条链，三处共用）

1. 三处都调 `PlayfabWrapper.GenericCloudScriptHandler(CloudHandle.X, payload)` 两参版 ⇒ 命中
   `GenericCloudScriptHandler(CloudHandle, object, Action onComplete = null, Action<string> onError = null)`
   （`out_cpp2il_dev_ilspy/PlayfabWrapper.cs:2283`）。IL2CPP 视图里三处都显式传 `0, 0`：
   `LiveOpsEvent.cs:230` / `:244` / `SegmentationController.cs:199`。
2. 非泛型重载把结果包成 `<>c__DisplayClass15_0.<GenericCloudScriptHandler>b__0(object _)`，
   形参 `_` **完全不使用**，只 `if (onComplete != null) onComplete()`，而 onComplete = null
   （`PlayfabWrapper.cs:262-268`）。
3. 回包里 `Error` 为 null ⇒ `ProcessCloudscriptResult` 走 `DeserializePlayfabResult`；
   `FunctionResult` 为 null 时以 `onComplete(null)` 结束，不会走 onError，也不会 NPE
   （`decomp_full/PlayfabWrapper__ProcessCloudscriptResult_object_.c` ·
   `decomp_full/PlayfabWrapper__DeserializePlayfabResult_object_.c` 开头 `if (param_1 == 0)`）。
