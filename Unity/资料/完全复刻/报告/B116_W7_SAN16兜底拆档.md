## 二、两档常量定义位置

| 档 | 常量 | 落点 | 值 |
|---|---|---|---|
| 表在、但**表里没有这张卡** | `AbilityAnimDurations.NoEntryFallback` | `Core/AbilityAnimDurations.cs:119` | **0f** |
| **整张表载不到 / 解析失败**（保守档） | `AbilityAnimDurations.LoadFailFallback` | `Core/AbilityAnimDurations.cs:124` | **1.0f** |
| 镜像（同值同语义） | `EventTiming.AbilityNoEntrySeconds` / `EventTiming.AbilityLoadFailSeconds` | `Core/EventTiming.cs:993`（同一物理行，刻意零行数变化） | 0f / 1.0f |

- 唯一判据口 = `AbilityAnimDurations.FallbackFor(bool tableLoaded)`（`AbilityAnimDurations.cs:143`）：
  `true ⇒ NoEntryFallback（0）` · `false ⇒ LoadFailFallback（1.0）`。⛔ 两档不许再合成一个数。
- 消费点：`AbilityAnimDurations.TryGet` 的 `out seconds`（`:205`）与 `EventTiming.AbilityHoldOf`（`EventTiming.cs:366`）**都走它**。
- 资源失败三条路（`ta == null` / 解析失败 / 表里一条都没有）现在都 `Debug.LogWarning` 出声（`AbilityAnimDurations.cs:167` / `:188`），且值固定 1.0。
- `DurationOf(EvtKind.Ability)`（**拿不到卡**的旧重载）= `AbilityLoadFailSeconds`（1.0，保守档）——
  它是「不知道是哪张卡」，⛔ 不是「这张卡没有动画」，**不许回 0**。
- `EventTiming` 侧同步：`AbilityHoldOf` 的 null 事件 = 保守档、查表命中 = 真值、查不到 = `FallbackFor(Loaded)`；
  `SourceOf` / `IsSourced` 的措辞一并对齐（`Ability` 仍 `IsSourced == false`，`BattleScene` 的 `unsourced == 2` 不受影响）。
- **未改** `Resources/ability_anim_durations.json`（`count 93 / fallbackSeconds 1.0` 本来就是对的）。
