static bool HandListenerContextAllows(CardDef card, string kind)

## 六、顺手发现

1. **`play check` 的 ①-c 统计会随这一类修复「变差」**：修复把手牌副本的贡献拿掉之后，那几张卡的**主档**可能变成「一个数字都没动」⇒ 计数从「被验到」掉进「没被验到」。⛔ 别把 ①-c 的 402→405 / 114→119 当成回归 —— 它是修复的**度量后果**（本笔已在 §3·3 逐张列出是哪 3 张）。
2. **`BL8 Noise Marine` 现在在 `play check` 里没有任何可观测面**（主档与电池都 = 0）：它的卡面只对「**督军**受伤」响应，而两档夹具都不打督军。建议后续给 `ruleprobe` 加一条「督军受伤」的 preset（本笔白名单外，没动）。
3. `BroadcastHandWhen` 的**早退预扫**（`:11060-11070`）仍然只看「卡型 + `WhenTriggers.Count`」，与新闸**判据不一致**（它只是省算力、不影响正确性：预扫放行后逐张还会被闸挡住）。若哪天要省这点算力，预扫也应该带上那道闸 —— 但**别只改预扫**（那会变成真正的漏判）。
