## ⑤ 资源侧**还欠什么**（诚实清单）

1. 🔴 **「已用（数据表）」不等于运行时加载**（16,794 条）。它只证明**名字整串出现在我们的表里** ——
   尤其 1,449 个精灵里，可能有一部分只是被 `_atlas_rects.json` 这类清单带进去的。**逐类核**还没做。
2. 🔴 **按名加载的路径没建模**：934 个「原版不可达」里 **779 个我们反而在用** ⇒ `Resources.Load("<名字>")` /
   `LoadAsset(name)` 这类入口静态图**看不见**。要坐实只能上运行时探针（原版能离线跑）。
3. **GameObject 13,086 个「没用上」不能直接当缺口**：它们多是预制体内部节点，我们是**重建**不是同名导入，
   按名字匹配天然对不上。要不要逐条核，取决于那个预制体是否已复刻。
4. **R2 只对了顶点「数量」**，没逐点比坐标（166 个流式网格）。要「重建出货」到工程里，得抽 3~5 个做点集比对。
5. **R4 的 7 个空 blob shader**（ClusterDeferred / XROcclusionMesh / LensFlareScreenSpace / BlitHDROverlay /
   XRMirrorView / StencilDeferred / XRMotionVector）**原版 build 里就是 10 字节** ⇒ 反编译不可能拿到，只能照 URP 官方实现。
6. **CardTrait「判过 D」只有台账映射**（`判据/CardTrait对账.md` §7），不是 trait 级结论 —— 台账是**方法级**的。
7. **`UM_Forge_Badge` 静态判不了**（三处都查过：0 PPtr / 0 容器 / 0 字面量）—— 不注「大概没用」。
8. **音频 / Material / Texture 只做到「名字命中」这一级**，没有逐条语义核对（那是各自线的事）。
9. **`Destroyer` / `Penitence` 两个卡表 token 待卡面核**（不在 `DefinedTrait`、不在 `Card_Trait/*`，只见于粉丝规则书）。

## ⑥ 顺手发现（跨件的）

1. 🔴 **资产身份必须用三元组**（文件, CAB, PathID）—— 这条已经影响过 R0/R3 两处，建议写进项目级注意事项。
2. 🔴 **`extract_full.py` 把 `globalgamemanagers` 与 `globalgamemanagers.assets` 写进同一个目录**
   （`os.path.splitext` 把 `.assets` 当扩展名切掉），4,590 与 20 个对象混在一起。引用那份导出件的人要知道。
3. 🔴 **`TypeTreeGeneratorAPI` 必须用裸程序集名**（不带 `.dll`）；UnityPy 1.24.2 的 helper 会自动补 `.dll`
   ⇒ 每次查询都 `failed to dump nodes raw`，会让人误判「IL2CPP 反推不可用」。
4. **UnityPy 生成的类型树读 `List<string>` 会读跑飞**（只读第一个串）—— 只影响没有类型树的内置文件；
   bundle 里的对象有真类型树，现有 `assets_full` 导出件**不受影响**（已抽 `bundle_prebuiltdecks` 验证）。
5. **`AssetRipper` 导出工程 = 同一 build，可当第二解码器**（本轮 12 个对象 + CardTrait 交叉验证都靠它）。
6. **`sharedassets0.assets`（= `Assets/Resources/`）是第二个入口**：26 个 SO **0 条 PPtr、0 条容器路径**
   ⇒ 只能 `Resources.Load` 按名加载；用「卡牌 bundle + allcards」那条路**结构上搜不到**。
7. **`trait_collection.json` 的「未解」清单有 4 条是假阴性**（GUID 都能解），其中 `Swarm Card Merge VFX`
   我们代码早就在用了。
8. **69 个 `CardTrait` SO 与工程已有的 `trait_collection.json` 逐字段一致**（两个独立解码互证）；
   `_stackable` / `_aIScore` 在本 build 里**几乎没有区分度**（10 / 0.0），别拿它们推行为。
9. **Ruri 已经把 422 个 shader 反编译好了**（`d:/2/tools/ruri_out_1020_rootshaders`，0 Dummy），
   本轮只是把 234 个 Shader **对象**逐条对上号 —— 以后做 shader 对拍直接查这张表。
