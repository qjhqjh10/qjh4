## 四、顺手发现（本会话新查到的，按重要性排）

1. 🔴 **`Recorded` 不是孤儿 —— 它是 Leviathan 地堡门的 Timeline 轨道，原版会播**。
   证据链：`assets_full/bundle_battlesharedresources_assets_all/GameObject/Bunker Door Parent.json`（`m_IsActive: true`，组件 `[Transform, PlayableDirector 7845524703085758649]`）
   → `PlayableDirector_7845524703085758649.json`：`m_Enabled: 1` · `m_InitialState: 1`(Playing) · `m_WrapMode: 1`(Loop) · `m_InitialTime: 15.0` · `m_PlayableAsset` = `Leviathan Bunker Door Animation`（5 条 track）
   → bindings：track `983775116529081651` → GO `-4873928100598937415`，`Recorded` 就在这条 track 上。
   ⇒ `工具/extract_missing_shaders.py:587` 那句「**原版 0 消费者**（13 场里没有任何 `Animation.m_Animation` 指着它）」**只查了 Animation 组件、漏了 Timeline**。
   我们 `battlearenaleviathan` 清单里 `Bunker Door Parent/Bunker_door/Cube` 是**静态网格**，`manifest` 里没有 PlayableDirector 字段。
   ⚠️ 复刻它需要 **PlayableDirector / Timeline** 支持，全仓目前只有 `WFModuleAnimation` 引 `UnityEngine.Playables`，没有 Timeline 绑定层。

2. **`R2_重建网格/` 是尺子不是出货** —— 全仓 `.cs/.py/.json` **0 引用**。别把它当「已落地」。

3. **没有任何运行时网格读回** —— `GetVertexBuffer` 只在两个 `Editor/*.cs` 里。

4. **`WarpforgeVFX/Animations/` 有 3 条与 `CardPresentation/Resources/Animations/` 重复**（`Division Up` / `Rank Up` / `Level Up Card`）；真正被 `Resources.Load` 取的是后者，前者无人引用。

5. **`R3` 表里有重名**（`Battle Arena Emperors Children Camera Intro` ×2）—— 再次印证「⛔ 绝不按 `m_Name` 找 clip」。

6. **`ImportMesh` 有一条会静默丢数据的支线**：非「单流 + 无 blendShape + 无 bindpose」的网格退回 `Instantiate`（对流式 = 未初始化内存），只 `LogWarning`。本轮无法判 169 个流式网格里有没有命中这条（需 Unity 侧跑 `MeshImportMethodProbe`）。
