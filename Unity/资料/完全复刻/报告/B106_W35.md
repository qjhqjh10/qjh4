## ① 结论

**已修。** 我们的 `AlliancesNotificationBadge` 原来 `: BadgeNotification`（与 `SocialBadge` 是**兄弟类**），
而原版是 `record AlliancesNotificationBadge : SocialBadge`。因为「哪条定义算哪条通知」是双向
`IsInstanceOfType` 的两道闸，兄弟关系 ⇒ 左竖导航 **SOCIAL** 那一颗（定义 = `SocialBadge`）对联盟邀请**恒计 0**。

改动共 **2 处代码 + 2 处注释就地改写 + 文件尾追加一段注记**；代码改动都是**同一物理行改写，行数零变化**。

## ⑥ 顺手发现（不在本单范围，**未改**，交给调度台）

### 1. 🔴 `CampaignBadge` / `ForgeBadge` 的「今天不影响计数」是**错的** —— 它们本该点亮 REWARDS 导航钮

三源一致（`out_cpp2il_dev_ilspy/Everguild.UI.Notifications/CampaignBadge.cs:8`、`ForgeBadge.cs:8`：
`public record CampaignBadge : RewardsBadge` / `ForgeBadge : RewardsBadge`；`out_il2csharp/…/CampaignBadge.cs:11`；
`il2cpp_out/dump.cs:123684/123752`）。

原版 `RewardsBadge.Validate`（`out_il2csharp/…/RewardsBadge.cs:24-44` 最清楚）语义是：
> `other is RewardsBadge` ∧ **两者运行时类型不同** ⇒ 比较 `parentId`；否则落到基类 `Notification.Validate`（类型相等）。

而 `CampaignBadge` 的 ctor 把继承来的 `parentId` 写成 `""`（`CampaignBadge.cs:26-32` 的 `this+16` 写 `""`），
所以原版：

- REWARDS 导航钮定义 = `RewardsBadge` + useFilter `parentId=""`
- 外闸 `IsRelated(RewardsBadge, CampaignBadge)` 原版 = **true**（`CampaignBadge : RewardsBadge`）
- 内闸 `CampaignBadge.Validate(RewardsBadge{parentId=""})` → 类型不同 → `"" == ""` → **true**

⇒ **原版里「战役有可领」会让 REWARDS 导航钮也亮**（锻造同理）。我们现在 `CampaignBadge`/`ForgeBadge` 都是
`: BadgeNotification`（兄弟）且各自 override `Validate` 比 `army` ⇒ **外闸就跳过了** ⇒ REWARDS 导航钮**少算这两类**。

**为什么本轮不做**（按铁律 14 的「能否迅速」三判据，②不过）：
改它们要同时动 `Validate` 的**语义**（`army` 比较 → `parentId` 比较），而
`Editor/B94Z1_Assert.cs:197-207` 明确用 `new CampaignBadge { army = "Goff" }` 做 useFilter 反例
⇒ 属于**会牵动已有断言**的一次性改造，不是「就地改基类」那一档。建议单独派单，施工单：

- 判据（已查清，可直接照做）：
  - `CampaignBadge : RewardsBadge`、ctor 里 `parentId = ""`（`CampaignBadge.cs:8,26-32`）
  - `ForgeBadge : RewardsBadge`（`ForgeBadge.cs:8`，同样 `parentId=""`；`army` 字段保留，但 `Validate` **不要**再 override）
  - 我们的 `RewardsBadge.Validate` 也要按原版补「**同运行时类型 ⇒ 走基类（类型相等）**」那一支
    （现实现无条件比 `parentId`；两种写法只在「同类型但 parentId 不同」时结果不同）
- 落点：`Shell/BadgeNotifications.cs` 的 `ForgeBadge` / `CampaignBadge` 两个类定义 + `RewardsBadge.Validate`
- 要同步复核的断言：`Editor/B94Z1_Assert.cs:190-210`（Campaign 页签 ④e/④f）· `Editor/MainMenuScene.cs:1180-1240`
