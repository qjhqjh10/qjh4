## 一句话结论

**根因不是某个 `.meta` 手写错了，是生成器：`ArtBaker.ApplyImportSettings` 里那行
`ti.maxTextureSize = isBackdrop ? 2048 : (path.Contains("/ui_deck/") ? 2048 : 1024);`
——`ui_menu` / `boosterpack` 落在 `1024` 那一档，而这两个子树里正好有 **66 张源边 2048** 的图。
已把这两个子树并入 2048 档（**按子树写规则，不按 66 个文件名硬编码**），并在方法末尾加了一条
**「实读导入后真实尺寸」的校验**。改的是生成器 ⇒ 可重建、可复跑、下一次烘焙不会再退回去。**

## ③ 改了什么（`Unity/MyGame/Assets/CardPresentation/Editor/ArtBaker.cs`）

`git diff --numstat` = **53 / 1**（净 +52 行）· 行尾 **纯 CRLF**（改前 626 CRLF / 626 LF，改后 678 / 678，**裸 CR = 0**）。

### 改动 1 · 把 `ui_menu` / `boosterpack` 并入 2048 档（`:480-495`）

```csharp
bool hiResUi = path.Contains("/ui_menu/") || path.Contains("/boosterpack/");
ti.maxTextureSize = (isBackdrop || hiResUi || path.Contains("/ui_deck/")) ? 2048 : 1024;
```

**为什么按「子树」而不是「66 个文件名」**（三种做法都评估过）：

| 做法 | 判断 |
|---|---|
| **全目录一刀切 2048**（`Resources/Art` 下全部） | ⛔ 会改写 `cards/`(1400+) / `avatars/` / `vfx/` 等 6000+ 份 `.meta`；虽然现读那些子树里**没有** >1024 的源图（导入结果不变），但会让「名义上限」与「真实需要」脱钩，将来谁往 `vfx/` 丢一张 4096 的图会**静默按 2048 压**，且看不出为什么。 |
| **只针对这 66 个文件名**（硬编码名单） | ⛔ 脆：其中 64 张是同一族 `UI_Deck_Warlord_*`，等于把一份名单分两处维护（铁律 6），以后新增督军还要改代码。 |
| **✅ 两个子树**（已采用） | 当前**只影响这 66 张**（两个子树里源边 >1024 的就这 66 张，其余 431 张源图 ≤1024 ⇒ 抬到 2048 **不改变导入结果**，Unity 不做上采样 —— 逐张量过 `IHDR`），且不透支到别的目录。 |

⚠️ 注释里把**判据、构建产物读数、原版出处**都写进去了（含「这不是 1024 是有意取舍」的证据链）。

### 改动 2 · 方法末尾加「实读校验」（`:536-572`）

照同一文件里 `ApplyArenaImportSettings` 的既有先例（`:652-677` 那段 `实读校验：没有一张被缩`）——
**判据 = 导入后的 `Texture2D.width/height`，不是 `.meta`、也不是「日志说改了 N 张」**。
只扫 `ui_menu` / `boosterpack` 里**源边 >1024** 的那批（现读 66 张）：
先用 `GetSourceTextureWidthAndHeight`（便宜，不加载贴图）筛，只有命中才 `LoadAssetAtPath<Texture2D>` 比真实尺寸。
⚠️ 源尺寸**必须**用 `GetSourceTextureWidthAndHeight`（`LoadAssetAtPath` 拿到的是已导入的那份 = 自证，同 `ApplyArenaImportSettings:604` 踩过的坑）。
⚠️ **先断前提再断结论**：`hiChecked == 0` 会印 `LogWarning`「一张源边>1024 的都没找到 —— 这条校验没验到东西」，
**不给绿**（本工程踩过 `if (x != null) Check(...)` ⇒ 静默跳过）。

## ⑦ 顺手发现（不在本任务范围，但下个回合需要知道）

1. 🟠 **`工具/sync_battle_ui_art.py` 的 meta 模板本身是 1024**：模板 = `Resources/Art/ui/40k_battle_Win_Skull.png.meta`，
   其 `DefaultTexturePlatform.maxTextureSize = 1024`。⇒ 任何走它**新建** meta 的 `ui_deck/` / `ui_menu/` 图先拿到 1024，
   **只能靠之后跑 `ArtBaker.ApplyImportSettings` 纠回来**。模板是生成物（`Resources/Art/**` 在 `.gitignore`）⇒ **不能当持久修复点**；
   要改就改**次序**（sync 先、ArtBaker 后）。这条把 `A937` 那句「导入 → ArtBaker」补上了**具体读数**。
2. 🟠 **「1024 那一档」的历史来源**：`git blame` = `e0f49278`（2026-09-15）；督军方形立绘 2026-10-18 才进来。
   ⇒ 属于「规则早于素材」，不是有人拍过板。以后遇到同族（某目录后来才进 >1024 的图）**先查这条**。
3. 🟡 **「已知格式错误」的例外一条都没碰**：`报告/B110_R1` §6 / §9 那两条（`TutorialInfo/Icons/URP.png` 是 JPEG 装 `.png`；`ui_menu/Copy@3x.png` 缺 meta）—— 前者**不在 `Resources/Art` 下**、后者现读 `.meta` 已存在（自愈）；
   另现读 `Resources/Art` 全树 **0 份** meta 缺 `TextureImporter:` 块 ⇒ `报告/B110_F3.md` 信息项里的 `IMPORTER_DEFAULT 2` **不在这棵树**，别把它算进这一批。
