## 一 · A：模板钉死 `textureCompression`（判据 → 改法）

### 1·1 判据（不是挑的）

`判据/B108_AUD09_纹理格式.md` §二 D 行 + §3·1（R7 原版 bundle 实读）：

- 13 阵营 `40k_Cardframes_*_SDF_tier*` **104 张全部 `m_TextureFormat = 4`(RGBA32) · 128² · 未压缩 · `m_ColorSpace=1` · mip=1**；
- `cardback_noise.png` 对应的原版 `Noise Combined` = **RGBA32 · 128² · cs=0**；
- **两张例外**：`generic.png` / `Card_board_frame_SDF.png` 同源 `Card board frame SDF`，原版 **BC7 · fmt=25**。

🔴 **为什么必须写在 `platformSettings` 里**：本目录 107 份 `TextureImporter serializedVersion: 13`
**没有顶层 `textureCompression` 字段**（`grep -l "^  textureCompression:"` = 0 命中），
生效的是 `platformSettings` 的 `DefaultTexturePlatform` 块（同族：顶层 `maxTextureSize` 也不生效，见 R7 §五 顺手发现 1）。

### 1·2 改了什么（`工具/import_original_card_sdf.py`）

| 位置 | 改动 |
|---|---|
| 模块 docstring | 新增一节「`.meta` 里的 `textureCompression: 0` 也是本脚本的硬不变量」：问题 / 判据 / 两张例外 / 为什么是平台块 / 验证命令 / **它证明不了什么** |
| 模板上方注释 | 补 `maxTextureSize` 顶层不生效的提示、补 `platformSettings` 一行 |

| 新增 `KEEP_BC7` | `("generic.png", "card_board_frame_sdf.png")` —— 与 `ArtBaker.ApplyImportSettings` 的 `isSdf` 例外表**同一条判据**（注释里点明「改一处要核另两处」） |
| 新增 `platform_settings_for()` | `keeper ⇒ Default 2 / Standalone 1`；其余 `⇒ 0 / 0`（`Standalone` 是 `overridden: 0` 的死值，照抄现值以免将来开覆盖时突变 DXT） |

> （`  __PLATFORM_SETTINGS__` + 以 `  - ` 开头的块 ⇒ `    - serializedVersion: 4`），YAML 立刻坏掉。

## 五 · 顺手发现

1. 🔴 **导入脚本文档里有一条判据出处是错的，已就地订正（铁律 5）**：
   原 docstring 写「原版是 Gamma —— `unity_run_ref/Warpforge_Data/globalgamemanagers` offset 272 = 0」，
   而 `判据/B108_AUD09_纹理格式.md` §1·4 复核**对不上**（该处字节是 `46 44 bd 37`，属哈希区）。
   **结论（原版 Gamma）成立**，出处已改成 `D:/2/tools/assetripper_out/ExportedProject/ProjectSettings/ProjectSettings.asset:56`
   的 `m_ActiveColorSpace: 0`，并保留更正痕迹。
2. ⚠️ **两张 keeper 的 `Standalone` 块是 `textureCompression: 1`，而它们的 `Default` 块是 `2`（BC7）** ——
   同一份 meta 里两个数不一致，**现在都是死值**（`overridden: 0`）。若将来谁把 Standalone 覆盖打开，
   `generic` / `Card_board_frame_SDF` 会掉到 DXT。模板里对它们**照抄现值 1**（保证与盘上逐字一致），
   但这是个隐患点 —— 建议真要开平台覆盖时先扫一遍这类「Default 与 Standalone 不一致的死值块」。
3. ℹ️ **模板的 `maxTextureSize` 分两处**：顶层写 1024（**不生效**，Unity 存盘时写回 2048）、
   生效值在 `DefaultTexturePlatform` 块（1024）。这与盘上 107 份实测一致，已在注释里写清。
4. ℹ️ **`--orig` 只要 6 秒**（13 个 cardassets 包 + 2 个额外包），比 R7 记的「1–3 秒/包」快得多，
   可以当日常回归用。
