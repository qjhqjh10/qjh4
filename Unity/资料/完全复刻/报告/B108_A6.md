## 三 · #120 后半句为什么「现读证明不成立」

TSV 写：「同一扇已开再点入口 ⇒ `HideAllWindows` 把自身打回 `Closed` ⇒ **整窗重建**（原版 `state=Open` 直接 return）」。

现读两条原版方法体：
1. `WindowsManager__OpenWindowCO.c:1560-1567`：`if (window.type == Fullscreen) { if (openWindows.Count > 0) HideAllWindows(); }` —— **没有把「正要开的那一扇」排除在外**；
2. `WindowsManager__HideAllWindows.c`：predicate = `w != null && state != Closed`（`cpp2il/out_cpp2il_dev_ilspy/WindowsManager.cs:1655-1673`），随后对每一扇调虚表 **`0x1c8` = `Hide()`** ⇒ **包括它自己**。

⇒ 原版「再点同一个全屏入口」时，顺序是 `HideAllWindows()`（把自己 `Hide` 成 `Closed` + `SetActive(false)`）→ 然后 `window.TryOpen(data)` 走 **`Closed` 支**（`GameWindow__TryOpen.c`：`state==0` ⇒ 播音 + `SetActive(true)` + `state=1` + 调 `Open()`）⇒ **原版也整窗重建**。`state == Open` 那条「一个字段都不写就 return」的分支在这条路上根本到不了。

⇒ 我们现在的行为（首开只 Build 一次；已开再入时 Hide 自己再重建）**与原版一致**，不是偏离。这一条也已经是 `账/菜单_外壳.tsv:881` 里 `B103_R1` 记过的结论（「⚠️『已开再入被重建』**是原版行为**（全屏支把本窗也 hide），⛔ 不要另做『已开就 return』」）。⛔ **别按 TSV 那半句去给四扇窗加「已开就 return」**（那才是偏离）。
