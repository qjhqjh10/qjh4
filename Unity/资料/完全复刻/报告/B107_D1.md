## 〇、结论（一句话）

**两棵「孤儿」都不是「被从商店窗里摘走」的页，而是两棵【出生就在场景根】的树：**
1. **`#2`（决定这条红的）** = 一具 **`ShopTabPage` 的整页内容树**。`Shell/ShopTabPage.cs:246 Setup()` 被**对一具已销毁的页**调用时，`_root` 是 Unity 假 null ⇒ `MainMenuSubmenuWindow.Node(null, …)`（`Shell/MainMenuSubmenuWindow.cs:382-386` → `MenuDraw.cs:168-172` 的 `SetParent(parent,false)`）把 `daily shop header` / **`Packs Scroll View`** / `Viewport` / `Content` / `CatalogItemShopContainer_i` / **`InfoHit`** 全建在**场景根**。

⇒ **没有人 `SetParent` 摘它们**；缺的是两个「该失效/该销毁」的动作：迟到的闭包拿着死页继续 `Setup()`；夹具收尾漏删。
