## 一、判据与口径（读表前必须知道）

| 口径 | 事实（本次现读） | 影响 |
|---|---|---|
| **`m_Interpolation` 字段** | **本 build 的 `AnimationClip` JSON 里根本没有这个字段**（grep 99 份 = 0 命中）。等价旋钮 = ① 每 clip 的 `m_UseHighQualityCurve`（**99/99 = true**）② 每键的 `weightedMode` ③ 每键的 `inSlope/outSlope` | 任务书里问的「插值模式」只能按 `weightedMode + 切线` 判 |
| **`weightedMode`** | **14,848 键里 14,846 个 = 0**；只有 **2 个 = 3**，且都在 `Valkyire Drop Movement` 的 position 曲线首/末键（不是卡牌族） | ⇒ 除那 2 个键外 **`inWeight/outWeight` 一律不生效**，`inSlope/outSlope` 就是真切线 |
| **`inWeight/outWeight` = 0.3333** | 14,625 个键带着 `0.33333334`，但 `weightedMode = 0` ⇒ **Unity 忽略** | 我们四条生成器都不存权重 = **正确**，不是缺字段 |
| **`inSlope/outSlope` = `inf`** | **383 个键**（全在离散属性曲线上，如 `m_IsActive` / `m_Enabled`）—— Unity 的「未定义切线」 | 生成器要能把 `inf` 写成 0 而不是抛 `Infinity` 进 JSON（见 §五 未核） |
| **零切线 = smoothstep** | 一条 2 键曲线若**两端切线都是 0**，Hermite 精确等于 `3u²−2u³`（**不是线性**） | 本文件大量用它判形状 |
| **`m_PreInfinity` / `m_PostInfinity`** | **850/850 = 2（Loop）** | 我们多数消费方按 `[0,1]` 求值 ⇒ 无差异；但 `WrapMode.Clamp` 与原版 `Loop` 在**外插**时不同（当前所有曲线首键 `t=0`、末键 = length，走不到） |
| **clip 级 `m_WrapMode`** | 现读分布：Default **46** · Once **31** · Loop **16** · ClampForever **6** | `Default` 对非循环 clip 解析为 `Once`（见下 `BattleHud` 那行） |
| **muscle clip** | **9 个** `legacy = false`（`Card Explosion` / `Cannon front Idle` / `Pump Animation` / `Dynamic Skulls` / `Battle Arena 2 Animations` / `SporeArmature\|LeviathanBigSpore` / `Shield Enter` / `Shield Exit` / `Recorded`）—— 曲线在 `m_MuscleClip`，`m_FloatCurves` 为空 | 我们**不重建**这些（见 §三），全部走运行时原包 ⇒ 不受「拷出来是空壳」影响 |
