## 一、一句话结论

三件里有 **1 条真断链、1 条精度缺口、1 条过期注释、1 条文档/自检缺口**；其余现读已落地：
- **T21**：6 张受影响卡里 **5 张已通**（Improvised Barricade / Jammed / Cult / Poisoned / Vengeance），**`Avenging Zeal`（UM40）真断链** —— 它的触发 `TriggeredCodex(650)` 在 `VfxMap.NoEmitTriggerNames` 里、不在路由白名单，生成器因此把那一行放进 `trigger_unmapped`，而 `TryResolveTriggerPicks` 只读 `trigger`/`ability` 两桶 ⇒ 今天一次都不播。引擎侧其实**有**发射口（`TriggerNameOfWhenKind` 的 `triggers:<kw>` → `case KeywordTable.Codex: return "TriggeredCodex"`，`EffectResolver.cs:7666`）⇒ 台账未跟上。
- **T21 精度缺口**：`EmitListenerTrigger` → `EmitCardTrigger` 对 `unit == null` 恒写 `InstanceId = 0`（`EffectResolver.cs:8432`），三处手牌调用点（`:10803/10905/11078`）没有把 `CardInstance.Id` 传下去 ⇒ 手里同名两张时手牌锚只能取第一张（`HandCardViewOf` 会出声，`BattleDriver.cs:39291-39295`）。已在 `T21-c` §六·5 记过，本轮确认仍开。
- **VfxMap 兜底**：`W64` 的 B1–B9 九条现读**全部闭合**；剩的是「一条过期注释（`ByEvent[Hit]` 仍写‘替代品’，实际 small/big 两份 PPtr 同 pathID、就是原版件）」+「手写远程时长表（A12，漂移风险）」+「缺一条兜底链自检锁」。**B14（GrabScreenFeature event 501）不属 VfxMap**，是同一轮审计的 shader/导出侧唯一未闭项，需 Unity A/B。
- **AN1**：R1–R8、R10–R16 现读全部有落点；R3/R12 **数据侧已修且断言已接线**（`Editor/BattleScene.cs:46866`），只差一次宿主实跑。真正还开的是 **R9③（不可达 trait 清单）** + `U4`（AnimFXModule 全量字段比对）· `U5`（notPlayed 22 条复核）· `U7`（`overrideByArmies` 10 条按卡阵营取）· `U2`（真机观感）· `U6`（表现层随机 vs 回放）。
