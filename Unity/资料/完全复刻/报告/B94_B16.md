### 6·3 `GetRandomAttackTarget`（账 `:373`，若调度台要「建出来」而不是判 D）

```csharp
// 原版 BattleManager__GetRandomAttackTarget.c:1-38
internal static UnitState GetRandomAttackTarget(BattleContext ctx, UnitState attacker)
{
    if (attacker == null) return null;
    int p, s;
    if (!FindSlot(ctx, attacker, out p, out s)) return null;
    int foe = 1 - p;
    bool ranged = CurrentAttackIsRanged(ctx, p, s);
    if (CanAttackNow(ctx, p, s, ranged) != RuleCodes.OK) return null;   // = GetAvailableAttackTargets 的前置
    var targets = new List<UnitState>();
    for (int t = 0; t < BoardSpec.Size; t++)
    {
        var u = ctx.Players[foe].Board[t];
        if (u == null) continue;
        if (IsValidTarget(ctx, p, s, foe, t, ranged) == RuleCodes.OK) targets.Add(u);
    }
    if (targets.Count < 1) return null;
    return targets[ctx.GetRandomInt(0, targets.Count)];   // 与原版同一张预烧表、上界开区间
}
```
（`FindSlot` / `CurrentAttackIsRanged` / `CanAttackNow` / `IsValidTarget` 都是 `RuleCore` 现成私有件，同 partial 内可直接调。）
