## 四 消费端：现在画的是什么 · 换源会/已改变什么 · `play check` 会不会变

### 4.1 `SetEffectRows` 现在画的是什么
- 入参 `IReadOnlyList<EffectRow>`，每行 = `(Who 左列, What 右列)`（`CardDisplayWindow.cs:1959` `IsEmptyRow`）。
- 槽模型（`:951-971`）：`n = min(rows.Count, 5)`；`EffectRowCount = 非空条数`；`_fxRoot/_fxTitle` 只在**非空 > 0** 时亮；逐槽 `on = i < n && !IsEmptyRow(rows[i])`（**空行占槽号但不画**）；超过 5 条只画前 5（并 `Debug.LogWarning`，不静默）。
- 外层（`:2568`）：`hideForEnvironmental` 为真 ⇒ 整组压掉、`EffectRowCount = 0`、返回 false。
- 数据来源（生产）：`BattleDriver.cs:13212` → `RowsOfEffects(EffectsToShow.Of(u, side == _me), side == _me)` ⇒ **已经是原版 `+0x108` 的投影**。旧口 `RowsOf(TempBuffs)`（`:851`）**已无生产调用点**（只剩 `B94B9_Assert.cs:77-96` 在直调它当单测口径）。

## 八 一句话结论（该不该现在做）

**该做，而且可以一次做完 —— 但要拆成 3 个会改可见画面的小批**。
理由（⛔ 不是「影响小」）：`GetCardEffectsToShow` 这一条链的**主干（S1 投影 / S4 消费 / S5 接线 / 槽位模型 / 环境卡闸）已在 2026-10-29 全部落地并在线上生效**，剩下的 5 条全是**同一条账（`特效动画:521`）的残差**，落点集中在 `UnitState.cs` / `CardInstance.cs` / `Enchantment.cs` / `EffectResolver.cs` / `工具/ruleprobe/**`，**没有一条在结算链上**（`Of()` 纯读、生产 `ctx=null`）⇒ 做了不会动指纹，只会让**行的序、行的合并、洞的位置**更像原版；不做则这条账永远停在 B，且「同一次 give 多属性印 3 行」「附魔洞跑到队尾」这两处玩家现在就看得见。⇒ 建议按 §五 的 **批 A（探针）→ 批 B（盖戳）→ 批 C（RowGroup）→ 批 D（removeTrait/setCurrentHealth）** 推进，每批前后各存一份 `ruleprobe effects` 全池 dump 作为验收证据。
