### 1·1 波 0 的关键取舍（照调度台的红线）

`CardDef.AttachAbilityTriggers` **只置 `AbilityTriggersVersioned`，不碰 `AbilityTargetsVersioned`**：

```csharp
public void AttachAbilityTriggers(IEnumerable<int> triggers)
{
    if (triggers == null) return;                          // 未知 ⇒ 不写（⛔ 别折成「没有」）
    foreach (int _tg in triggers) _abilityTriggers.Add(_tg);
    AbilityTriggersVersioned = true;                       // 🔴 只这一位
```
