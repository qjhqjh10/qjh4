## 二 与 `B97_W37` 不一致的两处（**以二进制为准**，逐条写清）

### 2·1 `shouldTriggerSummon` 的逐调用点表 —— **`_ResolveCardAutoSummoned` 是 0，不是「未解」**

W37 §4·1 那张表把 `_ResolveCardAutoSummoned_d__511:245` 记成「栈上 bool（未解）」，并把我们侧的分档判据
写成「`PlayFromHand` / `AutoPlayFromHand` 应触发」。本件回源现读（**同一个文件、同一行、全文**）：

```c
uVar15 = CardScript__MinionPlayedIntoField(lVar19, uVar13, uVar12, 1,
                                           in_stack_fffffffffffffe58 & 0xffffffffffffff00,
                                           in_stack_fffffffffffffe60 & 0xffffffffffffff00, 0);
```

第 6 个实参（= `param_6` → `+0x3c` = `shouldTriggerSummon`，工厂 `CardScript__MinionPlayedIntoField.c:20-25`
逐句实读）写的是 `& 0xffffffffffffff00` ⇒ **低位清零 ⇒ `false`**。
**这不是孤例**：同一个调用里的第 5 个实参 `keepStatus` 用的是**同一种掩码**，而它同样必须是 `false`
（`RuleCore.ApplyDeployTurnState` 的 doc 早已按「4 处常量 false」记着 `_ResolveCardAutoSummoned`）。
两个相邻实参同一种写法 ⇒ 那掩码就是本反编译里 `false` 的固定形状。

**最终表（本件现核，★ = 与 W37 不同）**

| `_ResolvePlayCardFromHand_d__447:892`（state 6） | 1 | false | **1** |

### 2·2 拍点是**落地那一拍**，不是「落地拍之后 + 一段间隔」

W37 §4·2 写「把它排在落地拍之后（第二拍），⛔ 别和 fade-in 同拍」。**那句话本身没错，但「落地拍」指的是

| state 1：`SetUnitInPlayLayer` / `SetDefaultScale` / `HideCardShadow` → `WaitForSeconds(+0x154 = **0.05**)` | `HoldTime = 0.05` | 0.45 |
| state 2：`UpdateMinionInPlayPosition` → `WaitForSeconds(+0x150 = **0.2**)` | `LandTime = 0.2`（那条落地 tween） | **0.65** |

`+0x1a0 = 0x3dcccccd = 0.1`（`get_AttackStepTime` 读的就是 `+0x1a0`，replay-skip 时才除）。
