## ② 卡框透明度 —— **验了，结论：我们这条「条在上」是视觉等价**

**做法**：直接采样工程里那批卡框贴图（`Resources/Art/cards/frame_*.png`，全 **1024²**）的 alpha。

| 贴图 | 条带（底部 10%，= 512 帧的 y 461..511） | 对照：卡面中部（45–55%） |
|---|---|---|
| `frame_astramilitarum.png` | 不透明率 **0.337** · 平均 α **0.342** | 0.055 / 0.061 |
| `frame_ultramarines.png` | 0.263 / 0.271 | 0.087 / 0.096 |
| `frame_ultramarines_strat.png` | 0.289 / 0.289 | 0.071 / 0.079 |
| `frame_astramilitarum_strat_tier1.png` | 0.350 / 0.351 | 0.079 / 0.086 |

⇒ **那段不是透明条**：那是**卡框自己的下边框**（实心描边，覆盖 26–35% 的像素、平均 α 0.27–0.35）；
卡面中部反而几乎全透明（5–9%，那是留给立绘的窗口）。

### 结论（二选一，按你的判据走第二支）
- ❌ 不是「那段透明 ⇒ 视觉等价」。
- ✅ **是「那段不透明 ⇒ 原版条也看不见」那一支的**反证**—— 但方向相反：正因为那段**不透明**，
  若原版真按兄弟序让**卡体盖在条上**，`xN` 就会被这条实心下边框**盖掉**；而实拍里 `xN` **看得见**
  ⇒ **原版的有效先后必然是「条在卡之上」**（真实机制可能是卡体那些 Image 的**材质渲染队列更高**，不是兄弟序）。
  ⇒ **我们这条队列（`QPageRow` 3032 > 卡 3000）与原版的可见结果一致 = 视觉等价，不是偏离。**
- 断言 ④ 的文案已按这条改写（从「判据不可及 + 实拍佐证」→「卡框下边框实心（不透明率 26–35%）⇒ 原版必是条在上 ⇒ 我们等价」）。

⚠️ **仍然没读到的那一半**：**真实机制**（卡体 Image 的材质队列具体是多少、或 `2DCard` 子树有没有自己的 Canvas）—— 但这**不影响结论**（可见结果已由贴图 alpha + 实拍双向锁定）。
