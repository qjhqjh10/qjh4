## §三 `B120-E09` · AI 牌池两维（**结论与派活简报的前提不一致 —— 以代码与反编译为准**）

### 3·1 现码：两维 = **阵营 × 模式**，`difficulty` **不参与**

`BattleDriver.PickBotDeck(faction, gameMode, seed)`（`:34765`）→
`PrebuiltDecks.GetRandomDeck(new System.Random(seed), playMode: gameMode, faction: faction)`（`:34779`）→
`FilterDecks`（`PrebuiltDecks.cs:697`）六道：① 阵营 ② 远端名单（我们传 null）③ `!HasHidden`（= `complete`）④ 禁卡表（null）⑤ **模式** ⑥ **阵营**，再 `cand[rng.Next(cand.Count)]` 等概率取一副。
⇒ **`difficulty` 从头到尾没出现**（断言 C19 直接切 `FilterDecks` 方法体验「没有 `difficulty` 这个词」）。

本地数据 = `Resources/prebuilt_deck_lists.json`（`PrebuiltDecks.Decks` **224 副** / `BotDecks` **196 副**），分档交叉表与 `B120-OFF` §二·B **逐格一致**：
Classic `0/5/10/15 = 12/15/74/17`（**118**）· Skirmish `5/10/15 = 26/40/40`（**106**，**没有 SuperEasy**）。

### 3·2 原版：bot 挑牌链**也没有难度维**

`cpp2il/out_il2csharp/MatchData.cs:1155-1393`（`GetBotDeck(MatchType)` 全文）现读：

| matchType 分支 | 取牌 |
|---|---|
| Ranked(10) / RankedBot / Unranked / UnrankedBot | `GetRandomDeck(GetNormalBotConfig().botDecks, possibleArmies: null, CurrentEvent)` |
| PracticeOffline(50)（非 Classic 事件）· ClosedDeck(110) · ClosedDeckBot(120) · FastMode(200) · FastModeBot | `GetRandomDeck(botConfig.botDecks, null, CurrentEvent)`（FTUE 态先试 `GetBotConfigDecks(true)`） |
| Tutorial / TutorialReplay / Campaign | 关卡 SO 的 `aiDeck` |
| **其余（未识别的 matchType）** | **打 `Can't get bot deck for match type`，再退 `GetRankedBotPrebuiltDeck(...)`** |

而**按难度**的 `GetDeckByDifficulty(difficulty, playMode)` 只被 `GetRankedBotPrebuiltDeck`（`MatchData.cs:1395`）调用，后者**只出现在上表最后那一行**（6 处 unknown-matchType 兜底：`:1200/1237/1295/1325/1358/1389`）⇒ **正常局到不了难度那一支**。

⇒ **`B120-OFF` §二·B 那句「取牌规则 = `GetDeckByDifficulty`…」不完整**：它是**两条 picker 之一**，且是**兜底那条**；活支是 `GetRandomDeck`，而它按的是**服务器精选名单 `botConfig.botDecks`**（本地拿不到 ⇒ 我们已经按铁律 18 标了 `🔶 自己设计`）。

### 3·3 因此**没有**加难度闸（判据与简报冲突时的处理）

- 给 `FilterDecks` 加一道 `difficulty` 闸 = **造原版那条链没有的行为**（铁律 18·0「默认复刻原版」）。
- 现码本来就与原版活支**同形**（阵营/模式过滤 + 等概率）—— 差别只在：原版那道「命中 `selectableBotDecks` 名单」我们拿不到（远端 `AIBotsConfig`），且我们多一道**阵营**闸（🔶，2026-10-26 已裁）。
- ⇒ 本批**代码零改动**，只做三件事：① 断言钉住现状（含「难度不是筛选维」这一条）；② 订正 `PrebuiltDecks.GetDeckByDifficulty` 的 doc；③ 账补丁里订正两条过期账行。
