## 六、本会话新增坑

- **530** 好友关系原来只存本机 ⇒ 对方看不到（服务端对称表 + 客户端 60 s 拉取 + 运行时注入）
- **531** `Il2Cpp.perform` 是异步的 ⇒ 别包完立刻读返回值（计数/日志写在 perform 内部，Promise 挂 `.catch`）
- **532** 「每个新版本清空存档」必须靠构建标记，不能靠卸载（Android/media 是否随卸载删除看 ROM）
- **533** `AddressablesManager` 单例要用 `get_Instance` 取，`FindObjectOfType` 返回空；`ForceRelease(1)` = General 且是强制释放
- **534** 内嵌包启动等待用 `global-metadata.dat` 映射当就绪信号；内存分档只作附加保险
- **535** 安卓 JS 读内存只能走 `/proc/self/status`（Profiler getter 被裁剪、无 Java 桥）
- **536** 联盟是每设备本地数据 ⇒ 云端网页管不到，原版也没有「解散」
- **537** Firebase 离线必失败 ⇒ 掐 `FirebaseDataManager.InitializeFirebaseAuth`；`PlayerAuthentication` 要用全名
- **538** `UpdateGroupInfo` 的公告板 = `GroupData.desc`（实测 payload 已记）
