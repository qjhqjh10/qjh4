## 三、`OFF-185` 商店（本轮两次改判，务必看清）

### 3.1 S-01：**上一轮的「一页最多 8 个」是误判，已改判回单页 13 个**

上一轮判「第 9 个起滚不到」，依据是两份 `FlexibleGridLayout__SetLayout*.c`。**那是错的**：

- 那两个文件各只有 **61 字节**，函数体是 `void NetworkingPeer__OnMessage(void) { return; }`（**反编译失败产物**）；
- `il2cpp_out/dump.cs` 里 `RVA 0x4B33B0` 被 **1,992 个方法**共用 = IL2CPP **空方法桩**；
- 真正的摆位/撑开在 `CalculateLayoutInputHorizontal`（`SetChildAlongAxis` + `rectTransform.sizeDelta`）；
- **实测**：13 个一页时 `Content 2853x989` / 视口 `1598x1009`，**拖内容区能滚到最右**，第 9–13 个全部可买。

⇒ `gen_shop_data.py` 的 `split_store_into_pages()` 改名 **`normalize_pack_store()`**（只重建货架、**不切页**）。
坑 **233** 记了完整教训。

### 3.2 S-04：描述行缺失（根因不是版式）

`BoosterInfoPopup` 三个文本取**同一条事件数据的不同 label key**（`Title=0` / `SubTitle=2` / **`Description=1`**），
我们原来没给 key=1。且 `EventLabel.Value` 走 I2 `GetTermData`，**查不到词条返回空串**（实测写中文、写原版键都是空；
换成已存在的 `Armies/Ultramarines` 立刻显示「极限战士」才定案）。

⇒ 服务端补 `key=1`（`mTerm = ShopBooster/Description/<Army>`）+ 新探针
`Probes/ShopDescProbe.cs` 运行时 `AddTerm`+`SetTranslation` 注册 13 个词条（`WF_OFFLINE_SHOPDESC=0` 关）。

### 3.3 S-05：商店数据有**三份**（坑 231）

**三条都同步了**：本地内置重打；云端 `server.py` 从 **11-09 版**换成 11-14 版（拿到 `PurchaseItem` /

## 四、`OFF-186` 断线弹窗（新文件 `Probes/DisconnectPopupProbe.cs`）

### 4.1 原版是什么样（先查后改）

| 项 | 原版 |
|---|---|
| 链 | `BattleNetworkManager.EventDisconnected` → `BattleManager.ShowDisconnectionPopup` → `AttemptReconnect` |
| 倒计时 | `Math.Max(10, VarsGlobal.maxSecToReconnect - playerDisconnects * 3)`，**`maxSecToReconnect = 30`** |
| 按钮 | **一个都没有** |
| 超时 | `FailedToReconnectAfterDisconnect()` = `AddResignAction(true)` + `DeadHero(BattleResult.Disconnect)` ⇒ **判负** |

### 4.2 现口径（🔶 用户 2026-11-14 定，非原版）

```
第 1 次断线 60 秒 → 第 2 次 57 → 54 … 最低 10 秒
「重新连接」= 立刻再探一次（可反复点）
「放弃（判负）」= 立刻 GiveUp ⇒ 调原版 FailedToReconnectAfterDisconnect()
倒计时归零 = 自动判负（与原版同一出口）
服务器恢复 = 自动关窗 + RECOVERED（不判负）
```

🔴 **只在「在线对战进行中」监控**（三层闸）：`PhotonNetwork.inRoom` + `room.PlayerCount >= 2` +
场景名以 `Battle Arena` 开头。**离线游玩连不上云服务器 → 照常玩、不弹窗**。

### 4.3 本轮踩到的两个坑（已修，坑 234）

| 坑 | 现象 | 修法 |
|---|---|---|
| `ShowPopUp` 是**异步**建窗 | `_popup` 恒 null ⇒ 恢复时关不掉 | 每拍轮询 `WindowsManager.popUpWindow` 认领 |
| `SetActive(false)` 关窗留残影 | 弹窗没了但**背景一直模糊** | 改调原版 `WindowsManager.HidePopUp(forceHide: true)` |
