## 三、🔴 下一步的第一件事（新会话从这里开始）

**用户口径：必须先点「结算视频」，回主菜单才崩；不点视频不崩。**

推论链（已核实的客观事实）：

```
videos_assets_all.bundle 在 APK 里（13.5 MB）
  但 files/aa/assets/aa/Android/ 只有 3 个包（allcards / localization / alternateartstyles）
  ⇒ mod_assets.js 的 rewrite() 只改写「本地真存在」的 id ⇒ 其余走远端 URL
  ⇒ 离线 ⇒ 加载失败（日志：本地没有 videos_assets_all.bundle（交给 Unity 缓存））
  ⇒ EndBattleDoors 的 videoPlayer / renderTex 处于坏状态
  ⇒ 点过视频后回主菜单、场景销毁时炸
```

**做法（按顺序）**：

1. **把 APK 里的 84 个 bundle 全解到 `files/aa/assets/aa/Android/`**（至少先补 `videos_assets_all.bundle`），
   让 `rewrite()` 全部命中本地。然后测「打完 → 点视频 → 回主菜单」。**很可能这一条下去就不崩了。**
2. 若仍崩：探针挂 `EndBattleDoors` 的全部方法（`Awake` / `OnDisable` / `OnDestroy` /
   `SetupDoor` / `ShowRewards` / `HideRewardsObjects`）+ `ResourcesBarController.Initialize`，
   **在点了视频之后**跑一次，看死在哪。
3. ⛔ **不要再按「Toggle 摸死对象」改代码**（已证伪，见 §四）。
