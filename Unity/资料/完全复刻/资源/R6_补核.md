## §0 先给一条结构性结论（对全部 26 个都成立）

这 26 个 SO（13 卡背 + 8 RawCardScript + 1 异画 + 2 头像 + 2 徽章）在引用图上：

⇒ 它们只可能是 **`Resources.Load("<名字>")` 按名加载**（`sharedassets0.assets` 就是 player 的内置 Resources 文件）。
这也解释了为什么「卡牌 bundle + allcards」那条路**结构上搜不到**它们 —— 那是另一套入口。

### 3.3 判据：`gen_cards_engine.py` 该在哪一步、从哪个字段生成

- **数据源**：`cards_raw.json`（= 上面那个 allcards 包的导出）里每张卡的 **`alternateArts`**
  —— 类型是 `[{m_FileID, m_PathID}]`（纯 PPtr，**不含 id 字符串**）。
- **必须先有一张索引**把 PPtr 翻成 id：`_tmp_view/wfres/altart_index.json`（我已生成，
  `path_id → {uniqueId, style, name, cardImage, fullWarlordImage}`，7 条）。建议落到
  `数据/索引/altart_index.json`（数据侧拍板，我没往工程里写）。
- **插入点**：`工具/gen_cards_engine.py` 主循环构造 `entry` 的那一段 ——
  `:4539` `"cardTraits": _traits,` / `:4553` `"spellType": (...)` 之后（字典在 `:4554` 收尾）、`:4555` 的
  「卡能不能进卡组」之前，加一列：
  ```python
  "alternateArts": _alt_ids(trow),   # [altart_index[str(p["m_PathID"])]["uniqueId"] for p in trow["alternateArts"]]
  ```
  缺值必须落 **`[]`**（不是 `null`）：`CardDatabase` 的契约要求「`null` = 整列缺席」与「没有行 = `[]`」分开
  （这条契约在 `gen_cards_engine.py:3854` 那段注释里明写着）。
- **消费点**：目前 **0 个**。`alternateArts` 在 `MyGame/Assets/**/*.cs` 里**只出现 1 次** —— `Shell/DeckInfoPopup.cs:2044` 的**原版字段偏移注释**（`alternateArts(8，数组引用)`），**不是读它的代码** ⇒ 这一步**只落数据、不改行为**，
  接 UI（详情窗/收藏的异画切换）是另一笔。
- ⚠️ `currentAlternateArt` 在原版 7 张上**全是 null**（没有「默认选哪张」的偏好），别自己补一个。
