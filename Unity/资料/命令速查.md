> 所有命令的原文。⚠️ 跑 Unity 批处理前 `unset ELECTRON_RUN_AS_NODE`；**同工程同时只能一个实例**。

```bash
# Unity 批处理构建战场（🔴 2026-09-20：类改名 `BuildArena1` → `ArenaBuilder`；用**环境变量 `WF_ARENA`** 选场）
# 单场（不设 WF_ARENA 就是 battlearena1）：
unset ELECTRON_RUN_AS_NODE && WF_ARENA=battlearenaspacewolves "D:/Unity/Hub/Editor/6000.3.23f1/Editor/Unity.exe" \
  -batchmode -quit -projectPath "D:\4\Unity\MyGame" -executeMethod ArenaBuilder.BuildFromCLI -logFile -

# **13 场全建一遍**（串行、约 10 分钟）：
... -executeMethod ArenaBuilder.BuildAll -logFile -

# 渲染 13 场预览图 → `Assets/WarpforgeArena1/arenas/<场景名>/preview_<场景名>.png`
... -executeMethod ArenaBuilder.RenderAllPreviews -logFile -

# 生成某个战场的清单+资产（在 d:/2 跑；`--no-copy` 只写清单）
PYTHONIOENCODING=utf-8 d:/2/Warpforge_tools/py312/python.exe \
  d:/2/Warpforge_tools/scripts/gen_unity_arena_manifest.py --arena battlearenasororitas

# === 特效还原 ===
... -executeMethod EffectExporter.Run -logFile -                 # 导出效果（全量导出前把 EffectExporter.Limit 改成 -1）
... -executeMethod EffectCompare.Run -logFile -                  # 原版 vs 导出 并排渲染比对 → d:/4/_tmp_view/cmp/
... -executeMethod WarpforgeSetup.RegisterShaders -logFile -     # 新增/改名自建 shader 后，注册进 Always Included

# === 特效「能用」这一侧（详见 资料/特效还原_进度与交接.md 第五节）===
"D:/2/Warpforge_tools/py312/python.exe" d:/4/Unity/工具/gen_effect_index.py   # 导出集变了 → 重建索引 → 重建效果库（两步都要跑）
... -executeMethod EffectLibraryBuilder.Run -logFile -
# 白板自检：播→消失闭环 / 渲染与台账一致 / 反复播不泄漏（grep "^WB " 看结果）
... -executeMethod WhiteboardTest.Run -logFile "d:/4/_tmp_view/whiteboard.log"
# 🆕 抓屏扭曲定位（三种纯色背景 + 一块不透明棋盘，量「相对空场景的贡献」）；图在 _tmp_view/distort/
... -executeMethod DistortProbe.Run -logFile "d:/4/_tmp_view/distort.log"
#    筛输出：grep "^DP "；退出码 0 = 断言全过；**断言条数看自检打印的那一行，别写死**

# 🆕 挂上抓屏 Feature（**幂等**，重复跑不会加两份）—— 把 GrabPassTransparentFeature 加进两个 Renderer 的
#    rendererFeatures；手动在 Inspector 里加也行，但那是「下个会话不知道做过没有」的改动 ⇒ 用这个入口
... -executeMethod WarpforgeSetup.RegisterRendererFeature -logFile -
# 🆕 混合状态 + shader 解析的**常驻守卫**（**改 shader/binder 之后必跑**）
... -executeMethod BlendProbe.Run -logFile "d:/4/_tmp_view/blend.log"
#    筛输出：grep "^BP "；退出码 0 = 断言全过；报告 _tmp_view/blend_report.tsv
# 🆕 **点名验「每个原版 shader 名都解析得到」**（`BlendProbe` 那段是拿报告里的名字试的，会漏）：
... -executeMethod ShaderResolveProbe.Run -logFile -

# 🆕 读任意原版 shader 的属性表 + pass 状态（**动手改自建 shader 之前先跑它**）
"D:/2/Warpforge_tools/py312/python.exe" d:/4/Unity/工具/dump_shader.py "Particle Distortion"
# 生成人看的白板场景 → Assets/WarpforgeArena1/Scenes/VFXWhiteboard.unity
... -executeMethod WhiteboardBuilder.Run -logFile -

# 重跑场景清单生成器
"D:/2/Warpforge_tools/py312/python.exe" d:/2/Warpforge_tools/scripts/gen_unity_arena_manifest.py

# === 规则引擎（详见 资料/规则引擎_进度与交接.md 第三节）===
# ⚠️ 下面所有 python 工具**必须带 PYTHONIOENCODING=utf-8**（脚本里有 ⚠️ 这类字符，
#    GBK 控制台会在**写文件之前**抛 UnicodeEncodeError）
# 卡表精简（改了 card_stats.json 或 数据/卡牌翻译/zh_cards.json 之后重跑；--check 只对账不写文件）
PYTHONIOENCODING=utf-8 "D:/2/Warpforge_tools/py312/python.exe" d:/4/Unity/工具/gen_cards_engine.py
# 🆕 卡面图标的计划表（改了任何卡的 desc / descZh 之后**必须跟着重跑**，两步）—— 判据与坑见 §七
PYTHONIOENCODING=utf-8 python Unity/工具/gen_icon_plan.py --write   # 落盘（不加 --write 是干跑）
PYTHONIOENCODING=utf-8 python Unity/工具/gen_icon_doc.py           # 人看的对照文档
# 原版美术同步进 gitignore 的 Resources/Art/（幂等；卡框/卡背/插图的做法见 §七）
"D:/2/Warpforge_tools/py312/python.exe" d:/4/Unity/工具/import_original_art.py
#   ⚠️ **导完美术必须再跑一次这个**（否则新 PNG 没开 Read/Write —— 见 §七）
... -executeMethod ArtBaker.ApplyImportSettings -logFile -
# 配不上的插图摊成人能看的（原版卡面 + 候选插图 + README）→ Unity/资料/待人工对_插图/
#   ⚠️ 那个目录在 .gitignore 里（全是原版资产）
"D:/2/Warpforge_tools/py312/python.exe" d:/4/Unity/工具/collect_unmatched_art.py
# 规则引擎自检（纯逻辑，很快）
... -executeMethod RuleEngineTest.Run -logFile "d:/4/_tmp_view/ruleengine.log"
#    筛输出：grep "^RE " d:/4/_tmp_view/ruleengine.log；退出码 0 = 全过，1 = 有失败
# 🆕 逐句解析探针（改 EffectText 的判据之前/之后拿来量）
#   写 d:/4/_tmp_view/probe_in.txt（一行一句，`#` 是注释）→ 跑 → 读 probe_out.txt
#   （卡级判定 + 逐段判定 + 每条 op 摊平；**只读文件、不碰工程**，可以反复跑）
... -executeMethod EffectParseProbe.Run -logFile -
#    筛输出：grep "^EP "；退出码 0
# 卡牌基座自检（**棋盘格数改过就要复跑**）
... -executeMethod CardBaseDemo.Run -logFile -
#    筛输出：grep "^CBD "；🆕 **判据看 `=== 合计：N 通过 / M 失败 ===`，退出码 0 = 全过**
#    （⚠️ 这两样是 2026-09-17 才有的 —— 在那之前它**一个断言都没有**，只是截图生成器）

# === 可玩对战（详见 资料/规则引擎_进度与交接.md 第一节）===
# 重建「能玩的那个场景」→ Assets/CardPresentation/Scenes/Battle.unity，打开按 Play
... -executeMethod BattleScene.BuildAndSaveScene -logFile -
# 卡组编辑自检（规则/筛选/加删牌/翻页/版面 + 截图）
... -executeMethod DeckScene.Run -logFile "d:/4/_tmp_view/deck.log"
#    筛输出：grep "^DK "；断言条数看自检自己打印的那一行（**别在这里写死**）
# 重建卡组编辑场景 → Assets/CardPresentation/Scenes/DeckEditor.unity
... -executeMethod DeckScene.BuildAndSaveScene -logFile -

# 对战自检：开局/拖拽/费用拒绝/出牌/攻击/护卫/技能与触发/打完整局/原版卡牌/卡组库那套牌/战术卡拖出去打
#   （断言数见 `资料/阵营推进_清单与交接.md` §一 ⚠️ 2026-09-16：原写 §五，实为 §一；另出 16 张截图）
... -executeMethod BattleScene.Run -logFile "d:/4/_tmp_view/battle.log"
#    筛输出：grep "^BT "；图在 d:/4/_tmp_view/battle/
#    ⚠️ 它**退出时可能 segfault**（崩在 Unity 关停之后）—— **判据看 `BT === 合计` 那一行，别看退出码**

# === 结算「开门」视频（详见 资料/规则引擎_进度与交接.md）===
# 视频元数据自检（阻塞、秒回；断言源尺寸 3840×1080 / 片长 / 帧数与原版元数据一致）
... -executeMethod VideoProbe.Run -logFile "d:/4/_tmp_view/videoprobe.log"
# 真播 + 左右拼 alpha 合成 + 像素断言 + 结算界面实拍（~30 秒）—— ⚠️ 不能带 -quit
... -executeMethod VideoProbe.Play -logFile "d:/4/_tmp_view/videoplay.log"
#    筛输出：grep "^VP "；图在 d:/4/_tmp_view/video/
#    视频本体在 gitignore 的 Resources/Art/videos/，从 素材/Warpforge原版/视频/videos/ 拷（改名 .webm）

# 从档案库同步资源（幂等）
"D:/2/Warpforge_tools/py312/python.exe" d:/4/Unity/工具/sync_from_d2.py --batch all

# === 进原版游戏（看"原版到底长什么样"的标准答案）===
# ⚠️ 必须先设 DOTNET_ROOT，不设起不来；副本路径必须纯 ASCII（MelonLoader 的 plthook_open 怕中文）
taskkill //IM Warpforge.exe //F
cd /d d:\2\unity_run_ref && set DOTNET_ROOT=<本机 dotnet 根> && start "" Warpforge.exe
# mod 配置：d:/2/unity_run_ref/UserData/sjs_dump_cfg.txt  四行：
#   第1行=bundle 名（写 scenes_scenes_mainmenuwarpforge.bundle 就进主菜单）
#   第2行=进场景后等几秒   第3行=**输出目录（归档位，别改回 `_tmp_view/orig`，那儿会被当垃圾清）**
#   第4行=动作：drive＝战斗驱动全套 / 空＝只 dump 一次+截一张 / 秒数列表如 45,75,105,135＝多时间点各一份
# 产出：runtime_ui_dump_*.tsv（UI 树，带 activeSelf 和 sprite 名）+ 真渲 PNG
# ⚠️ 战斗 UI 的「内容」出不来（要对局数据）—— 但 3D 战场是对的，UI 树里的 rect 也全是真的。
# ⚠️ 验不了的（实测，别再撞）：手牌注入（原版关服、卡数据在远程 CCD）、卡组编辑界面（实例化即黑）、
#    主菜单只拍得到顶栏、改游戏数据、ScreenCapture 截图会崩
```
