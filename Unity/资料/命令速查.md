## 🆕 **反编译里那些 `DAT_18xxxxxxx` 怎么解出它到底是什么**（2026-10-15 造 · 两条 recipe）

> 触发 = `A2111`：C1 报告留了个前提「`InitializeCardForDisplay` 写的若不是 `_ShadowColor` 则阴影色那条不成立」，
> 而反编译只给到一个**属性 ID 的地址**。两条 recipe 都是**当天现解出来、并互相印证过**的。

### 一、`Shader.PropertyToID(<字面量>)` —— 地址 → **字符串**

**症状**：反编译里写的是 `uVar1 = UnityEngine_Shader__PropertyToID(DAT_184240978, 0);`，
`DAT_184240978` 是 `.data` 里的一个 8 字节槽，`strings` / `grep` 在 DLL 里**一个都搜不到**（字符串不在 DLL 里）。

**为什么搜不到**：il2cpp 的字符串字面量**存在 `global-metadata.dat`**，DLL 那个槽里放的是**元数据 token**。

**两步**：

```bash
# ① 读那个槽的 8 字节（RVA = 地址 − ImageBase(0x180000000) → 查 PE 节表换成文件偏移；同一套办法见本文件「`_DAT_*` 常量」那节）
python -I -X utf8 - <<'PY'
import struct
b = open(r"d:/2/unity_run_ref/GameAssembly.dll", 'rb').read()
IMG = 0x180000000
pe = struct.unpack_from('<I', b, 0x3c)[0]
nsec = struct.unpack_from('<H', b, pe + 6)[0]; optsz = struct.unpack_from('<H', b, pe + 20)[0]
sec = pe + 24 + optsz
secs = []
for i in range(nsec):
    o = sec + i * 40
    vsz, va, rsz, raddr = struct.unpack_from('<IIII', b, o + 8)
    secs.append((va, vsz, raddr, rsz))
def rd(va, n):
    rva = va - IMG
    for sva, svsz, sra, srsz in secs:
        if sva <= rva < sva + max(svsz, srsz):
            return b[sra + (rva - sva): sra + (rva - sva) + n]
for va in (0x184240978, 0x184237790):        # ← 换成你要解的那个 DAT_
    print(hex(va), hex(struct.unpack('<Q', rd(va, 8))[0]))
PY
```

```bash
# ② token → stringLiteral 下标 → 字符串
#   编码实测：token 的低 30 位右移 1 位 = 下标 —— **即 (token & 0x1FFFFFFF) >> 1**
python -I -X utf8 - <<'PY'
import struct
b = open(r"d:/2/unity_run_ref/Warpforge_Data/il2cpp_data/Metadata/global-metadata.dat", 'rb').read()
litOff, litSz     = struct.unpack_from('<II', b, 8)     # header 是 (offset,size) 对数组
litDataOff, _     = struct.unpack_from('<II', b, 16)
def txt(k):
    L, di = struct.unpack_from('<II', b, litOff + k * 8)
    return b[litDataOff + di: litDataOff + di + L].decode('utf-8', 'replace')
print(txt(19898))     # ← 换成 ① 算出来的下标
PY
```

**本次的两条实测（可当自检对照）**：

| `DAT_` | 槽里的 qword | `(t & 0x1FFFFFFF) >> 1` | 解出来 |
| --- | --- | --- | --- |
| `DAT_184240978`（`Card2DController + 0x80`，`ChangeShadowColor` 用） | `0xA0009B75` | **19898** | **`_ShadowColor`** |
| `DAT_184237790`（`Card2DController + 0x84`，`ChangeHighlightColor` 用） | `0xA0009A51` | **19752** | **`_Outline`** |

✅ **自洽旁证**：这个 stringLiteral 表**是按字母序排的**（下标 19740–19905 是 `_OffsetSize`…`_ShadowLightIndex` 连续字母序）
⇒ 解出来的两个名字**落在同一段、且语义与调用点吻合**（`ChangeShadowColor`→`_ShadowColor`、`ChangeHighlightColor`→`_Outline`）。

### 二、`LayerMask.GetMask(<DAT>)` / `System_String__Equals(<DAT>)` —— **十进制首列直接查**

**更省事的一条**：`d:/2/tools/all_strings.txt` 的**十进制首列 = `地址 − 0x180000000`**。
拿到 `DAT_18xxxxxxx` 直接算差、在首列搜那个十进制数即可，**不用碰 DLL / metadata**。

实测对照两例：`DAT_184294bb8` → `69815224` → **`"BoardCardLimit"`**；`DAT_184272698` → `69674648` → **`"Default"`**。

⚠️ 这一条**优先用它**（一条 grep 就完事）；解不出来（该地址不在表里）再走上面那两步。

⚠️ **顺带一条坑**：`"Default"` 这个字面量在 **Sorting Layer 名**与**物理层名**两种用途间被 il2cpp **去重共用**
（`GameStaticData.GetLayerId` 认的那批 `Settings/Hand/Background/…` 是 **Sorting Layer** 名，
与 `TagManager_3.json` 的 `m_SortingLayers` 逐字相同）⇒ 读到 `"Default"` **别一律当物理层**。

## IL2CPP → C# 反编译（2026-10-25 第七十八会话实测 · 判据 → `资料/反编译工具链_IL2CPP转CSharp_调研与实测_1025.md`）

- 🔴 **官方 release 的 Cpp2IL 出不了方法体**（`dll_il_recovery` 在发行版里是**空壳**，写死 `ldnull; throw`，
  pre-19/20/21 都一样）⇒ **要方法体必须用自建的 `D:/2/tools/cpp2il/bin_dev/Cpp2IL.exe`**。
- 装在哪：`D:/2/tools/cpp2il/Cpp2IL.exe`（发行版，只给签名）· `D:/2/tools/cpp2il/bin_dev/`（★ 自建，真方法体）·
  `D:/2/tools/ilspycmd/ilspycmd.exe`（ILSpy 11.1.0.9782）· `D:/2/tools/il2csharp_src/`（替补，纯 Python）。

```bash
# ① 签名级 dummy DLL（7 秒；查类名/字段/方法签名用它）
cd D:/2/tools/cpp2il
./Cpp2IL.exe --game-path "D:/2/unity_run_ref" --output-as dll_empty --output-to "D:/2/tools/cpp2il/out_cpp2il"

# ② ★ 带真实方法体的 DLL（16 秒；日志末行应见 100% of methods successfully decompiled）
cd D:/2/tools/cpp2il
./bin_dev/Cpp2IL.exe --game-path "D:/2/unity_run_ref"   --output-as dll_il_recovery --output-to "D:/2/tools/cpp2il/out_cpp2il_dev"

# ③ DLL → C#：单个类（快）
"D:/2/tools/ilspycmd/ilspycmd.exe" -t BasicCardUI   --referencepath "D:/2/tools/cpp2il/out_cpp2il_dev"   "D:/2/tools/cpp2il/out_cpp2il_dev/Assembly-CSharp.dll"

# ③' DLL → C#：整工程（2,404 个 .cs + .csproj，1～2 分钟）
"D:/2/tools/ilspycmd/ilspycmd.exe" -p -o "D:/2/tools/cpp2il/out_cpp2il_dev_ilspy"   --referencepath "D:/2/tools/cpp2il/out_cpp2il_dev"   "D:/2/tools/cpp2il/out_cpp2il_dev/Assembly-CSharp.dll"

# ④ 替补：il2csharp（纯 Python，需 `pip install --user iced-x86`；Assembly-CSharp 约 5 分钟）
cd D:/2/tools/il2csharp_src/il2csharp-main
python il2csharp.py "D:/2/unity_run_ref" --only Assembly-CSharp   -o "D:/2/tools/cpp2il/out_il2csharp" --workers 0 --json
```
