## 一、为什么它能离线跑（不是巧，是工程规矩）

`RuleEngine/Core/` 有一条**成文铁律**：**只许碰 `UnityEngine.Debug` / `UnityEngine.Random`**。
它写在 `TutorialScript.cs:344-352`（那里把 `Resources`/`JsonUtility` 用 `#if` 包起来，并解释了原因），
并在 Core 各文件头注逐条重申：`BattleEvent.cs:12` · `CreatePool.cs:22` · `CardDef.cs:6` · `WhenEvent.cs:3` ·
`RuleCore.cs:13` · `EffectText.cs:18` · `GivePayload.cs:17` · `EffectSpec.cs:22` · `DeckRules.cs:1`。

**实测口径**（`grep -rho "UnityEngine\.[A-Za-z_]*"` 全目录统计，`using UnityEngine` 出现 **0 次** ⇒ 全是全限定名）：

| 引用 | 次数 | 性质 |
|---|---|---|
| `Debug.LogWarning` | 6 | 真调用（`BattleContext.cs:1336` · `GameplayVariables.cs:76` · `TutorialScript.cs:633/862/871/905`） |
| `Debug.LogError` | 4 | 真调用（`BoardSlots.cs:163` · `TutorialScript.cs:392/400/412`） |
| `Debug.Log` | 1 | 真调用（`RuleCore.cs:397`） |
| `Random` | 10 | 🔴 **全是注释**（代码刻意走 `ctx.Rng`；注释在劝阻用它） |
| `Resources` / `TextAsset` / `JsonUtility` | 各 1 | ⚠️ 真调用，**但被 `#if UNITY_5_3_OR_NEWER` 关着** |

⇒ **真实可编译的面 = 4 个成员 / 11 个调用点** ⇒ `Stub.cs` 三十行足够。

🔴 **推论（别踩）**：⛔ **绝不要**给探针加 `<DefineConstants>UNITY_5_3_OR_NEWER</DefineConstants>`。
那会打开 `TutorialScript.cs:385` 那条 `#if` 支（`Resources.Load` → `JsonUtility.FromJson`），
等于把这条工程规矩的地雷重新埋回去。Unity 侧那份 `_wfcheck.csproj:23` 定义了 300+ 个符号，
**探针故意一个都不定义**。

## 三、判据：两个数必须分开数

**摘要行**：

```
=== 全池 1120 张 · 解析差异 0 行 · 改名 0 行 · 新增 0 · 消失 0 · 基线 out_baseline.txt ===
```

- **解析差异** = 第 2 列往后变了 ⇒ **红**（逐行看：是修基线，还是修解析器）
- **改名** = 只有第 1 列（`id|name`）变了 ⇒ **黄**（本工程每批都在改卡名 / 重跑产物，通常无害）
- 退出码：`0` 解析差异 0 · `1` 有解析差异 · `2` 基线缺失

🔴 **为什么不能"逐字节相同"**（这是收编时最大的陷阱）：`scan` 的第一列含**卡名**，而卡名是**会变的产物**
（B16/B20 两批共改 6 张：`Dogmata`→`Sister Dogmata` · `Land Raider`→`Land Rider` · …）。
原样收一份旧基线 ⇒ **第一天就红，而且红的是噪声** —— 那会把「红了不用管」训练成习惯，**比没有基线更坏**。

**三态已实测（2026-10-18）**：绿（0/0/退 0）· 黄（改名 1/解析差异 0/退 0）· **红（解析差异 1/退 1）**。

## 四、三个坑（收编时全修了，别再踩回去）

| 坑 | 症状 | 根因 |
|---|---|---|
| `unparsed` 列恒为字面量 | 每张卡都是 `System.Collections.Generic.List\`1[System.String]` | `.Append(List<string>)` 命中 `StringBuilder.Append(object)`。**更要命**：`unparsed`（「没解析出来的碎片」）被整个丢掉 ⇒ B14 那次「1121 张只有 2 行不同」**对未解析碎片是瞎的**（不推翻结论，只是把覆盖面缩小） |
| 中文输出 GBK | 摘要行读不了 | 本机默认编码；`Console.OutputEncoding = UTF8` 修 |
| 退出码恒 0 | FAIL 45 条也退 0 | `Main` 是 `void`。**同族血案**：`_run_8_checks.sh:13-22` 记着「`$?` 被 `$(date)` 吃掉 ⇒ 编译错误也报 0」，`typecheck.sh:68-70` 也为此收紧过判据 |

## 五、与 `RuleEngineTest.Run` 的分工

| | ruleprobe | `RuleEngineTest.Run` |

⇒ 两者**不是替代关系**。探针绿 **不**等于自检绿；探针只是让你别为看一眼而等四分钟。
