## 〇、三句结论

1. **洗回（`shouldReshuffle`）= 纯服务器值，本地没有任何真值**：字段在 `GameplayVariablesData +0x48`，唯一的读点是
   `BattleManager._ResolveDrawCard`；它由 LiveOps 事件载荷 `PlayEventData.gameplayVariables` 下发，本地解包树/缓存/存档
   全盘 0 命中，类定义里也没有任何初始化器（默认 `false`）。⇒ 我们 `GameplayVariables.shouldReshuffle = true`
   那句「经典原版为 true」**没有任何本地判据支撑**，不要拿它当原版事实。
2. **psychic / plasma 在当前 build 是【死功能】**：`EntityScript.UsesPsychicEnergy()` 编译后就是 `xor al,al; ret`（恒 false），
   `ManaBuff.psychicMana/plasmaMana`（`+0x19/+0x1a`）**没有任何读者**（`ProcessManaBuff` 只读 `+0x1b/0x1c/0x1d`），
   全卡池 0 张 psyker/reactor、0 张 PlasmaPower、0 个 psychic/plasma 主动技能。⇒ **我们完全不建模 psychic/plasma，
   今天的可观察行为与原版一致，不需要补**（W58 报告把它列成「缺口」应改成「原版已死/本地无需建模」）。
3. **伏击【没有】回合开始自动揭示**：二进制直接调用点扫描证明 `CardScript.SetAmbush` 全库**只有 7 个调用点**
   （4 个 `SetAmbush(true)` 都是"面朝下打出场"，3 个 `SetAmbush(false)` 全在**攻击/受伤**路），回合开始/`BroadcastTurnStart`/
   `OnTurnStart`/`OnTurnSetup` **一个都没有**。⇒ 我们 `BeginTurn` 里那句 `RevealAmbush` 是**按粉丝规则书自造的行为**，
   应删；原版的翻开条件只有「用它攻击（攻击被取消）」与「它挨到伤害」，并且 **`Ambush` 能力只在【卡主自己的回合】被翻开时才触发**。

## 二、② psychic / plasma 两种法力

### 2.1 结论（这一条推翻了 W58 报告「未建模 = 缺口」的口气）

**当前 build 里它是死代码/遗留功能**：

- `UsesPsychicEnergy()` **恒 false**（机器码字面量 `xor al,al; ret`）；
- `UsesPlasmaEnergy()` 只对 `cardType==Tactic(20) && spellType==PlasmaPower(95)` 为真 ⇒ **卡池 0 张**；
- 主动技能的 `psychicCost/plasmaCost` 全卡池 **0 个 true**；
- 生成端（Psyker 620 / Reactor 625）**卡池 0 张**；
- 初始化（督军 `initialPsychicModifier/initialPlasmaModifier`）**1351 张全 0**；
- 就算有卡面效果 `manaBuff.psychicMana/plasmaMana=true`（卡池 0 张），`ProcessManaBuff` **根本不读这两个 flag**
  ⇒ 会退化成**加普通法力**（`ManaBuff` 构造器默认 `createMana=refillMana=true`）。

⇒ **我们的 `PlayerState` 只有 Energy/Faith/SpiritStones/QuestPoints 是正确的可观察行为**；
池内 6 张 `PsychicPower` 卡在原版也按**普通法力**判/付（因为 `UsesPsychicEnergy` 恒 false）——
我们现在的「普通 tactic + 普通能量」**恰好对上**。

## 三、③ 伏击（Ambush）揭示时机

### 3.1 结论（二进制调用点扫描，**不是** `.c` 的文本 grep）

`CardScript.SetAmbush(bool)`（VA **`0x1805FB1F0`**）在整份 `GameAssembly.dll` 的**直接调用点只有 7 个**：

| # | 调用方 | `true/false` | 语义 |
|---|---|---|---|
| 1 | `BattleManager.<ResolvePlayCardFromHand>d__447.MoveNext` (+0x32E) | `true` | 从手牌打出时**面朝下**（`HasCurrentTrait(0x4b0)` 才走） |
| 2 | `BattleManager.<ResolveSummonUnit>d__510.MoveNext` (+0x45D) | `true` | 召唤时面朝下 |
| 3 | `BattleManager.<ResolveCardAutoSummoned>d__511.MoveNext` (+0x46F) | `true` | 自动召唤时面朝下 |
| 4 | `BattleManager.ResolveTransformUnit` (+0x1266) | `true` | 变身成伏击单位时面朝下 |
| 5 | `CardScript.ResolveUnitAttacked` (+0x4DE) | **`false`** | **攻击**（actingCard == this）后翻开 |
| 6 | `CardScript.ResolveDamageDealt` (+0x580) | **`false`** | **挨到伤害**后翻开 |
| 7 | `BattleManager.<ResolveAttack>d__438.MoveNext` (+0x537) | **`false`** | **伏击单位发动攻击**时：攻击被取消 + 翻开 |

**回合开始路径（`NextTurn` / `BroadcastTurnSetup` / `BroadcastTurnStart` / `CardScript.OnTurnStart` / `CardScript.OnTurnSetup`）
一个调用点都没有。** ⇒ **原版没有「撑到自己的下个回合自动翻开」这条规则**。
粉丝规则书 `:166` 的后半句「若未被伤害：翻开并触发效果」**在这个 build 里没有实现**（实机表现是：面朝下的单位
一直藏着，直到你用它攻击、或者它挨到伤害）。

### 3.2 原版完整的翻开/触发语义（实读）

**`CardScript.SetAmbush(false)`（`CardScript__SetAmbush.c:69-129`）**：
1. 摘 `ambush` trait（1200 / `0x4B0`）、恢复卡面/数值、更新 trait 图标；
2. 若场上还有别的伏击单位 ⇒ 只改 UI；否则 `PlayerManager.ToggleCurrentMana(...)` 重算法力显示；
3. `CemeteryManager.AddExitAmbushActionToCemetery`（战斗日志 `Battle/Cemetery/ActionExitAmbush` = "{0} exits from Ambush"）；
4. **触发闸**：`isPlayer(+0x40) == IsPlayerTurn()` 时 → `RawCardScript.OnTrigger(0x29E = AbilityTrigger.Ambush(670))`。
   - `IsPlayerTurn()` 读 `BattleManager.playerTurnFlag(+0x274)`（`BattleManager__IsPlayerTurn.c`），
     该值在 `_NextTurn:257` 由 `NextTurn(bool isPlayerTurn)` 的入参写入 ⇒ 就是「**本地/该侧玩家是不是当前行动方**」。
   - ⇒ **只有当"翻开发生在卡主自己的回合"时，`Ambush:` 后面的效果才触发**；对手回合挨打翻开 = 只露脸、不触发。
   - 这与官方本地化文案 `CardTraitDescription/ambush` = “Troop is deployed hidden in play until interacted with,
     **trigger X when revealed during your turn**” 完全吻合（`官方本地化_en+zh-CN.json`）。

**三条翻开路（实读）**：
- (a) **用它攻击**：`_ResolveAttack:288-305` —— 攻方有 `ambush` 且在 play ⇒ `CancelAttack(攻方)` + `ClearPendingDamage(攻方)` +
  `ClearPendingDamage(目标)` + `SetAmbush(攻方,false)`。**这一记攻击不出任何伤害**，随后触发 `Ambush` 能力（因为发生在自己的回合）。
  （另有 `ResolveUnitAttacked:95-111`：广播发给每张牌时，`actingCard == this` 且未致死 ⇒ 同样 `SetAmbush(false)`。）
- (b) **它挨到伤害**：`ResolveDamageDealt:167-176` —— `damagedCard == this` 且 `cardState ∈ {2,0xf,3,0x11}` ⇒ `SetAmbush(false)`。
  ⇒ 若伤害发生在**自己的回合**（典型：GSC5 `Concealed Explosives`「Takes 1 damage at the start of your turn」），
  **翻开 + 触发**；发生在对手回合（被攻击掉血）⇒ **只翻开、不触发**。
- (c) **显式"触发伏击能力"**：`AddTriggerAmbush`（action `0x53`，能力逻辑 `0x1d1`）→ `BattleManager.ResolveTriggerAmbush` →
  `CardScript.TriggerAmbush()` → `OnTrigger(0x29E)`，**不改变是否面朝下**（例：GSC71 `Atalan Leader` 的
  `Strike: Trigger the Ambush abilities of all friendly troops`）。
