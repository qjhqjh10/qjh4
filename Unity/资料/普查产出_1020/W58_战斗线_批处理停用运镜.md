## 结论

1. **批处理生产路径已彻底停用**：`CameraIntro.Play` 在 `Application.isBatchMode` 下只做「记本位 / 建 clip / 绑光晕」的记录，
   **不置 `_playing`、不写位姿、`Tick` 整条不跑**（新增 `_batchSuppressed` 兜底，连「播完后每帧乘光晕」那一支也不跑）。
   `CameraIntroForTest.IsPlaying == false`、`Elapsed == 0`、`boardCam` 保持本位 `(0, 2.222075, −13.57198)`。
2. **真机行为零差异**：非批处理仍走 `Sample(0)` + `_playing = true`，`Update → AdvanceTimeline → Tick` 照旧逐帧推进。
3. **T12 接线 / 黑场同帧 / 重入断言全部保留**（没有删、没有改成恒真），改成「先验接线 + 批处理不起播，再**显式**走测试口起播」。
4. `typecheck.sh`：**运行时 0 / 编辑器 0**。⛔ 未跑 Unity（留给主对话统一复跑）。

## 批处理停用改法

### `Battle/CameraIntro.cs`（LF）

- `Play(...)` 变成薄壳：`return PlayCore(..., allowInBatchMode: false);`；
  新增私有 `PlayCore(..., bool allowInBatchMode)` 承接原方法体（`CameraIntro.cs:238-241` / `:246` 起）。
- `PlayCore` 末尾（原「只跳过 `Sample(0)`」那一段整段重写）：
  ```
  if (Application.isBatchMode && !allowInBatchMode)
  {
      _batchSuppressed = true;
      return true;   // clip/本位/ClipLength 已就绪，但没起播
  }
  _playing = true;
  if (!Application.isBatchMode) Sample(0f);
  ```
  ⇒ 批处理 **不建播放状态、不写位姿**。
- 新增字段 `bool _batchSuppressed`；`Tick` 在 `_cam == null` 之后立刻 `if (_batchSuppressed) return;`
  ⇒ **不再 tick**（相机、光晕都不动）。`Stop(...)` 里一并清零该标志。
- `StartForTest(...)` 改为 `PlayCore(..., allowInBatchMode: true)` ⇒ **自检口仍能在批处理下真播、逐帧推**
  （位姿 / 光晕 / 灭自证那几条靠它，保持绿）。
- 文件头「【泵】」一段补了生产修复②的判据与踩坑（实测一片红的清单）。

### `Battle/BattleDriver.cs`（CRLF）

- `StartCameraIntro` 开头记下这次调用的入参：`_cameraIntroKey` / `_cameraIntroFlareHost`（新增两个字段）。
  生产路径仍照旧懒建组件并调 `Play` —— 批处理下由 `PlayCore` 抑制。
- 新增自检口：
  ```
  public bool StartCameraIntroForTest()
      => _cameraIntro != null && boardCam != null
         && _cameraIntro.StartForTest(_cameraIntroKey, boardCam, _cameraIntroFlareHost);
  ```
  场键/光晕宿主取 `Begin` 里那次的原值（⛔ 不另算一份）。

## 4 条断言改法（`BattleScene.cs`，CRLF；T12 段）

> 实际受影响 **5 条**：题面那 4 条（接线 / 黑场同帧 ×2 / 重入）＋ **重入前提**（它也要「先把运镜推到中途」，
> 生产路径停用后同样变红）。全部**保留原语义**，只把「靠 `Begin` 自动起播」换成「显式测试口起播」。

| 原断言 | 改后 |
|---|---|
| `:18104` **接线**「`Begin` 之后已在播（t≈0）」 | 拆成两条：① `Begin` 把运镜挂到 `boardCam`（场键 ∈ 13 场表 + `ClipLength > 0`）+ **`IsPlaying == false`** + 相机在本位；② `StartCameraIntroForTest()` **显式起播**后 `IsPlaying && Elapsed < 1e-4` |
| `:18120` **黑场 0.625 s 同帧**「α≈0.5 且仍在播」 | 断言正文不变；前面新增一次显式 `StartCameraIntroForTest()`（批处理生产路径不起播） |
| `:18124` **黑场 1.625 s**「α<0 且仍在播」 | 同上，随显式起播后的 `Step` 走 |
| `:18144` **重入**「第二次 `Begin` ⇒ 复位本位 + t=0 重播」 | 先验 `Begin` 后相机**确实回到本位**（`Stop(resetHome:true)` 生效且生产路径不起播），再显式起播验 `IsPlaying && Elapsed < 1e-4 && HomePosition == 本位` |
| `:18139` 重入**前提**（推到中途，离本位 > 1） | `Begin` 后加显式起播再 `Step(0.625)`；`t12MidStarted` 一并进断言 |
| `:18130` 播完回本位 | 正文不变（显式起播后 `Tick` 照常推到终帧） |

另：该段 5 处独立的 `CameraIntro.Play(...)`（pose / 灭自证 / 光晕 ×2 / 无光晕）改为 `StartForTest(...)` ——
它们是「显式测试」而不是生产路径；不改的话光晕那两条会因批处理停用而变红。
