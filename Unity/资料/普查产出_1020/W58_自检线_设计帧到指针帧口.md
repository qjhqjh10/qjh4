## 一、换算恒等式（2026-10-20 现核）

**源码链**（逐句读过）：

| 量 | 式子 | 出处 |
|---|---|---|
| 设计帧点（乙式） | `PixelOfDesign(PosInDesignSpace(t))`；`PosInDesignSpace(t) = t.position / t.parent.lossyScale`（逐分量） | `Shell/MenuDraw.cs:71` · `:629` |
| 画布 px 换算 | `ToDesignPixel(w)` = `(w.x × PxPerWorldX + 960, 540 − w.y × 108)` | `Core/LayoutSpace.cs:299` |
| 指针帧点 | `ToDesignPixel(裸 t.position)`（**不除**父链缩放） | `Editor/MenuCheck.cs:206` · 同帧于 `Shell/PointerLayer.cs:1071` |
| 生产侧同形仿射 | `c + (v − c)·m`，`c = (DesignPxW/2, DesignPxH/2)` | `Shell/PointerLayer.cs:452/459`（`DesignToPtrPx` / `ScaleAbout`，`private`） |

设 `p = t.position`、`k = t.parent.lossyScale`（逐分量）：

```text
DesignPx(t)       = ToDesignPixel(p / k)
PointerFramePx(t) = ToDesignPixel(p)
ToDesignPixel 是以 C = (960, 540) 为不动点的仿射
⇒ pointer = C + (design − C) ⊙ k          （逐分量）
```

🔴 **⛔ 不是 `pointer = design × k`**：整值乘 k 会多偏 `C·(k−1)`（k = 2 时 x 多偏 **960 px**）。
本口乘的是**相对画布中心的偏移**。这与任务简报里「乘回父链缩放」同一含义 —— 乘的对象是偏移量。

**退化守卫**（与 `DesignPx` / `MenuDraw.DivByScale` 互逆）：
`owner == null` ⇒ `(-99999,-99999)` 哨兵（⛔ 不落回画面中心）；`owner.parent == null` ⇒ `k = 1`
（根没有缩放可乘）；`k` 非有限 / `|k| < 1e-6` ⇒ **该分量按 1**（那一档 `DesignPx` 根本没除）。
**单位缩放（两分量 `k == 1`）⇒ 逐位返回入参**（快路径），所以「新旧口同值」可以作**精确**断言。

## 二、新口签名与实现

```csharp
// Editor/MenuCheck.cs:238
public static Vector2 PointerFramePxFromDesign(Vector2 designPx, Transform owner)
{
    if (owner == null) return new Vector2(-99999f, -99999f);
    var above = owner.parent;
    if (above == null) return designPx;                       // 根：没有缩放可乘
    var k = above.lossyScale;
    float cx = LayoutSpace.DesignPxW * 0.5f;                  // 960：ToDesignPixel 的不动点
    float cy = LayoutSpace.DesignPxH * 0.5f;                  // 540
    return new Vector2(ScaleAboutPx(cx, designPx.x, k.x),
                       ScaleAboutPx(cy, designPx.y, k.y));
}

// Editor/MenuCheck.cs:251（单分量；k==1 逐位返回）
static float ScaleAboutPx(float centerPx, float v, float k)
    => (float.IsNaN(k) || float.IsInfinity(k) || Mathf.Abs(k) < 1e-6f || k == 1f)
         ? v : centerPx + (v - centerPx) * k;
```

doc 里写清了：恒等式（含 `DesignPx(t) ≡ DesignPx(t.position, t)` 的关系）· 不是整值乘 k ·
逐分量用 `lossyScale.x/y`（⛔ 无统一标量）· 退化守卫 · `owner` 该传哪一级（除/乘的都是**父级**那一级）。

## 四、断言与灭自证（`CollectionScene.CheckPointerFrameFromDesign`）

调用点：`RunCore` 收尾、汇总行之前（新 `Section("A1350 第二批：设计帧 → 指针帧…")`）。

夹具（自建、`finally` 里 `DestroyImmediate`，世界原点）：
设计矩形 `(1200,320)-(1400,520)` ⇒ 设计中心 `(1300,420)`；`host → mid(localScale=2) → quad`。

**① 单位缩放**：`new == PointerFramePx(t)` **逐位相同**（`==` 精确比较）· 设计点 = 1300/420。

**② 父链 ×2**：

| 断言 | 期望值（夹具字面量独立算） |
|---|---|
| 新口 x | `960 + (1300 − 960) × 2 = **1640**`（容差 0.01） |
| 新口 y | `540 + (420 − 540) × 2 = **300**` |
| 新口 vs `PointerFramePx(q)` | 两独立口互证，同帧（0.01） |
| `ButtonAt(新口)` | **命中探针 quad** |
| `ButtonAt(设计点 1300,420)` | **不命中探针** |

**为什么这是灭自证**：命中区半宽 = `WorldW × |ls| × PxPerWorldX / 2` = **200 px**（`HitBoxPx`），
而设计点与新口差 **340 px**（x） ⇒ 把实现改回「原样返回设计点」时：
新口读数 = 1300（≠ 1640）**且** `ButtonAt` 落到命中区 x∈[1440,1840] 之外 ⇒ **两条同时红**，
**实现与断言一起改回旧写法不可能同时绿**。

⚠️ 探针 quad 用队列 **4000**（压过真界面最高档 ~3362）⇒ `ButtonAt` 一定先拿到它；
`WindowButton` 是探针临时挂的（只为让 `CollectHits` 收它）。
