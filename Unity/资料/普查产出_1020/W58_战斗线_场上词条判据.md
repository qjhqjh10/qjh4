## 一、结论（3 句）

1. **原版场上卡一共有 7 个 trait 徽标位（左 3 / 右 4），图标中心 = `TraitIconContainer` 容器中心（±0.563，行 2.359 / 1.934 / 1.494 / 1.054，3DBody 空间）**；`Container`(−0.287) 与它的子节点 `Without counter`(+0.287) 的位移**互相抵消**，原版图标**没有**再往卡外偏。
2. **我们多偏了一档 `Badges.IconOutward = 0.21525`**：图标/角标/✕ 都被画到 ±0.778，图标外缘 `−1.006` 已经**超出可见 3D 卡体（±0.9286）0.078 卡单位** —— 这正是用户报的「词条图标超出卡面」。用户实拍交叉验证：徽标中心归一化 x=**0.192**（按网格量），原版容器位预测 **0.197**、我们现实现预测 **0.081** ⇒ 实拍**否决了 IconOutward**。
3. **`CardView.Board*At`（四个数值）本身是对的**（逐值 = 原版四个世界空间 TMP 节点），`InfoTexture` 的 `board` 分支位置也对（它今天只在 `PragatiDigits` 不可用时才走）；真正要修的还有三条：**两/三位数被 2D 卡面的 `StatDigitMaxW=31` 夹小、health 字号应比其余三个大 14%（8 vs 7）、四个数值的描边原版在场上全是 thick（0.12）**。
