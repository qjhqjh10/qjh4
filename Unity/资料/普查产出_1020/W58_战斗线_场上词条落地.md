## 一、结论（5 句）

1. **徽标图标/角标/✕ 不再往卡外偏**：`Badges.IconOutward` 0.21525 → **0**，图标中心 = 容器中心 ±0.563；图标外缘 **0.7908**，可见 3D 卡体半宽 **0.9286** ⇒ **余 0.1378**（旧实现越界 +0.078）。
2. **场上四个数值的尺子从 2D 卡面那套分出来**：最大墨宽 31 → **53/59/45 px**（原版 3D TMP 的 Rect），Health 字号 **8/7**，四个**全部 thick**，护甲盾 **+0.024**、尺寸 **0.3164×0.3904**，可行动底光改用原版 `Highlight` / `Highlight ranged` 独立子节点的偏移。
3. **顺带查出并修掉一条报告没列的差异**：徽标角标字号我们原来只有原版的 **41%**（1.6835 vs 原版 `5.5 × 0.7502 = 4.1261`），并且缺 **Bold + Extra Thick Outline 0.106 / FaceDilate 0.093** —— 已按原版材质逐值补齐。
4. **两条缺件做了图 + API**：`SwarmIcon`（原版 sprite 已用 UnityPy 解析出 = `Atlas_trait_icon_swarm`，几何逐值照抄）与 `HealText`（`+N`、世界字号 0.7、位置 (0,2)）。**动画 clip / 音效 / 触发接线**缺判据，见 §四。
5. `SetFace(Hand)` 现在**显式关掉**徽标 + Swarm 图标 + 治疗飘字（未来加 board→hand 路径不会挂错）。

## 四、没查清的部分（⛔ 没猜）

1. **Swarm 图标的 AnimationClip / 音效**：运行时那一份是 Addressable 预制体 `Swarm Battle Card Icon`
   （`CardScript.swarmObject`，GUID `87a100c766fda41059e261e3e1ed817b`，就在 `battleprefabs_vfxandmisc` 包里），
   `SwarmIconController.myAnimation` 指向**外部 CAB** 的 clip（PathID `6836189287277267510`）、
   `toggleOnSound` PathID `-4158225771113159080`。本批**没解析出 clip 的内容/名字**（外部 CAB 未定位），
   所以只实现「显示 + 0.3 s 淡出」，**动画与音效未播**。要做：先按 PathID 在依赖 CAB 里解析那两条资产。
2. **Swarm 的触发接线**：`CardScript.DisplaySwarm/RemoveSwarm` 的调用点在 `BattleManager.Update` /
   `MinionManager.RemoveSwarm`（反编译已读），对应的运行时驱动在 **`BattleDriver`** —— **不在本批白名单**。
   本批只提供 `CardView.SetSwarm(bool)`；接线另立账。
3. **HealText 何时显示**：`BattleCardUI.healText` 的**方法体没被反编译出来**
   （`d:/2/tools/decomp_full` 全目录按 `healText` 零命中；`ReactToUnitHealed` 只走
   `RawCardScript.OnTrigger(0x46, …)`，不再往下设文字）；时长/缓动/飘位也未查到。
   本批只提供 `ShowHeal(int)` / `HideHeal()`（文本 `+N`、位置/字号照 prefab 字段），**触发接线另立账**。
4. **`InBattleId`**：原版默认关，**何时打开没查到**（同 §六·2）⇒ 本批**没建**（建一个永远不显示的层没有判据意义）。
5. **场上数值的 thick 描边宽度 0.12**：字形表只烘了 thin(0.05) / thick(0.097) 两档；原版场上四份材质都是
   **0.12**。要精确到 0.12 必须重跑 `工具/gen_pragati_digits.py` 生成新字形表（`Core/PragatiDigits.Data.cs`
   是生成物，**不在本批白名单**）⇒ 本批只做到「四个都用 thick」。
6. **护甲盾 `Armour Background` 的父级 scale**：报告给的 (0.675, 0.7956) 等于把局部 `(−0.003, 0.024)`
   **不乘**父级 0.48287；而它的尺寸 0.3164×0.3904 **乘了** 0.48287。本批按任务口径「比数字高 **0.024**」
   落地（若 Unity 真的按父级 scale 作用位置，应为 +0.0116）。这条要么等实机量，要么回原版 prefab 跑一次。
7. **Health ×8/7 是最近邻放大**（画进 56 px 画布再铺满同一 `StatCell`）—— 物理尺寸正确，像素密度比其余三格低一档；
   若要逐像素等密度，得给 `PragatiDigits.Draw` 加字号参数（那个文件不在本批白名单）。
