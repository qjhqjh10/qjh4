## 结论（3 句内）

1. **原版联盟搜索既不是独立窗、也不是主菜单顶层「内容页」**：它是 `Social Submenu Variant`
   （`SocialMenuWindow : GameWindowWithTabs`，`windowsPlacement = 5`）里 **Alliances 页签 →
   `AllianceNotMemberVariant`** 这一支子视图；`JoinAllianceMenu` 只是该页内部的一个 `MonoBehaviour`
   子视图，由 `Join` / `Create` 两个页签键切换，**从不单独开窗**。
2. **我们的三层结构（`SocialWindow : MainMenuSubmenuWindow` → `AlliancesTab : SocialPage` →
   `AllianceSearchTab : SocialView`）与原版同构** ⇒ W58 判据里「原版是页、我们是窗」的**前提不成立**，
   D4 **不需要**「把联盟搜索改成主菜单页」这一步。
3. D4 真正的差只有**转圈件的那一档队列**：原版 `MenuLoadingController` 在 `Game UI` 画布
   **Default 层**、且是 `Safe area Only Horizontal` 的**最后一个孩子** ⇒ 压在主窗（placement 5/10）
   之上、全部 PopUps/Blocking 画布之下；我们 `QDark/QSkull/QCog = 4080/4081/4082` 在**所有东西**之上。
   落点建议 **3327–3329**（现梯子里 `TrophyInfoPopup` 3326 与 `GenericOptionsPanel` 3330 之间的空隙）。

### 1·5 暗底/骷髅/转圈「运行期显示条件」的静态结论

- 转圈/骷髅/暗底**整棵由 `Holder` 的 `activeSelf` 决定**（唯一开关点 = `MenuLoadingController.Show/Hide`）。
- **暗底在场景里是关的**（`Menu Dark Background_478.m_IsActive = false`），而它是 `Holder` 的**唯一子件**
  ⇒ **照序列化值，`ShowLoading()` 之后什么都不会显示**。全库**找不到**把它打开的赋值点：
  - `MenuLoadingController__{Awake,ShowLoading,HideLoading}.c` 只动 `Holder`；
  - `JoinAllianceMenu__Initialize` / `__FillOpenAlliances` / 回调里没有 `SetActive` 暗底；
  - 暗底上的两个脚本是通用的 `BackgroundCloseButton`（点外面关窗，`window` 为空）与
    `BackgroundOverDrawController`（只维护「当前哪块压暗层该 enabled」的静态栈，**不开 GameObject**）。
  ⇒ **序列化值 ≠ 运行期真相 的可能性很大，但本地静态判不了**（见 §七·1）。
- 骷髅：Sprite `7621650145332779859`（`40K_icon_searching_skull`）+ CanvasGroup α 0.7；
  齿轮：Sprite `5609191530438287762`（`40K_icon_searching_cog`）+ `SimpleRotation.speed = (0,0,-20)`。
  两者在 `Animated Loading Image` 子树里，随暗底一起被关。

## 四、改造方案（按最小可回滚切）

> 🔴 **先说「不要做什么」**：**不要**把 `SocialWindow` / `AlliancesTab` / `AllianceSearchTab` 改成
> 「主菜单内容页」，**不要**动 `MainMenuRuntime` / `MainMenuSubmenuWindow` / 左栏页注册 ——
> 原版就是这套结构，改了才是偏离（见 §一·1、§一·2）。D4 只剩转圈件层这一件。

### 切片 1：转圈件队列落到 3327–3329（核心，独立可回滚）

- 文件：`Shell/LoadingMenu.cs`
- 符号：`LoadingController.QDark / QSkull / QCog`（`:244`）

  1. `4080 / 4081 / 4082` → **`3327 / 3328 / 3329`**。
  2. 改写 `:86` 那段「必须高于全部 shell UI（现读最高 4030）」的注释：
     新理由 = **原版 `MenuLoadingController` 在 Default 层 / `Safe area` 最后孩子**
     ⇒ 压 placement 5/10 主窗、在 PopUps（窗/toast/横幅/教学）与 Blocking（tooltip/黑场）**之下**；
