## 1. 结论

1. **缺口已修**：`PlayReplay` 在 `BeginFromPendingCore` / `BeginTutorial` 重建完这一局之后、
   **逐条灌动作流的 `for` 之前**（= 「进入战斗、动作流开始前」），补了一句 `StartIntroMonologue();`。
   原版判据链：`_StartBattlePhase:36-47` 先 `ClickPlayReplay`，随后**照样落到同一道闸**
   `:141-148` ⇒ `Replay(160)` 不在排除集 `{100,130,140,190}` ⇒ **播**。
2. **一局只播一次**：复用 `W58-INTROFIX` 已落的 `_introStarted` 闩（`StartIntroMonologue` 内部第二道闸）；
   `Begin` 每局把 `_introStarted` / `_introStage` 复位。回放走 `BeginFromPendingCore → Begin`
   （教程走 `BeginTutorial → Begin`）⇒ **每次回放都先复位**，不会「第二份录像一句都不播」。
3. **不会重复播**：若录的是 **No-mulligan 模式**（如遭遇），`Begin` 的无换牌支**已经起播过一次**
   （`W58-INTROFIX` 那一笔）；`PlayReplay` 再叫一次被闩挡住 ⇒ 仍只播一次。
4. **教程回放不播**：`BeginTutorial` 把 `PlayMode` 置 `GameMode.Tutorial` ⇒ `Ctx.MatchType = Tutorial(100)`
   ⇒ `IsTutorialOrCampaignMatch` 挡住（`PlayReplay` 的新调用与 `Begin` 的无换牌支**同一道闸**）。
5. **不破坏回放契约**（起始条件 + 动作流）：独白只动表现层字段
   （`_introStarted` / `_introStage` / `_introFirst` / 新增的自检计数）+ 气泡与音频；
   不发引擎事件、不写 `Ctx`、**不消耗 `Ctx.Rng`**（`SpeakIntro` 里 `VoiceLines.TryPick(..., null, ...)`
   明写「随机源传 null」）。契约的既有闸（`Check(same, …)` + `ReplayDivergenceForTest < 0`）
   在独白若真动了引擎 / RNG 时会立刻红。
6. 新增一个**自检口** `IntroStartCountForTest`（本局真正过闸起播了几次），让「播了 / 只播一次」
   都能被确定性断言，而不依赖「此刻状态机在第几拍」。
