3. **初始值 = `HEAD` 那一版基线文件的规范化指纹 `f350e247…`**（= **上一次被确认的状态**），

   （口径与 `A1619` 的裁定一致：**重钉要等 `C3`/`C4` 交件后一起做**，本件**不抢跑**。）

**重钉办法（`A1619` 要的那一句，写清了）**：`check` 会打出——

```text
public const string PinnedParseMd5 = "38f38061c8116dc4497a666f6733517c";
```

**整行手抄进源码** = 本哨兵要求的「显式确认」（会出现在 `git diff` 里）。
🔴 **三个指纹一起钉**：`PinnedPoolMd5`（上面那个卡池现值）· `PinnedBaselineMd5`（上面那个基线现值）·
