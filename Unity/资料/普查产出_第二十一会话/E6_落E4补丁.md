## `IsPendingDeath` 那一口（为什么不能拿 `TakePendingDeaths` 代替）

`Core/BattleContext.cs:1297-1308`。**`_pendingDeaths`（`:1262`）是私有的**，公开面只有两个：

- `PendingDeathCount`（`:1268`）—— **只给一个数**，答不了「**这一个**在不在队列里」；
- `TakePendingDeaths()`（现读 `:1309`）—— **`_pendingDeaths.Clear()` 就在它体内**（现读 `:1312`）。

⇒ **判一次就把队列吃掉了**，而队列是 `FlushDeaths` 要消费的正本 ⇒ 拿它去判 = **静默把待处理的死亡连着清空**，
症状是「同批里后死的那几个不结算了」。所以**必须新开一口只读的**：

```csharp
public bool IsPendingDeath(UnitState u)
{
    if (u == null) return false;
    for (int i = 0; i < _pendingDeaths.Count; i++)
        if (ReferenceEquals(_pendingDeaths[i].Unit, u)) return true;
    return false;
}
```

⚠️ 按**身份**（`ReferenceEquals`）比、不按格号 —— 与 `AddPendingDeath` 去重那两行（现读 `:1292-1293`）是同一条口径；
按格号比会在「同一批里被顶位」时认错人。这一条我也补进了 `BattleContext.cs` 的文档注释里（见上表第二行）。
