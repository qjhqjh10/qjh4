## 四、本会话的坑 / 承重结论（新会话必读）

1. 🔴 **`poolTrueIds` 现在是【历史迁移表】，⛔ 不是翻译表。** `card_ids.json` 有 **`poolIdsAreTrue: true`**；
   再反转它会把真 id 映回旧 id ⇒ **认成另一张卡**（实测 SW 一族整体错位、预组 `suspect` 14→65）。
2. 🔴 **id 迁移必须一次性并发替换**：映射里有 **73 条链**；工具 `工具/migrate_pool_ids_k06.py` **只跑一次**（自带重跑护栏）。
3. 🔴 **换真值快照 ≠ 只换 id**：新快照有 1 张稀有度真的变了（`Skyborne Deployment` rare→common）、~120 张 SO 列从 `-1` 变有值；
   生成器的守卫**挡住是对的**，核完用 `RARITY_TRUTH_ACCEPTED` **显式放行**。
4. 🔴 **`K07` 的「399 改值」是表示差异虚高**（en==zh 压成字符串），**真改值 117**。
5. 🔴 **`guid_map` 旧表从 Addressables 目录出发** ⇒ 目录里没有的 GUID 根本没查过；正确做法 = **直接枚举 `AssetBundle.m_Container`**（容器键就是 GUID）。新工具 `工具/gen_guid_map_from_bundles.py`；**旧表别删**。
6. 🔴 **卡组行排序 = 原版「费用 → 本地化名」，第二把键必须是文化相关比较**（`StringComparison.CurrentCulture`），
   ⛔ **不是 `CompareOrdinal`**。判据：`DeckListDrawer.__c___Reorder_b__22_0.c` = `RawCardScript+0x78` = `manaCost`，
   `_b__22_1.c` = `GetLocalizedCardName`。zh-CN 给拼音序、en-US 给另一套 —— 原版用的是**玩家机器的当前文化**。
7. 🔴 **立绘孤儿删除有同名陷阱**：StarterCards 的 id = 卡名（`falcon`），池里也有 `ASH27 Falcon` ⇒ 先排除那 26 个 slug。
   本会话已删 **156 个旧 id 死图（312 文件 / 236.6 MB）**；清单 `d:/4/_tmp_view/backup_1018/art_orphans_deleted_20261018.tsv`。
   ⚠️ **`Resources/Art/` 在 `.gitignore` 里** ⇒ 换机器必须重跑 `工具/import_original_art.py`。
8. ⚠️ **探针三条指纹已重钉**（`PinnedPoolMd5` / `PinnedBaselineMd5` / `PinnedParseMd5`），判据 =
   HEAD 卡池与当前卡池**按卡名对齐后 0 处解析差异**（1,118 个名字）。⛔ 以后重钉先复跑这个对拍。
