# W63 · 冲突/经典 双模式卡组选择 · 点卡组看内容（只读代理，2026-10-22）

## 一、「冲突 / 经典」在原版是什么

- 枚举 `PlayModes.Classic=0` / `Skirmish=13`（`Warpforge_code/.../PlayModes.cs:3,16`）。官方中文 = **经典 / 小冲突**（官方表 `MainMenu/GameMode/{Classic,Skirmish}`）。
- 卡组**只有一份库**，模式是卡组自己的字段 `CardDeck.gameMode`（`Nullable<PlayModes>` @0x70，`dump.cs:20483`）。`DeckInventory.HasSkirmishDecks` 也是遍历同一份库判 `GameMode==0xd` ⇒ **没有两套独立卡组列表**。
- 「按模式分」发生在**列表/入口层**：
  1. 收藏 Deck 页的模式页（见 2）；
  2. 选卡组弹窗筛法 = 候选模式 == 当前这副的模式，否则 == `context.GameMode`（`DeckSelectionPopup___TryOpen_b__10_0.c:8-16`）；
  3. 模式窗只列本模式（`RankedDeckSelector__ChangeArmy.c` 谓词 = 阵营 + `deck.GameMode == event 模式`）。
- **字面意义的「两个模式各一副」= 练习窗**：`PracticeModePopup.decks` = **78 份 `DemoDeckInfoSO`**；每份 `classicDeck`@0x18 / `skirmishDeck`@0x20，`GetDeck(mode)`：0→classic，否则→skirmish（`DemoDeckInfoSO__GetDeck.c`）。84 份 Demo DeckInfo 中 **78 份两副齐全**，6 份（教程）只有 classic。

## 二、链路：原版 vs 我们

**原版没有「模式入口 → 先选卡组 → 进模式窗」这条独立链**，选卡组在窗内：
- 模式卡 → 模式窗：`LiveopsMenuContainer.OnClick` → `LiveOpsEvent.OpenWindow()` → 冲突=`SkirmishModeEventWindow` / 经典=`RankedEventWindowV2`。窗内四圆钮中间 `selectDeckButton` → `DeckSelectionPopup`（带模式筛）→ 点行 → `Deck info Popup`(state 3) → `Select deck` 才选定。
- 收藏 → Deck 页：`SelectDecksTab.ChooseTabToOpen` 数 `IOwnDeckPlayEvent`：**<2 直接进卡组列表；≥2 先出「选择游戏模式」页**（`SelectDecksTab__ChooseTabToOpen.c:33-38`）。点模式卡 → `DeckCollectionTab.currentEvent=event` → 列表按模式筛。
- 我们：模式卡→窗→换/建卡组+开战校验模式**已有**；**收藏 Deck 页的模式页完全缺** —— `FilteredDeckIndices` 只筛阵营+名字（`CollectionWindow.cs:3957-3971`）、`CreateDeck()` 不传模式（`:4494` → `CollectionData.CreateDeck(gameMode=0)`）⇒ 永远建经典。
- 练习窗：原版列 78 份 Demo 对；我们列**玩家自己的卡组**并按模式筛（`PracticeModePopup.cs:1528-1547`），默认模式取「当前这副的模式」；原版出厂 = **Skirmish(13)**。
- ⚠️ **关键前提**：原版模式页**事件驱动**，本地零 liveops 事件 ⇒ 严格照原版（<2）反而是「直接进列表」= 我们现状。要做两模式页必须做**离线等价物**（照 `LiveOpsLocalCatalog` 先例）——**要拍板**。

## 三、「点一下卡组」应发生什么

- 收藏 Deck 页：`DeckCollectionTab.OnItemSelected` → `DeckInfoContext(deck, Edit=0, null, true, null)` → 开 `Deck info Popup`。
- 选卡组弹窗：`DeckSelectionPopup.UpdateInfo` → 同一个 `Deck info Popup`（state=3，多一颗 `Select deck`）。
- **`DeckInfoPopup.Open` 无条件开 `listDrawer`、关 `infoDrawer`** ⇒ **原版一开就是卡表**。「点击卡组能看到里面有什么卡」= 原版行为，**不是缺陷**。
- 练习窗左列：点一格 = **只选中**，不弹窗；看内容走 `Show Deck Content`。
- 我们三处都照原版（收藏 `SelectDeck`→`OpenDeckInfo`；选卡组 T24；练习 `PickDeck` 只选中；`DeckInfoPopup` 默认卡表）。**⛔ 不建议改。**
