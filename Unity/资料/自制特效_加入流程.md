# 自制特效 —— 加入流程（2026-09-18 建立）

> **什么时候看这份**：你要**新增一张卡**、给它**配一个特效**，或者**自己造一个新特效**的时候。
> 三条路各一句：**复用已有的** → 改 `VfxMap`（第 四 节）；**微调已有的** → 复制 prefab（第 三 节）；
> **从零造一个** → 按下面走（第一、二 节）。

---

## 一、三条硬规矩（不遵守会**静默丢东西**）

| # | 规矩 | 不遵守的后果 |
|---|---|---|
| 1 | 🔴 自制特效的 prefab **只能放 `Assets/CardPresentation/Effects/`**（或任何 `Assets/WarpforgeVFX/` **之外**的地方） | `Assets/WarpforgeVFX/{Materials,Textures,Meshes,Prefabs}` 会被 `EffectExporter.ClearGenerated()` **整个删掉重建**（每次全量重导都跑）⇒ 你的东西**下一次重导就没了，而且不报错** |
| 2 | 🔴 **不要**把自制特效写进 `数据/游戏数据/effect_index.json` | 那个文件每次由 `工具/gen_effect_index.py` **重新生成**（它的输入是导出报告 + `animfx_components.json` + 台账）⇒ 你写进去的条目迟早被抹掉。**建库是直接扫目录的**，不需要你写任何 json |
| 3 | 🔴 **名字就是效果库的键**，重名会**警告 + 跳过**（不覆盖原版） | 反过来讲：如果你想改一个原版特效，**不能**用同名去顶 —— 得改 `WFEffectInfo.displayName` 换个名字，或走「改现有特效」（第三节） |

---

## 二、从零加一个自制特效（三步）

**① 把 prefab 丢进 `Assets/CardPresentation/Effects/`**
（目录不存在就先建；自检工具会自动建）

**② 在 prefab 根上挂 `WFEffectInfo`**（`AddComponentMenu`：`Warpforge/特效信息（自制特效用）`）—— 可选，但建议挂：

| 字段 | 说明 |
|---|---|
| `displayName` | 播它时用的名字。**留空 = 用 prefab 的文件名** |
| `destroyTime` | 多久后进收尾。**负 = 用测出来的自然时长**（不循环时才推得出来） |
| `exitDestroyTime` | 收尾时长（停止发射后还留多久让已飞出的粒子飘完）。负 = 播放器默认 3 秒 |
| `preventDestroy` | 勾上 = 不自己死，由牌局代码 `Kill()` 收。**循环类（光环 / 常驻）要勾** |
| `notes` | 给自己看的备注，不进库 |

**③ 生成效果库**（二选一）

```bash
# 菜单：Tools > Warpforge > 生成效果库
# 或 CLI：
UNITY="D:/Unity/Hub/Editor/6000.3.23f1/Editor/Unity.exe"
unset ELECTRON_RUN_AS_NODE && "$UNITY" -batchmode -quit \
  -projectPath "D:\4\Unity\MyGame" -executeMethod EffectLibraryBuilder.Run -logFile -
```

跑完就能 `WarpforgeEffectPlayer.Play("你的名字", parent, pos, scale)` 了。
⚠️ **`EffectExporter.Run` 之后必须跟一次 `EffectLibraryBuilder.Run`**（硬顺序：重导会把 prefab 的内部 fileID 全换掉，
不建库则 958 条引用全变 null **且不报错**）—— 但反过来说，**只加自制特效不需要重导**，跑库这一步就够。

## 三、改一个现有特效（微调用）

复制 `Assets/WarpforgeVFX/Prefabs/<原名>.prefab` → 粘到 `Assets/CardPresentation/Effects/` → 改名 →
挂 `WFEffectInfo` 把 `displayName` 设成新名字 → 重跑建库。

⚠️ **不要原地改导出目录里那份** —— 它是导出产物，下次重导就还原/消失。
⚠️ 复制出来的 prefab 会带着 `WarpforgeEffectBinder`（运行时按原版 shader 重建材质），**留着**，别删。

---

## 四、复用现有特效（新卡播已有的某个）

**跟上面三节无关**，改的是 `CardPresentation/Core/VfxMap.cs`：

- 现在是「**事件 + 阵营**」兜底（`VfxMap.PlayCard` / `Deploy` / `AttackMelee` / … 那批常量）
- **要逐卡配**：填 `VfxMap.ByCard`（键用卡名）—— 那个口子早就留好了
- ⚠️ **挑特效别凭名字**：`数据/游戏数据/effect_index.json` 里有还原质量判定，
  有一批是 `只有原版有内容` / `两边全程空` 的，播出来**是空的**。而且判定「对得上」**不等于**在我们场景里好看
  —— 实测 `BulletImpactBurst_Blood` 渲成一整块灰方块。**挑之前用 `Editor/VfxPicker.cs` 的试片台实拍看**

## 五、验收（改了这条链就跑它）

```bash
UNITY="D:/Unity/Hub/Editor/6000.3.23f1/Editor/Unity.exe"
unset ELECTRON_RUN_AS_NODE && "$UNITY" -batchmode -quit \
  -projectPath "D:\4\Unity\MyGame" -executeMethod UserEffectTools.Run -logFile -
```

判据看末尾 `WFEFF === 合计：N 通过 / M 失败 ===` 与批处理退出码。它 **2026-09-18 建时 16/0**，验的是：

1. 样本 prefab 建得出来；
2. **自制条目进了库**、`prefab` 引用不是空的；
3. **重名不顶掉原版**（故意造一个与 `Acid Rain Damage Target` 同名的靶子，断言原版那条仍指向导出目录）；
4. **原版 958 条一条不少**（实测 958 + 自制 1 = **959**）；
5. **播得起来且会自己收尾**（`Play` → ActiveCount +1 → 到寿命 `IsExiting` → 收尾走完不在播 → `Kill()` 后不占池子）。

它会**自动建样本** `Effects/Example_Spark.prefab`（**既是靶子也是抄的范例**），自检完把重名靶子删掉。

## 六、出处与相关

- 代码：`WarpforgeArena1/Editor/EffectLibraryBuilder.cs` 的 `UserPrefabDir` / `CollectUserEffects` ·
  `WarpforgeVFX/Runtime/WFEffectInfo.cs` · `WarpforgeArena1/Editor/UserEffectTools.cs`
- **为什么当初没有这条路**：库那条链原来是**单向**的「导出产物 → `effect_index.json` → 库」，
  `EffectLibraryBuilder` 的输入只有 `IndexJson` ⇒ **自制的东西没有任何入口能进来**，`Play("我的特效")` 是空的还不报错
- **将来要给自制特效也配「屏幕震动 / 拖尾吸附」这类模块**：`AnimFX` 那 18 类会做成
  **MonoBehaviour 形态、可手挂**（复刻那 958 个走运行时按数据装配，自制走手挂），见
  `资料/AnimFX_18类成表.md` 与 `资料/AnimFX_18类方法体_块1/块2.md`
