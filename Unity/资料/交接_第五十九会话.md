## 四、本会话的坑 / 承重结论（新会话必读）

1. 🔴 **真机前先看 player 的 `Assembly-CSharp.dll` mtime**（本会话开工时它还是 10-18 的，白验一轮）。
2. 🔴 **`-wfscene Battle` 在 player 上不生效**（开场动画播完回主菜单）。
3. 🔴 **外壳常驻件跨场景不关**：`UIBakeScreen` 全屏模糊快照 + 左栏/顶栏/聊天预览/`FadeBackground`
   挂在 DDOL 的壳根 ⇒ 切战斗不销毁，整屏是「主菜单那张糊图」，**看起来像运镜卡死**。
   修法 = `ShellRuntime` 的 `sceneLoaded` 钩子（覆盖全部 6 条进战斗的路）+ `MainMenuRuntime.Build` 开头清旧件。
4. 🔴 **同一面板有多份「当前是哪副」的来源 ⇒ 必然分叉**（练习窗 `PickedPrebuilt` vs `DeckIndex`）。
   修法 = 收成 `CurrentDeck` 唯一判源，**开战闸也必须走它**。活动窗是同一模式（`Shown*` 判源）。
5. 🔴 **合成鼠标的滚轮/拖拽进不了 Unity 滚动列表** ⇒ 列表深处的条目**只能真人选**。
6. 🔴 **`SetMySeat` 中途翻座位**两参档：要同时处理两张视图表 + 两张身份表 + fading + 登场账全套飞行票 +
   **`_myFaction/_foeFaction`** + **`_timeline` 整条清**。旧 `#27/#28` 断言过去靠「认领旧视图」碰巧绿。
7. 🔴 **动画打字机是「吃掉字母」不是「裁切」**：`SearchingMatchPopup` 的 `TypedChars` 起点 `len-3`，
   文案必须带三个点（`"Searching..."`，判据 = 官方本地化）。
8. ✅ **`PlayOrder` 进场序**（`T03·c` 批 A）：单位层 = 进场序（不是格号、不是座位序）；`-1` 排末尾。
9. ✅ **`or` 的第二种读法**：`SOR31`「dies **or is a friendly unit**」是**析取条件**，不是二选一 ⇒ 先看 `descZh`。
10. ✅ **`abilityContext` 是原版真实的 per-ability 闸**（40 = `InPlayOrDying` 待死也响 / 0 = `Play` 不响）——
    我们**没建模**，这是 `T03·d` 的新残余。
11. ✅ **图集精灵（SpriteAtlas）**：`SpriteAtlas.GetSprite` 在 bundle 载入的图集上**恒返回空**（`texture=null`）；
    可行路 = **名字 → `m_PackedSpriteNamesToIndex` → `m_RenderDataMap[i]`** 拿 texture+rect 自己裁。
12. ⚠️ **`ruleprobe.sh scan` 必须绝对路径**；基线重生成后**三个指纹都要重钉**。
13. ⚠️ **新增 `Step` 后必须重跑 `gen_diag_runner.py`**，否则每次起 Unity 都报「诊断入口过期」。
