## 五、本会话的坑 / 承重结论（新会话必读）

1. 🔴 **战斗场景没有 `AudioListener`** ⇒ 整场战斗**没有声音**且**不报错**（`isPlaying`/`time` 照常走）。修法 `BattleDriver.EnsureAudioListener()`（只在「一台都没有」时补）。判据：`listeners` 数 + 频谱非零。
2. 🔴 **`Scenes/Battle.unity` 烘死 `baselineY: 0.11`** —— 改了 `HandLayout.DefaultBaselineY` 不重存场景**真机不变**。
3. 🔴 **`m_Scale` 只对 CJK 面成立**：卡面拉丁字（name/desc/army/race/createdBy）必须按**字体面**换算 em（原版 em：name 0.19 / desc 0.2355 / army 0.15 / race 0.18）；旧换算量的是「汉字墨高」。修后卡面文字**小 14.7%**（可见变化）。
4. 🔴 **`FrameArtCoverage` 的基线不能含实心金属**：原版 `FlipAlphaMask` 下不透明金属底下的图**看不见**；基线 = 逐像素 `hole ∪ ring` ∩ 立绘板 ∩ 卡体。否则 tier4 会假红（92–95%）。
5. 🔴 **触发入队后，每个入口都必须有 `ActionScope`**：漏一个 = 静默不结算（本轮漏了 `Hurt`/`GrantDarkPact`/公开 `BroadcastWhen`/`TryCancelAttackByOwnAboutToAttack` 四处，13 条红）。
6. 🔴 **闭包捕获 for 变量**：`BroadcastHandTrapWhen` 的 `p` 在出队时已是 2 ⇒ `Players[2]` 越界；入队动作捕获的变量一律先 `var _x = x;`。
7. 🔴 **演示卡组不再落盘**（原版 `SelectDecksTab.CreateDeck` = 空卡组直接开窗、无入库调用）；但**起始卡组仍没人发** ⇒ 新玩家库 0 套（待接 FTUE）。
8. ⚠️ **预组名按 `PrebuiltDecks/<deckId>`**（`PrebuiltDeck__get_LocalizedName.c:15`）；换口径后原 95 副里 **20 副显示名变了**，其中 4 副语义是另一副牌名（待原版实拍核对）。
9. ⚠️ **`BattleDriver.cs` / `CardView.cs` / `EffectResolver.cs` / `RuleEngineTest.cs` 是纯 CRLF**；改前二进制数、改完再数（`sed -i` 会翻）。
10. ⚠️ **换牌压暗层**：原版 `ShadePanel` 是 `FrontCanvas` **第一个**子件（在卡后面），alpha **0.8**；我们把它建在画布层 ⇒ 盖住了世界空间的换牌卡（卡面最高亮度 98/255）。
    **修法不是挪压暗层**：战场几何整批也在队列 3000（`ArenaBuilder.cs:5068`，13 场最高到 3011）⇒ 压暗 ≤2999 战场就不暗、≥3001 又盖提示行。正解 = **把换牌卡抬到 `QMulliganCard = 3001`**（< `CardFan.QCardBase` 3009，放大窗仍在卡上）。
    **alpha 那条「只吃到 0.63–0.69」是误判**：本工程是 Linear 色彩空间，按线性光拟合透射 = 0.1206 ⇒ alpha **0.88 一直是对的**；现按原版改 **0.8**。
11. ⚠️ **收藏左栏那条竖向白带 = `Tab Buttons/Shadow` 没给 tint**：原版有这件（`40k_main_tab_shadow` 51×4、**纯白 + alpha 渐变**，靠 `m_Color=(0,0,0,0.475)` 变黑阴影），我们建它时没上色 ⇒ 显示成白条。已在 `CollectionWindow` 按原版矩形 + tint 重建。
    🔴 **正解在基类** `Shell/MainMenuSubmenuWindow.BuildBar`（同一行给 `Rect(...)` 补 `new Color(0,0,0,0.475f)`、顶边按窗取）——**奖励窗/商店走同一行，也有同样的白带**（用户已把这两页排后，所以只记不做）。
12. ⚠️ **`PlayerBuild.Run` 报 `script class layout is incompatible`** 时先原样重跑一次（本轮第二次 5 s 增量成功）。
