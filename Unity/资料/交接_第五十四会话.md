## 四、本会话的坑 / 承重结论（新会话必读）

1. 🔴 **卡池排序不是按卡牌 ID** —— 原版 = **阵营(`cardArmy`) → 战将优先 → `manaCost` → 本地化名**；收藏页多夹 `inventoryOptions`。实现在 `DeckEditorState.SortForDisplay`。
2. 🔴 **卡库显隐 = `showInCollectionOptions != 0`**（卡池/收藏共用）；天赋卡 92/92 为 0；大图详情的天赋卡走 `related_cards`（96/96 已正确）。加不进 = **显示 + `_GreyScale` 去饱和**，不是隐藏。
3. 🔴 **`Dark Pact of *` 是 `markOfChaos` 契约族**（BL46 四选一 / EC36/EC41 / 单位 BL6/7/8/10；生成链 `CardScript__AddEffect.c:776-792` case 8）；SO `manaCost=-1` = 不可直接打出 ⇒ 我们落 `cost=-1` + `RuleCodes.ErrNotPlayable=20`（`CanPlayCard` 与 `CanPlayTactic` 两道都要）。
4. 🔴 **`ReplayFitForFace` 必须保存/还原 `WrappingMode`** —— `SetAutoFitBox` 里的 `SetWrapWidth` 会把折行开回 1（`4995622` 的 N55 回归，12 颗红）。
5. 🔴 **`SortByName` 排序键已改 `Id`**（`CreatePool.cs:1210`）；同理 `SpawnTalents` 仍按显示名找卡（`A2142`，同类脆弱点）。
6. 🔴 **战斗表现已改「可等待流水线」**：`WaitingForBlockingAction` 挡 `CanDropAtSlot`/`EndPlayerTurn`/`CommitCommand`/`Resolve`/`DriveAiTurn`；**测试夹具在动作前必须推到放行**；`OnCardReturned` 不许被闸吞（提示条会消失）。
7. 🔴 **VFX `Extra Color` 已进 `UseOriginal`**；`UnlitAmbient` 顶点色分流用**浮点闸 `_VertexColorLerpOn`**（运行时 `new Material` 没有材质资产保活，`shader_feature` 会被 player 剥掉）；catalog 的短 `internalId` 直接当 GUID 会**全取错对象**（已加三道闸）。
8. 🔴 **`card_icon_plan.json` 两份必须一起重生成**；`A2135` 已做（只 4 张变）。
9. 🔴 **`RuleEngineTest_Diag.cs` 是生成物** —— 新增 `Step(...)` 用例后跑 `python 工具/gen_diag_runner.py`，⛔ 别手改。
10. 🔴 **数据侧口径**：`desc` = 引擎唯一解析输入；改它要重钉 `PinnedPlayMd5`/play 基线；`cardface_fixes.json` 是 CRLF；`cards_engine.json` 是单行 JSON（逐卡比，别看 numstat）；卡池张数一律现读。
11. ⚠️ **本会话提交前的工作树包含多轮未提交改动**（60+ 文件 + 多份报告），`git checkout -- <场景>` 只还原场景，**别 checkout 整个目录**。
