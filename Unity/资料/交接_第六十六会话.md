## 五、坑 / 承重结论（本会话新增）

1. 🔴 **不同场的 `AnimationClip` PathID 是包内局部的** ⇒ 按全库 pid 字典查会**静默取错包**；正确 = 本包优先 → shared → 否则报未解析。
2. 🔴 **`AnimFXController.DoDestroy` 与 `Exit()` 是两条路**：`Exit()` 到点**一定**自毁；只有 `DoDestroy()` 才「有模块就不销毁、交给模块」。⛔ 别把交接逻辑接到 Exit 计时上（本会话接错一次、断言当场抓红）。
3. 🔴 **`m_Calls` 不是原版没有，是我们自己的 dump 护栏截断的**；修法 = 只放宽 `eventToFire` 一条 + 逐键 diff（一起短路会误报几百个组件）。
4. 🔴 **同一 prefab 名被多张 CardAnim 共用、参数不同（215 组）** ⇒ 任何按 prefab 名查 `AnimInfo` 的写法都是错的。
5. 🔴 **原版卡体从来不是 alpha 混合**（Geometry/Opaque/One-Zero；溶解 = AlphaTest）；`CardView.SetQueue/StampQueue` 会盖掉 3D 体材质身份 ⇒ **`SetQueue` 与 shader 换队列必须成对改**。
6. 🔴 **`EndDissolve()` 早退条件原来判反了**（`== _dissolveMat` ⇒ 溶解后永不还原）；原版 `RestoreOriginalMaterial` **没有**材质身份分支。
7. 🔴 **引擎：原版 SO 名 ≠ DTO 名**（`damageCriteria/healCriteria/buffEffect`）⇒ 从 `cards_raw.json` 直取评分条目前必须 `rename_so_entry`；`--check` 结构上抓不到这类（两边都错就恒绿）。
8. 🔴 **判「原版有没有某能力」不能只看方法存在，必须 grep 调用点**（`AI.ShouldPlayComboCard` 有实现、零调用）。
9. 🔴 **`arena_diff_phases.sh` 曾经「假相位」**：反斜杠项目路径 + 套 `env` ⇒ Unity 静默不启动；且脚本只看 `cp` 成功 ⇒ 复制旧图。**判据 = 产物 mtime / md5 真的变**（现已修）。
10. 🔴 **跨 CAB 容器 Unity 不认**；**搬 AB 对象进主 CAB 会让 Unity 原生崩溃** ⇒ 15 prefab 不能靠 repack。
