## 二、判据

1. **它不是某一场的结构差，是 13 场共有**（`A1630` 原文）。判据 = `工具/arena_diff.py <场> --top 0` 的**色调表**：
   **七场逐个跑过**（`battlearena1` / `2` / `3` / `astramilitarum` / `tauviorla` / `leviathan` / `sororitas`），
   **形状完全一致**（0-25 档一律正偏、最亮档一律负偏），工具**每一场都打**「🔴 对比度被压缩」。
2. 🔴 **已经排掉的三批**（都有一手数据，**别再重做**）：
   · **① `WF_NOPOST=1`**（关掉整条后处理）⇒ **形状几乎不变**（暗部**还更亮**、亮部仍负偏）
     ⇒ **不是后处理 / Bloom / Vignette**；
   · **② `WF_HDRRT=1`**（换 HDR RT）⇒ 变成**整体偏暗**（线性值直接写成 8-bit PNG）⇒ **HDR RT 不是解法**；
   · **③ 运行时材质真值没差** —— `ArenaBuilder.ProbeMeshMaterials` 现读
     `_AmbientColorBlend=0.0000 · ambientMode=Flat · ambientLight=RGBA(1,1,1,0.000) · intensity=0.410 · fog=0`，
     **与原版真值逐项相同**（真值表 → `资料/普查产出_0920/场景光照与后处理_原版规格.md`）。
   · ⚠️ 另有正本 §一·1 那一批开关（`WF_NOREFL` / `WF_NOEMIT` / `WF_NOVIGNETTE`）—— 见 `T01` §二 第 3 条。
3. 🔴🔴 **2026-10-12 追加的那一刀把结论【收窄】了** —— 拿 `battlearenaaeldari` 的**天空区**（图 y 2%–12%）做三方对比：
   **我们预览 vs 原版实拍 = 几乎逐项相同（差 ≤4）**
   ⇒ **「对比度被压缩」不是全局的**：它**只出现在某些区域**（**前景地面 / 中景**），**天空区我们是准的**。
   ⇒ 🔴 **动手前必须先按区域分**，⛔ **别拿「全局」两个字去改整条管线**。
4. ⛔ **别按目前读数去改颜色**（`A1630` 原文自陈）—— 因为**「是尺子伪影还是真缺陷」还没判**（见下条）。
5. 🔴 **下一刀落在【材质 / 贴图侧】**（`A1630` 原文给的落点）：
   战场网格**几乎全是 `Everguild/UnlitAmbient`**（**unlit + 把光照烘进贴图**）
   ⇒ 嫌疑 = **贴图导入的 sRGB / 线性标志**、或那层 **`_APPLYAMBIENTCOLOR` tint 的算法**。
   ⚠️ **还没查清。**
6. 🔴 **「是尺子伪影还是真缺陷」的判据**（`A1630` 原文指定）：**拿我们自己 player 的真机截图**与原版实拍**比同一块区域**
   （同管线类别）。
   ⚠️ **这一条 2026-10-12 试过、没用上**：`-wfscene Battle` 起 player 抓到的是 `battlearenaaeldari`，
   但画面上**叠着整套战斗 UI**（均值 88.4 / p1 3 / p99 255）⇒ **与干净的原版实拍不可比**。
   ⇒ 要判这条**得先找一条没有 UI 遮挡的抓屏路**（例如**从 player 里只拍战场那台相机**）。

1. 🔴 **先把「真缺陷 vs 尺子伪影」判掉**（§二 第 6 条）—— 找一条**无 UI 遮挡**的抓屏路，比**同一块区域**。

   **把天空区从怀疑名单里划掉**（它已经是准的）。
3. **材质 / 贴图侧排查**（§二 第 5 条，`A1630` 指定的落点）：
