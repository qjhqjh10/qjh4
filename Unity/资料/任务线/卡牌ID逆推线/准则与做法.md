## 四、已验证的结论（⛔ 别推翻）

**完整清单在正本 §七·1；这里只留最容易被人「顺手改回去」的五条：**

1. **一张卡没有专属 C# 类**：全部卡共用「数据 + 一个 switch 分发」；按卡名/卡 id 分支的代码 = 0。
2. **枚举的主槽位按 10 递增留白（细分子项占邻位）**（`AbilityEffect` / `AbilityTrigger` / `CardArmy` …），**不是位掩码**。
3. **规则层内联、表现层才是指针**：`cardAbilities`/`activeAbility` 是 SO 内联结构；
   `cardImageReference`/`cardAnimations` 等是 `AssetReferenceTyped`（GUID）。
4. **id 前缀 → 阵营 1:1**；**32 位 hex 没有前缀**；**卡名不是主键**（重名严重）。
5. **`cards_engine.json` 的 id 现在就是原版真 id**（`K06` 已做完）；`poolTrueIds` 是历史迁移表，
   `poolIdsAreTrue=true` 时 ⛔ **不要反转它**。

## 五、已知的坑

1. ⛔ **别在 `assets_full` 里找卡 SO** —— 它 24 万个 JSON 里含 `cardAbilities` 的 = 0；
   真身是 allcards bundle / 旧 profile 缓存（见 `R_SO与触发代码链_可行性.md` §1·3）。
2. ⛔ **别把「旧快照」当「当前 build」** —— 旧包 1,192 张（2025-07-30），当前包 1,351 张；
   连**英雄血量**都在 2026 build 统一下调过（`报告.md:101`）。
3. ⛔ **别按卡名 join**：当前 build 有 108 个卡名有 ≥2 个对象；**同名不同 id 325 条**（`报告.md:58,99`）。
4. ⛔ **别把「B 档旁证」写成定论**（DT 稀有度 / draft pack / 预组共现都只是旁证）。
5. ⚠️ **`m_Name` 不等于 `uniqueId`**：资产名是 `33 EmperorsChildren-Heldrake` 这种带序号的名字。
6. ⚠️ **本地化键按 id 建**，不是按 `cardName`：`Card_Name/<uniqueId>`；
   `refNameId` / `cardDescriptionTextReferenceId` 等**非空时会覆盖键**（正本 §5·2）。
7. ⚠️ **「查不到」之前先确认搜对范围**：卡 SO 不在 `assets_full`、动画 prefab 在 `*cardanims*` 包、
   语音 clip 在 `*cardassets*` 包 —— 一个包里没有 ≠ 本地没有。
8. ⚠️ **别把「统计数」写死**：张数/条数会随包、卡池、生成器变；引用时现读。
9. ⚠️ **GUID 反查资产名不用 Addressables 目录**：直接枚举本地 bundle 的 `m_Container`
   （旧 `guid_map.tsv` 覆盖更小就是因为它从目录出发，`T14…报告.md:30-37`）。
10. ⚠️ **「枚举里有」≠「有样本/能跑」**：83 个 effect 里 26 个当前 build 0 张卡使用；
    `discardFromHand` / `autoPlayFromHand` 这类**在我们引擎里连动词都没有**（正本 §3·3）。
