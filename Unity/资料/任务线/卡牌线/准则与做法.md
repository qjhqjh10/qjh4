## 一、这条线是什么

**定义（照 `资料/任务_卡组卡牌战斗.md` §二 节头与类型体系）**，卡牌线 = 两半：

| 半边 | 管什么 | 主件（改这里之前先看） |
|---|---|---|
| **卡表数据** | `cards_engine.json` · `card_ids` · `desc`/`descZh` · `keywords` · 稀有度 · 卡名 · 官方本地化 · **真值回填** | `工具/gen_cards_engine.py` · `工具/gen_card_id_truth_index.py` · `数据/游戏数据/card_stats.json` · `数据/游戏数据/cardface_fixes.json` · `数据/卡牌翻译/zh_cards.json` |
| **卡面渲染** | `CardView` / `CardText` / `CardIcons` / 卡框 / 立绘 / 关键词图标 / `ArtBaker` | `MyGame/Assets/CardPresentation/Core/CardView.cs` · `Core/CardText.cs` · `Core/CardIcons.cs` · `Core/CardWinBox.cs` · `Core/Badges.cs` |

⚠️ **交界的账按「谁的主件在动」判**（`任务线/README.md` §四）：
· **卡面美术 / 场上卡体 / 特效** → **表现·特效线**（那是 `任务_卡组卡牌战斗.md` **§四**，⛔ 不属本线）；
· **卡面**排版**的几何**（费用/三围/底板的位置尺寸）→ **本线**（动的是 `CardView`/`CardText`）；
· **卡组编辑窗 / 收藏窗 / 详情窗**的版面与交互 → **界面线**；
· ⛔ **同一笔账不许两边都列**（铁律 6）。

🔴 **三条最容易犯的**：
1. **⛔ 别改生成物**（`cards_engine.json` / `card_icon_plan.json` / `card_vfx_by_card.json` 都是**生成物**）—— 一律改**生成器或源表**，再跑生成器。
2. **⛔ 别拿旧结论当判据** —— 本线**订正过多次**（例：「逐卡 VFX 等 `allcards`」是错的、「`CardIcons` 那层 `[Attack]` 是 OCR 猜的」是错的）。**引用前先看那一行有没有订正痕**。
3. **⛔ 别按 token 名猜属性** —— `[weapon]` 其实是**紫圈枪 = 远程**；`[Armor]` 在 `+N Attack … +N Armour` 这个搭配里**也是枪**；真护甲卡面一律写裸词 `Armour 1`（不带方括号）。**照 PnP 卡图逐张核**（铁律 7）。

## 三、干一件活的流程（**六步**）

```
① 读「本任务文件」→ 它里面有判据与出处；不够就回旧表行 / 判据件 / 普查产出
② 判据不够 ⇒ 先补判据（派只读子代理去勘），⛔ 别凭印象动手（铁律 1、10）
③ 动手改（生成器 / 源表 / .cs）→ 改完 `.cs` 立刻跑 `bash d:/4/Unity/工具/typecheck.sh`（**秒级，唯一挡「编不过」的**）
④ 落盘：把「查出的事实 / 坑 / 判据」写进该去的地方（见 §五）
⑤ 收工：按 `任务线/README.md` §五 那四步改总表
⑥ ⛔ 不跑自检、不起 player（见 §四）
```

**五条本线的硬规矩**：
1. 🔴 **改卡名 / 卡表之前，先拿 `zh_CN.csv` 的英文键精确查一遍**（**PnP 是印刷品** —— 2026-09-24 因它翻车一次、**19 条已回滚**）。同名/自造卡会命中**另一个阵营**的同名条目 ⇒ **手段本身要带闸**。
2. 🔴 **`prebuilt_decks_full.json` 永远别拿来改牌** —— 会碰**教程副** + **毁牌序**。预组要改走 `工具/gen_prebuilt_decks.py`。
3. 🔴 **卡池张数一律写成指针**（现读 `cards_engine.json` 的 `count`）—— ⛔ 别在文档里写死（§七 已四换口径）。
4. 🔴 **一条判据只留一处**：本线**两处写同一条规则**的先例已有（`BattleDriver` 手搓 `playable` vs 引擎的 `RuleCore.CanPlayCard`）⇒ **先 `grep` 谁在用**再改。
5. 🔴 **改 `desc` 不是纯文本改动** —— `desc` 是**引擎的唯一解析输入**，任一字符变化都会动 `工具/ruleprobe/PlayProbe.cs` 的 `PinnedPlayMd5` 哨兵与全池那几条断言。⚠️ **`descZh` 不进解析器**（全仓零调用点）⇒ 改中文相对安全。

## 四、验收口径（**现行：只做不验**）

🔴 **用户 2026-10-15 第八次收口**：「**之后暂时别检查，先完全复刻，复刻好了再检查**」。
⛔ **不跑 `*.Run` 自检**（一条都不跑）· ⛔ **连「起 player 截图看界面」也停**。
✅ **只留两件**：**秒级类型检查**（几秒，不算检查）· **「原版 vs 我们」的缺口普查**（那是复刻的**输入**，不是验收）。
🔑 **判别句**：**这件事是在「找出还没复刻的」，还是在「验证我刚改的对不对」？** 前者做，后者停。
🕐 **什么时候才验**：**复刻完成之后**统一验收（进游戏 → 截图 → 点）。

## 五、形成文件说明（**任务文件怎么写**）

### 5·1 一件活一个文件，文件名 `T<两位序号>_<短名>.md`
**必须有的六节**（⛔ 别写成散文）：
```markdown
# T0N · <一句话说清这件活>
> 状态 / 关联 A 编号 / **判据全集在哪**

## 一、要做什么（**能一句话说清「做完之后卡面/数据有什么不同」**）
## 二、判据（**逐条带出处**：PnP 卡图路径 / `文件:行号` / 报告 `§`）
## 三、我们现状（现状**逐处**给 `文件:行号` 或「现读 = N 张」）
## 四、怎么改（**改哪个文件/哪个生成器、改什么**；分几步；先做哪步；⛔ 标明「不许整列照搬」的地方）
## 五、做完了怎么自检（**照当时的验收口径**：现在是「只跑类型检查」，将来是「进游戏点」）
## 六、还差什么 / 判不准的（⛔ **不许猜**，写「没查到 + 我搜过哪些词/哪些包」）
```

### 5·2 什么写进**任务文件**、什么**不**写
| 写进任务文件 | ⛔ 不写 |
|---|---|
| 判据（带出处） | `CLAUDE.md` 已有的铁律（**抄一遍就会过期**） |
| 我们现状 + 行号 / 现读数 | 别的任务已写过的东西（**给指针**） |
| 改动清单 + 先后 | 大段反编译原文 / 大段卡片原文（**给 `文件:行号`**） |
| 「还差什么」 | 已经做完的过程叙述 |

### 5·3 详情**超过 ~150 行**就再拆
判据原文太长 ⇒ 搬进 `资料/待办判据_*.md`（**编号同一套**），任务文件只留「一句话 + 指针」。

### 5·4 收工后的归档
按 `任务线/README.md` §五。**已完成的详情文件搬进 `资料/历史/已收口_卡牌线_<日期>.md`**（原文一字不改）。

## 六、本线已知的坑（**继续加，⛔ 别删**）

1. 🔴 **旧台账有 59 行「状态」格是缺失的** —— `资料/任务_卡组卡牌战斗.md` 里**该文件现读 359 行只有 2 格**（全文件；⚠️ 别写死，现读为准），
   **§二 卡牌线 76/87 行没有状态格** ⇒ GFM 直接渲成 2 列。**后果**：抄状态时**别以为「没有状态列 = 没状态」** ——
   **回判据件**（按编号搜 `## Axxxx`）**或按行内文字判**（`⇒ 要做` / `✅ 已修` / `📌 结论` / `⛔ 等远端`），判不出写 `？` 并说清。
2. 🔴 **同一份旧台账自己写着读法**（`:19`）：**行内写 `✅ 已修` = 主件已改完、但这条账【还开着】**（后面写着尾巴）⇒ **看到 `✅` 别当已销账**；
   只有抬头写成 `✅ **\`Axxxx\`** ✅ … 会话已落地` 的才算**已闭**。
3. ⚠️ **行内的**裸 `|`**会把单元格切开** —— `A1678` 那一行因为正文里有 `\|Δ\|`，整行变成 6 条竖线、**状态格被撑坏**。
   ⇒ **写行/改行时判据 = 该行以 `|` 收尾且竖线数正好**（3 列 = 4 条）；⚠️ 数的时候要排除 GFM 转义的 `\|`。
4. 🔴 **`cardface_fixes.json` 是 CRLF**，而且**改它最容易造 JSON 重复键**（`json.loads` 静默取最后一个）⇒ **先 `grep` 键名、改完复扫重复键 = 0**。
5. 🔴 **`desc` 是引擎唯一解析输入** ⇒ 动一个字符就会移动 `PlayProbe.PinnedPlayMd5` 哨兵与全池断言（见 §三·5）。
6. ⚠️ **`cards_engine.json` / `card_icon_plan.json` / `card_vfx_by_card.json` 都是生成物** —— 手改会被下一次跑生成器覆盖（**静默**）。
7. ⚠️ **「我们卡池」与「原版快照」的落差永远是移动目标**：快照是 **2022 时代 / 2025-07-30**，我们池**比它新**（多 118 张、另有 186 张是快照独有）⇒ **任何 join 都要先看年代**。
8. ⚠️ **`card_stats.json` 现读 1213 条 ⇔ 我们卡池 1127 张**（差出来的多是 `environment` / 占位行）⇒ **两个数不是同一个东西，⛔ 别对等**。
