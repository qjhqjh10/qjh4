## 三、动手流程

1. 先确认**承载窗**能挂页签（`ParentEventWindow` 的 `TabbedWindowComponents`）。
2. 用 `menu_dump.py` 取该页**真值**（节点 / rect / sprite / activeSelf），⛔ 不照截图量参数。
3. 建页：窗参 + 树 + 文案逐值对 prefab；**远端数据留空并出声**（不静默、不编）。
4. 接消费口：`PurchasePremiumPanel`（已有零件）、抽卡特效走 `VfxMap` 的事件。
5. 改 `.cs` 后立刻 `bash d:/4/Unity/工具/typecheck.sh`（0 错）。
6. **不跑自检、不起 player**（现行口径：复刻完成再统一验收）。

## 四、已知的坑

1. 🔴 **活动数据全在远端** —— 本机只有 prefab/类桩；「长得像」不等于「数据对」，⛔ 别编奖励/价格。
2. 🔴 **`ILiveOpsTab` 的「事件 → Tab prefab」映射表还没读到** —— 开工前先补这一步（否则建出来的页挂不上活动）。
3. **过期活动不做**（用户 2026-09-17）—— 建页不等于补过期内容。
4. **抽卡特效 `<FRAC>_CardDraw` 缺 11 个阵营**（特效线 `T09`，等远端）⇒ 页建好后那一拍可能没有特效，**如实记**，别拿别的阵营顶。
