## 二、§九(f) 逐条：旧期望值 / 新期望值 / 算式与出处

**原版公式（逐句读出来的，不是我们的近似）**：`α = Lerp(A, A × colorVariation, t)`、`t = Clamp01(|cos(blinkSpeed × currentTime)|)`

- `d:/2/tools/decomp_full/BlinkGraphic__Update.c:17` —— `uVar3 = FUN_180488130(*(float*)(param_1+0x28) × *(float*)(param_1+0x30))`
- `:18` —— `& DAT_1834b2e60`（我复算 = 4B int `2147483647` = `0x7FFFFFFF` ⇒ **`Mathf.Abs` 的位掩码**）
- `:19-24` —— 夹取（上界 `DAT_1834b2bb8`，我复算 = **1**）⇒ **`Clamp01`**
- `:27-28` —— `a' = (A×v − A)×t + A` = **`Lerp(A, A×v, t)`**（新值写在 `Color` 的高 32 位 = a，低 32 位原样带过）
- `:30-32` —— `currentTime += Time.deltaTime`（**在写颜色之后**；时钟基 = scaled，F1 已改）
- 两个常量：`BlinkGraphic__.ctor.c:4-5` —— `0x28 = 0x3f800000` = **1.0**（blinkSpeed）· `0x2c = 0x3f000000` = **0.5**（colorVariation）
- **`FUN_180488130` = `Mathf.Cos`**：我自己复算了那条独立的判据 ——
  `UnityEngine.UI.Extensions.EasingCore.Easing___Get_g__inOutSine_0_30.c:7-8` = `(1 − F130(π·t)) × 0.5`
  （`read_literal` 复核 `0x1834b2e90` = **3.14159** · `0x1834b2bb8` = **1** · `0x1834b2bb4` = **0.5**）；
  easing 的 InOutSine 必须 `g(0) = 0` ⇒ `F130(0)` 必须是 **1** ⇒ **只能 cos**（`sin(0)=0` 会得 0.5）。
- `A` = **原色 = 1**（`_tapBase = tapLb.color`，建的时候传的是 `Color.white`；原版那件 TMP 的 `m_Color` 也是 `(1,1,1,1)`）
