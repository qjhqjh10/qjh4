- **改前**：没有这个方法（`ShakeSeedBase` 只能靠调用方手动赋值，且没人赋）。
- **改后**：

  ```csharp
  public static void AnchorShakeSeedToBattle(int battleSeed)
  {
      SettleShake();                    // ① 上一局没跑完的那次先收掉（幂等；`ShakeCamera` 开头本来也收）
      ShakeSeedBase = battleSeed;       // ② 本局第一下 = `ShakePhaseOffset(battleSeed)`

      LastShakePhase = 0f;
  ```

- **为什么**（对应验收标准 ①②③）：
  - ② ⇒ 验收①「两局之间第一下的相位不同」（不同对局种子 ⇒ 不同基线）；
