### 1.2 边宽怎么换成卡单位（**这条是本账的关键**）

照 **uGUI 自己的算式**，不是我推的：

```
com.unity.ugui/Runtime/UGUI/UI/Core/Image.cs:1157
    Vector4 adjustedBorders = GetAdjustedBorders(border / multipliedPixelsPerUnit, rect);
Image.cs:741  pixelsPerUnit           = spritePPU / canvas.referencePixelsPerUnit
Image.cs:757  multipliedPixelsPerUnit = pixelsPerUnit * m_PixelsPerUnitMultiplier
```

⇒ **画出来的边宽 = 边宽px × canvasRefPPU ÷ (spritePPU × ppuMul)**，单位 = `rect` 的单位（= 卡单位）。

- `canvasRefPPU`：原版 `m_ReferencePixelsPerUnit` **全库只有一个值 `100`** ——
  `07_场景/battlearena1/Canvas/*`（2 处）+ `bundle_menus*` 的 Canvas（30 处）实测均为 `100.0`（`grep -rh m_ReferencePixelsPerUnit | sort | uniq -c`）。
- `spritePPU = 100`（sprite 自己的 `m_PixelsToUnits`）⇒ **1 贴图px = 1/14.7 卡单位**。
- 🔴 **是 `÷ 14.7`，⛔ 不是 `× 14.7`** —— 与本仓已渲图核过的 `MenuDraw.Nine`（左栏 `Highlight`：30 ÷ 0.92 = **32.61**px）同一条算式；
  也自洽：32px 的图按 14.7 当 PPU ⇒ 自然尺寸 = 32/14.7 = **2.177 卡单位**，与卡面宽 2.0927 同量级（作者就是拿这个乘数把 32² 的小图放到卡面上）。
- 溢出检查：左+右 = 0.9524 < 1.7766 ✓ · 上+下 = 0.6122 < 1.55 ✓ ⇒ `GetAdjustedBorders` 那一步**不出力**（代码里仍留着，逐轴）。
