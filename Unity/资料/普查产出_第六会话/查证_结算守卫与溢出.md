### Q3 溢出伤害按什么算 —— 🔴 **有溢溅，是 Stomp 不是 Blast**
- **Blast 不是溢出**：`:get_CurrentBlast` = 关键词 `0x15e`；`BattleManager__ShouldTriggerAdjacentDamage.c:8-9` =
  `attacker.CurrentBlast > 0`；`BattleManager__ResolveTraitAdjacentDamage.c:18-24` 伤害 = 该关键词值，
  对**每一个**相邻单位各打一次（循环在 `_ResolveAttack:1020-1045`）。
- **Stomp 才是溢出**：位置 `_ResolveAttack:1057-1112`（主伤害 `:999` **之后**、反击 `:1114` **之前**）。
  判据 `BattleManager__ShouldTriggerStompDamage.c:20-36`：攻方 `HasCurrentTrait(0x4d8)` ∧ 目标 `(+0x68) < 0` ∧ 相邻数 > 0。
  数值 = `|target.CurrentSurvivor|`（`_ResolveAttack:1073-1090` 现取、负值取绝对值）。
  落点 `:1061-1068` 取**第 0 个**相邻单位、数量 >1 时 `:1065 GetRandomInt` **随机 1 个**。
  `BattleManager__ResolveTraitStompDamage.c:18-23`：`DamageInfo(源=攻方, 值=溢出, type 0xb)` → `GetAdjustedDamage` → `ReceiveDamage(相邻单位, 0xf, …)`。
- 🔑 **与我们实现的等价性**：我们的判据是 `dealt > hpBefore`、溢出 = `dealt − hpBefore`；
  原版是「打完后的裸血 `+0x68` < 0」、溢出 = `|裸血|`。因为「血 = 打前血 − 实际伤害」，
  两者在**没有其他东西在中间改血**时**恒等**。⚠️ 有 `Bastion` / 别的减伤 / 同批多段伤害时会分叉 —— 我们**都没做**。
