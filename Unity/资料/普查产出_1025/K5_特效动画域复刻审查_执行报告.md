## 结论（三行）

1. **player 构建里编译失败的那两条 shader 已修**（`WFParticlePremultiply` / `WFEclipseTau`）。根因 = `[Toggle(KEY)] KEY` 与 `CBUFFER` 同名变量，关键字开启时 Unity `#define KEY 1` ⇒ 重定义。改法与工程内同族件（`WFParticlePremultiplyGreyscale.shader:109` / `WFUnlitUVScroll.shader:120`）一致：**只留 `Properties` 里那一条**。全仓 46 个 `.shader` 扫过，**再没有第二处这类撞车**。
2. **特效生命周期原来有一处整条走错**：我们「到寿命 → 先 `Exit()`（含停发射）→ 再活 `exitDestroyTime`」，原版是「到寿命 → **直接 `Destroy(gameObject, destroyTime)`**，不调 Exit / 不停发射 / 不播 exitSounds」。已按反编译方法体改齐（影响 **859** 个实例 = `destroyTime > 0` 且非 `preventDestroy` 的那一档），顺带订正了 `exitSounds` 的**时间基准**（原版从 **Play** 起算，我们原来从 Exit 起算）。
3. **还查出两条跨线缺陷（本批不改，已写清判据与修法）**：① `WarpforgeEffectPlayer.DoDestroy()` 在生产代码里**几乎没有调用点**，而 39 行「一次性播出」的 `preventDestroy` 特效没有任何人持有/收尾 ⇒ **整局驻留**；② `destroyTime == 0` 的 38 个**持续型**特效被我们按 `natural` 提前收掉 ⇒ 状态还在、表现已经消失（修它必须两半一起改，否则会变成新的泄漏）。

## 二、差异清单

判定格式：**原版判据 → 我们 → 差在哪 → P + 状态**。

### P0

**P0-1 · 两个自建 shader 在 player 构建里编译失败（已修）**
- 原版判据：无（这是我们自建件，判据是**同族件的既定做法** + Unity 的 `[Toggle]` 语义）。
- 我们：`WFParticlePremultiply.shader` 的 `CBUFFER_START(UnityPerMaterial)` 里声明了 `float _SOFTPARTICLES;`，而 `_SOFTPARTICLES` **同时是关键字**（`[Toggle(_SOFTPARTICLES)]` + `#pragma multi_compile_local _ _SOFTPARTICLES`）；`WFEclipseTau.shader` 同形（`float _APPLYAMBIENTCOLOR;`）。
- 差在哪：**关键字一开，Unity `#define _SOFTPARTICLES 1` ⇒ 与同名变量重定义**，整份 shader 编不过 ⇒ player 里走 FallbackError（品红/不渲染）。实据：`_tmp_view/20261025_pbuild.log`（8 条 `Shader error in`，只有这两个 shader；`redefinition of '_SOFTPARTICLES' at …(81)` / `… '_APPLYAMBIENTCOLOR' …(96)`）。
- **已修**：删掉 CBUFFER 里那两格（本文件都只走 `#ifdef`、不读值），并留下判据注释。全仓 46 个 `.shader` 重扫（剥注释后按 `[Toggle(K)]` ∩ `pragma 关键字` ∩ `CBUFFER 变量` 取交集）：**除这两处外 0 命中**（`_ENABLEVERTEXSTREAMS` 是"潜在"但不是 BREAK —— 它没有 pragma，永远不会被 `#define`）。

### P1

**P1-1 · 「到寿命」那条路我们走错（已修）**
- 原版：`AnimFXController__OnEnable.c` = `currentTime = 0; if (destroyTime > 0 && !preventDestroy) Object.Destroy(gameObject, destroyTime);` ⇒ **到点直接销毁，不调 `Exit()`**。
  全量 grep 调用点：`AnimFXController__Exit` 全库**只有 2 处**（`BattleCardUI__CleanStatusAnims.c` / `__RemoveStatusAnim.c`，都是状态动画收场）。
- 我们（改前）：`Tick` 到 `_lifetime` 先 `Exit()`（= 发 `OnFinished` + 广播模块 `Exit` + **停发射**），再等 `exitDestroyTime`（默认 3s）销毁 ⇒ ① 多播原版不播的退场动画/`exitSounds`；② 每个自毁效果**多活 3s**。
- 差在哪：整条时间线的语义（不是参数）。
- **已修**：新增 `DestroyAtLifetime()`（到点**直接销毁**：不调 Exit、不广播模块、不播 exitSounds、不发 `OnFinished`），`Tick` 改走它；`ExpectedLifetime` 同步改成 `_lifetime`。影响面 = **859 / 990** 个实例（现读拆分：`destroyTime>0 且 !preventDestroy` = **859** 走这条计时路 · `destroyTime>0 但 preventDestroy` = **93** 不排销毁 · `destroyTime==0` = **38** 也不排销毁）。

**P1-2 · `Exit()` 里我们多了一句「停发射」（已修）**
- 原版：`AnimFXController__Exit.c` 只有三件（`OnFinished?.Invoke()` → `foreach (m in modules) m.Exit()` → `exiting = true` → `Destroy(gameObject, exitDestroyTime)`）—— **没有 `ps.Stop`**。
- 我们：额外 `ps.Stop(true, StopEmitting)` ⇒ 收尾窗口里原版还在发射，我们先停了。
- **已修**：删掉那句（停在 `DestroyNow` 的 `Destroy` 上，与原版一致）。

**P1-3 · `exitSounds` 的时间基准错（已修）**
- 原版：`AnimFXController__Update.c` 对 `sounds[]` 与 `exitSounds[]` 传的是**同一个 `currentTime`**（`+0x60`，从 Play 起算、Exit 不复位）；`PlaySoundOnTime__Update.c` 判据 = `elapsed < played * timeInterval + time`。
- 我们（改前）：`elapsed = _time - _exitAt`（从 **Exit** 起算）——与 `资料/AnimFX_实现与接线.md` §11.4 那句「`exitSounds` 的 `time` 也是从 `Play` 起算」**自相矛盾**，**代码这一侧错**。
- **已修**：`elapsed = s.onExit ? (_exiting ? _time : -1f) : _time`。影响面 = `exitSounds` 7 条。

**P1-4 · `DoDestroy` 在生产里几乎没有调用点 + `preventDestroy` 特效一次性播完无人收（跨线，未改）**
- 原版：`BattleManager__RemoveDestroyableAnims.c` 在两本 **per-slot 字典**（`+0x290` 下的 `+0x2d0` / `+0x2d8`）里查到该格登记的 GameObject ⇒ `GetComponent<AnimFXController>()` ⇒ `DoDestroy()`；`DoDestroy` = 「有模块 ⇒ 只广播、自己不死；没模块 ⇒ 销毁」。
- 我们：`WarpforgeEffectPlayer.DoDestroy()` **生产调用点只有 1 条**（`OnAnimationEndEvent` → 虫群合并）；`CardEffects.Play` 是 `Action<string,Vector3,Transform>`（**无返回值**）⇒ 调用方**拿不到实例**，也就无从 `Exit`/`DoDestroy`；`KillAll()` 在生产代码里**0 调用点**。
- 差在哪：**39 行「一次性播出」的 `preventDestroy` 特效**（17 个效果 / 37 个 (卡,效果) 对；`play` 27 + `trigger` 9 + `ability` 3）播完**永远不消失**。
  现读名单：`MarkerlightSource`(TAU10/18/25/35/37) · `Recon Hit|Scan|Enemy Hand` 系列(AM43/UM89/GSC67/73/DA42) · `Teleport Recall|Trait Summon|Trigger Effect Quick`(DA51/57/20/48 · 1 张老 id) · `Tau Buff Ranged`(5 张) · `MarkOfSlaanesh_enchantment`(6 张) · `Buff EC Stimulate passive`(EC51) · `CoordinatedEngagement`(TAU58) · `Explosion Hive Fleet Arrival Tendrils`(GSC59) · `Orbital Bombardment Enemy Warlord`(UM118) · `Tidewall Gunrig`(TAU63)。
- 修法（不属本批白名单）：`BattleDriver` 在一次**非 trait 帧**的 `CardEffects.Fire` 那条路上拿到实例（需要 `CardEffects.Play` 或新口返回 `WarpforgeEffectPlayer`）并按**格位**登记；单位离场走 `DoDestroy()`（原版那一跳）。
- **只记录**（铁律 11：要做，排后面）。

**P1-5 · `destroyTime == 0` 的 38 个持续型特效被我们提前收掉（跨线，未改）**
- 原版：`destroyTime == 0` ⇒ `OnEnable` 那个 `if` 不成立 ⇒ **不排销毁**；现读 990 个实例里 **38** 个是 0（`InvulnerableEffect*` / `CamouflageEffect` / `FlyingEffect` / `BloodThirst*` / `Aura_WhileInPlay_*` / `ShieldTraitEffect_Idle*` / `Blind_continuous_effect` …），由 `BattleCardUI.CleanStatusAnims` / `RemoveStatusAnim` 在**状态消失**时 `Exit`。
