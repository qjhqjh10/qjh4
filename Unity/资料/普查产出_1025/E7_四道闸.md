## 三 · ③ `tainted` —— 异侧 ∧ 载体(`thisCard`) Hero ∧ 候选 tainted ∧ !非隐身-vanguard

### 1 · 判据（反编译原文结构）

`RawCardScript__IsValidActiveAbilityTarget.c:98-102`（**接受**的条件，整串为真才放行）：

```
( HasCurrentTrait(候选, 0xa0=160) == 0 || HasVanguardTrait(候选) )      // :98-99
|| ( 候选.isPlayer == thisCard.isPlayer )                              // :100
|| ( get_cardType(thisCard) != 10 /* Hero */ )                         // :101
   && CardScript.IsInPlay(候选)                                        // :102
```

⇒ **拒绝** = 上面整串为假：

**候选 tainted ∧ !HasVanguardTrait(候选) ∧ 异侧 ∧ 载体(`thisCard`)卡型 == 10 (Hero)**

配套：

| 件 | 原版 | 出处 |
|---|---|---|
| `HasVanguardTrait(u)` | `HasCurrentTrait(u, 0x46=70 stealth) ⇒ 恒 false`；否则看 `0x3d4=980 vanguard` | `EntityScript__HasVanguardTrait.c:8-13` |
| 「载体」是谁 | `get_cardType(param_2)`，`param_2` = **`thisCard`（施放者）** | `RawCardScript__IsValidActiveAbilityTarget.c:72` / `:101` |
| `Hero = 10` | `enum CardTypeOptions { Minion=0, Hero=10, Tactic=20, Whispers=40 }` | `d:/2/Warpforge_code/Scripts/Assembly-CSharp/CardTypeOptions.cs` |
| 同族（攻击侧） | `tainted` 只在**攻方是督军**时挡，且目标非「非隐身 vanguard」 | `BattleManager__IsValidAttackTarget.c:186-190` |

### 2 · 实现

`Core/RuleCore.cs:10303-10306`：

```csharp
if (opposite && t.Has(ConditionEval.Tainted)
    && !HasVanguardTrait(t)
    && caster.Card != null && caster.Card.Type == "hero")
    return RuleCodes.ErrTarget;
```

助手 `Core/RuleCore.cs:10324`（照原版三行逐字）：

```csharp
static bool HasVanguardTrait(UnitState u)
{
    if (u == null) return false;
    if (u.Has(KeywordTable.Stealth)) return false;   // 原版 :8-11 —— 带 stealth ⇒ 恒 false
    return u.Has(KeywordTable.Vanguard);             // 原版 :12 —— 0x3d4 = 980 vanguard

```

> ⚠️ **载体判据是「卡型 = hero」，不是「坐在督军格」**：用的是 `caster.Card.Type == "hero"`
> （`CardTypeOptions.Hero = 10`），⛔ **不是** `caster.IsWarlord`。断言里专门把一张 hero 卡摆在
> **普通格**（`IsWarlord = false`）当施放者来区分这两种写法。
