## 问 1 原版怎么切环境

- **结论**：**运行期**切，不是"每环境一个场景/prefab"那么分。一条环境 = **1 条 `ScenarioEnvironmentConditionSO`**（雾/环境光/开关）+ **可选 1 个 prefab**（43 个，实例化到 `Camera.main`）。55 条 SO 里 13 条 Default 的 `scenarioObjects` 全空 ⇒ 默认态**不建任何 prefab**。
- **调用链**（逐跳，判据全在 `d:/2/tools/decomp_full/`）：

  **① 默认态（开场）**
  `场景里的 EnvironmentConditionsController` → `ScenarioEnvironmentConditionsManager__Awake.c`
  → `ApplyEnvironment(mgr +0x20 = defaultEnvironment, instant:true)`

  **② 换环境（打进攻卡生效）**
  `BattleManager._ApplyOffensiveAndDefensiveEffects_d__337__MoveNext.c`（末段 `:203-211`）
  → `BattleManager__ApplyEnvEffect.c` → `EnviromentalEffectCardsSO__GetEnviromentalEffect.c`
     （按 `card.army(+0x2c)` 命中阵营条目 → `OffensiveCardReferenceData.enviromentalEffectVFX.Load()`）
  → `ScenarioEnvironmentConditionsManager__ApplyEnvironment.c(BM +0x100, so, instant:false)`

  **③ `ApplyEnvironment`**（`ScenarioEnvironmentConditionsManager__ApplyEnvironment.c`）
  `CurrentEnvironment == so ⇒ return`（不重播）→ `旧.DisableEnvironment(instant)` → 记新的
  → `ScenarioEnvironmentConditionSO__EnableEnvironment.c(so, instant)` → `SetRegisteredBlendeablesState(返回值)`

  **④ `EnableEnvironment`**（`ScenarioEnvironmentConditionSO__EnableEnvironment.c`）
  `ApplyAmbientColor`（`RenderSettings.ambientLight = so.ambientColor` **无条件赋值** + `Shader.SetGlobalFloat(ambientColorBlend)`，时长 `so+0x18 blendTime`）→ `ApplyFog` → `so+0x48 scenarioObjects` 非空则 `AssetReferenceTyped.Load()` → `Instantiate(prefab, Camera.main.pos/rot)` → 对子树每个 `IScenarioEnvironmentBlendeable` 用 `lVar7`（duration `instant?0:blendTime` · direction **true** · target 1.0）逐个 blend；**返回 `lVar8`**（duration 同 · direction = `so+0x50 defaultScenarioObjectsState`）给**场景里已登记**那批。

- **默认那一态怎么来的**：`Awake` 里 `ApplyEnvironment(defaultEnvironment, instant:true)`。13 场共 **6 个**不同 Default SO：**8 场**（arena1 · astramilitarum · darkangels · emperorschildren · genestealers · sororitas · spacewolves · tauviorla）→ `Ultramarines Default Enviromental Condition`（全中性 `(1,1,1,0)`）；其余 5 场（arena2→Orks · arena3→Necrons · aeldari→Saim Hann · blacklegion→Black Legion · leviathan→Leviathan）→ 本阵营 Default。**13 条 Default 全是 `ambientBlend=0` / `fogDensity=0` / `scenarioObjects` 空** ⇒ 默认态只动 `ambientLight`。出处 `资料/普查产出_0920/场景光照与后处理_原版规格.md` §2.2（含逐场 6 个 SO 的颜色表）。
- **另外 3 态是不是只有打进攻卡才出现**：**是，判死**。传非 default SO 的**唯一**调用点 = `BattleManager__ApplyEnvEffect.c:19`；它的**唯一**调用点 = `_ApplyOffensiveAndDefensiveEffects_d__337__MoveNext.c`（进攻卡那条协程）。进攻卡选中 = `SetupEnviromentalEffectPhase` → `ClickChosenCardDone` → `matchData.playerEnviromentalEffect(+0x90)`；选到"空卡"（= 不使用进攻卡）⇒ **环境不动**。
- **🔴 阵营口径（决定"13×4"成不成立）**：**场与环境是同阵营配对，且都是【后手那一方】的阵营**。
  · 场：`SearchOpponentManager__StartBattle.c:57` `GetBattleArena(uVar5)`，`uVar5` 初值 = `MatchData.playerRawBattleData(+0x58).deckWarlord(+0x18).army(+0x2c)`；若 `SupportMethods.GetPlayerGoesFirstWithInitiative` 为真（= **本机先手**）则换成 `enemyRawBattleData(+0x50)` 那条 ⇒ **拿的是后手方的阵营**。
  · 环境池：`BattleManager__GetEnvEffectCards.c` 的 army 取 `playerGoesFirst(+0x247)==0 ? playerManager(+0xC0) : enemyManager(+0xC8)` = **同样是后手方**。
  ⇒ **13 场 × 4 环境 = 52 这条配对是原版的**，`sweep_env_states.py` 的 `ARENA_ARMY` 映射对得上。
- **还差什么**：① 上面那条只覆盖**"搜索对手"**入口（`SearchOpponentManager.StartBattle`）—— 排位 / 回放 / 遭遇 / 教程是否走同一处 **没查清**；② `ScenarioEnvironmentConditionSO__TestToggleOn.c` 也调 `ApplyEnvironment`（调试用），**它有没有被正式流程调用没查**；③ 我**没有实测**过 `EnableEnvironment` 里那次 `AssetReferenceTyped.Load()` 在离线态成不成（见问 3）。
