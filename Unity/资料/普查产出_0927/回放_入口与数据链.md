## §D 🔴 数据形态：动作流 or 状态快照？有没有本地文件 / URL 的痕迹？

### D·1 结论：**是「一局的动作流 + 起始条件」，不是状态快照；而且没有本地文件、没有 URL —— 全程走 PlayFab CloudScript 的 JSON 往返。**

三条证据：

1. **载荷就是两串 `PlayerAction`**：`BattleRecordData.playerLog`/`enemyLog` = `List<PlayerAction>`，一条 = **8 个 int**（`typ/act/tget/tgtd/pos/num/at/ts`，`DUMP:119888` 段）。整局没有任何「棋盘状态 / 卡实例快照」类型的字段。
2. **重建靠的是「重开一局 + 重放 + 用同一串随机数」**：`BattleRecordData.rngNum`（`int[]`）从 `MatchData.randomNumbers` 来、`playerMulligan`/`enemyMulligan` 都被存下来、播放走 `ExecuteNextAction(log, ref index, …)` —— 这是**确定性重演**，不是回放录像。
