**`UIRankingListController` 的方法体语义（`dump.cs:110947` 字段偏移 + `decomp_full/UIRankingListController__*.c`）**

- `Initialize(provider)`：清空 `highlightMountPoint`/`listMountPoint` 的子节点与 `rows` 列表 → 存 provider → **无条件 `subMenu.gameObject.SetActive(false)`** → `provider.Initialize(this)` → `ChangeSeasonRankingView(true)`。
  ⚠️ 反编译里 `subMenu` 只做了 IL2CPP 的 null 检查（不做就抛 NRE）⇒ **嵌入版 `subMenu` 是 0，这条路径若真被走到会抛**。**我们没跑到实况，照实记为疑点**（见 §H）。
- `ChangeSeasonRankingView(bool showCurrent)`：`showCurrent` 存进 0x78；`timerCounter.gameObject.SetActive(showCurrent && showTimer)`；**`lastSeasonText.gameObject.SetActive(!showCurrent)`**；`changeSeasonButton` 的文字 ← `LocalizationManager.GetTranslation(showCurrent ? "MainMenu/RankedWindow/CurrentSeasonButton" : "MainMenu/RankedWindow/LastSeasonButton")`；末尾 `Refresh(!showCurrent)`。
  ⇒ `Initialize` 末尾传的是 `true` ⇒ **出厂 active 的 `Last Season Text` 会在运行时被关掉**（Timer 则由 `showTimer` 决定）。
- `AllowChangeSeason(bool)`：只做 `changeSeasonButton.gameObject.SetActive(value)`。调用点 = `Everguild.Ranking.PlayerRankingDataProvider.Initialize`，传的是 `!string.IsNullOrWhiteSpace(previousSeasonLeaderboardKey)` ⇒ **有上一赛季榜才显示这个按钮**。
  🔴 **文件命名坑**：这条逻辑在 `decomp_full/UIRankingListController__AllowChangeSeason.c` 里**装的是别的函数体**（函数名写着 `DraftModeDeckInfoPanel__ToggleEnergyInfo`）；`dump.cs` 的类/字段是可信的，**`decomp_full/*.c` 的文件名不可信**（两个同名小方法撞了）。
- `SetRanking(List<RankingRowData>)`：`for (i = 0; i < maxRows + 1; i++)` —— 行不够就在 `listMountPoint` 下 `Instantiate(provider.rankingRowPrefab)` 并 `String.Format(..., i)` 改名，然后每行调 `Config(data[i])`，超出的调 `Hide()`。⇒ **行数上限 = maxRows + 1 = 51**。
- `SetHighlightedRow(data)`：在 `highlightMountPoint` 下 `Instantiate(provider.rankingRowPrefab)` 并改名 → `ShowHighlightedRow(bool)` = `highlightMountPoint.gameObject.SetActive(bool)`。
- `SetTimer(Nullable<DataKey>)`：空 ⇒ `timerCounter` 关 + `showTimer=0`；有值 ⇒ 开 + `TimerDisplay.Initialize(key)` + `showTimer=1`。

- `Start()`：给 `changeSeasonButton` 的 `m_OnClick` 加监听 → `ChangeSeasonButtonClick()` → `ChangeSeasonRankingView(showCurrent == 0)`（即那个 'Last season' 键是**切换**键）。
- `PlayerRankingDataProvider.Initialize(controller)`（源码在 `decomp_full/Everguild.Ranking.PlayerRankingDataProvider__Initialize.c`）：**只有在 `GameModes.GetActiveEvent(playMode)` 有活动时**才 `SetTimer(活动结束时间)` + `SetTitle(本地化串)` + `AllowChangeSeason(有上一赛季榜)`。没有活动 ⇒ **什么都不设**（保留 prefab 出厂值：标题 `TOP PLAYERS`、Timer 开着、按钮开着）。
