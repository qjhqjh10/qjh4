```
Popup Content  VLG  MB 4572911609513549880
{ m_Padding 全 0 · m_ChildAlignment = 0 (UpperLeft) · m_Spacing = 25.0

  m_ChildControlWidth = 1 · m_ChildControlHeight = 0
  m_ChildScaleWidth = 0 · m_ChildScaleHeight = 0 · m_ReverseArrangement = 0 }
```

🔴 **推出来的内容高度算法**（这次能算准了）：uGUI `HorizontalOrVerticalLayoutGroup.CalcAlongAxis` 里

⇒ **我们 `BattleLogTab.cs` 里 `n * RowH + (n - 1) * RowGap` 这条算式是对的**（只是注释里的 `PreferredSize` 应改成 `MinSize`）。
