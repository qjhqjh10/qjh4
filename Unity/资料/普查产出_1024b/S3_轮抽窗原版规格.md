## 〇、读法与三条硬结论

1. **设计帧 = 1920 × 1080**。证据：`Draft Mode Timed Mode Window` 根 RT `sz=(1920,1080)`（`RectTransform_-7058060996923004182.json`）；`Draft Mode Menu Demo` 根是 stretch `(0,0)-(1,1)`（预制体不带 Canvas，挂进 1920×1080 的窗口画布）。下文所有 px 均为该帧下的 `m_SizeDelta` / `m_AnchoredPosition` 原值，**没有经过任何缩放换算**。
2. **两个窗口预制体**：`Draft Mode Menu Demo`（GameObject PathID -4574324006155814203，免费/常规轮抽）与 `Draft Mode Timed Mode Window`（PathID 7897407911885171434，限时活动轮抽）。两者共用同一套 4 个状态页类，但**限时版换了 Pay/Warlord 两个页的脚本**（`DraftModeMenuPayStateTimed` / `DraftModeWarlordSelectionStateTimed`），并在 Pay 页多出阵营进度条 / 联盟积分。
3. **状态页不是按钮页签**：`DraftModeMenuDemo.tabs` 只有 **4** 项（Pay / SelectWarlord / SelectPacks / Ongoing），切换靠 `GameWindowWithTabs.GetTab<T>() + ChangeTabCO` 按**类型**取页（`DraftModeMenuDemo__GoToState.c`），预制体里没有任何页签按钮节点。`Intro State` 是预制体里第 5 个 `WindowTabBase`，但**不在 tabs 列表里**，且 `GetTabFromState(0)` 落到 Pay 页类 ⇒ 它的激活者**没查到**（见 §七）。

### 读表前必读的三条规则

- `Image.m_Type = 1/2 (Sliced/Tiled)` 时 `m_PreserveAspect` **完全不生效**；本表照抄 `PA` 值，施工时不要依赖它。
- `UIGradient` 角度是 `(sin, cos)` 语义。轮抽窗里没有独立 UIGradient 组件，颜色渐变只出现在按钮材质 `EverguildButtonMaterialModifier` 的 shader 上。
- **`m_Border` 不在 Image 上**（Unity 的 Image 没有该字段），Sliced 角块 = `Sprite.m_Border ÷ m_PixelsPerUnitMultiplier`。本 bundle 引用的 Sprite **全是外部依赖**（`m_FileID ≥ 2`），Sprite 资产未随包导出 ⇒ **角块像素值查不到**（见 §五）。
