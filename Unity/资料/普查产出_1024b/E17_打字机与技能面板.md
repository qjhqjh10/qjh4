## 三、顺手核：`DoReanimate` 的广播口径（只核、未改 `RuleEngine/**`）

**问题**：我们墓地退路走 `DeployFree`（会发 190 `OtherUnitSummoned` / 195 `ThisUnitSummoned`）；
原版「从墓地翻回来」是否也走 `_ResolveSummonUnit`？

**结论：不走，而且原版根本没有「墓地翻回来」这条路。**

| 环节 | 原版证据 |
|---|---|
| 入口 | `AbilityLogic__PlayAbility.c:1753` → `BattleManager__AddTransformFromRemnant`（能力码 `0x1AE`）；后者 `BattleAction___ctor(…, 0x48, …)` 入队（`BattleManager__AddTransformFromRemnant.c`） |
| 结算 | `BattleManager__ResolveTransformFromRemnant.c:85-93` → `CardScript__TransformFromRemnant` → `BattleCardUI.ChangeCardToRemnant(…, callback)` |
| 回调做了什么 | `BattleManager.__c__DisplayClass555_0___ResolveTransformFromRemnant_b__0.c`：`ResetToValuesInHand` → **`BroadcastUnitReanimated`** → `SetAsUnitInPlay` → `ResetSummonSickness` → `ActivateTraitsOnSummonOrEnchantment` → `UpdateWhileInPlay` → `CheckStun` → `UpdateFigures` → **`BroadcastWhileInPlay`** |
| 有没有 `_ResolveSummonUnit` | **没有**。`_ResolveSummonUnit_d__510__MoveNext.c` 全文只广播 `BroadcastUnitSummoned`（`:185`），且**全文 0 处** `Discard/Graveyard/Dead` 字样 ⇒ 它是「召唤」那条，不是复活 |
| 从墓地取牌 | `PlayAbility` 里与「牌从别处来」相关的只有 `AddDiscardFromHand` / `AddSummonUnit` / `AddSetCardToTop`（牌库顶）/ `AddTransformFromRemnant`；**没有「从弃牌堆进战场」** |

⇒ 对照我们：
- **残骸那一支**（`EvtKind.Deploy(Reanimate)` + `BroadcastWhen(Reanimated)`、**不发** `When deployed`）**与原版同形**；
  原版那条还多一次 `BroadcastWhileInPlay`，我们由 `Auras.Recompose` + `ActionPump.EmitWhileInPlayPass` 覆盖（近似）。
- **墓地那一支**是**我们自己的旧口径**（原版无对应）⇒ 它多发的那一族 190/195 广播**没有原版判据可比**。
  ⚠️ 但若以后要「贴原版最接近的那条」，该按**残骸那支的广播面**（只 `Reanimated`）来，即让 `DeployFree` 在
  `DeploySource.Reanimate` 下**不**发 `When deployed` 家族 —— 那是 `RuleEngine/**` 的活，本轮**没动**（越界）。
