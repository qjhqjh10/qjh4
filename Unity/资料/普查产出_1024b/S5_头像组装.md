## ① 原版层级

`AvatarDisplay` 字段接线（`MonoBehaviour_880497312993081906.json`，cell 那份）：
`avatarImage` → GO `Image` · `avatarHolder` → GO **`Border`**（**框 = avatarHolder**）· `highlight` → GO `Highlight` · `avatarName` → GO `Avatar Name`。
`AvatarDisplay__ChangeAvatar.c:57` 只 `set_sprite`（不碰 scale）；`__ChangeBorder.c:50` 同样。**⇒ 所有倍数都在 prefab 的 RectTransform 里。**

兄弟序（= 画序，底→顶）：`Raycast Target`(透明命中) → `Highlight` → `Border` → `Image`。**`Image` 在最后 = 头像画在框之上**。
**无任何遮罩**（`Image Container` 只有 RectTransform + CanvasRenderer；三个 Image `m_Maskable=1` 但父链无裁切件）。`m_Type` 全 = **0 Simple**、`m_PreserveAspect` = **1**（**不是 Sliced** ⇒ preserveAspect 生效）。`m_PixelsPerUnitMultiplier` = 1.0。框图 `Player Profile Border` 的 `m_Border` = **(0,0,0,0)**（无九宫）。头像 `m_FillAmount`=1 / `m_FillMethod`=4 ⇒ **方形原图，无圆/盾裁切**。

## ② 「立体感」从哪来

**没有**阴影层、内发光、高光叠层、额外材质（三个 Image 的 `m_Material` 全为空）。立体感 = 上表那条「头像可见宽 ≈ 框宽、**头顶戳出框顶 37px**、两侧靠 sprite 透明边露出框的黑色内胆」+ 选中格 `Highlight` 金色光晕（×1.9，271² > 框）。就三层。
