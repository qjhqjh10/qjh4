## 〇、先纠一处指路

`Shell/RankedTab.cs` **不是模式窗**，它是「玩家档案窗第 6 页 Ranking（排名）」。
- 经典模式窗 = `Shell/RankedEventWindow.cs`（原版 `RankedEventWindowV2`）

## 一、用户三问直答

### ① 中间那个大阵营图标 = `Faction Icon Image`

我们**无条件画**：`LiveOpsEventWindow.cs:499-501`（`MenuDraw.Rect(col, Tex(DeckRuntime.FactionIcon(ShownFaction)), 711.01,133.50→1233.64,656.14 = 522.63², "Faction Icon Image", QDeck)`）。

原版**有这个节点**（`Ranked Deck Selection/Faction Icon Image`；prefab `bundle_menus_assets_all/GameObject/Faction Icon Image.json` + `MonoBehaviour_7837662663833651120.json`：sprite=0、522.6333²、preserveAspect=0、raycast=1），
但 `RankedDeckSelector.ChangeDeck` 里它是 **`SetActive(deck == null)`**（`decomp_full/RankedDeckSelector__ChangeDeck.c` 中 `+0x80` 那一句）
—— **只在「该阵营 + 该模式一套卡组都没有」的空态显示**。有卡组时（= 参考图的状态）原版把它关掉，所以图上没有。
⇒ **我们多画的，就是这一件。**

### ② 那张立绘是谁 / 为什么恒是灵族

`LiveOpsEventWindow.cs:457-464 ShownWarlord` → `CollectionData.Warlord(DeckIndex)`（`CollectionData.cs:184-188`）→ `CardArt.TryDeckHero("ASH1") = UI_Deck_Warlord_Anvirr Keltoc`。

为什么恒是它，三条叠起来：
1. `DeckIndex = FirstDeckInMode(...)`（`:384`），而 `FirstDeckInMode` 在**没有一套符合本窗模式**时**回落到「当前/第 0 套」**（`:274-284`，第 283 行 `return (prefer>=0&&prefer<n)?prefer:0;`）；
2. 本机存档（`%AppData%/LocalLow/Everguild/Warpforge/WarpforgeDecks.json` 现读）**只有一套**：「复仇者之刃 / `WarlordId=ASH1` / `GameMode=0`（经典）/ 30 张」⇒ **小冲突窗（Skirmish 13）也把它画出来**；
3. `PickArmy` 又只在「找得到该阵营且模式合的卡组」时才换（`:1404-1408`），点没有卡组的阵营 = **画面原地不动**。

### ③ 没有该阵营卡组时原版是什么（**不是查不到**）

`ChangeDeck` 的 `deck==null` 支（同文件）明确：
- `warlordImage(+0x78)` / `warlordName(+0x48)` / `deckName(+0x50)` / `deckQuantity(+0x40)` **全 `SetActive(false)`**
- `factionIconImage(+0x80)` 与 `noDeckText(+0x58)` **`SetActive(true)`**，sprite 喂 `ArmyUtilities.GetArmyIcon(currentArmy)`
- `ChangeArmy` 同时把四颗圆钮按 `1 < 该阵营卡组数` / `0 < 该阵营卡组数` 关掉（`RankedDeckSelector__ChangeArmy.c`）

⇒ **空态 = 该（选中）阵营的大徽记 + 一句提示 + `Create deck` 钮，没有督军立绘 / 卡组名 / 督军名 / 张数，没有圆钮。**

提示文案两档：
- 该阵营 0 套 = 无占位符那句（官方 13 语表里**唯一候选** `MainMenu/Ranked/NoWarlordMessage`「你没有这个军队的任何战将。」）
- 有 N 套 = `String.Format("{0} {1} …")`（= `MainMenu/Ranked/NoDeckMessage`「你有{0} {1} 战将，现在为这个游戏模式构建你的卡组！」）

另：`Initialize` 在没有当前卡组时默认阵营 = **10 = Ultramarines**（`RankedDeckSelector__Initialize.c`；10 的枚举名见 `DeckRuntime.NoArmyFaction` 的注释）⇒ 我们空态现在喂 `ShownFaction=""` 得到 `40k_collection_bt_decks`（卡组图标）**也是错的**，应是 **UM 徽记**。

## 三、建议改法（按优先级）

- **P0** 中间栏加「本窗有效卡组」判据：`hasDeck = 预组已选 或 (Raw(DeckIndex)!=null && DeckFitsMode && 阵营==当前阵营)`；`false` 时**不画督军立绘/卡组名/督军名/张数**，改画「阵营徽记（选中阵营，无卡组时 UM）+ 空态提示 + Create deck」。（`:491-544 / :611-681`）
- **P0** `FirstDeckInMode` 去掉「不匹配就回落到 0」的兜底（`:283`）—— 原版 `ChangeArmy` 的筛法是「阵营 ∧ `deck.GameMode == 事件模式`」，一套都没有就是空态，**绝不拿别的模式的牌顶上**。
- **P0** `PickArmy` 改成 `ChangeArmy` 语义：切到该阵营第一套合法卡组，或进空态（`:1393-1424`）。
- **P1** 四颗圆钮按 `armyDeckCount` 显隐（0 / 1 / ≥2 三档），并据此重算居中（`:555-609`）。
- **P1** 张数文本改 `"{idx+1}/{armyDeckCount(阵营∧模式)}"`（`:702`）。
- **P2** 开窗把 `ArmyIndex` 设为当前卡组阵营（无卡组 = UM）；右栏该格用按下图（`:385`）。
- **P2** 空态下的徽记取「选中阵营」而不是 `ShownFaction`（`:478-485, :500`）。
- **P3** 删 `:652` 那颗多余的 `Generic Simplified UI Button`。
- **P3（请示）** 派系格进度条：参考图是满蓝条、我们是 0；没有赛季数据前我倾向保持 0（画满 = 编一个值），**请调度台裁**。
