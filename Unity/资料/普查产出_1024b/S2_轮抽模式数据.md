## ③ 原版流程（形状与用户描述一致）

- `DraftEvent : DraftEventBase<DraftEventSaveGame, DraftEventData>`（`dump.cs:126797`）
- 存档（`dump.cs:126817`）：selectedWarlord / **selectedPacks** / selectedCards / selectableWarlords / currentReRolls / payState / rewardsCollected / won / cardbackId
- `CurrentDraftRound` **= selectedPacks.Count** ⇒ 每选 1 包算 1 轮
- 配置 `DraftEventData`（`dump.cs:127940`）：`draftRounds` · `packsPerDraft` · `warlordsPerDraft` · premiumPrice/10Price · specificArmies/guaranteedArmies/blacklistedWarlords · Rewards · reRollCosts
- 状态机 `DraftModeState`（`dump.cs:126782`）：Intro 0 → PayScreen 2 → SelectWarlord 5 → SelectPack 10 → OngoingRun 15 → Finished 20 → Collected 22
- 方法链：Free/PayEventEntrance → GetRandomWarlords/PickWarlord → **GetRandomPack(warlord,packCount)/PickPack/ReRollPack** → GetCardsFromPacks → GetEventDeck → 匹配 → FinishRun → CollectRewards（另有 RefundRun/Expire）
- UI：`DraftModeSelectPacksStateDemo` 列表容量 **3**；`ShowPacks` 用 `DraftEventData+0x9C`(=packsPerDraft) 控实例化包数、`Random.InitState(seed + currentDraftRound + index)` 逐轮逐位确定；`OnOpen` 比 `已选包数 ?= packsPerDraft`
- 对局：`PickPack` 把包内 3 张塞进 selectedCards → `GetClosedDeckByPackIds(warlordId, packIds)` 生成 **ClosedDeck**；官方文案 `Battle/MatchType/ClosedDeck` =「Draft / 选秀」
- 跑团：输 3 场结束；Quote 键到 12 胜

⇒ **「3 张/包、每轮选 1 包、N 轮 = 3N 张」形状 100% 对上**；用户的「3 组 / 4 轮 / 12 张」自洽，但 **4 这个数值本地无真值**。
