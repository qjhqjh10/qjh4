## 三、图标 ↔ 关键词：**判据有三套，别混**

1. **主流（最硬）**：原版图集 `40ktraiticonatlas` 的 **78 张切片，文件名就是英文关键词** → `Resources/Art/traits/`。
2. **运行时认图**：**不查关键词表**，查**目录里贴图的名字**（归一化 = 只留字母数字转小写）+ 一张手写 Alias 表。
3. **卡面记号 → 图**：**逐卡计划表** `card_icon_plan.json`（按卡 id + 字段）。
   🔴 **方括号 token 名不可信**：同一个 `[Attack]`，`DA44` 是拳、`EC8` 是枪 ⇒ **别按 token 名猜属性**。

1. ✅ **2026-09-21 已修：连续句首关键词漏画第 2、4…个**（真 bug，2026-09-19 用户从卡面看出来）

     `look-behind requires fixed-width pattern`（旧文档写的「改成零宽断言」按字面做会失败）。
     ⚠️ 这条**英文侧同样中招**：`Ephemeral. Waystone.` 旧扫法也只出第 1 个。
