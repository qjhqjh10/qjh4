## 三、图标 ↔ 关键词：**判据有三套，别混**

1. **主流（最硬）**：原版图集 `40ktraiticonatlas` 的 **78 张切片，文件名就是英文关键词** → `Resources/Art/traits/`。
2. **运行时认图**：**不查关键词表**，查**目录里贴图的名字**（归一化 = 只留字母数字转小写）+ 一张手写 Alias 表。
3. **卡面记号 → 图**：**逐卡计划表** `card_icon_plan.json`（按卡 id + 字段）。
   🔴 **方括号 token 名不可信**：同一个 `[Attack]`，`DA44` 是拳、`EC8` 是枪 ⇒ **别按 token 名猜属性**。

### 特殊映射（实测，都会咬人）

| 情况 | 事实 |
|---|---|
| **多对一** | `Destroyer` → 用 `frenzied` 的图 · `Penitence` → 用 `rage` 的图 · `Concussion`(引擎)/`Concussive`(卡面) 同一张 · `Armor`→`armour` |
| **一对多** | `Quest Point` → `questPoints1/2/3`（**数字烘在图里**）· `Spirit Stone` → `SpiritStone_1..5` **五档** |
| `Dark Pacts` | 卡面画的是 **`markOfChaos`**（暗红盘 + 白八芒星）；原版**无同名枚举成员** |
| **四个名字一张图** | `[Energy]`/`[Icon]`/`[Faith Icon]` … 画**同一张金太阳**，且只对修女会成立 |
| **认不出（物理上分不开）** | `markOfKhorne/Nurgle/Slaanesh/Tzeentch` **四张逐字节相同**；`relentless` vs `resolution` **只差 1px** |
| 规则书里没有的图 | 11 张：`berzerk frenzied loot rage relentless resolution markOfChaos markOfKhorne markOfNurgle markOfSlaanesh markOfTzeentch`（数字版独有） |
| **判据强度** | `markOf*` ↔ 黑暗契约那几条是**推测（中/低可信）**；`loot` 甚至不是 `DefinedTrait` 成员 |
| 触发符号 | `⚡`→rally · `💀`→backlash · `🗡`/`⚔`→Melee · `🔫`→Ranged · `🛡`→shield · `❄`→markOfSlaanesh · `☀`→faith |

## 六、🔴 已知问题（**都未修**）

1. **连续句首关键词漏画第 2、4…个**（真 bug，2026-09-19 用户从卡面看出来）
   - 复现：`路标石。伪装。猛击：…` 只出 `['路标石。','猛击：']`（另一词没画）
   - 根因：`工具/gen_icon_plan.py:373-377` 的 `(?:^|[。；,，]\s*)` 把**前导分句符吃进匹配**、`finditer` 不重叠
   - 影响面：精过滤约 **104 处**（未过滤上界 231 个 (卡,字段) / 315 处 token）
   - 修法：改**零宽断言** + 复跑两步（`--write` → `gen_icon_doc.py`）；步骤见 `资料/卡面图标_现状与缺口.md` §二之五
2. **卡面「关键词段」一枚图标都没有**（见 §二 B）—— 原版印的是「图标 + 词」
3. **两个 token 被静默丢弃**（踩红线）：卡池 `keywords` 里的 `chosen of the four` / `hymn of battle`
   归一化返回 null 后**直接丢掉** —— **既不上「未实现关键词」单、也不打 `*`**（`CardDef.cs:2293-2303` 记的正是这个坑）
4. **「未实现关键词 0 个」有隐藏前提**：`Faith`/`Quest`/`Spirit Stone` 三个词在卡池里各 0 命中
   ⇒ 它们**即使没机制也永远不出现在名单上**（**结构性不可见**）。`Faith` 是三者中**真的没有关键词级触发**的那个。
5. **两条语义不可恢复的**：图标被 OCR 剥掉只剩裸 `+1`（`Genestealer Familiar` 是拳、`Cadre Fireblade` 是枪）
   ⇒ **宁可认不出**，要修只能走数据侧 `cardface_fixes.json` 的 `_manual_*` 列。
6. **5 张 `Stun` 是数据误抽**（卡面那个词是效果句里的内联图标，不是关键词）；另有 14 张同形状已清。
