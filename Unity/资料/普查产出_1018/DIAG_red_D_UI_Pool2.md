## §二 根因归并（4 组）

1. **本批「卡池排序」改到夹具取到的卡（#1/#2/#3/#7）**

   - 受影响的旧夹具都写着「第 0 格 = 一张有费用的普通卡」：Deck 的 tooltip 三条固定 `pool_0`；Collection 的计数条夹具经 `CardHit_0` 拿到卡（旧数据下是 `Autarch`，现在是 `Uriel Ventris`）。
   - 表现：战将 `ShowsCost=false` ⇒ 没有费用 tooltip；战将 `DeckCap(rarity,type)=1` ⇒ 计数条印 `x1`。
2. **断言先按原版改了、实现没跟（#4/#5）**：`MainMenuScene.cs:2909-2910` 是本批 diff 改的（期望 0/657），但 `PracticeModePopup.PickArmy` 仍是 toggle（`:1780`），且阵营格没接任何「已选中」守卫。原版判据 = `ChangeSelectedArmy.c:30-33` 的早返回（不是 `allowClickWhenAlreadySelected`；练习窗那颗 prefab 是 EverguildButton，不带 Toggle 语义）。
