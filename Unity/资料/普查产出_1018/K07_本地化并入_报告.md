**当前 build（2026）的官方 I2 本地化表已并入工程**：旧 2025-07-30 快照的 en+zh 表（9,441 条）

**四个数字（独立重算）**：

🔴 **关于「399」**：这个数**不能当「改值条数」**。旧 en+zh 文件把「en == zh」的 297 条压成**单个字符串**
（如 `"No Offensive Effect"`），而合并候选把**所有**值都写成 `[en, zh]` 两元数组。
把两种表示直接 `!=` 相比，会把 **282 条「值没变、只是表示不同」误算成改值**；
`282 + 117 = 399`。**归一化后真实改值 = 117 条**（en 列变 115 条 / zh 列变 117 条）。

**最终产物条数**：
- `官方本地化_en+zh-CN.json`：**10,854** 条 = 10,849（当前 build）+ 5（`--carry` 保留的旧表键，⛔ 不丢键）。
  这与**合并候选**的条数一致（候选现读 **10,854**；任务描述里的「现读候选 10,849」是旧口径，
  候选后来已把 5 条旧表键并进去）。
- `官方本地化_13lang.json` / `Resources/official_loc_13lang.json`：**10,862** 条
  = 10,857（当前 build 全部原始词条）+ 5（旧表独有键；另把当前 build 已清空的 5c4d 用旧值补回，
  见 §五·3）。两份逐键逐列**完全一致**（0 行不匹配）。
