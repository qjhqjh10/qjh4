## 二、判据原文（prefab 层，全部按 pid 现读）

### 1) `Toggle Border` —— 判据是 prefab 自己

`bundle_menus_assets_all` 里有 **3 份**同族 `Toggle borde/Button Text`（全文 `m_text = 'Toggle Border'` 的三颗），
**三颗 `Localize.mTerm` 全同** = `Demo/AvatarMenu/ToggleBorder`：

| 实例所在页 | Button Text 的 GameObject pid | 挂着的 `Localize` 组件文件 | `mTerm` |
|---|---|---|---|
| **`Avatar Tab`（本页用这颗）** | `-6946788127083038158` | `bundle_menus_assets_all/MonoBehaviour/MonoBehaviour_-9170721748395918798.json` | `Demo/AvatarMenu/ToggleBorder` |
| `Title Tab`（那页的 `Toggle borde` 是死节点，我们不建） | `-1517435614820992462` | `.../MonoBehaviour_-6561044466830837198.json` | `Demo/AvatarMenu/ToggleBorder` |
| `Profile Cosmetic Tab` | `3391580050359163769` | `.../MonoBehaviour_-2955158983638475911.json` | `Demo/AvatarMenu/ToggleBorder` |

- `Localize` 的 `m_Script.m_PathID = 8610481073976370760`（类名 `Localize`，经 `bundle_Waprforge_monoscripts/MonoScript` 反查）。
- 三个 `Localize` 的 `m_GameObject.m_PathID` 与上表 Button Text 的 pid **逐一相同**（不是同名不同物）。
- 父链（实读）：`Button Text / Toggle borde / Selected Item Panel / Avatar Tab / Tab Content / Tab  Area / Menu Area / Player Profile Window`。

### 2) `Select` —— prefab 侧判据是空的（原版本身没有）

`Select Avatar Button/Button Text` 全包 **3 份**，`m_text` 全是葡语占位串 **`Selecionar`**，
**组件表里一颗 `Localize` 都没有**：

| 实例所在页 | Button Text 的 GameObject pid | TMP 组件文件 | `Localize` |
|---|---|---|---|
| **`Title Tab`（本次要改的）** | `-4198606521465463943` | `.../MonoBehaviour_-1034895004042421383.json` | ❌ 无 |
| `Title Tab`（同页第二份实例） | `-1423572242308892110` | `.../MonoBehaviour_6233035307625970226.json` | ❌ 无 |
| `Avatar Tab`（已经是中文「选择」的那颗） | `-4434422748509996494` | `.../MonoBehaviour_-4788933935467431374.json` | ❌ 无 |

三颗的组件表（逐 pid 现读）都是同 7 件：`RectTransform` · `CanvasRenderer` · `TextMeshProUGUI` ·
`AspectRatioFitter` · `EverguildButtonMaterialModifier` ×2 · `EverguildTextController` —— **没有 `Localize`**。

⇒ **原版这颗钮在任何语档下都只显示葡语 `Selecionar`**（没人替换它）。
`Select` 是我们挑的上屏词（原文件里早就这么记着，见 `TitleTab.cs` 头部注释）。
**本次不再另挑新词**：照头像页那颗的现成口径，用 **同族同节点** 的键
`Demo/AvatarMenu/SelectAvatarButton`（= 头像页那颗当前上屏的键，`Loc.Table` 里已登记：
`Shell/Core` 侧 `Core/Loc.cs:2778` `new Entry("选择", "Select")`）。
⇒ 两页这颗钮从此**是同一个词**（中文 `选择`），也正好是用户点名的口径。

> ⚠️ 「原版用的就是这条键」对**称号页这颗**是【推断】（prefab 无 `mTerm` 可依），
> 已在 `TitleTab.cs` 的注释里写明，⛔ 未写成原版证据。
