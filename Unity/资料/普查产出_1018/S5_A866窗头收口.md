## 5. 行为不变的自证（逐处）

### 5·0 通用等价（四扇都成立，逐条核过）

1. **几何**：所有 `PxRect` 都是**从各窗常量块原样搬过来的同一个表达式**（例：Tutorial 的 `new PxRect(HdrL, HdrT, HdrR, HdrB)`）。
   ⚠️ 两处**没有**从别的字段现算：`TitleFitW/H`（照原式的写法给，见 §4）。
2. **树/兄弟序**：与改前逐位相同（底板 → `Window Title` → 尖角 → 返回钮 → `BackHit`；`BackHit` 的父件仍是返回钮的宿主节点）。
3. **队列**：全部照抄各窗常量（`QPlate/QWing/QTitle/QBack/QHit`）。
4. **文案**：标题字面量逐字照抄（含 `Game Mode` 的大写 M）；`Window Title` 的四个字体数逐值相同。
5. **接线**：`OnBack` 的 lambda 体逐字照抄（`() => Close()` / `() => { DailyData.StreakAutoCollect(); Close(); }`）。
6. **对齐次序**：`TitleFit` 三档与各窗改前**逐句同序**（见下表）。

| 窗 | 改前的次序（HEAD 实读） | 改后 |
|---|---|---|
| Tutorial | 字距 → 自适应 → `AlignLeft` | `FitAfterSpacing` ✅ 同序 |
| LiveOps | 字距 → 自适应 → `AlignLeft`（A492 已对调成这一序） | `FitAfterSpacing` ✅ 同序 |
| Energy | 自适应 → 字距 → `AlignLeft` | `FitBeforeSpacing` ✅ 同序 |
| DailyStreak | 字距 → `AlignLeft` → `SetVAlign(Capline)` | `SpacingOnly` + `TitleVAlign` ✅ 同序（`SetVAlign` 排在 `AlignLeft` 之后） |

### 5·1 逐处的两处「差点踩到」（都躲开了）

- 🔴 **`MenuDraw.Hit` 的 `target` 不能只传一半**：Tutorial 改前是 `Hit(hdr, "BackHit", …, () => Close())`（`target`/`art` **都不传**）。
  若我统一成「只要有返回钮 quad 就传 `target`」，`WindowButton.Bind(t, art: null)` 会走
  `HoverNameFor(null) = null` ⇒ 查一张不存在的悬停图（在 `MissingSwapArt` 里**记一条假账**）**并把 `tintOnHover` 关掉**
  ⇒ **这个按钮的悬停色偏没了**（Tutorial 那一档本来就是靠色偏）。
  ⇒ 共件里写成 `string.IsNullOrEmpty(s.BackSwapArt) ? null : backQuad`，并在那一行留了长注释（`Shell/MenuWindowBase.cs:801-807`）。
- **DailyStreak 的 `AlignLeft` / `SetVAlign` 改前是无条件调的**（不在 `if (title != null)` 里）。
  收进共件后我放在 `if (title != null)` 里 —— 两者等价，因为 `MenuDraw.AlignLeft` / `MenuDraw.SetVAlign` **都 null 安全**（`MenuDraw.cs:1742/1768` 头一句 `if (lb != null)`）。
  另外 `SetVAlign` 与 `AlignLeft` **互不干涉**（一个只动横向、一个只动纵向），次序与改前一致。

### 5·2 LiveOps 的 `Game Mode Icon`（唯一一处**建法顺序**变了，结果不变）

改前：底板 → 标题 → **图标** → 尖角 → 返回钮；改后：底板+标题+尖角+返回钮 → **图标**。
- `hdr` 的子件序 **不变**（图标不是 `hdr` 的子件）；
- 图标仍挂在 **`Header Background`** 底下（= 原来的局部 `bgT`，现在叫 `parts.Plate`）⇒ **`Plate` 的子件序也不变**：`Nine` → `Window Title` → `Game Mode Icon`（图标仍在标题之后建）。
⇒ 树逐位相同。

### 5·3 一处**调用次数**变了（无副作用，如实登记）

Tutorial / LiveOps 改前对同一张图各调了**两次**取图口（底板一次、尖角一次）：`Tex(ArtHeaderBg)` ×2。
改后 spec 里只调一次、两个层共用同一个 `Texture2D`。
- 取图口（`Tex`/`Art`）是「查缓存 + 记 `MissingArt`（**去重** `!MissingArt.Contains`）」⇒ **读数与清单都不变**；
- `MenuDraw.Nine` 收的是同一张贴图 ⇒ 画出来的东西不变。
⇒ 唯一差别是「查表次数 2 → 1」，**无可观测差异**（如实登记，免得下一个人以为是漏了）。

### 5·4 我**没有**改、但会盯着的东西
