## §二 实现（文件:行）

### 1. shader

- 🆕 `Unity/MyGame/Assets/CardPresentation/Resources/Shaders/CardSprite.shader`（+ `.shader.meta` / `Shaders.meta`）
  - 卡面基材：`Sprites/Default` 的等价转写（逐项照 `UnitySprites.cginc` 6000.3.23f1 实读）+ 属性 **`_GreyScale`（默认 0）**。
  - 灰化 = `lerp(rgb, lum, _GreyScale)`，`lum = dot(rgb, (0.299, 0.587, 0.114))`，**只动 RGB、不动 alpha**；
    预乘与 `Blend One OneMinusSrcAlpha` 与 `Sprites/Default` 一致 ⇒ `_GreyScale = 0` 时画面与原来一致。
  - ⚠️ 放 `Resources/` 是**故意的**：`Shader.Find` 只找构建内 shader；本仓其他自建 shader 走
    `ProjectSettings/GraphicsSettings.asset` 的 AlwaysIncluded，而那份工程设置**不在本笔所有权里**
    ⇒ 放 Resources = 自动进包，不必改工程设置。
- `Shaders/ArtOpaque.shader`：补 `_GreyScale`（默认 0）+ 同一段灰化（立绘那一层是卡面最大的颜色块）。
- `Shaders/Card3D.shader`：补 `_GreyScale`（默认 0）+ 在 `_Color` 之前灰化（场上 3D 卡体）。

## §三 断言（含灭自证）

`Editor/DeckScene.cs` 卡池「显示 + 变灰」那一节：

1. **① 加不进的格真的灰**（有督军时取一张 `CanAdd != None` 的卡）：
   - `cv.State == Unplayable`（状态标记保留，沿用原断言）。
   - **①-a 真去饱和通道**：`cv.LayerGrey("art")` 与 `cv.LayerGrey("frame")` 都 `> 0.99`
     —— 读的是**渲染器上真正生效的** `_GreyScale`（MaterialPropertyBlock 优先）。
     🧨 **灭自证**：把 `CardView.SetGrey` 改成 no-op ⇒ MPB 不写 ⇒ 读到材质默认 **0** ⇒ **本条必红**。
   - **①-b 不再是乘法压暗**：`cv.Tint.r/g/b` 都 `= 1`（0.55/0.55/0.58 那一档已作废）。旧断言（读 0.55/0.55/0.58）已替换。
2. **② 反向控制**：`ClearWarlord()` + `RefreshAll()` ⇒ 池里每一张英雄卡都 `CanAdd == None` ⇒
   **一格都不许灰**：同时看 `State == Playable`、`Grey == 0`、`LayerGrey("art") == 0`、`LayerGrey("frame") == 0`。
   （🧨 恒灰/灰度不复位的写法必红。）另补一条前提：**真的读到至少一格 `CardView`**
   （`checked2 > 0`，挡「探针一格都没读到 ⇒ `g2` 恒 0」那种假绿）。
3. 收尾把督军放回去、再 `RefreshAll()`，后面的断言按原状态跑（原逻辑不变）。

> ⚠️ 本轮**没有跑** Unity 批处理（任务书 + 用户口径「先复刻完再统一验收」）⇒ 这三条断言**还没实跑过**。
> 反例设计（灭自证）是按「读渲染器真实值」构造的，不是读我们自己的字段：

## §五 没查到 / 风险

1. **原版灰化的具体权重没逐位核**：`Everguild/UI/Greyscale Add` 的 DXBC 没反汇编到立即数。
   我们用 Rec.601 `(0.299, 0.587, 0.114)`（与仓里已有的 `TraitDisabled.shader` 同一口径）。
   ⚠️ 这只影响「灰的亮度」，不影响 0/1 语义与「是否去饱和」。
2. **原版只灰 3 个 Image，我们灰了全部层（含 TMP 文字）**：
   `CollectionCard` 的 `imageMaterialPairs` 只有 `Card Image Simple Greyscale` + `UI Greyscale` ×2；
   按任务书「把灰度传到卡面各层」我们额外把 TMP 文字/角标也去饱和了。
   若之后逐像素并排发现文字在原版里仍是彩色 ⇒ 去掉 `ApplyTint` 里的 `Greyed(...)` 即可（一处收口）。
3. **补间默认不启用**：`SetGrey(g, time)` 支持 0.25s 补间，但 `DeckRuntime` 传 0（批次/自检无帧循环，
   补间会让断言读到中间值）。原版是 0.25s 淡变 —— 真机验收时若要 1:1，把调用改成 `SetGrey(1f, 0.25f)`
   并在 Play 环境下即可（`SetGrey` 里 `!Application.isPlaying` 时自动瞬切，所以自检不会因此飘）。
4. **`Unplayable` 全局语义变了**：`SetHighlight(Unplayable)` 现在在所有宿主（战斗手牌 / 换牌 / 选牌 / 卡面探针）
   都从「乘法压暗」变成「去饱和 + 不着色」。这与原版（战斗卡预制体同样挂 `UIImageGreyscaleController`）一致，
   但**本轮没跑战斗自检**去复核那几条宿主；若某条旧断言还假设 `Tint = 0.55` 才会红 —— 全仓 grep 过，
   除本文件那条（已改）外**没有别处读这个值**。
5. **`SetData` / `SetFace` 各多一次 `if (_grey > 0f) ApplyGrey()`**：只在灰卡上扫渲染器（卡池里灰卡是少数），
   战斗热路径上 `_grey = 0` ⇒ 一个字节都不动。
6. `Resources/Shaders/CardSprite.shader` 是新文件（含 `.meta`）；**没有**改
   `ProjectSettings/GraphicsSettings.asset`（不在所有权内，用 Resources 保证进包）。
   若之后有人把它移出 Resources，必须同时在 AlwaysIncluded 里补 guid，否则 player 里 `Shader.Find` 会拿 null
   （代码会退回 `Sprites/Default` 并出声，但去饱和会失效）。
