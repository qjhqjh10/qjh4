### 0·2 `UIGradient` 的角度换算（**本报告最重要的口径**）

原版 `Content Area/Background` 那一族用的是 Asset Store 的 `UIGradient : BaseMeshEffect`：
字段 `m_color1 / m_color2 / m_angle=82 / m_ignoreRatio=1`，**有效方向轴 = `(sinθ, cosθ)`**，
且 `m_color1` 落在**轴的正端**（亮端）。

我们 `Core/CardArt.cs:478 CardArt.Gradient(c1, c2, angleDeg)` 的约定是 `(cosφ, sinφ)`、**`c1` 在 `t=0` 端**。
⇒ 要还原同一张图必须传 **φ = 180° + atan2(cos82, sin82) = 188°**（不是 82）。
这条换算已被 `资料/主菜单_原版规格.md` §A 的实测场钉死（左暗右亮：R 22 / 56），
并且 `DeckRuntime.cs:1396-1399` 与 `ParentEventWindow.cs:150` **都已经按 188 落地**。
⚠️ 本报告里的「原版 82」与「我们 188」是**同一件事的两种坐标系**，不是矛盾。

### 0·3 参考图坐标怎么读

- 1578×888 那一族（绝大多数）= **整幅就是游戏画面**，缩放 `1920/1578 = 1.2166`、`1080/888 = 1.2162`。
  ⇒ 游戏 px = 图片 px × 1.2166。
- `主界面参考图.png`（1503×883）是视频截图：**左侧 0..78 px 是黑边**，游戏画面从 x≈79 开始
  （缩放 ≈ `1920/1424 = 1.348`）；底部有字幕/水印，采样点只取干净区。
- 采样一律写 **图片像素（左上原点）**，括号里给 RGB（0–255）。

### 0·4 内容区渐变的原版色（下文反复引用）

`Content Area/Background`：`Image`（`m_Sprite = null`、`m_Type = Sliced`、`m_Color = (1,1,1,1)`、
`m_PixelsPerUnitMultiplier = 0.01`）+ `UIGradient`
· `m_color1 = (0.22352943, 0.01176471, 0.01960784, 1)` = **#390305 → RGB(57,3,5)**（⚠️ 原写 `#390503`，G/B 抄反 —— 见文件头订正）
· `m_color2 = (0.04705883, 0, 0.01568628, 1)` = **#0C0004 → RGB(12,0,4)**
· `m_angle = 82` · `m_ignoreRatio = 1`
· 矩形 = `167.17, 70.94 → 1920.01, 1080.00`（`Content Area` 同矩形）。
**实测呈「左暗右亮」**：沿 x 线性 `RGB(x) = (12+45t, 3t, 4+t)`，`t = (x−167)/1753`。

## 二、缺陷清单（按严重度排序）

### 🔴 D1（最高 · 影响 **8 个界面**）— 整窗渐变方向转了 90°，亮暗轴反了

- **位置**：`MyGame/Assets/CardPresentation/Shell/MainMenuSubmenuWindow.cs:409`
  `ImageQuad.Create(area, CardArt.Gradient(GradC1, GradC2, **82f**), …)`
- **影响面**：`Rewards Base Submenu Variant`（布道所 / 战役 / 锻造厂 三页）· `Shop Menu Variant` ·
  `Collection Menu Variant`（四页）· `Social Submenu Variant` —— 共 **4 个窗 / 至少 8 个页**。
- **原版**：`Content Area/Background` 的 `UIGradient` `m_angle=82` `m_color1=#390503` `m_color2=#0C0004`
  （有效轴 `(sin,cos)`、`c1` 在正端）⇒ **左 #0C0004 暗 → 右 #390503 亮**。
- **实拍判据**（收藏窗）：x=500/1000/1400 → (24,1,4)/(39,2,6)/(52,4,6)，与 `RGB(x)=(12+45t,3t,4+t)` 逐点吻合。
- **我们的实际画面**：同一张纹理按 `(cos82,sin82)` 投轴 ⇒ **下亮上暗**。同点期望 (42,2,5)/(35,2,5)/(28,1,4)。
  最明显处：内容区**右上角**参考图 R≈53，我们会画成 **R≈25**（Δ≈28）；**左上角**我们会亮一大截。
- **改法**：把这一处 `82f` 改成 **`188f`**（`DeckRuntime.cs:1396-1399` 与 `ParentEventWindow.cs:150` 已经是这个值，
  同一个 `CardArt.Gradient` 恒等式，可照抄）。⛔ 不要改 `CardArt.Gradient` 本身（主菜单/卡组编辑/活动窗都在用它）。
- **为什么一直没红**：`Editor/CollectionScene.cs:1266-1267` 与 `Editor/DeckScene.cs:7530-7544` 只断言「节点在 / 矩形对」，
  **没有任何一条断言方向或取色** ⇒ 方向错了照样全绿（与「断言全绿 ≠ 画面对」同一族）。

### 🔴 D2（高 · 影响 4 个窗）— 左栏底板缺 `Gradient2`（整条左栏应「中亮 / 上下渐黑」）
