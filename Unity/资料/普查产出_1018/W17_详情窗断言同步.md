## 二 · 新增那条：点「创建副本」后**数据不变**（现 `:7320-7387`）

1. **前置快照**：`owned0 = CardProgress.Owned(...)` · `wc0 = CardProgress.Wildcards(...)`（原来就有）·
   🆕 `craftSave0 = File.ReadAllBytes(persistentDataPath/CardProgress.SaveFileName)`（不存在 ⇒ `null`）。

3. **三条断言**（互补，一条都没省）：
   * `CardProgress.Owned(...) == owned0` —— 拥有数不动（原有）；
   * `CardProgress.Wildcards(rarity) == wc0` —— 通配符一张不扣（原有）；
   * 🆕 **存档逐字节相同**（`craftSave1` 与 `craftSave0` 比长度 + 逐字节；**含「点前 / 点后都不存在」**
     也要一致）—— 失败文案会打出改前 / 改后的字节数，改坏法 = 让 `OnCraftClicked` 回头调 `DoCraft()`/`Save()`。

4. 🆕 **前提断言（不静默）**：`CraftHit` 拿不到时**不许静默跳过**上面三条 —— 只允许
   `cd.Card.Rarity == "special"`（空价整块不建）这一档；其余情况红在这里。
