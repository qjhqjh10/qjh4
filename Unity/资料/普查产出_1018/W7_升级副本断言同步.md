## 二、新增的「等级 2 ⇒ tier2」断言怎么断

`Editor/BattleScene.cs:9919-9940`（紧接 `probe` / `probe2` 销毁之后）：

```csharp
CardProgress.SetLevel("UM19", 2);
var probeLv2 = CardView.Create(cam.transform, probeData, "FrameTierProbeLv2");
Check(probeLv2 != null && probeLv2.FrameTexture != null
      && probeLv2.FrameTexture.name.Contains("_tier2"), "…");
// 销毁 probeLv2
CardProgress.SetLevel("UM19", 1);
Check(CardProgress.Level("UM19") == 1, "（收尾）等级还原成 1");
```

- **为什么要它**：只断 `tier1` 时，把 `CardView.Build` 里 `frameTier = CardProgress.Level(d.artId)` **写死成 1**，
  上面那条 `tier1` 断言照样绿（断言与实现同义 = 自证）。加了 tier2 这条，链一断必红。
- **重画口径**：与生产同一条路 —— `DoUpgrade()` 之后走 `RebuildKeepingState() → Build() → CardView.Create`，
  所以这里**重新 `CardView.Create`** 一次（不是 `SetData`；`SetData` 不重建 `_frame` 那层）。
- **判据**：`frame_<阵营>_tier<N>` 命名（`CardArt.Frame` 的取法），断言 `contains("_tier2")`。
- **恢复**：`_persist` 已在 `ResetForTest()` 里置 false ⇒ `SetLevel` **只在内存**；跑完把 `UM19` 设回 1。

### 自检保护（不许污染开发机存档）

- `BattleScene.cs`：新增 **`CardProgress.ResetForTest()`**（`:301`，既有口：清三张表 + `_persist = false` + `_loaded = true`
  ⇒ 本进程**不读盘、不落盘**）。`BattleScene.cs` 全文件此前**零处**引用 `CardProgress`（已 grep）⇒ 无副作用。
- `CollectionScene.cs`：**早就在 `:961` 调过** `CardProgress.ResetForTest()` ⇒ 本笔不用再加。
