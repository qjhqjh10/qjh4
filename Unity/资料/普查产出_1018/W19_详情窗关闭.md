## ③ 关窗后的状态清理（为什么「不会误关收藏窗、收藏窗留在原页」）

逐跳核过，**结论：关闭详情窗只影响它自己，收藏窗不会被动、页签也不会回第 0 页**：

1. `Close()` 只碰 `this`：`CurrentState = Closed` · `Data = null` · `gameObject.SetActive(false)` · `Manager.NotifyClosed(this)`（`Shell/GameWindow.cs:656-737`）。
2. `NotifyClosed` 只把**这一扇**从 `openWindows` 摘掉（`Shell/WindowsManager.cs:462-479`）。
3. `ShowPreviousWindow` 取**列表尾**（= 收藏窗）→ 因为它不是弹窗，**跳过 `UnHide()`**，直接
   `prev.TryOpen()`（`Shell/WindowsManager.cs:505-571`）。
4. `TryOpen()` 落在 **`Background` 支**（`Shell/GameWindow.cs:499-509`）：**只** `SetActive(true) + state = Open`，
   **不调 `Open()`、不重建内容** ⇒ **页签 / 滚动位置 / 筛选全保留**。
   （实据 = 那句日志本身：「只提回前台，**不重建内容**」—— 这句话在这里是**好事**。）
5. 扇形残影：**关窗不销毁子件**（保持原版的「窗关了就是藏起来」），但下一次 `Build()` 的第一句就把整棵子树
   `DestroySafe` 掉重建（`Shell/CardDetailPopup.cs:711` 那一句），且 `_swapping` 在 `BuildCardStack` 末尾也复位
   ⇒ **画面不留残影、状态不留脏值**。
