   原来是 `SetRenderQueue` 在前、`SetFace` 在后；已按 `MenuDraw.TextCore` 的约定（**先 `SetFace` 再 `SetRenderQueue`**）排过来。

   避免它以后再被拿来画「本该 Sliced」的底图。
3. **`AllianceMemberOptionsPopup.ArtShadow` 注释过期**（见 P2-5），已就地订正（铁律 5）。
4. **自检兼容性盘点**（只读 grep，没跑）：本批改动点没有「按 quad 数量 / 按 ImageQuad 个数」直接断的站点 ——
   `RewardsScene` 的 `CheckArt` / `TintOf` / `CheckAt` 分别走 `GetComponentInChildren<ImageQuad>()` 与**节点世界位置**，

   若用在 **Nine 根节点**上会量到**角块**、不是整块（本批没有这种站点；`CheckAt` 量的是根的位置，安全）。
