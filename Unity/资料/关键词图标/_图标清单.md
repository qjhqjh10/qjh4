## 长得像、可能被认混的组

1. **完全同图（md5 一致）**：`markOfChaos` / `markOfKhorne` / `markOfNurgle`；`markOfSlaanesh`、`markOfTzeentch` 与它们只差 2–9 像素 —— **五张 markOf 实质是同一张暗红八芒星图**，无法靠外观分辨是哪位邪神。
2. **完全同图（差 1 像素）**：`relentless` / `resolution`（绿圆 + 白色双循环箭头）。
3. **盾形四张**：`armour`（银白双色盾）/ `shield`（青绿 + 盾内眼睛）/ `vanguard`（红白盾 + 红骷髅）/ `vulnerable`（深蓝 + 盾内蓝闪电）。
4. **白色骷髅头群（最多的一组）**：`backlash`（橄榄黄底）/ `berzerk`（品红 + 张口獠牙）/ `rage`（黑底 + 外圈尖刺）/ `invulnerable`（深蓝 + 十字框架）/ `remnant`（灰绿 + 苍白）/ `regiment`（橄榄绿 + 额上带翼徽记）/ `slay`（橙红 + 橙准星）/ `strike`（玫红 + 匕首贯穿）/ `synapse`（深紫 + 弯角多孔）/ `tide`（蓝绿 + 三个骷髅）/ `mob`（深红棕 + 交叉带）。
5. **展翅/翼形**：`agenda`（深绿 + 展翅十字剑）、`flying`（青绿 + 双翼长剑）、`questPoints`（深绿尖刺环 + 银色展翅矛徽）。
