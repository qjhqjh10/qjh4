# N1 · 敌方回合的「横幅 + 压暗」—— 原版判据与我们现在的实现

> 只读诊断（2026-10-24 · `N1`）。**没跑原版实况**（已关服）⇒ 结论全部来自 ① 全量反编译 `d:/2/tools/decomp_full/`
> ＋ ② 解包 scenes 包字段 ＋ ③ 机器码现读。凡拿不到的都写「查不到」。

## 1. 结论一句话

**原版那件（`WaitText` / 组件字段名就叫 `mulliganWaitText`）不是「敌方回合横幅」，它是「换牌等对手」那一下的过渡提示：
本地玩家一确认换牌（联网局）就整块亮起来（硬切、无淡入），对手的换牌一到 / 战斗阶段一开始就整块关掉；
单机局一次都不出现，回合循环里也一次都不出现。我们把它接成了「只要不是我的回合就一直挂着」，所以整段敌方回合都压暗。**

## 6. 修法（可执行清单，全部要做）

1. **判据单一出口**（`BattleDriver`）：新增 3 个状态 + 一个静态谓词（自检要吃真值表）：
   `bool ShowWaitBanner(bool mulliganOpen, bool localSubmitted, bool foeMulliganApplied)` ⇒ `mulliganOpen && localSubmitted && !foeMulliganApplied`。
   - `localSubmitted`：`OnMulliganDone` 两个分支（单机 `:7076-7078` / 联网 `:7060-7067`）置 true；`OpenMulligan`（`:6985`）清零。
   - `foeMulliganApplied`：单机在 `OpenMulligan:7022-7024` 之后置 true（= 原版 `receivedEnemyMulligan`）；联网在
     `ApplyLoggedAction` 收到 `m.kind == Mulligan && m.actor != _me` 时置 true；`OpenMulligan` 清零。
   - `27474` 改成 `_waitBanner.SetVisible(ShowWaitBanner(...))`，**删掉 `Ctx.Active != _me`** 与那两行「查不到」注释。
   ⇒ 单机局恒 false（与原版一致）；联网局只在「我交了、对手还没交」那一段 true。
2. **D3（面板 vs 横幅的接棒）**：联网 `OnMulliganDone` 里，提交后按原版顺序收面板（`_mulligan.Close()` / `FinishMulliganFinalPhase` 等价物）+ 关换牌那层 `MulliganPanel` 压暗，让 `WaitBanner` 立刻接管；`MulliganDone` 落地时不再重复关。⚠️ 要先核 `MulliganPanel.Close()` 是否被 `NetApply` 的后续步骤依赖。
3. **D4**：`WaitBanner.BuildCanvas` 建压暗时传 `raycast: true`，并在 `BattleDriver` 的点击 / `TickTooltipAt` 入口前调 `ShadeContains`（原版 `m_RaycastPadding` 下沿 1000）。

## 8. 没查清 / 拿不到

1. **原版实况没跑**（已关服）⇒ 「硬切、无 fade」是从「全部调用点都是裸 `SetActive`」推的，**没有逐帧实拍**。

2. **判据早就在仓里，只是没落进代码**：`普查产出_1015战斗判据/T13_HUD显隐条件总表.md:64` **逐字写着**
   「我换牌确认完、对手还没确认（`mulliganWaitText`，`BattleManager+0x1F0`）⇒ `SetActive(true)`；对手确认后关」——
   而同一份表 `:106` 又写「触发时机是我们挑的」。**同一份文件里两句互相打架**，代码照了错的那句写。
   ⇒ 建议：`:106` 那格就地订正、只留 `:64` 作唯一出处（铁律 5 / 6：两处各写一句必然不一致）。
3. **`YourTurnUI` 是死代码**（§2.3）；`资料/战斗规格/战斗重建_0827/…:237` 把它当成「大横幅」的记录会继续误导后来人。
4. **`ShouldFadeMulliganCards()` 恒 false**（机器码 `32 C0 … C3` 已核），而 `_FinishMulliganFirstPhase` 里那段「亮横幅」就挂在它下面 ⇒ 那段是死支。
   同类还有 `ShouldUseEnviromentalEffects()` 恒 false（我们早已记过）⇒ **原版这一版把这些「环境卡/换牌过渡」大部分都关掉了**，所以「对手换牌等不到」的窗口在实机上可能极短。⚠️ 这是「原版可能一闪而过」的唯一线索，**没有实拍不能下结论**。
