## 三 相机 mask 的真值（从存盘的 `Battle.unity` 现读）

| 相机 | 场景里的坐标 | `m_CullingMask.m_Bits` | 含义 |
|---|---|---|---|
| **战场透视相机** `BoardCamera 透视（原版值）`（`Scenes/Battle.unity:2681`） | `:2724-2726` | **256** = `0x100` = **只画层 8**（`ArenaLayer`） | **不画层 0** |
| **HUD/UI 相机** `Main Camera`（tag `MainCamera`，`:1015-1016`） | `:1102-1104` | **4294967039** = `0xFFFFFEFF`（int32 = **−257**）= **除层 8 之外全画** | **画层 0** |

（日志 `:1029xx` 那三条前置也逐条绿了：战场 cam ∋ 1<<8 · HUD cam ∌ 1<<8 · HUD cam ∋ 1<<0。）

⇒ 2D 档（层 0）**只可能被 HUD 画**。断言要的「战场相机画得到它」在这份场景里**逻辑上恒假**。

`(δ)` 排除（**但留一条备注**）：C6 判据 `资料/普查产出_1024c/C6_表现界面轮抽剩余判据.md:14/:32` 说
**原版**只有一台画层 0 的相机 = 战场透视相机（bits **1137**），UI 相机只画层 5（32）。
而我们重建的这份 `Battle.unity` 用的是另一套分工（战场 cam 256 / HUD 除 8 以外全画）——
所以「2D 档 → HUD」是**我们相机布置下的必然结果**，不是原版语义的等价物。
这不影响本诊断：断言本来就是**从存盘场景现读 mask** 的（`:51-52` `FindCams`），
现读出来 2D 档归 HUD ⇒ 断言期望就该是「HUD 画、战场不画」。
⛔ 但**别**为了迎合原版去把战场 cam mask 改成 1137 —— 那会让层 0 的所有 UI 件被透视相机重复画一遍（改动面远大于这 2 条）。

**新（两条轴各自按档位分方向，条数不变）**

```csharp
            int bit = 1 << expectLayer;
            bool boardDraws = boardCam != null && (boardCam.cullingMask & bit) != 0;
            bool hudDraws   = hudCam   != null && (hudCam.cullingMask   & bit) != 0;
            if (expectLayer == ArenaSlots.ArenaLayer)
            {
                // 3D 档：竞技场世界 ⇒ 战场透视相机，HUD 不能画
                check(boardDraws,
                      $"{what}：**战场透视相机**画得到它（mask {boardCam.cullingMask} ∋ 1<<{expectLayer}）");
                check(!hudDraws,
                      $"{what}：**HUD 正交相机不画**它（mask {hudCam.cullingMask} ∌ 1<<{expectLayer}）");
            }
            else
            {
                // 2D 兜底档：层 0 ⇒ **只归 HUD**；战场相机 mask 里没有层 0（Battle.unity 存盘 = 256）
                check(hudDraws,
                      $"{what}：HUD 相机画得到层 {expectLayer}（2D 兜底档只有这一台相机 —— mask {hudCam.cullingMask}）");
                check(!boardDraws,
                      $"{what}：**战场透视相机不画**它（mask {boardCam.cullingMask} ∌ 1<<{expectLayer}"
                    + " —— 2D 兜底档归 HUD）");
            }
```

要点：
- **断言条数不变**（每档仍是「战场一台 + HUD 一台」两条）⇒ 合计仍是 **209** 条；修完应为 **209 ✓ / 0 ✗**（现 207 ✓ / 2 ✗）。
- 两条轴**都**变成有方向的 ⇒ 「层写死 0 / 层写死 8」仍然两档各红一边（W11 §3·2 的灭自证性质**保留**）。
- 顺手把 `:216` 的 XML 注释从「『战场相机画得到』+『HUD 相机不画』三条一组」改成
