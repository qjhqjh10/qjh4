## 一、加时（Overtime）

### 1.1 触发 —— 原版代码只有一个判定点

`BattleManager.<NextTurn>d__395.MoveNext`
（`d:/2/Warpforge_tools/data/decomp_il2cpp_0827/decomp_out2/BattleManager._NextTurn_d__395__MoveNext.c`）：

```
:164-181  turnCounter 自增（判定用的是自增后的值）
:191-193  matchData.GameplayData.overtimeTurn 取出（Nullable<int>，两处空引用检查）
:194      if (!IsOvertime)
:205      if (turnCounter >= overtimeTurn)
:206          IsOvertime = true;                       // 字段偏移 +0x258（= +600）
:209          BattleHud.Instance.DisplayOvertime();
```

- `IsOvertime` 是 `BattleManager` 的 **private set** 属性（`BattleManager.cs:4719`）
  ⇒ **全盘唯一写入点就是这里**（`decomp_out` 1800 + `decomp_out2` 224 个方法体都搜过）。
- **每回合开始判一次；置 true 之后不再判**（`:194` 那道闸）。
- 🔴 **与回合时钟没有任何关系。** 这一段里**一个 `ClockManager` 调用都没有**；
  `ClockManager.StartTimer` 在 `_NextTurn:430` 的 `if (yourTurn)` **常规回合起钟**分支里，
  与 `IsOvertime` 无数据依赖。
  ⚠️ `资料/战斗规格/战斗重建_0827/子代理读报_csharp行为_0827.md:208` 那句
  「超时后再超 → `BattleHud.DisplayOvertime()`」**是错的** ——
  `DisplayOvertime` 全盘只有 `_NextTurn:209` 一个调用点（`BattleHud__DisplayOvertime.c` 只转发给 `OvertimeUi`）。

### 1.2 效果 —— 原版代码只做「多抽一张」

`decomp_out2/BattleManager__TurnStartCardDraw.c:35-65`：

```c
/* 常规：抽 GameplayData.drawCardsPerTurn 次 */
for (i = 0; i < *(int *)(gameplayData + 0x3c); i++) AddDrawCard(...);
/* 加时：再多抽 1 张 */
if (*(char *)(battleManager + 600) == '\0') return;   /* if (!IsOvertime) return; */
AddDrawCard(...);
```

⇒ **经典模式：加时 = 每回合起手多抽 1 张**（常规 1 + 加时 1 = 抽 2 张）。

🔴 **加时不动能量。** `GameplayVariablesData` 里**根本没有** `overtimeMana` / `overtimeDraw` 这类字段 ——
它那一族只有 `drawCardsPerTurn(0x3c)` · `manaAccumulation(0x40)` · `startingMana(0x2c)` ·
`manaPerTurn(0x38)` · `addedManaSecond(0x34)` · `handLimit(0x44)`。

### 1.3 两个模式口径不同（**用户 2026-09-16 指出**）

| 模式 | 加时效果 | 出处 |
|---|---|---|
| **经典 Classic** | 双方每回合 **抽 2 张**（不动能量） | 规则书 `:48` + 代码 `TurnStartCardDraw` |
| **遭遇 Skirmish** | 每回合 **+2 能量**（抽牌不变） | 规则书 `:137` + 用户 2026-09-16 |

⚠️ **规则书 `:137` 那段写在「通用资源」一节里，很容易被读成「两个模式都适用」—— 不是。**
经典以 `:48` 的模式表为准（只写「双方每回合抽 2 张」，**没有能量条款**）；
`:137` 的「每回合 +2 能量直至游戏结束」落在**遭遇模式**。

**佐证（都在本地）**：
- 原版**游戏内**的遭遇模式说明文案自己写着 **`Overtime begins earlier`**
