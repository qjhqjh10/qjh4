## ⚠️ 归一化时遇到的怪写法

同一关键词在 `keywords` 数组里长得不一样、归一化后才同名（各给一个原文）：

- **Talent**：`Talent` / `Talent: 'Uge Choppa` / `Talent: Aerial Seeding` / `Talent: Brood Progenitor` …共28种
- **Blast**：`Blast` / `Blast 1` / `Blast 2` / `Blast 3` …共6种
- **Shuriken**：`Shuriken` / `Shuriken 1` / `Shuriken 2` / `Shuriken 3` …共6种
- **Armour**：`Armour` / `Armour 1` / `Armour 2` / `Armour 2.` …共5种
- **Tide**：`Tide` / `Tide 1` / `Tide 2` / `Tide 3` …共5种
- **Companion**：`Companion` / `Companion 1: Gun Drone` / `Companion 2: Gun Drone` / `Companion 2: Missile Drone` …共5种
- **Sentry**：`Sentry` / `Sentry 1` / `Sentry 2` / `Sentry 4`
- **Rally**：`Rally` / `Rally: All enemies lose Stealth and Camouflage` / `Rally: Deal 1 damage to an enemy`
- **Strike**：`Strike` / `Strike: Draw a card` / `Strike: Give +1 to your units`
- **Oath**：`Oath` / `Oath 1` / `Oath 4`
- **Mob**：`Mob` / `Mob: Deal 1-3 damage to a random enemy` / `Mob: Gain +1 armor this turn`
- **Regeneration**：`Regeneration 1` / `Regeneration 2` / `Regeneration 3`
- **Vanguard**：`Vanguard` / `Vanguard.`
- **Stealth**：`Stealth` / `Stealth.`
- **Codex**：`Codex` / `Codex: Heals 3`
- **Dark Pacts**：`Dark Pact` / `Dark Pact of Excess`
- **Remnant**：`Remnant` / `Remnant.`
- **Artifice**：`Artifice` / `Artifice: Deploy a Necron Warrior`
- **Agenda**：`Agenda` / `Agenda: Gain 1`
- **Destroyer**：`Destroyer` / `Destroyer.`
- **Blood Thirst**：`Blood Thirst` / `Bloodthirst`
- **Ecstasy**：`Ecstasy` / `Ecstasy 5`
- **Teleport**：`Teleport` / `Teleport: Gain Vanguard and attack by itself`

归一化**没归到一起**、靠脚本里的 `ALIASES` 手动合的（每条都有依据）：

- `Concussive` → **Concussion**（图集 sprite 就叫 `concussive.png`，规则书写 Concussion）
- `Dark Pact` / `Dark Pact of Excess` / `Dark Pact of Resilience` → **Dark Pacts**（规则书条目是复数；of X 是 4 种增益的载荷）
- `Armor` / `armor` / `[Armor]` → **Armour**（美式拼写；卡池里没有独立的「护甲属性」字段）
- 尾点：`Armour 2.` `Remnant.` `Stealth.` `Vanguard.` `Destroyer.` —— 抄录时把句号带进了数组
- 冒号后是**载荷**不是新关键词：`Talent: Witchfire` `Rally: Deal 1 damage…` `Mob: Gain +1 armor…`；数字是参数：`Companion 2: Missile Drone` `Blast 2` `Tide 1`

> 大小写：任务里提到的 `hunt mark` 小写形态**在这份数据里不存在**（全文件只有 `Hunt Mark`，34 处）；`desc` 里的关键词写法实测 100% 首字母大写，小写只出现在 `[shield]` `[faith]` `[armor]` 图标方括号内。
> **词尾变化**：`desc` 侧另收了池子里仅有的 4 种变形 —— `Spirit Stones`(5) · `Remnants`(2) · `Prays`(1) · `Praying`(1)；其余关键词在卡面只用原形。
> **盲点自检**：desc 的「关键词位置」里出现的名字，除这 61 个以外只有 `Choose one` / `Your Warlord gains` 两个 —— 所以「不扫数组独有名字」不会漏掉真关键词。
