## ② 三个改动逐条（改前 → 改后 + 量纲判据出处）

### 1 量纲：条 `BarH` → `U(BarH)`；圆 `CircleD` → `U(CircleH)`
- **判据**：`ImageQuad.Create` 第 4 参的 doc **逐字** =「`worldHeight` 是**屏幕上的高度**（世界单位）」（`ImageQuad.cs:110`）；
  本现场 **1 px = 1/108 世界单位** = `EndPanel.PxPerUnit`（`EndPanel.cs:40` `1080f / DesignHeight`，`DesignHeight = 10f`；
  `Core/LayoutSpace.cs:148` 同一句）。
- **新增** `static float U(float px) { return px / EndPanel.PxPerUnit; }`，**照兄弟件**：`MulliganPanel.cs:194` `px / 108f` ·
  `CardChoicePanel.cs:102` `px * DesignHeight / 1080f` · `EndPanel.cs:55`（私有）`px / PxPerUnit`。
- **改前实绘**（算出来）：条 **62,370 × 6,894.72 px**（= 原版 ×108；`A964①` 报的 40,285 是「先按贴图比例定宽再 ×108」）⇒ 整屏铺满。
  **改后实绘**：条 **577.5 × 63.84** · 圆钮 **80.47 × 79.64**（脚本按 `WorldW = WorldH × aspect` 复核，逐位等于原版 rect）。
- ⚠️ **`CircleH`(79.64) 是本件新增的常量**（**同类**、不是顺手改别的）：原版 `CircleButton` **不是正方**，而 `ImageQuad.Create`
  只吃**高**（宽 = 高 × 比例），原来拿**宽** 80.47 当高 ⇒ 高多 0.83px；兄弟件取的就是这个高（`CardChoicePanel.cs:71` `PlayH = 79.64f`）。
  `CircleD`(80.47) 仍归 `HitContinue` 用，**命中口径一个字没改**。

### 2 `SetAspect`（原来一句都没有）
- **原版判据（2026-10-18 现读 `d:/2/新解包资源/assets_full/bundle_scenes_scenes_battlearena1/`）**：
  `Button`(RT 3348) `m_SizeDelta (577.50, 63.84)` + Image(MB **4202**) `m_PreserveAspect = 0` · `m_Type = 0(Simple)`；
  `CircleButton`(RT 3384) `m_SizeDelta (80.47, 79.64)` + Image(MB **4285**) 同样 `PA=0 / Type=0` ⇒ **两格都拉满 rect**。
- **贴图真实尺寸**（`Sprite/*.json` 的 `m_Rect` + 落地 PNG 头）：`40k_bt_underbutton` = **485×83**（比例 5.8434 ≠ 9.046）
  ⇒ 不补 `SetAspect` 只画 **373.04 × 63.84**（**窄 204.5 px**）；`40k_UI_bt_play` = **128×128**（≠ 1.0104，差 0.83px）。
- 兄弟件同一条：`CardChoicePanel.cs:161` 与 `MulliganPanel.cs:265`，**两句逐字相同**（后者那段注释还记着「这一处是漏了，不是设计」）。

### 3 `Label` 第 4 参（两处）+ 字号另走 `SetScriptHeight`
- `const int HeaderFontSize = 38` → **`const float ChromeFontPx = 38f`** + **`const int ChromeFontScale = 4`**。
  **档位算法（已写进注释）**：每档 = **7 px 大写字高**（`Label.cs:207`）、拉丁大写 ≈ **0.72 em**（`Label.cs:268`）⇒ fs38 要的
  大写字高 = 38×0.72 ≈ 27.4px ⇒ `27.4/7 ≈ 3.9` ⇒ **最近档 4**。
- 字号走 `Label.SetScriptHeight(text, px, pxPerUnit)` —— 「按 `Loc.HasCjk` 二选一（汉字 `SetGlyphHeight`≈1em / 拉丁
  `SetCapHeight`≈0.72em）」的**唯一一份**口径（`Label.cs:266`）；兄弟件同一形状（`MulliganPanel.cs:238` · `CardChoicePanel.cs:156`）。
- **标题那两行挪到了 `Show()` 末尾**（`SetChrome(true)` 之后）：`Show()` 开头刚跑过 `Hide()`，chrome 整排是关着的，而
  **TMP 未激活量不出尺寸**（CLAUDE.md §三那条坑）。`_barText` 留在 `Build()`（那时活着的）不动。
