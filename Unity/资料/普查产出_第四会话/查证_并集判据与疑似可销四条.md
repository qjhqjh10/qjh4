### 1. 两份换算式的原文 + 各用在谁身上

**甲式 = 裸 `transform.position` × 108 ± 原点**（**4 份**走它）：
- `Editor/RewardsScene.cs:180` `static float PxOf(float worldX) { return worldX * 108f + 960f; }` · `:184` `PxYOf(y) = 540f - y*108f`
  —— 用在 `QuadRectOf:528` → `RectOfUnion:542`

- `Editor/SettingsScene.cs:160` `float wx = q.transform.position.x * 108f + 960f, wy = -q.transform.position.y * 108f + 540f;` —— 用在 `RectOf:148`
- `Editor/MainMenuScene.cs:435` `LayoutSpace.PxX(q.transform.position.x)` / `PxY(...)`（`LayoutSpace.cs:175/179` 就是同一式）—— 用在 `HitQuadRect:429` → `UnionQuadRect:11150`

**乙式 = 先除父级 `lossyScale`，再 `ToPixel`，尺寸 × `K`**（**1 份**走它）：
- `Editor/DeckScene.cs:269-270` `var c = LayoutSpace.ToPixel(MenuDraw.PosInDesignSpace(q.transform)); float w = q.WorldW * PxPerUnit`（`PxPerUnit` = 108，`DeckRuntime.cs:59`）—— 用在 `UnionQuadsPx:279`
- 这一式的**权威原文**在 `Shell/MenuDraw.cs:655-661`（`QuadRectPx`，`K = DesignPxH / DesignHeight`），**但它是 `private`**；同式的还有 `ShellScene.cs:5317`（`GHitRect`）与 `Shell/ViewportClip.cs:289`。

### 2. 哪个是对的 —— **不等价，甲式错**

- 两式只差**一个因子**：甲式喂 `position`，乙式喂 `position / parent.lossyScale`（`MenuDraw.cs:71-79`）。
  ⇒ **`t.parent.lossyScale == 1` 时逐位相同**；**≠ 1 时甲式报的是「视觉 px」、不是设计 px**，偏差 = 父级累积缩放的 `(1 − 1/k)` 倍。
- 判据（**不拿我们自己另一份实现当判据**）：建件那一步写的是 `MenuDraw.Local:30-31 = RectCenter(r) − PosInDesignSpace(parent)`，而 `RectCenter` 走 `LayoutSpace.FromPixel`（**用实测 `VisibleWidth`**，`LayoutSpace.cs:157-162`）⇒ **读必须与写互逆**。乙式的 `PosInDesignSpace` 正是那条恒等式（`MenuDraw.cs:621-627` 自证：`PosInDesignSpace(q) = RectCenter(r)`）。**甲式少了那一次除法** ⇒ 在「父级带缩放」的输入下错。
- **有实据、不是推理**：`Editor/ShellScene.cs:5308-5309` 自己写着「**本窗根在批处理里 `scale = 0.8`，世界帧会差一档**」⇒ **同一个宿主里**甲式（`QuadPxRect:130-140` / `PiecesOutsideClip:117`）与乙式（`GHitRect:5317`）读数**必然差 0.8 倍**。触发输入 = 窗根被 `TransformScalerBySmallScreenUI` 乘 M（`WindowsManager.cs:381`），或链上任意 `localScale ≠ 1`（全仓 5 处写入点）。
- ⚠️ **非 16:9 那一档：甲乙两式【都】错** —— 两者都走 `LayoutSpace.ToPixel`（x 写死 108，`LayoutSpace.cs:168-172`），而写那一侧走 `FromPixel`（用 `VW`）⇒ **只在 16:9 重合**。这是 **`A990`**，**不是这两式之间的差**；正确式 = `MenuDraw.PixelOfDesign`（`:596-603`，`A990` 时新增）= `FromPixel` 的逆。
