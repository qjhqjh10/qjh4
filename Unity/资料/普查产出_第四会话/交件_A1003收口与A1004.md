## ③ `MenuDraw` 提 public 与并集口（签名）

```csharp
public static PxRect QuadRectPx(ImageQuad q)                                                         // :666（原 private，现提 public）
public static bool   QuadRectPx(ImageQuad q, out float x1, out float y1, out float x2, out float y2) // :677
public enum QuadGate { None = 0, Self = 1, InHierarchy = 2 }                                         // :689
public static bool UnionQuadRectPx(Transform t, QuadGate gate, bool searchInactive, out float x1, out float y1, out float x2, out float y2)                   // :716（转调下一版）
public static bool UnionQuadRectPx(Transform t, QuadGate gate, bool searchInactive, out float x1, out float y1, out float x2, out float y2, out int quads)     // :721（真身）
```
真身：`GetComponentsInChildren<ImageQuad>(searchInactive)` → 按 `gate` 逐块过滤 → `QuadRectPx` 求并集 →
`quads` 记**真被算进去的块数**；`t == null` / `quads == 0` ⇒ 四个 out 归零、回 `false`。
`PxRect`（`Core/UguiRect.cs:27`）本来就是 `public struct` + 公开字段 ⇒ `out` 形只是省掉各宿主的拆字段样板。

## ④ 三项差异怎么参数化（**都保留，⛔ 没统一**）

1. **激活闸三种** → `QuadGate`：`RewardsScene` = **`Self`**（`activeSelf`，父链关着也算）；
   `DeckScene`/`SettingsScene`/`ShopScene`/`ShellScene` = **`InHierarchy`**；
   `MainMenuScene` = **`None`**（**完全不过滤**，`activeInHierarchy` / `activeSelf` 都不看）。
   ⚠️ `ShopScene` 那两处还多一档：**`searchInactive = false`**（原样是 `GetComponentsInChildren<>()` 的缺省）
   —— 故这个形参**没有并进 `gate`**，两者是**两个轴**（`None + false` 是 `MainMenuScene` 那档做不到的组合）。
2. **`Label` 兜底** → **留在宿主**：只有 `RewardsScene.RectOfUnion` 有「一个 quad 都没有时退回 `RectOf`」，
   写成 `if (MenuDraw.UnionQuadRectPx(...)) return true; return RectOf(...);` —— 其余宿主直接回 `false`。
3. **非 16:9** → 本件**只**做了 `A1004` 那一行（`PixelOfDesign`）；**尺寸项 `WorldW × K` 那一半（`A990①`）没碰**，
   `MenuDraw` 里那条「同族还没收口的读口」注释已就地订正（把 `QuadRectPx` 从名单里划掉）。

**为什么出厂态读数逐位不变**：位置项只比甲式多一次 `PosInDesignSpace`（除以**父级** `lossyScale`）、尺寸项一个字没动
⇒ `k == 1` 时 `DivByScale(v,1f) == v`，两式**逐位相同**。已逐宿主核「父链有没有非单位缩放」：`SettingsWindow` 根 `0.9`
