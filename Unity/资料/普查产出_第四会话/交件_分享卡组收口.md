## ③ 两处怎么收口成一份

```csharp
// Deck/DeckRuntime.cs:3891 —— 分享的【唯一】实现（造串 → 写剪贴板 → 返回那一串）
public static string CopyDeckToClipboard(PlayerDeck deck)
// :3900 —— 那句提示的【唯一】文案（原版只弹一条 ShowMessage）
public static string ShareCopiedText(int len)
```

- **两个调用点**：`DeckRuntime.ShareDeckString()`（`State.Deck`，卡组编辑那颗 `Share`）· `Shell/DeckInfoPopup.ShareDeck("Share")`（`CollectionData.Raw(DeckIndex)`，Info 弹窗那颗圆钮）。
- **判据**：`CLAUDE.md` §三「两处写同一条规则 = 迟早不一致」。核法：`grep -rn "systemCopyBuffer" --include=*.cs` ⇒ 生产代码里**只有一处赋值**。
- **空串语义（有意改的）**：`deck == null` ⇒ **不写剪贴板**、返回 `""`，两个宿主各自**出声**说失败（原来 `ShareDeckString` 空串也写、还说「已复制（0 字符）」= 假报）。
- 原版第 ③ 句（toast）**不在共用件里**：两个宿主出声通道不同（`Say()` / `WindowsManager.ShowPopUp`）⇒ 各出各的，但**文案共用** `ShareCopiedText`。
