## 〇·一、`_EmissionColor` 那次退步（2026-09-15 已修）—— 三条坑

🔴 **坑一：原版材质带的是内置 shader 的默认值，不是「原版数据」。**
`_EmissionColor` 在 URP / 内置粒子 shader 的属性表里就是 `[HDR] _EmissionColor("Color", Color) = (0,0,0)`（`ParticlesUnlit.shader:9`），
没开发光的材质原样留成 `{0,0,0,1}`，而原版那边**根本不采它**（`_EmissionEnabled=0` / 无 `_EMISSION`）
⇒ **新接一个原版属性之前先问三句：默认值是什么、原版在什么条件下才采它、原版是加法还是乘法**（`工具/dump_shader.py` 读属性表）。
⚠️ **修法也不是「改成加法」** —— 原版 `Everguild/FX/Extra Color` 的属性表里**根本没有 `_EmissionColor`**
（21 项逐字：`资料/普查产出_0917/shader属性表_块1.md:278`），而它默认值是白 ⇒ 加了等于**白白多加一整份贴图（≈2×）** ⇒ **最终是整项删掉**。
（当时那三行「略偏亮」`StrikeEffect` / `VulnerableEffect` / `EnvironmentalCondition…` 已定案 —— **不是资产缺陷**。）

🔴 **坑二：`_EMISSION` 不能用 sweep 验。** 2026-09-18 实测（16 个目标 × 三批次，开 `WFSWEEP_GLOBALS=1`）：
**扫描态下它对全部 16 个目标都是全局开着的**（进第 1 个目标前就已开着；全局关键字总数第 1 个 59 个、第 2 个起 132 个）
⇒ **sweep 测的不是游戏里的样子**（游戏里我们的材质没开它，见 `EffectExporter.cs:388`）。
凡与 `_EMISSION` 有关的假设要**单效果 A/B，且先按 Emission 模块重置全局关键字**。
（同一次实测的另一半结论：绝对值漂移属实但**共模**，比值 `|ln|` 差 ≤0.0005 ⇒ **`RenderAt()` 不用改**；证据见正本 §五。）

🔴 **坑三：跑小批前必看** —— `EffectSweepBatch` 里写 `ResultPath` / `FrameCachePath` 的那几处是 `File.WriteAllText`，
**小批会把全量基线 `sweep_{orig,exp}.tsv` 与取景缓存整份覆盖掉**（先 `cp` 备份并存 md5、跑完按 md5 还原）。

**全量指标与逐组计数只认 `资料/特效还原台账.tsv` 一处**（修完已重跑全量 sweep 重生；`analyze_sweep.py` 每次会打「尺子自检」表，**看计数变化前先跟它比**）。**本节不抄第二份**。
⚠️ **`资料/特效E组_逐效果根因表.md` 的锅名单要按新台账重核**（那张表是按旧台账分的组）。

### 四、🔴 `MapProp` 无条件改属性名 —— 一次静默丢掉 207 个材质的贴图（2026-09-17 已修）

⚠️ 原记的根因「`EffectExporter.cs:299-307` 只对**根**渲染器 `psr0` 调 `ImportMaterial`，其余渲染器一律 `trailSlots.Add(-1)`」**不成立**

⇒ 凡是落到自建 shader 的材质，**贴图和颜色整个丢掉、不报错**。
实测（扫 `Assets/WarpforgeVFX/Materials/*.mat`）：`WarpforgeVFX/Particles/Extra Color` 上 **207 个材质、带贴图 0 个**；

## 三、shader 现状：三层解析架构

```
① 自建 shader（工程资产）      ← 最优先。可改、跨平台、属性名与原版对齐
② 工程自带（URP/Sprites）      ← 次优先。标准 shader 走这条
③ 原版 shader bundle（817KB）  ← 兜底。只给工程里没有的 Everguild 自定义 shader 用
```

优先级开关：`WarpforgeShaderMap.PreferBuiltIn`（默认 true，只影响 ① 要不要抢在前面）。

> ⚠️ **② 必须排在 ③ 前面**。`shaders_assets_all.bundle` 里连 `Universal Render Pipeline/Particles/Unlit`
> 这类标准 URP shader 都有，但那份**和工程自带的同名 shader 不是同一个对象**
> （实测 `GetInstanceID()` 不同），而且**在编辑器下渲染会出故障（整片品红）**。
> 拿它当基准会让「原版 vs 导出」的比对整个失真（原版那一侧全是品红）。
> 修好后原版那侧的品红像素 15899 → 0。**bundle 里的 shader 只适合运行时用。**

**为什么自建 shader 是最优解**：它是普通 `.shader` 工程资产（所见即所得、任意平台），而**属性名与原版一一对应**，所以原版材质的数值可以原样灌进来，零转换。

## 八、踩过的坑（别重踩）

| 坑 | 真相 |
|---|---|
| **🆕🔴 原版材质里的「黑 `_EmissionColor`」是死值，不是数据** | 2026-09-15 把 `_EmissionColor` 接进自建粒子 shader 时写成了**乘法**（`col = tex * _Color * _EmissionColor * IN.color`），而原版那批材质的 `_EmissionColor` 是**内置 shader 的默认黑**（`{0,0,0,1}`，URP `ParticlesUnlit.shader:9`），原版那边要 `_EmissionEnabled`/`_EMISSION` 才采它 ⇒ 我们这边一乘，**整个材质被乘成黑**，13 个效果同时变暗 30 倍。**修法**：🔴 **2026-09-18 更正 —— 一度改成加法发光项，那条也作废了**（实测原版 `Everguild/FX/Extra Color` 属性表里**根本没有 `_EmissionColor`**，而它默认值是白 ⇒ 加了等于**白白多加一整份贴图 ≈2×**）⇒ **最终是整项删掉**（见 §〇·一）。⚠️ **这和上面 `_SrcBlend` 残留值是同一个坑的第二次**：原版材质带的是内置 shader 的默认值，**接一个新属性前先问「默认值是什么、原版什么条件才采它、是加法还是乘法」**。定位：把 `4e0741d`（③-3）那一笔回退掉**13 个效果就全部复原**；细节见 §〇·一 |
| **🆕⚠️ 重导 prefab 之后必须重建效果库，否则所有特效静默不播** | 效果库（ScriptableObject）存的是 **(guid + fileID)** 引用。重导 prefab 时 GUID 不变（.meta 还在），但**内部 GameObject 的 fileID 会重新生成** → 958 条引用**全部解析成 null**。实测对账：库里 958 条，fileID 对得上的 **0 条**。而它**不报错**，只是 `Play()` 返回 null、什么都不发生（本会话就是被这个坑掉的：卡牌落位该播特效，一声不响）。**规矩：跑过 `EffectExporter.Run` 之后一定要跑一次 `EffectLibraryBuilder.Run`。** 现在 `Play()` 遇到空 prefab 会打警告、构建器生成完也会自检空引用数 |

| **legacy 粒子 shader 在 URP 里会变粉** | `Mobile/Particles/Additive` 这类是内置管线的，`Shader.Find` 找得到但渲染错误。且混合写死在 shader 里、材质上没有 `_SrcBlend`，必须按 shader 名推断混合 |
| **不清旧产物会累积副本** | `GenerateUniqueAssetPath` 会不断产出 `X 1.mat` `X 2.mat`。已加 `ClearGenerated()` |
| **`ParticleSystemRenderer.mesh` 不是 `MeshFilter`** | 漏了这条，Mesh 模式发射的粒子（弹体/光环）导出后会整个消失 |
| **比对时相机取景必须统一** | 各自自动构图会让亮度差失去可比性，曾据此得出错误结论 |
| **`-executeMethod` 一次只能给一个** | 给两个只会跑最后一个 |
| **`rm -rf Assets/WarpforgeVFX` 会连自己写的 Runtime 脚本一起删掉** | 清理只删 `Prefabs/Materials/Textures/Meshes` 四个子目录 |
| **卡框产物曾整目录丢失** | `桌面/新建文件夹 (5)/去盾牌/` 曾被清空过（原因未查明），重跑 `d:/4/Unity/工具/remove_medallion.py` 即恢复 |
| **项目文档说 `Warpforge_code` 是「签名桩」** | 核实属实：方法体全空（`AnimFXModuleTween.Initialize(){}` / `PlayAnimCoroutine(){return null;}`），0 个文件含桩标记——是**直接留空**而非抛异常。字段名/类型/`[SerializeField]` 是完整的，这部分能用 |
