   `DA_Smothering_Decree` · `GSC_Cult_Propaganda` · `GSC_Improvised_Barricade` · `GSC_Jammed_Communications` ·
   `GSC15 Poisoned Supplies` —— 全部是 `2026-09-16` 补进来的那 9 张（`.jpg` 手机翻拍 + `Poisoned Supplies` 换用了 `6破坏卡/` 那张翻拍、没用 `卡背和部队卡PDF（用不着）/` 里的 png）。
2. **假·没行 = 46 张**。C2 用的键是**卡名**，而同一个卡名两边写法常常不同（`card_ids.json` 的 `note` 也记着同类事）：

   `Sister Dogmata` ↔ `Dogmata` · `Bladeguard Lieutenant` ↔ `Bladeguard Veteran` ·
   `Poisoned Supplies` ↔ `Pilfered Supplies`（**这张是真容易配错的那一对**，`check_pnp_cards.py` 的注释里就点过名）……
   ⇒ 这些卡**行都在**，只是按名字 join 配不上。

**读数随口径浮动（我实测的三种口径）**：

| join 口径 | 命中 | 「缺」 |

| 卡名**精确**相等 | 1041 | **85** |

## 四、实测的坑（本批踩到 / 绕开的，下一个会话会再遇到）

1. 🔴 **一个字段里两条 token 互相包含 = 同一个位置画两枚（静默）**。`CardIcons.Rewrite` 是
   `s.Replace(token, tag)`（**纯子串、全局、先换长的**）⇒ 长那条插进去的**标签里就含短那条**。
   本批第一版逐卡表就撞了 **14 处**（`AM43 [desc] 'Armour' ⊂ 'Armour 2.'` 等），生成器的自检当场报出来。
   **绕法**：逐卡 token **按卡按字段现挑** —— 从词本身**向右延长**到与本字段**所有**既有 token 都不构成包含关系；
   挑不出来就**如实丢掉**（只 `GSC38 desc` 一条）。**只能向右** —— 裸 token 那一支把图标插在 token **起点**。
2. 🔴 **守卫③ 是【整字段】级的，不是【逐处】的**。字段里已经有一条含该词的 token（例 `Ferocity:`），
   规则对**整个字段**让位 ⇒ **同卡第二次出现**画不出来（本批 6 张这样：`AM29`/`SW42`/`UM90`/`TL29`/
   `ASH_Orian_Laratharjos`/`TAU16`）。**绕法**：逐卡给**带上下文**的 token（`Shield to` / `Ferocity,` /
   `Sentry 2` / `Synapse,` / `Stealth,` / `Stealth to`），中文侧同理（`狂暴时` / `哨戒 2` / `突触时` / `潜行时`）。
3. 🔴 **量「卡面印了没有」时，左边那侧不能用词边界**。转录里图标+词常与**前一个词粘连**
   （`nonFlyingFlying enemy` / `MeleeTalentTalent:`）⇒ 第一版度量加了 `(?<![A-Za-z0-9])` 守卫，
   把 `GOF85`/`EC5` 判成「卡面没印」**假阳性**。**去掉左守卫**（只留右侧 `(?![A-Za-z0-9])`）之后读数才自洽。
4. ⚠️ **`_还原效果文字.md` 的卡名不是主键**。同名的写法两边常有出入（见 §二）；**要用 PnP 文件名 / `ocrSrc`**。
5. ⚠️ **别把「挑不出安全 token」写成「卡面没印」** —— 那是两件事（铁律 2：没查到就说没查到）。
