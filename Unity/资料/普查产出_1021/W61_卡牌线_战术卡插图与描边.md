## 1. 结论一句话

- **① 做到**：非单位卡的立绘不再裁成「矩形 union」，改成**按卡框 alpha 的开口逐行切条带**
  （拱形开口逐行贴合，边缘再往框底下钻 3 贴图像素）⇒ 拱顶/异形开口都填满，
  多出来的部分被卡框盖住（= 用户说的「允许有边缘被卡框盖着」）。
- **② 做到（机制换了、**待渲一张图定一个数**）**：`_Outline` 从原来那层 SDF（等值带落在卡内 72%、
  正好压在画窗内沿）**搬到一层专用的 `outlineGlow`**（同一个 shader + 同一张 SDF，quad 放大
  `OutlineGlowScale = 1.35`）⇒ 等值带落到**卡框外沿**，只露在卡外那一圈。
  同时补上原版材质里**一直没绑的 `_Noise`**（`Noise Combined`）。

## 4. 没查清 / 与原版矛盾的地方

1. 🔴 **`OutlineGlowScale = 1.35` 是【从实拍反推的唯一一个可调数】**，不是原版字段：
   实测光带中线在卡半宽 **72%**，要让带子压到卡框外沿（框内容 bbox x −1.02..1.08、卡半宽 1.046）
   ⇒ 1.046/0.755 ≈ **1.39**，取 **1.35** 让它稍微压进框内一点。**这一条没有像素级判据**
   （原版 shader 是 Shader Graph 的 DXBC，`_Outline` 到底按哪条等值线出带子我没解出来 ——
   本机没有 `fxc/dxc`，`工具/dump_shader_blob.py` 只到 RDEF 资源名那一层）。
   ⇒ **主对话渲一张并排图后若偏内/偏外，只改这一个常量**（注释里写了同一句）。
2. ⚠️ **原版字段与实拍矛盾**（见 §2·②）：`stratagemHighlightFrame` 那张 SDF 与 `troop` 那张几乎逐像素相同、
   都是实心卡形；**按字段推不出「光围整卡」**。我们按实拍做，**并把这条矛盾留在这里**。
3. ⚠️ **`_Noise` 补上之后，软光/影（落地阴影）也会多一层噪声** —— 原版是**同一条材质**、本来就有这一层
   （卡背那条路也一直有），但**我们之前没绑**⇒ 这次补上会**改动阴影观感**。
   渲图时请一并看一眼「卡的落地阴影有没有变脏」；若变脏，那是**原版就有的样子**（别急着回退，先和参考图比）。
4. ⚠️ **`_Noise` 对光带位置的影响没量过**：`Noise Combined` 的 B 通道均值 **0.278**（默认白图是 1.0），
   若 shader 用它做 `sdf ± noise*k` 的偏移，光带半径会跟着动 —— 与 §4·1 那个 1.35 **可能叠加**。
   ⇒ 第一次渲图时**先看半径对不对，再看颗粒**。
5. **没跑到真机/Unity**（派单禁止）：`OutlineGlowScale`、噪声观感、条带在真机手牌上的观感，**都要靠一张渲染图定**。

## 5. 顺手发现（⛔ 我没改，交主对话分诊）

1. **`SdfMaterial()` 里 `_Cull` 的注释是错的**：`CardView.cs` 卡背那段写着「`_Cull = 2`（背面剔除），
   **与卡面那层不同**」—— 现读 `Card Frame SDF` 材质 JSON，**`_Cull` 也是 2.0**。两条是同一个值，
   注释里的「与卡面不同」不成立（只影响注释，不影响画面）。
2. **`_ALPHACHANNEL`（float，材质里 = 0）我们也没抄**：shader 属性表里确有这一项（`AlphaChannel`），
   但 `_ALPHACHANNEL_R` 关键字已经开着了；这一个是默认值还是另有讲究**没查**。
3. **`_SpriteAlphaEdge`（float，材质里 = 0.397）卡面那条没抄**（卡背那条抄了）。同理没查它在 shader 里有没有被读。
4. **单位卡的「可打出」绿描边现在其实也是坏的**（同一个根因）：SDF 那条带子落在卡半宽 72%，
   而单位卡的立绘铺满整个卡面 ⇒ 带子被立绘完全盖住 ⇒ **单位卡的可打出绿光一直看不见**。
   这次换层 + 放大之后**单位卡也一起修好了**（`SetOutline` 对两种卡是同一个口）。
5. `ArtMeshInFrame` 的 `frameQuad` 形参现在**仍然没人用**（它走 `ArtBoard`），改前就是这样，没动。
