## 二、文件名与函数体不一致（T07 第 2 项）

### 2·1 判定规则（机器可复现）

1. 文件名 stem 反查 `wanted_full.txt` → 原始方法名 `name`（形如 `类.嵌套类$$方法`）。
2. Ghidra 渲染规则 `T(name)`：`$$`→`__`；再把 `.`、`$`、`|`、`:` 各换成 `_`
   （实测：`<>c` 保留 `<>`；`<Clone>$`→`<Clone>_`；`g__...|21_0`→`g__..._21_0`；`global::`→`global__`）。
3. 取 `.c` 文件**第一条函数签名行**（跳过开头 `/* ... */`）里 `(` 前的最后一个 token = **函数体真名**。
4. `T(文件名所指方法) != 函数体真名` ⇒ 判为「不一致」。

一行自检示例：

```bash
head -1 "D:/2/tools/decomp_full/CardCollectionTab.__c___GetCollection_b__8_1.c"
# void AlternateArtCardCollectionTab_<>c__<GetCollection>b__11_1(undefined8 param_1,longlong param_2)
grep -n "GetCollection>b__8_1$\|GetCollection>b__11_1$" D:/2/tools/all_methods.txt
# 11006:7236464  CardCollectionTab.<>c$$<GetCollection>b__8_1
# 10906:7236464  AlternateArtCardCollectionTab.<>c$$<GetCollection>b__11_1
```

> ⚠️ T07/`W58-K12` 记的文件名 `CardCollectionTab.__c___GetCollection_b8_1.c` 少了两个下划线；
> 实际文件名是 **`CardCollectionTab.__c___GetCollection_b__8_1.c`**（`b__8_1`）。内容结论不变。

### 2·2 现读数量（2026-10-21）

| 项 | 数字 |
|---|---|
| 总 `.c` 文件 | **25,096** |
| 函数体与文件名**一致** | **17,736（70.67%）** |
| **不一致** | **7,360（29.33%）** |
| ├ 函数体 = **同一地址上的另一个方法**（首个「不含空格」的名字） | **7,022（95.4%）** |
| ├ 函数体是 `FUN_/thunk_FUN_`（Ghidra 没命名） | **299（4.1%）** |
| ├ 函数体是**另一个地址**的方法（残余，内容归属未证） | **38（0.5%）** |
| └ 同地址但不是「首个空格自由名」 | **1** |

按「该文件自己是什么方法」拆分（分母是 25,144 个 stem；41 个大小写合并在内）：

| 文件自身类别 | 总数 | 不一致 | 不一致率 |
|---|---|---|---|
| 普通具名方法 | 19,830 | **4,455** | 22.5% |
| 编译器 lambda 闭包 `<>c` | 3,123 | **1,607** | **51.5%** |
| 迭代器状态机 `<...>d__N` | 2,125 | **1,288** | **60.6%** |
| 局部函数 `g__` | 66 | **10** | 15.2% |

⇒ **不是 lambda 独占**：普通方法也有 4,455 个。lambda/迭代器的**出错率**约为普通方法的 2.3–2.7 倍。

### 2·3 成因（实证，非推测）

1. **IL2CPP 相同代码折叠**：`all_methods.txt` 里 **13,991 个地址**挂着多个名字（这些地址共 151,763 行）；
   `wanted_full.txt` 里 **903 个地址**挂着 **8,062 个名字**。
   最极端：地址 `4929072`（一个 `return *(param+0x18)` 的通用 getter）挂了 **1,931 个方法名**（现读）。
2. **Ghidra 一个地址只建一个函数、只取一个名字**（`Renamer.java` 的 `if (fm.getFunctionAt(a) == null) createFunction(...)`）。
3. 哪些名字能被 Ghidra 接受：**含空格的名字会被拒**（泛型实参 `A<object, object>` 里有空格）；
   **重名（且大小写不敏感）会被拒**（例：`RoomOptions$$get_isVisible` vs `get_IsVisible` 只落一个）。
   ⇒ 函数体显示的是「该地址上**第一个被接受**的名字」。
   按此规则做整库重命名模拟，能精确预测 **24,641 / 25,096 = 98.2%** 的函数体首行；剩余 455 中 299 个就是 `FUN_`，38 个是 §2·2 的「另一个地址」残余。
4. 因此：**函数体内容是正确的**（同一地址 = IL2CPP 判定为同一份代码，语义相同），**错的是文件名**。
   例外是那 **38 个**「函数体名字属于另一地址」的文件 —— 其内容归属**未证**，引用前要单独核。

### 2·4 对已有结论的影响（W58-K12 那条要扩写）

- W58 写的「lambda 级结论只当旁证」**方向对、范围太窄**：**任何方法**都可能被折叠换名（4,455 个普通方法）。
- 正确用法：**索引按函数体首行建，不按文件名**。本次现读：25,096 个文件里只有 **18,051 个不同的函数体名**；
  重复最多的函数体：`<>f__AnonymousType31___ctor`（1,503 个文件）、
  `AuthenticationValues__get_AuthGetParameters`（732）、`NetworkingPeer__OnMessage`（676）、
  `PhotonHandler___ctor`（358）、`<>f__AnonymousType7<Int32Enum>___ctor`（301）。
- 299 个 `FUN_` 文件：内容可能是对的，但**没有名字**，不能按名引用。
- 38 个「另一地址」文件：**不要按文件名引用**，需要回到地址/调用点人工核。

### 2·5 普查脚本（可复现；本次未落进仓库，按 T07「只写一份报告」）

```python
# python -I -X utf8 census.py   （2026-10-21 实跑输出：17736 7360）
import io, os, re, collections
DEC = "D:/2/tools/decomp_full"
def parse(p):
    for line in io.open(p, encoding="utf-8", errors="replace"):
        line = line.rstrip("\r\n")
        if "\t" in line:
            a, n = line.split("\t", 1)
            try: yield int(a), n
            except ValueError: pass
T = lambda n: n.replace("$$", "__").translate(str.maketrans({".": "_", "$": "_", "|": "_", ":": "_"}))
SAN = re.compile(r"[^A-Za-z0-9_.-]")
fn = collections.defaultdict(list)
for a, n in parse("D:/2/tools/wanted_full.txt"):
    fn[SAN.sub("_", n)].append((a, n))
def body(p):
    t = io.open(p, encoding="utf-8", errors="replace").read(2000).lstrip()
    while t.startswith("/*"):
        t = t[t.find("*/") + 2:].lstrip()
    return t[:t.find("(")].rstrip().split()[-1]
ok = bad = 0
for f in os.listdir(DEC):
    if f.endswith(".c"):
        if body(os.path.join(DEC, f)) in {T(n) for a, n in fn[f[:-2]]}: ok += 1
        else: bad += 1
print(ok, bad)   # 17736 7360
```
