## 三、踩过的坑（本会话新增；**正文已进 `CLAUDE.md` §三，这里只列索引**）

| 坑 | 一句话 |
|---|---|
| 裸 CR（`\r\r\n`） | 让「按行号」的一切工具算错且**静默**（`DeckRules.cs` 中 7 个 ⇒ 行号偏 +7 ⇒ `--fix` 改错 15 行还变绿）。修法 = 二进制 replace；工具一律按二进制读 |
| `.c` 文件名 16.5% 不可信 | Ghidra 同形函数合并命名；引用前查 `G4_文件名与内容不符_全量.tsv` |
| `.c` 有 367 行 ≠ 逻辑完整 | 先看**返回类型**：`void` 出现在本该返 `float` 的函数上 ⇒ **值全丢**，算式要回 RVA |
| 四份 Cpp2IL 产物只有一份有真体 | `out_cpp2il_dev_ilspy`；「100% of methods decompiled」说的是**签名**不是体 |
| Cpp2IL 会静默丢字段赋值 | 「只是转调」且签名带参数而体里没用它 ⇒ **必须反汇编确认** |
| 泛型类方法体从没被导出 | `dump.cs` 写 `// RVA: -1`，真地址在 `GenericInstMethod` ⇒ 按 RVA 非负筛会**整类筛掉** |
| `Auras.Recompose` 不能当重挂点 | 幂等 ≠ 无副作用（重放夹血/费用/誓约） |
| `ScheduleAction` 会推队尾 | 拿它排演出回调 ⇒ 悄悄拖慢 AI 节奏且零报错 |
| `play all dump` 看不见 AI | 结构上没有 AI 决策列 ⇒ 不能当「改对/改错」的证据 |
| 引擎事件把关键词放在 `CardId` | ⛔ 别按 `e.Keyword` 取（会数出 0） |
| `Loc.T` 有三档兜底 | 「手写表没有」≠「会印键名」；扫 `Loc.T` 必须跳注释 |
| `JsonUtility` 把 `null` 物化 | `!= null` 恒真（锚点计数、`Manifest` 七个字段都中） |
| 原版随机数是「开局预烧 100 个整数 + 按下标取」 | 同局确定、**不是种子可复现**；实现要用 `ctx.Rng` 预烧 |
| `Transform.Find` 把 `/` 当路径 | 节点名带斜杠时按名找必须逐子件比 `name` |
| `--fix` 只改起始行 | range 尾会失真；且「工具报的行号」可能本来就漂了 |
