| 缩写 | 实指 |

| `工/` | **已进 Unity 工程**的切图 `MyGame/Assets/CardPresentation/Art/原版/`（368 张 PNG：`0_mainmenu/` `去重资源/` `battleatlasui/` `卡组选择按钮/`） |
| `G/` | **Godot 原型** `d:/warpforge/`（**不是 Unity 主工程**；UI 全用 GDScript 代码搭，`.tscn` 只有根节点） |

**「有 / 半有」一律指 `G/`（Godot 原型）**。**Unity 主工程零菜单场景**——`Assets` 下 6 个 `.unity` 只有 Battle / DeckEditor / CardBase / BattleArena1 / VFXWhiteboard / SampleScene，**本块 98 个界面在 Unity 侧一个都没有**。
Godot 原型有同名 `.gd` = 那一件已有实现，可作 Unity 移植的参照，但**不等于 Unity 做了**。
