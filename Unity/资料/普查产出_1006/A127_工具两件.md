**`_lg_is_vertical` 的判据（这是本件的核心，全文逐条写进了 docstring）** ——
`EverguildLayoutGroup : HorizontalOrVerticalLayoutGroup`（`dump.cs:112913`），字段
`alignment` @0x70（枚举 `Horizontal=0 / Vertical=1`，`dump.cs:112899`）· `evenlySpaceinBetween` @0x74：

1. `EverguildLayoutGroup__get_IsVertical` = `*(int *)(this + 0x70) == 1` ⇒ `isVertical = (alignment == 1)`。
2. 四个覆写体（`CalculateLayoutInputHorizontal/Vertical` · `SetLayoutHorizontal/Vertical`）**开头都先调一次
   `CalculateSpacing()`**，然后才 `CalcAlongAxis` / `SetChildrenAlongAxis`，传的 `isVertical` 就是
   `(int)this[0xe] == 1`（= 同一个 `alignment`）。
   ⚠️ `CalculateSpacing` 是**这个类自己新增的虚方法**（全量 dump 里 `CalculateSpacing` 只出现在这两行：
   `dump.cs:112909`（闭包方法）与 `:112930`（`protected virtual void CalculateSpacing()`）——
   uGUI 的 `HorizontalOrVerticalLayoutGroup` **没有**这个钩子，工程里那份
   `HorizontalOrVerticalLayoutGroup.cs` 也 grep 不到），所以它只可能被**本类**的那四处调用
   （反汇编里那四处的头一句形状一致：`(**(code **)(*param_1 + 0x3c8))(param_1, *(undefined8 *)(*param_1 + 0x3d0))`
   = klass 上 slot 41 的 `(methodPtr, methodInfo)` 一对，即「无参虚方法」）。
3. `EverguildLayoutGroup__CalculateSpacing` 的**第一句**是 `if (*(char *)(this + 0x74) == 0) return;`
   ⇒ **flag=0 时整条 no-op**，四个覆写体剩下的部分只剩「用 `isVertical = (alignment==1)` 调 HOVLG」
   ⇒ **与 `HorizontalOrVerticalLayoutGroup` 逐位等价**（本工具那两套算式本来就是照 HOVLG 抄的）。
4. flag=1 时它**改写 `m_Spacing`**：`spacing = (本组该轴尺寸 − 子件数 × 首个子件该轴尺寸) / (子件数 − 1)`
   （末尾 `UnityEngine_UI_HorizontalOrVerticalLayoutGroup__set_spacing`）—— 「本组该轴尺寸」取决于运行期
   布局跑到哪一步 ⇒ **序列化的 `m_Spacing` 不是运行期那个值** ⇒ 返回 `None`（**没排**）。
   ⚠️ 实测本包 3 个 `EverguildLayoutGroup`（`Missions Tab/…`、`Weekly Mission Container/…`、
   `Rewards Base Submenu Variant/…` 的 `steps`）**全是 `evenlySpaceinBetween = 1`**。

**`FlexibleGridLayout` 为什么也只能是「没排」**：它是 `LayoutGroup` 的**直接子类**（没有 `isVertical`），
`CalculateLayoutInputHorizontal`（VA `0x180807E20`）里自己摸 `rows`/`columns`/`itemSize`/`spacing`
+ 一张 `bool[,] grid` 打包表，逐个子件 `SetChildAlongAxis` 并回写本组 `sizeDelta`；
而 `CalculateLayoutInputVertical` / `SetLayoutHorizontal` / `SetLayoutVertical` **三处共用同一个 RVA
`0x4B33B0`**（反汇编是裸 `ret` = 空壳）。⇒ 与 HOVLG / GridLayoutGroup **都不是一回事**，本工具不套。

**`EverguildGridLayoutGroup`** 仍走 `grid?`（分类**没变**）：它是 `GridLayoutGroup` 的子类，
四个覆写都只是 `ApplyMobileScaleIfNeeded(() => base.X())` —— 那个函数把 **`cellSize`(0x68/0x6c) 与
`spacing`(0x70/0x74) 四处乘 `cellSizeMobileMultiplier`(0x80)**，且**只在移动端平台为真时**乘，
调完 base 再原值写回 ⇒ **桌面档 = 原封不动的 GridLayoutGroup**（本工具本来就不排 Grid 系）。

**为什么要「先钉 CAB」**（设计判据，写在 `fileid_note` 与文件头里）：`m_FileID` 是**引用者所在那份
CAB 的 externals 下标**（0 = 本文件，N ≥ 1 = `externals[N-1]`），而**同一包内多份 CAB 的 externals
顺序不一致**（实测；见下）⇒ 拿包级的一份 externals 去解所有对象 = **静默错**。
「引用者在哪份 CAB」只有**真包**答得了（解包目录按资产类型分目录、不带这个信息）。

**（1）§④ 的第一条：一个包内多份 CAB 的 externals 是否逐位一致**

```python
# -*- coding: utf-8 -*-
import os, sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8', errors='replace')
import UnityPy
D = r'D:/2/unity_run_ref/Warpforge_Data/StreamingAssets/aa/StandaloneWindows64'
files = sorted(f for f in os.listdir(D) if f.endswith('.bundle'))

def extlist(sf):
    return [getattr(x, 'path', None) for x in (getattr(sf, 'externals', None) or [])]

multi, one = [], 0
for fn in files:
    env = UnityPy.load(os.path.join(D, fn))
    bf = list(env.files.values())[0]                       # ← 外层 key 是包路径，值是 BundleFile
    cabs = {k: v for k, v in (getattr(bf, 'files', {}) or {}).items()
            if not (k.endswith('.resS') or k.endswith('.resource'))}
    if len(cabs) == 1:
        one += 1
        continue
    lst = {k: extlist(v) for k, v in cabs.items()}
    ks = list(lst)
    same_len = len({len(lst[x]) for x in ks}) == 1
    same = all(lst[x] == lst[ks[0]] for x in ks)
    ndiff = None
    if same_len and not same:
        ndiff = sum(1 for i in range(len(lst[ks[0]]))
                    if any(lst[x][i] != lst[ks[0]][i] for x in ks))
    multi.append((fn, len(cabs), [len(lst[x]) for x in ks], same, same_len, ndiff))
print('单 CAB 的包 =', one, ' 多 CAB 的包 =', len(multi))
for fn, nc, lens, same, sl, nd in multi:
    print('%-56s CAB=%d 条数=%-12s 逐位同=%-6s 同长=%-6s 不同位=%s'
          % (fn[:56], nc, lens, same, sl, nd))
```

**（2）§④ 的第二条：CAB 名 → 包 是否唯一**

```python
# -*- coding: utf-8 -*-
import os, sys, io, time
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8', errors='replace')
import UnityPy
D = r'D:/2/unity_run_ref/Warpforge_Data/StreamingAssets/aa/StandaloneWindows64'
files = sorted(f for f in os.listdir(D) if f.endswith('.bundle'))
t0, cab2b, dup, n_cab = time.time(), {}, {}, 0
for fn in files:
    env = UnityPy.load(os.path.join(D, fn))
    bf = list(env.files.values())[0]
    for k in (getattr(bf, 'files', {}) or {}):
        if k.endswith('.resS') or k.endswith('.resource'):
            continue
        n_cab += 1
        if k in cab2b and cab2b[k] != fn:
            dup.setdefault(k, [cab2b[k]]).append(fn)
        cab2b.setdefault(k, fn)
print('扫 %d 包耗时 %.1fs · CAB 总数 %d · 唯一 CAB 名 %d · 重名 %d'
      % (len(files), time.time() - t0, n_cab, len(cab2b), len(dup)))
```
