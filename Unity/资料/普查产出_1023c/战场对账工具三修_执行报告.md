### 3·2 新写法（**没改 diff 算法**，只改「喂给它的文件」）

现读 `arena_diff.py:190-205` 后按它的约定接线：`alts = glob('preview_<场>__p*.png')`，`diffs = [base] + alts`，`np.median`。

脚本现在每场做四步：

1. **`base` 另存 `__p2.png`**（`:81`）—— 让 `__p*` 收集能吃到「默认相位 2.0」那张 ⇒ **中位跨 4 个不同相位**。
   * 但**先比 md5 守卫**（`:66-71`）：若 base 与某个**非 2** 相位图逐字节相同 ⇒ 说明它是上一轮覆写留下的
     ⇒ **⛔ 不另存**（否则等于把 p12 贴成 p2 的标签，比原来更糟），只报红 + 打印「先重渲 base」的完整命令；
     已存在的 `__p2` 若没更新，会额外提示「可能是旧代码渲的」。
2. **逐相位渲染**：保留「正斜杠 + 直接前缀赋值」，判据从「只看 mtime」升级为 **mtime(`%.9Y`) + md5 + rc** 三条（`:87-105`）：
   rc≠0 → 红；mtime 与 md5 都没变 → 红「渲染没发生」；mtime 变了但图逐字节相同 → 黄字提示（渲过了，只是没变）。
3. **跑完把 base 还原成默认相位**（`:108-111`，与 `arena_ablate.sh:26/58/64`「基准不许被诊断档污染」同一口径）
   ⇒ 之后 `arena_diff` 的 base / 色调表、`arena_compare.py`、`arena_imgstats.py` 读到的都是**默认相位**，不是最后一个相位。
4. **打印「本次参与中位的文件 + 每张 md5 前 8 位 + 票数/不同相位数/重复点名」**（`:113-139`）
   ⇒ 一眼看出 base 有没有被当相位用；不同相位 < 3 时额外报红（`A1615`）。

另外：`shopt -s nullglob`（`:33`）—— 相位图一个都没有时 `for f in …__p*.png` 不会退化成字面量。
