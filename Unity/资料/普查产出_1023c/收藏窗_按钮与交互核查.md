## 〇、结论（先看这几条）

1. **缺 1 条 P0 族（3 处叠加）**：用户点名的「卡牌悬停淡蓝光」——**机制在、颜色错、尺寸错、强度错**。
   原版 = `_Outline` 颜色 **RGBA(0, 0.5027, 1, 1)**（`#0080FF`）、quad **4.4281×4.4281** 设计单位、alpha 目标 **1.0**；
   我们 = `_Outline` **白 (1,1,1)**、quad **卡的 1.09×1.06**、alpha 只有 **0.447**（被 `RimAlphaScale` 乘掉）。详见 §三。
2. **其余控件：没有「未实现的按钮」** —— 每个可点件都有 handler（全文件已无活的 `NotifyNotBuilt` 调用）。
3. **「实现但不像」7 处**：悬停光（上条）、4 个滚动区少了橡皮筋（原版 `Elastic`）、`Filter Toggle` 与搜索框 / Owned / Upgradable 行**少了 ColorTint 悬停**、卡格点击少了选中 punch。
4. **命中区 2 处比原版小**：`Filter Toggle`（原版 `m_RaycastPadding=(-10,-10,-15,-10)`）与 `Clear filters`（四边 −10）。

## 三、🔴 专节：卡牌悬停的「淡蓝光」（用户点名）

### 3·1 原版是哪一层（判据链完整）
1. 层级路径：`Collection Card ▸ Content ▸ CardUI ▸ 2DCard ▸ Front ▸ **Card Highlight And Shadow**`
   （兄弟序在 `CardImage` / `CardFrame` **之前** ⇒ 画在卡后面，只从轮廓外沿露出来）。
   组件 = `Image` + `UIImageMaterialColorChanger`（`MENUS/MonoBehaviour/MonoBehaviour_7149398958002140504.json`
   与 `MonoBehaviour_3736930816788264280.json`）。
2. **颜色从哪来**：`Collection Card` 根组件 `CollectionCard`
   （`MENUS/MonoBehaviour/MonoBehaviour_40971030049256792.json`）：
   `highlightColor = {r: 0.0, g: 0.5026950836181641, b: 1.0, a: 1.0}` ⇒ **`#0080FF`（0,128,255）**、
   `useHoverHighlight = 1`、`useSelectedHighlight = 1`、`initialCardScale = 150`、`initialHeight = 512`。
3. **写到哪个属性**：`DEC/Card2DController__.ctor.c` 把 `Shader.PropertyToID(<字面量>)` 写进 `+0x80` / `+0x84`；
   两条字面量经 `d:/2/tools/il2cpp_out/stringliteral.json` 反查：
   `0x4237790 = "_Outline"`（→ `+0x84`）· `0x4240978 = "_ShadowColor"`（→ `+0x80`）。
   `DEC/Card2DController__ToggleHighlight.c` 与 `ChangeHighlightColor.c` **都传 `+0x84`** ⇒ **写的是 `_Outline` 的颜色**。
4. **触发链**：`CollectionItem.OnPointerEnter` → `HoverHighlight(true)`
   → `DEC/CollectionCard__HoverHighlight.c` → `Card2DController.ToggleHighlight(on)`
   → 取该材质当前色、**把 alpha 改成 1/0**、交 `UIImageMaterialColorChanger.DoColorChange(…, 0.2f)`。
   `DEC/CollectionCard__Start.c`：开场先 `ChangeHighlightColor(highlightColor)`（整色写入）+ `ToggleHighlight(false)`（alpha→0）。
5. **时长 / 曲线**：`0x1834b2bb0 = float 0.2`（`工具/read_literal.py` 实读）⇒ **0.2 秒**；
   `UIImageMaterialColorChanger.Update` 是**按时间线性插值**（`f = t/duration` 后 lerp，无 ease）⇒ **线性**。
   ⚠️ 它**没有**「悬停延时」、**没有**缩放/位移/描边——只有 alpha。
6. **尺寸/位置**：`Card Highlight And Shadow` 的 `RectTransform`
   （`MENUS/RectTransform/RectTransform_4117944419202364760.json`）= 锚 0.5/0.5、**`sizeDelta = 4.4281 × 4.4281`**、
   `anchoredPosition = (0, −0.01265)`、`localScale = 1`。
   同一棵树里：`2DCard` = 2.0927×3.3313（= 卡体）、`CardFrame` = 2.2452×3.2572（= 卡框）。
   ⇒ **光晕 quad ≈ 卡框宽的 1.97 倍 / 卡框高的 1.36 倍**（左右各多出约半个卡宽，上下各多约 0.17 个卡高）。
7. **材质**：`Image.m_Material` → pid `-3316280387615011577` =
   `bundle_duplicateassetisolation_assets_all/Material/Material_-3316280387615011577.json`，名 **`Card Frame SDF`**：
   shader `Everguild/FX/Card Highlight And Shadow`、`_CustomRenderQueue = 3000`、
   keywords `_ALPHACHANNEL_R` + `_NOISE_CHANNEL_B`、`_Outline = (0.358,0.059,0.327, **0.0**)`（平时不可见）、
   `_Inner_Edge 0.333` · `_Inner_Fallof 0.224` · `_Outer_Edge 0.465` · `_Outer_Fallof 1.053` ·
   `_SpriteAlphaEdge_Outer 0.484` · `_SpriteAlphaEdge_Inner 0.043` · `_NoiseIntensity 1.15`。
   ⚠️ `Image.m_Sprite` 在 prefab 里是 **null**：sprite 由 `Card2DController.SetFrame(frame, highlightFrame)`

### 3·2 我们的实现（`Core/CardView.cs`）
- `SetHoverHighlight(bool)` `:6569-6575`：`ApplyRimColor(new Color(1f, 1f, 1f, on ? 1f : 0f), 0.2f)`
  ⇒ **颜色是白**，时长 0.2 ✅。
- `ApplyRimColor` `:6582-6607`：`target.a *= CardHighlight.RimAlphaScale`（`Core/CardHighlight.cs:168` = **0.4470588**）
  ⇒ **悬停最亮只有 44.7%**。

- `RimMaterial` `:9935-9970`：shader 同 ✅，但材质值取的是 **`Card board Frame SDF`**（战斗 `MinionLight` 那份）：
  `_Inner_Edge 0.242` · `_Inner_Fallof 1.0` · `_SpriteAlphaEdge_Inner 0.339`；
  贴图是 `CardArt.CardFrameSdf()`（另一张 SDF），并显式写 `_ShadowColor = (0,0,0,0)`。

### 3·3 判定与要改什么
- 判定：**⚠️ 实现但不像（P0）** —— 机制（SDF `_Outline` + 0.2s）对，**颜色/尺寸/强度/材质档四处不对**。
- 要改（判据全齐，可直接派）：
  1. `SetHoverHighlight` 的颜色改成 **`new Color(0f, 0.5026951f, 1f, on?1f:0f)`**（出处见 3·1 ②）；⛔ 不要动战斗状态那几条色
     （`CardHighlight.ColorOf/FrameColorOf` 是另一套）。
  2. 菜单档**不要乘 `RimAlphaScale`**（原版菜单路径 alpha 目标就是 1）——
     建议给 `ApplyRimColor` 加一个 `bool rawAlpha`，只有悬停这条传 true（别改常量，常量在战斗那条上仍成立）。
  3. 菜单档 `PlaceRim` 改成 **`localScale = (1.97, 1.36)`**（相对卡框），或按原版 4.4281/2.2452、4.4281/3.2572 现算。
  4. 菜单档材质参数切到 **`Card Frame SDF`** 那一档（四个值见 3·1 ⑦），并核对 `_SpriteAlphaEdge_Inner` = 0.043。
  5. ⚠️ 回归面：这条层是**战斗状态环共用的**。改完必须并排看「收藏页悬停」与「战斗手牌状态色」两侧。

## 六、没查清的（⛔ 不猜，写清还差什么）

1. **卡片点击音的原版 cue 名**：`CollectionCard.onClickSound` 指向 pid `604076303329428464`（fileID 6），
   该资产**不在已解包树里** —— 搜过 `bundle_audiocontrol_assets_all/`（只有 `AudioMixer*`）·
   `bundle_soundcollection_assets_all/` · 全库 `find -name "*604076303329428464*"` = **0**。
   要拿到得走 `d:/2/unity_run_ref` 运行时读，或查 `bundle_*` 里未导出的 `AudioCue` 类型。
2. **收藏页到底弹不弹数值/关键词 tooltip**：prefab 上四个 `EverguildTooltipTrigger` 的 `registerEvents = 0`，
   而启用位由 `Card2DController.ToggleTooltips` 控制，其**调用点全在** `BattleCardManager` / `CardScript` /
   `CardInBoosterPack` / `CardDisplayWindow` / `MulliganManager`（`grep -rl ToggleTooltips`）；
   收藏链路没有调用点 ⇒ **倾向「不弹」**。仍缺两块判据：① `registerEvents` 字段的消费者
   （`EverguildTooltipTrigger` 的 `Awake/OnEnable` 未在 `decomp_full` 里出产物）② `TextTooltipController.Toggle` 的默认值。
3. **`SelectedHighlight` punch 向量**：`DEC/CollectionCard__SelectedHighlight.c` 读静态表
   `DAT_1842da2a8 + 0xb8` 的 Vector3 再 `× 0.05`（`0x1834b2f94 = 0.05`，符号位由 `^ 0x80000000` 翻），
   源向量的实际值没解到 ⇒ 「≈±0.05 每轴」是**推的**，落地前建议先用 0.05 试并实拍对照。
4. **卡背悬停的属性 id**：`CollectionCosmetic` ctor 里 `Shader.PropertyToID(<字面量>)`（`+0x70`）的字符串
   没解到；我们的「就是 `_Outline`」是**按材质属性集合推的**（`Shell/CollectionWindow.cs:4465-4478` 已如实标注）。
   另：卡面那颗 `SetFrame` 的第二实参（highlight sprite）具体是哪张图，也还没有调用点据。
