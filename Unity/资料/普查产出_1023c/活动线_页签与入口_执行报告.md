## 一、判据查证结果（⛔ 全部现读，不是凭结构猜）

### 1·1 `SetupTabs` 到底做什么（`d:/2/tools/decomp_full/BaseParentEventWindow__SetupTabs.c`）

逐句：

1. `LiveOpsManager.GetAllEvents(2, <某个 targetId>)` —— **事件数据的来源 = liveops（远端）**。
   该方法的实参语义（`LiveOpsManager__GetAllEvents.c` + `LiveOpsManager.<>c__DisplayClass6_0.<GetAllEvents>b__0.c`）：
   `GetAllEvents(int p1, string p2)` = 对 `GetAllEvents(0,0)` 的全量结果 `Where(谓词)`，谓词比两样：
   `GetComponent(ev, 0xf)` 的 `field_0x10 == p1`、且它的 `TargetId == p2`。**`p1` 是什么枚举值没解**（见 §六）。
2. 再 `Where(谓词)`（缓存谓词 `b__4_0` / `b__4_1`）：方法体是 `FUN_1800021f0(4, …, ev)` / `(0x15, …, ev)`
   —— 一个泛型组件取用子的 tag **4** 与 **0x15(21)**。**tag 4 不在我们抄的那份
   `EventComponentReferenceType` 里**（我们只有 0/1/10/11/12/13/20/21/25/30/35）⇒ **这两个谓词的具体条件没解**（见 §六）。
3. 遍历事件，逐事件二选一：
   - **`HasComponent(ev, 13 /*TabButton*/)`** ⇒ `label = GetLabel(ev, 0)`（**label 0 = Title**）·
     `sprite = LoadAsset(ev, 0)`（`EventAssetReferenceType.Icon`）→
     `TabButtons.AddTabButton(label, sprite)` → `transform.SetAsLastSibling()` →
     `EverguildToggle.add_OnClick(<SetupTabs>b__2)`。
     **那个回调 = `WindowsManager.OpenWindow(GetComponentReference(ev, 12 /*Popup*/), ev)`**
     （`BaseParentEventWindow.__c__DisplayClass4_0___SetupTabs_b__2.c`）
     ⇒ **这一类页签点了是「开另一扇窗」，不是换页**。
   - **`HasComponent(ev, 11 /*Tab*/)`** ⇒ `BaseParentEventWindow__CreateEventTab(ev)`：
     `LoadComponent(ev, 11)` + `TryGetLabel(ev, 4 /*NavigationBarTitle*/)`，**取不到退回 `TryGetLabel(ev, 0)`** +
     `LoadAsset(ev, 0)` → `GameWindowWithTabs.CreateTab<…>(title, sprite, component)` =
     **本窗里的一个内容页**；随后给它的通知组件 `UiBadgeNotification.AddNotificationType`、
     给页面 `SetEventComponent`、并按 `是否可选中` 调 `TabButtons.ToggleInteractable(tab, …, false)`。
4. **一个事件都没有** ⇒ `GameWindowWithTabs.SetupTabs(0)`（基类那一支 = 左栏空）。
5. `TabButtons__AddTabButton.c` 逐句（点出来的那颗钮怎么造）：
   `Instantiate(tabButtonPrefab, tabHolder)` → `gameObject.SetActive(true)` → `SetSiblingIndex(0)` →
   **`set_name(label)`（节点名 = 页签文字）** → `Image.sprite = 图标` → `Toggle.group = group` →
   `GetComponentInChildren<文字组件>().SetText(label)`。返回那颗 `EverguildToggle`。

**⇒ 原版两种页签**：①「事件钮」= 左栏一颗、点了**开另一扇窗**；②「内容页」= 本窗里的一页。
**排序**：内容页按事件列表序建；事件钮 `SetSiblingIndex(0)` 之后又被 `SetAsLastSibling()` 提到最后。

### 1·2 原版这几个窗**从哪打开**（有入口，且已核到映射）

链路（全部方法体现读）：

1. `NavigationPanelController__BuildEventButtons.c`：左竖导航里**按 liveops 事件动态建「事件钮」**——
   每个事件 `Instantiate(eventButtonPrefab)` → `OpenEventButton.Initialize(ev)` → 挂进导航空的 `ToggleGroup`。
2. `OpenEventButton__SetButtonInfo.c`：图标 = `LoadAsset(ev,0)` · over-icon = `HasAsset(ev,9)` 时 `LoadAsset(ev,9)` ·
   **文字 = `TryGetLabel(ev,4)` 取不到才用 `TryGetLabel(ev,0)`** · `LiveOpsUtility.IsTimedEvent` 为真才显示计时。
3. `OpenEventButton__ButtonClick.c` → `OpenWindow` → `WindowsManager.OpenWindow(GetComponentReference(ev, **10**), ev)`
   （10 = `EventComponentReferenceType.MainWindow`）。
   那颗钮同时是 toggle：`OpenEventButton__ToggleValueChange.c` 里 `false` 那一支会把开出来的窗 `Close()`。
4. `BaseParentEventWindow__Open.c` 自己也会 `NavigationPanelController.GetToggle(5)` / `SetToggle(5)`
   （= 导航第 6 颗，`Event`），`ParentEventHandler__BeforeRefresh.c` 也在同一颗上兜（没事件时把它 `SetActive(false)`）。

🔴 **`ev → 哪扇窗` 的映射我核了**（`bundle_menus_assets_all/AssetBundle/AssetBundle_1.json` 的
`m_Container`（键 = GUID）→ `asset.m_PathID` → UnityPy 读 `m_Name`）：

| 事件的组件引用 | GUID | PathID | 真名 |
|---|---|---|---|
| Parent 事件 `MainWindow`(10) | `9a26697357770d8458298d89467fd459` | `-3290546486736551612` | **`Parent Event Window`** |
| Scoring 事件 `Tab`(11) | `e6914cbdd45814f5f9bd40a854c12218` | `-555883983194387681` | **`Expansion Pass Tab`** |
| Orks1 `TriggerPopup`(20) | `44c1eb3a347b840fd9e2e67ba85b7d02` | `-112613514281772147` | `Full Screen Event Announcement Variant` |

⇒ **原版有入口**（左竖导航那颗事件钮），**不是**「远端配置驱动到没有入口」。
⚠️ 但那颗钮的名单来自 liveops 事件列表；本机**没有那条链**（与三个活动窗文件头记的同一个缺口）。
