2. **显隐照原版那条门**：`SuperSampling.RowVisible` = 「当前画质档 == `PC`」∧（该档 `allowSuperSampling` = 我们取真）。
   `PC` 档 ≡ 原版「非移动」那档（**案 (a)**，调度台已裁）。`Mobile`(0) ⇒ 藏；`PC`(1) ⇒ 在。
   **节点照原版一直建、由 `SetActive` 决定在不在画面上**（= `ConfigureSuperSamplingVisibility.c:29` 那一句）；
   那一行藏起来时，**`Vsync` / `FPS Limit` 自己往上挪一格**（原版 VLG 跳过 inactive 子件）⇒ 格位号不是一个常数。
3. **生效时机照原版**：**点一下不生效**（只写 flag + 置脏），真正写 `renderScale` 的是
   ① **关窗**（`SettingsMenu.Close` 的脏位支）② **应用画质**（`ApplyGraphicsQuality` 那一跳）③ **启动那一次**。
4. **「场景切换」那个时机我们工程里没有对应物**（如实报告）：全仓没有「场景切换结束」事件，
   `LoadScene` 散在 4 处业务代码里。⇒ 用**最近的等价物**补了启动那一跳，并在类注释里写明
   **「这是我们挑的等价时机，原版是 `SceneChanged()`」**。
5. 自检补了 **8 条两态断言**（显隐两态 + `renderScale` 1.0→2.0→1.0 + 「点了不立刻生效」+ 「档不允许 ⇒ 开关被强制清 0」），
   期望值全是**原版字面量 1.0 / 2.0**（⛔ 不从被测实现里读 `SuperSampling.RenderScaleOff/On`）。
   **⚠️ 我没跑 Unity ⇒ 这些断言还没被实跑过**（见 §六）。
