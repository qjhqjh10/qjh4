## A1369 — 判：**(β) 真缺陷待做**（形态确认；**今天 0 张可触发**）

### ① 原版收费边界在哪一层（第一权威 = 反编译 + 签名桩）
- `ActiveAbility.cs`（**桩，第一手**）= `{ int manaCost; …; List<AbilityLogic> activeAbilityLogic; }`
  ⇒ **一个 cost + 一串 logic** = **一次 ability 收一次**。
- `BattleManager__PayActiveAbilityCostOath.c`：一次激活**只调一次** `PlayerManager__UseMana`；
  `BattleManager__CanUseActiveAbility.c`：余额也是**整条 ability 判一次**（`PlayerManager__HasEnoughMana`）。
- 🔴 **「重复」在原版不是重跑 ability，而是 `AbilityLogic` 上的乘数**：
  `AbilityLogic.cs` = `TargetCriteria multiplier`（Tooltip：*"If different from 'Any',
  multiply by number of targets meeting criteria"*）+ `int furtherMultiplier`
  ⇒ `for each` = **在一个 logic 内把数值乘 N**，**不回到收费那一层**。
- ⇒ 收费边界 = **ability 层**；`for each` / `, plus` / `instead` **全在它下面**，都不该另收。

### ② 三个洞的可达性（现读全池 1126 张）

|---|---|---|---|
| 1 `for each` 重复付费 | 付费前缀句内含 `for each`/`for every`/`N times` | **0 张** | 不可达 |
| 2 `, plus` 前半句白给 | 付费前缀 + `, plus` | **0 张** | 不可达 |
| 3 `instead` 跳过付钱那条 | 付费前缀句内 `instead`，且**付钱那条被跳** | 2 句，**都不成组** | 不可达 |

  ⇒ 形状与付费前缀今天**不同框**。

  ⇒ 前半句 0 价，与注释「白给」一致。
