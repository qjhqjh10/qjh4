## 三、T19 护栏重钉（为什么换成 ASH15，为什么它仍有判别力）

**旧护栏为什么失效（现读数据，非推测）**：
- `D5` 把 `VO_BlackLegion_Hexscorn_vs_Varro.ogg` 从 `UM48` 名下摘走（归回 `BL36`）⇒ `UM48` 的 `deploy` 桶**空了**。
- 现读 `Resources/voice_lines.json`：「有 `deploy` 行但卡 SO 无 `summonAudio`」的 6 张 =
  **`AM66` / `ASH15` / `ASH3` / `BL35` / `BL36` / `SAU36`**；
  旧名单里的 `UM48` / `BL34` **已经一条 deploy 行都没有** ⇒ 删掉护栏也**无行可捞**，两条路都静默 ⇒ 旧 mutation 绿得没意义。

**换成 `ASH15`（Howling Banshee，SaimHann）**：
- 仍有一条 deploy 兜底行 `VO_CW_SaimHann_Howling Banshee - Shriek.ogg`（**盘上真有**，台词 `Shriek`）；
- 卡 SO 的 `audio` 只有 `attack` / `death`，**没有 `deploy`** ⇒ `TryPickExact` 落空，真正走到护栏那一支。

**为什么要把它摆到棋盘上（关键）**：
`SpeakFor` 先看 `board[e.Slot]`，再退回 `CardDatabase.Find(_pool, 卡名, **本局阵营**)` 解析。
`ASH15` 属 SaimHann，本局是 Ultramarines vs Goff ⇒ 按名字**解析不到**（会像旧版 `AM66` 那样「因为错的原因」变绿）。
夹具改成 `Board[probeSlot] = new UnitState(def, false)`（`FreeSlot` 取合法空格，避开督军格）⇒ 走「卡本体」那条路，**与阵营无关**，也不重开一局/不改局面；`finally` 立刻置回 `null`。

**判别力**：
- 保留护栏 ⇒ `if (e.Kind == EvtKind.Deploy && clip == null) return;` ⇒ 静默，`ShownSide == -1`。
- 删掉护栏 ⇒ 后缀兜底从 `deploy` 桶捞到 `Shriek`（盘上有）⇒ `Speak` 弹气泡 ⇒ `ShownSide != -1` ⇒ **本条红**。
- ⚠️ 兜底那条之前先 `chat.HideAll(); chat.StopVoice();`（`AnyShown` 必须为假，否则 `onlyIfQuiet` 会挡掉气泡 ⇒ 假绿）。

数据级名单同步改成 `{ "AM66", "ASH15", "ASH3", "BL35", "BL36", "SAU36" }`（判据同一条：`TryPickExact(…, deploy)` 必须落空）；
文案里加了 2026-10-24 的就地订正痕（旧名单为什么过期）。
