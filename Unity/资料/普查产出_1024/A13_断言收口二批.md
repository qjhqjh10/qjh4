## 四、`DeckScene` 翻面说明（为什么翻、判据在哪）

**旧断言**（`:7642-7649` 原文）：
```csharp
int popId502 = pop502.GetInstanceID();
_rt.TryClose();                                    // 窗还开着 + 仍脏 ⇒ 再弹一次
Check(_rt.ModalPopup != null ? _rt.ModalPopup.GetInstanceID() : 0, popId502,
      "★ 还开着时再弹 ⇒ **复用同一扇实例**（每次都新建 ⇒ 这条红）");
```
它把**我们旧的（非原版）行为**钉死了 —— `WindowsManager.ShowMessagePopUp` 当年是「还开着就复用 + `Configure`」。

**判据（第一权威 = 反编译方法体，`A11` 亲读）**：
`d:/2/tools/decomp_full/WindowsManager._LoadPopup_d__55__MoveNext.c:20-45`
```c
if (popUpWindow != 0) {                       // *(this+0x60)
    CloseWindow(this, popUpWindow, false);    // ① 先关
    Object.Destroy(popUpWindow.gameObject);   // ② 再销毁
}
prefab = (*(param_1 + 0x28) == 0) ? <1 按钮版> : <2 按钮版>;   // ③ 按**按钮数**挑
popUpWindow = Object.Instantiate(prefab, …);  // ④ 每次新建
```
配 `_LoadPopUpAndShow_d__59__MoveNext.c` 的 `bVar4 = 1 < buttons.Count`。
⇒ **原版每次都销毁 + 重建**；字段 `popUpWindow` 只是「旧的还在不在 ⇒ 先关掉销毁」的判据，**不是复用**。
`A11` 已把 `WindowsManager.ShowMessagePopUp` 改成同形 ⇒ 正确期望 = **`!= popId502`（新的一扇）**。

**改后**（`:7649-7670`）：
```csharp
int popId502 = pop502.GetInstanceID();
_rt.TryClose();
var pop502b = _rt.ModalPopup;
CheckTrue(pop502b != null, "★ 还开着时再弹 ⇒ 窗还在（先断非空，否则 null 会让下面那条假绿）");
if (pop502b != null) CheckTrue(pop502b.GetInstanceID() != popId502, "★ 新的一扇实例 …");
if (pop502b != null) CheckTrue(pop502 == null, "★ 旧的那一扇已被销毁（原版那句 Object.Destroy）");
…
ClickPopupButton(pop502b, "ButtonRight");   // ⚠️ 必须改用**新的**那扇（旧的已销毁 ⇒ FindDeep 找不到钮）
```
🔴 **两个坑，别人改同类断言时别踩**：
1. `DeckScene` 的 `Check<T>(got, want, msg)` 是**相等**断言（`MenuCheck.Check`）——
   直接把期望「换个方向」写回去（`Check(newId, popId502, …)`）会**仍然断相等** ⇒ 假绿。
   必须用 `CheckTrue(a != b, …)`。
2. `pop502` 在批处理下走 `DestroyImmediate` ⇒ **当场为 null**；后面任何 `ClickPopupButton(pop502, …)`
   都会 `FindDeep(null)` 找不到钮 ⇒ 连带红。⇒ 收尾那一跳必须改成 `pop502b`。

**条数变化**：这一条从 1 条 `Check` 变成 3 条（非空 / 新实例 / 旧已销毁）⇒ `DeckScene` 的断言合计
**1801 → 1803（+2）**。同步点别把 1803 当成回归（判绿红只认 `✗` = 0）。

**同文件 `:6930-6944`**（那条「还是同一扇实例」）：**平凡真、仍绿**（④ 的 ESC 之后根本没有第二次
`ShowMessagePopUp`），只把标题与注释里「原版是重配 + 重开同一实例」订正成「原版销毁重建」，
并把断言文本改成诚实的「（⚠️ 平凡真：…）」。

## 七、顺手发现（⛔ 只报不改）

1. 🔴 **`Check<T>(got, want, msg)` 在 `DeckScene`/`ShellScene`/`CollectionScene`/`MainMenuScene`/… 是【相等】断言**
   （`MenuCheck.Check`）。本批翻面时差点直接「把两个实参对调」——那样**仍然断相等**、永远绿。
   ⇒ 以后凡是要断「**不一样**」（新实例 / 换了对象），必须 `CheckTrue(a != b, …)`。这条建议写进
   `资料/工作准则_操作经验.md`（本代理不动它）。
2. ℹ️ **`VfxMap.ResolveCardIdOf` 只在「同名多 id」时才用阵营消歧**（`ids.Count == 1 ⇒ 直接 return`）。
   ⇒ 自检夹具想按**卡名**走逐卡特效时，要么用**表里唯一**的卡名（本批 `Arjac Rockfist` / `Techmarine` / `Dark Talon`
