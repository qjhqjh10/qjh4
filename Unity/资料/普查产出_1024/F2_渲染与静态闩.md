## 一、逐条结论

### 1 · P1-4 · `GrabPassTransparentFeature.cs` 两个 `NativeArray` 从不 Dispose —— ✅ 已修

**现状确认（改前）**：`GrabRedrawPass.RecordRenderGraph` 里
`tagValues = new NativeArray<ShaderTagId>(…, Allocator.Temp)` /
`stateBlocks = new NativeArray<RenderStateBlock>(…, Allocator.Temp)`，**从头到尾没有 `Dispose()`**。
只在 `layerMask != 0`（= 开关 `WF_GRAB_501` 且层配好）时执行 ⇒ 打开后**每帧 2 个**未释放的 NativeArray。

**🔴 R1 建议的那一版（「`CreateRendererList` 之后立刻 Dispose」）会引入 use-after-free，没照做。**
逐条实读 URP/Core 包源码（判据可复查）：

| 事实 | 出处 |
|---|---|
| `graph.CreateRendererList(param)` → `m_Resources.CreateRendererList(desc)` | `com.unity.render-pipelines.core…/Runtime/RenderGraph/RenderGraph.cs:1058-1063` |
| 那里**只是把 `RendererListParams` 按值存进资源表**（`RendererListResource(desc)`），**没有**读数组 | `…/RenderGraph/RenderGraphResourceRegistry.cs:863-867` |
| `RendererListResource` 把 `desc` 原样存着（NativeArray = 指针别名） | `…/RenderGraph/RenderGraphResourceRendererList.cs:50-59` |
| 真正的 `context.CreateRendererList(ref desc)` 在**之后的** `CompileRenderGraph → CreateRendererLists()` 里才跑 | `…/RenderGraph/RenderGraph.cs:2489` · `…/RenderGraphResourceRegistry.cs:1208-1223` |

⇒ 数组必须活到**执行期**。提前 Dispose = 那一步 `GetUnsafeReadOnlyPtr()` 读已释放内存
（editor 里被 safety check 直接抛、player 里读垃圾内存 ⇒ 501 的重画画错/崩）。

**✅ 实际改法**：**一对常驻数组**（`Allocator.Persistent`、长度恒 1），**懒建一次、每帧只改值**，
由 `ScriptableRendererFeature.Dispose(bool)` 释放；`Create()` 重入时先释放上一份（防脚本重载/渲染器重建漏一份）。

- `GrabPassTransparentFeature.cs:271-290`：`BuildLists()` / `DisposeLists()`（幂等，`IsCreated` 守卫）
- `:319-326`：`BuildLists(); _tagValues[0] = ShaderTagId.none; _stateBlocks[0] = _stateBlock;` ⇒ `param` 用常驻数组
- `:109`／`:116-122`：`Create()` 重入释放 + `Dispose(bool)` 释放
  （`ScriptableRenderer.Dispose()` 会逐个 Dispose feature —— `…/universal/Runtime/ScriptableRenderer.cs:779-791`，钩子确实存在）
- 文件尾新增 **§④ 验收**（怎么开、看什么、反面验收）

**为什么不是 `using` / `try/finally`**：`using` 只能在同一同步作用域内 Dispose，
而这份参数的生命周期**跨到 RenderGraph 执行期**（上面那张表），作用域内 Dispose 就是 use-after-free；
也**不能**「用 `Allocator.Temp` 留到下一帧再 Dispose」—— `Allocator.Temp` 的语义是**帧末自动回收**，
跨帧 Dispose 是重复释放。所以唯一安全解 = `Persistent` + 显式释放（`Dispose(bool)`）。

**⚠️ 默认关的路径行为一个字没变**（论证）：
`RecordRenderGraph` 第一行就是 `if (layerMask == 0) return;`（`:300`）⇒ `BuildLists()` **不会被调用** ⇒
**零分配、零新代码执行**；`AddRenderPasses` 的 500 那一半与 `GrabPassPass` 类**一个字节没动**。

**补断言**：该文件**没有自检宿主** ⇒ 给的是「怎么验证」，见 §四 ①。
