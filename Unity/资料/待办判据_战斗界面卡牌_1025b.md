## 解码法（本轮新打通，可复用）

IL2CPP **字符串字面量 metadata-usage** 的本地解码链（不需要跑游戏）：

1. 反编译里 `FUN_1803f44f0(&DAT_xxxxxxxx)` → 该 `DAT_` 在 `.data` 的 4/8 字节值 = `encoded`；
2. `usageType = encoded >> 29`（**5 = StringLiteral**）、`index = (encoded & 0x1FFFFFFF) >> 1`（低 bit 恒 1，是标记位）；
3. `global-metadata.dat`：字面量表在 **offset 256**（条目 8B = `{int32 length; int32 dataIndex}`），数据区在 **offset 212368**；第 `index` 条即该字面量。
对照验证 4 条：`0xA0002489→4676 = "Battle/HUD/YourTurn"`（官方词条里确有该键）· `0xA00065DD→13038 = "PrebuiltDecks/"` · `0xA0005837→11291 = "MenuDeck/DeckName/"` · `0xA000CB6D→26038 = "{0} {1} %R{2}"`（`AlternateArtCard.DisplayName` 的 format，见 `AlternateArtCard__get_DisplayName.c:33`）。

## 顺手发现（只报不改）

1. **`PrebuiltDeck.LocalizedName` 用的键族在本机官方表里不存在**：它拼的是 `"MenuDeck/DeckName/" + deckId`（槽 `0x1842cf0f0` → 11291）。而官方本地化表里实际有名字的是 **`PrebuiltDecks/*`**，由 `DeckDrawer.GetItemName.c:23` 与 `DemoDeckInfoSO.GetName.c:20`（槽 `0x184292c50` → 13038）使用。⇒ 我们 2026-10-23 改用 `PrebuiltDecks/` 是对的（`LocalizedName` 那条路取不到键，会回落原文）。
2. **`ChatPanel` 的聊天头像可能是整块 2×**：prefab `Profile border` = 146.03×163.14 但 **`m_LocalScale=(0.5,0.5,1)`**（世界 73.02×81.57），子件 `Profile content` 255.18×257.20 @1.0（世界 127.59×128.60）。我们 `Shell/ChatPanel.cs:555-556` 按 146.03×163.14 画 border、按 255.18 画 content ⇒ 两者都是世界的 2×（比例对、绝对尺寸大 2 倍）。未确认聊天窗根是否有 2× 全局缩放 ⇒ **待核**，⛔ 不要直接改。
3. **`Avatar Item Small` 的 `Image` 出厂是关的**（`m_Sprite=0` + `m_Enabled=0`，7 个实例全部）⇒ 原版立绘完全靠运行期灌图并开层；任何「拿 prefab 里没有图」推断「原版不画」的说法都要再核一次。
4. **EventSystem 只有 Intro 一份、且挂在常驻管理器下** ⇒ 其它场景不做 EventSystem 也能吃到输入；`m_DragThreshold=5` 是全局值（见 #4）。
