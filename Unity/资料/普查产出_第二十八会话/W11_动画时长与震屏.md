## #10 震屏幅度 + Perlin 波形

**① 幅度（原版做法）**：preset 真件 `Shake Hit Small`（`解包整理/09_游戏数据/动画曲线/MonoBehaviour/Shake Hit Small_4555857231027011253.json`）
= `amplitude 2.0` · `direction (0,0.2,0.2)`，运行时被 `CardScript__ResolveAttackAnimationEffects.c:32-52` 按 `GetUnitSize` **覆盖成 2.0/4.0/8.0**。
🔴 **就地订正（铁律 5）**：`CardFeel` 原写「我们只用到第 1 档 —— 我们的单位不占多格，尺寸 2/3 接不上」**是错的**：
`GetUnitSize`（`SupportMethods__GetUnitSize.c:11-16`）判的是**单位当前近战攻击**（≤3→0 / ≤7→2 / 其余→3），我们本地**早就有**（`UnitSizeOf`，挨打后坐一直在用）。
⇒ 新增 `ShakeAmplitudeForUnitSize` / `ShakeWorldAmplitudeFor(size)`（**由真件字段现算，不再是写死的 0.04**）+ `ShakeCameraForHit(...)`；
`ShakeWorldAmplitude`(0.04) 保留 = 尺寸 0/1 档别名；拆出 `ShakePresetAmplitude`/`ShakePresetDirMag`/`ShakeVerticalFrac`/`ShakeOriginalPxPerUnit`（**全登记进 `Catalog`**，`Unclassified()` 仍空）。

**② 波形（原版做法）**：`Warpforge 6D Shake`（`Cinemachine.NoiseSettings`）= **程序化噪声**（无采样点数组）；
场景 `CinemachineImpulseSource.m_ImpulseDefinition`（battlearena1 `MB_4914.json`）：`m_ImpulseType=3`(**Legacy**) ·
`m_RawSignal`=该噪声 · `m_RepeatMode=0` · `m_ImpulseDuration=1.0` · `m_AmplitudeGain=0.1` · `m_FrequencyGain=0.05` ·
**`m_Randomize=1`**；而它的语义写在**本地签名桩自己的 Tooltip**（`Warpforge_code/Scripts/Cinemachine/Cinemachine/
CinemachineImpulseDefinition.cs`）：**「Legacy mode only: Randomize the signal start time」**
⇒ 随机的**不是方向/幅度，是「从噪声的哪一刻开始播」**。⇒ `ShakeNoise01(t, phase)` 改成
**Perlin 三条带 + 每次随机的起播时刻**；`ShakePhaseOffset(seed)` 由 `System.Random` 派生；`ShakeCamera` 加可选 `phaseSeed`。

**可复现性**：种子**全部**来自 `System.Random`（**一处都没用 `UnityEngine.Random`**）；序号是进程内单调计数 ⇒
**同一串事件流（同一局重放两次）必然给同一串种子** ⇒ 逐帧位移逐位相同；`ShakeSeedBase` 可写（默认固定常量），
要「两局也不同」就在开局设它 —— ⚠️ **那一句还没接**（`BattleDriver` 不在白名单；且 `BattleContext`
**没有暴露对局种子**）⇒ **今天：同一局可复现 ✅，两局之间第一下相位相同**（如实标注，不是「原版那样」）。

**断言**：档位判据 / 三档取值 / 旧常量==尺寸 0/1 档 / 比例 2×·4× / `ShakePhaseOffset` 纯函数 / 换种子必变 /
**灭自证①** 同种子下「近战 2」与「近战 8」位移之比 = **4.0**（写死第 1 档 ⇒ 恒 1 ⇒ 红）/
**灭自证②** 同一 `t` 两个相位噪声不同（忽略 `phase` 的实现 ⇒ 红）/
**灭自证③** `t=0` **不再恒等于峰值**（32 种子 ≥24 个 ≠1 —— 换回 cos 叠加必红）/ 噪声有起伏且不越界。
另**改掉两条旧断言**（`full == ShakeWorldAmplitude` 那一帧满幅、`t=0.18 落到谷底`）—— 两条都是**正弦近似才成立**的性质。
