## A1884 `FireEvent` 多点

### 改了什么

- `Core/CardEffects.cs`：新增 **`Fire(string, Vector3[], Transform)`**（`:37`）与 **`FireEvent(string, Vector3[], …)`**（`:66`），语义 = **给 N 个点就在 N 个点各调一次 `Play`**
  （顺序 = 数组顺序）；`null`/空数组 ⇒ **出声 + 一个都不播**。两个**单点**版（`:21`/`:59`）**转发**给数组版 ⇒ 落点规则只留一处。
- `Battle/BattleDriver.cs`：`PlaySignals`（`:10774-10822`）把这一批（同一 drain）里**每一方抽到的 N 张落点一次算齐**（`Vector3[][] drawPoints`，
  `points[k] = HandRow01(mine, n - k)`，k 从 0 = 最先抽到的那张），连同 `drawIndex` 写进 `PendingSignal`（`:10828` 新增 `points`/`pointIndex`）；
  `PlaySignal`（`:11009`）新增两参，HUD 那一族（`:11084`）**从批数组取自己那一个点**、走多落点重载，批里没有它（资源图标那三件）⇒ 退回原来的单点。
- 🔴 **第二条出口也补上了**：`StepReplaySignal()`（`:4143`，回放条「单步」）的调用点（`:4154`）原来只传 `drawFromEnd`
  ⇒ 只补 `AdvanceTimeline` 的话单步那条路走的还是老的单点路（铁律 10 第 5 条）。现在两处实参**一样**。

### 「改前 → 改后」落点表

场景 = 我方手牌 3 张，同一个 drain 连抽 2 张（A 先、B 后）⇒ 抽完 `count = 5`。
