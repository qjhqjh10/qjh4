> 🔴 **先纠一条前提（本普查最大的结论）**：`T05 §2·3` 记的「三个名字在库里没有 ⇒ 是效果库
> `EffectLibraryBuilder` 生成时漏了」，**后半句不成立**。

## 一、这个「库」是什么（文件路径 + 生成方 + 名字来源 + 查库入口的行号）

**库资产（生成物、进不了 git）**
- `d:/4/Unity/MyGame/Assets/Resources/WarpforgeVFX/WarpforgeEffectLibrary.asset`
  —— `ScriptableObject`，**968 条** `WFEffectEntry`（现读；`generated` 字段 = `2026-10-15 20:15 … 共 968 个`）。

  懒建索引 `_map`（`Rebuild()` `:97`）。`TryGet(name,out)` `:119` 是**唯一的按键取库口**。

**查库/报错入口（判据只此一处）**

  `Play(string effectName, …)` → `lib.TryGet` 失败 → **`:145`** `Debug.LogWarning($"[WarpforgeVFX] 效果库里没有 '{effectName}'")`。
  ⇒ **T05 那句日志就是这一行**（另有同族：`VFXWhiteboard.cs:126` 白板版、`WarpforgeEffectHook.cs:27` 的
  「特效没播出来」——`hook` 只是把 `CardEffects.Play` 接到 `WarpforgeEffectPlayer.Play` 上，**同一道门**）。

**生成链（谁生成、名字从哪来）**

  `:1211`「**已换成子集库（12 个效果）**」。我按过滤器重算 963 → 恰好 **17 条**（`AmbushEffect` / `Antimatter Explosion` /
  `ArmourEffect_Bladeguard_Shield` / `Atk_GrotGrenade(+_big)` / `Attack_Stomp` / `Buff_DaemonicPact_troop` /
  `CardPrefab` / `Card_Buff_Hand(+_Ork,+_SW)` / `Explosion Hive Fleet Arrival Tendrils(+ OLD)` / `Explosion_Ground(+Break)` /
  `Lightning_Green` / `StunEffect_proc`）⇒ **22 = 17 + 5 逐条对上**。
- 白名单：`…/Editor/WhiteboardBuilder.cs:28-41` 的 `Effects`（12 条，`:26-27` 注释明写「不要再抄第二份」）。
- **本仓早就写明了这是预期的**：`…/Core/PlayerBoot.cs:264-270`——
  「Battle 那一局是 AI 代打，它走 VfxMap 挑的效果多半**不在子集效果库**里（日志会明写「效果库里没有 `Tap Blue Glow`」）」。

   `bundle_battleprefabs_vfxandmisc_assets_all`）。
