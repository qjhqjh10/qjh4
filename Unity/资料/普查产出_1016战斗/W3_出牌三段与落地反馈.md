## 二、判据缺口那一问的答案（题面 §五）：`onDone` 该挂在哪 —— **末尾（0.55 s）**

**读过的文件**：`BattleManager._ResolvePlayCardFromHand_d__447__MoveNext.c`（全篇）· `CardScript._MinionPlayedIntoField_d__314__MoveNext.c` · `CardScript__MinionPlayedIntoField.c`（ctor：参数极性）· `CardScript__UpdateMinionInPlayPosition.c` · `MinionManager__PlayMinionFromHand.c` · `MinionManager__MoveMinionToConversionPoint.c` · `CardScript__LandOnGround.c` · `d:/2/tools/il2cpp_out/dump.cs`（字段名）。

**原版是「边演边出」，但『卡的效果结算』在落地之后**（逐句）：

1. state 1/2（`PlayPlayerCard`/`PlayEnemyCard` 协程跑完）→ `PlayerHand.RemoveCardFromHand` + `BattleManager.PayCardCost`（`:355-379`）
2. → `MinionManager.PlayMinionFromHand`（起飞补间）**接着** `WaitForSeconds(GetMinionConversionTime(card))` → `state 6`（`:409-421`）
3. state 6 → `CardScript.MinionPlayedIntoField(…, 1, …)` 起协程 → `state 7`（`:892-899`，**yield 整条**）
4. state 5/7 之后才走到 `LAB_1809bd825`：`CardScript.ResolveCardPlayed` → `CommunicateBattleAction` → `BattleHud.SetTurnPlayedCards` → `PlayerHand.CardPlayedWithEffects` → `CemeteryManager.AddPlayCardAction` → `FinishResolvingAction`（`:1057-1132`）

⇒ **我们的 `onDone` = `RuleCore.PlayCard`（付费 + 落位 + 效果 + 广播，一次全做）对应的是第 4 步那一半 ⇒ 该在演出之后。**
**第二条独立理由**（不依赖对方法的解读）：`DoPlay` 会 `SetParent(boardRoot)` + `SetFace(CardFace.Board)` + `RefreshAll/SyncBoard` 把卡摆到 `ArenaSlots.RootPosition` —— **它把视图抢走**；若 `onDone` 仍在 0.3 s，落下那 0.2 s 就没有对象可演了（视图已被搬进 3D）。

**代价（如实记）**：我们的引擎事件只有一条 `Deploy` ⇒ 登场那两件（`Invoke Minion Card Fade Default` 淡入 + 阵营召唤法阵）也跟着挪到了落地那一拍（原版是**飞行开始**那一拍）。要分开得把「离手/付费」那一刻也变成一条事件，**本件不做**。
**顺带**：落地**音**（`BattleSfx.LandOnGround`，跟 `Deploy` 走）因此正好落在落定那一刻 ✓ 与原版同一拍。

## 三、没做的事 + 为什么

1. **原版 state 0 那段 `WaitForSeconds(timeToScaleIntoMoving = 0.1)` 没做**（`VarsGlobal` 字段，值见 `资料/VarsGlobal_原版数值.md:43`）。它覆盖的是 state 1 的 `SetUnitInPlayLayer`（「卡片换成 3D 体」那一拍）；我们的整套交接挂在序列**末尾**（§二），照抄只会得到 0.1 s **什么都不发生**的死等 ⇒ 宁可少一段，不硬凑。
2. 🔴 **落尘的「缩放」没做到原版那一档**：原版 `SetParent(MinionManager)` 之后 `localScale = Vector3.one × desiredScale`（**0.36 / 0.69**，`CardScript__LandOnGround.c:87-106`）。我们的 `CardEffects.Fire` **钩子没有 scale 参数**（`WarpforgeVFX/Runtime/WarpforgeEffectHook.cs` 硬编码 `1f`，那个文件**不在本件白名单**）⇒ 现在按 prefab 自带尺度播，**多半比原版大**。要照原版得给钩子加一档 scale（跨 `WarpforgeEffectHook` + `CardEffects` 两处）。**如实出声、不许静默** —— 这条也写进了 `LandDustFieldFor` 的注释。
3. **`landOnGroundParticlesLocalOffset` 的 0.015 没做量纲换算**（原版是**竞技场单位**）⇒ 直接加在 HUD 平面上（≈1.6 px）。与第 2 条是同一个缺口（落尘那件整体没按原版尺度换算）。
4. **旋转/缩放跨度**仍是 `MoveTime`（0.3）。原版**缩放是瞬时的**（`MoveMinionToConversionPoint.c:74-83` 在起飞**之前**就把 `localScale` 设成 `GetUnitSizeInPlay`）—— 我们保留「0.3 s 收到落位尺寸」的观感，⛔ 本件不动它（题面只要求三段结构）。
5. **中段「拍」的分工没拆**：原版在**下落开始那一刻**（state 1）就把卡从 `2DCard` 换成 3D 体（`SetUnitInPlayLayer` + `DefaultScale`）；我们的交接（`DoPlay`）在序列末尾 ⇒ 落下那 0.2 s 用的是**2D 手牌卡面**。要照原版得把交接拆成「中途一次 + 末尾一次」，会动 `DoPlay` 的分工 ⇒ 本件不做（已在 §二/§三·1 写明）。
6. **抽牌绕 Y 翻转 · 进墓地 `GoToCemetery`** —— 题面明确划给下一轮，本件一个字没动。
7. `CardFeel.ReturnToHand`（回手，题面 §四·4 要求同步核）**不需要改**：它的时间轴取自 `Card Hand To Board` 那条 clip 的常量（`HandToBoardEnd 0.9167` 等）与 `_TransformUnitInPlayToCard` 的两个 `_DAT_`（0.208 / 3.0），**与 `DeploySequence` 的常量没有任何引用关系**（grep 确认）⇒ 正向改时长不影响它。
