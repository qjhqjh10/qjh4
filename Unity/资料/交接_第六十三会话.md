## 四、坑 / 承重结论（本会话新增，新会话必读）

1. 🔴 **换牌倾斜的根因是手牌重排补间的旋转尾巴**：`Begin → SyncHand → Relayout → HandLayout.Place`（`animateRelayout=1`）
   起 0.2 s 含旋转的 `CardTween.ToPose`；`MulliganPanel.BuildCardButtons` 的 `SetPose(...,0f,...)` 没 `DOKill`；
   deal 翻面只占 0.15 s ⇒ 手牌旋转最后落盘。修法 = `DOKill` + 换牌期 `relayout:false`（临时关 `animateRelayout`，
   **不能直接 return**，否则 `_lastPose`/`_saved*` 丢 ⇒ 点完成时手牌从屏幕中间飞下）+ deal `OnComplete` 补平。
2. 🔴 **可打出绿光半径 1.35 是 Gamma/Linear 补偿，不是原版参数**：原版 Gamma 下 SDF 带子 0.84–0.99 卡半宽；
   我们 Linear 被 sRGB 解码 ⇒ 0.69–0.83。修法 = `card_sdf/*.meta` 107 张 `sRGBTexture:0` + `OutlineGlowScale=1.0`。
   ⚠️ 同族 104 张 SDF 还喂**卡面软阴影**、`Card_board_frame_SDF` 喂**场上状态环** ⇒ 三者一起外移（同一根因）。
   ⚠️ `ArtBaker.ApplyImportSettings` 原来无条件写 Clamp ⇒ 已加 **Repeat 白名单**（7 张）。
3. 🔴 **底座绿光「到一半就没了」= 原版几何**：环半径 0.243 < 卡体半宽 0.333 ⇒ 整圈在卡后、只有前半圈可见；
   亮弧靠 `Halo UV scroll` 的 UV 滚动（速度属性 `Vector4_62056e41…=(1,1,0.63,0)` + 贴图 **Repeat**）。
   ⚠️ 探针 `n=0` 是**激活那一帧**还没吐粒子，后续截图证明在跑。
4. 🔴 **打出的兵绿光整回合不亮 = 请求被丢**：形态要到登场 clip **0.7 s** 才切 Board，`SetCanAct` 在非 Board 时
   直接 return 且不记请求；`SyncBoard` 非逐帧 ⇒ 出牌后 1 s 内几次回刷全丢。修法 = `_canActWanted` + `ApplyCanAct()`
   + `SetFace` 末尾重放；另加结构兜底（`Face != Board && v != _handToBoardCard ⇒ EnterBoardBody`）。
5. 🔴 **滚轮量纲 = ±1，不是 ±120**：真机 `[SCROLLPROBE] raw=1.0000`；原 `/120` 让缩放慢 **120 倍**。
   `TouchInputManager` / `MenuScroll` / `DeckRuntime` 同源同错，已改 1；`NotchPx==120f` 是**另一个量**（px/格），别动。
6. 🔴 **大图详情的「点后面的卡」**：原版能点的是**扇形里的相关卡**（`UI Collider` 逐卡），点手牌（模态背景后）关窗是原版行为。
7. 🔴 **血痕偏移**：`PopOffset.y` 原 0.590（卡身高 80%）→ 正确 **0.234**（`(1.708 − Height/2 − BodyMidOffset) × CardLocalToOurs`）。
8. 🔴 **VFX 语义分桶**：原版**没有通用近战件**（删除 `BulletImpactBurst_crowd`）；远程兜底 = `BulletImpact_2shot_trail`；
   非攻击来源的 `Hit` 不生成粒子；**反击演出完全没有**（新账）。
9. 🔴 **`abilityContext` 计数**：池内原始非 0 = **173 条 / 157 张**，合并 3 条同 `(trigger,context)` 重复行后 = **170 条**；
   简报原来的 159/148 是错的（已就地订正）。只落非 0 ⇒ `-1` = 未知、`0` = Play 由默认表达；
   11 张 `{0,50}` 战术卡保留 `ctx=50`（trigger 0 在 skip 表，消费端不读）。
10. 🔴 **`useOverDraw` 语义已闭合**：`RawCardScript+0x58`，`CardOverdrawHandle` 里 `(useOverDraw==0)||idx!=0 ⇒ Small`；
    `CardDatabase` 必须用 **v9 守卫**，否则整列缺时 JsonUtility 给 0 ⇒ **全池静默不溢出**。
11. 🔴 **`ArtBaker.ApplyImportSettings` 会把 `Resources/Art` 下所有贴图强制 Clamp** —— Repeat 修复必须进白名单，否则下次烘焙静默回滚。
12. ⚠️ **两个自检宿主会重写场景**：`CardBaseDemo.Run` 重写 `CardBase.unity`、`DeckScene.Run` 重写 `DeckEditor.unity`
    （本会话提交前已回滚）。`BattleScene.BuildAndSaveScene` 重写 `Battle.unity` 是**有意**的。
13. ⚠️ **`RuleEngineTest` 里 `Slay 就地结算` 是判断，不是已坐实的原版事实**（Slay 与 Backlash 同道 priority=1，按字面 FIFO
    原版可能排在下一个死者之后）⇒ 另立复核账。
14. ✅ **「召唤病」是误判，已销账**：ASH15（Howling Banshee）带 **`Flank`**，原版
    `displaySummonSickness = +0x58 && !fast && !flank` ⇒ 本来就该能打。复测请换一张不带 fast/flank 的兵。
