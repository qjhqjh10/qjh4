## ③ `Attack → Hit` 的时长（整场节奏）

**结论（可直接填）**
- **近战：起手（前冲开始）→ 命中（受击特效 + 震屏）= `0.10 s`**；**命中 → 扣血判定 = `0.30 s`** ⇒ **Attack → 扣血 = `0.40 s`**。
