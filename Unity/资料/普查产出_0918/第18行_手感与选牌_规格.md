## 一、`SupportMethods.GetUnitSize` / `GetPushBackFactor` —— 挨打后坐的幅度

```csharp

int GetUnitSize(EntityScript e) { int m = e.CurrentMeleeAttack;
    return m <= 3 ? 0 : (m <= 7 ? 2 : 3); }   // 只有 0/2/3 三档，**永不返回 1**
// D/SupportMethods__GetPushBackFactor.c:5-11
float GetPushBackFactor(int size) => size == 2 ? 1.0f : size == 3 ? 1.5f : 0.5f;
// 常量是 `.rdata` 硬编码（不在 VarsGlobal）：0x1834b2bb8=1.0 · 0x1834b3090=1.5 · 0x1834b2bb4=0.5
```
调用形状 —— `CardScript.ReceiveAttackAnim(受击方, 攻击方位置, 攻击方)`（`D/CardScript__ReceiveAttackAnim.c:27-28,38-89`）：

```

dir  = (|dir| > 1e-5) ? normalize(dir) : Vector3.zero;      // 1e-5 = 0x1834b2f44；重合时不后坐
punch = dir × GetPushBackFactor(GetUnitSize(**攻击方**))     // 0.5 / 1.0 / 1.5（原版世界单位）

```
⇒ **幅度只由「攻击方」的近战攻击档决定**（受击方 size 不参与）；方向一律**背离攻击方**。
第二处调用 `D/BattleManager._ResolveUnitShake_d__472__MoveNext.c:139-147` 把已算好的档**直接**喂 `GetPushBackFactor`，再走 `CardScript.DoPushBack`

**同一 size 档的另两个消费者**：相机震屏 amplitude **2.0 / 4.0 / 8.0**（`D/CardScript__ResolveAttackAnimationEffects.c:30-50`，常量 `0x1834b2bbc/b2df0/b2e00`；我们已实现 `CardFeel.ShakeAmpUnitSize*`）· 单位抖动 `DoUnitShake(2/4/8)`（`D/BattleManager._ResolveUnitShake_d__472__MoveNext.c:167-181`，size 取自另一字段 `+0x20`）。

## 三、选牌面板（`ChooseCardMenu`）的卡行

**1）卡的位置完全由 `chooseMenuAnchor`（类型 `CardsHorizontalLayout`，`S/MonoScript_7953367724191579424.json` 的 `m_ClassName`）算**：

**3）公式**（`D/CardsHorizontalLayout__GetPosition.c`，签名 `GetPosition(i, n, selectedIndex = −1)`）：

```
availW = 0.98 × (renderCamera 在该深度上的可见世界宽)   // :130-145；透视/正交两条路都化成「可见宽 × 系数」，

y_i    = anchor.y + m_yAxisCurve(i/(n−1)) × m_maxHeight(0.44) × m_heightModifier((n−1)/6)   // :221-236

```
