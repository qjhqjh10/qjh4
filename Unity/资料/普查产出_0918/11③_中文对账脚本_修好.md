## 二、原来为什么读不了（**量出来的**，不是推的）

`EffectParseProbe.Dump`（`Assets/RuleEngine/Editor/EffectParseProbe.cs:87`）输出的是**多行** op：

```
        atturn 载荷「…」 目标[（没写）]        ↳回合内层（turn_end） 1 条：   ← 组头**粘在父行尾**（`Nested` 没先补 \n，:169）
          · deploy n=1 载荷「sacred rose sister」 条件=anypraying …        ← 内层 op：**10 空格**
        ↳尾句 「attacks a random enemy」                                    ← 尾句：**8 空格**（:160）
```

旧脚本的四条读法，逐条对不上（**每条都量过全池**）：

| 旧读法 | 实际 | 全池代价（`probe_out.txt` 实测） |
|---|---|---|
| op 行 = `^ {8}\S` | 内层 op 是 **10 空格 + `· `**，第 9 个字符是空格 ⇒ **被滤掉** | **29 个 desc 块 / 31 条内层 op** 全丢 |
| 尾句 = `^ {16}↳尾句` | 尾句与 op 同缩进（**8 空格**）⇒ 正则**永不匹配** | **87 个尾句**被当成另一条脏 op（verb 解不出） |
| 组头独立成行 | `Nested` 先 append 组头、后补 `\n` ⇒ **粘在父行尾** | 29 块受影响（信息在，只是位置不对） |
| 新标记 `**随机抽**` / `死后转给[…]` / `选牌[…]` | 探针 0916 就加了（`EffectParseProbe.cs:119-150`），脚本**一个都没用** | 选牌族（`动作=copies` 等）判不了 |

**代价实例（可复查）**：`Sororitas Rhino` 的 `At the end of your turn, if any friendly unit is Praying, deploy a Sacred Rose Sister`
—— 条件 `条件=anypraying` **就写在内层 op 上**（`probe_out.txt:4331` 起），旧脚本看不见 ⇒ 报成
**A 类「条件被吞」**。修好读法后它自动变成 C 类（阶段②里已经没有它）。

另外两个**不是格式、但同样是「脚本没读对」**的：

- **51 个 `?` 桶不是「卡池里没有」**：`probe_out.txt`(09-16 19:33) 比 `desc_to_cards.tsv`(09-16 12:06) 新 ⇒
  **26 行**在池子里明明找得到（`Deal 1-3 damage to all enemies.` = `Eldritch Storm` 的一句）却没映射；
  另有 **25 行是子句**，旧脚本「按 desc 完全相等再取一遍中文」⇒ **子句永远取不到中文**、一律记成「中文缺」。
- **同名跨阵营会串中文**：`Maulerfiend` 池里两张同名（一张 `Ecstasy 5…`、一张 `Deal 1 damage to all enemies
  for each Dark Pact on your troops`）。改成「按名字取中文」的那一版当场**凭空报出一条 A**
  （第一张的中文显示成第二张的「每有一个我方部队身上的黑暗契约…」）—— 这正是自检 **J1** 盯的那件事。
  最终版改成**按卡对象取**（`cards_for` 直接返回卡对象），不再经过名字。

import io,json,re,importlib.util

m=importlib.util.module_from_spec(spec); import sys; sys.argv=['x']; spec.loader.exec_module(m)
probe=m.parse_probe(m.PROBE)
doc=json.load(io.open(m.CARDS,encoding='utf-8'))

for desc,blk in probe.items():
    if not re.search(r'(?i)\bfor (each|every)\b', desc): continue
    cs=[c for p,c in pn if norm(desc) in p]
    if not cs: continue
    sp=m.spec_features(blk)
    print(('OK ' if sp['count'] else '**NO-COUNT**'), cs[0]['name'][:40], sp['count'])
EOF
#    → 45 行；除 Patriarch（静态降费）外每一行都是 OK（有 计数=）
