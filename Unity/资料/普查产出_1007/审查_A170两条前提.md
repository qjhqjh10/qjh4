「不可滚」这条链，判据是 UGUI 自己两段源码（A170 引对了）：

  **不是子节点外接框**（A170 没写这点，但结论因此才成立）。
- `AdjustBounds`：`excess = view.size − content.size`，x/y 两轴都 >0（508.16 / 221.5）⇒ 内容 bounds **被撑到视口大小**
  （`ScrollRect.cs:1332-1352`，注释原文 *Scrolling is only possible when content is larger than view*）⇒ `CalculateOffset(zero)` 恒 0 ⇒ **没有可停留的滚动范围**。

⚠️ **补一句更准的话（不改结论）**：`Elastic` 下 `OnScroll` **会先把 delta 加进去**（`:648-700` 只在 `Clamped` 夹取）、`OnDrag` 被
`CalculateOffset + RubberDelta` 抵消（`:779-815`）、随即 `LateUpdate` 弹回（`:866-880`）⇒ 现象是「**能抖/有橡皮筋，但停不住、也看不到折叠以下**」，
写进正本别写成「拖也拖不动」。

## ③ 未决点（最重要）：尾部那段链式 `SetActive` **跑，且无条件**

办法：`dump.cs:88436` 给 `GraphicsTab.OnSetup` 的 `RVA 0x774570 / Offset 0x772F70` ⇒ 从 `GameAssembly.dll` **文件偏移 0x772F70**
取字节（PE 节表 `.il2cpp` VA `0x4b3000`→RAW `0x4b1a00`，`Offset` 那栏就是文件偏移）；函数长 **2577 字节**由 `.pdata` 的 `RUNTIME_FUNCTION`（`0x774570–0x774F81`）给出。capstone 反汇编。

**一、尾部是直线代码，没有一个条件能跳过它。** `0x180774cd1 → 0x180774f43` 依次：`smallScreenToggle`·`hiFPS`·`qualityDropdown`·
`cardsTextInHandDropdown`·`ConfigureSuperSamplingVisibility`·`superSampling`·`extendedCompatibility`·`autoZoom`·`vsync` 的 Set*WithoutNotify，
再 vtable 调一次 `fpsLimit`，然后 4 次 `SetActive`，epilogue + **`ret`**。这一段**唯一的分支是空引用检查**，
每一条都 `je 0x180774f44` = 共享的 NRE throw（`call 0x1803f47a0`），**没有一条能跳过或跳出尾部**。

**二、尾部唯一前驱 = `foreach` 正常跑完。** 尾部入口 `0x180774cd1` 的**全部**前驱只有 `0x180774c87: jmp 0x180774cd1`
（我把全函数的 jcc/jmp 目标全列过）；到它的唯一路径 = `0x180774ae3 call rax`（接口槽 **+0 = MoveNext**，fallback 第 3 实参 0）
→ `0x180774ae5 test al,al` → `0x180774ae7 je 0x180774c5e` → `0x180774c69 call 0x1803f3750`（`IEnumerator.Dispose`）→ `jmp 尾部`。
对照体：同循环的 `get_Current` 走**槽 +1**（`0x180774b34/b96/b48`）⇒ +0 确是 MoveNext。`Enum.GetValues` 是有限数组 ⇒ **尾部每次都执行**。
（Ghidra 把循环出口渲染成 `if (cVar2=='\0') { <尾部>; break; }` —— `break` 是假象，真出口是那段 `ret`。**§④1 说「CFG 糊了」对，现在钉死了**。）

**三、`OnSetup` 运行期确实被调**：`WindowTabBase.Setup()` 调 vtable `*(*this + 0x198)`（`WindowTabBase__Setup.c`），基址 0x138 ⇒ 槽 6 = `OnSetup`（`dump.cs:88436` 明写 `Slot: 6`）。

**四、字段偏移映射（A170 逐条正确）**：`+0x30 smallScreenToggle · +0x38 hiFPS · +0x40 superSampling · +0x48 extendedCompatibility ·
+0x50 autoZoom · +0x58 qualityDropdown · +0x60 cardsTextInHandDropdown · +0x68 vsync · +0x70 fpsLimit` ⇒ 尾部 = `hiFPS` 关 ·`vsync` 开 ·
`fpsLimit.transform.parent` 开 ·`extendedCompatibility` 关，且 `fpsLimit.transform.parent` = `FPS Limit` 那一行（标题与滑块同父）。
**⇒ 运行时 `Hi FPS toggl` 与 `Android extra compatibility` 都不在。**

### 运行时几行 —— 还有一个动态条件：`Use super sampling`
尾部里 `ConfigureSuperSamplingVisibility` 干的是 `superSampling.gameObject.SetActive(!isMobilePlatform && qualityDefinition.allowSuperSampling)`
（`GraphicsTab__ConfigureSuperSamplingVisibility.c`；`allowSuperSampling` = `QualityDefinition` +0x2D，见 `…__get_AllowSuperSampling.c`）。
**该值我读出来了**：`level0` 的 `QualitySettingsManager` MB（pid 346；MonoScript 3881 = `QualitySettingsManager`；⚠️ 解包目录里**没有**它 ——
玩家场景文件不带 type tree、两个导出器都跳过，得从 `Warpforge_Data/level0` 按原始字节读）。payload = `priority 2 / status 0 / count 5` + **5 条 36 字节记录**：

| quality | URP pid | clampCombat | clampMenu | qualityNumber | enCardsAntiAliasing | **allowSuperSampling** |
| --- | --- | --- | --- | --- | --- | --- |
| 0 VeryLow | 540 | 1280 | 1280 | 1 | 0 | **0** |
| 1 Low | 541 | 1920 | 1920 | 2 | 0 | **0** |
| 2 Medium | 541 | 1920 | 0 | 2 | 0 | **0** |
| 3 High | 4575 | 1920 | 0 | 2 | **1** | **0** |
| 4 Ultra | 542 | 0 | 0 | 2 | **1** | **1** |

🔴 **记录长 36 本身就定了 bool 宽度**：7 个声明字段只有 30 字节（4+12+4+4+4+1+1），实测步长 **36**（44+5×36 = 224 = 数据全长；
「quality = 0,1,2,3,4」只在步长 36 下成立，步长 32 会读成 0,0,0,2,0）⇒ `4+4+8+4+4+4+**4**+**4** = 36` ⇒
**这份玩家场景文件里 `bool` 占 4 字节**。同文件三个独立样本互证：`TouchInputManager`(297/299) 只有 1 个序列化字段 `bool forceMobileInput` ⇒ payload **4**；
`AssetBundleManager`(429) = 24 = 实测 payload；`SceneChanger`(307) = 4+4+字串(4+18)+float = 36 = 实测 payload。
⚠️ **陷阱**：AssetBundle 里烤好的 type tree 把 bool 标成 **1 字节**（menus 包扫了 233,731 个 bool 节点全是 `byteSize=1`）——
拿那套约定读 `level0` 会得出「AA=1 / SS=0」的错答案（那样五行 `allowSuperSampling` 全 0 = 该功能全平台死代码，与它自己的 UI/点击/本地化/listener 全在相矛盾）。

## ④ 顺带核 A170 §⑤3：vtable 槽 `0x438` = `Slider.SetValueWithoutNotify` → **成立**

- 调用点：`0x180774e44 mov rcx,[r15+0x70]`（fpsLimit）… `0x180774e51 mov r9,[rcx]`（klass）… `0x180774e6d mov r8,[r9+0x440]`（MethodInfo）
  → **`0x180774e74 call qword ptr [r9+0x438]`**。
- `dump.cs:926922` `public class Slider : Selectable, IDragHandler, …`（TypeDefIndex 17463）：`Slot: 46 get_value`·`Slot: 47 set_value`·
