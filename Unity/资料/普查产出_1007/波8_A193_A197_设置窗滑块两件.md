### 二·2 A193 的判据与口径

**① 判据**：原版 `Background`（轨道）与 `Handle`（手柄）两颗 Image 的 `m_RaycastTarget = 1`
（`资料/普查产出_1007/波8_注释订正批.md` §五⑤ + 九根逐颗实读）；手柄中心 = 轨道左 + 12 + 值/2 × 481.18
⇒ **2 档时手柄探出轨道右端 19.7 设计 px**（0 档探出左端 5.7）⇒ 原版点得到。

**② 改法（判据只此一份）**：新抽 `WfSlider.HitBand`（`Battle/WfSlider.cs:354-378`）——
「**轨道 ∪ 手柄**」，**两块共用同一个纵向带**（半高 = `max(轨道半高, 手柄半高)`）⇒ **并集本身就是一块矩形**，
横向取 min/max 即可：

```csharp
public static void HitBand(float trackL, float trackR, float halfTrackH,
                           float handleCx, float halfHandle, bool hasHandle,
                           out float lx, out float rx, out float halfH)
{
    halfH = hasHandle ? Mathf.Max(halfTrackH, halfHandle) : halfTrackH;
    lx = trackL; rx = trackR;
    if (!hasHandle) return;
    lx = Mathf.Min(lx, handleCx - halfHandle);
    rx = Mathf.Max(rx, handleCx + halfHandle);
}
```
- `WfSlider.Contains`（`:389-398`）**改写为转调它**（逐值等价，含 A169 那条「手柄那一块也算命中」）；
- 设置窗 FPS 行的命中区（`Shell/SettingsWindow.cs`）：建行时仍用 `MenuDraw.Hit`（`MenuDraw`/`WindowButton`
  那套只吃**矩形 quad** ⇒ 宿主侧**没法直接调谓词**），但**矩形由 `FpsHitRectPx(idx)`（`:830-838`）
  经 `WfSlider.HitBand` 算出来**，并且在 `PlaceFps`（`:1066-1096`）里**逐档重算**（`UpdateFpsHit`，`:845-860`）
  —— 手柄跟着值挪，矩形也必须跟着挪。⛔ 宿主侧**没有**第二份判定逻辑（只有「把这一块矩形摆到哪」）。
