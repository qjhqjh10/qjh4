## 三、🔴 对账结果：旧表确有错，三类

按卡名归一化匹配上 **1073 / 1118**。

### ① 字段（兵种）错了 **37 处** —— 用户最担心的那一类

根因：`card_stats.json` 把**卡的类型**（`Unit`/`Troop`/`Soldier`）填进了**字段**列。
`卡牌数据总表.md` 里这两列是分开的（`类型=Unit` / `关键词=Infantry`），**我们的生成器读错了那一列**。

| 卡 | 旧表 | 卡面实际 |
|---|---|---|
| Daemonette · Alluress | `Troop` | **`Daemon`** |
| Hunting Wolf · Fenrisian Wolf | `Troop` | **`Beast`** |
| Hrolf the Ironhowl | `Infantry` | **`Beast`** |
| Throne of the Heretic · Defensive Turrets · Grim Effigy | `Spell` | **`Defence`** |
| Shivversplint | `Upgrade` | **`Combat Elixir`** |
| Antrak Silk · Heliotrophos · Skorflense | `Elixir` | **`Combat Elixir`** |
| Heavy Intercessor · Orian Laratharjos · Assault Terminator … 20+ 张 | `Unit`/`Troop`/`unit` | **`Infantry`** |

**为什么致命**：`天下一张 <字段> 卡` / `造一张 <字段> 卡` / `<字段> 得 +1` 全靠它筛 ——
字段错 = **筛错卡**。`Hunting Wolf` 是兽不是兵，`Daemonette` 是恶魔不是兵。

### ② 关键词的**数值被吃掉** ~53 处

卡面写 `Armour 1. Blast 2`，我们的 `keywords` 是 `['Armour','Blast']` —— **数字没了**。
`KwValue("armour")` 取不到值就是 0 → **护甲/爆裂实际不生效**。

实例（我开图核过）：`War Walker`（`Armour 1. Blast 2`）· `Vyper`（`Shuriken 3`）·
`Taurox Prime` · `Flamer Trooper` · `Manticore` · `Leman Russ Vanquisher` · `Venomcrawler` ·
`Assault Terminator` · `Deathwing Terminator` · `Terminator Champion` …

### ③ 关键词**整个缺失** ~13 处

`Slugga Boy` / `Hornhelmz' Boy` / `Snakebite Grot` / `Deffkopta` 的 **`Tide N`**、
`Ophydian Destroyer` / `Damaged Plasmacyte` 的 **`Regeneration N`**、
`Hulking Aberrant` 的 **`Armour 1`**、`Night Spinner` 的 **`Blast 3`** —— 旧表里完全没有。

### ④ 其余的差异（**多为表示差异，不是内容错**）

| 项 | 处数 | 说明 |
|---|---|---|
| 效果文字（旧表缺开头的关键词声明） | **238** | `Flying. Flank.` 那串在 `desc` 里没有，但引擎真正读的 **`keywords` 列有** → **不影响玩法** |
| 效果文字（真差异） | 105 | 混着上面①②、OCR 噪声（`i`、`attack` 这类多出来的词）与词序/标点 |
| 稀有度 | 28 | 多数已抽验为**旧表错**（如 `Deathwing Terminator` epic→common） |
| 费用 | 9 | 含 `Wraithknight` 3→10、四张 `Dark Pact` 全 1→2、`Terminator Champion` 7→6 |

## 四、已知的**不完美**（如实标着）

1. **图标没有语义** —— 子代理一律只写形状（`【图标:眼睛】` / `【图标:盾牌】`），
   **没有猜它是哪个关键词**。好处是不会带偏数据；代价是**同一枚图标在不同批次可能起了不同名字**
   （多批都主动报告了「不确定是不是同一枚」）。**要对齐图标得单独做一轮。**
2. **稀有度有系统性不确定**：多批报告 `common`（浅青）与 `rare`（绿）在 PnP 渲染下色相接近；
   Tau 那批干脆用**像素取样**判色，可信度更高。**建议：拿宝石色卡复核那 28 处稀有度差异。**
3. **45 张卡在新表里有、旧表里按名字对不上** —— 多为 OCR 名字写法不同（见 `_对账.md` 末节）。
4. **`卡牌信息权威表_0824.md` 里的既有裁决没被推翻** —— 本表只抄卡面，不做归类裁决。

## 六、关键词 ↔ 图标（2026-09-13 建立）

**为什么做**：卡面上的效果文字里全是**图标**，子代理抄的时候只写了形状（`【图标:眼睛】`）——
因为**不许猜语义**。而图标到底代表哪个关键词，原版自己给了答案。

### 证据链（很硬）

原版图集 **`d:/2/新解包资源/assets_full/bundle_atlasindividual_assets_40ktraiticonatlas/`**
里，**每个关键词一个 sprite，文件名就是英文关键词**（`Atlas_trait_icon_blast` → `Blast` → 爆裂）。
按每个 sprite 的 `m_Rect` 从 `Texture2D/40k Trait icon atlas.png`（1024×1024）切出 **78 个图标**。

**产物**：`资料/关键词图标/关键词与图标_对照表.md`（+ 同目录 `icons/` 里的 PNG）
—— 和规则书 `:161-225` 的 **61 个关键词对上 67 个**。

| 文件 | 是什么 |
|---|---|
| `关键词与图标_对照表.md` | **对照表正表**（图标文件 / 中文名 / 英文名 / 规则书行号 / 带不带数值） |
| `_规则书关键词表.md` | 规则书 61 个关键词的**原文表**（中文名 + 英文名 + 效果 + 行号 + 带数值?） |
| `_图标清单.md` | 78 个图标**逐张看过的客观描述**（形状+颜色）+ **15 组易混组** |
| `icons/*.png` | 切好的图标。⚠️ **原版资产，不进 git**（`.gitignore` 已加规则） |

### 已确认的硬事实

- **5 张 `markOf*` 是同一张图**：`markOfChaos`/`markOfKhorne`/`markOfNurgle` **md5 完全相同**，
  `markOfSlaanesh`/`markOfTzeentch` 与它们只差 7 / 2 个像素（80×80 共 6400 px）。
- **`relentless` 与 `resolution` 只差 1 个像素**（绿圆底 + 白色双循环箭头）—— 卡面上也分不出。
- 规则书里查不到的 11 个：`berzerk` / `frenzied` / `rage` / `loot` / `relentless` / `resolution` + 5 张 `markOf*`。
- 反过来规则书有、这张图集没有的：`Dark Pacts` / `Destroyer` / `Penitence`，以及 `Health`/`Cost`/`Type`/`Skulls`
  （那些属于别的 UI 图集）。
- **数值类图标大多不在这张图集里** —— 只有 `Melee`（近战）与 `Ranged`（远程）在。

### 🔜 下一步能拿它干什么（**用户 2026-09-13 点名**）

> 「以后可以**逐个卡牌进行对比**，找出正确关联。这些图标可能是 **buff 或者 debuff 效果**的图标，
> 比如**重生、护甲、脆弱**等。」

也就是说：现在卡表里的 `【图标:X】` 还是**形状占位符**，可以拿这张图集去**逐张卡对出真关键词**。两条路子：

1. **图像比对**（可靠）：从卡图上把图标抠出来，和 `icons/*.png` 做模板匹配
   （注意不同底色/缩放 —— 图集是 80×80，卡面上的图标要小一些）。
2. **语义比对**（快但会错）：按形状描述去猜。⚠️ **别用这条** —— 有 15 组图标长得几乎一样
   （白骷髅头就有 11 张），猜必错。

对出来之后，`_合并总表.md` 的「效果原文」就能从 `【图标:护盾】Armour 1` 还原成 `Armour 1. Blast 2`，
**和新旧卡表的效果文字对账会一下子干净很多**（现在那 105 处「真差异」里有一大半是图标没还原造成的）。
