# §六 · 回归（`BattleScene.Run` 4407/2 → 唯一新红）

## 红的那条

```
BT ✗ ★ F1/回手兜底：取不到溶解材质 ⇒ **关 3D 体**那条路（实得 MaterialDissolve）
```

### 是**断言**的触发顺序错了，⛔ 不是实现

- **实现是对的**：`CardFeel.ReturnToHand` 里 `canDissolve = !ForceNoDissolveForTest && card.BeginDissolve()`，
  为假就进「关 3D 体」那一支（源码现读 `CardFeel.cs:1299` 起）。同一块里下一条「α 仍是 1」当时是**绿**的
  —— 那正好反证了兜底支真的走了（老版本会 `SetAlpha(0)` ⇒ α 变 0）。
- **错在断言**：`LastReturnFallback` 是**静态的上一次结果**。我上一轮删「重复的 `ReturnToHand(f1)`」时删错了那一句，
  把 `CardFeel.ReturnToHand(f1)` 调到了 `Check` **之后** ⇒ `Check` 读到的是**本节前面那几张探针**留下的
  `MaterialDissolve`。
- **修法（不放宽断言）**：把「调一次 → 紧接着断」恢复成相邻两句，并在注释里写清「这个计数器是静态的、
  中间不许插别的 `ReturnToHand`」。断言语义一个字没改。

### 顺手补的（`D5` 的发现）

`CardFeel.ReturnToHand` 的**溶解支演完不还原材质** ⇒ 那张卡会一直挂着溶解材质
（原版末尾有 `DelayedResetMaterial(0.55)`）。现在：

```csharp
t.OnComplete(() => { if (onDone != null) onDone(); if (canDissolve) card.EndDissolve(); });
if (canDissolve) t.OnKill(() => card.EndDissolve());
```
- ⚠️ `OnComplete` 在 DOTween 里是**单槽**（再设一次会覆盖前一个）⇒ 两件事写进**同一个 lambda**。
- `OnKill` 在「正常播完」时也会跟着触发 ⇒ `EndDissolve` 会被叫两次；`CardView.EndDissolve` 自 D5 起幂等，安全。
