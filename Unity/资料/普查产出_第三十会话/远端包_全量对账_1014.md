## 五、🔧 无 type tree 的 `.assets` 怎么读（本会话 `A650` 现做的，可复用）

**判据**：`read_typetree()` **全失败**（`resources.assets` **616 / 616 fail**）⇒ 该文件**没有 type tree**。

**做法（三步）**：
1. `env = UnityPy.load(<文件>)` ⇒ `env.files` 是 dict，取那个 `SerializedFile`；看 `externals`（`resources.assets` 是
   `[globalgamemanagers.assets, Library/unity default resources, sharedassets0.assets]`）。
2. 对每个对象调 **`obj.get_raw_data()`** 拿原始字节，按**标准 MB 头**手工切：
   ```
   offset  0: m_GameObject.m_FileID  (int32)
   offset  4: m_GameObject.m_PathID  (int64)
   offset 12: m_Enabled              (uint8 + 3 字节 pad)
   offset 16: m_Script.m_FileID      (int32)   ← 通常是 1 = externals[0]
   offset 20: m_Script.m_PathID      (int64)
   offset 28: m_Name 长度 (int32) + 字节
   ```
   （⚠️ **`resources.assets` 这个 build 是 32 字节起** —— ⛔ 别把「固定 32」套到别的文件上。）
3. **把 `m_Script.m_PathID` 翻成类名**：查
   `d:/2/新解包资源/assets_full/globalgamemanagers/MonoScript/MonoScript_<pathID>.json` 的 **`m_ClassName`**
   （该表现读 **4,453 份**）。
   ⇒ 🔴 **这是「不知道类名也能解」的通用口子**，比 `menu_dump.mono_index()` 直接、也不依赖任何索引文件。

**工具**：`d:/4/Unity/工具/_a650_unpack_resources.py` · `_a650_probe2.py`

**这一步的产出（`resources.assets` 那 616 个对象到底是什么）**：
`Image`×174 · `Text`×149 · `Toggle`×66 · **`DebugUIHandler*`×约100** · `ContentSizeFitter`×24 · `VerticalLayoutGroup`×23 ·
`Button`×22 · `LayoutElement` · `Scrollbar` · `GraphicRaycaster` · `CanvasScaler` · `EventTrigger` · `TMP_FontAsset`/`TMP_SpriteAsset`/`TMP_Settings` ·
`LanguageSourceAsset` · `ServerSettings` · `DOTweenSettings` …
⇒ **全是 Unity 自己的运行时调试面板 ＋ 第三方库的 Resources 资产，没有一个游戏自己的 UI 组件。**
