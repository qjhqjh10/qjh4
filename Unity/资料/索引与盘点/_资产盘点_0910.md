### 3. `d:/2/Warpforge_code/` — 反编译 C#（查逻辑用，**不能编译成可运行程序**）

**体量**：16,294 文件 / 72M。`Scripts/` 下 14,866 个 `.cs`（58MB），`Assemblies/` 130 个 dll。

**关键结论（本次实测，含 dll 元数据解析）**：

1. **`Assembly-CSharp/` 2,294 个 .cs / 6.8MB —— 只有签名桩，没有方法体。**
   类型、字段、枚举、属性、方法签名、Attribute 全部齐全且真实；方法体被掏空只剩默认返回值。
   铁证：`Assembly-CSharp.dll` 有 21,131 个方法，全部方法体合计仅 **67,517 字节，平均 3.2 字节/方法**（`BattleManager::CanUseActiveAbility` 的 IL 是 `0A 16 2A` = `stloc.0; ldc.i4.0; ret`）。1 字节纯 `ret` 的有 8,872 个。
   例：`AchievementsManager.GetIconByTier(int tier) { return null; }`、`CardScript` 里连编译器生成的迭代器状态机骨架都还原了但 `MoveNext() { return false; }`。
   工具痕迹：ILSpy 注释（123 文件命中），**不是** Il2CppDumper 的 dummy dll（无 `Token/Address` 特性）。
2. **Warpforge 自己的代码只在两处**：`Scripts/Assembly-CSharp/`（本体逻辑，含 `Everguild/` 子命名空间：Addressables/LiveOps/OldShop/Ranking/Scenes/UI.Notifications/Utils/W40k）与 `Scripts/Assembly-CSharp-firstpass/`（353 文件，基本是第三方插件）。其余全是第三方库（PlayFab 1217、System 1076、UnityEngine.* 、Spine、DOTween、Cinemachine、Firebase、I2 Loc 等）。
3. **`Assemblies/` 的 dll 是 IL2CPP 的 reference/dummy 程序集**：格式上是标准 .NET PE（RuntimeVersion v4.0.30319，可被 dnSpy/ILSpy 读），实质无真实 IL。真正的游戏本体是 `GameAssembly.dll`。
4. **能不能编译**：C# 桩理论上能编译过（`.csproj` 齐全、130 个引用 dll 全在），但产物是**空壳程序集，没有任何游戏行为**。

**真实控制流在哪**：`Warpforge_tools/data/decomp_il2cpp_0827/` —— Ghidra 12.1.3 headless 从 `GameAssembly.dll` 反编译的 C 伪代码：
- `decomp_out/` 1,800 个 `.c` / 8.0MB，覆盖 **34 个类**（`BattleManager` 647 方法、`CardScript` 423、`BattleCardUI` 81、`BasicCardUI` 71、`PlayerHand` 66、`VoiceLinesController` 48、`CardDeck` 41、`CardDisplayWindow` 37、`ClockManager` 35、`BattleHud` 33、`ActiveSkillDisplay` 30、`BattleCommsManager` 28、`ManaManager` 19、`MulliganManager` 17 等）——**基本全是战斗 + UI，没有卡牌效果解析/AI/商店/成就/教程类**。
- `decomp_out2/` 224 个 `.c`，专收协程状态机 `_d__NNN__MoveNext`。
- `ghidra_scripts/` 5 个脚本（`Decomp.java`/`Renamer.java`/`FindRefs.java`/`il2cpp_decomp.py`/`il2cpp_renamer.py`），可重跑。
- 质量：方法名/字符串名可靠（已用 IL2CPP `script.json` 还原），控制流是真的（能看出 `CardScript__AddEffect` 的前置校验、extrinsic effect 去重）；但变量全是 `undefined4/undefined8/longlong`，字段访问是裸偏移（`param_1 + 0x228`），未识别调用是 `FUN_1803f44f0` 这类地址名，无结构体/类型还原。
