### 3D 战场还原评估（2026-08-18 第二轮核查第 1/3 项）

**用户要求：原版是 3D 战斗（3D 战场/单位卡牌/3D 特效），不能 2D 敷衍。评估结论：完全可行，资源齐全。**

| 3D 资源 | 位置 | 说明 |
|---|---|---|
| 战场模型（几何 OBJ） | `06_模型/scenes_scenes_battlearena1/`（28 个：Floor plane/背景建筑/桥梁/大炮/围栏/发电机/旗帜/沙袋/车辆）| 纯几何（无内嵌贴图） |
| 战场贴图 | `07_场景/battlearena1/Texture2D/`（5 张：Battle Arena 1 Floor 4096²/Background 2048²/Back Background 2048²/Baked/运输舱）| **场景贴图可直接用** |
| 卡牌 3D 模型 | `06_模型/battleprefabs_vfxandmisc/Card 3D WH40k.obj` + Card 3D Subdivided + Card_Remnant_HO | 战场 3D 卡牌几何 |
| 特效部件模型 | battleprefabs_vfxandmisc 124 个（Chopper/Axe/Bullet/Sky 等）| 3D 粒子部件 |
| 共享资源模型 | battlesharedresources 249 个（Altar 祭坛/建筑/背景）| 战场装饰 |
| 13 阵营战场模型 | scenes_scenes_battlearena*（45-80 个/阵营）| 阵营差异化战场 |
| 摄像机 | battlearena1 Camera JSON：**BoardCamera 位置 (0, 2.22, -13.57) 正对 z 轴**，28mm 焦距 41.5mm 传感器（FOV≈73°）| 原版 3D 视角 |
| 材质链 | Material JSON m_TexEnvs → 纹理引用 | 可解析 |

**实施路径（convert_unity_3d.py 工具 + Godot 3D）**：
0. ✅ **战场背景 3D 化（第一步已完成，2026-08-18）**：battlearena1 贴图同步 `assets/ui/battle/3d/`（floor 4096²/background 2048²/back_background）→ battle.gd `_build_3d_world()`：Camera3D 原版 BoardCamera (0,2.22,-13.57) FOV73° +180° 转（Unity +z→Godot -z）+ 环境光+平行光 + 3D 地板 40×40（阵营地面图切换 _floor_mat3d）+ 远景墙 z=27 + 2D 建筑剪影层保留；2D 三段背景（天空/建筑/地面+渐变遮罩）移除；**vision 验收**：地板透视延伸+工业纹理+2D UI 清晰叠加+氛围契合
1. ✅ **卡牌 3D 化（第二步已完成，2026-08-18）**：battle.gd `_update_3d_cards()`——每格 3D 卡牌（PlaneMesh 正面卡面纹理+背面卡背，每卡独立材质）位置=格子屏幕中心→摄像机射线与地板平面求交（`_screen_to_floor`），look_at 面向摄像机；2D 卡图隐藏（3D 卡牌替代），2D 角标/状态/遮罩保留在格子上；Card 3D WH40k.obj 已验证（**坑：是浮雕卡（角色凸起）非平板，不适合贴卡面**，平板用 PlaneMesh 正反两面）；**vision 验收**：真卡单位 3D 卡面显示+角标保留+工业地板远景正常（白盒测试卡无 art 纹理属预期）
2. **3D 粒子**：convert_unity_particles.py 扩展 3D 模块（GPUParticles3D：3D position/velocity/gravity）——子弹弹道/枪口火光/爆炸冲击波
3. **3D 粒子**：convert_unity_particles.py 扩展 3D 模块（GPUParticles3D：3D position/velocity/gravity）——子弹弹道/枪口火光/爆炸冲击波
4. **交互层**：2D Control 保留（点击/部署/攻击选择器），3D 场景作战场渲染层——不重写 battle.gd 交互逻辑
5. 13 阵营战场模型按 f_self 切换

**风险**：① OBJ 无贴图——靠 Material JSON 纹理链恢复（battlearena1 场景贴图已验证可用，阵营场景待验证）② OBJ 顶点量大（Floor 8434 行）需 LOD/合并 ③ 3D 与 2D 交互层坐标对齐（格位换算）
