## ② 改了什么（两条路各怎么接）

接线点 = **`Net/NetBattle.cs` 的 `WireSession()`**（两个 `Attach` 都走它：`s.OnPeerLost += HandlePeerLost` · `s.OnClosed += HandlePeerClosed`）。
选它是因为**原版那半边也挂在「对局」这一层**（`BattleManager`/`BattleErrorUIManager`），而 `NetBattle` 正是我们的对局联机层；且它已经管着 `OnResumed` / `ResumeProvider`。
**三层一起出声**（`SayPeerGone` 一处写）：`Debug.Log` + 提示行 `INetBattleHost.NetSay` + **弹窗 `NetRuntime.Notice`**（它弹的就是 `WindowsManager.ShowPopUp`，`NetRuntime.cs:104-105`；战场里也弹得出来）。
- **路①对面主动离开（`OnClosed`/`bye`）** ⇒ 「联机对局结束：〈对面报的理由〉」。
- **路②对面掉线（`OnPeerLost`，心跳超时/连接断）** ⇒ 「对手掉线了 —— 正在等他回来（对局已暂停）」。
- **路③（顺带，原版的 D 条）对手回来** ⇒ `Tick()` 里**认边沿**（`_peerGone` 由掉线那一下置位）说一句「对手回来了 —— 联机已恢复，接着打」。⚠️ 原版那一刻是 `CloseAllWindows`，**我们没跟着调**（它会把玩家这一刻自己开的窗一起关掉，而原版那一刻台面上只有那一扇提示窗）⇒ 改成提示行说一句；这条口径记在这里。
- 顺手：`NetBattle.Detach()` + `BattleDriver.AttachNet` 拆旧的；**不属于协议改动**（`NetKind` 一条没加）。

## ④ `OnDestroy` 与 `LeaveBattle`（放弃匹配）两条的结论

- **`OnDestroy` 该捎 `bye` ⇒ 已加**（`BattleDriver.OnDestroy` 里 `LeaveNetRoom(); AttachNet(null);`）。
  判据：原版在「销毁 / 退出应用」这条路上**也是主动退房间**，不是等对面超时 ——
  `NetworkCustomManager__OnDestroy.c:13-19`（`PhotonNetwork.connected` 就 `Disconnect()`，**对面会收到 PlayerDisconnected** ⇒ 走①那条链）；
  `PlayerDataManager__QuitApplication.c:23-35`（退出应用时显式 `LeaveRoom()`）。
  两道现成的闸保证**不重发**：`_net == null`；`LeaveNetRoom` 里 `State == Off`（= 原版那个 `state = 100`）。
- **`BattleNetworkManager.LeaveBattle`（放弃匹配）⇒ 不再接新入口，理由三条**：
  它的三个调用点（`BattleManager__CancelMatch` / `__ClickExitBattle` / `BattleNetworkManager__EventDisconnected`），
  在我们这边**都已经有等价落点**：① 大厅阶段放弃匹配 = `NetMatchmaking.Cancel`（2026-10-03 做的 `match.cancel`，自检 L 系列在盯）；
  ② 打完之后离场 = `LeaveBattle` → `LeaveNetRoom()`（B8）；③ 对局中途退出 = `Forfeit()` → `resign` 消息（对应原版 `SendForfeit`）。
  ⚠️ 它里面那一句 `NetworkCustomManager.RemoveRoomAfterLeaving()`（把房间从名录里摘掉）**没有对应物** —— 我们是 P2P、没有房间名录 ⇒ 不复刻（不是"没查到"）。

## ⑤ 没查清 / 没做的（⛔ 别当成"复刻完整了"）

1. **倒计时判弃权没有做**：原版那 15 秒起的倒计时 + 到点 `DeadHero(对面,3)`（①的第 10/11 条）我们**没有** ⇒ 现在对面一直不回来，这一局会**一直停着**（提示行/弹窗说了"在等他回来"）。归下一批。
2. **对局时钟暂停没有做**：`BattleDriver.TickClock` 那一侧没有联机闸（原版 `ShowDisconnectionPopup` 那一刻 `PauseClock`）。
3. **大厅阶段（还没进对局）对面掉线/离开仍然不弹窗**：`NetMatchmaking` 完全不看会话状态，玩家只能从设置窗里的 `StatusText` 看出来。要接得让 `NetRuntime` 那条路**避开对局中**（否则同一台会话上会弹两次）⇒ 归下一批。
4. **我们是 P2P、没有服务端** ⇒ 原版的「状态 1 = 自己掉线 / 状态 2 = 对面掉线」两扇窗在**同一个事件**下必然重合：两端都断，两边都说"对手掉线了，正在等他回来"，这是**唯一诚实**的说法（原版那种分法要有服务端告诉你"你掉线了"）。⇒ 这一条是**我们的口径**。
5. 文案是**我们的措辞**（原版键已知 = `Battle/HUD/WaitOpponentConnectionMsg`），正式译文在远端 I2 表、**本地拿不到**（同 `Resign` 那条口径）。
6. 自检**没跑**（红线：不跑 Unity；联机自检必须串行）—— §9 那几条的**绿红归主对话在同步点上跑**。
