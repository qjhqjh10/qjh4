## ② RC1 机制（**这一条是本次最有价值的发现**）

**判据链（逐句可核）**：

1. `Net/NetSession.cs:23` `SilentTimeoutMs = 10000`；`:55` `_lastRecvMs` 是**实例字段、默认 0**；`:65-66` `NowMs` = **进程级静态** `Stopwatch`（`_sw`，类首次被用到就开始跑）。
2. **主机侧从没给它赋过初值**：`StartHost`（`:95-118`）只设了 `_lastAccepted = _t.AcceptedCount`（`:107`）—— 对照**客机**那条路 `InternalConnect` 是设了的（`:146` `_lastRecvMs = NowMs;`）。
3. `Pump()` 里的**次序**才是要害（`:183-219`）：静默超时判在 **`:190`**（`if (_t.IsConnected && now - _lastRecvMs >= SilentTimeoutMs)`），而给主机补 `_lastRecvMs` 的那一句在**它后面**（`:210-219` 那一支，`:213` `_lastRecvMs = now`）。
4. accept 线程在 `Net/NetTransport.cs:209-230` 把 `_connected = true`（`:219`）、`AcceptedCount++`（`:220`）—— 与主线程 `Pump()` 并发 ⇒ 只要这一步落在「`Pump()` 的 `:190` 判完 / `:210` 尚未跑」的窗口里，主机就会拿 `_lastRecvMs == 0` 去比 `now`。
5. ⇒ **`now ≥ 10000` 时（= 进程起来 10 秒后）**，主机在**从没见过对面一个包**的情况下判自己「10 秒没收到对面的任何消息」→ `_t.ClosePeer()` → `SetState(WaitingReconnect, …)` → `OnPeerLost()`；**同一个 `Pump()` 紧接着还会跑 `:210` 那一支**：`SetState(Handshaking, "有客机连进来了…")` 把状态**倒着改回去**，而 `Challenge` 因为刚 `ClosePeer` 已经发不出去 ⇒ **这一局永远握不上手**。
6. **日志实证**（`netbattle.log:5674-5676`，时钟闸那一段）：`Handshaking：连上了…`（客机）→ `WaitingReconnect：连接断了：10 秒没收到对面的任何消息` → **`Handshaking：有客机连进来了`** —— 这个 `WaitingReconnect → Handshaking` 的**倒退**只可能出自同一个 `Pump()` 调用，也正是「掐完又握手」那两句。
   随后同一段还有第二发（`:5681` `WaitingReconnect：连接断了：读取中断…WSACancelBlockingCall`）⇒ **`OnPeerLost` 在一段里被点了两次**（这也解释了 `:5824`「刚开局闸就已经按下」）。
7. **为什么它前面那些段全绿**：那些主机的首连都发生在 `now < 10000` 的窗口里，`now - 0 >= 10000` 不成立，同一段代码**静默地不发作**。阈值是**进程级**的、不是「会话年龄」⇒ 与本批改了哪几处无关。
8. **它是老缺陷、本批只是把它踩出来**：`git log -S "SilentTimeoutMs" -- Assets/CardPresentation/Net/NetSession.cs` → 唯一引入提交 = `85666bf`（2026-09-26「联机（P2P）整条打通…」）；`HEAD` 版的 `_lastRecvMs` 初始化与 `Pump()` 次序**与工作区逐字相同**（`git show HEAD:…NetSession.cs`：`_lastRecvMs` 只出现在 55 / 146 / 191 / 208 行，`205/207` 是 `_lastAccepted` 那两行）。本批把 NetBattleTest 拉长（新增 §10/§11/§12，且 §9④ 第一格自己烧掉 4 秒）⇒ 第 10 秒那道线**落进了第 10 段之后**。
9. 🔴 **真 Play 推断（未实测，需两机/真 Play 确认）**：真机上 `NetSession` 类一开局就被用到 ⇒ 玩家点「当主机」等对面连进来时 `now ≫ 10000` **恒成立** ⇒ **主机应该连一条都收不下**。这与「两台机器真连一次还欠着」是同一件事的另一面，建议**先修再验**。

**建议修法（只写不改）**：`StartHost` 里补一句 `_lastRecvMs = NowMs;`（与 `:146` 对称；最小改动）；**同时把次序摆正** —— `:210` 那一支（接受连接）移到 `:183` 心跳/超时块**之前**，或给 `:190` 加一道「已经握过手」的闸（`State != NetState.Listening`）。只改其中一个都会留下别的边角（前者挡不住「重连时 `_lastRecvMs` 也陈旧」那一档）。
