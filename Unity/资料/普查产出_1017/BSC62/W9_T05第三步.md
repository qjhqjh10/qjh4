## 二、`PendingSignal` 加了什么字段 · 一条事件怎么变成 N 条

- `beat`：本信号是不是「按表展开的一拍」（`false` = 老形状，行为逐字不变）。
- `beatVfx`：**本拍的 prefab 名**（`CardAnimBeat.vfx`）。**空串 = 纯延时拍**（原版 `Wait_300ms/1s/1.5s/2s`）：没有特效可播，但时长照算。
- `beatSp/beatEp/beatPt`：本拍三个位置选项（原版 `AnimInfo` 的 `0x18/0x1C/0x20`）。
- `beatTail`：**不是这一串的第一拍** ⇒ 事件级副作用（`SpeakFor`/`PlayRemnantSfx`/`PlayBattleSfx`/`PlayFeel`/`PlayTraitParticles`）**不再重复**。不设这道门，一次技能会响 N 遍语音与音效。

**一条 → N 条**（`ExpandAbilityBeats(e, t0)`，`PlaySignals` 里调）：
1. `CardAnimOrder.TryGetBeats(e.CardId, _beatBuf)` —— 按**卡名或 id** 查表；`0` ⇒ 回 `false`（走原样一拍，它已出声）。
2. 逐拍过两道门（§三、§五），通过的排一条 `PendingSignal`：`at = t0 + acc`，`beat=true`，`beatTail=!first`。
3. `acc += beat.Waits ? max(0, beat.Duration) : 0` —— **每拍各自错开**（见 §三）。
4. 所有拍都被门挡掉 ⇒ **仍排一条空拍**（`beatVfx=null`, `beatTail=false`），让事件级副作用照原版响一次（否则整条静默）。
5. 调用方 `continue` 前 `t += EventTiming.DurationOf(e)`（**该卡技能总时长**，`Core/AbilityAnimDurations.cs`）—— 后面的事件照旧按原节拍跟上。

## 三、waitForAnim 落地式（把口径 1/2/3 代进代码说一遍）

- **口径 1**（每拍各读自己的 `0x58`）：`CardAnimBeat.Waits` = `w != 0`，`w` = 生成期抄来的 `AnimInfo.waitAnimToApplyEffect`。**⛔ 不是「只有最后一拍才 wait」**（旧记录把 `PlayAnim(…, List<CardScript> abilityTargets)` 的**目标**误当成了 `cardAnimations`**步骤**，`R4` 已就地订正）。
- **口径 2**（三选一 + 无目标报错）：`opt = (int)PositionOption.abilityTarget = 2`；`multi = (sp==2 || ep==2 || pt==2)`。
  · 我们的引擎**一条事件只带 0 或 1 个目标**（`TargetPlayer/TargetSlot`，只有 `EffectTargets.NeedsPick` 才填）⇒ `targetCount = (ViewAt(TargetPlayer,TargetSlot) != null) ? 1 : 0`。
  · `multi && targetCount==0` ⇒ **出声 + 跳过这一拍**（原版 `PlayAnim.c:172-176` 是 `LogError` + **return**；⚠️ **原版整段 return，我们只跳这一拍** —— 见 §九·1）。
- **口径 3**（落地式）：`waitForAnim(拍 i, 目标 j) = (j == targets.Count-1) && waitAnimToApplyEffect_i`。
  代入 `targetCount`：**多目标拍且 `targetCount==1`** ⇒ `j==0==Count-1` ⇒ `= Waits`；**非多目标拍** ⇒ 原版单目标那一支（`PlayAnim.c:274`）⇒ `= Waits`。**两种情形都退化成 `Waits`** ⇒ 代码里只写 `if (b.Waits) acc += b.Duration;`（这正是 `R4` §四说的退化）。

## 四、每拍耗时从哪来（复用 AbilityAnimDurations 的哪一处）

- **每拍**：`CardAnimBeat.Duration = vd+ts+tm+te`（`vfxDelayTime` 0x24 + `timeAtStartPos` 0x2C + `timeMoving` 0x30 + `timeAtEndPos` 0x34）= **`AnimInfo.GetAnimDuration()`** 的同一个式子。⚠️ **不含 `startDelay`(0x28)** —— 原版的 `GetAnimDuration` 也不算它。
- ⚠️ **为什么不是「复用 `AbilityAnimDurations`」**：那个件（`Core/AbilityAnimDurations.cs`）**只暴露「整张卡 Σ 时长」这一个口**（`TryGet(cardIdOrName, out seconds)`），**没有逐拍口**，而且它是**黑名单（只准读/复用）**⇒ 逐拍只能由本拍的 4 个字段现算，式子与它**同源**（文件头已互指）。
- **整条事件占多久**：仍是 `EventTiming.DurationOf(e)` → `AbilityAnimDurations.TryGet(e.CardId)`（**这一处是真复用**，`t += DurationOf(e)` 一字未改）。
- ⚠️ 两者的「和」**不必然相等**：`DurationOf` 只覆盖 `activeAbility`（109 行），而展开用的是**全表行**（§九·1）。

## 五、锚点怎么解析（用 ResolveAnimAnchor · null 怎么吃 · EnsureAnimAnchors 补在哪）
