# P3 · 「已有卡牌 ID 的卡，能不能正常触发动画和特效」—— 覆盖率诊断

> 只读代理 P3 · 2026-10-17 · 数字全部**现读**（脚本见 §二，可原样复跑）。
> ⛔ 本文件不改工程、不跑 Unity；结论只覆盖**静态可达性**，不含真机观感。

## 〇、一句话结论

**能触发，但大多数卡播的不是「它自己的」那件。**

- 全池 **1127** 张卡，**每一张**在它可能触发的每个事件上都能解析出一个**通用兜底**特效名，且这些名字**全部在效果库（969 条）里、0 缺失** ⇒ 「什么都不播」的情况不存在
  （**唯一例外 = 抽卡 `draw`**：本地只有 Ultramarines / Sautekh 两族有那件，其余 11 阵营留白并出声；阵亡另走 `CardFeel` 那条，见 §一）。
- 但**逐卡专属**那一档只有 **1010 张卡**有数据行；按「引擎实际会发的事件」筛一遍，**只有 595 张（53%）的逐卡行真的能命中**。
- **415 张卡有逐卡行、但行被挂在它这个卡种永远不会发的事件上**（战术 369 / 防守 30 / 单位 16），**117 张根本没有逐卡行** ⇒ 这两类（合计 532 张）只播通用兜底。
- **卡牌 ID 不是这条链的开关**：事件里带的是**卡名**，`VfxMap` **id / 卡名两把键都收**；实测 **9 张没有 `card_ids` 映射键的卡仍有逐卡行、5 张能命中**，而 **96 张有映射键的卡没有逐卡行**。决定因素是「原版卡 SO 里这张卡自己绑了什么」+「事件时机对不对得上」，不是 ID 有没有。

**关键点（回答「ID 有没有影响」）：** 整条链上**没有任何一步读卡牌 uniqueId**。
`BattleEvent.CardId` 装的是**卡名**（`BattleEvent.cs:202` 的 doc；发点 `RuleCore.cs:2427` / `EffectResolver.cs:1621` 都传 `card.Name`），
而 `VfxMap.TryResolvePerCard` 收 **id 或卡名**（`VfxMap.cs:544–559`，2026-10-15 账 `A2082` 才补的卡名索引）。

## 二、覆盖率（数字 + 可复现命令）

### 2·1 复现脚本（只读；读 4 个文件，不写任何东西）

```python
# 用法： "D:/2/Warpforge_tools/py312/python.exe" -I -X utf8 p3_cov.py
import json, collections, io
R = "d:/4/Unity"
eng = json.load(io.open(R+"/MyGame/Assets/RuleEngine/Resources/cards_engine.json", encoding="utf-8"))["cards"]
rt  = json.load(io.open(R+"/MyGame/Assets/CardPresentation/Resources/card_vfx_by_card.json", encoding="utf-8"))
full= json.load(io.open(R+"/数据/游戏数据/card_vfx_by_card.json", encoding="utf-8"))["byCard"]
m   = json.load(io.open(R+"/数据/游戏数据/card_ids.json", encoding="utf-8"))["mapping"]
lib = {l.strip()[8:].strip() for l in io.open(R+"/MyGame/Assets/Resources/WarpforgeVFX/WarpforgeEffectLibrary.asset", encoding="utf-8")
       if l.strip().startswith("- name: ")}
byid = {c["id"]: c for c in rt["cards"]}
prio = {k:i for i,k in enumerate(rt["confPriority"])}; worst = len(prio)

def chosen(card, ev):                      # 复刻 VfxMap.EnsureLoaded 的「按 confPriority 取第一条」
    for e in card.get("events") or []:
        if e["ev"] != ev: continue
        best, br = None, worst+1
        for x in e.get("es") or []:
            r = prio.get(x.get("c") or "", worst)
            if r < br: br, best = r, x
        return best
    return None

act = {cid for cid,row in full.items()
       if any((e.get("soField") or "").startswith("activeAbility") for e in (row.get("ability") or []))}

def allowed(c):                            # 引擎**实际会发**的事件（判据见 §三）
    if c["type"] in ("tactic","defence"): return {"play"}     # PlayTactic 只发 EvtKind.Play
    s = {"play","deploy","hit","death","trigger","attack_melee","attack_ranged"}
    if c["id"] in act: s.add("ability")    # EvtKind.Ability 只发给场上单位的主动技能
    return s

tab = collections.defaultdict(collections.Counter)
for c in eng:
    evs = {e["ev"] for e in (byid.get(c["id"]) or {}).get("events") or []}
    t = c["type"]; tab[t]["total"] += 1; tab[t]["has_row"] += bool(evs)
    if   evs & allowed(c): tab[t]["reachable"] += 1
    elif evs:              tab[t]["row_but_event_never"] += 1
    else:                  tab[t]["no_row"] += 1
for t in ("unit","hero","tactic","defence"): print(t, dict(tab[t]))
print("TOTAL", {k: sum(tab[t][k] for t in tab) for k in ("total","has_row","reachable","row_but_event_never","no_row")})

miss = {(ev["ev"], (chosen(c,ev["ev"]) or {}).get("n")) for c in rt["cards"] for ev in (c.get("events") or [])
        if chosen(c, ev["ev"]) and chosen(c, ev["ev"]).get("n") not in lib}
print("resolved names NOT in library:", len(miss))
print("has card_ids key:", sum(1 for c in eng if c["id"] in m), "/", len(eng))
```

### 3·1 按卡种（= 引擎会发哪些事件）

| 卡种 | 总数 | 有逐卡行 | 可命中 | 有行但事件不发 | 无行 |

**为什么战术/防守只有 5 张可达：**
`RuleCore.PlayCard` 对非单位卡**开头就分流**到 `EffectResolver.PlayTactic`（`RuleCore.cs:2389`），
而 `PlayTactic` 只发 **`EvtKind.Play`**（`EffectResolver.cs:1621`）。
`EvtKind.Ability` 全仓只有 3 个发点（`RuleCore.cs:7567` `UseAbility` · `:7725` `UseOathAbility` · `:7961` 替代行动
Duty/Pray/Ferocity/Agenda），**全部是「场上单位」的主动能力** ⇒ 战术/防守卡**永远不会**触发 `ability` 那一格。

生成器按「我们拍的」归到了 `ability`）⇒ **战术 372 + 防守 30 = 402 条 `ability` 行永远不播**：
这 402 张卡里 **387 张的唯一一行就是它**，另 10 张虽然还有别的行、但那些行也不可达（推断出来的
`deploy`/`hit` 行）；只有 **5 张**靠自己的 `play` 行命中（`ASH86` / `BL42` / `BL55` / `SAU50` / `SOR51`）。

## 四、缺的那部分到底是什么（五类，各带代表卡与出处）

### ① 原版快照里**没有这张卡** ⇒ 一行都没有（78 张，运行时表全部缺席）

- 大头 = **SpaceWolves 44 张**（该阵营池里共 **68** 张，其中 **44 张**不在全量件 `byCard` 里 ——
  该族 id 是照 PnP 文件号自建的、多数晚于 2022 真值快照；⚠️ 这 68 张**在 `card_ids.json` 里都有键**）。
- 代表：`SW11 Blood Claw`（unit）· `SW5 High Rune Priest`（tactic）· `SW1 Logan Grimnar`（hero）——
  三张在 `数据/游戏数据/card_vfx_by_card.json` 的 `byCard` 里**都没有键**。
- 结果：只播通用兜底。

### ② 原版这张卡**自己就没有 VFX 绑定**（28 张，只有 `_assetRefs` 立绘/语音）

- 代表：`AM61 Defence Batteries`（defence）· `BL37 Abaddons Chosen` · `DA39 Ancient Reliquary`（tactic）——
  `byCard` 里只有 `_assetRefs`，没有 `ability/attack/death/...` 键。
- 这不是缺陷（原版没绑），但**「有 ID」也不会让它有专属特效**。

### ③ 原版引用了、**本地解不出/不在库**（22 条 unresolved 在 20 张卡上；1 条 `inLibrary:false`）

- 代表：`DA60 Defensive Turrets` —— `ability` 那条
  `prefab = null`、`unresolved = "GUID 在 guid_map.tsv 里没有解出具名资产"` ⇒ 运行时整条被丢弃。
- `DA48 Deathwing Assault` 的 `Teleport Trigger Board Effect Only` 在**全量件里**记着 `inLibrary:false`
  （那是 2026-10-15 的数据），但**效果库已于 10-16 补进**（现读 969 条、名字在）—— 全量件的这一列已过期。
- ⚠️ 运行时表**已经把 `prefab = null` 的条目滤掉**（`gen_card_vfx_by_card.py` 的 `rt_noprefab`，现读 22），
  所以**不会**出现「解析到 null 再播空」；表现是**该档留白 → 掉兜底**。

### ④ 事件**没发到**（最大的一类：415 张）

- **`ability` 错位**：原版把 `cardAbilities[].abilityLogic[].cardAnimations[]` 全归到了 `ability`，
  但那张表里真正的 `abilityTriggerName` 分布是
  **`ThisCardPlayed` 696 · 无 143 · `UseSpiritStone` 69 · `UseFaith` 48 · `Unstable` 36 · `Codex` 32 · `Strike` 21 · … ·
  真正的主动技能（`activeAbility`）只有 99 条**。
  ⇒ 这些动画的原版时机是「打出 / 触发 / 耗资源」，我们却只在「主动技能」那一格查 `ability`。
- 代表：`ASH54 Wailing Doom`（tactic，`ThisCardPlayed` → `WailingDoom`）· `AM60 Timely Reinforcements`（defence，
  `ThisCardPlayed` → `GuardSummon`）· `BL3 Chaos Legionary`（unit，`UnitReceivesMarkOfChaos` → `BulletImpact_2shot_trail_chaos`）
  · `GOF57 Ork Nob`（unit，`OtherCardPlayed` → `FlankEffect`）—— **四张的专属件都在库里，但永远不会被播**。

### ⑤ 引擎/播放层**没实现**的那几条（与 ID 无关）

- **同一 (卡,事件) 多条候选被折叠成 1 条**：445 行有多候选，其中 **397 行是「同置信度平票」**，
  当前实现按**文件顺序**取第一条（`VfxMap.cs:465–473`）⇒ 播哪一件**没有判据**。
  代表：`DA48` 的 4 条 `authoritative` 候选，选中的是 `Basic_army_DA`，不是 T05 刚补进来的传送那件。
- **逐卡残骸体**（`remnantBodyPrefab`）今天没接（`A2096`）。
- **飞行单位抬高/浮动**（`A2081`）没做。
- **走位/终点参数**（`endPosOption`/`pointTowardsOption`/`easeCurve`/`screenShake`…）`T05` 第 4 步未接。
- **5 件 `AnimFXModuleAnimation` 的 Exit clip** 播不出（无 `.anim` / `.controller`）。

## 五、ID 是否影响可播放性 —— **明确判定：不影响**

| 判据 | 事实 | 出处 |
|---|---|---|
| 事件里装的是什么 | `BattleEvent.CardId` = **卡名**（`CardDef.Name`） | `RuleEngine/Core/BattleEvent.cs:202`；发点 `RuleCore.cs:2427` / `EffectResolver.cs:1621` |
| 解析层收几把键 | **id 或卡名都收**：先按 id 查，查不到就 `ResolveCardIdOf` 按名换算（重名用阵营钉） | `Core/VfxMap.cs:544–559` |
| 无 id 的卡能不能有逐卡行 | **能** —— 23 张没有 `card_ids.json` 映射键的卡里，**9 张有逐卡行、5 张能命中**（例：`UM_2nd_Company_Terminator` 有 `trigger` 行）。⚠️ 口径 = §二脚本（只有 `activeAbility` 才抬 `ability`）；另 6 张带 `Oath`/`Ferocity` 的（`UM_Phobos_Librarian` / `UM_Scout_Sniper` / `UM_Suppressor` / `UM_Vico_Therbeus` / `SW13` / `SW15`）会因誓约/替代行动发 Ability 而**实际播到**，但那一条是别的触发时机的动画（见 §七·3） | 现读（§二脚本） |
| 有 id 的卡是不是一定有 | **不是** —— 1104 张有 id 的卡里 **96 张没有逐卡行**（64 张全量件里就没有、其中 SpaceWolves 44；28 张只有 `_assetRefs` 立绘/语音；4 张原版条目全解不出） | 现读 |
| 表演闸门里有没有读 uniqueId | **没有** —— `VfxMap` / `CardEffects` / `WarpforgeEffectPlayer` / `CardFeel` 全链无 uniqueId 读取 | 上述源码 |

**所以：**
- 「**有 ID 的卡**」能不能播动画/特效 —— **能播通用兜底**（所有卡都能）；
  **能不能播它自己那件**取决于 ①原版快照里有没有这张卡 ②原版有没有给它绑 VFX ③那条绑定的**时机**是否与引擎发的事件对齐 ④prefab 在不在库里。
- 「**没有 ID 的卡**」**不是**被这条链挡住的 —— 只要**名字对得上**逐卡表（`nm`），照样能取到专属件；
  反之**有 ID 也可能取不到**（ID 与名字都不在表里）。

> 📌 结论按 `595/1127` 说：**约一半的卡（595）能命中至少一条自己专属的行**；
> 其中「有 ID」的 590 张、「无 ID」的 5 张 —— **差别来自卡池构成，不来自 ID 本身**。
