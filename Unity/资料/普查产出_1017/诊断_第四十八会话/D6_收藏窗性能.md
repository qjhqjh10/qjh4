## 三、原版为什么快（反编译判据，⛔ 不是拿我们的常量自证）

全部出自 `d:/2/tools/decomp_full/`（2026-10-18 全量反编译）：

1. **原版滚动视图是「回收池」**：`PolyAndCode.UI.RecyclableScrollRect`。cell **只在 `CreateCellPool` 里 `Instantiate` 一次**（`PolyAndCode.UI.VerticalRecyclingSystem__CreateCellPool.c`；一个 while 循环里 `UnityEngine_Object__Instantiate` + `SetParent` + 入池，之后不再建），且 `ReloadData` 走的是 **`StartCoroutine`**（`PolyAndCode.UI.RecyclableScrollRect__ReloadData.c`）⇒ **异步**，不是一口气同步建完。
2. **换卡 = 改现有 cell 的字段，不重建对象**：`CardCollectionDisplay__RefreshCells.c` 遍历 `RecyclableScrollRect.Cells`，逐格只做 `SetCard`（vtable `0x218`）+ 张数文本 + 灰化/升级高亮；`CollectionCard__Config.c` 同样是「记下数据 + 调 `CardUI.SetCard`」。**整条路径没有 `Destroy`/`Instantiate`/`new Material`。**
3. **卡面本体是预制体里的 uGUI 层**：`BasicCardUI__SetRawCardData.c` 只写字段/文本/计数器；`BasicCardUI__SetCardImage.c` 把 sprite 转给 `CardImageController.SetImage`（uGUI `Image` 换 sprite ⇒ **共享材质，不产生每卡材质**）。对照我们：每卡 ≈10–14 份 `new Material`（`CardView.AddLayer:2817` / `RimMaterial:5977` / 4 份 TMP `fontMaterial`）。
4. **字体是 Static、图集已烘死**：原版三份 `Asar/Pragati/RobotoCondensed SDF` 都是 `m_AtlasPopulationMode = 0`（`Core/TmpFont.cs:21-28` 记录的解包读数）⇒ **运行时零字形栅格化**；我们卡面今天仍以 CJK（Dynamic + Noto）兜底。
5. **刷新还额外延后 1 秒**：`CardCollectionDisplay__RefreshCollection.c` 末尾 `DG_Tweening_DOVirtual__DelayedCall(…, 1, …)` ⇒ 原版连这点刷新都不在开窗那一帧做。
6. 🔴 **原版的逐卡耗时：本地查不到实测**（原版已关服，跑不到可比读数）⇒ 写「查不到」，不猜。

## 四、分步修法

### 第 1 步（低风险、现在就能做、不依赖任何新读数）—— **只建当前页，其余页第一次切过去时再建**

- 改哪：`Shell/CollectionWindow.cs:3047-3052` 那个 `for (p…) tabs[p].Setup();`。落地页是页 0（`:121` 那行 `tabButtons.Click(0)`）。
  做法：`Build()` 只 `tabs[0].Setup()`；其余页在「切页 / 第一次 `PageNode(p)` 被用到」时 `Setup()` 一次（用 `_pageBuilt[p]` 记）。
  ⚠️ 自检兼容：`Editor/CollectionScene.cs` 大量断言假定了四页都建好 ⇒ **非 Play（batch）下保持全建**（`if (!Application.isPlaying) 全建 else 只建当前页`），或在自检入口显式逐个 `Setup`。⛔ 别让自检变成「静默跳过」。
- 预期：**首开 75.5 s → ≈3 s**（只剩页 0 的 2.75 s）；点 Cards 页时仍会卡 51 s（第 3 步再治）。
- 风险：低（不动绘制、不动池、不改判据）。原版旁证：见 §三·1/5（异步 + 延迟刷新）。

### 第 2 步（低风险，照 Cards 页已落地的同一套做）—— **Styles / Cosmo 两页池化**

- 改哪：`CollectionWindow.cs`
  - 页 3：`:1894 RebuildStyleCells` —— 复用 `_cellPool` 那套（键 = `CardId + 语档`；`:1923` 只在未命中时 `Create`；本趟没露头的 `SetActive(false)` 并改名 `CollectionAltArt_parked`）；`RebuildStylesPage:1864` 重建前先清池（照 `RebuildCardsPage:1012` 的做法）。
  - 页 2：`:1278 RebuildCosmoCells` —— 池**整格 GameObject**（不是只池贴图）：键 = 卡背名；命中就只改位姿/uv/激活。
- 先例：Cards 页 `_cellPool:997-1000 / 1052-1147`；卡组编辑 `Deck/DeckRuntime.cs:2789-2960`（按「这张卡」找视图、滚出屏幕才销毁）。
- 预期：页 3 滚动 **17.3 s → ms 级**；页 2 滚动 **3.4 s → ms 级**（开窗那 17.3 s / 3.4 s 仍需第 3 步才能压掉）。
