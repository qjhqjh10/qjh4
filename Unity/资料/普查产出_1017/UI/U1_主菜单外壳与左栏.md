# U1 · 主菜单外壳（主界面 / 顶栏与玩家账户 / 左栏导航 / 运行层）界面普查

> **2026-10-17 · 只读普查代理 U1**。范围 = 主菜单这一屏 + 顶栏/账户 + 左栏 + 外壳运行层。
> 判据优先顺序：原版场景/预制体字段 → 反编译 → 本仓已写好的施工图 → 用户实拍。
> 我们的实现 = `CardPresentation/Shell/{MainMenuRuntime,TopBar,WindowsManager,ShellRuntime,MainMenuWindow,...}.cs`。

## 一、结论摘要

1. **骨架基本齐**：背景渐变、顶栏（玩家名/头像/等级/资源条/4 颗钮）、左栏 5 颗钮、聊天预览、模式卡、三个窗口锚点都建了，几何/图名/字号多数有原版出处。
2. 🔴 **一处高严重度功能缺口：左栏第 1 颗「PLAY / Home」点了没反应** —— 原版它开的是场景内的 `MainMenuWindow`（`closeOtherMenus=1`），我们的 `OnNavClick` 对 `idx==0` 只打一句「还没接」⇒ **从收藏/商店/奖励/社交窗里点 PLAY 回不到主菜单**。
3. 🔴 **一处高严重度交互缺口：`GameModes` 的横向滚动（和视口裁切）整块没实现** —— 原版是 `ScrollRect`（20 列，内容自然宽 11134px），我们 4 列硬摆到 x=2405 ⇒ **练习/教学那一列 90% 在屏外、鼠标滚轮/拖拽都到不了**。
4. **左栏两件缺动态**：① `NavigationPanelController.Toggle`（卡组编辑/排位窗打开时整栏左移 −1162.77px/0.3s 收起、回来时滑回）完全没做；② 选中高亮是「建一颗/撤一颗」硬开关，原版 5 颗常在、由 Toggle 淡入淡出。
5. **顶栏账户块**：名字/头像/等级圆牌/资源条都在；**7 颗红点全部只画了底图、没有 `OneText` 计数文本**（原版 fontSize 34 / auto 18–34 / base 36 / 白）。
6. **运行层**：窗口开/关/叠/压背景/ESC/键盘导航已做；缺 **安全区真正生效**（两个 zone 是空节点，主菜单/窗口都不在其下）、**离屏烘焙+UI Blur 背景**、**教程聚光灯 `ScreenHighlightPosition`**、**进战斗的 `LoadingMenu` 黑场过渡**、**关窗默认音效**。
7. **分辨率口径与原版不同**：原版 `CanvasScaler match=0`（宽度优先、窄屏变高），我们 `LayoutSpace` 固定高度（窄屏裁左右）。
8. **三处记录已过期，须就地订正**：① `Loading text` 说「本地没有词条」⇒ 官方中文表 2026-10-14 已解出 `MenuLogin/Intro/Loading`；② 资源条说「只导了 2 张图标」⇒ `Resources/Art/ui_menu/` 现有 6 张；③ T02 说「模式卡底部倒计时不是缺陷、别建」⇒ 10-13 的 `A1480` 记录与 prefab 字段/用户实拍都指向「要做」。

**最该做的 3 件**：① PLAY/Home 回主菜单；② 模式卡横向滚动 + 裁切；③ 左栏收起/放回（`NavigationPanelController.Toggle`，含 `MainMenuWindow.ToFocus` 恢复）。
