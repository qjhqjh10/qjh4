## 一、结论摘要

1. **设置窗主体已很完整**：原版五页（General / Media / Account / Graphics / Support）全部建了，另加我们自加的 Online（栏里 5 格、Online 从 General 页进）——`Shell/SettingsWindow.cs:137,1637-1642`。**真正缺的是三个下拉**：画质档仍是“点一下换下一个”（原版是 TMP_Dropdown 列表）、`WindowMode Selector` 与 `Text In Hand Selector` 整行没建（`SettingsWindow.cs:3551/3806`、`:4504`、`:3564`）。
2. **卡详情窗**的放大卡/相关卡/异画/关闭主体都在（`Shell/CardDetailPopup.cs:568`、`Core/RelatedCards.cs`），剩余偏差就是 `T05` 那 6 条（lore 印效果文字、文字块偏高 20px、底板看不见、`Current Style` 印字、Lock Icon、Buy Original Card 低 42px）。**新发现：卡牌来源窗 `WhereToGetCardsPopup` 整窗没建**（全仓 `WhereToGet` 0 命中）。
3. **通用确认/提示族已收口**：`GenericPromptWindow`→`PromptPopup`、`MessagePopupWindow{,_2Buttons}`→`PopUpGameWindow`、`MessagePopupWindowDuel`→`DuelPopupWindow`、`GenericOptionsPanel` 都建了（`Shell/PromptPopup.cs:50`、`PopUpGameWindow.cs:84`、`DuelPopupWindow.cs:34`、`GenericOptionsPanel.cs:76`）。**toast 只剩 `A1141` 那一族（任务/等级/经验飘窗 6 个 prefab）没建**；另有一条跨全部窗的缺口：**默认开/关窗音效没接**（`GameWindow.cs:76,469` 只有显式 `openSound`，`useDefaultCloseSoundIfNull` 无消费者）。
4. **加载/错误**：战斗侧 `LoadingMenu` 已建（`BattleDriver.cs:10033+`，A2109），错误横幅走 `MessageToast` + `ErrorMessageBanner`（菜单档已分档）；大厅断线弹窗+撤匹配 A902 已落。**壳侧 `LoadingMenu` / `Loading Controller` 没建**，现用 `BlockingOverlay` 替代，且转圈只有 **128 px**，原版 `Animated Loading Image` 存档 **270.4×270.4**（`BlockingOverlay.cs:39` vs 场景 `Loading Controller`）。
5. **匹配窗很完整**：`SearchingOpponentWindow`、`Searching Oponent Popup`、四扇入口窗都在；12 秒 bot 链是原版离线真值（`阶段二_战斗入口_原版规格.md:345-352,374-379`）。遗留是 `T08 A1501`（练习窗英文）与 `T01 A1535`（Deck List Drawer 族）。
6. **教程**：`Tutorial Mode Menu`（`TutorialModePopup.cs:83`）与战斗内 `TutorialOverlay`（`Battle/TutorialOverlay.cs:167`）都建了；**`Tutorial Message Window PopUp` 整窗没建**。
7. **档案/排行**：`Player Profile Window` 六页全建（`PlayerProfileWindow.cs:77`、6 键 `:160-165`）、成就页（`AchievementsMenu.cs:45`）、四个排行榜（`LeaderboardWindow.cs:47`）都在。**排位赛季三窗没建**（`Ranked Division Change Window` / `Ranked New Season WIndow` / `Ranked Season Ended Window`）。
8. **事件窗最明显的缺口是“活动说明弹窗”**：四扇事件窗都在，但 `Help Button` 只打一句日志（`LiveOpsEventWindow.cs:945-952`）；原版有 **`BaseEventPopup` 一整族 6 个 prefab**（Base Event / Event Help ×2 / Liveop Event Help / Full Screen Event Announcement / Base Expiration）。
9. **其他整窗没建的独立小窗**：`WelcomeScreen Alpha`（WelcomePopup，静态文案齐全）、`Rate Popup`（RatePopup，1–4 星/5 星）、`Item Display Window`、`Give Feedback Popup menu`。`Sunset Popup` 属“过期活动”，按用户边界不做。
10. **最该做的 3 件**：① `BaseEventPopup` 事件说明族（玩家点了 Help 现在没反应）② 设置窗三个下拉（画质行为 + WindowMode + Text In Hand）③ `WhereToGetCardsPopup`（卡牌来源窗，卡详情族唯一整窗缺口）。
