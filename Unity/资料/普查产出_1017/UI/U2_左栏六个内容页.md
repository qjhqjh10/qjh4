# U2 · 左栏六个内容页（收藏/商店/锻造厂/战役/日常/奖励）界面普查

> 2026-10-17 · 只读普查（未跑 Unity、未改任何产品/文档）。判据优先级照铁律 2：
> **反编译方法体 > 解包资产实读 > 本仓施工图 > 用户实拍**；实拍只判「有没有 / 大概什么样」。
> **范围口径**：左竖导航的 COLLECTION / SHOP / REWARDS 三扇窗，加奖励窗内 `Missions` / `Forge` / `Campaign` 三页，
> 加奖励弹窗族（`Reward Window` / `Daily Reward Popup` / `Daily Streak Popup` / `Booster Info Popup` / `Booster Pack Open Window` / `Campaign Reward Window`）。
> ⚠️ 原版**没有**「六个独立页」：锻造厂 / 战役 / 日常是**奖励窗的三个页签**，奖励是**一扇宿主窗 + 若干弹窗**（本报告照这个真实结构写）。

## 一、结论摘要

1. **六页主体全部已建**：本范围找不到「整页没建」的界面；缺口已下沉到**细件、动态值、交互**三层。
2. **最普遍的一类缺陷 = 倒计时全是死字符串**：商店 `12h 24m`、战役 `Siguiente: 5d 20h 15m`、日常三处 `Resets in 12h 34 m` 等
   均写死在代码里；原版统一由 `TimerDisplay` 每秒（按 `targetFrameRate` 帧）从服务器时间重算。
   **全仓只有规格/显隐规则提到这个组件，没有任何「实现倒计时」的任务或账**。
3. **战役页 `Premium Panel` 缺三态**：我们五件（底图/标题/点数/按钮/计时器）一次性全建、恒显示；
   原版 `ChangeState` 按 state 0/1/2 关按钮、关点数行、只留标题+倒计时。实拍正好是 state 2。
4. **锻造页奖励卡只有一张裸图**：原版是卡框 + 品阶 + 阵营名行 + 数量/名字行 + 底部阵营小徽（实拍逐张可见）。
5. **收藏页 T03 的状态表已大面积过期**：`A1503` 的五条（游戏模式图标/名字条高/卡背画序/军队顺序）在 2026-10-11 就已落地，
   但表上仍写 `✗`；真正还开着的是 `A1529` `A1536` `A1642` `A1644` `A1509`。
6. **收藏·卡背页点一张卡背仍是死路**（`NotifyNotBuilt`）；原版走 `OnItemSelected` 开详情/装备窗，本仓普查只标了「不确定」。
7. **日常/战役的信息圆钮（`40K_generic_bt_info`）全都没接 tooltip**；原版每颗都挂 `EverguildTooltipTrigger`（锻造页那颗已接）。
8. **商店/战役/日常的「数据」仍是我们自建**（服务端 PlayFab / LiveOps），这部分不算缺陷，但不能当原版数字。
9. **奖励弹窗族基本齐**：`Reward Window`（含领取粒子）、`Daily Reward Popup`（四态）、`Daily Streak Popup`、两扇开包窗、战役奖励窗都已落地。
10. **最该先做的三件**：① 跨屏 `TimerDisplay` 等效件；② 战役 `Premium Panel` 三态；③ 锻造奖励卡整层（`A816`）。
