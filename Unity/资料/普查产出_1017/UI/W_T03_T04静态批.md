## 四、断言（新增 7 条，全在 `Editor/CollectionScene.cs` §A1642）

| # | 断什么 | 取法（关键） | 改坏法 ⇒ 红 |
|---|---|---|---|
| 1 | `Decks Tab` 是 `Select Deck Tab` 的**直接孩子** | `page0.Find("Decks Tab")` | 不建这一层 |
| 2 | `Collection Display` 是 `Decks Tab` 的**直接孩子** | `decksTab.Find(...)` | 不建 / 挂错父 |
| 3 | `Deck Scroll View` 是 `Collection Display` 的**直接孩子** | `disp.Find(...)` | 退回挂 `page` |
| 4 | `Deck Filters` 是 `Collection Display` 的**直接孩子** | `disp.Find(...)` | 退回挂 `page` |
| 5 | `Empty Collection Warning` 在 **`Deck Scroll View` 之下** | `deckSv.Find(...)` | 退回挂 `page`（⚠️ 别的格用递归 `FindChild` ⇒ 只有这一条抓得住） |
| 6 | `Header` 是 `Select Deck Tab` 的**直接孩子** | `page0.Find("Header")` | 不建这一层（我们改前就是） |
| 7 | `Header` 矩形：中心 `CheckAt(167.2,1920.0,70.9,155.9)` + 宽 `1752.83` + 高 `85.00`（`sizeDelta × 108`） | 期望值 = **原版字面量** | 摆错位置 / 尺寸写错 |
| 8 | `Header.GetSiblingIndex() == page0.childCount − 1` | 兄弟序 | 删掉 `SetAsLastSibling()` ⇒ 它停在**第一个** |

**为什么层级用 `Transform.Find` 而不是 `FindChild`**（这条单独写清楚，防止下一个会话「统一」掉）：
`MenuCheck.FindChild` 是 `GetComponentsInChildren` + `name ==`（**递归**）⇒ 拿它断「层级」时，
**「挂 `page`」与「挂 `Collection Display`」两种状态它都取得到** = 弱断言。`Transform.Find(name)` 只找**直接子件** ⇒ 层级错了就取不到。
另外跨层路径（`"Decks Tab/Collection Display/Deck Scroll View/Viewport"`）也是同一道理，且顺带把三层容器钉在 A435 那几条上。

**为什么第 5 条单列**：`Empty Collection Warning` 在**四个页各有一份同名节点**（原版如此、矩形逐页不同），
`DeckEmptyShown` 已经限定在 `PageRoot(0)` 里递归找 ⇒ 它分不出「挂 `page`」与「挂 `Deck Scroll View`」；本条第 5 格补的就是这一半。

**没有引用的实现常量**：本 §的期望值全部是原版字面量（`167.2 / 70.9 / 1920.0 / 155.9 / 1752.83 / 85.00`），
⛔ 不读 `CollectionWindow.HdrL…` / `TabsRect`（那是自证）。

## 五、没查清 / 本批没做的（逐条 + 为什么）

1. **`Header ▸ Filters`（`GridLayoutGroup`）那一层没建** —— 原版树里 `Clear Filter Button` 装在它下面
   （`Filters` 位于 592.2,70.9→592.2,155.9，宽度算出来 0；`Clear Filter Button` 按锚点落回 612.2）。
   **不建的理由**：本页 `Deck Filters ▸ Filters` 已经叫 `Filters`（`CollectionWindow.cs:3359`），
   再在 `Header` 下建一颗同名节点 ⇒ 全页两颗 `Filters` ⇒ `FindChild`（按名字取**第一个**）会取错那一棵。
   要建的话必须同时给 `Deck Filters ▸ Filters` 改名或全仓改取法 —— **那是另一笔账，不在本批白名单范围内改得干净**。
2. **`Header ▸ Filter Toggle` 包一层容器没做** —— 原版是 `Filter Toggle`(50×50) ▸ {`label`, `icon detail`}，
   且 `label` 的矩形（437.2..587.2）**在父件框之外**。我们今天是三颗平铺（`Filters Button` / `Filters Icon` / `Filters Label`）。
   同 1：`BuildFilterHeader` 是**四页共用**，给一页加这层会让另外三页的树形与它不一致（另外三页的页头节点名原版不叫 `Header`，
   本批没逐页现读 ⇒ 不动）。
3. **`Header` 内部兄弟序与原版不同** —— 原版 = `Filter Toggle` → `Control Buttons` → `Separator Line` → `Filters`；
   我们 = `Filters Button` / `Filters Icon` / `Filters Label` / `FiltersHit` / `Separator Line` / `Clear filters` / `ClearFiltersHit` / `Control Buttons`。
   **影响 = 0**：本窗所有画图件都显式设 renderQueue，兄弟序不决定谁盖谁。等 1、2 建了再一并对齐。
4. **另外三页（Cards / Cosmetics / Styles）的页头容器** —— 原版那三页的页头节点名**本批没有逐页现读**
   （报告只给了 `Select Deck Tab`），且它们的页头在 `BuildFilterHeader` 里与 Deck 共用同一条语句 —— **本批不动**。
5. **`A1273` 的闸门（实机挂几张卡）仍是判据缺** —— 见 §三；本批只把「给定 n 时的行宽」定死，没有擅自加闸。
