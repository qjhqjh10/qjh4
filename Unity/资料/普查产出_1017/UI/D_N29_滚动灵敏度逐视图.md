## 四、改法（给写手）

1. `Shell/MenuScroll.cs`：`NotchK` 改成**每实例一份**灵敏度（构造函数/`Build` 参数，默认值照调用点给）。
   原版语义 = uGUI `ScrollRect.scrollSensitivity`（每格像素 = 值 × 滚轮 delta，Unity 默认 1.0）。
   ⇒ 我们的「一格 = N px」应直接取原版值（原版也是 px/格；`A1543` 已按 100/50 落地并验过这条口径）。
2. **逐调用点**：按上表传参；表里没有的（如 MissionsTab）**先现读再传**，⛔ 别套 0.4。
3. 断言：`Editor/*Scene.cs` 里对每处 `MenuScroll` 断「灵敏度 == 原版字面量」（照 `A1543` 的写法）。
4. ⚠️ `N29` 与 `A1543` 是同一族：`A1543` 只改了卡组编辑；本表把它扩到全壳。

1. **MissionsTab 的滚动**：143 条里没匹配到 `MissionsTab`/`Daily Missions` 的 ScrollRect —— 可能它用的是 `MenuScroll` 之外的自定义滚动，或 prefab 路径不含 scroll。写手必须单独核（别假设）。
2. 上表「1.0」的那些**是不是真的可滚**：uGUI 默认值是 1.0，但部分节点可能是 `InputField` 自带的（已标注）。
3. 同一族多实例（`Card Filters` 50 vs 1.0、`GeneralDetails` 50 vs 1.0）⇒ 按**用途/父链**取，⛔ 别按名字取。
