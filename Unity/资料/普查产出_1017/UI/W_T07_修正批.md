## 三、`A1272`（`count` 宽度 / 对齐）三步

全部在 `Shell/MissionsTab.cs` 的 `BuildRewardCell`（唯一一份实现，三个宿主共用）。

| 步 | 改法 | 依据 |
|---|---|---|
| ① 每日行（竖向变体）**去掉无条件 `AlignL`** | `AlignL(cLb, c);` → **`if (sideIconW > 0f) AlignL(cLb, c);`**（竖向档走我们默认的「行盒锚在框心」= Center） | 原版每日行 `count` 的 `m_HorizontalAlignment = 2 (Center)`（横向变体才是 `1 Left`） |
| ② 登录卡两格的**主轴落点** | 新增第 12 个形参 **`sidePadL`**（设计空间原值）；`off = sidePadL + (r.W − sidePadL − (icon+gap)) × alignT`、`off2` 同式加 `numW`。调用点：第 0 格 `sideAlignT: 1f, sidePadL: -20f` · 第 1 格 `sideAlignT: 0f, sidePadL: 10f` · 骷髅卡不变（`0.5f` / 缺省 `0`） | uGUI `GetStartOffset` = `padL + (innerSize − totalPref) × alignmentOnAxis`；`innerSize = 格宽 − padL`（`padR = 0`）。三格亲读：`MiddleRight` + `m_Padding.m_Left −20` / `MiddleLeft` + `10` / `MiddleCenter` + `0` |
| ③ `count` 的**自框宽 = `numW`** | `c2 = new PxRect(dh2.x2 + sideGap, r.y1, dh2.x2 + sideGap + numW, r.y2)`；随后 `SetWrapWidth(R(c2).W)` → `SetWrapping(false)`（原版折行 0）→ 最后才 `AlignL` | 原版 `count` 挂 `ContentSizeFitter h:PreferredSize` ⇒ 框宽 = `preferredWidth`；我们是「图标右 → 格右」整条（偏宽） |

顺序（防「量宽 ↔ 缩字」回路）：**建标签（临时宽框）→ 量 `numW` → 重摆图标 → 重设字框宽 → 再左对齐**。
`numW` 量不到（`PreferredWidthPx` 返回 0，它自己出声）⇒ 整块**原地不动**（保留旧档），⛔ 不猜。

套出来的三格落点（`'100'` ⇒ `numW = 50.29` 设计）：

- 登录卡第 0 格：`off = −20 + (182.5 − 110.29) = 52.21` ⇒ 图标 `52.21..107.21` · count `112.21..162.50`（右边 = 格右）
- 登录卡第 1 格：`off = 10 + 0 = 10` ⇒ 图标 `10..65` · count `69..119.29`
- 骷髅卡：`off = (325 − 111.29)/2 = 106.855`（与 A1289 的结果一致）
