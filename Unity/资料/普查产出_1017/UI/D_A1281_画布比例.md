# A1281（图像 px → 画布 px 的绝对比例）—— 静态判据（2026-10-17 · 主对话现核）

> 结论：**不存在「一个固定比例」**。比例是**屏幕分辨率的函数**，原版口径已查到。

## 一、判据

`bundle_scenes_scenes_mainmenuwarpforge/MonoBehaviour/MonoBehaviour_2577.json` = `Game UI` 的 `CanvasScaler`：

| 字段 | 值 | 含义 |
|---|---|---|
| `m_UiScaleMode` | **1** | `ScaleWithScreenSize` |
| `m_ReferenceResolution` | **1920 × 1080** | 参考分辨率 |
| `m_ScreenMatchMode` | **1** | **`Expand`**（不是 MatchWidthOrHeight、不是 Shrink） |
| `m_MatchWidthOrHeight` | 0 | 在 `Expand` 档**不生效**（只在 `m_ScreenMatchMode = 0` 时用） |
| `m_ReferencePixelsPerUnit` | 100 | —— |
| `m_ScaleFactor` | 1.2 | 在 `m_UiScaleMode = 1` 下**不生效** |

⇒ **画布缩放系数**（uGUI `CanvasScaler.HandleScaleWithScreenSize` + `Expand`）：
```
scale = min(Screen.width / 1920, Screen.height / 1080)
画布 px = 屏幕 px / scale
```
- 1920×1080 ⇒ scale = 1.0（截图与画布 1:1）
- 2560×1440 ⇒ scale = 1.3333
- 3440×1440 ⇒ scale = 1.3333（宽度被高度限制，左右多出的部分是**加宽**而非放大）

## 二、对 `A1281` 的结论

- 「绝对比例没定死」**不是缺判据，是缺【截图分辨率】**：量任何一张实拍前，先记下它的分辨率，
  用上面那条式子换成画布 px。
- ⛔ **别再用「图像 px ≈ 画布 px」的隐含假设**（1280×720 的截图会差 1.5 倍）。
- 我们自己的壳：`LayoutSpace` = **可见高度固定 10 世界单位、宽随宽高比展开**（1080 px = 10 单位）
  ⇒ 与 `Expand` **同构**（高度是基准、宽度扩展）—— 这一半两边一致，**不需要改**。

## 三、`A1273`（`Daily Missions` 有多宽 / HLG 分配）

- 同一份 `CanvasScaler` 口径适用：它与 `A1273` 的「两帧不同、宽不可比」是同一件事 ——
  **两帧截图分辨率不同**时，先用 `scale` 归一再比。
- ⚠️ `A1273` 另一半（**页内实例 vs 作者态模板**、HLG 分配）仍需单独按 prefab 现读；
  **本文件不替它下结论**。
