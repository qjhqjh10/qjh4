## ① 改了什么（`Core/RuleCore.cs:1588`）

`DeployFree` 在 `ps.Board[dst] = unit;` → `Auras.Recompose(ctx);`（`:1575`）之后，补上**与 `PlayCard:1247` 完全相同**的一句：

```csharp
unit.Exhausted = !HasDeployExemption(unit);   // 判据共用：方法体在 `RuleCore.cs:1175`（只此一处）
```

理由（同 F6）：`new UnitState` 的 `Exhausted` 是**构造时**按**卡模板**关键词算的快照，而光环是**在那之后**才把
`fast`/`flank`/`ferocity` 挂上来的（`Core/Aura.cs:653` `AddAuraKeyword` —— 它**不碰** `Exhausted`）⇒ 不重算＝
「**光环给了侧翼、单位却动不了**」（`Has("flank")` 为真、单位仍疲劳）。位置与 `PlayCard` **逐字对齐**
（手牌加成 → 光环重算 → **这次重算** → 广播 / `ResolveDeploy`，两条路一致）。
⚠️ **只重算刚落地的这一个 `unit`**，⛔ 不遍历全场（遍历会把本回合**已经行动过**的单位放活＝一回合动两次）。
