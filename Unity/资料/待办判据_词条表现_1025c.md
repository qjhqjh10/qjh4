## 1. 列 ② 的五个码（「被赋予 / 获得」时要不要即时生效）

原版的攻击许可是**两个缓存位**：`canAct`（`+0x230`）与 `canAttack`（`+0x23C`），由 `CardScript.ActivateMinion` 算一次；所以**中途改变关键词必须有人重算**，否则会「关键词给了、这一回合照样动不了」。
（判据：`CardScript__ActivateMinion.c:14-82` · `CardScript__CanAttackNow.c:57-74` · `CardScript__AddEffect.c:570-572` · `d:/2/tools/il2cpp_out/dump.cs:35454-35458` 的字段偏移）

| 码 | 含义 | 谁负责 |
|---|---|---|
| **A** | **授予 / 摘除时必须重算 `canAct`/`canAttack` 两个缓存位** —— 原版有硬编码重算链 | 原版 `AddEffect case 3 → AddTraitSilently:570-572`（`fast`/`flank`）→ `UpdateSummonSicknessAnims.c:20` → `ActivateMinion`；`ferocity`/`oath` 在 `ActivateMinion.c:43-69` 只抬 `canAct` |
| **B** | **不需要重算** —— 攻击许可 / 目标合法性 / 结算数值都是**每次现读**关键词 | 我们 `RuleCore.IsValidTarget` / `CanAttackNow` / `FieldAttack` 全部 `u.Has(...)` 现读 |
| **C** | **必须重刷视图**：徽标 7 格 · 状态框集合 · 面朝下 · 飞行高度 | 原版 `UpdateTraitIcons` + `CleanStatusAnims`（`AddEffect.c:667-671`）；我们 `SyncBoard` → `TraitFrames.SyncKeywords` / `Badges.For`（`BattleDriver.cs:24945`、`:26262-26280`） |
| **D** | **需要 `Auras.Recompose`**（只有改了棋盘的才要；关键词授予本身不改棋盘） | `Core/Aura.cs` 的 `Recompose`；9 个棋盘写入点，见 `CLAUDE.md` §三 |
| **E** | **授予那一刻要写引擎字段 / 播一次广播 / 出声**（不是视觉层） | 原版 `CardScript__AddEffect.c:570-660` 那一串逐 trait 的 `if`（下表逐条抄了） |

## 4. 「现池」那一列是怎么算出来的（可复跑）

```bash
python -I -X utf8 - <<'EOF'
import json,re,collections
d=json.load(open(r'D:/4/Unity/MyGame/Assets/RuleEngine/Resources/cards_engine.json',encoding='utf-8'))
keys="""fast flank vanguard giantkiller stealth summonrift flying armour shield dodge stun blind
survivor bastion sacrifice droppod poisoned resistant cantattack longrange sneakattack terror sniper
darkpact rally strike slay backlash penitence doublerage mob regiment unstable ecstasy destroyer
sabotage cruelty ability waystone artifice agenda ferocity oath bloodthirst pray duty codex
spiritstone uprising teleport stimulation ambush pack sentry shuriken blast concussive stomp swarm
synapse tide companion talent ephemeral remnant regeneration markerlight huntmark camouflage
vulnerable noncombatant unstunnable unstoppable sentinel berzerk maintenance landing jam tainted
ward precognition piercing syphon coward relentless resolution firststrike combo support large
mekaniak""".split()
keys=sorted(set(keys),key=len,reverse=True)
cnt=collections.Counter()
for c in d['cards']:
    s=set()
    for k in (c.get('keywords') or [])+(c.get('cardTraits') or []):
        n=re.sub(r'[^a-z0-9]','',str(k).lower())
        for K in keys:
            if n.startswith(K): s.add(K); break
    for k in s: cnt[k]+=1
for k in sorted(cnt,key=lambda x:(-cnt[x],x)): print(k,cnt[k])
EOF
```
⚠️ 它只数 `keywords` ∪ `cardTraits`（**印成词条**的那一批）；`desc/descZh` 里以**效果文字**形式出现的另注（`stun 30` · `blind 6` · `hunt mark 22` · `markerlight 15` · `spirit stone 37` · `dark pact 37` · `vulnerable 29`）。
