## ② 接口形状（`Core` 侧只暴露一件事）

```csharp
// Unity/MyGame/Assets/RuleEngine/Core/IAiScorer.cs
public interface IAiScorer
{
    float ScoreAttack(BattleContext ctx, int side, int slot, int foeSlot, bool ranged);
}

public static class AiScorerHook
{
    public static IAiScorer Scorer;      // 注入点；null = 没装
    public static bool Installed { get; } // 调用方用它选「走钩子 / 走回退」
}
```

**为什么是这五个参数**（判据不是我们发明的，是原版那一段用到的全部输入）：

| 参数 | 原版出处 | 说明 |
|---|---|---|
| `ctx` | —— | 局面（棋盘 / 关键词 / 能量 / 疲劳…） |
| `side` | `AI__SelectBestAttackAction.c:24` 的 `*(actingCard + 0x40)` | **出手方是显式的一维**，不是「隐含 = `ctx.Active`」 |
| `slot` | 同上（`action.actingCard`） | 出手单位所在格 |
| `foeSlot` | `action.targetCard` | 目标格（在 `1 - side` 那一方） |
| `ranged` | `actionType ∈ {1 近战, 2 远程}`（`:41-45`） | 近战 / 远程两档各算一次分 |

**刻意不做的三件事**

1. **不把 `AiAction` 传进来** —— `AiAction` 是 `Data/` 的类型，传它就等于 `Core` 依赖 `Data`。
2. **不在这里缓存分数** —— 评分依赖当场局面；接口只保证「同一输入 → 同一分数」（确定性）。
3. **不用「返回 0」表示「没装」** —— 0 是**合法分值**（原版「打不死的小兵」就落在 0 附近）。
   判据 = 自带 `Installed` 位，⛔ 别让「没接上」静默变成「全都一样好」。

**注入有三条入口**（`Data/SimpleAI.cs`，都调同一个 `InstallAiScorer()`，幂等）：

1. `static SimpleAI()` 静态构造 —— 第一次用到 `SimpleAI` 时；
2. `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]` —— 进 play 模式 / player 启动。
   **这一条是必需的**：狂暴强制出手发生在**玩家回合结束时**，AI 可能**一次都还没动过**
   （先手第 1 回合），只靠 ① 会漏掉那一回合的选靶；
3. 宿主显式调 —— `-executeMethod` 批处理**不会**触发 ②，自检里显式调一次。
