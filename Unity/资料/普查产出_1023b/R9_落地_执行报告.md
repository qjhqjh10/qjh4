## 二、落地的算式（照抄判据，一行没改）

```text
T   = t × frequencyGain + phase          // 三条带共享同一个 T（不是每带各加相位）
u_i = 带i.Frequency × T
带i = Constant == 1 ? Amplitude × 0.5 × sin(2π·u_i)
                    : Amplitude × (Mathf.PerlinNoise(u_i, 0) − 0.5)
输出 = (Σ_{i=0..2} 带i) / ShakeBandPeak     // 0.149，别改
```

`phase` = 原版 `m_StartTimeOffset` = `Random.Range(−1000, +1000)` ⇒ 我们用 `System.Random` 派生
（工程红线「对局可复现」，区间与均匀分布照原版）。

## 三、公式核对数值（手算 = 断言期望）

| 场景 | 输入 | 手算 | 断言 |
|---|---|---|---|
| `Constant=1` 单带（f=1, A=1, gain=1, phase=0） | t=0.25 ⇒ u=0.25 | `0.5·1·sin(π/2)/0.149` = **+3.3557** | ①（±1e-4） |
| 同上 | t=0.75 ⇒ u=0.75 | **−3.3557** | ① |
| 同上 | t=0.50 ⇒ u=0.5 | `sin(π)=0` ⇒ **0** | ① |
| `Constant=0` 单带（f=1,A=1,gain=1） | u = 0.13…0.78（6 点） | `(PerlinNoise(u,0)−0.5)/0.149` | ②（同时 ≠ `(PerlinNoise(0,u)−0.5)/0.149`） |
| 三带相加（f=1/2/3, A=1/1/1, c=1） | t=0.125 ⇒ u=0.125/0.25/0.375 | `0.5·(0.70711+1+0.70711)/0.149` = **8.1014**（单带最大只有 3.3557） | ③ |
| 默认信号（Y 三条带 1/0/1） | 9 个 (t, phase) 点 | 按算式**独立实现**一遍逐点相等 | ④（<1e-5） |
| 默认信号值域 | 401 个采样 | 峰值 = `0.0745/0.149` = **0.5** | ⑤（≤0.55 且非常数） |

**「峰值减半」的手算复核**（原版 → 我们的单位）：
原版 `pos` 三带合峰 = `0.5·(0.059+0.040+0.050)` = **0.0745** → `×(|velocity|=1 × m_AmplitudeGain=2.0×0.28284)`
= 0.04215 → 旋转后竖直分量 `×0.7071` = **0.0298** 原版世界单位 → `×73.1/108` = **0.0202** 我们的世界单位。
旧实现峰值 = `0.04 × 1` = 0.04（**1.98× 偏大**）；新实现 = `0.04 × 0.5` = **0.02** ⇒ 落在原版值上。

**相位改动对既有断言的影响（已核算）**：`BattleScene` 里 `ShakeCamera(..., 4242)` 那条先断言
`|n0| > 0.05`。新口径下 `phase(4242) = −1000 + 2000×0.85442606 = **708.8521**`；
两条正弦带贡献 `n0 = **−0.3134**`，Perlin 带再加 ±0.1342 ⇒ `|n0| ∈ [0.179, 0.448]` ⇒ **稳过**。
（`System.Random` 的派生实现已用公开已知值校验：seed 0 的首个 `Next()` = 1559595546、
`NextDouble` = 0.7262432699679598。）

## 六、没查清 / 明确没做的部分

1. **`FromToRotation(Vector3.down, velocity)` 的竖直符号仍在用我们自己的 `verticalSign`**。
   判据 §2·5/§五·6 说原版 raw **−Y 指向 velocity** ⇒ 挨打（direction y=+0.2）原版相机是**朝下**的，
   与我们现在「相机向上抬」相反。**本轮没改**：它不在本次「4+1 处」范围内，而且会翻掉
   `BattleScene` 现有两条符号断言（19710-19722）与真机观感 ⇒ 要改需用户/主对话拍板，另立一条。
2. **`OrientationNoise`（角度抖动）不复刻** —— 2D 版已知简化（判据 §五·6、§六·5），数据已收进 json 备查。
3. **`Mathf.PerlinNoise` 允许轻微越界 [0,1]**（判据 §六·2）⇒ 我们**不 clamp**，照原版。
4. **Cinemachine 精确 patch 号仍未知**（只知道 2.9.x / `915237edaa40`）；不影响算式（全部来自机器码）。
5. **`BattleScene` 旧断言 `notPeak`（`:19813` 附近）现在恒真**：它原本验「旧正弦实现 t=0 恒为 1」，
   新值域 ≤0.5 ⇒ `|x−1| ≥ 0.5 > 0.02` 必然成立。**仍然通过、不再是有效判据**（没有被它掩盖的问题：
   同一节的 ④ 已经用逐点参考实现覆盖了「不许退回旧式」）。是否删改由主对话定（本代理只被授权「只加断言」）。
6. **`ShakeCameraForHit` / `ShakeCameraForLand` 没显式传 preset 参数**：它们的 preset
   （`Shake Hit Small` / `Shake Land on ground`）的 `frequency/attack/sustain/decay` **与默认值逐位相同**
   （0.05 / 0 / 0.1 / 0.3 ⇒ 0.05 / 0 / 0.1 / 0.3），所以用默认参是真值、不是省略；已在 `ShakeCamera` 的注释写明。
7. **`Request` 每次都带 `SignalRec` 引用**（不深拷）——`Resolve` 每帧都可能调，避免复制 3×3 表；
   缓存表在 `Signals` 里是静态的，只读使用。
