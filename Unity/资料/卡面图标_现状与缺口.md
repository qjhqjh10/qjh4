## 一、原版卡面上的图标（照成品卡图 + 解包资源核过）

**总则**：图标全部**嵌在正文句流里**，不是独立一行；**关键词类一律「图标 + 紧跟英文词」**
（`【翼】Flying.`）；只有 **数值 / 资源类**图标后面没有词（`+2`【拳】、`Give -2`【枪】）。
图标直径 ≈ 40 px（卡宽 900 的 4–5%）。

| 类 | 例 |
|---|---|
| **近战数值**（粉拳圆徽） | `… gains +1`【拳】` and …` |
| **远程数值**（紫枪圆徽） | `Give +1`【拳】`, +1`【枪】` and +1 Health…` |
| **行首付费/资源前缀** | `1`【绿圈1 = 灵魂石】`: Gain Shuriken 2 this turn`（灵族）· `8`【金太阳 = 信仰】`: Deploy an additional Battle Sister`（修女会）· `⑤`【灵魂石 5 档】 |
| **关键词前缀** | `【盾】Armour 1.` · `【闪电】Rally:` · `【骷髅】Backlash:` · `【卡】Talent:` · `【齿轮】Artifice:` · `【碎卡】Ephemeral` … |
| **触发前缀** | `⚡ Rally:`（= rally 图标）· `💀 Backlash:`（= backlash 图标） |
| **阵营资源** | 暗黑天使任务点（`gain`【带数字的徽章】）· 灵魂石 · 信仰 |

**⚠️ 四件容易想当然、实际不是的：**

1. **原版没有「关键词单独一行徽标」这回事**（卡面上）—— 关键词就是正文里的「图标 + 英文词」。
   **但棋盘上的单位卡有**：`BattleCardUI.boardTraitIcons`，左 3 + 右 4 共 **7 个 `TraitIconContainer`**
   （每个 = `TraitIcon` + `Trait Icon Background` 底板，组件 `BoardTraitIcon` 带
   `traitIcons[2]` / `traitNotActiveIcons[2]` / `counterText`）—— 这就是「buff/debuff 图标」。
2. **阵营行 / 兵种行是橙字纯文本，没有图标**。
3. **`+N Health` 永远是文字，没有生命图标**；护甲写裸词 `Armour N`（**可以有银盾图标前缀** ——
   2026-09-15 三张卡面实测：`Bladeguard Ancient` / `Hardwired Destruction` / `Unforgiven Redemptor` 都带盾）。
4. 🔴 **方括号 token 的名字是 OCR 猜的，换张卡就换意思** —— 见下面「坑」。

## 二之四、🔴 图标**多大**：标定过程（2026-09-15，这段是这次最费劲的地方）

**问题**：原版那份 sprite asset 的 `m_FaceInfo` **是 0**（`pointSize=0 / scale=0`），
TMP 遇到 0 会退回**按当前字体**算缩放，而原版卡面的字体和我们**不是同一份**
⇒ **照抄原版的 `m_Scale` 不保证渲出来一样大**。所以大小只能**量**（铁律 7：拿成品卡图当尺子）。

**① 尺子（成品卡图，可复查）**：`D:/2/Warpforge部队卡片/Dark Angels/3部队/Warpforge_12_Aggressor.png`（900×1200）
那一行 `Strike: Gain 〔questPoints1〕` —— 用**图集切片去卡面上做模板匹配**量出来：

- 图标墨迹 **h≈48 px**（并排放大图 `_tmp_view/cardmeas/qp_zoom.png`）
- 同行的拉丁大写高 **h≈24 px**（`S`、`G`、`i` 的升部都是 23~24；**`b`/`t` 那 31 是升部，不是大写**，别量错）
- ⇒ **图标 ÷ 大写 ≈ 2.0**、图标 ÷ 卡高 = **4.0%**（48/1200）、图标 ÷ 卡宽 = **5.33%**（48/900）

**② 我方（`-executeMethod IconSizeProbe.Run`，扫描输出在 `_tmp_view/iconsize/`）**：
探针把字形缩放乘几档、量 `H` 与图标的**墨迹高**（⚠️ `characterInfo.ascender-descender` 量不出字形高，
那是**行盒**、整行一个数；要用 `meshInfo.vertices` 里那个字 4 个顶点算）：

- 卡面效果文字字号 **2.485**、拉丁大写墨迹 **0.19** 卡单位
- 目标图标 = 2.0 × 0.19 = **0.38** 卡单位
- 照抄原版（scale 1.7）时图标 **0.49** ⇒ **偏大 29%**（探针一开始那张图里「图标比旁边字母大一圈」就是它）

**③ 定案**：字形缩放乘 **0.776**（`IconSetup.CalibScale`，写在那个常量的注释里）。
复量结果：图标 **0.38** / 大写 0.19 = **2.00**，与成品卡图**分毫不差**。

## 二之五、🔴 两种记号的处理规则**不一样**（2026-09-15 实测，一开始做错了）

计划表里的 **1369 处记号分两类**（实测：**方括号 195 处 / 裸词 1174 处**）：

| 记号 | 卡面上原本印的是什么 | 怎么画 |
|---|---|---|
| `[Attack]` `[Spirit Stone]` 这类**方括号** | 那是**卡图 OCR 猜出来的占位**，卡面那个位置**只有图标** | **换掉** —— 记号不再出现 |
| `Waystone.` / `路标石。` / `集结：` 这类**裸关键词** | 那是**卡面上真印着的字** | **在词前面插入图标、词留着**（原版就是「图标 + 紧跟那个词」） |
| `☀` / `①` 这类**符号** | 那个字符**就是那张图**（OCR 把它抄成了字符） | **整串吃掉**，只留图标 |
| **数字烘在图里的**（`SpiritStone_N` / `questPointsN`） | 文本里那个数字**已经印在图上了** | **连数字一起整串吃掉**，只留图标 |

**判据**（实测口径，计划表 1369 处）：**方括号 195 / 裸关键词 1095 / 符号 79**；
「数字烘在图里」**与前三类重叠**（共 100 处，既有 `①`、也有 `[Spirit Stone]`、也有 `1 Quest Point`），
判据是「**那个数字就在图名里**」（`1` ∈ `questPoints1`），**不是**按 token 名猜。

- **方括号** = token 以 `[` 开头。
- **符号** = **首字符不是字母或数字**（`☀`(U+2600) 是符号类；`①`(U+2460) 是「Number, Other」、
  既不是字母也不是 ASCII 数字，也是符号类）。⚠️ **判据别写成「单字符」**：
  `☀` 是单字符但 `1 Quest Point` 不是，两类要走不同的路。
- ⚠️ 一开始两类都当「换掉」，结果**关键词整串消失、卡面只剩一个图标**（`Lychguard` 实测）；
  符号那类不判的话卡面会「图标 + 那个字符」**画两遍**。
- ⚠️ 另外三条实现细节（都在 `CardIcons.Rewrite` 的注释里）：
  **长的 token 先换**（短 token 是长 token 子串时，先换短的会把长的那条打散）、
  **整个过程幂等**（同一份文字会被换两遍 —— 实测 `[践踏]` 第二遍变成 `<sprite>……<sprite>践踏`）、
  🔴 **正则里必须写 `[0-9]` 不能写 `\d`** —— .NET 的 `\d` 是 **Unicode 数字类**、**把 `①` 也算数字**
  ⇒ `\d+①` 会把 `①①` 整段吃掉、那条替换变成空操作，**卡面原样印出 `①`**（`Farseer` 实测撞到）。

## 二之六、❌ 走过的一条弯路（记着别再试）：**字号不需要为图标放大**

一度以为「图标按世界单位摆、`FitToBox` 量不到它」⇒ 该把基准字号乘 **1 + 2.0 × 0.0779 = 1.156**。
**实测是错的**：字号一放大，行**更宽** ⇒ 折行变多 ⇒ 整块更高 ⇒ `FitToBox` 反而把字号往死里缩
（实测 `Heavy Intercessor` 从正常的 2.49 掉到 **1.02**、`Lychguard` 从一行变两行）。

真因：**图标本来就随字号缩** —— 字形缩放已经标定好，「图标 ÷ 大写」是个**常数 2.0**，与字号无关。
所以**字号该由文字自己定，图标跟着走，不需要任何补偿**。
（`CardIcons.FontScaleFor` 现在恒返回 1，留着只是把结论记在代码里。）

⚠️ 顺带一个**口径坑**：`TmpFont.WorldGlyphPerFontSize = 0.0948` 是**汉字**口径，
`WorldCapPerFontSize = 0.0779` 才是**大写**口径 —— **混用会静默算错字号 22%**。
