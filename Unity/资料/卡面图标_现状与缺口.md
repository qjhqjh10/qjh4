# 卡面图标 —— 现状与缺口（2026-09-14）

> **回答的问题**：原版卡面效果文字里那些图标（近战/远程、触发前缀、资源），
> **我们现在画了吗？效果实现了吗？**
> **一句话**：**一枚都没画** —— 效果文字是**纯文本原样输出**，连 `[攻击]` 这种方括号占位符都照字面印出来。
> **素材基本齐，缺的是「画上去」这一步。**

## 一、原版卡面上到底有哪些图标（照成品卡图逐张核过）

**总则**：图标全部**嵌在正文句流里**、**不是独立一行**；
**关键词类一律「图标 + 紧跟英文词」**（`【翼】Flying.`）；只有 **3 类**图标后面没有词
（数值图标、行首费用前缀、任务点）。图标直径约 36–44 px（卡宽 900 的 4–5%）。

| 类 | 例（卡图路径 + 卡面原文） |
|---|---|
| **近战数值**（深底粉拳圆徽） | `Ultramarines/2天赋/Warpforge_00c_Master-of-Arms-2.png` → `Your Warlord gains +1【拳】 and …` |
| **远程数值**（紫底紫枪圆徽） | `Aeldari/3部队/Zrzut ekranu 2026-04-16 o 18.59.12.png` → `Give +1【拳】, +1【枪】 and +1 Health…` |
| **行首费用前缀** | `Aeldari/3部队/Warpforge_03_Shining-Spear.png` → `【1】Gain 【镖】Shuriken 2 this turn` |
| **信仰付费前缀**（古铜**方**牌+金太阳，**不是**圆徽） | `Sorotitas/2天赋/Warpforge_04_Lead-the-Righteous.png` → `8【☀】: Deploy an additional Battle Sister` |
| **关键词前缀** | `【盾】Armour 1. 【爆】Blast 2`（`Aeldari/3部队/Warpforge_29_War-Walker.png`）· `【闪】Rally:` · `【骷髅】Backlash:` · `【卡】Talent:` · `【十】Regeneration 1` · `【兜帽】Camouflage` · `【盾徽】Vanguard` · `【螺】Stun` · `【齿轮】Artifice:` · `【碎卡】Ephemeral` … |
| **资源** | 能量（行首圆内数字，102 张）· 信仰（只以行首金太阳付费前缀出现）· 暗黑天使任务点 `gain 【①】` · 灵魂石（**卡面上是纯文字** `Gain 2 Spirit Stones`，**没有图标**） |

**⚠️ 三件容易想当然、实际不是的：**
1. **原版没有「关键词单独一行徽标」这回事** —— 关键词就是正文里的「图标+英文词」。
   唯一带前缀图标的**成行**写法是 `Talent:`（卡片形图标）与 `Agenda:`（绿色圆徽）。
2. **阵营行 / 兵种行是橙字纯文本，没有图标**。
3. **`+1 Health` 永远是文字，没有生命图标**；护甲**有**银盾图标。

**形状名 ≠ 图**：逐卡抄录表里出现过 **178 个形状名，只对应 78 张真图** ——
同一个形状横跨 `backlash`/`remnant`/`strike`/`synapse`/`regiment` 五张不同图
（`资料/关键词图标/关键词与图标_对照表.md:32`）。**别拿形状名当键。**

## 二、我们现在画了什么 —— **一枚效果图标都没有**

| | 现状 |
|---|---|
| **效果文字** | `BattleDriver.cs:2124` 的 `FaceText()` **直接返回 `DescZh`（没有就 `Desc`）、逐字不改**。全工程 grep `<sprite` **零命中** —— 没有任何 `[..]` → 图标的替换 |
| **方括号占位符** | `cards_engine.json` 的 `desc` 里 **86 张卡 / 120 处**（`[Attack]` 33 · `[attack]` 14 · `[Armor]` 6 · `[Ranged]` 5 · `[Energy]` 4…）；`descZh` **34 张 / 52 处**（`[攻击]` 20 · `[能量]` 4…）⇒ **卡面现在照字面印「+2 [攻击]、+2 [装甲]」**（例：`AM50 Thunderous Charge`） |
| **符号** | `desc` 里还有 8 种符号 28 个（`☀`18 · `②`3 · `💀`2 · `❄`1 · `🗡`1 · `🔫`1 · `🛡`1 · `⚡`1） |
| **🔴 字体还画不出** | 卡面字体是 `Fonts/NotoSerifCJK-Regular.ttf`（`Editor/TmpSetup.cs:40`）。解它的 cmap：`☀`/`①`/`②`/`★` **有**，**`⚡` `⚔` `❄` `💀` `🗡` `🔫` `🛡` 全无** ⇒ 这些是**缺字**。而字体覆盖检查（`TmpSetup.cs:497` 的 `Corpus()`）只查 `CardText.AllChinese()` + ASCII、**不查 `desc`** ⇒ **不会报警**（静默失效） |
| **独立图标渲染** | **没有**。卡底四个数值是**纯数字**画在原版卡框自带的宝石上（`CardView.cs:1472-1478`），另加费用底 `Card_Frame_Cost_Icon`、护甲盾底 `pedestal_icon_armor`（`CardView.cs:485-494`）。**没有**把 `+1 Attack` 画成 `+1` + 近战图标 |
| **关键词徽标** | `CardArt.Trait()` **全工程只调用过 1 处**（`CardView.cs:505`，Ephemeral 临时卡）—— **已导入的另外 72 枚一枚都没用上** |

## 四、缺口清单（要动手时照这个排）

1. **把 `desc` / `descZh` 里的 `[..]` 占位符换成图标**（英文 86 张 / 中文 34 张）——
   素材就绪，缺的是「`[Attack]` → sprite」这张**替换表**（可从 `_还原效果文字.md` 反推）。
2. **emoji 缺字**（`⚡💀🔫` …）**必须走图标渲染** —— 字体里没有，靠字体永远画不出来。
3. **数值图标**（近战/远程/护甲/生命）先做：它们**只在正文里出现、不带词**，替换规则最简单。
4. **补导 5 张 SpiritStone + 27 张 battleatlasui**（含徽标底板）。
5. **关键词徽标**：`CardArt.Trait()` 已有通道，目前只用了 1 处。
