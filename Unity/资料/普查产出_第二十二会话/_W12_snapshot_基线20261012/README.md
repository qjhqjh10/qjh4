TSV 列：`effect  time  lit  sum  lit_srgb  sum_srgb`
**判读用 `lit` / `sum`（原始值）。** `*_srgb` 那两列是排查色彩空间时加的，
实测把 sRGB 变换再套一遍会把所有比值压到 0.9 附近、掩盖真实差异 —— 别用。

🔴 **2026-10-02（第二轮）：`sum` 的【定义】改了，仓库里现在这份 TSV 是旧定义 —— 两趟都要重扫。**
- **为什么改**：原来 `sum = Σ(像素.r + 像素.g + 像素.b)`，**把底图自己的亮度也算进去了**。
  而底图（plate）两侧**完全相同** ⇒ 它在比值里是个**常数偏置**、把比值**系统性拉向 1**，底图越亮偏置越大。
  实据：`BulletImpact_AcidSpit`（**同一份资产、同一个 shader**）**只换底图亮度** ——
  黑/白底图 **0.99**、低对比底图 **0.63**。
- **改成什么**：**`sum = Σ|像素 − 底图|`**（逐通道取绝对值再求和），**只统计原来那批 `lit` 像素**
  —— 与 `EffectIso` 的 `contrib = Σ|像素−背景|/255` **同一个定义**（那边除了 255，是常数因子，不影响比值）。
  两把尺子口径就此统一。
- ⚠️ **为什么取绝对值、不取有符号差**：扭曲族（抓屏）会**同时**提亮一部分、压暗一部分，
  有符号求和会**互相抵消到接近 0** ⇒ 比值变噪声。取 `|Δ|` 对四族都成立。
- ⚠️ **只统计 `lit` 像素、不是全画幅**：全画幅会把 ±1 LSB 的光栅噪声累加 65536 次（≈260），
  **弱效果会被噪声淹没**（同 `sweep_frames` 那条「判定级噪声底」的教训）。
- ⇒ **这份数据（A–E 五段）是旧定义下测的**，与重扫后的数字**不可比**；重扫后本节要重写。

## ⚠️ 两个必须记住的坑（都实测踩过，两个方向都能把 900+ 个效果误判）

1. **原版那趟必须加载全部 84 个源 bundle**。原版 prefab 的材质也要解析 shader，
   而 `battleprefabs` 里的 shader 不是可加载资产（`LoadAllAssets<Shader>()` 返回 0）。
   只加载它一个包 → 原版渲染成**品红** → 品红很亮 → 原版亮度和虚高 → 比值假性掉到 0.2。
2. **导出那趟一个源 bundle 都不能加载**。`wf_shaders_extra.bundle` 是从 `battleprefabs`
   抽出来的，那个包在场时 Unity 按「内容相同」判重、拒绝加载补充包 → 导出侧退回占位材质。

两边的条件互相冲突，所以**必须分两个进程跑**，结果按效果名合并。
试过在一个进程里 `Unload(false)` 卸包，但连 prefab 一起销毁了，不行。

## 🔴 2026-10-02：**尺子换了一次（空场景 → 棋盘底图）—— 新旧数字不可比**

- **为什么**：空场景里两类效果**根本量不出** —— **抓屏族**（`Particle Distortion`，233 条）抓屏幕色来扭曲，
  空场景**没有可扭曲的内容**；**软粒子族**按「粒子到不透明场景的距离」淡出，空场景里深度缓冲停在**远平面**
  ⇒ 两侧的深度项都退化成常数（E 组那批「偏亮」相当一部分就是这么来的）。
- **做法**：场景里加一块**填满视野 · `_ZWrite=1` · `renderQueue=2000`** 的棋盘 quad
  （`EffectSweepBatch.MakeBackdrop`，几何照抄 `DistortProbe.MakeCheckerboard`），
  并**先渲一张「只有底图、没有效果」的基准图（plate）**；判读基准从常量 `Bg` 改成**逐像素比 plate**。
  **定义没变**（都是「效果真正改动了哪些像素、改了多少」），只是基准换成了有内容的底图。
- **开关**：`WFSWEEP_BACKDROP=0` 退回旧口径（做 A/B）。
- 🔴 **底图口径上线后又修了它自己两处**（2026-10-02 深夜，都**还没重扫**）：

     单帧扫描下抓屏族采到的是**上一个时刻**的画面。实测 11 条抓屏效果：比值 **6.0–14.4× → 1.8–2.7×**
     （**只修了一半**，残余 ~2× 是另一件事：Feature 关掉时两侧 ~1 ⇒ 差异全在抓屏那条路上）。

## 当前这份数据的口径

- 8 个时刻：0.15 / 0.30 / 0.50 / 0.75 / 1.00 / 1.50 / 2.00 / 3.00 秒
- 噪声下限：两侧亮点数都 ≥ 60 才参与判定（256×256 = 65536 像素）
- 判定依据：在「两侧都亮」的时刻上取**亮度比的中位数**，落在 0.7–1.4 算对得上
- 置信度：峰值亮点 ≥500 高 / ≥200 中 / 其余低

**验收指标 = `|ln(亮度比)|` 的中位/均值**（不受带宽边界影响）。

> 粒子位置/大小/寿命每次都不同。判据（`StabilityProbe`）：同一份资产**在同一个进程里

>
> 修法三件事缺一不可（`EffectSweepBatch.SeedAndReset()`）：

> ps.randomSeed = 20260911;          // 显式钉死

> ```
