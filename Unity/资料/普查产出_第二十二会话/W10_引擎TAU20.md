## 三、断言（**全部落在已有用例 `TestEventLayerTail()` 里**，⛔ 没新增 `Test*` 方法）

**A. 解析层**（`Editor/RuleEngineTest.cs:17187`，⑧-bis 块）
- `WhenEvents.Parse("an enemy gains Markerlight")` → kind=`getsmarkerlight`、**极性 `RelEnemy`**。
- **反例**：`… gains Markerlight **this turn**` 必须**仍认不出**（串尾匹配的纪律）。
- 🔴 **灭自证的那一条**：`EffectText.TryWhenSuffix(卡面原句)` 切出的效果那半 ≈ `Gains Long Range`，且 `ops[0].Verb + "/" + ops[0].Payload == "gain/long range"` —— **量载荷、不量「有没有 op」**：改前它也「解得出 op」，只是载荷是 `markerlight` ⇒ 只量有无的话**改前改后都绿**。
- **三族不许被抢**：`Lower cost by 1 when an enemy dies` / `For the rest of this battle, when …` / `… Vanguard when attacking` 三条都必须 `TryWhenSuffix == false`（抢走 = 两处登记或常驻层漏收）。

**B. 端到端**（同文件 `:17339` ⑤ ＋ `:17368` ⑤-bis，和既有 ①~④ 同形）
- 正例：挂 `When an enemy gains Markerlight, gain +1 Attack` 的夹具 ＋ 战术卡 `Give Markerlight 1 to an enemy troop` ⇒ `WhenFired == 1` **且 `w.Attack == before + 1`**（**量局面、不只量日志**）。
- **反例（灭自证）**：同一条路由 `Give Hunt Mark`（**别的关键词**）触发 ⇒ `WhenFired == 0` **且 `w.Attack == 2`（一点没动）**。⚠️ 挡的是「把广播写宽成**任何**关键词被给予」—— 只钉正例的话，无条件调 `BroadcastKeywordEvent(ctx, GetsMarkerlight, u)` 照样全绿。

**怎么才能红**：
- 撤掉 `WhenEvent.cs:904` 的词形 ⇒ A 前两条 + B 正例全红（B 的 `WhenTriggers.Count == 1` 先红）。
- 撤掉 `EffectResolver.cs:6700` 那行广播 ⇒ B 正例三条红（反例仍绿 ⇒ 正例必需）。
- 把广播改成「任何关键词」⇒ B 的 **⑤-bis 反例**红（正例仍绿）。
- 撤掉 `Dispatch` 的 8c-bis ⇒ A 的 `ops[0].Payload` 退回 `markerlight`（**改前的真实读数**）⇒ 红。
- 把 `AddWhenTrigger` ①-c 挪到 ② 之后 ⇒ 该类一条断言都不红，但注册没了 ⇒ B 的 `WhenTriggers.Count == 1` 红（**这就是「三层缺一层」的判别式**）。
