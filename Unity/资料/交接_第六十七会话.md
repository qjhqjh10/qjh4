## 五、坑 / 承重结论（本会话新增）

1. 🔴 **shader loader 的通配会先把动画包整只加载**：`WarpforgeShaderLoader.EnsureLoaded()` 的 `wf_arena_*.bundle` 把 9 只 `wf_arena_anims_*` 先加载，桥再 `LoadFromFile` ⇒ Unity「同一份内容只能加载一次」9/9 失败。**修法 = 桥先认领已加载包再加载**（`ExtraProbeAssets`/`LastExtras`），并加 `--verify-arena-anims`。
2. 🔴 **`Quaternion.Angle` 有 0.162° 盲区**（`dot > 1−1e-6` 即返回 0）⇒ 小角度断言会假绿/假红。用 `AngleDegTiny = 2·Atan2(|v|,|w|)·Rad2Deg`。
3. 🔴 **断言扫到「世界空壳」= 恒绿空扫**：`SettingsPanel` / `MultiCardDisplay` 的文本在 `_panel`，不在壳 `transform`；W62 前提与本体都要改扫 `PanelRect`。
4. 🔴 **点击会重建列表**：`DeckRow_YourDeck` 点后已被 `DestroyImmediate` 重建，断言必须**点完重找**。
5. 🔴 **短哈希不是卡 id**：`6ed51d59` 只是全长 id 前 8 字符；测试里必须用全长。
6. 🔴 **T27「待死」夹具必须 `ctx.AddPendingDeath`**：只 `Health=0` 产不出状态 5。
7. 🔴 **D15 的 `AddRange` + 重复 `keywords`** ⇒ `EC33` Rally `-2/-2` 结算两次；**⛔ 别回退 D15**（反编译判过它是对的），从数据侧去掉重复正文。
8. 🔴 **play 基线 476 行 = 61→62 27 + 62→63 417 + 63→64 8 + 64→65 0 + 65→工作树 237**；**未重钉**；重钉前须 EC33 修好 + 425 旧账签字。
9. 🔴 **prefab 合并要保世界变换**：astra/EC 的 `Scenario` 根在 `(113.238,−8.695,19.853)`，直接挂 Baked 会整体平移 ~113 单位。
10. ⚠️ **PnP 是印刷品，版式不作准**：`Goff Stompa` 并排显示我方多一行阵营文字，但数字版 prefab 才是版式权威 ⇒ 保留阵营行。
11. ⚠️ **`cards_engine.json` 真路径 = `Unity/MyGame/Assets/RuleEngine/Resources/`**，`cards_raw.json` 在 `普查产出_1018/allcards_1350/`；`数据/游戏数据/` 没有它们（已知的坑）。
12. 🔴 **世界档 3D TMP 字号 ×10 不是 ×100**：`CardsInHandText` 的 `m_isOrthographic=0` ⇒ `orthographicMultiplier 0.1`；按 ×100 传 min 50px 会永远缩不进 64px 框（γ 根因）。

15. ⚠️ **A2 的 `TurnTimerTickPulse` 光 `RunListed` 不生效**：必须 `RunListed → gen_effect_index.py → EffectLibraryBuilder.Run` 三步。
