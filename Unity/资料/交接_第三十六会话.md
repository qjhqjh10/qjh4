## 三、🔴 本会话查清的三件（结论 + 判据）

### 3·1 **引擎版本：不换**（用户问）
- **原版 = Unity `6000.2.6f2`**（亲读 `Warpforge_Data/globalgamemanagers`）· **我们 = `6000.3.23f1`**（`ProjectSettings/ProjectVersion.txt`）。**同一大版本、差一个次版本**。
- 🔴 **三条图形包把门焊死**：URP / Core RP / ShaderGraph 的 `package.json` 都写着 **`"unity": "6000.3"`** ⇒ **降级装不上**。
- 🔴 **「场景布置差距」逐条追下来，没有一条是引擎版本造成的** —— 全落到我们自己的生成器/清单（静态合批丢 `firstSubMesh` · **顶点色整条丢失** · `m_CustomRenderQueue` 没进清单 · `JsonUtility` 把 null 物化把粒子钳死 · `ColorLookup` 根本没复刻 · 相机栈是两台 base 不是 base+Overlay）；**最大来源 = 13 场里 12 场没开始**。
- **联网查到、本地查不到的那几条**（`docs.unity3d.com` / `docs.unity.com` / `raw.githubusercontent.com` **全被网络策略挡**，只能靠搜索标题/摘要）：
  · **6.3 起 Render Graph 默认开启、Compatibility Mode 将被移除** ⇒ ✅ **打不到我们** —— 我们的 `WarpforgeVFX/Runtime/GrabPassTransparentFeature.cs` **已经写了 `RecordRenderGraph`**（已在 Render Graph API 上）。
  · **`InstanceID → EntityId` 迁移**（6.3 文档有专页）⇒ 我们用了 **27 处 `GetInstanceID()`**，但在 6.3 下**编得过**（类型检查 0 错）⇒ 是弃用/新增，不是移除。
  · **URP 17.3 的 `MaterialUpgrader` 修正（Alpha Clipping）** —— 只在**升级那一刻**跑；我们是新建工程，不涉及。
  · **6.3 更紧的光照贴图 / HTTP-2 默认** —— 与复刻无关（我们不用烘焙光）。
  · ⚠️ **仍无法排除的**：**粒子 / 导入器 / uGUI 运行时 / 物理 / shader 编译器**的逐版本行为差 —— **官方 release notes 打不开，拼不出完整 changelog**。
