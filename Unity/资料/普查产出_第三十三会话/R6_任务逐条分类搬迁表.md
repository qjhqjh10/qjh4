### 2·1 我用的边界（都能用第 6 列复核；主对话不同意可以按证据重判）

2. **卡面层序（`CardView.SetQueue` / 徽标底板 / 场上数值格）归卡牌线**，不归表现·特效线 —— 判据 = 这几条的诊断报告自己叫 `DIAG_卡面层级三项.md`，行内自陈「同族（都是卡面层序）」。
3. **`shader` / 粒子 / 材质**：改 `ArenaBuilder` / 13 场清单 ⇒ **战场线**；改卡体 / 战斗内特效 ⇒ **表现·特效线**。例：`A1578` 粒子 render queue 走 `mat_renderqueue.tsv` + `ArenaOriginalMaterial` ⇒ 战场线。
4. **纯「注释 / 账目 / 文档订正」归工具·文档线**；但**代码里某条注释**归它所在文件的线（例 `Core/Loc.cs` 的注释 ⇒ 界面线）。
5. **语音（`voice_lines.json` / 台词 / 音频资产）暂归表现·特效线** —— 本套体系**没有独立语音线**（见 §6·⑧）。
6. **性能 / 卡顿归它所在那一屏的线**（收藏窗 ⇒ 界面线）；**Battle 场景加载帧**那两条（`A1750`/`A1780`）归表现·特效线（行内自己怀疑「首次 shader/材质编译 + Resources 首次加载」）。
