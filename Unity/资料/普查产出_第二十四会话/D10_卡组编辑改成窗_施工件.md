## 零、`D9` 重勘的要点（补落盘）

- **入口少算了一处**：`Shell/LiveOpsEventWindow.cs`（现读约 `:1147`）**还有第三处 `LoadScene("DeckEditor")`**。
- **两条 additive 特有撞车**：

  · **命中**：`OtherWindowUp()`（= `wm.TopWindow.IsOpen()`）—— 进编辑器那一刻收藏窗**一直是 `Open` 且是 `currentWindow`**
    （`GoEdit` 关的是**弹窗**、不是收藏窗）⇒ **闸恒真** ⇒ **`A1701` 与 `A1132` 是同一处**。
- **设计级死结（additive 特有）**：主菜单那一棵**不在 DDOL 层**，关掉菜单相机它就不画；
  而**收藏窗走同一台相机**（世界空间 quad、无 uGUI Canvas；两台相机参数一致）⇒
  **「关掉主菜单、只留收藏窗」做不到** ⇒ 这是 additive 路线被否决的直接原因。
- **回程落点**：additive 下 `MainMenuRuntime.Build` **根本不会跑** ⇒ `PendingReturn` 会**一直挂在静态口上没人消费**
  （而 `Editor/DeckScene.cs` 那 5 条 `A855` 断言正是照它观测）。
- **半做会当场坏**：只改入口不改回程 ⇒ 主菜单被**单场景重载**、而收藏窗**从来没被关过** ⇒
  重载后 `Build()` 的 `OpenCollection()` 走 `closeAll:true` 先把还开着那扇关掉（连带 `ShowPreviousWindow` 那串 = **`A1709` 族**）
  ⇒ **窗闪一下 + `A1709` 风险放大**。

## 一、原版真身（`D10` 现读）

- **类** = **`DeckEditingWindow : GameWindow`**（**直接子类**，不是 `GameWindowWithTabs`）。
- **开窗参数**：`windowsPlacement = 10 (World)` · `type = 0 (Fullscreen)` ——
  🔴 **这两个值都不在代码里、只有 prefab 序列化字段有**（ctor 没赋）。
- **ESC = 保存**（它覆写了 `ESCPressed` ⇒ `TrySaveDeck()`；基类那条「ESC 关窗」被绕过）。
- **不是模态**（`type=0`，不是 `PopupGameWindow`）；`GameWindowOptions` 没传（`SelectDecksTab__CreateDeck.c:28` 只给 `closeAll=false`）。
- **尺寸/锚点** = prefab 根 RT **全屏拉伸**（`anchorMin(0,0) anchorMax(1,1) sizeDelta(0,0)`）；
  唯一子件 `Content Area` 四周内缩 `167.175 / 70.94`。
- **渲染队列：原版查不到** —— 它走 UGUI Canvas 排序，prefab 子树里 **0 个 Canvas / 0 个 SortingGroup**；
  「队列」是**本仓 `ImageQuad` 的自建语汇**。
- **prefab 树**：根 `Deck Editing Menu` → `Content Area` → 5 子件（`Background`/`Header`/`Sidebar`/`Card Display`/`Cosmetic Display`）；
  **248 节点 / 最深 12 层** · **无 Camera** · **无 Canvas** · 6 个 `CanvasGroup`（出厂 alpha=1）。
  留痕 → `资料/普查产出_第二十四会话/D10_prefab树.md`。
- **开**：`SelectDecksTab__CreateDeck.c:28` `WindowsManager.OpenWindow<DeckEditingWindow>(wm, deck, closeAll:false)`
  （收藏窗 Decks 页的 Create；Edit 走同一个类）。`TryOpen` 开头 `NavigationPanelController.Toggle(0,1,0)` = **收起左竖导航**。
- **关**：`DeckEditingWindow__Close.c:19-20`：`Toggle(1,1,0)`（**放回导航栏**）→ `GameWindow.Close()`；
  随后若 `wm.currentWindow` 是 `CollectionScreen` ⇒ `ReturnFromImportDeck(...)` ⇒
  **回到底下那扇一直开着的收藏窗**（**页签从未被切过**）。

## 二、我们现在是什么 / 最小改动

- `Deck/DeckRuntime.cs`：`_cam = Camera.main`（≈`:1145`）· `Root = transform`（≈`:1148`）·
  `Build(lib)` 先清空自己所有子件再重建 · `BackToMenu()` → `LoadScene("MainMenu")` · 自己会 `WindowsManager.EnsureHost()`。
- 🔑 **最小改动 = 新建 `Shell/DeckEditingWindow.cs : GameWindow`**（形状照 `Shell/DeckInfoPopup.cs:796-814`）：
  `new GameObject("Deck Editing Menu")` → `AddComponent<DeckEditingWindow>()` → `type=Fullscreen` / `placement=World` →
  `WindowsManager.AttachToAnchor(win)`；`Open()` 里 `AddComponent<DeckRuntime>()` + `Build(DeckLibrary.Load())`。
  ✅ **`DeckRuntime` 结构一行都不用改** —— `Root = transform` **天然就是「窗根」**，
  而 `AttachToAnchor` 把窗根挂到锚点下时写的正是 `localPos=zero / rot=identity / scale=one`，**与今天场景根同形**。
- **`GameWindow` 契约**：`type`/`placement` **必须显式赋**（哨兵会 `LogError` 并兜底）· `Open()` 必须能建内容 ·
  `IsOpen()` 读 `CurrentState` · ESC 由 `PointerLayer.KeyCancel → TopWindow.ESCPressed()` 派发。
