## 三、材质 / shader 导出

### 3.1 本轮实质突破：`Escartem/AnimeStudio` 内嵌 DXBC → HLSL

- `AnimeStudio.Utility/ShaderConverter.cs` 里有个 `HLSLDecompiler` 静态类，`[DllImport("AnimeStudio.HLSLDecompiler")]`，
  签名 `Decompile(byte[] shaderByteCode, int size, out IntPtr shaderText, out int shaderTextSize)`。
- 调用点在 **DX11 那一支**：`DX11VertexSM40/50 · DX11PixelSM40/50 · DX11GeometrySM40/50 · DX11HullSM50 · DX11DomainSM50`
  → `HLSLDecompiler.DecompileShader(buffSpan.ToArray(), …)` → `sb.Append(hlslText)`，
  即**把反出来的 HLSL 直接写进导出 `.shader` 的 `Program "vp" { "…" }` 体里**（失败则写 `// decompile/disassembly error …`）。
- 原生库来源（README 致谢原文）：`3Dmigoto and HLSLcc by Unity - shader decompilation`。
- 🔴 **对比判据（同族其他分支做不到）**：`aelurum/AssetStudioMod` 的 `AssetStudioUtility/ShaderConverter.cs` 里，
  DX11 那一支是**整段注释掉的**，只留下：`sb.Append("// shader disassembly not supported on DXBC");`
  ⇒ **AssetStudio 家族不是 shader 反编译器**（第一轮对 AssetRipper 的结论，对 AssetStudio 全家族同样成立）。

## 五、红队：看着有用、实际不行（每条给判据）

1. **「AssetStudio 能导 shader（连 DXBC 都能）」** —— **不成立**。
   `aelurum/AssetStudioMod` 的 `AssetStudioUtility/ShaderConverter.cs` 里，DX11 那一支**整段被注释掉**，
   代码里只剩一行 `sb.Append("// shader disassembly not supported on DXBC");`。
   ⇒ 它出的是**ShaderLab 壳 + 一句注释**，不是可编译的 HLSL。（第一轮对 AssetRipper 的同一结论，在本轮对 AssetStudio 全家族**逐源复核成立**。）
2. **「AssetStudioMod 支持 1.7–6000.2，所以能帮我们建场」** —— **不成立**。
   `AssetStudio/Classes/` **33 个类里没有 `Scene`**，只有 `GameObject/Transform/MeshRenderer/MeshFilter/SkinnedMeshRenderer`；
   `ExportType` 枚举只有 `Convert | Raw | Dump | JSON`（无「导出 Unity 工程」）。⇒ 走得出层级，**出不了 `.unity`**。
3. **「AssetStudio 家族的 sprites 覆盖够用」** —— **不够**。类表里有 `Sprite.cs`/`SpriteAtlas.cs`，
   **但没有 `SpriteRenderer` / `SpriteMask` 类** ⇒ 我们那条「78 个 prefab 被遮罩」的坑（`资料/已知的坑.md:533`）**它也解不了**。
4. **「AnimeStudio 有 DXBC→HLSL，直接拿来用」** —— **先过不了「解析」这一关，大概率**。
   判据：`AnimeStudio/Classes/Shader.cs` 的 `SerializedPass` 构造里，读 `m_EditorDataHash`/`m_Platforms` 的条件仍是
   `if (version[0] > 2020 || (version[0] == 2020 && version[1] >= 2))` —— **对 6000 也成立、照样去读**；
   而 `Razviar/assetstudio` 的 `UNITY_6000_FIXES.md` **实证 Unity 6000 已删掉这两个字段**
   （症状 = `Unable to read beyond the end of the stream`，**1082 个 shader 失败**），修法是加 `&& version[0] < 6000`。
   AnimeStudio 里唯一的 6000 逃生口是 `if (reader.Game.Type == GameType.AFKJourney && version[0] >= 6000) { …return; }`
   —— **绑死在某个具体游戏上**。
   ⇒ 对我们（原版 6000.2.6f2 · 通用 Unity 游戏）**代码上没看到排除分支**。⚠️ **未实测**（见 §七）。
5. **「★ 高 = 合适」** —— 反例两条：`BobLChen/ShaderLab` 101★ 但**方向相反 + 2021 停更**；
   `Razviar/assetstudio` 只有 503★，却是**唯一 README 明写 `6000.0 - 6000.4+` 的 AssetStudio 分支**。
6. **「AssetRipper 支持到 6000.4，所以我们的 6000.2 一定行」** —— **要打问号**：第一轮已记，
   README 的版本区间**不等于**「我们这 4.4 GB 解包树实跑通过」。**本轮仍未实测**。
7. **「DevXUnityUnpacker 是免费工具」** —— **不采信**。它在 CSDN 上以 `【免费下载】` 系列出现 6+ 篇（`gitblog_09807` 等），
   但：**GitHub 搜 `DevXUnityUnpacker` = 0 命中**、**官网 `devxdev.net` HTTP 000 连不上** ⇒
