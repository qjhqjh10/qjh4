## 四、本会话的坑 / 承重结论（新会话必读）

1. 🔴 **批处理没有帧循环 ⇒ 一切「等补间/等事件」的隐藏状态都会变成「隐形但吃射线」**：
   - `ChatPopupPanel.Hide()` 只起 0.5s 淡出、**不撤 raycastTarget** ⇒ 隐形气泡整屏吃射线（在 OverHand 层，压过根画布所有钮）。测试收气泡必须 `HideImmediate()`。
   - `BattleLogPanel.Hide()` 只起滑动、`_root` 等滑到底才关 ⇒ 隐形日志面板继续吃射线（首中 `LogBG`）。测试必须 `Hide()` + `FinishSlideForTest()`。
2. 🔴 **`ClippedTextGuard` 的 FastAction 截断（已修，但要记住）**：回调里 `OnDisable()` 自我 `Remove`，而 `FastAction.Call` 是 `node = node.Next`、`LinkedList.Remove` 会把被摘节点 `Next` 置 null ⇒ **只要有一颗 `_lb` 已销毁仍订阅的守卫，排在它后面的订阅者这一趟全收不到且静默**。已改成「整类共用静态派发器 + 遍历副本」。⛔ 别改回逐守卫直挂 `TEXT_CHANGED_EVENT`。
3. 🔴 **TMP 的 `TEXT_CHANGED_EVENT` 在批处理不可靠**：`OnPreRenderObject` 在非 active/awake 时静默早退。自检要验「重排后重裁」，要么显式 `ON_TEXT_CHANGED(guard.TmpForTest)`，要么直接用 `Reclip()` 那条路。
4. 🔴 **开场运镜在批处理必须彻底停用**：只「不 `Sample(0)`」不够——`_playing` 仍 true，后续任何 `Step` 都会 `Tick` 把相机推进 clip 中段，导致数值探针屏外/落点 0/18/射线簇一片红。已加 `_batchSuppressed`，`StartForTest` 才允许批处理真播。
5. 🔴 **uGUI 射线在批处理要「先真渲一次」**：`Canvas.ForceUpdateCanvases()` 不给 `Graphic.depth`，`GraphicRaycaster` 跳过 `depth==-1`。`RenderOnceForTest()` 已加。另：`Screen=640×480` 而画布 1920×1080 ⇒ 外扩点可能被推出屏幕，取点先过 `IsInsideScreen`。
6. ✅ **VfxMap 钉行游标（真缺陷，已修）**：`ResolveAllTimed` 先按能力序号筛选、后钉行，`pin` 从 0 起且 `CardPick` 不带行号 ⇒ 第 2 条能力被钉回第 1 条 `Offset`（SOR56/SOR23/SOR67）。修法 = 钉行放到筛选之前并复用同一组 `pin[]`。
7. ✅ **多词条顺序判据（T03·c）**：单位层 = `allCardsInPlay` **进场序**（不是棋盘位置）；卡内 = `cardAbilities` 列表序（全触发不去重）；动作层 = `priority` 四道队列 `Interrupt > Instant > DelayedInstant > Player`；玩家无选择权。
8. ✅ **死亡/击杀链**：`PendingDeath.ActingCard` + `FlushDeaths` 逐死者「反噬 → 记账 → 下一个」；Backlash(80) 先于 Unstable(81)；死者自身先于观察者；嵌套死亡 FIFO；D8 受伤预调 + 排除并用 `EffectChain` 闸防爆栈。
9. ✅ **伏击**：原版**没有回合开始自动揭示**；翻开只在受伤/被攻击/攻击取消三条路，且 `owner == IsPlayerTurn` 才触发 `Ambush`；攻击面朝下单位会取消该记（**不吃攻击配额、不疲劳**）。
10. ✅ **回合流程**：加时按**全局回合**（用户 2026-10-20 确认，2026-10-17「按能量」旧口径作废）· `Gain N Energy` 永久抬上限（`createMana`；`refill` 只回当前）· 手牌上限丢**新抽那张** · `shouldReshuffle=false`（用户拍板：卡组空就空、只疲劳）· psychic/plasma 是原版死功能，不建模。
