## ② A447 —— `ShowPreviousWindow` 那一跳（要做的那笔）

### 判据：**本件亲读指令流**（⛔ 不是照 H14 报告抄；派单要求重核）

```
PY=D:/2/Warpforge_tools/py312/python.exe
$PY d:/4/Unity/工具/disasm_va.py D:/2/unity_run_ref/GameAssembly.dll 0x180876560 200   # WindowsManager.ShowPreviousWindow
$PY d:/4/Unity/工具/disasm_va.py D:/2/unity_run_ref/GameAssembly.dll 0x180835FD0  45   # 无参 TryOpen()
$PY d:/4/Unity/工具/disasm_va.py D:/2/unity_run_ref/GameAssembly.dll 0x180836120  24   # 带参 TryOpen(data,options)
```

**① 那一跳调到的是【无参】重载 —— 目标地址是硬编码的 `0x180835fd0`**（`ShowPreviousWindow` @ `0x180876560`）：

```
1808767C1  48 8b 4f 58              mov rcx, qword ptr [rdi + 0x58]   ; rcx = this->currentWindow
1808767C5  48 85 c9                 test rcx, rcx
1808767C8  0f 84 8e 00 00 00        je   0x18087685c                   ; null ⇒ 抛（il2cpp 守卫）
1808767CE  33 d2                    xor edx, edx                      ; rdx = 0
1808767D0  e8 fb f7 fb ff           call 0x180835fd0                  ; ★ 无参那条
```

- `0x58` = **`WindowsManager.currentWindow`**（`d:/2/tools/il2cpp_out/dump.cs` 的 `WindowsManager` 字段表：
  `List<GameWindow> openWindows // 0x50` · `GameWindow currentWindow // 0x58` · `PopUpGameWindow popUpWindow // 0x60`）
  ⇒ 调用对象就是**列表尾那一扇**（与我们 `prev` 同义）。
- ⚠️ 那条 Ghidra `.c`（`WindowsManager__ShowPreviousWindow.c:83`）印的是 `GameWindow__TryOpen(win, 0)` ——
  那个 `0` 是 il2cpp 调用约定的**尾槽**（同函数里 `set_CurrentWindow(this, value, 0)`、而那个 setter 只有一个实参）
  ⇒ **一个 `data` 都没喂**。⛔ 别读成「传了 `null`」。

**② 无参那条一次都不调 `SetupData`**：

```
180835FDF cmp byte ptr [rip+…], 0 / 180835FE9 jne / 180835FEB lea rcx,… / call 0x1803f44f0   ; il2cpp 类初始化守卫
180835FFE 8b 73 68    mov esi, dword ptr [rbx + 0x68]    ; ★ 头一条业务指令 = 读 CurrentState（+0x68）
180836001 33 ff       xor edi, edi
180836003 85 f6       test esi, esi
180836005 74 08       je   0x18083600f                      ; Closed 支
```

**它之前没有** `mov rax,[rcx]` + `call [rax+0x188]`；而**带参那条**（`0x180836120`）序言之后**头三句**正是它：

```
18083612F 48 8b 01                 mov rax, qword ptr [rcx]         ; vtable
180836135 4c 8b 88 90 01 00 00     mov r9, qword ptr [rax + 0x190]  ; MethodInfo
18083613C ff 90 88 01 00 00        call qword ptr [rax + 0x188]     ; ★ SetupData
```

**③ 两条的三支本体逐句相同**（`0x180835F01…0x180836112` ↔ `0x1808361EB…`）：
`Closed` ⇒ 播 `openSound`(`+0x28`) → `SetActive(go,true)`（`call 0x182ff25c0`）→ `mov [rbx+0x68],1` →
`call [rax+0x178]`（`Open()`）→ `[rbx+0x58]` 委托（`OnOpen`）；`Background` ⇒ `state=1` + `call [rax+0x1a8]`；
`Open` ⇒ `ret`。⇒ **两句的差别只有开头那一句 `SetupData`**。

### 结论与我们原来的偏离

- 原版回来之后那扇窗的 `Data`（以及三个 `SetupData` 覆写里的 `_ctx`/`Index`）**原样保留**。
- 我们原来走 `prev.TryOpen(null)` ⇒ 走**带参**重载 ⇒ `SetupData(null)` 把它**清成 null**。
  那句注释「传 `null` 与…无参调用**同义**」**不成立**：「同义」只到「都不重建内容」那一层，
  **写数据这一层正好相反**。
