**一句话**：`Shell/MenuDraw.cs` 的 `ClipText` 把**形参** `clip` 覆盖成了「解析后的框」，
于是交给 `ClippedTextGuard` 的是**快照**、不是调用方原样那一份 ⇒
**H25 报的「守卫每次重裁重新解析」（A435① 第 3 件）实际没生效**。

**逐句**（`Shell/MenuDraw.cs`，现读）：

```csharp
public static bool ClipText(Label lb, PxRect? clip, Vector2 softPx)          // :977
{
    // :982-983 「下面 `ArmTextGuard` 那一行改传 `clip`（调用方原样那一份，未经解析）」← ⛔ 这句与代码不符
    var _st = ViewportClip.Resolve(lb != null ? lb.transform : null, clip, softPx, default(Vector4));  // :984

    ...

```

**两个可观测后果**（都静默）：

| # | 症状 | 判据 |
