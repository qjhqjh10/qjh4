## 一、A436 结论：**V8 对，V4a 那一句错**（错在「挂错了重载」）

- `资料/普查产出_1010/V4a_壳与共用件口径.md:35` 原来写 `GameWindow__TryOpen.c` = 「非 `Closed` ⇒ … 后 return（**不 SetupData**）」
  ⇒ **只对【无参重载】成立**；而**生产路径走的是带参那个** ⇒ 结论被安到了错的身上。
- `资料/普查产出_1012/V8_判据补查.md:169-174` 的读法（**`SetupData` 在分档之前**）⇒ **成立**。
- ⇒ **A436 的另一支（把 `SetupData` 移回 `Closed` 支）不成立**；
  `Shell/WindowsManager.cs` 的 `TryOpen` 现在是「① `SetupData(data)` → ② 读 `CurrentState` → ③ 三档」，
  **与原版带参重载逐句同构** ⇒ **不用改**（本件因此没有动这个文件）。

### 指令流证据（本件亲读，`工具/disasm_va.py D:/2/unity_run_ref/GameAssembly.dll <VA>`）

**① 带参重载 `TryOpen(object data, GameWindowOptions options)` = VA `0x180836120`**（`dump.cs`：RVA `0x836120` / Slot 6）：

```
18083612F  mov rax, qword ptr [rcx]              ; rax = this->vtable（rcx = this）
180836135  mov r9,  qword ptr [rax + 0x190]      ; r9 = 该槽的 MethodInfo
18083613C  call qword ptr [rax + 0x188]          ; ★ SetupData(this, data, options) —— 第一句就调
180836142  cmp byte ptr [rip+…], 0 / …           ; il2cpp 类初始化守卫
18083615E  mov esi, dword ptr [rbx + 0x68]       ; ★ 读到 CurrentState 时，SetupData【已经跑完】
180836161  xor edi, edi
180836163  test esi, esi
180836165  je   0x18083616F                      ; Closed ⇒ 走重建支
180836167  lea eax, [rdi + 1]
18083616A  jmp  0x18083623E                      ; 非 Closed ⇒ 跳到「只看 state 是 1 还是 2」那段
```

- **Closed 支**（`0x1808361EB` 起）：`call 0x182fecae0`（`Component.get_gameObject`）→ `call 0x182ff25c0`（`GameObject.SetActive(go, **true**)`）
  → `mov dword ptr [rbx+0x68], 1`（`state = Open`）→ `mov rdx,[rax+0x180]` / `call [rax+0x178]`（**`Open()`**）
  → `mov rax,[rbx+0x58]` / `call [rax+0x18]`（触发 `OnOpen` 委托）。
- **非 Closed 支**（`0x18083623E`）：`cmp esi,1` / `cmovne edi,eax` / `test edi,edi` / `je …262`
  ⇒ **`state==1`（Open）一个字段都不写就 `ret`**；**只有 `state==2`（Background）** 才 `mov [rbx+0x68],1` + `call [rax+0x1a8]`（`ToFocus`）。
- **全函数只有一处 `call [rax+0x188]`**（就是开头那句）⇒ `SetupData` **无条件、且只跑一次**。

**② 无参重载 `TryOpen()` = VA `0x180835fd0`**（`d:/2/tools/decomp_full/GameWindow__TryOpen.c` **就是它**）：

```
180835FE6  mov rbx, rcx
180835FDF…180835FF7 （il2cpp 类初始化守卫）
180835FFE  mov esi, dword ptr [rbx + 0x68]       ; ★ 直接读 CurrentState —— 【头一句就是它】
180836003  test esi, esi
180836005  je   0x18083600F                      ; Closed 支
18083600A  jmp  0x1808360DE                      ; 非 Closed 支
```

⇒ 读了 30 条指令，**没有任何 `call [rax+0x188]`** ⇒ **它确实不调 `SetupData`**。
⇒ **V4a 原来的观察本身没错，只是把无参版的行为当成了整条 `TryOpen` 的行为。**

**③ 槽位→偏移的自洽链（四条独立读数互相印证，用来证明 `+0x188` 就是 `SetupData`）**：
`dump.cs` 的 Slot 号 = `Open()` **4** · `SetupData` **5** · `TryOpen(data,options)` **6** · `ToFocus` **7**；
`VirtualInvokeData` 是 16 字节（`{methodPtr, methodInfo}`）⇒ 基址 `0x138` ⇒
`+0x178 / +0x188 / +0x198 / +0x1a8`。四条实读**逐一吻合**：

| 实读到的调用 | 落到的槽 | 该槽是什么 |
|---|---|---|
| `call [rax+0x178]`，`rdx = [rax+0x180]`（两个重载的 Closed 支） | Slot 4 → `+0x178` | **`Open()`** |
| `call [rax+0x188]`，`r9 = [rax+0x190]`（带参重载第一句） | Slot 5 → `+0x188` | **`SetupData`** |
| `(**(code **)(*param_2 + 0x198))(...)`（`WindowsManager__OpenWindowCO.c:89`） | Slot 6 → `+0x198` | **`TryOpen(data, options)`** ← **生产路径** |
| `call [rax+0x1a8]`，`rdx = [rax+0x1b0]`（非 Closed 支） | Slot 7 → `+0x1a8` | **`ToFocus()`** |

⇒ **生产路径确认**：`WindowsManager__OpenWindowCO.c:89` 调的是 **Slot 6**（带参重载）⇒ **`SetupData` 会跑**。
（旁证：`WindowsManager__ShowPreviousWindow.c:83` = `GameWindow__TryOpen(win, 0)` ⇒ 调到的是**无参**那个，**不重喂 `data`**。）
