## 五、坑 / 承重结论（本会话新增，⛔ 别推翻）

1. 🔴 **`SkirmishEventWindow.ForceActiveEventForTest` 必须成对使用**（自检量活动期 prefab 时置 `true`，节末 `ResetEventProbeForTest()`）。
2. 🔴 **`LiveOpsEventWindow.Open()` 不调 `base.Open()`** ⇒ 自己 `Create(null)+Open()` 状态停在 `Closed`；要用 `WindowsManager.OpenWindow(w)`（断言类 `Run(WindowsManager)` 就是为此）。
3. 🔴 **`WindowsManager` 同一时刻只让一扇全屏窗开着** ⇒ 自检里「开一扇、当场断一扇」，别两个都开完再断。
4. 🔴 **`CardBaseDemo` 把 `CardTween.Mode` 设成 `Manual`** ⇒ BIG 补间要手动 `CardTween.Advance(0.35f)` 才到终态。
5. 🔴 **条带路的 x 极值 ≠ 硬矩形边**（越界窄条整段丢弃）⇒ 用「三明治」判据（画窗边 0.83949 + 硬矩形 0.914668）。
6. 🔴 **轮抽数据：882 个文件只有 855 个不同 `packId`** ⇒ 下游按 `key` 不按 `packId`；**包名前缀 ≠ 阵营**（按 `packArmy`）。
7. 🔴 **`MainMenuScene` / `ShellScene` 的计数口是 `_sink`（`CheckSink` 公共字段）**，不是 `pass/fail`。
8. 🔴 **`ProjectSettings` 的 `companyName/productName = Everguild/Warpforge`**（与原版相同）⇒ 存档进同一个 `LocalLow/Everguild/Warpforge/`；改它会挪存档 ⇒ **等用户拍板**。
9. 🔴 **卡面效果文字的版式 = 固定矩形 + 垂直居中**（不是下沿对齐）；数值容器上沿 y01 **0.7972** 是硬边界。
10. 🔴 **头像 = 三层各放大**（Image ×2.0 / Border ×1.25 / Highlight ×1.9），头像画在框**之上**、无遮罩；放大后相邻格会重叠 ⇒ 队列要分档。
11. ⚠️ **`Check<T>(got,want,msg)` 是相等断言**；**`CardView.State` 默认 `Normal`**；**`PlayCard` 的 slot 是请求格不是落点**。
12. ⚠️ **编辑器批处理里 DOTween `TweenExtensions.*` 是静默 no-op**；`transform.DOKill()` 不读 `initialized`。
13. ⚠️ **改 `.cs` 用 Edit/Write**（⛔ `sed -i` 会翻行尾）；改完立刻 `git diff --numstat` 核。
14. ⚠️ **bash 里别用双引号包带反引号的 python 脚本**（反引号会被命令替换、内容被吃掉 —— 本会话踩过一次，靠 Edit 工具修回）。
