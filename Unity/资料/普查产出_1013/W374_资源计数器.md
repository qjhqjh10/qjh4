而**本地没有 Addressables catalog** ⇒ 名字要靠 **bundle 的 `AssetBundle.m_Container`**（它把
`guid → PPtr(PathID)` 记下来了）反查。链路（逐条可复现）：

1. 全 `AF/**/MonoBehaviour/*.json` 里带 `smallIcon` 字段的 = **3 份币种 SO**
   （`bundle_cosmeticsso_assets_all/MonoBehaviour/{Blackstone,Gacha tickets}.json` ·
   `bundle_duplicateassetisolationso_assets_all/MonoBehaviour/Crystals.json`）；
2. 取它的 `smallIcon.m_AssetGUID`，在 `AF/*/AssetBundle/*.json` 的 `m_Container` 里查到 `PathID`；

### 4·3 我们的「拥有数」是怎么来的（**我们自己的**，非原版）

- 原版 = `CurrencyExtensions.GetOwnedCount(GameCurrency)`，数据在后端（**拿不到**）。
- 我们 = `Wallet.Of(记账键)`（`CP/Shell/DailyData.cs:1396` 起；用户 2026-09-17 定的「不做真实经济 / 资源固定 9999」
  ⇒ 任何没记过账的键读出来都是 `StartAmount = 9999`）。
- **币种 → 记账键**这张表是**我们挑的**（我们的名册按**图名**记账，原版按枚举）：
  · `campaignPoints` → `40K_genearl_icon_Campaign_points_big`（A370 已落的口径）
  · `crystals` → `40k_general_icon_currency_crystal`（⚠️ 那是**大图**那一档，见 §六·4）
  · `gold` → `40k_topmarquee_currency_gold`
  · 其余 4 颗 → `null` = **我们没有任何一路会给它们记账** ⇒ 按 0 计
    （⇒ 非常显的那几颗默认**不显示**；blackStones 虽然也是 key=null，但它在**恒显集**里 ⇒ 照显）
- ⇒ **生产态默认显示 4 颗**（crystals/blackStones/gold + campaignPoints），与那张实拍逐颗吻合。
