## 四、A709（换口 · 期望值与容差**动没动**）

### 4·1 换口前后（整段 `CheckFits`，现读 `:8604–:8632`）

```csharp
static void CheckFits(Transform t, float boxPx, string what)
{
    var lb = t != null ? t.GetComponentInChildren<Label>() : null;
    if (lb == null) { CheckTrue(false, what + "（节点不在）"); return; }   // ← 未动
    float rx1, ry1, rx2, ry2;                                            // ← 新
    if (!TmpRenderedRect(lb.transform, out rx1, out ry1, out rx2, out ry2))  // ← 新（换口）
```

### 4·3 🔴 换口时**必须**补的那一句前置（否则是**弱断言**）

⇒ 少了那句前置，量不到时 `w = 0`、`0 ≤ boxPx + 1f` **恒真** ⇒ **假绿**。

### 4·4 为什么量的是 **`lb.transform`** 而不是 `t`（本件的一处**取舍**，如实标）

| | 旧 | 本件 |
|---|---|---|
| 取 `Label` | `t.GetComponentInChildren<Label>()`（**只找激活的**） | **一字未动**（同左） |
| 量哪个 TMP | （不量 TMP，读 `lb._tmpW` 缓存） | **刚取到的那一颗 `Label` 自己的 TMP**（`lb.transform`） |

- 若改成 `TmpRenderedRect(t, …)`（`CheckHAlign` 的写法），它会捞 `t` 底下**第一颗** TMP（**含 inactive**） ⇒ 与 `lb`（**只找激活的**）**未必是同一颗** ⇒ 会把「节点不在（红）」与「量到了别一颗（绿）」混成一档，**改变判据**。
- 用 `lb.transform` ⇒ **被测对象与旧写法逐字相同**（就是 `lb` 那一颗），只换测量口。TMP 是 `Label` 的**子件**（`Battle/Label.cs:784` `TmpFont.NewText(transform, …)`；同文件 `CheckWrapMode` 的订正注释也写着「`Label` 与 TMP **不在同一颗节点上**」）⇒ 找得到。
