## 二、照范本核过的 `ShadeHit` 签名与调用形状（现读）

### 2·1 签名（`Shell/MenuDraw.cs:1898-1899`，逐字现读）

```csharp
public static Transform ShadeHit(Transform dark, PxRect r, int qShade, int qContentMin,
                                 System.Action onClick, string name = "CloseHit", PxRect? clip = null)
```

对比 `Absorb`（`Shell/MenuDraw.cs:1999-2000`）：

```csharp
public static Transform Absorb(Transform parent, string name, PxRect r, int qShade, int qContentMin,
                               PxRect? clip = null)
```

🔴 **两者的参数顺序不一样**：`ShadeHit` 的 `name` 在**最后**、`Absorb` 的 `name` 在**第二**。
按 `Absorb` 那一行的顺序去写 `ShadeHit` ⇒ 把 `name` 当 `rect` 传 ⇒ **编不过**（已写进代码注释，⛔ 别再踩）。

### 2·2 语义差异（三处，来源 = 两段函数体现读）

| | `ShadeHit` | `Absorb` |
|---|---|---|
| 命中档 | `qShade`（**压暗层自己那一档**） | **由函数算** = `qContentMin − 1` |
| 动作 | `onClick`（`Hit(..., onClick, …)` ⇒ 带 `WindowButton`） | **`onClick = null`** ⇒ 命中后什么都不做 |
| 额外 | 挂 `ShadeHitMark`（`WasShadeHit` 的读口）；`qShade >= qContentMin` 时**出声** | 挂 `AbsorbMark` + **`wb.absorbOnly = true`**（`Click` 早退，零视觉零告警）；`q <= qShade` 时**出声** |
