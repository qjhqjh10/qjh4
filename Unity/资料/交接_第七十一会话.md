## 五、坑 / 承重结论（本会话新增，⛔ 别推翻）

1. 🔴 **`Check<T>(got, want, msg)` 是「相等」断言** —— 翻面时对调实参仍断相等（假绿）；必须 `CheckTrue(a != b, …)`。
2. 🔴 **`AnimFXCheck.cs` 真身在 `Assets/WarpforgeArena1/Editor/`**，`CardPresentation/Editor/` 下没有它。
3. 🔴 **编辑器批处理里 `DOTween` 的 `TweenExtensions.Kill/Complete/Play…` 全是静默 no-op**（`initialized==false` 直接 return）；
   `transform.DOKill()` / `DOTween.Kill(targetOrId)` 不读 `initialized`。⚠️ 判空验**先看接收者类型**（`WarpforgeEffectPlayer.Kill()` 是真生效的）。
4. 🔴 **全局覆盖（`DebugFrameTier` / `SmallScreenUI` / `CardTween.Mode`）必须在所有相关渲染/读数做完后再还原**（H1 踩过）。
5. 🔴 **`out` 参数陷阱**：`CountSet` 是 `out int`，帮助方法返回非 null 但 `out` 仍 0 ⇒ 既不报 gap 又静默 0。
6. 🔴 **`guid_map_bundles.tsv` 缺行 ≠ 零引用**（判零引用走卡 SO 类型树 / `cards_raw.json`）。
7. 🔴 **`play check` 的「①-a/①-b 差异段为空」不代表没差异**（已知量具 bug，A1 报过；判据要自己重生成基线逐行 diff）。
8. 🔴 **`scan` 对 `unitConditions` 这类纯数据改动结构性失明**（唯一兜底 = 卡池 md5 哨兵）—— P2 记。
9. ⚠️ **`PlayCard` 的 slot 是【请求格】不是落点**（连续无洞模型会挪格）；自检里**别按请求格取卡**，要按身份/`PlayOrder` 扫盘。
10. ⚠️ **`CardView.State` 默认 `Normal`** ⇒ 「断言 State == Normal」是同义反复，要先拨非默认档。
11. ⚠️ **`CreatedByVisible` 现在有「名字为空 ⇒ 不印」闸**；`Fill` 收空串会拆节点（不会点亮空节点）。
12. ⚠️ **`PinnedBaselineMd5` 是第四颗钉子**（重生成 `out_baseline.txt` 后必须一起改，漏了会报「基线被静默改写」，方向正好反）。
