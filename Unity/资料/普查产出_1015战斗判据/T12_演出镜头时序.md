## 结论

1. **原版战斗的镜头一共只有 5 类动作**：① **开场运镜**（每场一份 Unity 传统 `Animation` clip，2.5 s 从偏移位姿飞回相机本位）② **取景平移**（每帧按 zoom 算 `lensShift.y`，唯一写 `Camera.lensShift` 的地方）③ **自动缩放**（场上「较忙那半」人数 → 查曲线 → zoom，`SmoothDamp` 追上）④ **屏震**（两条并行通道：Cinematic impulse 与 CameraShake 传统抖屏）⑤ **画幅黑边**（`Camera.rect`）。**出牌 / 攻击 / 加时 / 结算开门 / 换牌期全部不改镜头**。
2. 🔴 **「摇镜」不是词不对，是真有这个功能，只是原版叫 `<场名> Camera Intro`**。13 场各一份 clip（12 份名 `Battle Arena X Camera Intro`，Leviathan 那份叫 `Battle Arena Leviathan`），**全工程唯一的播放入口就一句** —— `BattleManager.cameraAnim(0x190).Play()`。
3. **镜头不改 `transform`、不改 `fieldOfView`、不改 `aspect`**：全反编译里 `Camera.set_fieldOfView` **0 处**、`set_aspect` **0 处**、`Animation.Play` 在 BattleManager **只有一处**。运镜 = 那条 clip（改 vcam 的 `Transform`）+ 每帧写 `sensorSize`/`lensShift`。
4. **震屏有两条互不相干的通道**：新路 `AnimFXModuleScreenShake → CameraShakerManager → CinemachineImpulseSource`（活的）；老路 `ObjAnimEffects(op 40) → CameraShake.DoScreenShake`（⚠️ **原版战斗场景里没有 `CameraShake` 组件**，`FindObjectsOfTypeAll` 取空 ⇒ **空转**）。
5. **我们已做到 5 类里的 3 类半**（取景/缩放/手动摇镜/屏震都在），**唯一整件没做的是「开场运镜」**。

## 顺手发现（现场看到但不在范围内 —— 照实报，⛔ 我没改）

1. **两处 clip 命名错**：`bundle_scenes_scenes_battlearenasororitas` 与 `bundle_scenes_scenes_battlearenaspacewolves` 的 intro clip
   **都叫 `Battle Arena Emperors Children Camera Intro`**（原版资产里就重复/错名）。⇒ 将来**按名字找 clip 会撞车**，
   要**按包**取，别按 `m_Name`。
2. 🔴 **`CameraShake` 那条老抖屏路在原版战斗场景里就是空转**：`ObjAnimEffects` 与 `CameraShake.DoScreenShake` 都用
   `Resources.FindObjectsOfTypeAll<CameraShake>()` 取组件，而 **arena1 里没有 `CameraShake`**（`grep baseShakeTime` = 0）
   ⇒ 取空 → 静默 return。**⇒ 复刻优先级要按这条重估**（真正在响的是 `AnimFXModuleScreenShake` 那条）。
3. 🔴 **`BattleCameraSreenSize.Initialize(instant:false)` 的 3 秒 `DOTween` 补间是死代码**：
   `Initialize` 的唯一调用点是 `ResolutionHasChanged`，而它**传 `instant=true`**；`DoLensShift` **零调用点**。
   ⇒ 序列化 `animTime = 3.0` **在本 build 里从来不生效**（我们那边文件头也已经这么记了）。**⛔ 别照 3 秒去实现补间。**
4. **零调用点的公开方法**（复刻时别当成「活的」）：`CombatCameraZoom.DetectPlayerInput` · `CameraShake.AttackShake` ·
   `CombatCameraZoom.ToggleManualCameraControl`（同一逻辑 `LateUpdate` 里内联了一份）。
5. **`CombatAutoZoom.cs` 类注释里那句「人数 = `min(左半, 右半)` 传来的那个『较忙那半』」自相矛盾** ——
