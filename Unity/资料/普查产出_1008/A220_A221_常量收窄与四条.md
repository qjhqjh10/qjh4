## 一 · A220：队列常量可见性收窄

### 1·1 结论

- **放宽本身是必要的**（本仓 **0 个 `.asmdef`** ⇒ `Editor/` 与 `Shell/` 跨程序集，`private`/`internal` 够不着）——
  本件**只收「用不到的」**：收窄全部是**同一个类内**把 `public` 去掉（`public const` → `const`），
  **零行为变更**（`const` 的可见性只在编译期存在）。
- 收窄的判据 = **脚本逐常量扫全工程 `.cs` 的「外部代码引用」**：限定名 `类型名.常量名`，
  **已剔掉注释里的提及**（注释不产生编译依赖）；**0 处 ⇒ 可回 `const`**。
  - 脚本口径：**排除声明文件自己**；**300 个 `.cs`** 全扫；**限定名**匹配（非限定名跨类引用在 C# 里不可能出现）。
  - 🔴 **额外核过两件会「看着对、其实编不过」的事**：① **同文件里的第二个类型**（`LeaderboardWindow.TabEntry` /
    `MissionRerollPopup.MissionRerollContext`）**没有**用这些常量；② **没有任何类从这 5 扇窗派生**
    （`grep "class X : <窗>"` 全 0）—— 否则子类里的**非限定**用法会漏掉（`LiveOpsEventWindow` 那一族**正是**这种情况，见 §三·1）。
- 🔴 **收窄后 = A47 接线批之前那一形态**（实测 `git show 4ddbecf^`）：那一批把**整行**放宽成 `public`，
  而注释里写的理由只点名**两个**（「自检宿主要拿这两个档核…」）⇒ 本件就是把**没点名的那些**收回去。
- `QBase` **不在本批收窄范围**（它不是 A47 那批放宽的：`git log -S"public const int QBase"` 追到 **`c830abb`**，
  远早于 A47；且全工程 7 处 `QBase` 声明**清一色 `public`**）⇒ 保持原样，**逐文件在注释里写明**。
