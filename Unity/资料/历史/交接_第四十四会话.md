## 四、🔴 本会话踩过的坑 / 承重结论

1. 🔴 **同一个「卡」有两套命中矩形** —— 手牌/棋盘 = `BoxCollider2D` 主面（`HitHalfW/H`）· **展示窗 = `UI Collider`**
   （`UiColliderHalfW/H`，更小）。**写断言前先读清是哪一档**（本会话 `R5`：`W4` 的断言按前者取样、
   `W16` 已把实现改成后者 ⇒ 取样点落空、实得 −1/−1）。
2. 🔴 **旧读数可能是「坏状态」校准出来的** —— `R8` 的灭自证阈值 0.05 是按「底片停在旧分辨率」的
   0.2165 定的；修好之后真值只有 0.024 ⇒ 阈值反而不成立。**修完一个 bug，回头核一遍依赖它数值的断言**。
3. 🔴 **批处理里「显隐变化 → TMP 重排」必须由自检显式驱动** —— 节点从关到开之后 `OnEnable`/`Awake` 不跑，
   `WorldW` 停在初值、`textBounds` 是未测量哨兵 `4.29e9`。自检里要 `ForceRelayout()`。
4. 🔴 **拍品/奖励格要画「整层」就走抽屉库 `ItemDrawer.Draw`**（卡面 + 品阶 + 阵营名 + 数量 + 小徽）——
   我们锻造奖励已从「一张 150px 裸图」改成它；野牌 id = `Wildcard<阵营><1..4>`，图 = `40k_general_wildcard_*`（四档本地都有）。
5. 🔴 **`m_FileID` 是 1-based，且它指的是 cue 包装、不是 clip** —— 只在 `AudioClip/` 按 pid 找会得出
   「名字没解出」的**假结论**（本会话解出：`ButtonClick Back`→`UIButton Back` · `ButtonClick`→`UI Select Toggle`）。
6. 🔴 **`HudCanvas.Group` 的 z 账要 `Prune()`**（踢掉已销毁/已换父的登记）—— 否则反复重建同一件会让
   兄弟序漂（`Tooltip` 底图盖住文字就是它）。
7. 🔴 **主菜单的 `MenuScroll` + 裁切**：本文件的树全停在原点、拿绝对 px 当 `localPosition` ⇒
   **不能挂 `ViewportClip` 节点**（那会把节点挪走）；裁切走 **`MenuDraw.Nine(clip)` / `ClipText`**，
   卡图用 **UV 窗收缩**，命中区同裁。
8. 🔴 **写手并行修复必须对表**：同一件活两笔并行（断言 / 实现）**落地前互相对一遍**（`R5` 的教训）。
9. ⚠️ **`Collection Menu Variant` / `Shop Menu Variant` 原版 `useDefaultCloseSoundIfNull = 0`** ——
   已显式关（否则会多一声）。
10. ⚠️ **`LoadingMenu.StartFaded` 场景实例 = 0**（`=1` 的是 menus prefab 与战场实例）—— U3 原记录已订正。
