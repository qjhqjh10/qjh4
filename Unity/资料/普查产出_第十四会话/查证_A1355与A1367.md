## 一、`A1355` —— 结论：**成立，原版【确实】把空投舱当第一层判死血量；`.c` 那支不是假象 ⇒ 要做**

### 结论（一句话）
原版 `CardScript.EnoughPendingDamageToDieWithDamageValues` **确实**把 `dropPod` 血池当循环里的**第一层**，扣穿才往「幸存者/堡垒」走；
`.c:261` 那个 `iVar5 = 0` **是机器码里的真指令**（`0x1805ec25a xor esi,esi`），**不是** Ghidra 的渲染假象 ⇒ 这笔账**该做**，⛔ 不能按「读不通」挂起。

### 证据
入口：`all_methods.txt` = `6209024  CardScript$$EnoughPendingDamageToDieWithDamageValues` ⇒ **RVA `0x5EBE00` / VA `0x1805EBE00`**。

① **池子被读进来了**（`.c:90-99`）

0x1805ec093  mov    ebx,[rdi+0xdc]

### 推断链（实证 / 推断分开写）
- **实证①**：`.c` 的 if/else **两支体与机器码逐条相同**（含 `cmp esi,r13d` + `jge` 的**条件方向**）。
- **实证②（排除「假象」这一步是这么做的）**：我先按 `.c` 的布局假设「尾块就在 `LAB_1805ec100` 前面」，去 disasm `0x5EC0xx` 一看 —— 那里是**读池子 / 读攻击 / 初始化循环变量**（即 `.c:90-108`），**不是**尾块。
  真尾块被编译器放到**另一座岛**上：`0x1805EC225–0x1805EC266`，以**显式 `jmp 0x1805ec100`** 回边。
  ⇒ 这**正是**「`.c` 的块顺序 ≠ 地址顺序」的形状（`已知的坑.md` §8 第 1 条）；**但这一次它没有把语义弄反** —— 我按**地址顺序**重读了一遍，两支体仍与 `.c` 一一对应。
  ⇒ 「渲成 `iVar5 = 0` 与 if 支相同」不是渲染事故，**是原版的真行为**；**不能用「像 `A1168` 那类假象」把它挂起**。
- **实证③**：`esi` 在**每条**伤害上累加（`add esi,ebx`），池子只在 `esi < r13d` 时被扣、否则**这一条整个丢给池子**。
- **推断（有实证支撑）**：else 支「把累计清零」**不是读不通** —— 池子在结算侧**整份吃掉这一击、不溢出到血**（证据③），
  所以「清零 + 置 `bVar3`（此后走幸存者/堡垒）」与结算**自洽**。整句读作：**池子没花完 ⇒ 拿它抵；花穿了 ⇒ 这一击全给它、之后不再看它**。
- **推断**：`A1335` 给结算侧建的模型（`RuleCore.cs:4725-4746`）与本层是**同一条判据的两侧** ⇒ 预览侧该有它。
- ⇒ **落点/最小改法**（给写手的口径）：`RuleCore.cs:4398-4440` 的循环里，在**幸存者/堡垒那一块之前**加一层：
  `if (u.Has(DropPod) && !poolSpent) { if (acc < pool) { pool -= acc; acc = 0; } else { acc = 0; poolSpent = true; } /* 本轮跳过幸存者/堡垒 */ }`，
  `pool` 取 **`u.KwValue(KeywordTable.DropPod)`**（唯一来源，与 `ApplyDamage` 同一口，⛔ 别另开算式）。
  ⚠️ 原版是 `if / else` ⇒ 走池子那一轮**必须跳过**幸存者/堡垒块；只插一段 `if` 会**两边都算**。
  断言：带 `dropPod` 的单位，池没穿时**判死应为假**、穿的那一击**整份计入池**（`pool` 恰好减到 <1）；反向沙包 = 把这一层退回旧写法即变红。

### 还差什么

## 二、`A1367` —— 结论：**(γ) 不是缺陷**（`R7` 判得对，我独立复核过）；它 = `A1375` 的一个实例

### 结论（一句话）
`DA39` 走的是**裸写正文那条路**（`CardDef.CollectBareKeywordBody`）—— 那是解析层**明写的第二条路**，**原始数据本来就是这个形状**（两份数据源同形）
⇒ **不是缺陷**；它印出来差的那个冒号是**另一笔账 `A1375`**（渲染层）⇒ **改 `A1375` 一处即可覆盖 `DA39`**，⛔ 不要为此改 `DA39` 的数据。

### 证据
1. **数据（两份独立源同形 ⇒ 裸写不是我们改出来的）**
   · `cards_engine.json` 的 `DA39`：`desc="Stun an enemy"` · `keywords=["Flying","Rally"]`（**desc 里没有 `Rally:` 前缀**）
   · `card_stats.json`（源表）：同名卡 `desc="Stun an enemy"` · `keywords=["Flying","Rally"]` · `keyword="Flying, Rally"`
2. **解析层两条路，两条都在用**
   · **A 路** `CardDef.AddTriggerOp`（声明 `CardDef.cs:1230`，**要求 `X:`**）：现读 `DA37 Nephilim Jetfighter` = `keywords=["Flying"]` · `desc="Rally: Deal 3 damage to an enemy…"`（前缀在 desc 里）
   · **B 路** `CardDef.CollectBareKeywordBody`（`CardDef.cs:465`）：判据 ① desc 里**没有**带正文关键词的 `X:` 前缀 ② 本卡声明的带正文关键词**唯一**（表 = `BodyKeywords`，`CardDef.cs:278`）。
     `DA39` 两条都满足（`rally` 在表里、`Flying` **不在** ⇒ 唯一）；收进来的正文转调 `EffectText.Parse`（`CardDef.cs:511`）⇒ **两条路解析的是同一份 `desc`**。
3. **卡面**（PnP 还原抄录 `资料/卡表核对_卡图提取/_还原效果文字.md:316`）= `FlyingFlying. RallyRally: StunStun an enemy`
   ⇒ 印的是 **`Rally:`**（`RallyRally:` = 图标词 + 印刷词 + **冒号**）。
4. **渲染层就是差这个冒号（= `A1375` 的落点）**
   · `BattleDriver.FaceTextFull`（`BattleDriver.cs:11648-11649`）= `CardText.KeywordSegment(…) + core`
   · `CardText.KeywordSegment` 末行（**`CardText.cs:263`**）= `string.Join(zh ? "。" : ". ", …) + (zh ? "。" : ". ")` ⇒ **一律 `. ` 收尾**
   ⇒ `DA39` 印成 `⟳Flying. ⚡Rally. ⟳Stun an enemy`，卡面是 `Flying. Rally: Stun an enemy`。
   · **A 路不受影响**：`KeywordSegment` 的 ①（`CardText.cs:226`「正文字里已经有这个词 ⇒ 跳过」）会把 `Rally` 从关键词段剔掉，交给 desc 自己去印 `Rally: …`。

### 推断链
- **实证**：上面 1/2/3/4 全是现读（数据 + 代码 + 卡面抄录）。
- **推断**：`DA39` 的**效果本身会触发**（B 路把 `Stun an enemy` 解析成 `rally` 的 op）⇒ 差的只有**一个标点** ⇒ 「不是缺陷」成立；A1367 该**销账**。
- **`A1367` 与 `A1375` 的关系 = 同一件事的两面**：`A1367` 问「走哪条路」（答：B 路，没问题）；`A1375` 问「B 路印出来的样子对不对」（答：差冒号）⇒ **把力气放 `A1375`**。
- **`A1375` 的面（我复算的，⛔ 别照抄「~200 张」）**：
  · 按 `CollectBareKeywordBody` 那两条判据**离线复算全池 1126** ⇒ 真走得进那条路的 = **93 张**
    （`rally`20 · `artifice`10 · `codex`10 · `mob`7 · `strike`6 · `ecstasy`6 · `duty`5 · `agenda`/`ambush`/`uprising`/`ferocity` 各4 · `regiment`/`slay`/`cruelty` 各3 · `backlash`2 · `stimulation`/`pray` 各1）。
  · **逐张对卡面**（`_还原效果文字.md`）：**84 张卡面印的是 `X:`**；`EC39 Maulerfiend` 1 张我的判据挑的词与卡面印的不同（卡面是 `Strike:`）；**8 张按名字在那份抄录里找不到 ⇒ 未核**（如实）。
  · **数据自己的主流写法**：全池 1126 里「(卡,关键词) 对」带 `X:` 前缀 **194** 个、裸写 **95** 个（`rally`：65 带前缀 / 21 裸写）⇒ **`X:` 是同一张表自己的主流**，裸写是少数。
