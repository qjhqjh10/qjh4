### 三·3 「结果为什么能一处不变」—— 三条穷尽扫描（全池逐项扫，非抽样）

1. **标记词不可能拼出卡名**。英文那一趟是「按空白切词 → 拼回短语 → `Norm` → 查索引」

   （`<link=…>` 与 `<sprite name="…">` 里的**空格**把标记切成两段）⇒ 拼出来的键**必以
   `link` / `sprite` / `name` / `nobr` 开头**。
   **全池扫描：名字以这四个词开头的卡 = 0 张**（另：名字以数字开头的卡 2 张 ——
   `2nd Company Terminator` / `7th Company Bike`，而新加的、以数字开头的词只有
   `N</nobr></link>`（`N` = 关键词数值，`Norm` 后 = `Nnobrlink…`）⇒ 也拼不到那两张）。
2. **关键词段不可能多出、也不可能吃掉一次命中**。
   · 段里带进来的字**全是关键词显示名**（`Card_Trait/*` 那 62 条的中英两列）——
     **没有任何一个中文显示名含某张卡名（0）**，**没有任何一个英文显示名等于某张卡名（0）**；
   · **图标计划里的 token（或其单词）一个都不是卡名（0 处）** ⇒ 替换（把 token 吃掉那种）
     不会吃掉任何一次命中。
3. **备注那一半也扫了**。`FaceTextFull` 会在正文后追加 `UnimplementedNotes`（`词*` 与
   `效果本版…*`）：`效果本版结算不了` / `效果本版没作用` 两条中文备注**不含任何中文卡名**，
   带 `*` 的关键词形态 `Norm(英文名 + '*')` 也不是卡名。⇒ 那一半贡献 **0**。
