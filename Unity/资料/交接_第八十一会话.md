## 三、怎么完成（工作方式）

### 3·1 节奏（**用户 2026-10-26 定**）
- **不再「一批一同步点」**：子代理**回一个补一个**；**轻量记账随时做**；**重同步点**等主场域接近 100% 再做一次。
- 中间态安全：账的「漂移」只是行号；合并补丁**不需要 `.cs` 写手停手**。
- ⚠️ **两条硬约束**：① **主表只有调度台合并时写**（代理一律只写 `_parts/` 补丁）② **`--fix` / 重钉 / 重生成**必须在「没有账写手 + 没有 `.cs` 写手」时做。

### 3·2 并发与切块
- **10 路**（7 执行 + 3 查判据/顺手做）；**轮换阈值 = 上下文 80%**（⛔ 别 50% 就切）。
- **一文件一写手**：派活前**由调度台显式列出每个文件归谁**，⛔ 不能让代理自己按 `git status` 判「这个文件没人写」（两个代理同时开工时谁都没痕迹）。

### 3·3 落账三条铁律（本会话新增的工具链）
```bash

# 3) 只有当【没有 .cs 写手 + 补丁已合并完】时才压行号漂移
```
