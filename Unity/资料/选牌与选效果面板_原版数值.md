## 七、实况（2026-09-14 跑过一次）

| 项目 | 结果 |
|---|---|
| **数值** | ✅ 拿到 —— `资料/原版参照图/Unity参照管线_0825/data/panel_0914/runtime_rect_choose_panel.tsv`（+`runtime_rect_mulligan.tsv`）。每个节点的 `rect`/`sizeDelta`/`anchoredPosition` **与静态 JSON 逐条相同**；另有 `lossyScale=0.0674`（世界尺度，**随分辨率/相机变，不是要抄的参数**）· `ChooseCardMenuAnchor childCount=0` |
| **观感（截图）** | ❌ **没拍到** —— 3 张 shot 只有 3D 战场、UI 一张没有；`shot_mulligan_panel.png` **全黑** |
| **根因** | `uiCam.Render()` + `targetTexture` 在 **URP 下画不出 UI**（UI Camera `clear=Nothing` 却把 RT 清成黑 = 它根本没往 RT 里画东西），与 2026-08-25 那次全空同因。`ScreenCapture` 早验证会崩 ⇒ **这条路走不通** |
| 卡在哪 | ① 手牌注入仍 `inj FAIL: empty Data`（日志同现 `CardsCollectionAddressables found: 0`）② 面板要触发才有卡，探针强制展开也只有空框 ③ URP 下无可用 UI 截屏手段 |
| ⇒ 结论 | **数值是实况核过的，观感仍无实况证据。** 要拿观感，得先解决「URP 下的 UI 截屏」，**不是再跑一次能解决的** |
