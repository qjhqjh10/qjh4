## 五、顺手发现（⛔ 只报不改）

1. **`LiveOpsEventWindow.StartBotBattle` 是「唯一 LoadScene 点」之一，但它是 `public` 且不是 `virtual`** —— 子类**没法**在「真正切场景那一刻」插手，只能挂 `OnSearchFinished`（基类紧接着调，语义上够近，但**是间接的**）。根因：这一步里 `BattleSceneFor(faction)` 在批处理早退**之前**调，所以连它也不能当钩子。**建议**（另一笔账）：把 `StartBotBattle` 改成 `virtual`，或在基类加一个 `protected virtual GameMode PlayModeForWindow`，让「本窗模式号」像 `DeckGameMode` / `BattleSceneFor` / `TrophyIconArt` 一样成为**子类声明的一格**。
2. **`BattleDriver.cs:2106` 那条警告的措辞**（「卡组张数（N）和**本局模式**对不上（遭遇 12 张 / 经典 30 张）」）—— 它判的其实是**规则参数**（`_vars`），而「本局模式」现在是个真枚举了。⚠️ 我**没改**（改了要动 `Editor/BattleScene.cs` 里可能钉着它文案的断言，且属措辞）。建议随 §四·1 那批断言一起改。
3. **「12 张的牌从练习窗开出去」这条缝是真的**（`PracticeModePopup.Open()` 只把 `DeckIndex` 重置成 `DeckLibrary.Current`，**不筛模式**；筛模式的是它**开出去的那扇**选卡组窗）⇒ 会出现 `PlayMode = OfflinePractice(6)` 但 `Vars = 遭遇那套` 的一局。原版 UI 不允许这种局面。本轮**按现状如实记录**（`NetPendingBattle.Vars` 特意按牌判、就是为了让这种局面重放也一致）。要不要在练习窗也拦一道，属另一笔账。
4. `Editor/BattleScene.cs:4769` 那条既有断言 `Check(rec.Mode == (ctx.Vars.IsSkirmish ? "Skirmish" : "Classic"), …)` —— **现读仍然成立**（那个宿主里 `PlayMode` 恒走兜底那一支，两句逐字等价）。⚠️ 但它现在**只覆盖兜底那一支**；真正声明过模式号的那四条路它一条都没覆盖（= §四·1 的缺口）。
