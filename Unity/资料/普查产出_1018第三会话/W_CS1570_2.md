## 改法：逐条怎么转义的
- **38 处只做转义**，`<`→`&lt;` · `>`→`&gt;` · `&`→`&amp;`（成对的尖括号如 `<枚举名>` / `<Deck>` /
  `<turnCounter>` / `<属性>` 两端都转；当「小于号」用的裸 `<`（`a < b` / `< 1` / `490.45 < 视口`）只转 `<`）。
  **一处一个字都没增删**，全部是同一行的字符替换（38 行 ⇒ `git diff --numstat` 逐文件 +1/-1 或 +N/-N）。
- **正文里合法的 XML 标签一律没动**（`<summary>` / `<para>` / `<see cref=…>` 等）。
- ⚠️ **两处 `//` 普通注释（非 `///`）没动** —— csc 不解析它们，不属于 CS1570：
  `SettingsPanel.cs:288` · `NetBattle.cs:459` · `SettingsWindow.cs:1257` · `RuleCore.cs:1024` · `UnitState.cs:335`
  （这几处与我要改的那几行**字面几乎一样**，很容易误伤 —— 我的锚点都加长了以确保唯一匹配）。

### 🔴 单列：`TutorialModePopup.cs` 的**第 39 处**（**不是转义，是真结构错，被我的修复「露出」的**）
- 现象：转义 `:221` 的 `<Deck>` 之后，`:233` **新报 1 条** `结束标记 para 与开始标记 summary 不匹配`。
- 真因（**HEAD 里就已经如此**，不是本轮谁改坏的、也不是我改出来的）：`:216-233` 那段 doc 里
  **`<para>` 开 5 次**（217/218/220/222/227）、**`</para>` 关 6 次**（217/219/221/226/228/**233**）——
  多一个闭。`:229` 那条 `⚠️ 原版还有两列本地取不到…` 是**没被 `<para>` 包住的裸段**，却以 `</para></summary>` 收尾。
  原先被 `:221` 的 `<Deck>` 吃掉了（解析器在 `</para>` 处重新同步），所以**一直没报**。
- 改法：给 `:229` **补上缺的那个 `<para>`**（⇒ `/// <para>⚠️ **原版还有两列本地取不到**…`）。
  **判据 = 本仓约定**：`grep -rn '/// <para>⚠️' --include=*.cs` = **323 处**（⚠️ 提示一律各自成段）；
  且**作者自己的习惯也指向这一改** —— 同文件 `:622` 那段没有 `<para>` 时结尾就只写 `</summary>`，
  而这里偏偏写了 `</para></summary>` ⇒ 作者当时以为自己在 `<para>` 里。**正文一字未改**。
