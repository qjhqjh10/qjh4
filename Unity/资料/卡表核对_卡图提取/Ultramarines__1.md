## 存疑

1. **「字段」列对非部队卡照抄了那行橙字（与规格书 §二 的字面要求冲突）**。规格书 §二说「字段只填部队卡兵种，类型名填 `—` 并写进存疑」；本次收到的指示是「一律照抄那行橙字（填进字段列）」。我按后者填了，在此登记原文，便于回退：
   - `Warlord`：UPDATED_Warpforge_01_Roboute-Guilliman.png、Warpforge_00_Lieutenant-Titus-2.png、Warpforge_01_Chaplain-Letharius-2.png、Warpforge_06_Valius-Paxor.png、Warpforge_1_Marneus-Calgar.png、Warpforge_3_Uriel-Ventris.png、Warpforge_5_Varro-Tigurius.png
   - `Codicil`：Warpforge_03_Primarch-of-the-XIII.png、Warpforge_04_Master-of-Battle.png、Warpforge_05_Supreme-Strategist.png
   - `Psychic Power`：Warpforge_23_Spear-of-Macragge.png、Warpforge_7_Might-of-Heroes.png、Warpforge_9_Smite.png、gaze.png
   - 我**没有**在本批看到 `Defence` / `Dark Pact` / `Overlord Power` / `Combat Elixir`。本批 45 张里也没有任何一张「5防御卡」目录的卡。

2. **版面差异 A：橙字大卡名的卡没有白色卡名、也没有橙字阵营行。** 本批 16 张是「橙字大卡名 + 无 `Ultramarines` 行」：Roboute Guilliman / Valius Paxor / Author of the Codex / Primarch of the XIII / Master of Battle / Supreme Strategist / Angel's Wrath / Catechism of Death / Suppressor / Incursor / Phobos Lieutenant / Tactical Marine / Firestrike Servo-Turret / Scout Sniper / Vico Therbeus / Attack Bike。
   其余 29 张是「白色卡名 + 橙字 `Ultramarines`」。**两类在同一个目录里混着出现，看不出与类型/稀有度相关**。
   ⇒ 所以「橙字阵营行」不是每张都有，别拿「没有阵营行」当数据缺失。

3. **督军卡（7 张）没有右上角费用六边形**——那个位置画的是带翅膀的 Ultramarines 阵营徽章。所以 7 张督军的「费用」都是 `—`，不是我没看清。同理，督军卡右侧也没有护甲盾牌（只有红 2 / 紫 2 / 绿生命 / 底部宝石四项）。

4. **三种「蓝色圆形徽章」我可能分不清**（尺寸只有约 40px，语义我不敢猜，只按形状区分）：
   - `【图标:蓝圆徽-放射】`＝蓝圈内白色放射状/罗盘状纹路 → 出现在 **Codex** 前面（Guilliman、Author of the Codex、Master Tactician、Primaris Techmarine、Heavy Intercessor、Primaris Eradicator、Storm Speeder Hailstrike）。
   - `【图标:蓝圆徽-图形】`＝蓝圈内一个白色小人/翼状图形 → 出现在 **Oath** 前面（Suppressor、Angel's Wrath、Catechism of Death、Incursor、Phobos Lieutenant、Tactical Marine、Firestrike Servo-Turret、Scout Sniper、Vico Therbeus、Attack Bike）。
   - 我用两个不同的描述是因为观感确有差别；但如果其实同一个图标，这两组会被我拆成两个 —— 请以实物复核。

5. **白色圆形关键词图标也分两种，可能被我拆错或并错**：
   - `【图标:白圆徽-水滴】`＝白圈内深色水滴/兜帽形 → Camouflage（Scout Bike、Scout、Scout Sniper、Vico Therbeus）。
   - `【图标:白圆徽-盾准星】`＝灰白圈内盾形加准星/箭头 → Long Range（Phobos Lieutenant、Firestrike Servo-Turret）。
   两者在 900px 图上都是「白色小圆盘」，差别很小。

6. **`【图标:红白圆徽】` 同时用于 Sentry 与 Vanguard**（Master of Battle、Suppressor、Firestrike Servo-Turret 的 Sentry；Supreme Strategist、Assault Intercessor 的 Vanguard）。这两张图我看不出可靠差别 —— 可能本来就是同一枚图标，也可能是两个相似图标被我并了，请复核。

7. **Warpforge_7_Might-of-Heroes.png 的 `Shield` 图标**（`【图标:眼睛】`）看起来和 Stealth 的「眼睛」图标是同一种同心椭圆造型 —— 一个效果文字里写着 Shield 却用睁眼图标，这有点反常，我按看到的形状记，没有按语义改。

8. **UPDATED_Warpforge_15_Suppressor.png 的效果里 `this game` 与 `and` 之间有一个明显空档**（像是漏印的图标或排版空隙）。我按普通空格照抄，如果其它批次也有同样空档，值得单独判一下是不是少了一个图标。

9. **稀有度判色**：本批出现三种宝石。偏**青/浅蓝**的我记 `common`（Heavy Intercessor、Eliminator Sergeant、Storm Speeder Hailstrike、Scout Sniper、Scout、Assault Intercessor、Attack Bike、Incursor、Tactical Marine）；**绿**记 `rare`；**紫**记 `epic`；**金/橙黄**记 `legendary`。青与绿在这批图上差别不算大（青的更接近白蓝），如与其它批次口径不一致请统一。

10. **有两套卡框版式并存**：一套是「图 + 下方独立文字面板」（如天赋卡、UPDATED 系列），另一套是「文字直接压在图上」（如 Warpforge_01_Chaplain-Letharius-2 / Warpforge_06_Valius-Paxor / Warpforge_07_Incursor / Warpforge_08_Phobos-Lieutenant / Warpforge_09_Tactical-Marine / Warpforge_10_Firestrike-Servo-Turret / Warpforge_12_Vico-Therbeus / Warpforge_13_Attack-Bike）。字段位置不变，但同一张卡的效果文字行数会因此不同 —— 我没有按版式做过任何推断。

11. 本批**没有任何「5防御卡」目录的卡**，也没有近战/远程/生命全缺的部队卡；`3部队` 目录 19 张全部有近战/远程/生命（符合规格书「有近战/生命的是部队」的判据）。
