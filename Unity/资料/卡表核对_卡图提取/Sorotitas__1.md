## 存疑

- **四张督军卡**：`Warpforge_01_Celestian-Sacresant-Aveline.png` / `Warpforge_01_Erika-Luminas.png` / `Warpforge_03_Junith-Eruita.png` / `Warpforge_05_Morvenn-Vahl.png` —— 效果下面那行橙色小字写的是 **`Warlord`**（类型名，不是兵种），按规格 `字段` 列填 `—`。这四张卡右上角**没有蓝色六边形费用**（那个位置是阵营大徽记），所以 `费用` 也是 `—`；生命右下角是绿色方块数字（35/35/35/40），近战/远程是左下红紫两圆（各 2），**没有盾牌**。
- `Warpforge_04_Sacred-Rose-Sister.png` —— 效果文字的行首布局异常：第一段被上下拆成「2【图标:太阳】 Gain +1【图标:拳头】 and」/「: +1【图标:爪】 4【图标:太阳】 Gain +1」，**第二行以「:」开头**。我按画面上看到的顺序逐字抄了（保留了那个孤立的冒号），实际语义多半是「2【太阳】: Gain +1拳头 and +1爪  4【太阳】: Gain +1 Health」。请勿把它当成原文里真有那两个位置。
- **`Pray:` 前的小图标有两种样子，我不确定是不是同一个图标**：白圈淡色「人形」（Aveline / Erika Luminas / Junith Eruita / Morvenn Vahl / Ministorum Priest / Battle Sister / Battle Sister Gunner / Celestian / Dialogus / Hospitaller / Sacred Rose Sister / Sister Superior / Zephyrim Superior / Aestred-Thurga / Celestian Superior）与白圈「骷髅+交叉骨」（Sister Novitiate / Simulacrum Bearer / Imagifier / Simulacrum Celestian）。后者与 `Penitence:` 用的图标看起来是同一个（Arco-flagellant / Death Cult Assassin / Sister Repentia / Penitent Engine）。我分别记作【图标:人形】和【图标:骷髅】，**请对比旧数据判断这两个到底是不是同一个关键词图标**。
- **`Shield` 关键词前的图标形状存疑**：多张卡（Daemonbreaker / Sacred Rose Sister / Adelaide the Serene / Preacher / Celestian / Dialogus / Aestred-Thurga）上它是**青色圆圈里一个杏仁形+深色瞳的形状，看起来像「眼睛」，不像盾牌**。我按形状记作【图标:眼睛】。而 `Armour` 前的图标是明确的**银白盾牌**（Castigator / Crusader / Canoness / Celestian Sacresant），记作【图标:盾牌】。前者可能才是「盾」的另一种画法，请核。
- **`Vanguard.` 与 `Strike:` 的图标**：都呈「红圈 + 白色骷髅」的样子（Crusader / Celestian / Celestian Sacresant 的 Vanguard，Missionary 的 Strike）。Crusader、Celestian 两张上图形很小，我一度看成盾形；以 Celestian Sacresant 的大图为准统一记作【图标:骷髅·红】。两者是否同一个图标不确定。
- **`Camouflage.` 前的图标**（Death Cult Assassin / Ephrael Stern）：白圈内是一个淡灰「尖形」纹样，像兜帽/尖盾/贝壳，**认不出语义**，暂记【图标:尖盾】。
- `Warpforge_13_Hymn-of-Battle.png` —— 末句「or Deploy a Crusader」里，`Deploy` 后面我**没看到**图标（同一张卡的「Gain 1」后面有明显的金色太阳图标）。如果旧数据里这里有图标，是这一处我看漏了。
- **【图标:卡片】与【图标:卡片·爆裂】是不是同一个图标不确定**：`Talent:` 前是白卡片+深色绶带；`Ephemeral.` 前是白卡片+右上角橙黄爆裂。我按看到的差别分成两个写法。
- **版面观察（不影响上面 11 列）**：`Warpforge_06_Sororitas-Rhino.png`、`Warpforge_19_Sister-Repentia.png`、`Warpforge_24_Seraphim.png` 三张卡**没有**卡名下面那行橙色阵营小字（`Adepta Sororitas`），卡名下面直接是效果文字。
- **本批没有看到橙红宝石（special）**；出现的只有 common（浅青）/ rare（绿）/ epic（紫）/ legendary（金）四种。
