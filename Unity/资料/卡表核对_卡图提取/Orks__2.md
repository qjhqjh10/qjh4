## 存疑

- **图标命名是我的形状描述，不是关键词判定**（规格 §四 要求描述形状）。本批用到 14 种，逐一说清我看到的形状，供你们和旧数据比对：
  - `【图标:红骷髅徽章】` = 红色盾形/菱形小徽章，里面白色骷髅 + 交叉骨头（有时像上下两排牙）。**文案里一律出现在 `Mob:` 前面**（本批 13 张：Zodgrod / Shoota Boy / Spanner / Skarboy Nob / Snakebite Battlewagon / Gargantuan Squiggoth / Killa Kan / Mekboy Gazmek / Big Shoota Boy / Meganob Ugrak / Deff Dread / Battlewagon，以及计策 Stomp 'Em）。
  - `【图标:绿圆骷髅】` = 绿色圆盘 + 白色骷髅与骨。**一律在 `Unstable` 前面**。
  - `【图标:青圆骷髅】` = 青绿圆盘 + 白色骷髅。**一律在 `Tide N` 前面**（Squighog Boyz / Deffkopta / Boomdakka Snazzwagon / Killa Kan）。
  - `【图标:橙圆骷髅】` = 橙红圆盘 + 白色骷髅。只出现在 Beastboss on Squigosaur 的 `Slay:` 前。它和上面三种「圆盘骷髅」是不是同一个图换配色，我判断不了 —— **如果要合并，请以旧数据里的关键词 ID 为准**。
  - `【图标:粉圆骷髅】` = 品红圆盘 + 白色骷髅（骷髅上像插着一把短剑）。出现在 `Strike:` 前（Rukkatrukk Squigbuggy / Kommando）。
  - `【图标:红盾骷髅】` = 红色**盾形**轮廓 + 白色骷髅。出现在 `Vanguard` 前（Snakebite Battlewagon / 'Ardshell Gurk）。**它与 `Mob` 的红徽章长得很像**（都红底白骷髅），我靠「盾形轮廓 vs 徽章形」区分，**这两个可能是同一个图，存疑**。
  - `【图标:盾牌】` = 银白色盾牌（`Armour N` 前面那一个）。
  - `【图标:爪】` = 白色兽爪印 + 棕黄底（`Stomp` 前）。
  - `【图标:闪电】` = 黄色闪电（`Rally:` 前）。
  - `【图标:循环箭头】` = 两个橙色弧形箭头围成一圈（`Flank` 前）。
  - `【图标:齿轮】` = 金色齿轮/星形（Warbiker 的 `Fast` 前）。
  - `【图标:眼睛】` = 蓝灰色圆 + 白色眼形/月牙（`Stealth` 前）。**注意**：Weirdboy 的 `Shield.` 前面那个图标我看到的也是「浅蓝圆 + 白色眼形」，和 Stealth 的图标形状相同 —— 我按看到的形状记成 `【图标:眼睛】`，**但文案是 `Shield`，这两个图标的对应关系存疑**。
  - `【图标:书】` = 白色纸张/书页 + 黑色符号（`Talent:` 前）。
  - `【图标:爆裂】` = 紫色圆 + 白色爆裂/花瓣状图案（`Blast N` 前）。
  - `【图标:漩涡】` = 棕金色同心螺旋/靶心（`Stun` 前）。
  - `【图标:翅膀】` = 青白翅膀（`Flying` 前）。
  - `【图标:红齿】` = 红色圆 + 白色锯齿状大口/牙齿。只出现在 Dead Choppy 的 `Blood Thirst` 前。**同一个图案也出现在 Beastboss on Squigosaur 卡面左下角**（叠在近战红圈 7 的左上，见下条）。
  - `【图标:黄绿圆飞机】` = 橄榄/黄绿圆 + 白色飞机/飞弹形（`Concussive` 前，Gunwagon / Stompa）。这个形状我**认得最不确定**，可能是鸟、导弹或某种飞行物。
- **Beastboss on Squigosaur**：左下角近战红圈 `7` 的左上叠着一个小红圆徽章（白齿/血口图案，即上面 `【图标:红齿】`）。它不是效果文字的一部分（没有文字与之相连），我**没有**写进「效果原文」。请判断这是不是「本卡带 Blood Thirst」的数值标注。
- **计策卡（8 张）**：卡面下半部是棕色文本框，**没有**「效果下面那行橙色小字」—— 也就是说**计策卡看不到任何归类/类型行**。`字段` 列全部填 `—`。类型我按所在目录 `4计策` 判为 `计策`（版面也符合：无攻/甲/血）。
- **部队卡（37 张）**：橙色小字一律是兵种（Infantry / Vehicle / Beast 三种），没有一张写 `Defence` 之类。本批**无防御卡**，所以规格「补充」一节说的那行橙色字没机会验证。
- **卡名字色**：这 45 张的**卡名都是橙色**（不是规格 §二 写的「白色大字」），且**卡名下面没有单独的阵营名行**（如 `Orks`）—— 卡名下面直接是效果文字。规格 §二 的版面描述与这批实物不符，按实物记。
- **标点/引号**：Beastboss on Squigosaur 效果里的 `"Slay: ..."` 卡面用的是弯引号，我统一写成直引号 `"`。`Stomp 'Em`、`Dok's Toolz` 同样按直引号 `'` 抄。
- **文件名 `Warpforge_25_Cyber‑augmentation.png`** 里的连字符是 **U+2011 不换行连字符**（我从工作清单原样复制），卡名我在表里按普通连字符写成 `Cyber-augmentation`。
- **Killa Kan 效果首行**：卡面是 `【图标:青圆骷髅】 Tide 1` 后面**没有句号**，直接接第二个图标 `【图标:绿圆骷髅】 Unstable.`。同理 Deff Dread `Unstable` 后无句号、Battlewagon `Unstable` 后无句号、Stompa `Armour 2` 后无句号 —— 我按卡面照抄，没有替它补标点，**这几处可能是排版漏字，不是我抄漏**。
- **稀有度**：本批出现的宝石色只有 浅蓝(common) / 绿(rare) / 紫(epic) / 金(legendary) 四种，**没有橙红(special)**。Zodgrod Wortsnagga / Beastboss on Squigosaur / Painboss / Ork Nob / Mekboy Gazmek / 'Ardshell Gurk 六张底部是**金黄色菱形**，我判为 `legendary`（不是 `special`）。
