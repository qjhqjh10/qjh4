# 卡面逐张提取 · 规格书（子代理必读）

> 2026-09-13 建立。**你要做的是「看图抄数据」，不是「理解游戏」。**
> 唯一权威来源是卡图本身（PnP 打印卡，900×1200 PNG）。**不许参考任何已有的 md/json 数据**。

---

## 一、卡图在哪

`D:\2\Warpforge部队卡片\<阵营>\<类别>\*.png`

类别目录：`1督军` `2天赋` `3部队` `4计策` `5防御卡`（另有两个特例：Genestealer Cult 的 `6破坏卡`、
Emperor_s Children 的 `6药剂`、Dark Angels 的 `6秘密`）。

⚠️ **跳过**任何名字里带 `卡背和部队卡PDF（用不着）` 的目录 —— 那不是卡。

## 二、卡面版面（按位置认字段，别猜）

一张卡从上到下长这样：

| 位置 | 是什么 | 怎么记 |
|---|---|---|
| **右上角蓝色六边形** | **费用** | 纯数字 |
| 左上角圆形徽章 | 阵营图标 | **不用记** |
| **中间白色大字** | **卡名** | 逐字抄 |
| 卡名下面**橙色**小字 | **阵营名**（如 `Ultramarines`） | 逐字抄 |
| **再下面的白色文字块** | **效果 / 关键词文字**（带图标） | **逐字抄**，图标见 §四 |
| **效果文字下面那行橙色小字** | **字段**（兵种，如 `Infantry` / `Vehicle`） | ⭐ **这一列最要紧**；没有这行就写 `—` |
| 左下**红色**圆（剑图标） | **近战攻击** | 数字 |
| 左下**紫色**圆（枪图标） | **远程攻击** | 数字 |
| 右侧**盾牌** | **护甲** | 数字；盾牌上没有数字就写 `—` |
| 右下**绿色**方块 | **生命** | 数字 |
| 底部中间**宝石** | **稀有度** | 见 §五 |

⚠️ **不是每张卡都有全部字段**：计策/天赋/防御卡通常没有攻/甲/血，也没有「字段」那行橙色字。
**缺哪一项就写 `—`，绝对不要写 `0`、也不要按「别的卡长这样」去补。**

### ⚠️ 补充（2026-09-13，第一批跑完发现的）

**「效果下面那行橙色小字」是「这张卡的归类」**，具体写什么看卡的类型：

| 卡的类型 | 那行橙色字通常写 |
|---|---|
| 部队 | **兵种**：`Infantry` / `Vehicle` / `Drone` / `Beast` / `Character` … |
| 防御卡 | `Defence` |
| 别的类型 | 可能没有这一行 |

⇒ **`字段` 这一列只填「部队卡的兵种」**（Infantry/Vehicle/Drone/…）。
如果那行写的是 `Defence` 之类的**类型名**，这一列填 `—`，并在 `## 存疑` 里说明你看到了什么。
（不是让你无视它 —— **看到了就写进存疑**，我们要靠这个判断版面规律。）

## 三、输出格式

写一个 markdown 文件，**表头逐字照抄下面这一行**（列的顺序和名字都不许改）：

```
| 文件名 | 卡名 | 费用 | 近战 | 远程 | 护甲 | 生命 | 字段 | 类型 | 稀有度 | 效果原文 |
|---|---|---|---|---|---|---|---|---|---|---|
```

- **文件名**：PNG 的文件名（含 `.png`），**原样**，这是回溯凭证
- **类型**：只许填这五个之一 —— `督军` / `部队` / `天赋` / `计策` / `防御`
  （判据：所在目录 + 版面。**有近战/生命的是「部队」**；督军没有费用但有生命；
  计策/天赋没有攻甲血。拿不准按目录名填，并在最后一列标 ⚠️）
- **效果原文**：**逐字抄英文原文**，不要翻译、不要改写、不要纠正拼写、不要补全缩写。
  卡面上的句号/换行照抄（换行用空格接起来即可）。

**文件末尾**再加一节 `## 存疑`，逐条列出你拿不准的卡（文件名 + 一句话说明）。
没有就写 `（无）`。

## 四、效果文字里的**图标**怎么记

卡面效果里有大量**图标**（不是文字）。统一写成 `【图标:形状】`：

```
【图标:眼睛】【图标:准星】【图标:盾牌】【图标:骷髅】【图标:齿轮】【图标:水滴】
【图标:拳头】【图标:闪电】【图标:爪】【图标:书】【图标:六边形】【图标:?】
```

- 描述形状即可（眼睛/准星/盾牌/爪/骷髅…），**认不出语义就写 `【图标:?】`** ——
  **不要猜它是哪个关键词**，那会把我们的数据带偏。
- 同一个图标在不同卡上**用同一个描述**（比如一直叫它 `【图标:眼睛】`），我们要靠它做比对。

## 五、稀有度 = 底部宝石的颜色

| 宝石颜色 | 稀有度（照抄这个英文词） |
|---|---|
| 浅蓝 / 青色 | `common` |
| 绿 | `rare` |
| 紫 | `epic` |
| 金 | `legendary` |
| 橙红 | `special` |

## 六、纪律（重要）

1. **一张都不许跳**。你负责的每一张 PNG 都要在表里出现一次，**一行一张**。
   写完之后**自己对一遍**：表里的行数 == 你负责的 PNG 数，不等就补。
2. **看不懂就标 ⚠️**，不要编。宁可交一张「有 3 处存疑」的准确表，
   也不要交一张「全都填满」但掺了猜的表 —— 我们要拿它去核对旧数据。
3. **不要读别的 md / json**（尤其不要读 `卡牌数据总表.md`）——
   你的价值就在于**独立**抄一遍，好和我们已有的数据对照。
4. 效果文字**很长**的卡（5~6 行）慢慢读，别漏掉后半句 ——
   `Codex:` / `Oath N:` / `If …:` 这些前缀后面的内容同样要抄。
