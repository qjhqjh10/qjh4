## 存疑

1. **图标 16 种，全部是「按形状取名」，语义未对照任何规则书**（照规格要求不猜关键词）。用到的标签与出现处：
   - `【图标:骷髅】` = 白色圆颅骨 → Remnant（多数卡）/ Backlash（`Warpforge_08_Lokhust-Lord.png`）
   - `【图标:爪】` = 金色圆底白色爪形 → Destroyer
   - `【图标:拳头】` = 红/棕圆底白色握拳 → 近战 +1（`Warpforge_01`、`Warpforge_02_Hardwired-Destruction`）
   - `【图标:准星】` = 紫底同心圆+十字准星 → Sniper（`Warpforge_21_Deathmark`）与远程 +1（`Warpforge_02_Hardwired-Destruction` 的第二个图标）
   - `【图标:盾牌】` = 蓝银盾 → Armour
   - `【图标:十字】` = 绿底白十字 → Regeneration
   - `【图标:齿轮】` = 白蓝齿轮 → Artifice
   - `【图标:翼】` = 蓝底白展翅 → Flying
   - `【图标:翼(红)】` = 红底白徽记 → Vanguard（见第 2 条）
   - `【图标:书】` = 倾斜的米色矩形（卡片/书页状）带深色印记 → Talent
   - `【图标:星】` = 白色放射状/星爆形（带红棕芯） → Ephemeral
   - `【图标:爆炸】` = 紫底圆徽里的白色爆裂形 → Blast
   - `【图标:闪电】` = 金/黄底白色闪电 → Rally
   - `【图标:眼睛】` = 圆底白色眼睛 → Stealth
   - `【图标:螺旋】` = 棕橙底白色螺旋 → Stun（`Warpforge_23_Psychomancer`）
   - `【图标:循环箭头】` = 棕橙底白色环形双箭头 → Flank（`Warpforge_17`、`Warpforge_24`、`Warpforge_28`）
2. **`【图标:翼(红)】`（Vanguard）语义不明、且与 `【图标:翼】`（Flying）形状相近**：Vanguard 是红底白色徽记，看起来像带翼的骷髅/带角小兽；Flying 是蓝底白色双翅。我按底色把它们分成两个标签。若二者本应互不相干，请以「Vanguard 行上的那个红底徽记」为准。
3. **`【图标:爪】`（Destroyer）与 `【图标:拳头】`（近战 +1）都是手爪形白徽记**，只靠底色区分（金底 vs 红/棕底）。若对照发现两处应为同一图标，说明底色判断有误。
4. **`Warpforge_08_Lokhust-Lord.png` 的 Backlash 图标与 Remnant 图标都是骷髅形**，肉眼难分（Remnant 为白/灰正脸颅骨，Backlash 略大略亮）。两处我均记 `【图标:骷髅】`；若原版设计中 Backlash 另有图标，此行会漏掉一处区分。
5. **`【图标:星】`（Ephemeral）与 `【图标:爆炸】`（Blast）都是放射/爆裂形**：Ephemeral 是独立的白底红芯星爆，Blast 是紫色圆徽内的白色爆裂。低分辨率下有认混的可能（`Warpforge_2/38/44/4/6` 的 Ephemeral，`Warpforge_09_Annihilation-Barge`、`Warpforge_12_Tesla-Immortal` 的 Blast）。
6. **`Warpforge_01_Ramatekh-the-Cruel.png` 卡面上没有橙色的阵营行**（另外三张督军 `Imotekh`/`Nemesor`/`Orikan` 都有 `Sautekh Dynasty` 橙字，且 `Warpforge_22_Night-Scythe.png` 这张部队卡也没有橙色阵营行）。不确定是漏印还是该卡本就不显示，故照实记录。
7. **督军卡的「费用」**：右上角六边形里只有阵营徽记、**没有数字**，故 4 张督军费用一律记 `—`（不是 0）。
8. **护甲**：45 张里只有 `1_Warpforge_30_Lychguard.png` 画了盾牌（数字 2），其余 44 张盾牌位无数字 → 全部 `—`。
9. **`1_Warpforge_30_Lychguard.png` 文件名带 `1_` 前缀**（与同目录其它文件命名不同），照原样抄。
10. **`Warpforge_25_Canoptek-Reanimator.png` 的字段行是 `Monster`**（本批唯一的非 Infantry/Vehicle/Warlord 字段），已照抄。
11. **`Warpforge_19_Canoptek-Spyder.png` 卡面上没有 Remnant 图标**（本批其它 Necron 单位基本都带），`Warpforge_35_Scarab-Swarm.png`、`Warpforge_33_Plasmancer.png`、`Warpforge_36_Ghost-Ark.png` 等同样没有 —— 即「哪些卡带 Remnant」不统一，我按图面实录，没有按同类卡补。
12. **计策/防御卡：本批 45 张里没有**（`Necron` 目录只有 `1督军`/`2天赋`/`3部队` 三个子目录），故「类型」列只出现 `督军`/`天赋`/`部队` 三种。
