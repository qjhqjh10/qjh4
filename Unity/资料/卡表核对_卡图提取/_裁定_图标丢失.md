# 「Gain N」图标被 OCR 丢掉 —— 54 张逐张对卡图（2026-09-13 第三十三轮）

> **背景**：卡表里有一批卡的 `desc` 写着 `Gain 1` / `Gain 2` / `Gain 3`，**后面什么都没有**。
> 实测不是「原版就这么写」，而是**卡面上那个图标被 OCR 丢了**。
> 例：`March of Vengeance` 卡面是 `Give +1 ⟨拳头⟩ to a friendly unit. Gain ⟨徽记⟩ 2`，我们只剩 `Gain 2`。
>
> **⚠️ 这批卡的危害是「静默算错」**：`Gain N` 裸数字**照样解析得出**
> （`EffectText.TryGain` 把裸数字当成「+1 能量」，出处 `rule_core.gd:3114`），
> 所以覆盖率数字**一点都不会动** —— 但打出来是**加能量**，不是卡面写的那个东西。

## ⚠️ 先说一条**更正**（我第一遍读错了一次，这里留痕）

第一遍看 `Grim Effigy` 的卡图时，我把那个徽记认成了**信仰太阳 ☀**，于是写下了
「`Grim Effigy` = `Gain 2 ☀`」。**那是错的** —— 它是**议程/任务点（Agenda / Quest Point）徽记**。
子代理用两条独立证据推翻了它：

1. **官方中文文本**：`d:/warpforge/data/i18n/zh_CN.csv` 里这些句子一律是「**获得 N 点任务**」；
   修女会 Faith 那几句才是「获得 1 ☀」。
2. **像素级模板匹配**：`Grim Effigy` 自匹 **1.00**（说明方法有效），
   而 DA 那批卡对「任务点徽记」匹配 **0.58**、对「信仰太阳」只有 0.5–0.6 且被压过。
   ⇒ **两个是不同的图标**，我当时是拿修女会那颗金色信仰太阳当模板去匹 DA 的徽记。

**教训**：卡面上「一个圆形徽记」有好几种（信仰 / 任务点 / 灵魂石 / 议程），
**光看形状认不出来** —— 要么对官方中文文本，要么做像素匹配，**别凭印象**。

## 怎么查的

派 3 个子代理，**逐张开成品卡图**把那一句抄回来（`D:/2/Warpforge部队卡片/<阵营>/<分类>/Warpforge_NN_<卡名>.png`）。
判图依据：卡面图标 **逐像素**与 `D:/4/Unity/资料/关键词图标/icons/` 里的图标对比
（例：`Ravenwing Champion` 那个图标绿色像素只有 25，而 `SpiritStone_1` 是 2474 ⇒ 排除灵魂石）。

## 图标含义（2026-09-13 实测，**这一列以后照抄**）

| 卡面图标 | 是什么 | 我们 desc 里的规范写法 |
|---|---|---|
| **锯齿/环形徽记** | **议程 · 任务点 Quest Point**（暗黑天使的阵营资源）| `Gain N Quest Points` |
| ☀ 金色太阳 | **信仰 Faith**（修女会）| `Gain N ☀` |
| 蓝色石头 | 灵魂石 Spirit Stone | `Gain N Spirit Stones` |
| 粉/红圆 + 拳头 | **近战攻击 Attack** | `Gain +N Attack` |
| 紫红圆 + 枪 | **远程攻击 Ranged Attack** | `Gain +N Ranged Attack` |
| 银盾 | 护甲 Armour | `Gain +N Armour` |
| 圆形能量 | 能量 Energy | `Gain N Energy` |

## 🔴 最重要的三条结论

1. **暗黑天使的阵营资源是「任务点」**（不是信仰、不是能量）。那批 DarkAngels 卡
   （`Ravenwing Champion` / `The Rock` / `Techmarine` / `Wages of Retribution` /
   `Reconnaissance Mission` / `Watcher in the Dark` / `Grim Effigy` / `Aggressor` / `Asmodai` /
   `Black Knight` / `Darkshroud` / `Fury of the Unforgiven` / `Hunt the Fallen` / `Intercessor` /
   `Librarian` / `March of Vengeance` / `Master Interromancer` / `Master Lazarus` /
   `Master of Repentance` / `Ravenwing Bikes` …）卡面上画的全是那个徽记。
   ⇒ 这**正好解释**了另一条独立查出来的事实：原版**只给暗黑天使显示任务点图标**
   （`cmp [督军+0x2c],0x6e`=110=DarkAngels，见 `BattleDriver.ShowsQuestPoints`）。
   ⚠️ 顺带查出 **2 张被误标成 `[Energy]`**（`Techmarine` / `Wages of Retribution`）——
   它们一直给的是能量，实际应该是任务点。
2. **有几张的图标读错了**，不只是丢了：`Power of the Waaagh!` 写的是 `[Armor]`、
   `Fenrisian Wolf` 写的是 `[armor]`、`Sisters Repentia` 写的是 `[Armor]`、
   `Malgarash the Adamant` 写的是 `[Weapon]`、`Xarahan Daemon Prince` 写的是 `[Power]`
   —— 卡面分别是**拳头（近战）**。⇒ 这几张的强度一直算错（该加近战却在加护甲）。
3. **`Librarian` 还漏了开头一整个关键词**：卡面是 `Shield. Agenda: …`，我们 desc 里没有 `Shield.`。
   （已补进去。）

## 落盘方式

写进 `Unity/数据/游戏数据/cardface_fixes.json` 的 **`desc`** 列
（2026-09-13 新开的一列，由 `gen_cards_engine.py` 读取 —— 见它的 `load_cardface_fixes`），
**不是** `STAT_FIXES`（那是数值，这是文本）。
