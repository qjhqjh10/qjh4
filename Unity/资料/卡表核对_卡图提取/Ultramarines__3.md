## 存疑

1. **版面差异：卡名是橙色、且没有 `Ultramarines` 阵营行的，共 3 张** —— `Warpforge_28_Adaptive-Strategy.png`（Adaptive Strategy）、`Warpforge_29_Fall-Back.png`（Fall Back）、`Warpforge_30_Champions-of-Humanity.png`（Champions of Humanity）。这三张的卡名本身就是橙色大字，下方直接是效果文字，**没有**「白色卡名 + 橙色 Ultramarines」那两行。其余 42 张都是「白卡名 + 橙 Ultramarines」。
2. **`zeal.png`（Avenging Zeal）是第 4 种组合** —— 卡名是**白色**，但**也没有**橙色的 `Ultramarines` 行，效果文字紧接卡名。它的费用 12、效果里提到 "friendly Troop or **Stratagem**"，是否属于某个特殊类别（督军/签名卡？）我无法从卡面判断，按所在目录 `4计策` 填「计策」。
3. **防御卡 3 张（`Warpforge_67_Hive-Factory.png` / `cover.png` / `firestrike.png`）效果下方那行橙字写的是 `Defence`**（类型名，不是兵种）。按规格 §二补充，`字段` 列填 `—`，在此说明我确实看到了 `Defence` 这一行。这 3 张同时也都有橙色 `Ultramarines` 阵营行（在卡名下方）。
4. **5 张部队卡的「字段」行**（效果下方橙色字）依次是：Redemptor Dreadnought = `Vehicle`、Repulsor Executioner = `Vehicle`、Sternguard Sergeant = `Infantry`、Sergeant Telion = `Infantry`、Tyrannic War Veteran = `Infantry`。
5. **45 张卡的「护甲」全部记 `—`** —— 我在每张卡右下区域都只看到左下红圆（近战）+ 紫圆（远程）、右下绿方块（生命）以及底部宝石，**没有任何一张出现带数字的盾牌**。这可能是 Ultramarines 这批卡的版面就这样，也可能是盾牌被放在我没识别的位置，抽样看这 45 张是一致的。
6. **稀有度判色风险**：这批里 `common`（浅青/薄荷）与 `rare`（绿）在 PnP 渲染里色相接近，我按「偏青 → common、偏绿且饱和度高 → rare」判。具体判定：common = WF09 / WF12 / WF28 / WF31 / WF32 / WF34 / WF48 / WF58 / WF63 / chapters due / forward / gather / pariah；rare = repulsor / tyranic / WF08 / WF29 / WF30 / WF33 / WF49 / WF51 / WF54 / WF59 / WF61 / WF62 / oath of moment。如果有基准色卡，建议复核这一批。
7. **同名片，数值不同**：`Warpforge_47_Tactical-Insight.png` 费用 **0**、`tactical insight.png` 费用 **1**；两张卡名同为 `Tactical Insight`、插画相同、效果文字都是 `Refill 2 Energy`、稀有度都是 epic。不确定是原版就两张还是一个有印错。
