## 根因分组（8 条 = 1 个根因）

1. 🔑 **全部 8 条同根因**：本批新增的 `WfSlider.HitHandlePadded`（`WfSlider.cs:459-468`）第一句
   `float ppu = 1f / U;`（`:462`，注释自称「= 108」）—— 而 `U` 是 `const float U = 108f`（`:173`，1 世界单位 = 108 px）
   ⇒ `ppu = 0.00926`，**点被缩了 108 倍、框没有** ⇒ 手柄命中区实际是 **~10456×9116 世界单位**（±5228 ≈ 5.4 屏）。
2. 传动链（两跳而已）：`Contains` 恒 true →① `SettingsPanel.PointerFrame` 的滑块支（`:1228`）恒 true ⇒ 红 **1/2/5/6/7**；

3. 🔑 **正/反一对（同形状、一正一错，日志自己把病灶夹在中间）**：`SettingsPanel.cs:1479` 写的是 `1f / U(1f)`，
   而那边 `U(px) = px/108`（`:419`）⇒ 那个 `ppu` **= 108、是对的** ⇒ A1301②（日志 68113 ✓ 外扩圈必中 / 68101 ✓ 有界）

   ⇒ 本批三处「原版 pad 命中框」只有 **WfSlider 这一处符号反了**。

   ⇒ 进它之前必须先在 px 域（`l * 108`）。**修法**：`WfSlider.cs:462` 改 `float ppu = U;`（或 `1f / (1f / U)`），
