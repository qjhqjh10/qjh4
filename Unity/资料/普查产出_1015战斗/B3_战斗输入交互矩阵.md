## 〇、先把「输入源」定死（**这是整张矩阵的地基**）

🔴 **原版战斗每帧读的不是 `UnityEngine.Input`，而是 `TouchInputManager` 的静态字段**（那个类每帧把
Input 抄一遍）。判据：`U:161/192/351/627/832/997/1105/1187` 每次调用的是 `FUN_180617800(0)`
—— 反编译里**没解出符号**，我用机器码定死它是什么（逐字节读，`VA 0x180617800`）：

```
48 8b 05 …      mov  rax, [cls_slot]        ; 类指针槽（=TouchInputManager，见下）
48 8b 88 b8 00… mov  rcx, [rax+0xb8]        ; static_fields
0f b6 41 08     movzx eax, byte [rcx+8]     ; ← 就取这一个字节
```
而 `TIP:128-133` 正是 `*(TouchInputManager.static + 8) = Input.GetMouseButton(0)`
⇒ **`FUN_180617800` = `TouchInputManager.get_TouchPressed`，语义 = 「左键此刻按着」**。
（同一手法证实 `FUN_180789a30` = `get_TouchPosition`（读 static+0/4，`TIP:140-150` 写的是
`Input.mousePosition`）· `FUN_180789a80` = `get_TwoFingerMidPoint`（读 static+0x24/0x28））

| 输入 | 原版从哪读 | 出处 |
|---|---|---|
| 左键**按着**（电平） | `TouchInputManager.TouchPressed` ← `Input.GetMouseButton(0)`（PC）/ `touchCount==1`（手机） | `TIP:128-133` · `:235` |
| 左键**按下那一帧** | `Input.GetMouseButtonDown(0)` —— **全战斗只有 2 处** | `U:117`（离开战场）· `U:1098`（case 8） |
| 左键**松开** | ⛔ **没有这个事件** —— 靠「上一帧 TouchPressed=1、这一帧=0」隐含表达 | 见 `U:192` 那一支 |
| 右键 / 双指 | `TouchInputManager.TouchPressedSecondary` ← `Input.GetMouseButton(1)` / `touchCount==2` | `TIP:134-139` · `:286` |
| 滚轮 | `TouchInputManager.ScrollDelta`（static+0x20） ← `Input.mouseScrollDelta` | `TIP:91,96` |

## 七、顺手发现

1. 🔴 **`BattleManager.IsPlayingCardState()` 在本 build 里没有任何调用点**（全库 grep 只有它自己的定义 + `BattleManager__IsPlayingCardState.c`）—— 死代码。它的判据是 `UIstate ∈ {2,3,5} || ==4`（`…:8-13`），可作为「哪几档算『正在出牌』」的**官方口径**引用。
2. **`CardScript.IsRightButtonOrTwoFingerTouch()` 也没有调用点** —— 它内部那句 `Input.GetMouseButton(1)` 是**唯一**在 `CardScript` 里读右键的地方；真正的右键判定在 `OnTouchDrag`/`OnTouchEnter` 里**各写了一遍**（两处写同一条规则）。
3. **`UIstateOptions` 的全体是 15 档（0..14）**，而 `Update` 的 `switch` 只列 10 档 —— 做「原版有哪些交互状态」的普查时，⛔ 别拿 switch 的 case 当全集（`choosingResolutionCard(14)` 在 `Update` 里根本没有分支）。
4. `CardCollider` 是**纯转发层**：它把 EventSystems 事件同时转发给 `cacheScrollRect(+0x30)`（手上的 ScrollRect）和 `CardScript(+0x20)`，自己只维护 `allowClick(+0x44)` 与 `pointerDownPosition(+0x38)`；`allowClick` 在 `OnPointerDown` 置 1、`OnPointerExit` 清 0，`OnPointerClick` 靠它决定要不要调 `OnTouchUpAsButton` ⇒ **「按下后在卡外松手」不产生点击**。
5. `TouchInputManager` 的静态字段表（本次为解 `FUN_180617800` 顺出来的，以后核输入直接用）：
   `+0x0/4 TouchPosition` · `+0x8 TouchPressed` · `+0x9 TouchPressedSecondary` · `+0xc/0x10 TouchDragDelta` ·
   `+0x14 IsDragging` · `+0x18/0x1c TouchDragDeltaViewport` · `+0x20 ScrollDelta` · `+0x24/0x28 TwoFingerMidPoint`
   （判据：`TIP:` 逐行写点 + 三个 getter 的机器码）。
