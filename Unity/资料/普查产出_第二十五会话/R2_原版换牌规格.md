## 1. 原版流程（时间顺序）
1. 双方牌库建好（`CreatePlayerDeck`：`BattleManager.playerShuffledDeck(+0x310)` / `enemyShuffledDeck(+0x318)`，先按 `MatchData.ShouldShuffleDeck` 决定洗不洗）→ `_SetupMulliganPhase`（`BattleManager._SetupMulliganPhase_d__341__MoveNext.c:19-25`）。
2. 进场：`battleStage ≠ 60(PostBattle)` ⇒ `battleStage = 40(Mulligan)`；**`UIstate = 11(mulligan)`**；等 1 帧。
3. `GameplayVariablesData.showMulligan`（`matchData.GameplayData +0x49`）为真才 `Shade.SwitchShade(true)`；**为假 ⇒ 直接 `ClickMulliganDone()`，整个换牌界面跳过**（`:44-46`）。
4. 🔴 **双方同时**：`AddCardsToMulligan(playerHand, playerGoesFirst, 教程强制数)` 与 `AddCardsToMulligan(enemyHand, !playerGoesFirst, …)` **两个协程同时 StartCoroutine**（`:90-95`）。
5. 逐张发牌（`PlayerHand._AddCardsToMulligan_d__41__MoveNext.c`）：`GetMulliganCard(isPlayer)` **从自己的 `*ShuffledDeck` 弹【第 0 项】**（`BattleManager__GetMulliganCard.c:37-66`）→ `SetupCardInMulligan`（记 `mulliganOption`）→ `MoveCardToMulliganPos`（位 = **`MulliganAnchor` 的 `CardsHorizontalLayout.GetPosition(i,n)`**）→ `DrawCard(pos,scale,time)` + `SetStateAsMulligan(false)` ⇒ **state = 13(inMulliganSelected)**。每张之间 `WaitForSeconds(timeToDraw×常量)`；若 `ScenarioVariables.startingHand(+0x1C) > 0` 再等 `startingHand × timeToDrawPlayerCard(+0xA8)`。
6. `MulliganManager.ActivateMulligan(goFirst)`：显示 `MulliganText`+`MulliganContinueButton`；提示行词条 = `Battle/Mulligan/Instructions`、`TurnText` = `Battle/Tips/GoFirst` 或 `Battle/Mulligan/secondTurn`；**对换牌区每张牌**在**该卡世界位**实例化预制体 `MulliganFrame`（scale = 该卡 `localScale`）；同时起 `MulliganCountdown`。
7. 玩家：**点每张牌上那颗「换」钮**标记/取消；点 Continue（或 `Space`/`Enter`，或倒计时归零）提交。
8. `ProcessMulliganDone`：`ShowMulliganElements(true)` → 灭 `MulliganContinueButton`+`MulliganText` → `BattleManager.ClickMulliganDone()` → **销毁全部 MulliganFrame**（换牌区的牌与状态原样留着）。
9. `ClickMulliganDone`（`:29-70`，门控 `UIstate==11`）：我方清单 `GetMulliganCardsToDiscardIds` → `matchData.playerMulligan(+0x80)`；然后分三条：Replay→`SetupReplayMulligan`；**非联网 → `AI.GetAiMulliganCards(enemyHand)` → `matchData.enemyMulligan(+0x88)`**（AI **此刻才算**，不提前）；联网→断线检查。
10. `FinishMulliganFirstPhase`：**先结算我方**（`playerHand.FinishMulligan`）→ 若 `receivedMulliganAck(+0x2A8)` 为假 ⇒ `SetWaitingForEnemy()`（提示行词条 `Battle/Mulligan/WaitEnemy`）**或**（联网）显出 `mulliganWaitText(+0x1F0)`。
11. `FinishMulliganFinalPhase`：等 `receivedEnemyMulligan(+0x29C)` 与 `receivedMulliganAck(+0x2A8)` **都真**（联网靠回包；兜底 `MulliganFallbackCountdown` 重发）→ 灭 `chooseCardManager(+0x1F8)` → `playerHand.FinishMulliganFinalPhase()`（淡出卡 UI）→ 关 `mulliganWaitText` → 停倒计时/`StopMulligan` → `enemyHand.SetMulliganCardsToDiscard(matchData.enemyMulligan)` → `enemyHand.FinishMulligan()`。
12. 收尾：**双方各洗一次牌库**（`ShuffleDeck`×2）→ `CompleteMulliganPhase(敌)` + `CompleteMulliganPhase(我)`（换牌区的牌**原对象**并进真手牌 `PlayerHand+0x50`）→ 等 `timeToPositionCard(+0xA4)` → 停转圈 → 等 `introStageStepTime(+0x20)` → 相机初始化 → **`StartBattlePhase`**。

## 3. 换掉的牌 / 新牌
- **被换的牌 → 回【牌库】，不是弃牌堆**：`PlayerHand__ReplaceMulliganCard.c` = `set_parent(card, 我方/敌方 `DeckManager` 的 transform)`（按 `card.isPlayer` 取 `playerDeck(+0xF0)`/`enemyDeck(+0x108)`）+ **`deck.Add(card)`**，再 `card.ReturnToDeckAnim(timeToDrawEnemyCard)` 播回库动画。**不销毁、不复用做新牌。**
- **新牌 = 从 `*ShuffledDeck` 列表弹第 0 项**（`GetMulliganCard`：`get_Item(0)` → `SetActive(true)` → `RemoveAt(0)`）；取到后 **`List.set_Item(同一格, 新牌)`** 插回换牌区、`mulliganOption = 0`、`MoveCardToMulliganPos(idx, count)` 飞进那一行（`PlayerHand._FinishMulligan_d__52__MoveNext.c` state 1 段）。**不是随机抽，是按牌库列表序取下一张。**
- 次序：**先把被换的牌送回牌库并播动画 → 再取新牌**；**全部替换完之后才 `ShuffleDeck(双方)`**。
- **`MulliganAnchor` 是「换牌期的正式手牌位」，不是临时展示位**：换完 `CompleteMulliganPhase` 把这些牌（**同一批对象**）并进 `PlayerHand+0x50` 真手牌列表并 `SetStateInHand`/`SetSortingLayer`/`FinishMulliganUi`/`ToggleTooltips(false)`。⇒ 牌**从来不回「手牌位」**。（**A1671 答案**：不是临时位；要改的是「牌在哪」。）

## 5. `mulliganOption` 那道闸
- 类型 = `MulliganOptions`（dump.cs `TypeDefIndex:776`）：`normal=0 · secondTurn=10 · extraWarlord=20 · **whispersOfChaos=30**`。
- 闸读它（`ClickMulliganSelected.c:27`：`!= 0x1e` 才允许翻标记）；**同一字段还被 AI 读**：`AI.GetAiMulliganCards` —— **30 ⇒ 这张不换**，否则 `rawCard.manaCost > 4 ⇒ 换`（`AI__GetAiMulliganCards.c:44-52`）。
- **赋值点全查过，只有 3 处**：`PlayerHand.SetupCardInMulligan`（唯一调用者 = `<AddCardsToMulligan>`）· `CardScript.Awake`(=0) · `_FinishMulligan` 给新牌(=0)。`PlayerHand.GetMulliganOption` **无任何调用者（死代码）**。
- `<AddCardsToMulligan>` 的赋值（`MoveNext.c:100-118`）：`i < start ⇒ 30`，而 **`start(+0x3C)` 在同一函数里硬编码写 0** ⇒ **30 分支不可达**；实际只有 `[0,extraWarlord)⇒20`、`[extraWarlord, extraWarlord+secondExtraCards)⇒10`、其余 `⇒0`。`extraWarlord` = `heroRawCard+0x118`（<1 记 0）；`secondExtraCards` = `ScenarioVariables(+0x20)`，**只对后手那一方读**；`startingHand(+0x1C)` 只参与**总数**、不参与分带。
- ⇒ **这道闸在本 build 恒真 = 等于没有**；**教程局也不会不同**（教程只经 `AddCardsToMulligan` 第 3 参改**张数**，不改 option）。
- ⚠️ 这是**静态穷举赋值点**的结论，**没跑到实况**；枚举名还留着 ⇒ 判据可能在**数据侧/远端**而非代码。
