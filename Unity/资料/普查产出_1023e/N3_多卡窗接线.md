## 五 · 没查清 / 没验的部分（如实记）

   实跑时若红，按这个顺序判：

   ② **牌库张数 / 阵营**（前提那条）：这一局是 `Ultramarines vs Goff` 自动凑的原版卡组，
      `driver.MyFaction` = `Ultramarines`；若自动凑牌里混了别家卡 ⇒ 前提那条会红并打出实数；

      若时间线里还有**更晚**的残留事件排在它前面（同一时刻并列时按先来先播），不会影响；
      真红就打印 `Clock` / `TimelineTailAtForTest` / `TimelinePending` 再判。
2. ⚠️ **`IsPlayerTurn` 与 `e.Player == _me` 不完全等价**（见 §六·1）：对现池唯一持有者等价，
   将来出现「不在自己回合也结算的 470 卡」时要回来加 `Ctx.Active == _me`。**已写进代码注释**。

   原版 `WindowsManager.OpenWindow` 也是模态窗，但**原版那一拍不等**（时间线不等 ≠ 玩家不用点「继续」）。
   这两件事在注释里分开了；**真机手感没验**（要真 Play 才能看）。

## 六 · 顺手发现（不在本件范围，⛔ 本批一个字节都没改）

1. 🔴 **原版那道闸是「本地玩家**回合**」，我们判的是「施放方是**本机**」** ——
   对现池唯一持有者（`GSC55`，一张手牌战术、只在自己回合结算）两者**等价**；
   一旦出现「不在自己回合也结算」的 470 卡就会分家。**已写进 `OpenShowCardsWindow` 的 doc**，未改行为。
   建议主对话按铁律 5·b 决定要不要立账（我倾向只留注释，因为今天不可达）。
2. ⚠️ **`ShowMyDeck` 的标题是写死的中文 `"你的牌库"`**（`BattleDriver.cs:10805`），
   而这一扇窗的其余文案全走 `Loc`（「继续」走 `Battle/Mulligan/ButtonDone`）。
   ⇒ **英文档会露中文**。⚠️ 但它属于**我们挑的额外入口**（原版根本没这扇窗的这条路），
   原版没有对应词条 ⇒ 判据为空（铁律 11 例外①）⇒ **本批没动**。真要修，得先定用哪条键。
   （改它会连带改 `BattleScene.cs` 那句 `mcd.HeaderShown == "你的牌库"`。）
3. ✅ **顺手核掉一条担心**：`ShowCardsWindow` 会进 `Ctx.ActionLog`（`Emit` 里那句），
   而日志面板的 `default: skipRow = true`（`BattleDriver.cs:9396-9401`）⇒ **不会印出空行**，无需处理。
4. ⚠️ **`EvtKind` 现在是 18 种**，`EventTiming` 的 `IsSourced` / `SourceOf` / `DurationOf` 三处都有 `default`
   ⇒ 新事件自动「有出处 + 0f」。这一档恰好对（原版非阻塞），但**下一个人加事件时要自己确认 default 是不是他要的**
   （`BattleScene.cs:1593` 那条 `unsourced == 2` **不会**因为 `default: true` 拦住他）—— 与 J2 报告 §四·3 同一条。
5. ⚠️ **`MultiCardDisplay.Toggle(...)` 全仓零调用点**（本批 grep 过：只有声明）。不是本件的问题，留个记录。
