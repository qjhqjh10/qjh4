### 3.3 改动（`Shell/CollectionWindow.cs`，两页同一套）

1. **每格加一层容器 `Content <i>`** = 原版 `Collection Card/Content`：
   - `RebuildCardsCells`：`var cellT = Node(parent, "Content " + i, r);`，卡体与张数条都挂进去
     （`CardView.Create(cellT, …)` / 复用支 `v.transform.SetParent(cellT, false)` /
     `v.SetPose(Local(cellT, …))` / `BuildCardsCounter(cellT, …)`）；**命中区 `CardHit_*` 留在外面**
     （原版射线件在 `Content` 的**上一层** `Collection Card` 上 ⇒ punch 时命中区不跟着动）。
   - `RebuildStyleCells`（异画页）：同一条，容器 `Content <i>`，`AltArtHit_*` 留在外面。
   - 两处清理循环改成「**先把池里的 `CardView` 从上一趟容器摘出来挂回 `parent`，再销毁容器**」
     —— ⛔ 反过来会连池里的卡一起销毁（池化静默退化，自检「滚 100px 新建 0 张」会红）。
2. **punch 改打容器**：两处 `onClick` 由 `PunchCardCell(v.transform)` 改成 `PunchCardCell(cellT)`。
3. **新增自检读数** `public static Transform LastPunchTargetForTest`（`PunchCardCell` 里记 `_cardPunchTarget`）。
4. 订正 `PunchCardCell` 那段判据注释（含 `+0x60` 是 CanvasGroup 的三条旁证、PPtr 落点、`Content` 的孩子清单），
   并把「复位」那段理由改写（目标现在是恒等缩放的容器，不是 `CardView`）。

**几何保持不变的算式**（写在这里备查）：`MenuDraw.Local(parent, rect) = RectCenter(rect) − PosInDesignSpace(parent)`；
容器由同一个 `Node/ApplyPxRect` 摆出 ⇒ `Local(cellT, cardR) = RectCenter(cardR) − RectCenter(r)` ⇒
卡的世界位置、尺寸（`sizeDelta`）与缩放**逐位不变**（容器 `localScale = 1`，`lossyScale` 与父相同）。
`CardView` 源码里**没有任何 `transform.parent` 依赖**（`grep "transform.parent\|\.parent\."` 零命中）⇒ reparent 安全。
