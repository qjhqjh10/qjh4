### D6 🔴 🆕 **`Codex` 白名单大小写失效**（**这条同时是对第一批 Ultramarines 结论的订正**）

- 白名单（`Core/VfxMap.cs:1859-1925`）对 `Codex` 用的是
  `switch (triggerName) { … case "Codex": … }` —— **C# `switch` 对 string 是大小写敏感（ordinal）**。
- 而引擎发出来的 keyword 是 `KeywordTable.Codex = "codex"`（小写，`Core/CardDef.cs:5300`），
  发射点 `RuleCore.cs:11233` `FireTriggerAt(ctx, u, KeywordTable.Codex, p, s)` → `FireTriggerAt` 的
  `emitSignal` 把 **`keyword` 原样**写进 `BattleEvent.Keyword`（`RuleCore.cs:10706-10709`，没有大写化）。
- `TryResolveTriggerPicks` 里那一段：
  `targetSrc = keyword`（= `"codex"`）→ `CanonicalTriggerName("codex")` = `"codex"`（只映射 `penitence→Rage`）
  → `IsRoutedTriggerName("codex")` → 前两条 `OrdinalIgnoreCase` 比的是 `ambush` / `TriggerEnchantment`，都不匹配
  → `switch("codex")` 落不到 `case "Codex"` ⇒ **返回 false** ⇒ `target = null` ⇒ `picks = trig`（整桶播）。
- ⇒ **32 条 / 23 张 Ultramarines 卡的 Codex 逐卡动画，实际一直没按 Codex 播**（播的是 `trigger` 桶里那几件 trait 动画）。
  第一批报告我当时按「`Codex` 在白名单里」判成一致 —— **已就地订正**（那 23 张现在是「差异」）。
- **修法一句话**：`case "codex":`（或整段改成 `OrdinalIgnoreCase` 比较）—— 与 `Ambush` / `TriggerEnchantment` 那两条同一个写法。
- ⚠️ **这批没跑 Unity**，所以这是**读码结论**（判据链在上面每一句都给了行号）。要坐实最快的办法：给 `UM13` 之类放一次 Codex 触发，看播的是 `CodexEffect` 还是它 `trigger` 桶里那件。
- ⚠️ 顺带：`Rage` 那条**是好的** —— 引擎发 `KeywordTable.Penitence = "penitence"`，`CanonicalTriggerName` 先把它换成 `"Rage"`，正好落在 `case "Rage"`。
- **本批 Codex 分布**：`Ultramarines` 23 张 / 32 条（`UM13 UM15 UM16 UM20 UM24 UM25 UM28 UM3 UM37 UM55 UM56 UM57 UM59 UM67 UM68 UM71 UM72 UM78 UM79 UM84 UM85 UM86 UM96`）；其余 5 个阵营 **0 张**。
