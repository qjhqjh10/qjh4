## 0 · 一句话结论

`A8`（`新账-102`）把 `Core/CardIcons.Rewrite` 开头那道闸扩成
`if (HasOfficialMarks(text) || HasRenderedMarkup(text)) return RewriteMarks(text, field == DescZhField);`（`Core/CardIcons.cs:326`），
而 **`HasRenderedMarkup` 只认 `<sprite` / `<link=`**（`:628-633`）、**`RewriteMarks` 四支只吃 `((` / `$$` / `[[` / `(N)`**（`:647-655`）。
这四处的「第二遍」喂进去的**都是第一遍的产物** ⇒ **必带 `<sprite`/`<link=`** ⇒ 闸**必然短路**到 `RewriteMarks`
⇒ 而它们的串里**一个记号都没有** ⇒ 四支**逐字节恒等** ⇒ **`第二遍 == 第一遍` 在结构上不可能为假**。

被牺牲的是它们**本来想钉**的东西 —— 计划表那两句幂等守卫（`Core/CardIcons.cs:415`
`if (s.IndexOf(it.token) < 0) continue;` / `:495` `if (s.IndexOf(bare) >= 0) continue;`）**已无活输入**
（见 §4·2 的全池模拟）。今天「换两遍 == 换一遍」是**闸**在保证 ⇒ 判别式必须**钉闸**。
