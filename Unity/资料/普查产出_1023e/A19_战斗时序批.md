## 1. 换牌逐张错开 —— ✅

**结论**：原版是「**每放好一张**就 `WaitForSeconds(timeToDraw × 0.5)`」，不是「首张延时」；
第 0 张 t=0 立即落位，最后一张之后**也等一次** ⇒ 整条链 ≈ `N × 步长`。

**证据（复核过，与 C1-A01 一致）**
- `d:/2/tools/decomp_full/PlayerHand._AddCardsToMulligan_d__41__MoveNext.c:119-127` 亲读：
  `MoveCardToMulliganPos(...)` → `WaitForSeconds(get_timeToDraw(lVar3) × DAT_1834b2bb4)` → `state = 1; return 1`
  ⇒ **先落位再等**，循环下一张。
- `DAT_1834b2bb4` = **0.5**（C1-A01 用 `工具/read_literal.py` 现读；本轮沿用，未重复读）。
- `timeToDraw` 敌我 = 0.3 / 0.15（`CardFeel.DealSeconds`，出处 `资料/VarsGlobal_原版数值.md:54-55`）
  ⇒ **我方 0.15 s/张 · 敌方 0.075 s/张**。

**改动清单**（`Battle/BattleDriver.cs`）
- 新增 `public const float DealStaggerFrac = 0.5f`（判据头注带出处）。
- 新增 `public static float DealStaggerDelay(bool mine, int i)`（`i<=0 ⇒ 0`）与
  `public static float DealChainSeconds(bool mine, int n)`（= `n × 步长`，钉住「最后一张之后也等一次」）。
- `PlayDealAnimation()`：按 `i` 算 `dealDelay = DealStaggerDelay(true, i)`，喂给
  `CardFeel.DealInPose(..., delay, ...)`（两条支）与 `CardFeel.DealIn(v, deck, dealDelay)`（退路）。
  **没有**改 `CardFeel.DealDuration`（0.3，`W63` 换牌角度兜底的前提，⛔ 不动）。
- `SyncFoeHand()`：`foreach` 换成按下标循环，喂 `DealStaggerDelay(false, i)` 给 `CardFeel.DealInQuad`。

**断言（`Editor/BattleScene.cs`）**
1. 纯口径（放在原「敌我发牌用时分开」那条后面）：
   `DealStaggerFrac == 0.5` · `Delay(mine,0)=0` · `Delay(mine,1)=0.15` · `Delay(mine,3)=0.45` ·
   `Delay(foe,1)=0.075` · `Delay(foe,2)=0.15` · `Chain(mine,4)=0.6` · `Chain(foe,4)=0.3`。
   🧨 改坏法：系数写 0 ⇒ 中间三条红；写成「第 i 张等 (i+1) 步」⇒ 第 0 张那条红；
   `DealChainSeconds` 写成 `(n−1)×步长` ⇒ 最后两条红。
2. **行为面**（A1540 那一格、换牌阶段 `Begin` 之后）：推 `0.05 s` ⇒
   **第 0 张已离开牌堆（>0.01 世界单位）、第 1 张还压在牌堆上（<1e-3）**。
   🧨 改回「同帧全起」⇒ 第 1 张也会 >0.01 ⇒ 红。
3. ⚠️ **顺带修了一条既有夹具**：A1540 那一格原来写死「泵 24×1/60 = 0.4 s」——
   逐张错开之后第 3、4 张要到 `0.45+0.3 = 0.75 s` 才落位，写死 0.4 会让那三条**假红**。
   已改成 `pumpNeed = DealChainSeconds(true, hn) + CardFeel.DealDuration + 0.1`（按张数推）。

**没查清的部分**：`_dealt` 的顺序 = **手牌序**（`SyncHand` 按 `h` 遍历）。换牌期整手都是新牌 ⇒ 与「放入序」同序；
常规抽牌一轮 1~2 张也同序。但若将来源码改成「一次抽多张且插到手里中间」，`_dealt` 的下标就不再等于放入序
（那时要换成按抽牌事件顺序排）。今天没有这种路径。

  · 玩家拖拽：`StartHandToBoardClip` 的 `HandToBoard` 完成回调（清 `_handToBoardCard` 之后）；
