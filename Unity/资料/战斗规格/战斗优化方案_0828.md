### sd_card.gd 新增（默认值向后兼容）
```gdscript
var _num_labels: Dictionary = {}          # kind → Label
func set_stat(kind: String, new_val: int, base_val: int = -1, animate := true, color_change := true) -> void
func sync_stats(u: Dictionary) -> void    # health←u.health/u.max_health; melee←u.attack/card.attack; ranged←u.ranged_attack/card.ranged_attack; armor←u.armor(≤0隐); cost 不动
```

- `_make_num` 改返回 Label（仅 sd_card 内部消费）；build 内 5 格记入 `_num_labels`。

## 阶段 F3：【目标选择链路 + AI 即时胜负/演出】（P0-B + P0-C，最大工程）

### 3.1 状态机
`_state` 增 `"tactic"`（手牌战术待选目标，可右键/ESC 取消=卡未打出）与 `"pending_fx"`（触发效果待选目标，**不可取消**=原版语义，须点合法格）。

### 3.2 战术出牌流（`_hand_release` 1088-1110 改造）
- 拖出卡先 `RuleCore.tactic_target_type(card)`（2439-2456）：`"none"` → 现状（拖到己方空槽部署）；需目标 → `_slot_unit_at(p,pos)`（`_slot_at_mouse` 1113-1120 + 槽非空）：
  - 命中合法目标单元槽（enemy→p1/friendly→p0/any→两侧）→ `play_card(ctx,0,held,-1,p,idx)` → `_after_events()`；
  - 未命中 → `_enter_tactic_mode()`（`_state="tactic"`、`_glow_valid_targets(need)`、`_target_hint("Choose tactic target (%s) - right-click to cancel")` 长显，卡不打出）。
- `_on_slot_input`（1123-1158）新增分支（优先级）：
  1. `_state=="pending_fx"`：点合法格（阵营+非空+敌 stealth/camouflage 过滤，规则同 rule_core 3710-3737/4057-4066）→ `resolve_pending_fx(ctx,p,idx)` → `_append_events`+`_after_events`+退出挂起态；ERR → tip"Invalid target"。
  2. `_state=="tactic"`：同校验 → `play_card(ctx,0,_sel_hand,-1,p,idx)` → `_after_events()`；ERR → tip+保持。
  3. 右键取消（`_on_slot_input`/`_on_hand_card_input`/`_input` ESC 分支）：仅 tactic 态（pending_fx 不可取消）。
  4. 现有 attack 分支（1138-1149）不动。
- 高亮 `_glow_valid_targets(need)`：新函数（不动 `_glow_slots` 780-799 签名），绿框 Color(0,1,0.129)（原版 ValidTargetColor），按 need 过滤两侧格。
- hint：新 `_target_hint` Label（样式=TipText fs60 绿条 α0.6，但手动开关不 2s 自卸）。

### 3.3 三挂起弹窗链（`_check_pending_ui()`）
顺序（旧版 4715-4718）：pending_fx → cost_act → choose_one → pending_choose（现有 ChooseCardMenu 保持）。
- `_check_cost_act()`：AI（p==1）→ `resolve_cost_act(ctx,1,true)` 自动；玩家 → 弹窗=PanelContainer+`40k_popup_texture`+标题 `"%s — Activate for %d %s?"`+效果文本+Activate/Just play 两钮（旧 4846-4898 文案/布局，`_label` 新版工具重建）；全屏拦截层+暗幕 α0.6118。
- `_check_choose_one()`：AI → `resolve_choose_one(ctx,1,0)`；玩家 → VBox 效果文本按钮弹窗 `"%s — Choose one:"`。
- 防重入：每 checker 带"已开不重开"；resolve 完成后重新调链（级联）；弹窗打开先挂起卡展窗/设置/聊天（简化）。
- z：挂起弹窗 z_index=110（Front 层，高于现有 100 档）；Doors(CanvasLayer 40) 恒顶。
- M3 兜底：pending_fx 无合法格 → 提示+退出挂起态（不 erase ctx 键，回合边界自然擦除）。

### 3.4 AI 回合（`_run_ai_turn` 2506-2564 改造）
- 改 async 步骤化：`const AI_STEP_DELAY := 0.45`；每步 `_after_events()`（= `_append_events`+`_refresh_board_values`+`_check_pending_ui`+即时 `check_winner` 短路）→ `await _on_ai_step_done`/`await process_frame` 演出。
- `_on_turn_end`：`_ai_running=true` → `await _run_ai_turn()` → `false`。（M4 guard：END TURN/出牌/攻击入口 `if _ai_running: return`）
- AI 战术目标：`need != none` → `_ai_pick_tactic_target(need)`（旧 4574-4590 语义：enemy→敌最低血非督军→兜底督军+stealth 过滤；friendly→受伤单位→督军；any→随机）→ `play_card(ctx,1,best,slot,tp,ts)`。
- 挂起冻结：每步 `while pending_fx_need != none: await _pending_resolved`（signal：resolve/cancel 后 emit）。
- 即时胜负：每步 `_after_events()` 返回值短路；`_maybe_show_doors`（2348-2354）加防重入（`_battle_doors.visible` 判）。
- 战术击杀补门：`_hand_release` 出牌成功（1103-1104）+`_on_choose_done`（3441）后各补 `_maybe_show_doors()`。
- `refresh_turn_ui`（2582-2594）入口加 winner 兜底（AI 打死玩家的双保险）。
- 删除旧内联 AI choose 片段（2535-2539，并入 `_check_pending_ui` 的 AI 分支）。
