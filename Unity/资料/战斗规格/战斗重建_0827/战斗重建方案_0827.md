## 四、运行时行为状态机(核心交互,全部 C# 反编译来源)

```
对局启动: GameData.pending_mode/pending_tutorial → RuleCore.new_battle(deck_p, deck_e, mode)
  → Mulligan(起手 3+英雄附加+后手+1;原版 MulliganOptions=normal/secondTurn/extraWarlord/whispersOfChaos)
    [选牌→ClickMulliganDone→begin_turn p0]
  → 回合循环(每回合):
    begin_turn → 能量 Refill(min(9,unused)+1 → 上限 10) → 抽 1(加时每回合多抽 1) → 回合提示
    → 玩家点击手牌选格部署(UIstate 锁+协程队列;ResolvePlayCardFromHand)
    → 选中己方单位→攻击选择器(四钮)→选目标→ResolveAttack(规则校验 RuleCore.play_card/attack)
    → END TURN(60s 计时;狂暴未打=禁止结束+Tips/PendingBerzerk)→ end_turn → AI 回合(自创)
  → 胜负: check_winner → EndBattleDoors(骷髅 BroadcastEarnSkull 逐个亮;奖励'2000'/'34')
```

**Godot 落点**(引擎映射报告):
- 协程队列+UIstate 14 态锁 → `battle.gd _state` 机+`await` 序列(与 RuleCore 同步调用,规则核=纯函数同步→UI 动画 await)
- 原版信号总线(SignalBus+IBattleSignal 20 类+48 Broadcast*)→ RuleCore 的 `ui_events` 事件数组(回合/出牌/伤害/死亡/抽牌……battle.gd 消费→VFX/UI 刷新);**无事件文本流**——中文/英文化字符串由 battle.gd 层拼(UI 英文按 JSON)
- EverguildButton → 项目 Button 惯例(flat=false+StyleBoxTexture 三态+子 Label;灰显=modulate≈(0.5,0.5,0.5)或 Greyscale 材质→记录差异:原版=材质灰显)
- TMP VAlign 4096=Midline/8192=Capline 无 Godot 直接对应 → Label 垂直居中近似+文本对齐微调(记录近似)
