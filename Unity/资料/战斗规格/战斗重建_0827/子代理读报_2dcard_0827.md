## 0. 单位体系 (至关重要, 旧记录"相对比例值"需修正为下述精确理解)

**模板坐标=根节点未缩放 px, 1 单位="卡单位"; 运行时/场景预制缩放链:**
- 根节点 CardUI Reference RT 3421 `m_LocalScale=(223.14, 223.14, 223.14)`, sizeDelta(2.5437, 3.3686) → 多卡展示窗尺寸 567.6×751.7 px
- 显示窗克隆 CardUI (4) RT 2663 `m_LocalScale=(250.0,250.0)`, size(2.5437,3.3686) → 显示窗大卡 635.9×842.2 px (与项目 card_displayer.gd scale=250.0 完全一致)
- 墓地克隆 CardUI (1) GO 1013 `m_LocalScale=(1.0)` (运行时由脚本重设)
- **数值格子树: scale=1.0 → 尺寸/字体的 JSON 值即"卡单位"** (Health 0.4²、Cost 0.4²、fs 0.34 等)
- **文字子树 (Name and description / Created By Text 下所有 TMP): scale=0.01** → JSON px 值 ×0.01 = 卡单位 (NameTextUnit sz 160×29.73 ×0.01 = 1.6×0.297 卡单位, fs 19×0.01=0.19 卡单位)

**项目换算基准 (与 sd_card.gd 一致)**: 卡单位 ×scale → Godot px (池 112.5 / 图鉴 150 / 大卡 250); y 翻转为 Godot 轴。文字层 fs 的"卡单位"值 = JSON fs×0.01。

## B. 战斗动态数值层分析 (战斗侧最关键差异)

### B0. 结论先行

原版卡牌的数值 (血量/攻击/费用/护甲) **不是静态文字**, 而是 5 个 `CardTextCountersController` (挂 BasicCardUI, 即 CardUI Reference 根上) 驱动; 战斗运行时每次数值变化, 由 `CardScript` 调用私有刷新方法 → 计数器 `SetText(newAmount, currentValue, baseValue, doColorChange, doAnimation, hideIfZero, removeContainerIfBelowZero)` 完成 **文字set + 涨/落颜色 + bump 动画 (0.75 缩放 0.4s)**。项目 sd_card.gd 目前是纯静态一次性 build, **完全没有动态更新接口 → 战斗侧必须新增**。

### B1. 动态更新链路 (方法签名级证据)

```
[数值源] CardScript (战场运行时卡, 3135 行) 持有 health/attack/armour/cost 运行时值
    │ 每次变化后调用 (私有):
    ├─ CardScript.UpdateHealthText(bool shouldAnimate = true)      (line 3003)
    ├─ CardScript.UpdateAttackText()                               (line 3007)
    └─ CardScript.UpdateCostText()                                 (line 3016)
    │  (方法体被 ILSpy 剥离 — 按 BasicCardUI 公开属性推断调用:
    │   BasicCardUI.HealthCountersController / Cost / MeleeAttack / RangeAttack / Armour —
    │   均 public 属性 => CardScript 经 basicCardUI.xxx.SetText(...) 更新)
    ▼
[数值更新器] CardTextCountersController (BasicCardUI 5 个字段分别挂 4212/5146/4209/4060/4966)
    public void SetText(int newAmount, int currentValue, int baseValue,
                        bool doColorChange, bool doAnimation,
                        bool hideIfZero = false, bool removeContainerIfBelowZero = true)
    - 写 textsToSet[i].text = newAmount (每计数器 1-2 个 TMP; cost=小/大双 TMP)
    - doColorChange: DoColorChange(currentValue, baseValue) → 涨/落色 (statIncreaseIsPositiveToThePlayer=1 决定极性;
      textColorsSO=null → 走代码内置色; 具体色值需核实 — 疑绿涨红落)
    - doAnimation: bump 动画 textsToSet → 缩放至 cardTextBumpSize(0.75)/cardTextBumpTime(0.4s) 后回弹
      (BasicCardUI.SetChangedAmountTextUp 协程)
    - hideIfZero=true 时 0 值隐藏; removeContainerIfBelowZero=true 且 <0 时移除容器 (守卫负值)
    - SetText(int newAmount) 重载 = no color/no anim
    - HideStat() / ResetHide() — 隐匿/恢复单个数值 (战斗中潜行/未揭示?)
```
