## 2. 逐条

### ① `A1249` —— 我们【多】算一档：打掉**本身已是残骸**的格子也算击杀

**我方现状（改前，现读）**：`Core/RuleCore.cs:3978`（旧行号）那一句
`bool killed = !target.IsWarlord && !target.IsAlive;` —— **判据里没有任何「残骸」概念**；
残骸 `Health = 1` ⇒ 挨任意一下都满足它。残骸的产生口（**唯一写点**）现核仍在
`Core/RuleCore.cs` 的 `CleanupDeaths` 里 `IsRemnant = true`（`grep -n "IsRemnant = true" Core/*.cs`
只命中 `RuleCore.cs:4671` + 一行注释）。

**原版判据（第一权威 `d:/2/tools/decomp_full/`，RN 文档已逐行读过、本笔复核过形状）**：
`CardScript__ResolveDeadCard.c:242-259` —— Slay 是在**死亡结算**那一跳发的，
`:256` 的闸写死了 `*(char *)(local_308 + 0x65 /* isRemnant */) == 0`。

**实现形状与理由**：在共用判定口里加第 ⑤ 道闸 `if (victim.IsRemnant) return false;`。
⛔ **没有新造判据** —— `IsRemnant` 全仓唯一写点就是残骸的产生口，读它不算第二份规则。
⚠️ **语义正好对上**：*刚被打到 ≤0、即将翻面*的那一下，我们手里那张 `target` 是**旧对象**
（`IsRemnant == false`）⇒ **放行**（= 原版此刻 `0x65` 还是 0：翻面那条 action 排在死亡结算**之后**）；
*本来就是残骸*的那一格，`target` 是残骸对象（`IsRemnant == true`）⇒ **挡掉**。

### ② `A1250` —— 我们【少】算一档：用能力 / 效果摧毁不算击杀

**我方现状（改前）**：`killed` 只在 `DeclareAttack` 尾段算（**全仓唯一发射口**）⇒
`EffectResolver` 那几条「会打死人」的路（`DoDeal` / `DoEachUnitDeal` / `DoDestroy`）与
`RuleCore.ResolveEffect` 的 `damage` 那一支**一次都不记击杀**。

**原版判据**：同一道闸 `:252` 允许 `local_28 ∈ { 0xf /* combatDefender(15) */, 0x14 /* ability(20) */ }`
（`UnitDeathType.cs`）⇒ **效果击杀也算**；另外 `tactic(30)` / `combatAttacker(10)` / `poison(40)`
**不予放行**。

**实现形状与理由（调度台的裁定：提升成共用判定口）**：
新增具名口 `RuleCore.TryCreditKill(ctx, killer, victimP, victim)`（**判别式 + `Slay` 触发 +

| # | 闸 | 原版出处 | 我们的写法 |

### ③ `A1256` —— 「强制攻击」在我们这边【会被替身截】、原版【不会】

**我方现状（改前）**：`Core/EffectResolver.cs:1586`（旧行号）—— 强制攻击那条 op 的出口
`TryAttackOnce` 调的是**同一条** `RuleCore.DeclareAttack` ⇒ 走同一段替身重定向。

**原版判据（`P-K` 已 `grep -rln` 现核，本笔引用）**：`forceAttack` 是**另一条 action**
（`BattleActionType 0x2a` → `BattleManager._ResolveForceAttack_d__504`），
而**全库只有 `_ResolveAttack` 调 `CheckUnitsCancellingAttack`** ⇒ 那条路**根本不经过替身那道闸**。

**实现形状与理由**：给 `DeclareAttack` 加一个**末尾可选形参** `bool forced = false`

`EffectResolver.TryAttackOnce`（`:1603`）是**唯一**传 `forced: true` 的调用点。
其余（疲劳 / 目标合法性 / 反击 / 事件 / 击杀）**一律照旧** ——
原版 `AllowResolveAttack` 对 `forceAttack` **没有** `redirectedAttack(0x4a)` / `scriptedAttack(0x34)`
那两条短路（`P-K` §10·1 那句「也不受 `AllowResolveAttack` 闸」**本笔不采信**：它没有给出 `:92-94`/`:134-136`
之外的证据，而这两处只覆盖 0x34 / 0x4a）⇒ 我们**只**去掉重定向这一件事。
