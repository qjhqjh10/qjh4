## 〇、四句话结论

1. **「选近战/远程」的机制 = 已复刻到「悬停即选」这一档，但不是逐段一样** —— 入口（拖拽）、悬停即选中（`+0x92/+0x90/+0x91` 三格）、换打法那一下的音效、准星、黄圈 1.3 倍、点位/外扩距离 **都对**；
   差的是 **5 处**：① 三颗钮的**显隐规则**（原版近战/远程恒显，我们只显"可用"的）② **拖拽起手就点亮合法目标 + 亮准星**（我们等选完打法才亮）③ 技能钮的**悬停音**（`soundOnSelect`，原版只有技能那颗有）④ 技能钮的**悬停 tooltip**（原版 `Battle Tooltip Variant`）⑤ 指针离开某颗钮时**其它钮淡出**（`DisableTemporary`）。
2. **Duty / Pray / Oath / Ferocity / Agenda 的效果 = 引擎侧早就做了**（同一个「主动能力」槽，`RuleCore.CanUseAlternative` / `UseAlternativeCore`），**按钮的专属图五张也做了并接了**。
   差的不是"没做"，是**表现细节**：技能钮的图标来源（原版**按军队**查 `activeAbilityIcons`，我们按关键词）、非五阵营的图标为空（我们画了一张自己挑的灰占位图）、悬停音/tooltip。
3. **场上词条的表现 = 做了两条通道**（7 格徽标 `boardTraitIcons` + `TraitFrames` 状态框/特效），**今天的真机截图里就能看到隐身/灵魂石/狙击手三枚徽标**。
   真正的缺陷是**「多画」**：原版那 7 格要 `hasIcon && isInPlayIcon && traitIcon != null`，我们只拿"有图"当替身 ⇒ **17 个词条我们画了、原版不画**（含 **先锋 vanguard**、盔甲、集结、飞行、伏击、猎杀标记、标记灯…）；另有**敌方伏击面朝下时原版整排不显示**，我们照画。
4. **清单里有没有**：**三层都有对应行，但没有一行覆盖上面这些差异**（详见 §四）。而且 `Badges.cs` 现在写的那句「`hasIcon/isInPlayIcon` 取不到」**已过期** —— 那两列 2026-10-23 起就在 `数据/游戏数据/trait_collection.json` 里（实测 77 条全带）。

## 二、T1·b · Duty / Pray / Oath / Ferocity / Agenda —— 效果是谁执行、哪一拍、要不要玩家点

### 2·1 原版模型（一句话：**它们不是"被动词条"，是"替代主动能力"**）

- 每张卡最多**一个**"主动能力"槽。`RawCardScript.GetActiveAbility`：
  **若 `hasAlternativeAbility(+0x2aa)` 且 `BoardAnalysis.MeetsCriteria(criteria=+0x2b0)` ⇒ 返回 `+0x2b8`（替代能力），否则返回 `+0x260`（普通主动能力）**
  ⇒ `Duty: …` 那一行**就是**这条卡在战斗界面里的"技能" —— 与原版那颗技能钮**同一个位置**（`attackType=4`）。
  （`D:RawCardScript__GetActiveAbility.c:1-20`）
- **什么时候触发**：玩家**点/悬停技能钮 → 选目标 → 释放**（`TryUsingActiveAbility` → `BattleManager._ResolvePlayActiveAbility` → `CardScript.ResolveActiveAbilityPlayed`）；**不是自动**。
- **用完之后**（`CardScript.UsedActiveAbility`）：
  · 非 oath ⇒ `+0x48 += 1`（"用过主动能力"计数，**替代能力自己的 `criteria` 就是拿它判"还能不能用"**）+ `ActivateBloodThirst`；
  · duty(0x4c4) ⇒ `BroadcastUnitDuty`；
  · agenda(0x4d3) ⇒ 抛 `TriggerAbilitySignal(0x2c1)`；
  · oath(0x4fb) ⇒ `PayActiveAbilityCostOath` + `TriggerAbilitySignal(0x2da)`；
  · ferocity(0x4f1) ⇒ `BroadcastUnitFerocity`；若没有 `dontReturnFerocity(0x4f6)` 且不在待死状态 ⇒ `AddRecallToDeck(…,3,…)` + `ActivateTraitParticlesFromCode(0x4f1)`。
  （`D:CardScript__UsedActiveAbility.c:1-90`）
- **用法闸**：`CardScript.CanUseAbilityNow` —— `hasActiveAbility(+0x220)`、能量够（oath 还要多一道 `CanUseOathAbility`）、`+0x228 ∈ {2,3,0x11}`。
  （`D:CardScript__CanUseAbilityNow.c:1-60`）
- **UI**：选择器那**一颗**技能钮（图标/数值见 §1·3；tip 见 §1·1 ⑨）；**没有**别的面板。
