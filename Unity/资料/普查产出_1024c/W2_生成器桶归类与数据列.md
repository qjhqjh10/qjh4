## 二 R4 · `ability` 桶不再收「未归口」的触发

### 2·1 判据（三条，都现读过）

1. **`EvtKind.Ability` ↔ 该卡的 `activeAbility`，⛔ 不是全部 `cardAbilities`**
   —— 同一份口径写在 **`工具/gen_card_anim_order.py` 的文件头**（不是本件新立的）：「若拿全表
   （含 `cardAbilities`）展开，会把出场/触发时机的动画播在『发动技能』那一拍上 —— 错误演示、
   而且看着有动画（完全静默），比少播更坏」。
2. **`ability` 桶是整桶播的**：`BattleDriver.PlaySignal` 的 `case EvtKind.Ability → VfxMap.Ability
   → FireEventAll → ResolveAllTimed(Ability)`（`BattleDriver.cs:18479 / 19325`），
   不走 `CardAnimOrder` 的那些卡**当场把整桶播完**。
3. **「引擎会发这个名字的 `EvtKind.Trigger`」这份名单的正本只有一份**
   = `CardPresentation/Core/VfxMap.cs` 的 `IsRoutedTriggerName`（正向锁 `MustRouteTriggerNames`、
   反向闸 `NoEmitTriggerNames`）。⇒ 生成器**在生成期解析这个 C# 源**（`routed_trigger_names()`），
   ⛔ 不在 Python 里抄第二份（本仓红线：两处写同一条规则 = 迟早不一致）。
   解析结果现读 **38 个名字**，并与 `MustRouteTriggerNames`（19 个）逐条交叉校验、与
   `NoEmitTriggerNames`（8 个）反向校验 —— **任一条不通过直接抛、停手**（⛔ 不许静默退化成空集）。

## 七 顺手发现（不属于本件，但下个会话该知道）

1. **AN1「screenShake 的 `presetPathID → 名字` 映射本机没有」是错的** —— 已在本件解决（§3·1）：

   这一项可以划掉**。

   AN1 的清单漏了（§3·2）。
4. `stats.traitAuthority.multiPlayBuckets` 那两个数（1070 → 1218）**不是这次改出来的** ——
