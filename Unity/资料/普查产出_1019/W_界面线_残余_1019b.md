### 3. `T16 / N45①` DXBC 逐条核 —— 已核完（原版 blur 的精确算法已解出）

**判据来源**：`bundle_scenes_scenes_mainmenuwarpforge/Shader/Shader_339.json`
（`m_ParsedForm.m_Name` = **`Everguild/FX/Two passes blur`**）·
材质 `Material/Material_3.json`（`m_Name = UI Blur` · `_Sigma = 2.25` · `_steps = 10`）。

**结构（实读）**
- 属性表只有三个：`_MainTex` · `_Sigma` · `_steps`（`_steps` 在 CB 里按 **Int** 传）。
- 2 个 pass；`m_PlayerSubPrograms` 映射：**pass 0 = 横向（blob 5/6/7）· pass 1 = 纵向（blob 8/9/10）**。
- DXBC 共 9 段（platform 4）：3 段 VS（三份**逐字节相同**）、3 段横向 PS（相同）、3 段纵向 PS（相同）。
  platform 18 解压后 `DXBC` 段 = **0**（不是 DXBC，Windows 用不到，未核）。
- 常量缓冲：`_MainTex_TexelSize` @32（`cb0[2].xy`）· `_Sigma` @48（`cb0[3].x`）· `_steps` @52（`cb0[3].y`，Int）。

**逐条指令解码（PS，横向那份，`Shader_339` blob 段 [3]）**
```
N     = (int)_steps                       ; cb0[3].y
half  = N / 2                             ; imax(-N,N) >> 1（整数、无符号右移）
inv   = 1.0 / (2π·σ²)                     ; r0.w，σ = cb0[3].x
for (k = -half; k <= half; k++)           ; §loop：break 条件 = (half < k)
    w  = inv·exp(-k²/(2σ²)) + inv·exp(-(k+1)²/(2σ²))   ; exp = 2^x，源码里乘了 1.442695 = log2(e)
    sum  += tex2D(_MainTex, uv + (k·_MainTex_TexelSize.x, 0)) · w
    wsum += w
out = sum / wsum                          ; o0.xyzw = r0.x · r2 —— **RGBA 全参与，alpha 不强制 1**
```
纵向那份只把 `_MainTex_TexelSize.x` 换成 `.y`（其余逐指令相同）。

**与我们的 `Shaders/UIBlur.shader` 的差异（逐条，⛔ 不是等价实现）**

| 项 | 原版（DXBC 实证） | 我们 | 判断 |
|---|---|---|---|
| 采样点数 | `_steps=10` ⇒ 只有 **11 抽**（k=-5..5） | 中心 + **±1..±10** ⇒ **21 抽** | ❌ 不同 |
| 权重 | `w(k)=g(k)+g(k+1)`（相邻两高斯相加在**同一抽**上） | `w(k)=g(k)` 对称 | ❌ 不同 |
| 有效 σ（σ=2.25 时实算） | **≈2.165**，且核**不对称**（均值 ≈ **−0.44 texel**） | ≈2.25，均值 0 | ❌ 不同（可见程度低，但是真差异） |
| `_steps` 语义 | **整数**、`/2` 取半 | 浮点 1..steps | ❌ 不同 |
| alpha | 参与模糊（归一化 RGBA） | 强制 **1**（文件头自陈「有意」） | ❌ 不同（有意的取舍） |
| 常数 `1/(2πσ²)` | 每个权重都乘（归一化后**抵消**） | 不乘（同样抵消） | ✅ 无可观测差 |
| 两趟方向 | pass 0 横 / pass 1 纵 | 同 | ✅ |
| 纹理/采样器 | t0/s0 · 只采 `_MainTex` | 同 | ✅ |

⇒ **结论：`N45①` 从「未核」变成「已核，且抓到 5 条真差异」**。我们的实现是「视觉上相近的高斯」，不是原版算法。
⚠️ 本轮**没有改** `Shaders/UIBlur.shader`（不在本写手白名单；且属行为变更）—— 建议主对话另派/另立账：
把文件头里「没有逐条核原版 DXBC / 本件没做」那段**过期自陈**改掉，并决定是否按上面算法 1:1 重写。
