  if idx < 2 (Intro=0 / MirrorMatch=1):

  else → 现行的 Chat_Messages/<id>-Chat<idx>
GetChatId(card) = chatMessagesReferenceId(+0x168) ?: customIntroReferenceId(+0x170) ?: 卡 id(+0x38)
talksFirst（CustomIntroChatData +0x20）另管「谁先说」（ChatManager.IsPlayerFirstIntro）

   `TAU2` 的 SO 列 5 个对手，I2 有 10 条（多 `BL36/IA/SOR/TAU65/TBC_IA`）；
   `ASH76` 的 SO 说 `ASH74`，I2 是 `{Drukari,SaimHann,UM46}`。
   ⇒ 键存在**不等于**原版会走那一档（原版闸门是 SO 里的 list）—— 硬用键集 = **猜**（铁律 2）。
2. **运行时没有那份数据**：`cards_engine.json` / `card_vfx_by_card.json` 只有 `refNameId`，
   **没有** `chatMessagesReferenceId` / `customIntroReferenceId` / 两个 custom 列表 / `talksFirst`
   （grep 0 命中）⇒ 要建必须先做**数据侧导入**（生成器 `工具/gen_cards_engine.py` 或新开一份伴生表），
   **不在本笔白名单**。
3. **`talksFirst` 是行为位、不是文本位**：它改「谁先说」（`IsPlayerFirstIntro`），I2 表里**没有**这个信息
   ⇒ 只做文本、不做它 = 半套机制（静默的行为差异），也违反「不做半套」。
4. **`-vs*` 18 条：查不到触发点** —— 当前 build 的 `stringliteral.json` 里**没有任何 `-vs` 字面量**，
   反编译里也没有方法拼它（`GetLocalizedChatMsg` 拼 `-Chat`、两个 CustomIntro 拼 `-`+id/枚举名）
   ⇒ 多半是旧版本遗留数据，⛔ 不建、也⛔ 不猜。
