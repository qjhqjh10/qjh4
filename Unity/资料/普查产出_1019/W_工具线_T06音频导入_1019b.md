### 2·4 `quality` 只能反推（明确标“推断”）

Unity 文档（本机 `UnityEditor.CoreModule.xml:6669`）：`quality` 是 **0–1**，含义是“**结果文件大小 / 源文件大小的比例（roughly）**”。
原版包里能测到的落地比值（`m_Resource.m_Size ÷ PCM 大小`，PCM = 时长 × 采样率 × 声道 × 2）：

| 类别 | n | 压缩/源比值 中位数 | 对应码率（中位） |
|---|---|---|---|
| `vo` Vorbis（mono） | 1742 | **0.0886** | 62.1 kbps |
| `vo` ADPCM | 115 | 0.2817（= 4 bit/16 bit 的理论值，符合 ADPCM） | — |
| `music`（stereo） | 2 | **0.0724 / 0.0755** | 102–107 kbps |
| `bgm`（stereo） | 25 | **0.0806**（0.0516–0.1933） | 73–273 kbps，中位 114 |
| 流式 `sfx`（stereo 为主） | 11 | **0.0540** | 62–79 kbps |

⚠️ 这是**行业惯例 + Unity 文档口径的推断**，不是原版直证：Unity 的 Vorbis 编码器在 `quality=1.0` 时到底给多少码率，本地没有可核的映射表。
⇒ **结论：`quality` 判不出原版值；先保持 1.0**。若以后要“码率也对齐”，验收办法：导入后用反射调 `UnityEditor.AudioUtil.GetSoundSize(clip)`（该 API 在本机 `UnityEditor.CoreModule.dll` 里存在）打印实际大小，
与上表的原版 `m_Resource.m_Size` 比；按差值调 `quality` 并重导。

### 3·1 探针代码（设计；⛔ 本次不写、不跑）

```csharp
// A1931 诊断：打印 FindAssets 返回集 vs 磁盘实际文件；再对漏项做一次 ForceUpdate 复测。
[MenuItem("Tools/CardPresentation/诊断音频导入覆盖(A1931)")]
public static void DiagnoseAudioImportCoverageCLI()
{
    string root = ArtDir + "/audio";
    foreach (var sub in new[] { "vo", "sfx", "music", "bgm" })
    {
        string dir = root + "/" + sub;
        if (!Directory.Exists(dir)) { Debug.Log($"[AUDIT] {sub}: 目录不存在 {dir}"); continue; }

        var onDisk = Directory.GetFiles(dir, "*.*", SearchOption.TopDirectoryOnly)
            .Where(p => p.EndsWith(".ogg", StringComparison.OrdinalIgnoreCase)
                     || p.EndsWith(".wav", StringComparison.OrdinalIgnoreCase))
            .Select(p => p.Replace('\\', '/')).ToList();
        var guids  = AssetDatabase.FindAssets("t:AudioClip", new[] { dir });
        var found  = new HashSet<string>(guids.Select(AssetDatabase.GUIDToAssetPath));
        var missing = onDisk.Where(p => !found.Contains(p)).ToList();

        Debug.Log($"[AUDIT] {sub}: onDisk={onDisk.Count} findAssets={guids.Length} " +
                  $"missing={missing.Count} extra={found.Count(p => !onDisk.Contains(p))}");

        // ① 漏项：看 importer / clip 各是什么（区分 α: FindAssets 漏 vs β: 导入失败 vs γ: 只是没跑设置）
        foreach (var p in missing)
        {
            var ai   = AssetImporter.GetAtPath(p);
            var clip = AssetDatabase.LoadAssetAtPath<AudioClip>(p);
            Debug.Log($"[AUDIT]   MISSING {p}  guid={AssetDatabase.AssetPathToGUID(p)}  " +
                      $"importer={(ai == null ? "null" : ai.GetType().Name)}  clip={(clip == null ? "null" : "ok")}");
        }
        // ② 找到的：看有没有“importer 类型不对 / clip 取不到”的静默异常
        foreach (var p in found)
        {
            var ai   = AssetImporter.GetAtPath(p);
            var clip = AssetDatabase.LoadAssetAtPath<AudioClip>(p);
            if (ai == null || ai.GetType() != typeof(AudioImporter) || clip == null)
                Debug.Log($"[AUDIT]   ABNORMAL {p}  importer={(ai == null ? "null" : ai.GetType().Name)}  clip={(clip == null ? "null" : "ok")}");
        }
        // ③ 对每个漏项做一次强制导入，再看它进不进 FindAssets（α/β 的分水岭）
        foreach (var p in missing)
        {
            AssetDatabase.ImportAsset(p, ImportAssetOptions.ForceUpdate | ImportAssetOptions.ForceSynchronousImport);
            bool now = AssetDatabase.FindAssets("t:AudioClip", new[] { dir })
                        .Select(AssetDatabase.GUIDToAssetPath).Contains(p);
            var ai = AssetImporter.GetAtPath(p);
            Debug.Log($"[AUDIT]   AFTER-IMPORT {p}  found={now}  importer={(ai == null ? "null" : ai.GetType().Name)}");
        }
    }
}
```

## §四 结论与建议

### 4·1 哪些有原版直证、哪些没有

- ✅ **有直证（包内 `AudioClip` 序列化字段，2434/2434 条全部对得上）**：
  `loadType` · `compressionFormat` · `preloadAudioData` · `loadInBackground` · `channels`（→ `forceToMono` 保持 false）· `sampleRate`（→ Preserve）· `ambisonic` / `3D`。
- ⚠️ **只能推断（明确标“推断”）**：`quality`（不在 clip 里；按 Unity 文档口径 + 原版码率反推，见 §2·4）。
- ⛔ **判不出（没有直证，保持现状）**：`normalize` · `conversionMode`。

### 4·2 改 `.meta` 还是改导入器？

**改导入器（扩展 `ArtBaker.ApplyAudioImportSettings`），⛔ 不要手改 `.meta`。**

理由：
1. `.meta` 是 Unity 生成的；手改写进去的值一旦资产被重导/新拷（换 guid）就丢，且没有“谁改的”记录。
2. 本仓红线“同一条规则只写一处”：现在是 `ArtBaker` 一处，扩它即可；手改 2434 个 `.meta` = 把规则散成 2434 份。
3. 导入脚本（`import_original_audio.py` / `import_battle_sfx.py` / `import_battle_bgm.py`）每次重跑都可能带来新文件；**设置步骤必须是可重复、全覆盖、幂等的**。
