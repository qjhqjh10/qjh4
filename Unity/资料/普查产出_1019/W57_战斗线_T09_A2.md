## 四、顺手发现（记账，⛔ 本波不改白名单外的东西）

1. **`HudExtraDrawnPx` / `CameraResetButtonDrawnPx` 的语义随 A2 变了**：它们读 `HudPiece.SizePx`（= `sizeDelta`），
   而 A2 把 `sizeDelta` 改回**节点 rect** ⇒ 这两个口现在回的是节点 rect、**不是**「画出来的尺寸」。
   已在 `BattleScene.cs` 的 A1302 / A423 两段就地订正（改为按 `Image` 的内接算法现算），并在两个口自己的 doc 上写明。
2. **`HudButtonsBlocked` 原来漏了 `_logPanel`**：旧手搓链靠 `HandleBattleLog` 的「面板开着 ⇒ 无条件接管」挡住底下，
   uGUI 下没有那道挡箭牌 ⇒ 日志面板开着时点 HUD 钮会穿透（例如**结束回合**）。已补。
3. **A1 遗留缺口**：进攻卡钮迁 uGUI 后，世界侧输入没有被挡（点它在 x[0,109] y[447,554]，正压在棋盘左缘上）。
   本批的 `PointerOverHudButton` 把它一起包进来了（原版 `IsPointerOverUIObject` 语义）。
4. **`ClickEndTurnHud` 必须显式补三条闸**（当前行动方 / 暂停中 / 模态）—— 旧链靠 `Update` 的先后顺序天然满足；
   换成 uGUI 后不写就是「对面回合也能结束回合 / 暂停中也能结束回合」（静默、画面正常）。
5. **另一代理在 00:02 正在写 `RuleEngine/Core/EffectResolver.cs`**：本波最后一次 typecheck 中途撞上它的 3 条半成品错误
   （`CS0128` / `CS1503` / `CS0103`，全在该文件）—— 按 CLAUDE.md 13·3 判为**别人的活**，等它写完后复跑 ⇒ 绿。
   ⛔ 没有去改别人的文件。
6. **A964 E4 的 settings 白名单核销**：原来那条「`_settingsBtn` 藏起来照样接管（已知隐患）」是因为
   `ImageQuad.Contains` 不看 `activeSelf`；uGUI 的 `activeInHierarchy` 闸让这个隐患**自然消失**。
7. **`_allianceBtn` 的 `SetAspect(W/H)` → `SetNodeRect(W,H,false)`**：数值逐位相同，但后者把「rect 就是命中矩形」
   这件事写成了显式判据（⛔ 不再依赖 1×1 占位贴图的尺寸）。
8. `BattleEventSystem.cs` / `BattleHudButton.cs` **本波一个字没改**（A1 的口够用：`Attach` / `ClickForTest` /
   `ClickCountForTest` / `ResetClickCountForTest` / `HasAction` / `SyncRaycasters` / `Instance`）。
