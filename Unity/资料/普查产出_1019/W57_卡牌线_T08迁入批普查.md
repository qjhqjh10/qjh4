## 三、`A1848` 的 `pick_id` 段（**读全**）

### 3·1 `pick_id` 是什么

`工具/gen_cards_engine.py:932-938`：

```python
def pick_id(cands, faction):
    """从候选里挑**这张阵营**的那一个。挑不出（0 个或多个）返回 None —— **不猜**。"""
    pre = PREFIX_OF.get(faction)
    if not pre: return None
    hit = [cid for cid, _ in cands if cid.startswith(pre) and cid[len(pre):].isdigit()]
    return hit[0] if len(hit) == 1 else None
```

- **输入** `cands` = `load_ids()`（`:903-915`）从 `card_ids.json` 的 `mapping` 建的 **`{归一化卡名: [(id, 卡名), …]}`** 里按**我们的卡名**取出的候选。
- **判据** = ① `id` 以本阵营前缀开头（`ID_PREFIX`，`:879-893`，前缀↔阵营是 `decklists.json` 的实际统计）② 前缀之外**全是数字** ③ 候选**恰好 1 个**；否则返回 `None`（**不猜**）。
- ⇒ **它只认「前缀 + 纯数字」的原版短 id**；32 位 GUID 形态的 `uniqueId` 它**永远挑不出来**（这是 `A1800` 的第一根因，见 `:801-802`）。

### 3·2 谁消费

**唯一的真实消费者 = `gen_cards_engine.build()` 的 id 解析块**（`:2257-2299`）：

| 顺序 | 函数 | 现读行号 | 作用 |
|---|---|---|---|
| ① | `pick_direct_id(id_direct_tbl, …)` | `:2270` | **现行唯一身份判据**：按 `(阵营码, 归一化卡名)` 从「原版 `uniqueId` 直取表」取；唯一落位才认 |
| ② | `pick_truth_id(truth_idx, …)` | `:2272` | 名级联（官方英文名 → `m_Name` 尾巴 → `cardName`），**只作交叉校验**；直取落空时才真的兜底 |
| ③ | `pick_id(id_by_name.get(...), faction)` | `:2276` | **老路、第三级兜底**：`pick_truth_id` 也落空时才用 `card_ids.json` |
| ④ | `make_id(faction, name)` | `:2294` | 自造 id；**末尾硬断言禁止**（`:2940-2966`，`id_made != 0` ⇒ 非零退出、一个字节都不写） |

- 产出的 `id` 写进 `cards_engine.json` → `RuleEngine/Data/CardDatabase.cs` → 全引擎 / 存档 / 回放 / 立绘 / 语音 / 图标 / VFX / 预组牌全部按它走。
- `gen_card_id_truth_index.py:9` 的 docstring 也提到 `pick_id`，但**只是说明「它只认前缀+纯数字」**，不是调用方。

### 3·3 原版真值怎么取（现行三层）

1. **真值本体**：`TRUTH_CARDS_SRC = 资料/普查产出_1018/allcards_1350/cards_raw.json`（`:851`，**当前 build 1,351 张**，K06 换源）；`load_truth_cards()`（`:1097-1130`）按 `uniqueId` 建键。
