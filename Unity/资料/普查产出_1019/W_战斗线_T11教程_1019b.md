## 五、顺手发现（照实报，⛔ 本批没改）

1. 🔴 **T11 规格 §九.4「`dontDrawCard`/`dontDrawTalent` 读点没找到」不成立** —— 读点是
   `BattleManager__TurnStartCardDraw.c:14-18` 与 `CardScript__OnTurnStart.c:157-171`（见 §三 G-3）。
2. 🔴 **T11 规格 §八「`playerTurnEndEnchantment` / `enemyTurnEndEnchantment` 无读点」不成立** ——
   读点 = `BattleManager__ResolveEndTurnEnchantment.c`；且偏移是 **0x78/0x80**（`dump.cs` 现读）。
3. **原版 `ShowPlayerActionAnim` 会对【任何】`playerAction` 且 `textReference` 非空的动作建一条小提示**
   （用动作自己的 `GetTipPosition` + 强制 `preventSkipTip`）；我们只在 `Kind == SmallTip` 时才画提示。
   ⇒ 「等玩家那一拍」的提示面**比原版窄**（不是 7 条缺口之一，未见有人记过）。
4. **T11 规格 §八说 `actionOnPlayerResign`「6 关全非空」容易被读成「有内容」** —— 实际是**非 null 的空动作**
   （`actionType` 空串、`scriptedActionData` 0 条）。已在 `PlayTutorialResignAction` 注释里写明。
5. **`dontDrawCard` 数据**：S1 的 `Player 1` 回合就写着 true —— 若将来接上 G-3，**第 1 关第 1 回合会少一张起手**，
   自检里所有按「起手/牌库张数」写的期望值都要跟着核。
6. `TutorialStage +0x60/+0x70` 是 `skipNormalBattleEndOnVictory/Defeat`（已有注释正确）——
   别因为 G-4 的新注释把它们又认成 enchantment（offset 冲突的那条坑）。
