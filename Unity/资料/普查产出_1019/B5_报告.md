### 1 · 同名单位血账（消费 `InstanceId`）

**根因**：`资料/普查产出_1018/W_战斗线_串行与阻塞.md` §五 —— 棋盘是「连续无洞」模型（插人推人 / 外补位），
格号会变；同名两张换格之后旧口径（`Dictionary<HpKey,int>`）会把「引擎已扣、还没演到」的那一笔
加到**换上来那张卡**的卡面上，而被打那张永远停在旧值。

**判据（第一权威）**：原版每个目标在**受击那一拍**才改 HP（`_ResolveMultiDamage…:136-168`）；
原版「单位身份」= `CardScript + 0x22c` 的本局唯一号（E12 落进 `BattleEvent.InstanceId`，
`d:/2/tools/decomp_full/BattleCardManager__GetCardFromUniqueId.c:33` 等，见 `BattleEvent.InstanceId` 的 doc）。

**改法（`Battle/BattleDriver.cs`）**

- 账型：`readonly Dictionary<int, PendingHpEntry> _pendingHp`（键 = `CardInstance.Id`；
  `PendingHpEntry { amount, owner, name, slotAtNote }`）——— `:12731-12755`。
  另有第二本账 `_pendingHpBySlot`（`HpKey → FIFO<(instanceId, amount)>`），**只作 `InstanceId == 0` 的退路**。
- `NotePendingHp`（`:13190`）：
  - `e.InstanceId != 0` ⇒ **直接记那一份**（先确认它还在场上：`TryFindInstanceSlot`）；同名换格也不会认错人；
  - `InstanceId == 0` ⇒ 退回「(座位,格号) + 名字」的旧口径（如实保留）。
- `CompletePendingHpBeat`（`:13243`）：
  - `e.InstanceId != 0` ⇒ **直接销那一份的账**（`DropPendingHpQueueEntry` 把 FIFO 里同一笔摘掉），
    再 `RefreshInstanceData` 按实例找它**现在**那一格刷卡面；
  - 否则依次退到 FIFO → 当前住户 → 「记账格号 + 名字」。
  - 主路径**不会**因为「账没了」去扣别人头上的账（`:13292` 那条 `e.InstanceId == 0` 守卫）。
- 空位清理：`SyncBoard` 的 `u == null` 分支改调 `DropPendingHpForSlot`（`:15303` 调用 · `:13360` 定义）：
  人不在场 ⇒ 作废；人挪到别的格 ⇒ 那一笔挂到**新格**的 FIFO（旧事件格仍销得掉）。
- 显示：`ToBoardCardData` 改按 `u.Instance.Id` 查账（`:13524`）。
- 跨局 / `DropSignals`：`_pendingHp` 与 `_pendingHpBySlot` **成对清**（`:3321-3322` · `:13520-13521`）。
- 测试口：`PendingHpForTest(owner, slot)` 仍按格号调，但内部解成「现在站在那一格的单位」的实例（`:12848`）。

### 2 · `autoPlayFromHand` 的手牌飞行

**判据**：原版 `BattleManager._ResolveCardAutoSummoned_d__511__MoveNext.c:104,122,187` →
`CardScript.PlayEnemyCard/PlayPlayerCard` → `MoveIntoFieldFromHand` —— 与真人出牌**同一段**手牌起飞。
（引擎侧消费约定：`RuleEngine/Core/BattleEvent.cs` 的 `DeploySource.AutoPlayFromHand`；E11 已落。）

**我们的形状**：`EffectResolver` 的 `op.AutoPlay` 是「先进手牌 → `SetupCardInHand` → 立刻拿掉 →
`DeployFree(fromHand:true)`」，整段**同步算完** ⇒ 那张牌从来没在画面上落到手里。

**改法（`Battle/BattleDriver.cs`）**

- `CompletePendingDeploy`（`:13449-13465`）：AI 票那一支之后新增
  `else if (animateFeel && e.DeployFrom == DeploySource.AutoPlayFromHand)` ⇒ 订一张飞行票
  （`handIdx = 当前手牌张数`）+ 落地 cue 押后（`_aiDeployLandingCue`）。
  **复用** B2/B3 那套票箱/载体/落地交接（⛔ 不另造第二套）——`SyncBoard`/`PlayBattleSfx`/`PlaySignal`
  的消费点都按 `HpKey` 通用，不看座位。
- `StartAiDeployFlight`（`:15021`）：
  - 手牌卡背载体**只在对手侧**用（`:15052`，我方手牌是 `CardView`，且那张牌画面上没进过手）；
  - 退路起点按 `owner` 选手牌布局（`:15114`）：我方 = `hand` + 引擎手牌张数；
  - **索引超过现有张数 ⇒ 按「张数 + 1」取末位**（`:15116-15126`）—— 那正是那张牌被
    `Hand.Add` 进去时会占的位置（紧接着就被 `Remove`）。

  与 AI 那条同一份判据；`PlayBattleSfx(Deploy)` 的四条被票跳过 —— `:13653` 那段）。
