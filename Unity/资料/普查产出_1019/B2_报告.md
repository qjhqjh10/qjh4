## 二、证据（文件:行号 + 对拍报告条目）

### 偏差 7 · 触发式多播一件原版没有的通用特效（`R` §4 #7）

- **原版判据**：`CardScript.ActivateTriggerTraitAnim` 只做两件事 ——
  `BattleCardUI.HighlightTraitIcon`（徽标脉冲）+ `DisplayTriggerAnim`（状态框）；
  全量反编译里**没有**任何「触发 ⇒ 播某件通用 prefab」的调用点。
- **改前**：`PlaySignal` 的 `case EvtKind.Trigger: evt = VfxMap.Trigger;`（= `Faith_trigger_unit`）
  ⇒ 每一次关键词触发都在那格播一件**原版没有的**金色符记。
- **改后**：
  - `Battle/BattleDriver.cs:13374` 新增纯函数 **`GenericVfxFor(BattleEvent)`**（事件 → 通用特效名，
    `null` = 没有）。`PlaySignal` 的唯一消费点：`:13471`。`Trigger` 回 `null`（`:13394`）。
  - 触发仍然有反馈（原版那三样都还在）：`PlayFeel → PlayTraitPulse`（徽标 + `TraitFrames.DisplayTrigger`）
    `:13538` 一带的 `PlayTraitParticles`。
  - 生产里 `VfxMap.Trigger` 那一行**已无消费者**（`Core/VfxMap.cs` 不在本批白名单 ⇒ 没删；
    见 §三·1 的接口需求）。
- **断言**：`Editor/BattleScene.cs:24009-24015` —— `Trigger == null`（主断）+ `Death == null`（对照）
  + `Play == VfxMap.PlayCard`（**灭自证**：不是恒 null）。
  另在 §二 的「触发效果」小节把**旧断言**（`:7797`）改成 `FiredCount(VfxMap.Resolve(VfxMap.Trigger)) == 0`
  —— 那条旧断言原来**把错口径钉死了**（正是「自检绿 ≠ 口径对」那一类）。

### 偏差 8 · AI 出牌没有落位演出（`R` §4 #8）

- **原版判据**：AI 走**同一条** `BattleManager._ResolvePlayCardFromHand`（`R` §2·2）——
  牌离开手牌 → `MinionPlayedIntoField`（0.3 飞向格位上方 → 0.05 悬停 → 0.2 落下，见
  `Board/DeploySequence.cs` 文件头逐条出处）→ 落地反馈。
- **改前**：`AfterAiAction` 只 `RefreshAll`，视图由 `SyncBoard` **直接建在终点**（没有位移）。
- **改后**：
  1. **票**：`DriveAiTurn` / `FinishAiTargetingAnim` 在 `SimpleAI.ExecuteAction` **之前**记「这一手打的是
     手牌第几张、那张叫什么」（`CaptureAiPlayTicket`，`BattleDriver.cs:12919`，调用点 `:11673` / `:11754`）；
     `SimpleAI.PlayTurn` 那条路（自检 / `-wfdrive`）由 `OnAiExecuted` 用 `AiAction.HandInst` 补票。
  2. **订飞行**：`CompletePendingDeploy`（`:12887`）在 `Deploy` 演到那一拍、且票与
     `Deploy.CardId` 对得上（+ 2 s 窗口）时，把这一格订成「要演飞行」，落地 cue 同时押后。
  3. **起演**：`SyncBoard` 建出视图的那一帧调 `StartAiDeployFlight`（`:14373`）—— 用
     **玩家那条同一组生产函数**（`DeploySequence.Play` + `BoardLayout.DropTargetWorld[AtHeight]`）：
     起点 = `foeHand.SlotPosition(idx, n)` / `RotationAt` / `EnemyCardScale`（敌方手牌原位），
     终点 = `PoseFor` 的 3D 位姿；飞行段归 HUD 正交相机画、落地那一刻切回 `ArenaLayer`
     （与玩家 `DoPlay` 那次交接同一个判据：屏幕上同点）。
  4. **不许被外层同步拉回去**：`RefreshAll` 的顺序是 `PlaySignals → SyncBoard ×2`，飞行是在
     `PlaySignals` 里的那次 `SyncBoard` 起演的 ⇒ **紧接着外层那次 `SyncBoard` 必须跳过层与位姿**。
     新增 `_aiDeployFlying`（`:12515`）+ `IsAiDeployFlying`（`:14331`）+ `SyncBoard` 的守卫（`:14584`）。
     ⚠️ 这是本件**最容易漏、且最会骗过断言**的一处（卡「确实动过」但一帧就被拉回终点）。
  5. **票不会烂在账上**：视图本来就在、这一格没走「新建」⇒ 飞行演不了 ⇒ 票与落地 cue 一起作废
     （`BattleDriver.cs:14595` 一带）—— 不删的话以后那一格**每次 `Deploy` 都会被吞掉四条 cue**（静默丢音）。
  6. **落地那一拍**：`PlayAiDeployLandingVfx`（`:14341`）= 卡淡入 `VfxMap.Deploy` + 阵营召唤法阵 +
     扬尘 + 震镜头 —— 这几件在 `PlaySignal` 里因「这一拍是起飞」被跳过（`:13538` / `:13588`）。
- **断言**：`Editor/BattleScene.cs:24154-24222` —— 起点在飞（0.2 s 位移 > 0.01）+ 落地段还在走
  （0.2→0.8 s 又一段位移）+ 落地 cue 结账，**灭自证** = 关掉 `animateFeel` 走同一套夹具 ⇒ 不订飞行、视图一动不动。
  飞行次数用生产计数口 `AiDeployFlightsStartedForTest` 的**增量**判（不依赖内部 map 的瞬时状态）。

### 偏差 10 · 快进 / 跳过（`R` §4 #10）

## 三、没查清 / 缺什么 / 接口需求

   （背面翻面 / 卡框层都在）；我们飞的是 `CardView.Create(..., CardFace.Board)` 刚建出来的场上样式。
   起点/终点/时长/缓动逐值同源 ⇒ **轨迹与节奏对**，外观差一层「卡框/背面」。要完全复刻得把
   手牌视图搬上场（那是 `CardInteraction` 那条路的另一份实现），**另开一笔**。
3. **AI 飞行的覆盖面**：只认「`DriveAiTurn` / `FinishAiTargetingAnim`（执行前记票）+ `SimpleAI.PlayTurn`
   （`OnAiExecuted` 里用 `HandInst` 补票）」这三条。**效果召唤 / 触发产物 / 教程脚本出的牌不飞** ——
   原版那几条是 `_ResolveCardAutoSummoned` / 脚本路径，判据没查（`R` §5 没列），本批不猜。
4. **联机里「对手打出的单位」不飞**：远端动作用 `ApplyLoggedAction` 直接落引擎，没有「手牌第几张」的票
   （`NetApply` 那层不传 HandIdx）。这是**既有**限制（偏差 8 只点名 AI），要补得让 `NetProtocol.MsgAction`
   带手牌下标 —— **跨线接口**，本批不动。
5. **偏差 9 的边界**：没有飞行的路（召唤物 / 批量脚本）保持四条同拍。原版 `_ResolveCardAutoSummoned`
   那两条 cue 在哪一拍响**没查**；查到之后再决定要不要给它们也拆（不是「不做」，是判据未定）。
6. **偏差 10 的「真跳过入口」**：如果将来做**回放播放**（我们已有 `ReplayStore` 录制），原版那套
   `ClickPlayReplay` / `ClickPauseReplay` + `+0x521` 跳过策略要照做 —— 那是回放线，不在战斗线。
7. **顺手发现（未改，属别人/别的账）**：
   - `PlayUnitDamageCue` / `PlayMeleeHitCues` 仍是「生产不再调用、只给自检」的口（B1 已记）。
