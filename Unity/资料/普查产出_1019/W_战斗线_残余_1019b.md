### 3·1 偏差 5：`NonTargetSpellPlayed` / `TargetedSpellPlayed` 到底是什么

**逐句读**（`d:/2/tools/decomp_full/`）：

- `CardScript__NonTargetSpellPlayed.c`：
  1. `cardState(0x228) = 6`；
  2. `rawCardData(0x28)` 的**虚表槽 `0x308/0x310`** 一次调用，实参 `(manager, this, this, null)`；
  3. `IsTheSameTurnPlayed` ⇒ `OnTrigger(0x24e, …)`；
  4. `BattleManager.BroadcastTacticPlayed`（遍历场上卡 → `CardScript.TacticPlayed`，后者只在 `HasCurrentTrait(0x410)` 时转 `rawCardData.OnTacticPlayed`）；
  5. `CardScript.GoToCemetery`（`CemeteryManager.AddCardToCemetery`）。
- `CardScript__TargetedSpellPlayed.c`：同上，但 `(manager, this, param_2, param_3)`；之后若 `param_2/param_3` 同侧且目标带 trait **`0x47e`**：写目标的 `synapseCard(0x288)` → `ActivateTraitParticlesFromCode(0x47e)` → 对**相邻单位**逐个 `IsValidTarget`（虚表 `0x318/0x320`）→ `OnCardPlayedWithTargetJustThisCardPlayed` → `BroadcastUnitSynapse`。
- **虚表槽的身份**（这是本条的钥匙，B1 当时没认出）：IL2CPP 的 `VirtualInvokeData` 是 **16 字节一对**（`methodPtr` / `MethodInfo*`）⇒ `+0x308` 的方法指针配 `+0x310` 的 MethodInfo、`+0x318` 配 `+0x320`。和 `RawCardScript.cs` 的**虚方法表**对：`+0x308` 的 4 参形态 = `OnCardPlayedWithTarget(BattleManager, CardScript thisCard, CardScript cardPlayed, CardScript targetCard)`；`+0x318` 的 2 参形态 = `IsValidTarget(CardScript thisCard, CardScript targetCard)`（两者在桩里都是 `virtual`）。
- **结论**：**这两个方法里没有任何「演出」调用** —— 它们是玩法触发（我们的 `EffectResolver` 已经覆盖同一语义）。看得见的东西只有下面三件：
  1. 战术卡那条 **`playMinionFromHand`（2D）**：非目标支在 `_ResolvePlayCardFromHand…:621-624`；目标支在 `BattleManager__Update.c:288-291`（拖进场那一刻）。**我们原来一条都没播** ⇒ 已补（见改动清单）。
  2. **`DissolveWholeCard`**（`:638` / `MoveIntoFieldFromHand:80`）：逐句 = `DOScale(Vector3.one × spellPlayedScale, 0.2)` + `BattleCardUI.FadeCardItems(0, 0.2)`。目标向量读的是 `Vector3` 的静态块（`DAT_1842da2a8 + 0xb8 → +0xC = one`；类身份反证 `资料/普查产出_1011/审查_W1.md:113`），`VarsGlobal+0x40 = spellPlayedScale = 1.0` ⇒ **目标就是 (1,1,1)**、**没有位移**、两条补间都没 `SetEase`（吃 DOTween 默认 OutQuad）。已照抄。
  3. **目标战术卡的 `StartTargetedSpellAnim`**：`BattleManager__StartTargetedSpellAnim.c` 把 **`heroCard.rawCardData.targetedSpellAnim(0x130)`** 实例化在卡的 2D 位置。🔴 **这一位在本 build 是空的**：`资料/普查产出_1018/allcards_1350/cards_raw.json` 的 `full_raw` 里，**1,351 张卡（含 66 个 `cardType=10` 督军）的 `targetedSpellAnim` / `nonTargetedSpellAnim` 两个 PPtr 全是 (FileID 0, PathID 0)**；同一份 `full_raw` 里 `cardImageReference` 是正常 GUID（说明不是导出漏字段）⇒ **原版本身没有做这条**（铁律 11 例外①），⛔ 别补一个自造的。
- ⚠️ **仍差的三点（如实记）**：
  · **AI / 远端打出的战术卡没有溶解**：原版 AI 也走同一条 `_ResolvePlayCardFromHand`；我们只有玩家那条 `DoPlay` 有溶解，敌方手牌是卡背 `ImageQuad`、也**没有「这一手是战术卡」的票** ⇒ 现在只是把手牌卡背摘掉。要做需给敌方战术卡一张票（接口需求）。
  · **目标战术卡的溶解时机**：原版在**拖进场那一刻**（`BattleManager.Update` → `MoveIntoFieldFromHand`）就溶解；我们统一在松手后的 `DoPlay`。时长/形状对，**时刻晚一段**。
  · **卡池里没有的卡**（教程 / 自设计阵营 `StarterCards`）在 `EvtKind.Play` 上 `CardDatabase.Find` 取不到 ⇒ **判不出单位/战术** ⇒ 这条 `playMinionFromHand` 不播，并由 `BeatSoundOff` 出声（每张卡一次）。⛔ 没拿「猜一个」代替。
