## 三、没查清的部分（⛔ 不猜，给「还差什么」）

1. **「编辑模式下 `SetActive(true)` 会派 `OnEnable`」这条前提**：本仓有两份实证
   （`W3_子2.md` §2·4③ · `已知的坑.md:1125` 的反面表述），但本波**不能跑 Unity 复核**。
   ⇒ 已加**双保险**：`SetActive(false)→AddComponent→SetActive(true)` + `EnsureCurrentInEditMode()` 反射兜底（会出声）。
   若两条都不成立，断言 #1 会红，并留下 `[BattleEventSystem]` 的 LogError。
2. **`InputSystemUIInputModule.OnEnable` 在批处理（无输入设备）下的日志/行为**（计划 §六·3）：
   本机源码确认没绑动作时会 `AssignDefaultActions()`（`InputSystemUIInputModule.cs:1639-1656`），但没实跑。
   ⇒ 第一批跑 `BattleScene.Run` 时**要观察日志**有没有 InputSystem 的告警。
3. **`Graphic.depth` 在批处理编辑模式下 `Canvas.ForceUpdateCanvases()` 之后是否有效**：
   如果仍是 `-1`，#9/#10 会红。那是「第一次实测」的预期风险（计划 §六·4 同口径）。
4. **`EventSystem.RaycastAll` 在 `ScreenSpaceCamera` + 正交相机 + `planeDistance 20.3` 下的排序**：
   本机只做了源码核对（`GraphicRaycaster.Raycast` / `MultipleDisplayUtilities` 在编辑器 Windows + New Input 下
   返回 `(x,y,displayIndex=0)`，不会走 `Display.activeEditorGameViewTarget` 那条 fallback），**没跑过**。
5. **`Button` 组件有没有必要**：计划说「加 `Button`（`transition=None`）**或**直接实现 `PointerClick`」——
   本波选了后者（理由见 §一·2）。若后续窗口需要 `Selectable` 的悬停态/导航，再补 `Button`。
6. **`HudPiece.SizePx` 的拉伸锚边界**（计划 §六·1）：A1 这颗是点锚，不受影响；A2 把全屏 blocker 当可点件时要先定读法。

## 四、顺手发现（记账，⛔ 本波不改白名单外的东西）

1. **`HudButtonWorldPosForTest` 的键表原来是三份 `switch` 复制**（世界坐标 / 显隐 / 写口），
   不是 A964 文案写的「两处」。本波收成 `HudButtonPieceForTest` 一处（顺手按铁律「两处写同一条规则」收口），
   并把 `Editor/BattleScene.cs` 那句文案订正了。
2. **`BattleDriver.TickHudButtonFeedback` 仍然用 `_offensiveBtn.Contains(world)` 判悬停/按下反馈**（`:8798-8799`）。
   那是**纯视觉反馈**、不是点击路径（不触发动作），本波**没动它**。如实记：
   uGUI 迁移完成后，悬停反馈的判据理论上也应换成 `IPointerEnter/Exit`（归 `T09` 后续步骤），否则
   「指针在钮上但被面板挡住」时反馈会亮（面板挡射线、但手搓 `Contains` 不知道）。
3. **`HudCanvas.cs` 文件头第 3 条与 `GraphicRaycaster` 那两句注释是过期状态**（「这一轮不建」）——已就地订正。
4. **`资料/已知的坑.md:4415` 与 `W3_子2.md` §2·4③ 的表述需要合看**：
   前者说「分界是类型带不带 `[ExecuteAlways]`」，后者说「激活那一刻会派 `OnEnable`」。
   两者对**建的时候就是活的**那些脚本不矛盾（前者讲 AddComponent 路径），但措辞容易读成互斥。
   本波按后者写了实现 + 兜底；**建议战斗线收口时把这条并成一句**（不在本波白名单）。
5. **`BattleScene.Run` 不 `SaveScene`**（只有 `BuildAndSaveScene` 存盘，而它**不调 `Begin`**）
   ⇒ A1 新建的 `EventSystem` **不会被烘进 `Scenes/Battle.unity`**（与计划 §〇·6「uGUI 层运行时建」一致）。
