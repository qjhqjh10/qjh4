### 1·1 总口径（唯一）

原版「可点区域」= **该钮子树里每一颗 `m_RaycastTarget == 1` ∧ 祖先 active ∧ `m_Enabled == 1` 的 Graphic**，
**先各自按自己的 `m_RaycastPadding` 修正**（分量序 **L,B,R,T**；**负值 = 外扩**），**再取并集**。
⛔ 不是 `m_TargetGraphic` 那一处（三个反例 / 四关判据 → `资料/普查产出_第四会话/普查_全仓命中区与关闭键族.md` §〇-1）。

   - `SetColliderNotInHand(state)`：`state != 0xB && != 6` ⇒ 开主 box、关大 box；`state == 0xB/6` ⇒ 主 box **关**。
