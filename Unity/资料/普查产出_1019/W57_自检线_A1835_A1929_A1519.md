### `A1519` —— `ProfileData.AvatarIndex` 是 `public static` 可变字段（**已硬化**）

**选了哪个方案、为什么**：选 **「属性 + `SetAvatarIndexForTest`」**（判据件的甲案），
而不是只加一个复位口。理由：
1. 收成**属性 + 私有后备字段**后，写口只剩 **一处**（将来要加审计 / 夹取只改这一处）；
2. `SetAvatarIndexForTest` **返回原值**，把「原值是什么」固定成一次数据传递 ⇒ 调用方不用自己再存一份
   （省掉「存了但存错时机」那一类坑）；
3. **setter 必须留 `public`**：生产侧 `Shell/AvatarTab.cs:419` 也在写（玩家真选头像），
   而自检与生产分属两个程序集、两边都要写 ⇒ C# 做不到「只给自检可见」。
   ⇒ 硬化落在「**唯一写口 + 成对的测试 API + 写点清单（谁改谁还原）**」这三件上，而不是权限收紧。
4. `setter` **不夹取**（与原来的字段逐位同语义），越界值仍由 `AvatarArt` / `AvatarName` 两个读口各自 `Clamp`。

**改前 vs 改后**（`Shell/ProfileData.cs`）：
- 改前 `:205`：`public static int AvatarIndex = 0;`（可变 public 静态字段，无还原纪律、无写点清单）。
- 改后 `:204-244`：属性 `AvatarIndex { get; set; }` + `static int _avatarIndex` +
  `SetAvatarIndexForTest(int) → 原值` + `RestoreAvatarIndexForTest(int)`；
  doc 里列全**已知写点**（生产 `AvatarTab` / 自检 `MainMenuScene` · `BattleScene`）与「谁改谁还原」。
- 本文件内的调用点已示范新写法：`Editor/MainMenuScene.cs:1793-1802`
  （`SetAvatarIndexForTest((AvatarIndex + 7) % Count)` → 收尾 `RestoreAvatarIndexForTest(oldIdx)`，
  行为与改前逐位相同）。
- ⚠️ **没有**顺手改 `TitleIndex`（同族的 `public static` 可变字段）—— 见 §四·1，本波不越界。

## 四、顺手发现（只报不改）

1. **`ProfileData.TitleIndex` 是同族的 `public static` 可变字段**（`Shell/ProfileData.cs:245` 附近，
   `public static int TitleIndex = -1;`）—— 与 `A1519` 完全同性质（自检改了会跨节漏）。
   本波白名单只要求 `AvatarIndex`，**没动它**；建议下一批按同一形状硬化（属性 + 成对测试 API）。
2. **`Editor/BattleScene.cs` 的 `AvatarIndex` 写入仍是手写保存/还原**（`:17402` 存、`:17599/17602/17623/17630` 写、
   `:17651` 还原）。静态扫过 `17402..17651` 之间**没有**会跳过还原的外层 `return`（只有局部 lambda 里的 return）
   ⇒ 今天不漏；但该文件不在本波白名单，**没改**。下次动它时建议换成
   `SetAvatarIndexForTest` / `RestoreAvatarIndexForTest`（与 `MainMenuScene` 同形）。
3. **`CheckAt` / `CheckAtWorld` 仍是全文件通用的「只比中心」助手**，本波只给齿轮那一处补了边界。
   其余调用点（信封 / 挑战 / 导航钮 / 玩家信息块…）**同样存在「缩一半照样绿」的盲区**。
   新助手 `CheckRenderedQuadEdges` 可直接复用 ⇒ 建议另立一条账逐处补（本波不越界）。⚠️ 注意：
   字那一族不能直接用它（`RenderedRect` 的中心仍取节点位置，见 `TmpRenderedRect` 的 doc）。
4. **参考图那副「铺场流」比现在的演示牌更适合当排序夹具**：同费用段有 2/3/4 张不同卡（演示牌只有 1/2/3），
   且卡名覆盖「中文码点序 ≠ 英文名序 ≠ Id 序」—— 若将来排序断言需要更强鉴别力，可考虑照那副牌造夹具
   （⛔ 但别直接改 `PlayerDeckForDemo`：另有断言按它「满 30 张」的形态在跑）。
5. **`A1814` 报告里的行号全部已漂**：`Editor/MainMenuScene.cs:931` 那条裁决性断言现在在 `:1049-1060`，
