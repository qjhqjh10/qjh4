## 三、没查清（如实登记）

1. **`EventPopupVariant.EventHelp` 的运行期观感没验**：本轮只核了「GUID → `Event Help Popup Variant`」与根 MB 的 `titleTextTag=0 / descriptionTextTag=12`；`BaseEventPopup` 对 `EventHelp` 的版面支持存在，但**没有跑 Unity/player 看实际渲染**（按本轮口径不做验收）。
2. **「我的卡组」在原版这扇窗里 lore 显示什么，判据只到「没有 lore 数据」这一层**：`DeckGeneralInfoDemo.ShowPayerDeckInfo.c` 里 lore 取的是 `*(this + 0x90)`（缓存的 Demo DeckInfo），而练习窗原版列的是演示/预组卡组 ⇒ 我们的自建卡组没有对应 SO。我们按「空 + 出声」办，**没有拿别的文案顶**。
3. **103 副预组里有 25 副本地没有 lore**（Demo DeckInfo 之后新增的卡组，如 `ASH_SK_4` / `ORK_SK_5` / `AeldariDeck6`）。这些键在官方表里也**不存在**，⇒ 留空 + 出声，不是漏接。
4. **练习窗仍列「我的卡组」而不是原版的 78 份 Demo DeckInfo** —— 这是普查报告里已登记的既有偏离（`W_C §4.1`），本轮**没有动它**；lore 只在通过 `Deck Selection Popup` 选到预组时出现。
5. **`Leviathan` 的 lore 键在原版资产里是交叉的**：`Demo DeckInfo Leviathan 4` 的 classic 是 `LeviathanDeck4` 但 `loreLocalizationKey = Demo/LeviathanDeck5`，`Leviathan 5` 反之。我们**照资产 PPtr 原样**落表（`LeviathanDeck4→Demo/LeviathanDeck5`、`LeviathanDeck5→Demo/LeviathanDeck4`），不是笔误；若原版运行时确有交换，这是**原版数据如此**。
