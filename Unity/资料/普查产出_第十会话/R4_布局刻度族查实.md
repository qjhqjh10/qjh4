### 1·2 Q1：原版 preferred width **算得出** —— 给数

**公式**（`d:/4/Unity/MyGame/Library/PackageCache/com.unity.ugui@27635d171b1a/Runtime/TMP/TMP_Text.cs:3684-3717`）：
```csharp
float fontSize = m_enableAutoSizing ? m_fontSizeMax : m_fontSize;   // ← 用【上限】，不是 m_fontSize
float preferredWidth = CalculatePreferredValues(ref fontSize, margin, false, wrapMode).x;   // margin = ∞
```
单字形 advance = `glyph.m_Metrics.m_HorizontalAdvance × (fontSize / faceInfo.m_PointSize) × faceInfo.m_Scale × character.m_Scale × glyph.m_Scale`；
preferred width = Σ（+ `m_characterSpacing`，这三颗都是 0）。

**字体 = `Pragati-Regular SDF`**（判据：`Victories title` 的 `m_fontAsset = {m_FileID: 5, m_PathID: 3485036404935369831}`；
menus 包的 externals[5] = `CAB-62d1945b7005c115fb946f0d264a205b`；在 `fonts_assets_all.bundle` 里
pid `3485036404935369831` 的 `m_Name` = **`Pragati-Regular SDF`**）。
`m_PointSize = 95.0` · `m_Scale = 1.0` · **无 kerning**（`m_KerningTable` 空、`m_FontFeatureTable.m_GlyphPairAdjustmentRecords = 0`、
ligature/multipleSubst 也是 0）⇒ **advance 求和就是精确值**。

| 文案 | 字号 | **算出的 preferred width** |
|---|---|---|
| `Victories: ` | 53.5 | **176.98** |
| `Termina en: 23d 5h`（prefab 出厂文案，西班牙语） | 38.0 | **248.44** |
| `Termina en: 3d 5h` | 38.0 | 232.51 |
| `Termina en: 123d 12h` | 38.0 | 280.29 |
| `Total Victories`（`751`） | 77.0 | 96.81 |

⚠️ 三条**限定**（不是「算不出」，是「这个数不是唯一真值」）：
① 值**依赖字体**——本工程装的是 `NotoSerifCJK-Regular SDF`（`Resources/Fonts/`），我们画出来的宽度**本来就不等于**原版；

### 1·4 Q3：裁定 = **要复刻 CSF 那一档**（铁律 11：全部要做，只有先后）

- **判据**：原版三颗 `m_SizeDelta.x = 0` + `ContentSizeFitterMinMax(h:PreferredSize)`（§1·1 现读）。
- **我们框架有没有对应机制**：**没有**。`Shell/MenuDraw.cs:1843-1866` 的 `TextCore` 收的是一个固定 `PxRect`；

### 2·3 裁定：**真偏离**

原版那两颗在屏上：Score 字号 48×1.148 = **55.1** 画布 px（框 133.32）· Collect 55×1.32 = **72.6**（框 280.88）。

⇒ 相对框小 **1/1.148 = −12.9%**（Score）· **1/1.32 = −24.2%**（Collect）（= P8 说的 ≈13% / ≈24%）。
