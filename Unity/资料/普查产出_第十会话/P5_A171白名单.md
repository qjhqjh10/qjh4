## 五、新加的那条区间断言

```csharp
if (lb.AutoSizing && px > 0f)
{
    float now = lb.FontPxNow;
    float lo = Label.FontSizeToPx(lb.FontSizeMin) - TolPx;
    float hi = Label.FontSizeToPx(lb.FontSizeMax) + TolPx;
    bool inRange   = now >= lo && now <= hi;
    bool staleAtBase = !lb.gameObject.activeInHierarchy && Mathf.Abs(now - px) <= TolPx;
    ...越界 ⇒ autBadN++，把 `名字=实得∉[lo,hi]` 印出来
}
```

- **它挡什么**：`min`/`max` 落错档（例如把 `autoMaxPx` 传成 `fs`）· 收敛值跑到钳位区间之外。
- **两条守卫都带名字**：`autBadN > 0` 时印 `名字=10.80∉[9.00,31.50]` 这种串（⛔ 不是只印计数）。
- 🔴 **唯一一处「不是全量断」的地方，如实说清**：**未激活的 `Label` 只放行「停在 `base`」那一档**。
  理由 = **TMP 不给未激活的对象重排**（`TextMeshPro.cs:2114` `OnPreRenderObject` 头一句
  `if (!IsActive() && !m_ignoreActiveState) return;`）⇒ 那颗的 `fontSize` 是**写在 `SetAutoFitBox` 里的 `base`**、
  **不是「渲出来的字号」**（同族判据 = `CheckAutoFit` 的 `skipRendered` 那一格 · `D2` §2 也记了「未激活 ⇒ 实得 = base」；
  实测那 5 颗外链钮正是 `10.80 = base`）。⛔ 但它**不是静默跳过** —— ③ 的字段断言照样管它，`autN` 也把它算进去（下面那条会印总数）。
- **覆盖闸**：`CheckTrue(autN >= 10, …)` —— 本窗开自适应的 `Label` 数（按调用点算 ≈ 60+）远大于 10 ⇒ 不会「扫了个空」还报绿。
